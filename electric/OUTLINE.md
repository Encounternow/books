# 《動手玩電：給國中生的電學、電子學與電路學實作課》全書大綱

檔名規則：`src/XX-章名.md`，XX 為兩位數章號。附錄用 `src/appendix-X.md`。

## 第零部　開始之前
- 00-前言.md：給老師與家長、給同學、怎麼使用這本書、安全守則、器材總表、示波器與邏輯分析儀是什麼（一頁預告）

## 第一部　基礎電學
- 01-電是什麼.md：電荷、電流（A）、電壓（V）、導體與絕緣體、閉合迴路、GND 的意思、水流比喻；認識麵包板與杜邦線；第一次用三用電表量電池電壓；第一個電路：電池+電阻+LED。
- 02-電阻與歐姆定律.md：電阻（Ω）、色碼、用三用電表量電阻、V = I × R 與三種變形、LED 限流電阻怎麼算（含 LED 順向電壓）、實驗：改變電阻看 LED 亮度並量電流。
- 03-串聯與並聯.md：串聯總電阻相加、並聯倒數相加（只教兩電阻情況的乘除公式 R1R2/(R1+R2)）、電壓分配與電流分配、克希荷夫兩定律用「水管分流」講、分壓器公式、可變電阻與電位器、實驗：分壓器量各點電壓、並聯 LED。
- 04-電功率與電池.md：P = V × I、瓦特、電阻發熱（摸摸看 1/4W 電阻超載）、電池的 mAh、估算一顆電池能亮多久、電池內阻（量空載與負載電壓差）、USB 5V 供電、Arduino 的 5V/3.3V 腳能給多少電流、串聯電池與並聯電池。

## 第二部　電子元件與訊號
- 05-電容.md：電容像水桶、法拉與 µF、極性、充電與放電、RC 時間常數 τ = R × C（只教「5 個 τ 就充飽」）、實驗：用 LED 看電容放電變暗、用三用電表看電壓慢慢下降、用示波器第一次看充放電曲線（Arduino 產生方波經 RC）。延遲關燈電路。
- 06-示波器入門.md：示波器在看什麼（電壓對時間的畫圖）、探棒與 1×/10×、接地夾、V/div、s/div、觸發（Trigger）為什麼重要、自動/一般模式、游標與自動量測（Vpp、頻率、週期）、實驗：量電池（直線）、量 Arduino 方波、量 ESP32 或 Arduino 產生的不同頻率、把兩個通道一起看。
- 07-電感與電磁.md：電流生磁（自製電磁鐵）、磁生電（線圈+磁鐵+LED 或三用電表 mV）、電感（H）、電感抗拒電流變化、反電動勢（為什麼關掉線圈會出現高電壓尖波）、飛輪二極體、繼電器構造、直流馬達原理、實驗：用示波器看關掉電感/馬達時的尖波，再加二極體看尖波消失。
- 08-二極體與LED.md：單向導通、順向壓降 0.7V（1N4007）與 LED 的 1.8–3.2V、逆向、整流（用 Arduino 方波或自製線圈的交流當訊號源，示波器看半波整流）、保護用途、LED 種類與電流、七段顯示器簡介（可選）。
- 09-電晶體.md：電晶體是「用小電流控制大電流的水閥」、NPN 的 B/C/E、基極電阻計算（簡化：IB = (5-0.7)/RB，放大倍數 β 約 100，只要 IB 夠就飽和）、當開關驅動馬達與蜂鳴器、MOSFET IRLZ44N 與 G/D/S、達靈頓簡介、實驗：Arduino 經電晶體開關馬達；用示波器看電晶體集極電壓反相。
- 10-交流訊號與濾波.md：直流 vs 交流、正弦波、頻率、週期、振幅、Vpp、方波與 PWM（占空比）、RC 低通濾波：把 PWM 平均成直流（示波器前後對照）、濾波為什麼能去抖動與去雜訊、蜂鳴器與音調（頻率 → 音高，用 tone() 做電子琴，示波器量頻率）。

## 第三部　數位電路與微控制器
- 11-數位邏輯.md：0 與 1、HIGH/LOW 與電壓門檻、二進位數與十進位換算（0–255）、AND/OR/NOT/XOR 真值表、用兩個按鈕與 Arduino 模擬邏輯閘、用邏輯閘組合做簡單判斷（例如：門開 AND 天黑 → 亮燈）、上拉與下拉電阻、按鈕彈跳（用示波器或邏輯分析儀看彈跳）。
- 12-Arduino入門.md：Arduino UNO 板子構造（腳位、USB、電源）、安裝 Arduino IDE、第一個程式 Blink、setup 與 loop、pinMode/digitalWrite/digitalRead/delay、序列埠監控視窗 Serial.begin/println、按鈕控制 LED、變數與 if、用示波器看 digitalWrite 的波形與 delay 時間對照。
- 13-感測器與類比輸入.md：類比與數位的差別、ADC 與 analogRead（0–1023，ESP32 0–4095）、把讀值換算回電壓、光敏電阻+10kΩ 分壓、可變電阻調整、map()、DHT11 溫濕度（用函式庫）、實驗：自動夜燈、用序列繪圖器畫曲線、用示波器看分壓點電壓變化。
- 14-PWM與馬達控制.md：analogWrite 與 PWM（0–255）、呼吸燈、用示波器量占空比與頻率（UNO 約 490Hz / 980Hz）、SG90 伺服馬達與 Servo 函式庫（用示波器看 1–2ms 脈波）、直流馬達+電晶體+PWM 調速、ESP32 的 ledcWrite。
- 15-通訊協定與邏輯分析儀.md：為什麼晶片之間要「講話」、序列與並列、UART（TX/RX、鮑率、起始/停止位元）、I2C（SDA/SCL、位址、主從）、SPI 簡介、邏輯分析儀是什麼與示波器差在哪、安裝 PulseView、接線（GND 一定要接）、實驗：擷取 Serial.println 並解碼看到字元、擷取 Arduino 與 OLED 的 I2C 訊號並解碼看到位址 0x3C、改鮑率看波形變化。
- 16-ESP32與無線.md：ESP32 與 UNO 差別（3.3V、Wi-Fi、藍牙、雙核）、在 Arduino IDE 安裝 ESP32 板、腳位注意（只能 3.3V 輸入、哪些腳不能用）、連 Wi-Fi、做一個網頁伺服器用手機控制 LED、讀取 DHT11 顯示在網頁、顯示在 OLED、MQTT 概念介紹（可選）、深度睡眠與省電簡介。

## 第四部　專題製作
- 17-專題製作.md：專題流程（問題 → 規劃 → 接線 → 程式 → 測試 → 展示）、5 個專題各含材料/接線/完整程式/延伸：(1) 智慧夜燈（光敏+PWM 漸亮）、(2) 溫濕度氣象站（DHT11+OLED+ESP32 網頁）、(3) 手機 Wi-Fi 遙控風扇（ESP32+MOSFET+馬達）、(4) ESP32 迷你示波器（ADC 快速取樣，序列繪圖器畫波形，與真示波器比對）、(5) 電子琴/反應遊戲（按鈕+蜂鳴器+邏輯）。最後一節：怎麼寫專題報告與上台展示。
