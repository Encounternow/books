# 前言　開始之前

## 這本書是給誰的

這本書是寫給**想自己動手搞懂電的人**。主要對象是國小五、六年級程度較好的學生與國中生，但完全沒碰過電子的大人也可以從第 1 章讀起。它假設你會四則運算、會把 a = b × c 移項、看得懂折線圖，其他都從零開始。

它的目標不是讓你背公式，而是讓你**親手把電路接起來、親眼用儀器看到電在做什麼**。

市面上的電學教材常常分成兩種：一種只講理論，算了一堆歐姆定律卻沒摸過電阻；另一種只教 Arduino 接線和複製程式碼，做出會動的東西卻不知道為什麼會動。這本書把兩者接在一起：每個概念都有一個「動手做」的實驗，每個實驗都盡量用**示波器**或**邏輯分析儀**把看不見的電壓與訊號畫出來。當你第一次在示波器上看到電容充電的圓弧曲線、第一次用邏輯分析儀解碼出 Arduino 傳出的 "Hello"，那個「原來如此」的瞬間就是這本書存在的理由。

## 給同學：怎麼讀這本書

1. **一定要動手做。** 只看不做，一週後就會忘光。
2. **接錯了不要怕。** 本書只用低電壓，最糟糕的狀況是燒掉一顆幾塊錢的零件。但請遵守下面的安全守則。
3. **每章的「想一想」要真的想。** 答案就在底下，但先想過再看，才會真的學到。
4. **把量到的數字記下來。** 書裡有很多空白表格，填上去。真正的工程師都會記錄數據。
5. **卡關的時候看「常見錯誤與除錯」和附錄 E。** 你遇到的問題，九成別人也遇過。
6. **一週一章就好。** 一章約 2–3 小時含實驗，全書大約半年。不要趕，實驗做完、數字填完再往下。
7. **已經玩過 Arduino 的人**可以從第 5 章開始，但請回頭補第 2、3 章的計算，後面的章節都靠它們。

## 給陪讀的家長

你不需要先懂電學。和孩子一起讀、一起接線、一起轉示波器的旋鈕就好。你最有用的角色是：

- **採購與整理器材**：附錄 A 有完整清單與購買提示。零件用分格盒裝好、貼上數值標籤，孩子才不會把時間花在找零件上。
- **安全把關**：讀一遍下面的安全守則，實驗前看一眼接線，尤其是電解電容的正負極與電池有沒有短路。
- **卡關時陪著查**：先翻該章的「常見錯誤與除錯」和附錄 E，再一起拿三用電表逐段量，通常都找得到問題。不要直接給答案。
- **讓孩子自己操作儀器**：示波器與邏輯分析儀是本書的特色，請讓孩子親手按按鈕、轉旋鈕，大人示範一次就好。

本書的器材都是台灣電子材料行與網購容易買到的常見零件，全書只用 12V 以下的直流電。

## 怎麼使用這本書

全書分成四部，共 17 章加附錄：

| 部 | 章 | 內容 | 主要工具 |
|---|---|---|---|
| 第一部　基礎電學 | 1–4 | 電流、電壓、電阻、歐姆定律、串並聯、功率、電池 | 三用電表、麵包板 |
| 第二部　電子元件與訊號 | 5–10 | 電容、示波器、電感、二極體、電晶體、交流與濾波 | 示波器 |
| 第三部　數位與微控制器 | 11–16 | 數位邏輯、Arduino、感測器、PWM、通訊協定、ESP32 | Arduino、邏輯分析儀、ESP32 |
| 第四部　專題製作 | 17 | 五個完整專題與展示方法 | 全部 |

每一章都有固定的段落：**本章目標 → 開場 → 核心概念 → 動手做 → 用儀器看看 → 常見錯誤與除錯 → 想一想 → 本章小結 → 名詞表**。你可以先讀目標和小結，知道這章要學什麼，再回頭仔細讀。

本書的電路圖用文字符號畫，看起來像這樣：

```
 Arduino D9 ──[ 220Ω ]──►|── GND
                        LED
```

`──` 是導線，`[ 220Ω ]` 是電阻，`►|` 是 LED 或二極體（箭頭方向是電流可以流的方向），`GND` 是接地（電路的「零點」）。每個實驗的文字圖下面還會有一張彩色的**麵包板接線圖**，照著插就可以。這些符號和正式的電路符號怎麼對照，請看**附錄 G**。

## 安全守則（一定要讀）

本書只用 **12V 以下的直流電**，來源是電池、USB、Arduino 或 ESP32。這些電壓不會電到人。但還是有幾件事要注意：

1. **絕對不碰家用插座。** 牆上的 110V 交流電會致命。本書任何實驗都不需要它。
2. **電池不可以短路。** 用導線直接把電池正負極接在一起，電線會發燙甚至起火。9V 電池與鋰電池尤其危險。
3. **電解電容有正負極，接反會爆。** 長腳是正極，殼上有白色條紋那邊是負極。接電源前先檢查兩次。
4. **電阻、電晶體摸起來燙就先拔掉電源。** 表示有東西接錯或電流太大。
5. **線圈、馬達、繼電器一定要加飛輪二極體**（第 7 章會教），不然會產生高壓尖波打壞 Arduino。
6. **示波器探棒的接地夾只能接電路的 GND。** 接到別的地方可能燒壞示波器或你的電路。
7. **接線時先拔掉電源，接完檢查再接上。** 養成這個習慣可以避免九成的意外。
8. **LED 一定要串電阻。** 沒有電阻的 LED 會在一秒內燒掉。

## 示波器與邏輯分析儀是什麼（一頁預告）

這兩台儀器是本書的主角，第 6 章和第 15 章會完整教。這裡先讓你有個印象。

**三用電表**只能告訴你「現在的電壓是 3.2V」，一個數字。但電路裡的電壓常常是一直在變的，例如 Arduino 讓 LED 每秒閃一次，電壓就是 5V、0V、5V、0V 一直跳。三用電表看不出來。

**示波器（Oscilloscope）**就是一台「把電壓隨時間的變化畫成圖」的機器。橫軸是時間，縱軸是電壓。你會看到方波、正弦波、電容充電的圓弧線、馬達關掉時的高壓尖波。它讓看不見的東西變成看得見。

```
電壓
 5V ┤    ┌────┐    ┌────┐
    │    │    │    │    │
 0V ┼────┘    └────┘    └──── 時間
```

**邏輯分析儀（Logic Analyzer）**專門看數位訊號，也就是只有 0 和 1 的訊號。它一次可以看 8 條線，而且可以幫你「翻譯」：Arduino 用序列埠印出 "Hello"，邏輯分析儀能把那串 0 和 1 解碼回 H、e、l、l、o 給你看。晶片之間怎麼講話，用它一看就懂。

```
CH0 (TX) ─────┐ ┌─┐ ┌───┐ ┌─┐ ┌─────
              └─┘ └─┘   └─┘ └─┘
             起始 0 1 0 0 1 0 0 0 停止  → 'H'
```

準備好了嗎？翻到第 1 章，我們從一顆電池和一顆 LED 開始。
