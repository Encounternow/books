# 圖片放這裡

章節裡用 Markdown 語法插圖，路徑相對於 `src/`：

```markdown
![第 2 章 LED 限流電路的麵包板接法](images/02-led-breadboard.jpg)
```

- 檔名建議：`章號-內容.副檔名`，例如 `05-rc-charge-scope.png`。
- 照片請縮到寬 1600px 以下、單張 500KB 以內，網頁才不會太慢。
- 示波器截圖：多數示波器可以插 USB 隨身碟按 Save 存成 PNG。
- 邏輯分析儀截圖：PulseView 用 File → Export → PNG。
- 電路圖：用 Fritzing 畫麵包板圖（最適合初學者），或用 KiCad 畫標準電路圖，匯出 PNG/SVG。
