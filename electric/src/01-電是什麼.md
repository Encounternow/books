# 第 1 章　電是什麼

## 本章目標
- 學完你會用「水流」的比喻，說出電荷、電流、電壓各是什麼，以及它們的單位。
- 學完你會分辨導體與絕緣體，並且解釋為什麼電路一定要「繞成一圈」才會動。
- 學完你會看懂麵包板裡面哪些孔是相連的，知道杜邦線該插哪裡。
- 學完你會用數位三用電表量電池的電壓，也會把電表「串」進電路裡量電流。
- 學完你會親手接出人生第一個電路：電池＋電阻＋LED，而且知道每個零件為什麼要在那裡。

## 開場：一顆不亮的燈

小安的手電筒壞了。他把電池拿出來，換上新的，還是不亮。他把電池反過來裝，不亮。他把燈泡轉一轉，喀的一聲，燈亮了！原來是燈泡沒鎖緊，金屬接點之間有一點點空隙。

「只是一點點空隙，電為什麼過不去？」小安問。

這是一個非常好的問題。電不是魔法，它很像水：水要流動，需要水壓、需要水管，而且水管不能斷掉。電要流動，需要電壓、需要導線，而且整條路一定要繞成一個圈。只要中間有一小段斷掉，哪怕只有一根頭髮那麼細的縫，電就不走了。

這一章，我們要先搞懂「電」到底是什麼東西、它怎麼流、靠什麼推動。接著你會認識兩個以後每一章都會用到的好朋友：麵包板和三用電表。最後，你會接出自己的第一個電路，親眼看到 LED 亮起來，然後用電表量出它「吃」了多少電。

## 核心概念

### 電荷：會互相推擠的小東西

用塑膠尺摩擦頭髮之後去吸小紙片，那就是電荷（Electric Charge）在作怪。

所有東西都是由原子組成的，原子裡有帶正電的質子和帶負電的電子（Electron）。平常正負一樣多，互相抵消，東西看起來「沒電」。但電子很輕、很容易被搬走，某個地方電子多了或少了，那裡就帶電了。

電荷有一個很重要的脾氣：**同性相斥、異性相吸**。電路裡的電流，說穿了就是一大群電子因為被推、被吸而一起移動。

電荷的單位是庫侖（Coulomb），記作 C。一庫侖是非常多的電子，大約是 6 後面再接 18 個零那麼多顆。本書幾乎不會直接用到庫侖，但它是理解「電流」的基礎。

### 電流：每秒流過多少電荷

想像一條水管，你想知道水流得多「大」，最自然的方法就是問：**每秒鐘流過多少水？** 每秒 1 公升，和每秒 10 公升，當然是後者水流比較大。

電流（Current）就是這個意思：**每秒鐘流過導線某一個截面的電荷量**。

> 電流 I ＝ 電荷量 Q ÷ 時間 t

電流的單位是安培（Ampere），記作 A。1 A 就是每秒流過 1 庫侖的電荷。

**算一個例子：** 如果 10 秒內有 5 庫侖的電荷流過一條導線，電流就是 5 ÷ 10 ＝ 0.5 A。

在我們的電路裡，1 A 其實是很大的電流，LED 這種小東西只需要大約 0.01 A 就很亮了。所以你常會看到一個更小的單位：毫安培（mA），1 mA ＝ 0.001 A，也就是 1 A ＝ 1000 mA。例如 0.02 A 就是 20 mA；反過來，7 mA 就是 0.007 A。

**電流的方向：** 全世界都約定電流從電源的正極（＋）流出，經過電路，流回負極（－）。有趣的是，真正在動的電子其實是反方向跑的，這是歷史上先約定方向、後來才發現電子的結果。整本書我們都照「正極流向負極」來想，所有公式都是這樣定義的，不會出錯。

### 電壓：推動電流的「水壓」

水為什麼會從水塔流到你家的水龍頭？因為水塔比較高，有「水壓」在推。水塔越高，水噴得越有力。

電壓（Voltage）就是電路裡的水壓：**兩個點之間「推動電荷的力道」的差距**，也叫電位差。單位是伏特（Volt），記作 V。

請記住：**電壓永遠是「兩點之間」的東西。** 說「這裡有 5V」其實是省略了「比另一點高 5V」，就像「水塔 20 公尺高」是指「比地面高 20 公尺」。

**算一個例子：** 一顆 3 號電池大約 1.5V，意思是正極比負極高 1.5V。把兩顆頭尾相接（第一顆的正極接第二顆的負極），就像把兩座水塔疊起來，總電壓是 1.5 ＋ 1.5 ＝ 3V。

生活中常見的電壓：

| 電源 | 電壓 |
|------|------|
| 3 號電池（一顆） | 約 1.5V |
| 9V 方型電池 | 約 9V |
| USB 充電孔 | 5V |
| Arduino UNO 的 5V 腳位 | 5V |
| ESP32 的 3V3 腳位 | 3.3V |
| 家用插座 | 110V（本書絕對不碰） |

本書只用 12V 以下的直流電，摸到不會有感覺，很安全。但家用插座的 110V 可以讓人受傷甚至死亡，**全書任何實驗都不可以接插座**。

### 導體與絕緣體

水要流動需要水管，電要流動需要能讓電子通過的材料。

- **導體（Conductor）**：電子可以在裡面自由跑的材料。金屬都是導體，像銅、鋁、鐵。鹽水和人體也能導電（所以濕手摸電很危險）。
- **絕緣體（Insulator）**：電子跑不動的材料。像塑膠、橡膠、玻璃、乾木頭和空氣。

你手上的杜邦線就是「銅線（導體）外面包塑膠皮（絕緣體）」，讓你可以安全地拿著線。

### 閉合迴路：電一定要繞一圈

這是本章最重要的觀念，也是小安手電筒的答案。

想像水族箱的水泵：水從水泵出來，流過水管、過濾器，然後**再流回水泵**。如果把回程的水管剪斷，水泵還是在轉，但水不會持續流動，因為沒有路可以回去。

電路（Circuit）這個英文字本來就是「繞一圈」的意思。電流從電源正極出發，經過導線和零件，一定要能夠**回到電源負極**，整個圈完整無缺，電流才會流。這叫做閉合迴路（Closed Circuit）。

圈圈某處斷開了（開關打開、導線鬆脫、燈泡沒鎖緊），叫做斷路（Open Circuit），電流是 0。

相反的狀況叫短路（Short Circuit）：電流找到一條「幾乎沒有阻礙」的捷徑，直接從正極衝回負極，不經過零件。這時電流會非常大，電池會發燙、甚至漏液。**絕對不要用導線直接把電池的正極和負極接在一起。**

```
   閉合迴路（LED 會亮）         斷路（LED 不亮）           短路（危險！）

    ┌──[ 1kΩ ]──►|──┐         ┌──[ 1kΩ ]──►|─ ─┐        ┌─────────────┐
    │           LED  │         │           LED   │        │             │
   ─┴─ 9V            │        ─┴─ 9V        斷開 │       ─┴─ 9V         │
   ─┬─               │        ─┬─                │       ─┬─            │
    │                │         │                 │        │             │
    └────────────────┘         └─────────────────┘        └─────────────┘
                                                          電流只走導線，
                                                          沒有任何零件擋住
```

### GND：大家約定的「海平面」

我們說「玉山海拔 3952 公尺」，意思是比海平面高 3952 公尺。海平面就是大家約定的「0 公尺」。

電路裡也需要一個約定的「0V」，叫做接地（Ground），簡寫 GND。電路中每一點的電壓，都是「跟 GND 比，高了多少」。

- 用電池時，電池的負極（－）就是 GND。
- 用 Arduino 或 ESP32 時，板子上標著 GND 的腳位就是 GND。它們的 5V 腳位，意思就是「比 GND 高 5V」。

之後用示波器時，探棒的黑色鱷魚夾一定要夾在 GND；三用電表的黑棒通常也接 GND。先記住這個觀念，以後會省很多麻煩。

### 認識麵包板

麵包板（Breadboard）是一塊布滿小孔的塑膠板，裡面藏著一條一條的金屬夾片。零件的腳插進孔裡會被夾住，不用焊接就能接電路，拆掉重接也方便。

重點是：**哪些孔在裡面是連在一起的？** 這是初學者最容易接錯的地方。請仔細看這張圖：

```
   ┌───────────────────────────────────────────────────────┐
   │ ＋ ○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○  ＋ │ ← 電源軌：整排橫向相連
   │ － ○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○  － │ ← 電源軌：整排橫向相連
   │                                                       │
   │        a   b   c   d   e        f   g   h   i   j     │
   │  1     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○  1  │
   │  2     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○  2  │
   │  3     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○  3  │  ← 每一「列」的 a–e
   │  4     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○  4  │     五個孔相連，
   │  5     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○  5  │     f–j 五個孔相連，
   │  ⋮     ⋮   ⋮   ⋮   ⋮   ⋮   溝槽  ⋮   ⋮   ⋮   ⋮   ⋮      │     但 e 和 f 之間
   │ 30     ○═══○═══○═══○═══○        ○═══○═══○═══○═══○ 30  │     被中間溝槽隔開
   │                                                       │
   │ ＋ ○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○  ＋ │
   │ － ○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○═══○  － │
   └───────────────────────────────────────────────────────┘

   ═══ 代表裡面有金屬片相連
```

請記住三條規則：

1. **中間的主區域：同一列的 a、b、c、d、e 五個孔是連在一起的；f、g、h、i、j 五個孔也是連在一起的。** 但 e 和 f 之間有一條溝槽，兩邊不相通。上下不同列（例如第 1 列和第 2 列）也不相通。
2. **兩側的電源軌（標著＋和－的長條）：整排橫向相連。** 我們習慣把電源的正極接到＋軌，GND 接到－軌，這樣整塊板子到處都能拿到電。
3. **注意：** 有些比較長的麵包板，電源軌在正中央會斷開成左右兩段。拿到新麵包板時，先用三用電表的蜂鳴檔（本章後面會教）確認一下。

所以，如果你把 LED 的兩隻腳分別插在 a3 和 b3，它們會被同一條金屬片連在一起，等於把 LED 短路，當然不會亮。正確做法是把兩隻腳插在**不同列**，例如 a3 和 a4，或者跨過溝槽插在 e3 和 f3。

### 杜邦線

杜邦線（Jumper Wire）是接麵包板用的細導線，接頭有兩種：**公頭（Male）** 是一根金屬針，可以插進麵包板或 Arduino 的孔；**母頭（Female）** 是一個小洞，可以套在模組的針腳上。「公公線」兩端都是針，「公母線」一端針一端洞。本書大部分時候用公公線。

### 三用電表怎麼量電壓

三用電表（Multimeter）是電學實驗最重要的工具，可以量電壓、電流、電阻（所以叫「三用」）。本書用數位三用電表，有液晶螢幕、旋轉開關、兩支測棒（紅、黑）。

**量電壓的四個步驟：**

1. **插測棒。** 黑色測棒插進標著 **COM** 的孔（Common，共同端）。紅色測棒插進標著 **V**（通常是 VΩmA 或 VΩ）的孔。
2. **轉旋鈕。** 轉到直流電壓檔，記號是 **DCV** 或 **V⎓**（V 加上一條直線和一條虛線）。注意不要轉到 ACV（交流電壓，記號是 V~），那是量插座用的。如果你的電表有好幾個數字檔位（200m、2、20、200、1000），請選**比你要量的電壓大一點點**的那個：量 1.5V 的電池選 2V 或 20V 檔；量 9V 電池選 20V 檔。如果你的電表是「自動量程」，就只要轉到 V⎓ 就好。
3. **把測棒跨在兩點之間。** 紅棒碰電壓高的那一點（電池正極），黑棒碰電壓低的那一點（電池負極或 GND）。量電壓時，電表是「並排」在零件旁邊的，電路照常運作，不需要拆線。
4. **讀數字。** 螢幕顯示的就是兩點之間的電壓。如果出現負號（例如 −1.48），表示紅黑棒碰反了，大小還是對的，電表不會壞，調換一下就好。

```
   量電壓：電表「跨」在兩點之間，不用拆電路

          ┌──[ 1kΩ ]──┬──►|──┬───┐
          │           │  LED  │   │
         ─┴─ 9V      紅棒    黑棒  │
         ─┬─          │       │   │
          │        ┌──┴───────┴─┐ │
          │        │  三用電表   │ │
          │        │   V⎓ 20   │ │
          │        └────────────┘ │
          └───────────────────────┘
           這樣量的是 LED 兩端的電壓
```

### 三用電表怎麼量電流

量電流跟量電壓**完全不一樣**，這是初學者最常搞混、也最常把電表弄壞的地方。

回想水管：要知道水管裡每秒流過多少水，你得把水管切開，把流量計**接在水管中間**，讓所有的水都從流量計流過去。電流也一樣：**你必須把電路切開一個缺口，把電表串進去，讓電流從電表裡面流過。** 這叫做串聯（Series）量測。

**量電流的五個步驟：**

1. **插測棒。** 黑棒還是插 **COM**。紅棒要換插到標著 **mA** 的孔（有些電表寫 VΩmA，和量電壓同一個孔；有些電表有獨立的 mA 孔，請看孔旁邊的字）。如果你的電表另外有一個 **10A** 或 **20A** 的孔，那是量很大電流用的，本書大部分實驗用不到。
2. **轉旋鈕。** 轉到直流電流檔 **DCA** 或 **A⎓**。選比你預期的電流大一點的檔位，例如預期 7 mA 就選 20m（20 mA）檔；完全不知道多大就先從 200m 檔開始。
3. **先把電源拔掉**（拔掉電池扣或 USB），再把電路切開一個缺口。例如把電阻和 LED 之間的導線拔掉。
4. **把電表接進缺口。** 紅棒接電流「進來」的那一邊（靠近電源正極的那一邊），黑棒接電流「出去」的那一邊。然後接回電源。
5. **讀數字。** 單位要看你選的檔位：20m 檔顯示 7.03 就是 7.03 mA。

```
   量電流：電表「串」在電路中間，所有電流都要流過電表

          ┌──[ 1kΩ ]──┐           ┌──►|───┐
          │           │           │  LED  │
         ─┴─ 9V      紅棒         黑棒     │
         ─┬─          │           │       │
          │        ┌──┴───────────┴──┐    │
          │        │    三用電表      │    │
          │        │  A⎓ 20m  mA孔   │    │
          │        └─────────────────┘    │
          └───────────────────────────────┘
           電阻和 LED 之間切開，電表補上去
```

**三個絕對要記住的警告：**

- **量電流時，電表內部幾乎是一條沒有阻礙的導線。** 如果你在電流檔把兩支測棒直接碰電池的正負極（像量電壓那樣跨接），就等於把電池短路，電表裡的保險絲會燒斷，電表從此量不到電流。這是三用電表最常見的死因。
- **量完電流，立刻把紅棒插回 V 孔、旋鈕轉回電壓檔。** 不然下一次你想量電壓時，紅棒還在 mA 孔，一跨接就短路了。
- 換檔位、插拔測棒時，先把電源拔掉。

## 動手做

### 實驗 1-1：量電池電壓

**材料**
- 數位三用電表 1 台
- 3 號電池 2 顆、3 號電池盒（2 顆裝）1 個
- 9V 電池 1 顆、9V 電池扣 1 個

**接線**

這個實驗不用麵包板，直接用測棒碰電池就好。

```
   3 號電池（單顆）           9V 電池（接上電池扣）

      ┌──────────┐             ┌──────┐
   ＋ │    AA    │ －          │  9V  │   電池扣：紅線＝＋，黑線＝－
      └──────────┘             └─┬──┬─┘
      ▲          ▲               紅  黑
     紅棒       黑棒             ▲    ▲
                                紅棒  黑棒
```

**步驟**
1. 黑棒插 COM，紅棒插 V 孔，旋鈕轉到 DCV 的 20V 檔（自動量程電表轉到 V⎓）。
2. 紅棒碰 3 號電池凸起來的那一端（正極），黑棒碰平的那一端（負極）。讀數字，記在表格裡。
3. 故意把紅黑棒對調再量一次，看看螢幕有什麼不同。
4. 把兩顆 3 號電池裝進電池盒，量電池盒伸出來的紅線（＋）和黑線（－）之間的電壓。
5. 把 9V 電池扣扣上 9V 電池，量紅線和黑線之間的電壓。
6. 試試看：旋鈕轉到 2V 檔再量 9V 電池。超過量程時電表會顯示「1」或「OL」，意思是量不到，不會壞，換回 20V 檔就好。

**你應該看到**
- 單顆 3 號電池：新的大約 1.55–1.65V，用過的可能只剩 1.2–1.4V。
- 兩顆串聯：大約是單顆的兩倍，例如 3.1V。
- 9V 電池：新的大約 9.3–9.6V，用過的可能 8V 多。
- 測棒反接：數字前面多一個負號。

**觀察與記錄**

| 量測對象 | 預期電壓 | 實際量到的電壓 | 紅黑棒反接時顯示 |
|----------|----------|----------------|------------------|
| 3 號電池 A | 1.5V | | |
| 3 號電池 B | 1.5V | | |
| A ＋ B 串聯（電池盒） | 3.0V | | |
| 9V 電池 | 9V | | |

想一想：A 加 B 量到的電壓，和 A、B 分別量到的電壓加起來，是不是幾乎一樣？

### 實驗 1-2：第一個電路——點亮一顆 LED

**材料**
- 麵包板 1 塊
- 9V 電池 1 顆、9V 電池扣 1 個
- 1kΩ 電阻（色碼：棕 黑 紅 金）1 顆
- 紅光 LED 1 顆
- 公公杜邦線 2 條
- 數位三用電表 1 台

**關於這兩個零件：**
- **LED**（Light Emitting Diode，發光二極體）是只准電流「單向通行」的燈。**長腳是正極（＋）**，接電壓高的那邊；**短腳是負極（－）**，接 GND。接反了不會亮，但也不會壞。
- **電阻**（Resistor）是用來「擋一下」電流的零件，沒有方向性。LED 很脆弱，直接接 9V 電池會一閃就燒掉。1kΩ 電阻會把電流限制在大約 7 mA，剛剛好。第 2 章會教你怎麼算，現在先記得：**LED 一定要配電阻**。

**接線**

```
   9V 電池扣紅線 ──[ 1kΩ ]──►|── 9V 電池扣黑線
                            LED
                        長腳  短腳

   麵包板上的位置（每一列的 a–e 五個孔互相連通）：
          a     b     c     d     e
    5    紅線   ○    電阻   ○     ○      ← 電池扣紅線插 a5，電阻一腳插 c5
    6     ○    ○     │     ○     ○         （電阻的本體橫跨第 6、7 列）
    7     ○    ○     │     ○     ○
    8     ○    ○    電阻  LED長   ○      ← 電阻另一腳插 c8，LED 長腳插 d8，同列所以相連
    9    黑線   ○     ○   LED短   ○      ← LED 短腳插 d9，電池扣黑線插 a9，同列所以相連
```

文字說明：
- 電池扣紅線 → 麵包板 a5
- 1kΩ 電阻：一腳 c5，另一腳 c8
- 紅光 LED：長腳 d8，短腳 d9
- 電池扣黑線 → 麵包板 a9

這樣電流的路線是：紅線（＋）→ 第 5 列 → 電阻 → 第 8 列 → LED 長腳 → LED → 短腳 → 第 9 列 → 黑線（－），剛好繞一圈。

**步驟**
1. 先不要扣上 9V 電池。把電阻、LED、兩條線照上面的位置插好。
2. 檢查三件事：LED 的長腳是不是在靠電阻那一側？電阻和 LED 是不是在同一列才相連？紅線和黑線有沒有不小心插在同一列？
3. 扣上 9V 電池。LED 應該立刻亮起來。
4. 把 LED 拔起來，左右腳對調再插回去。LED 應該不亮。這證明 LED 是有方向的。再把它換回正確方向。
5. 用電表量三個電壓（旋鈕轉 DCV 20V 檔，紅棒插 V 孔）：
   - 電池扣紅線與黑線之間（紅棒 a5、黑棒 a9）。
   - 電阻兩端（紅棒 c5、黑棒 c8）。
   - LED 兩端（紅棒 d8、黑棒 d9）。
6. 做完後拔掉電池，省電也安全。

**你應該看到**
- LED 亮起紅光，不會很刺眼，但在室內很清楚。
- 電池大約 9V；LED 兩端大約 1.8–2.0V；電阻兩端大約 7V。注意：LED 電壓加上電阻電壓，差不多就等於電池電壓。這不是巧合，第 3 章會解釋。

**觀察與記錄**

| 量測位置 | 紅棒插 | 黑棒插 | 量到的電壓 |
|----------|--------|--------|------------|
| 電池（紅線到黑線） | a5 | a9 | |
| 電阻兩端 | c5 | c8 | |
| LED 兩端 | d8 | d9 | |
| 電阻電壓 ＋ LED 電壓 | （用算的） | | |

### 實驗 1-3：把電表串進電路量電流

**材料**
- 實驗 1-2 接好的電路（不要拆）
- 數位三用電表 1 台

**接線**

我們要把電阻和 LED 之間切開，把電表補上去。做法是把電阻在 c8 的那隻腳拔起來，改插到另一列（例如 c12），然後用電表的兩支測棒把 c12 和 d8 連起來。

```
   電池扣紅線 ──[ 1kΩ ]── 紅棒〔 三用電表 A⎓ 20m 〕黑棒 ──►|── 電池扣黑線
                                                         LED

   麵包板上：
    5    紅線  ○   電阻  ○   ○
    ⋮
    8     ○   ○   ○   LED長 ○      ← 黑棒插這一列（例如 e8）
    9    黑線  ○   ○   LED短 ○
    ⋮
   12     ○   ○   電阻  ○   ○      ← 電阻另一腳改插 c12，紅棒插這一列（例如 e12）
```

文字說明：
- 電池扣紅線 → a5
- 1kΩ 電阻：一腳 c5，另一腳 **c12**（原本在 c8）
- 電表紅棒 → e12（和電阻同一列）
- 電表黑棒 → e8（和 LED 長腳同一列）
- LED 長腳 d8、短腳 d9，電池扣黑線 a9（不變）

**步驟**
1. **先拔掉 9V 電池。**
2. 把電阻在 c8 的腳拔起來，改插 c12。這時候電路被切開了，中間有個缺口（第 12 列和第 8 列之間）。
3. 電表：黑棒插 COM，**紅棒換插到 mA 孔**，旋鈕轉到 DCA 的 **20m** 檔（如果沒有 20m 就用 200m）。
4. 紅棒插進 e12（靠電源正極那一邊），黑棒插進 e8（靠 LED 那一邊）。杜邦線的公頭可以直接插麵包板，測棒如果插不進去，可以用一條杜邦線插在麵包板上，再用測棒碰杜邦線露出的金屬。
5. 扣上 9V 電池。LED 應該還是亮的（因為電表把缺口補起來了，迴路又閉合了），螢幕上會出現電流值。
6. 拔掉電池，把 1kΩ 電阻換成 330Ω（橙 橙 棕 金），**旋鈕改轉到 200m 檔**（因為預期電流會超過 20 mA，留在 20m 檔會顯示「1」），接回電池再量一次電流，LED 是不是更亮？（330Ω 時電流大約 21 mA，還在 LED 安全範圍內。）
7. **量完以後：拔掉電池，紅棒插回 V 孔，旋鈕轉回 DCV。** 養成這個習慣。

**你應該看到**
- 用 1kΩ 時，電流大約 7 mA（6–8 mA 都正常，看電池多新）。
- 用 330Ω 時，電流大約 21 mA，LED 明顯比較亮。
- 數字是負的：紅黑棒方向和電流方向相反，對調就好。
- 顯示 0 而且 LED 不亮：電表沒有真的補上缺口，檢查測棒有沒有插緊。

**觀察與記錄**

| 電阻 | 預期電流 | 量到的電流 | LED 亮度（暗／中／亮） |
|------|----------|------------|------------------------|
| 1kΩ | 約 7 mA | | |
| 330Ω | 約 21 mA | | |

## 用儀器看看

這一章還不用示波器，但三用電表有一個超好用的功能：**蜂鳴檔（Continuity，通路測試）**，它可以告訴你「這兩點有沒有連在一起」。

**怎麼用：**
1. 旋鈕轉到有喇叭圖案或二極體符號（►|）的那一檔。有些電表要再按一個按鈕切換到蜂鳴模式。
2. 黑棒插 COM，紅棒插 V 孔（和量電壓一樣）。
3. 先把兩支測棒互相碰一下，應該「嗶」一聲，表示功能正常。
4. 測棒碰在你想確認的兩點上。有嗶聲＝相連；沒聲音＝沒連。
5. **一定要在沒通電的情況下用**（拔掉電池）。

**用蜂鳴檔探索麵包板：** 拿一塊空的麵包板，把兩條杜邦線插在不同的孔，用測棒碰線的金屬端：

| 測試的兩個孔 | 預期結果 | 實際結果 |
|--------------|----------|----------|
| a1 和 e1 | 嗶（同一列 a–e 相連） | |
| a1 和 a2 | 無聲（不同列） | |
| e1 和 f1 | 無聲（被溝槽隔開） | |
| ＋軌最左邊和＋軌最右邊 | 嗶（整排相連）；若無聲，表示你的電源軌中間是斷開的 | |

**用蜂鳴檔找斷線：** 杜邦線用久了裡面的銅絲可能斷掉，外表看不出來。測棒碰線的兩端，沒嗶就是壞線，丟掉。

**預告：** 第 6 章會用示波器看電池。電池的電壓在示波器上是一條平平的水平線，因為直流電不隨時間變化，和之後的方波、正弦波很不一樣。

## 常見錯誤與除錯

- **LED 不亮** → LED 接反了 → 確認長腳在靠電阻（電壓高）那一側。
- **LED 不亮** → 零件沒有真的接在一起 → 檢查電阻和 LED 的腳是不是插在同一列，而不是隔壁列；用蜂鳴檔從電池紅線開始一段一段確認。
- **LED 不亮，電池摸起來變熱** → 短路了 → **立刻拔掉電池**。檢查紅線和黑線、或 LED 兩隻腳是不是插在同一列。
- **電表顯示 1 或 OL** → 量程太小 → 轉到更大的檔位。
- **電表顯示負號** → 紅黑棒接反 → 對調測棒，數值本身是對的。
- **數字一直跳動、不穩** → 測棒沒碰好，或電池快沒電 → 把測棒壓緊；換新電池。
- **電流檔量到 0，LED 也不亮** → 電表沒有真的串進缺口 → 檢查測棒插的列；確認紅棒插在 mA 孔。
- **電流檔量到 0，蜂鳴檔碰兩支測棒也不響** → 保險絲燒了 → 請老師協助更換。以後絕對不要在電流檔跨接電池。
- **連電池都量不到** → 電表自己的電池沒電，或旋鈕轉到 ACV、Ω 區 → 換電表電池；確認旋鈕位置。

## 想一想

1. 把三顆 1.5V 的 3 號電池頭尾相接串起來，總電壓是多少？
<details><summary>參考答案</summary>

1.5 ＋ 1.5 ＋ 1.5 ＝ 4.5V。就像把三座一樣高的水塔疊起來。

</details>

2. 你量 9V 電池時，螢幕顯示 −8.72。這代表什麼？電池壞了嗎？
<details><summary>參考答案</summary>

負號代表紅棒碰到負極、黑棒碰到正極，接反了。電池電壓是 8.72V，比 9V 低一些，用過一陣子但還能用。電池和電表都沒壞，測棒對調就會顯示 8.72。

</details>

3. 為什麼量電流的時候，絕對不能像量電壓那樣，把兩支測棒直接碰在電池的正負極上？
<details><summary>參考答案</summary>

電流檔時電表內部幾乎是一條沒有阻礙的導線。直接碰電池兩極，等於把電池短路，會產生非常大的電流，保險絲會燒斷，電池也會發燙。量電流一定要把電表串進電路的缺口，讓電路裡的電阻限制電流。

</details>

4. 小美把 LED 的長腳插在麵包板的 c7，短腳插在 d7，然後電阻的一腳也插在 e7。LED 會亮嗎？為什麼？
<details><summary>參考答案</summary>

不會亮。c7、d7、e7 都在第 7 列的 a–e 組，被同一條金屬片連在一起。LED 的兩隻腳被直接接通，電流從金屬片走捷徑，不經過 LED（LED 被短路）。兩隻腳必須插在不同列。

</details>

5. 實驗 1-3 用 1kΩ 時，電流大約是 0.007 A。如果 LED 亮了 1 分鐘，總共有多少庫侖的電荷流過 LED？
<details><summary>參考答案</summary>

電荷量 Q ＝ 電流 I × 時間 t ＝ 0.007 A × 60 秒 ＝ 0.42 C。看起來很小，但其實是幾十億億顆電子流過去了。

</details>

6. （開放挑戰）請在實驗 1-2 的電路裡加一個按鈕開關，讓 LED 只有在按住按鈕時才亮。用 ASCII 畫出電路圖，並說明開關要放在迴路的哪裡。提示：按鈕平常是「斷開」的，按下去才「接通」。
<details><summary>參考答案</summary>

開關可以放在迴路的任何位置，因為只要迴路有一處斷開，整個迴路就沒電流：

```
   9V 紅線 ──／ ──[ 1kΩ ]──►|── 9V 黑線
           按鈕              LED
```

沒按時迴路不閉合，LED 不亮；按住時迴路閉合，LED 亮。放在電阻前面、中間或 LED 後面效果都一樣。注意按鈕開關有四隻腳，兩兩成對，要接「按下才會相通」的那一對，可以先用蜂鳴檔確認。

</details>

## 本章小結

- 電流是「每秒流過多少電荷」，單位是安培（A）；本書常用毫安培（mA），1 A ＝ 1000 mA。
- 電壓是推動電荷的力道，單位是伏特（V），而且永遠是「兩點之間」的差距。
- GND 是大家約定的 0V 參考點，電路中每個點的電壓都是「比 GND 高多少」。
- 電流只能在閉合迴路裡流動：從電源正極出發，經過零件，一定要回到負極。斷一處就全停。
- 短路（正負極直接相連）會產生大電流，讓電池發燙，絕對要避免。
- 麵包板中間區域同一列的 a–e 相連、f–j 相連，兩側電源軌整排相連；不確定就用蜂鳴檔測。
- 量電壓：紅棒插 V 孔，轉 DCV，把電表「跨」在兩點之間，不用拆電路。
- 量電流：紅棒插 mA 孔，轉 DCA，把電路切開，把電表「串」進缺口；量完立刻插回 V 孔。
- LED 長腳接正極、短腳接負極，而且一定要串一顆電阻限制電流。
