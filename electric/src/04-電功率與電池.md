# 第 4 章　電功率與電池

## 本章目標

- 學完你會用 P = V × I 算出任何元件「吃」掉多少功率，知道瓦特是什麼。
- 學完你會判斷一顆 1/4W 電阻會不會過熱，並親手摸到超載電阻的溫度。
- 學完你會看懂電池上的 mAh，估算一顆電池可以讓 LED 亮多久。
- 學完你會量出電池的內阻，解釋為什麼舊電池「量起來有電壓，卻推不動馬達」。
- 學完你會知道 USB、Arduino 的 5V 與 3.3V 腳位能給多少電流，以及電池串聯和並聯的差別。

## 開場：為什麼充電器會熱、電池會「虛弱」？

小宇把手機接上充電器，一個小時後摸到充電器溫溫的，心裡想：「它又沒有在動，為什麼會熱？」晚上他拿出遙控車，放進去年的舊電池，用三用電表一量：8.5V，看起來還有電啊！可是一按前進，馬達只「嗯」了一聲就不動了。換上新電池，一樣是 9V 電池，車子卻衝了出去。

這兩件事其實是同一個主題：**電在流動的時候，每一秒鐘都在把能量交出去**。交出去的能量有的變成光（LED）、有的變成轉動（馬達）、有的變成熱（充電器、電阻）。而電池交出能量的「速度」是有上限的，舊電池的上限變得很低，所以電壓量起來還在，卻給不出大電流。這一章我們就來弄清楚「功率」與「電池」這兩件事。

## 核心概念

### 功率：電每秒做了多少事

想像一座水車。水從高處落下（電壓）、水量很大（電流），水車就轉得很有力。水車每一秒拿到的能量，就是「功率」。

**功率（Power）** 的符號是 P，單位是 **瓦特（Watt，W）**。它告訴你一個元件每秒消耗（或產生）多少能量。公式很簡單：

```
P = V × I
功率（W）= 電壓（V）× 電流（A）
```

算一個例子：一顆紅色 LED 兩端電壓 2V，流過 20mA（= 0.02A）。

```
P = 2V × 0.02A = 0.04W = 40mW
```

40 毫瓦（mW）非常小，所以 LED 摸起來不會熱。

因為歐姆定律 V = I × R（第 2 章），把 V 或 I 代進去，可以得到另外兩個常用的寫法：

```
P = V × I
P = V² ÷ R      （只知道電壓和電阻時用這個）
P = I² × R      （只知道電流和電阻時用這個）
```

例子：一顆 220Ω 電阻直接接在 9V 電池上。

```
P = V² ÷ R = (9 × 9) ÷ 220 = 81 ÷ 220 ≈ 0.37W
```

0.37W 看起來很小，但下一節你會發現：對一顆小電阻來說，這已經太多了。

順帶一提，家裡電費單上的「1 度電」就是 1000W 的東西用 1 小時所消耗的能量。能量 = 功率 × 時間，功率越大、用越久，吃掉的能量越多。

### 電阻會發熱：1/4W 是什麼意思

電阻吃進去的功率沒有變成光或轉動，**全部變成熱**。買電阻的時候你會看到「1/4W」這種字，這是**額定功率（Power Rating）**，意思是「這顆電阻最多能安全地把 0.25W 的熱散掉」。超過了，它會越來越燙、變色、發臭，嚴重會燒斷。

我們算算 9V 電池接不同電阻時的功率：

| 電阻 | P = 81 ÷ R | 和 0.25W 比 | 預測 |
|---|---|---|---|
| 10kΩ | 81 ÷ 10000 = 0.0081W | 很小 | 完全不會熱 |
| 1kΩ | 81 ÷ 1000 = 0.081W | 約 1/3 | 微溫 |
| 330Ω | 81 ÷ 330 ≈ 0.245W | 剛好接近 | 明顯溫熱 |
| 220Ω | 81 ÷ 220 ≈ 0.37W | 超過 1.5 倍 | 燙！ |

這張表在「動手做」會讓你親手驗證。

### 電池的容量：mAh 是什麼

電池像一座水塔，水塔的大小就是**容量（Capacity）**，單位是 **毫安培小時（mAh）**。「2000mAh」的意思是：可以用 2000mA 的電流放 1 小時，或是 20mA 放 100 小時。

```
使用時間（小時）= 容量（mAh）÷ 電流（mA）
```

例子：一顆 3 號（AA）鹼性電池大約 2000mAh。點亮一顆 20mA 的 LED：

```
2000 ÷ 20 = 100 小時
```

9V 鹼性電池比較小，大約只有 500mAh：

```
500 ÷ 20 = 25 小時
```

真實情況會打折，因為電池用到後面電壓會慢慢降低，LED 會越來越暗，而不是突然熄滅。大概抓計算值的 7 成比較實際：25 × 0.7 ≈ 17 小時。

### 電池的內阻：為什麼舊電池推不動馬達

回到開場的問題。你可以把一顆真實電池想成「一個完美的電池」再串聯「一個很小的電阻」，這個電阻叫做**內阻（Internal Resistance）**，符號 r。

```
 ┌─────── 真實電池 ───────┐
 │                        │
 │  ┌──┤├── [ r ]──┐      │
 │  │  完美        內阻   │
 │  │  9V                 │
 └──┼────────────────┼────┘
    −                +
```

沒有接負載（空載）時，電流是 0，內阻上沒有壓降，你量到的是完美電池的電壓。一旦接上負載有電流流過，內阻就會「吃掉」一部分電壓：

```
V負載 = V空載 − I × r
```

所以反過來，只要量兩個電壓和電流，就能算出內阻：

```
r = (V空載 − V負載) ÷ I
```

例子：一顆新的 9V 電池，空載量到 9.40V。接上 200Ω 負載後量到 9.15V。

```
I = 9.15 ÷ 200 ≈ 0.0458A（45.8mA）
r = (9.40 − 9.15) ÷ 0.0458 = 0.25 ÷ 0.0458 ≈ 5.5Ω
```

新電池內阻只有幾歐姆。用久的電池內阻可能變成 30Ω、50Ω 甚至更高。馬達啟動要吃好幾百 mA，假設 300mA、內阻 30Ω：壓降 = 0.3 × 30 = 9V，整顆電池的電壓都被內阻吃光了，馬達當然轉不動。這就是「量起來有電壓，用起來沒電」的原因。

### USB 與 Arduino 能給多少電

本書所有實驗都用 12V 以下的直流電，常見的電源有三種：

| 電源 | 電壓 | 大約能給的電流 |
|---|---|---|
| 電腦的 USB 孔 | 5V | 500mA（USB 2.0 規格） |
| 手機充電器 | 5V | 1A～2A 以上（看充電器標示） |
| 9V 電池 | 9V | 短時間幾百 mA，但內阻大、容量小 |
| 3 號電池盒（4 顆） | 6V | 1A 以上，容量大 |

Arduino UNO 本身也可以當電源，但要注意上限：

- **5V 腳**：由 USB 供電時，整塊板加上你接的東西總共不能超過約 500mA（板上有保險絲）。
- **3.3V 腳**：最多 **50mA**，只能接小東西（例如一些感測器）。
- **每一支 I/O 腳（D0～D13、A0～A5）**：建議 20mA，絕對不能超過 40mA。所有 I/O 腳加起來不能超過 200mA。
- ESP32 的 I/O 腳更弱，每腳建議 12mA，而且只能 3.3V。

所以小直流馬達（啟動時幾百 mA）**絕對不能直接接在 I/O 腳上**。第 9 章我們會用電晶體來解決這個問題。

### 電池串聯與並聯

**串聯（Series）**：正極接下一顆的負極，電壓相加，容量不變。

```
 ┤├──┤├──┤├──┤├      4 顆 1.5V 串聯 = 6V，容量仍是 2000mAh
 1.5V 1.5V 1.5V 1.5V
```

你手上的 3 號電池盒就是這樣：4 顆 AA 串起來得到 6V。9V 電池拆開來看，裡面其實是 6 顆 1.5V 的小電池串聯（6 × 1.5 = 9V）。

**並聯（Parallel）**：正極接正極、負極接負極，電壓不變，容量相加。

```
 ┌──┤├──┐
 │ 1.5V  │     2 顆 1.5V 並聯 = 1.5V，容量 2000 + 2000 = 4000mAh
 ├──┤├──┤
 │ 1.5V  │
```

並聯有一個重要規則：**只能並聯同型號、同樣新舊的電池**。如果一顆滿電、一顆快沒電，滿的那顆會拚命往沒電的那顆灌電流，兩顆都會發熱。絕對不可以把 9V 電池和 AA 電池並聯，那是短路。

## 動手做

> 安全提醒：本章會讓電阻發熱，請按照步驟的時間限制操作，用指背輕碰，不要握住。只要看到電阻變色或聞到焦味，立刻拔掉電池。

### 實驗 4-1：量 LED 與電阻各吃了多少功率

**材料**

- 3 號電池盒（4 顆 AA，約 6V）
- 220Ω 電阻 1 顆
- 紅色 LED 1 顆
- 麵包板、杜邦線
- 數位三用電表

**接線**

```
 電池盒 +（6V）──[ 220Ω ]──►|── 電池盒 −（GND）
                          LED
```

- 電池盒紅線 → 220Ω 一端
- 220Ω 另一端 → LED 長腳（+）
- LED 短腳（−）→ 電池盒黑線（GND）

**步驟**

1. 先不要接電路，三用電表轉到直流電壓（DCV，20V 檔），量電池盒的電壓，記下 V電池。
2. 接好電路，LED 應該亮起來。
3. 電表紅棒放在 LED 長腳、黑棒放在 LED 短腳，量 LED 兩端電壓 V_LED。
4. 電表改量 220Ω 兩端電壓 V_R。檢查：V_LED + V_R 應該幾乎等於 V電池。
5. 量電流：把電表轉到直流電流（mA 檔，紅棒插到 mA 孔），拔掉 LED 短腳到 GND 的那條線，改成「LED 短腳 → 電表紅棒，電表黑棒 → GND」，讓電流流過電表。記下 I。
6. 用 P = V × I 算出三個功率：P_LED、P_R、P總（= V電池 × I）。

**你應該看到**

V電池 約 6.0V、V_LED 約 1.9V、V_R 約 4.1V、I 約 18～19mA。以 18.6mA 計算：

```
P_LED = 1.9V × 0.0186A ≈ 0.035W = 35mW
P_R   = 4.1V × 0.0186A ≈ 0.076W = 76mW
P總   = 6.0V × 0.0186A ≈ 0.112W = 112mW
```

注意 35 + 76 = 111mW，和 P總 幾乎一樣。電池交出來的功率，全部被 LED 和電阻分掉了，一點都沒有消失。另外，這個電路裡有 2/3 的功率浪費在電阻上變成熱，這就是為什麼限流電阻「不划算但必要」。

**觀察與記錄**

| 項目 | 量測電壓（V） | 電流（A） | 功率 P = V × I（W） |
|---|---|---|---|
| 電池 | | | |
| LED | | （同上） | |
| 220Ω 電阻 | | （同上） | |
| LED + 電阻的功率加總 | | | |

### 實驗 4-2：摸摸看，電阻超載有多燙

**材料**

- 9V 電池與電池扣
- 10kΩ、1kΩ、330Ω、220Ω 電阻各 1 顆（都是 1/4W）
- 麵包板

**接線**

```
 9V 電池 + ──[ R ]── 9V 電池 −
```

- 電池扣紅線 → 電阻一端
- 電阻另一端 → 電池扣黑線
- 一次只接一顆電阻。

**步驟**

1. 動手前先算：用 P = V² ÷ R 算出四顆電阻各會吃多少功率，填進表格的「計算功率」欄。
2. 插上 10kΩ，等 20 秒，用指背輕碰電阻本體，記下感覺。拔掉。
3. 換 1kΩ，一樣等 20 秒再碰。拔掉。
4. 換 330Ω，等 20 秒再碰。拔掉。
5. 換 220Ω，**只等 15 秒**，用指背很快碰一下就離開。立刻拔掉電池。這顆電阻超過額定功率 1.5 倍，會很燙。
6. 等 220Ω 冷卻後看看它的顏色有沒有變深。

**你應該看到**

10kΩ 完全沒感覺；1kΩ 微溫；330Ω 明顯溫熱（它剛好吃 0.245W，貼近 0.25W 的上限）；220Ω 燙到不能久碰。超載時間久了，電阻表面會變成深褐色，電阻值也可能永久改變。

**觀察與記錄**

| 電阻 | 計算功率 P = 81 ÷ R（W） | 超過 0.25W？ | 摸起來（無感／微溫／溫熱／燙） |
|---|---|---|---|
| 10kΩ | | | |
| 1kΩ | | | |
| 330Ω | | | |
| 220Ω | | | |

### 實驗 4-3：量電池的內阻

**材料**

- 9V 電池（最好準備一顆新的、一顆用過很久的）
- 100Ω 電阻 2 顆（串聯成 200Ω）
- 麵包板、杜邦線
- 數位三用電表

為什麼用兩顆 100Ω 串聯而不是一顆 200Ω？因為 9V 接 200Ω 總共會吃 81 ÷ 200 ≈ 0.4W，一顆 1/4W 電阻撐不住。串聯後每顆分到 4.5V，各自只吃 4.5² ÷ 100 ≈ 0.2W，剛好安全。這就是上一節學到的東西派上用場。

**接線**

```
 9V 電池 + ──[ 100Ω ]──[ 100Ω ]── 9V 電池 −
            ▲                     ▲
            └─── 三用電表（DCV）───┘
```

- 電池扣紅線 → 第一顆 100Ω
- 第一顆 100Ω → 第二顆 100Ω
- 第二顆 100Ω → 電池扣黑線
- 電表紅棒夾在電池扣紅線，黑棒夾在電池扣黑線（量的是電池端電壓）。

**步驟**

1. 先把電阻拔掉，只接電表，量空載電壓 V空載。
2. 插上兩顆電阻，**5 秒內**讀電表，記下 V負載。
3. 拔掉電阻（不要讓電池一直放電）。
4. 算電流 I = V負載 ÷ 200。
5. 算內阻 r = (V空載 − V負載) ÷ I。
6. 換舊電池再做一次。

**你應該看到**

新電池：空載約 9.4V，負載約 9.15V，掉 0.25V 左右。

```
I = 9.15 ÷ 200 ≈ 0.0458A
r = 0.25 ÷ 0.0458 ≈ 5.5Ω
```

舊電池：空載可能還有 8.6V，但接上負載後掉到 7.4V 甚至更低。

```
I = 7.4 ÷ 200 = 0.037A
r = (8.6 − 7.4) ÷ 0.037 = 1.2 ÷ 0.037 ≈ 32Ω
```

內阻差了好幾倍。如果你有小直流馬達，可以再試試看：把馬達直接接在舊電池上、同時量電壓，你會看到電壓一瞬間掉到剩 3、4V，馬達可能動不了；新電池掉得少很多。

**觀察與記錄**

| 電池 | V空載（V） | V負載（V） | I = V負載 ÷ 200（A） | r = (V空載 − V負載) ÷ I（Ω） |
|---|---|---|---|---|
| 新 9V | | | | |
| 舊 9V | | | | |
| 其他（例如電池盒 6V） | | | | |

### 實驗 4-4：電池串起來，電壓加起來

**材料**

- 3 號電池盒（4 顆 AA）
- 單顆 AA 電池 1 顆（從電池盒拿一顆出來也可以）
- 9V 電池
- 數位三用電表

**接線**

這個實驗不用麵包板，直接用電表的兩支探棒碰電池兩端。

```
 單顆 AA：  紅棒 → 凸起那端（+）   黑棒 → 平的那端（−）
 電池盒：   紅棒 → 紅線           黑棒 → 黑線
```

**步驟**

1. 電表轉 DCV 20V 檔，量單顆 AA 電池，記下來。
2. 量 4 顆裝好的電池盒，記下來。算算看是不是「單顆 × 4」。
3. 量 9V 電池。想一想：它裡面要幾顆 1.5V 的小電池串聯才會得到這個數字？
4. 把電池盒其中一顆電池反過來裝（正負顛倒），再量一次。

**你應該看到**

單顆約 1.5～1.6V，電池盒約 6.0～6.4V，剛好 4 倍。9V 電池約 9.0～9.5V，是 6 顆串聯。反裝一顆之後，那顆電池的電壓變成「減」的：1.5 × 3 − 1.5 = 3V。這就是為什麼遙控器電池裝反會不能用。

**觀察與記錄**

| 量什麼 | 量到電壓（V） | 預測（V） |
|---|---|---|
| 單顆 AA | | 1.5 |
| 4 顆串聯 | | |
| 9V 電池 | | |
| 反裝一顆後 | | |

## 用儀器看看

本章最重要的儀器是三用電表，重點是**量電流的正確方法**：

1. 紅棒要插在 **mA 孔**（不是 V/Ω 孔），轉到直流電流檔（DCA，200mA 檔）。
2. 電表要**串聯**在電路裡：把原本的導線斷開，電流從電表的紅棒進去、黑棒出來。
3. **絕對不可以**用電流檔去「並聯」量電池兩端，那等於把電池短路，電表裡的保險絲會燒掉。
4. 量完電流，記得把紅棒插回 V/Ω 孔，不然下次量電壓時又會短路。

示波器也能看電池，而且能看到三用電表看不到的「瞬間變化」。如果你已經讀過第 6 章，可以試試看：

- 探棒夾在 9V 電池兩端（接地夾夾負極）。
- 設定：CH1 直流耦合（DC）、2V/div、水平 200ms/div，觸發模式 Auto。
- 畫面上會是一條平平的線，在 0V 上方約 4.5 格的位置（9V）。
- 這時把小直流馬達接到電池上，你會看到線**瞬間往下掉**，然後慢慢回升一點：

```
電壓
 9V ┤──────────┐
    │          └──┐  ← 馬達接上去，內阻吃掉電壓
 6V ┤             └──────────
    │
 0V ┼─────────────────────────── 時間
              ▲
           接上馬達
```

舊電池的掉落會深得多。

## 常見錯誤與除錯

- **量電流時電表顯示 0，電路也不動** → 電表轉到電流檔但紅棒還插在 V/Ω 孔，或保險絲已經燒斷 → 檢查紅棒位置；轉到電阻檔量電表自己的兩根棒子，如果是無限大，保險絲壞了，請老師更換。
- **實驗 4-1 的 V_LED + V_R 和 V電池 差很多** → 杜邦線或麵包板接觸不良 → 把線重新插緊，用電表量每一段導線兩端是否為 0V。
- **220Ω 電阻一插上就冒煙** → 可能拿到的是更小功率（1/8W）的電阻，或電池是 2 顆 9V 串聯 → 立刻拔掉，確認電壓與電阻額定功率。
- **內阻算出來是負的** → 空載與負載電壓記反了，或負載電壓在接上很久之後才量（電池回升） → 重做一次，接上負載 5 秒內讀值。
- **內阻算出來超大（幾百 Ω）** → 可能用了快沒電的電池，或用了舊的碳鋅電池；也可能電池扣接觸不良 → 換電池、重新壓緊電池扣。
- **電池盒量到的電壓只有 3V 或 4.5V** → 有一顆裝反了或接觸點生鏽 → 檢查每顆方向，用橡皮擦擦彈簧。

## 想一想

1. 一台 5V、100mA 的小風扇，功率多少？

<details><summary>參考答案</summary>

P = V × I = 5V × 0.1A = 0.5W。

</details>

2. 你想把一顆 1/4W 電阻直接接在 5V 上，最小可以用幾 Ω 的電阻而不超載？

<details><summary>參考答案</summary>

P = V² ÷ R 移項得 R = V² ÷ P = 25 ÷ 0.25 = 100Ω。所以至少要 100Ω；實際上留一點餘裕，用 220Ω 以上更安全。

</details>

3. 一顆 2000mAh 的電池接一個吃 50mA 的電路，理論上可以用多久？考慮實際打 7 折呢？

<details><summary>參考答案</summary>

2000 ÷ 50 = 40 小時；打 7 折約 28 小時。

</details>

4. 一個電池盒空載量到 6.2V，接上 100Ω 電阻後量到 5.8V。算出電流與內阻。

<details><summary>參考答案</summary>

I = 5.8 ÷ 100 = 0.058A。r = (6.2 − 5.8) ÷ 0.058 = 0.4 ÷ 0.058 ≈ 6.9Ω。

</details>

5. （開放挑戰）電動車的電池包通常是幾百顆小電池串聯再並聯。想想看：為什麼要串聯這麼多顆？為什麼又要並聯？如果只串聯不並聯，會有什麼問題？

<details><summary>參考答案</summary>

串聯是為了得到高電壓（幾百伏特），同樣功率下電壓高、電流就小，電線可以比較細、發熱比較少。並聯是為了增加容量（mAh）和能給出的最大電流。只串聯不並聯，容量會跟單顆一樣小，跑不遠，而且大電流會讓每顆電池的內阻壓降很大、發熱嚴重。

</details>

6. （開放挑戰）設計一支手電筒：用 3 顆 AA 電池（4.5V）點亮一顆白光 LED（順向電壓 3.2V，電流 20mA）。需要多少 Ω 的限流電阻？電阻吃多少功率？電池大約能用多久？

<details><summary>參考答案</summary>

電阻上的電壓 = 4.5 − 3.2 = 1.3V，R = 1.3 ÷ 0.02 = 65Ω，用 68Ω（或手邊有的 100Ω，會稍暗一點）。電阻功率 = 1.3 × 0.02 = 0.026W，1/4W 綽綽有餘。使用時間 = 2000 ÷ 20 = 100 小時，實際約 70 小時。

</details>

## 本章小結

- 功率 P = V × I，單位瓦特（W），代表每秒消耗的能量；也可以寫成 P = V² ÷ R 或 P = I² × R。
- 電阻吃進去的功率全部變成熱。1/4W 電阻最多只能承受 0.25W，超過會燙、變色、燒壞。
- 電池容量用 mAh 表示，使用時間 = 容量 ÷ 電流，實際大約打 7 折。
- 電池有內阻 r，接負載時電壓會掉：V負載 = V空載 − I × r。舊電池內阻大，所以「有電壓卻沒力」。
- 量內阻：r = (V空載 − V負載) ÷ I。
- USB 孔約給 500mA；Arduino 5V 腳總共約 500mA、3.3V 腳只有 50mA、每支 I/O 腳建議 20mA。馬達不能直接接 I/O 腳。
- 電池串聯電壓相加、容量不變；並聯電壓不變、容量相加，而且只能並聯相同狀態的電池。
- 量電流要串聯、紅棒插 mA 孔；量完記得插回去。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 功率 | Power | 每秒消耗或產生的能量，P = V × I |
| 瓦特 | Watt（W） | 功率的單位，1W = 1V × 1A |
| 毫瓦 | Milliwatt（mW） | 千分之一瓦特 |
| 額定功率 | Power Rating | 元件能安全承受的最大功率，例如 1/4W |
| 容量 | Capacity | 電池能放出的總電量，單位 mAh |
| 毫安培小時 | mAh | 1mA 的電流放 1 小時的電量 |
| 內阻 | Internal Resistance | 電池內部像串聯著的小電阻，接負載時會吃掉電壓 |
| 空載 | No Load | 沒有接任何負載，電流為 0 的狀態 |
| 負載 | Load | 接在電源上、會消耗電流的東西 |
| 串聯 | Series | 頭尾相接，電壓相加 |
| 並聯 | Parallel | 正接正、負接負，容量相加 |
| 保險絲 | Fuse | 電流太大時會燒斷來保護電路的元件 |
