# 第 5 章　電容

## 本章目標

- 學完你會用「水桶」的比喻說明電容在做什麼，看懂 µF、nF、pF 的換算。
- 學完你會分辨電解電容的正負極，知道為什麼接反很危險。
- 學完你會算 RC 時間常數 τ = R × C，並且知道「5 個 τ 就充飽（或放光）」。
- 學完你會做出一個放開按鈕後 LED 慢慢變暗的「延遲關燈」電路。
- 學完你會用三用電表看電容電壓慢慢下降，並用示波器第一次看到充電與放電的曲線。

## 開場：關掉電源，燈怎麼還亮著？

小宇組了一塊 Arduino 的電路，拔掉 USB 線的瞬間，他注意到板子上的電源指示燈不是「啪」一聲熄滅，而是像螢火蟲一樣慢慢暗下去，大概半秒鐘才完全黑掉。他把 USB 插回去再拔一次，又看到一樣的事。

「電都拔掉了，燈還有電可以用？」他拿放大鏡看板子，發現 USB 孔旁邊有幾顆圓柱形的小元件，上面印著「100µF」。那就是電容。電容像一個小水桶，電源接著的時候它悄悄把水裝滿；電源一拔掉，它就把存的水倒出來，所以燈還能多亮一下下。

這一章我們就來玩這個小水桶：它能裝多少、裝滿要多久、倒光要多久，以及怎麼用三用電表和示波器「看」到它在倒水。

## 核心概念

### 電容像水桶

電阻是「讓電流不好走的窄水管」，而**電容（Capacitor）**是「接在水管旁邊的水桶」。它的構造很簡單：兩片金屬板，中間夾一層不導電的東西。電壓加上去，電荷就往兩片金屬板上堆，一片堆正電、一片堆負電。電壓拿掉，電荷還留在上面，這就是「存電」。

```
 電路符號：

   ──┤├──    一般電容（陶瓷電容，沒有正負）

   ──┤|──    電解電容（有正負，彎的那邊是 +，直的那邊是 −）
      +
```

水桶越大，同樣的水位能裝越多水。電容也一樣：**電容值（Capacitance）**越大，同樣的電壓能存越多電荷。電容值的符號是 C，單位是**法拉（Farad，F）**。

1 法拉非常非常大（1V 就能存 1 庫侖的電荷），所以日常用的電容都是「百萬分之一法拉」等級。換算要記熟：

```
1 F  = 1,000,000 µF（微法拉）
1 µF = 1,000 nF（奈法拉）
1 nF = 1,000 pF（皮法拉）
```

例子：100µF = 0.0001F；100nF = 0.1µF；1000µF = 0.001F。

怎麼看電容上的數字？

- **電解電容**（圓柱形、藍色或黑色外殼）會直接印「100µF 25V」。25V 是**耐壓（Rated Voltage）**，代表最多只能加 25V，超過會壞。本書最高只用 12V，所以 16V 或 25V 的電容都安全。
- **陶瓷電容**（小小的扁圓片，淡黃或藍色）印三個數字，例如「104」。讀法是：前兩個數字「10」後面加上第三個數字那麼多個 0，單位是 pF。「104」= 10 後面加 4 個 0 = 100000pF = 100nF。

### 極性：電解電容接反會爆

陶瓷電容沒有方向，怎麼接都可以。**電解電容有正負極**：長腳是正（+），短腳是負（−），而且外殼上有一條白色或灰色的帶子，帶子那邊是負極。

接反會發生什麼事？電解電容裡面是一層非常薄的化學膜，接反的時候這層膜會被破壞，電容變成短路，裡面的液體快速發熱、變成氣體，外殼撐不住就會「啪」一聲噴開。所以本書的安全紅線之一就是：**電解電容的正極一定接比較高電壓的那邊**。不確定時先用三用電表量一下哪邊電壓高。

### 充電與放電

把電容接上電池，電荷會流進去，電容兩端的電壓從 0 慢慢升到電池電壓，這叫**充電（Charging）**。充電不是瞬間完成的，因為電路裡一定有電阻（就算沒有刻意放，電線和電池內阻也算），電阻限制了電流，水桶只能慢慢裝。

把充滿的電容從電池拔下來，接到一個電阻上，電荷會從電阻流掉，電壓從滿慢慢降到 0，這叫**放電（Discharging）**。

重點是「慢慢」的樣子：**一開始快，越來越慢**。放電時，剛開始電壓高、電流大，水嘩啦嘩啦流；電壓越低、電流越小，最後只剩涓涓細流，所以曲線是圓弧形的，不是直線。

```
電壓                                 電壓
 9V ┤        ╭───────────            9V ┤╮
    │      ╱                            │ ╲
    │    ╱                              │  ╲
    │   ╱                               │   ╲
    │  ╱                                │    ╲
    │ ╱                                 │     ╰╮
 0V ┼╯─────────────────── 時間        0V ┼──────╰──────────── 時間
         充電                                  放電
```

### RC 時間常數：τ = R × C

充電要多久？放電要多久？這取決於電阻 R 和電容 C 的乘積，叫做**時間常數（Time Constant）**，符號是希臘字母 τ（唸作「tau」）。

```
τ = R × C
時間常數（秒）= 電阻（Ω）× 電容（F）
```

例子一：10kΩ 和 100µF。

```
τ = 10000Ω × 0.0001F = 1 秒
```

例子二：10kΩ 和 100nF。

```
τ = 10000Ω × 0.0000001F = 0.001 秒 = 1 毫秒（ms）
```

例子三：1kΩ 和 1000µF。

```
τ = 1000Ω × 0.001F = 1 秒
```

小技巧：kΩ 乘上 µF，答案直接就是 ms。10kΩ × 100µF = 1000ms = 1 秒；10kΩ × 0.1µF = 1ms。

τ 是什麼意思？**每過一個 τ，放電時的電壓會變成原來的 37%；充電時則是「剩下的差距」縮小到 37%**。用表格看最清楚（以 9V 為例）：

| 經過時間 | 放電：剩下多少 | 放電電壓（從 9V 開始） | 充電：充到多少 | 充電電壓（充向 9V） |
|---|---|---|---|---|
| 0 | 100% | 9.0V | 0% | 0V |
| 1τ | 37% | 3.3V | 63% | 5.7V |
| 2τ | 14% | 1.2V | 86% | 7.8V |
| 3τ | 5% | 0.45V | 95% | 8.6V |
| 4τ | 2% | 0.17V | 98% | 8.8V |
| 5τ | 0.7% | 0.06V | 99.3% | 8.9V |

所以我們只要記一句話：**5 個 τ 就算充飽（或放光）了**。10kΩ 配 100µF，τ = 1 秒，5 秒就充飽。想讓它慢 10 倍？把電阻換成 100kΩ，或把電容換成 1000µF。

### 電容在電路裡做什麼

1. **暫時供電**：開場故事裡的 Arduino 電源燈，就是電容在電源拔掉後撐了一下。
2. **延遲**：放開按鈕後 LED 慢慢熄滅，或者讓某件事「等一下」再發生。這章的實驗 5-1 就是。
3. **濾波／穩壓**：把忽大忽小的電壓弄平順（第 10 章會用示波器看）。
4. **擋直流、讓變化通過**：電容充飽後直流電就流不過去了，但變化中的訊號可以「透過」它（第 6 章 AC 耦合會用到這個觀念）。

## 動手做

> 安全提醒：電解電容的長腳（+）一定要接電路裡電壓高的那邊，白色帶子那邊接 GND。本章最高只用 9V，電容耐壓 16V 以上都安全。接線前先把電池拔掉。

### 實驗 5-1：延遲關燈電路——用 LED 看電容放電

**材料**

- 9V 電池與電池扣
- 按鈕開關 1 個
- 220Ω 電阻 1 顆（充電用）
- 1kΩ、4.7kΩ、10kΩ 電阻各 1 顆（放電用，輪流換）
- 1000µF 電解電容 1 顆（耐壓 16V 以上）
- 紅色 LED 1 顆
- 麵包板、杜邦線

**接線**

```
 9V + ──[ 按鈕 ]──[ 220Ω ]──┬──────────┐
                            │+         │
                          ══╧══     [ 1kΩ ]
                          1000µF       │
                            │−        ►|  LED（長腳在上）
                            │          │
 9V − ──────────────────────┴──────────┴── GND
```

- 電池扣紅線 → 按鈕一腳
- 按鈕另一腳 → 220Ω → 麵包板上的「節點 A」
- 1000µF 長腳（+）→ 節點 A；1000µF 短腳（−，白帶那邊）→ GND
- 1kΩ 一端 → 節點 A；1kΩ 另一端 → LED 長腳
- LED 短腳 → GND
- 電池扣黑線 → GND

**步驟**

1. 檢查 1000µF 的方向：長腳在節點 A（高電壓），白帶在 GND。
2. 按住按鈕約 2 秒，LED 亮起。
3. 放開按鈕，盯著 LED，用手機碼表量「從放開到完全看不見」花了幾秒。
4. 把 1kΩ 換成 4.7kΩ，重複步驟 2～3。
5. 再換成 10kΩ，重複一次（房間最好暗一點，因為電流很小，LED 比較暗）。
6. 算一算每種電阻的 τ = R × C，填進表格。

**你應該看到**

按住時 LED 亮，放開後 LED 不是立刻熄滅，而是慢慢變暗。用 1kΩ 時 τ = 1kΩ × 1000µF = 1 秒，大約 1.5～2 秒後幾乎看不見（LED 要 1.8V 以上才會發光，所以電壓掉到 2V 以下你就看不到了，不用等到 5τ）。換 4.7kΩ，τ = 4.7 秒，會亮比較久、但比較暗；10kΩ 時 τ = 10 秒，可以撐十幾秒，但很暗。

按鈕按下去的時候，220Ω 負責充電：τ = 220Ω × 1000µF = 0.22 秒，大約 1 秒就充飽了，所以按 2 秒綽綽有餘。

**觀察與記錄**

| 放電電阻 | τ = R × C（秒） | 放開後看不見 LED 的秒數 | 亮度（亮／普通／暗） |
|---|---|---|---|
| 1kΩ | | | |
| 4.7kΩ | | | |
| 10kΩ | | | |

### 實驗 5-2：用三用電表看電容電壓慢慢掉

**材料**

- 9V 電池與電池扣
- 按鈕開關 1 個
- 10kΩ 電阻 1 顆
- 100µF 電解電容 1 顆；另外準備 470µF、1000µF 各 1 顆做比較
- 麵包板、杜邦線
- 數位三用電表
- 手機碼表（或請同學數秒）

**接線（放電）**

```
 9V + ──[ 按鈕 ]──┬──────────┐
                  │+         │
                ══╧══     [ 10kΩ ]      三用電表（DCV 20V 檔）
                100µF        │          紅棒 → 電容 +
                  │−         │          黑棒 → GND
 9V − ────────────┴──────────┴── GND
```

- 電池扣紅線 → 按鈕 → 電容長腳（+）
- 電容短腳（−）→ GND
- 10kΩ 跨在電容兩端（一端電容 +，一端 GND）
- 電表紅棒夾在電容 +，黑棒夾在 GND

**步驟**

1. 先算：τ = 10kΩ × 100µF = 1 秒。預測放開按鈕後每秒的電壓，填進表格「預測」欄（用上一節的表：37%、14%、5%……）。
2. 按住按鈕，電表應該顯示約 9V（電容充飽）。
3. 放開按鈕的同時按下碼表，每隔 1 秒讀一次電表。因為電表每秒只更新 2～3 次，建議一個人讀數、一個人報時，或是用手機錄影電表和碼表再慢慢看。
4. 換成 470µF（τ = 4.7 秒），每 5 秒讀一次，會輕鬆很多。
5. 換成 1000µF（τ = 10 秒），每 10 秒讀一次。
6. 額外觀察：把 10kΩ 拔掉，只留電表。充飽後放開按鈕，看電壓掉多快。

**接線（充電）**

想看充電曲線，把 10kΩ 移到按鈕和電容之間：

```
 9V + ──[ 按鈕 ]──[ 10kΩ ]──┬────  電表紅棒
                            │+
                          ══╧══ 100µF
                            │−
 9V − ──────────────────────┴────  電表黑棒（GND）
```

7. 先用一條杜邦線碰一下電容兩端讓它放光（電壓歸 0）。
8. 按住按鈕不放，每秒讀一次：應該看到 0 → 5.7 → 7.8 → 8.6 → 8.8 → 8.9V，越來越慢地接近 9V。

**你應該看到**

放電時（10kΩ + 100µF）大約是：

| 時間 | 0 秒 | 1 秒 | 2 秒 | 3 秒 | 4 秒 | 5 秒 |
|---|---|---|---|---|---|---|
| 電壓 | 9.0V | 3.3V | 1.2V | 0.45V | 0.17V | 0.06V |

換 470µF 後（τ = 4.7 秒）：0 秒 9.0V、5 秒約 3.1V、10 秒約 1.1V、15 秒約 0.4V、20 秒約 0.1V。換 1000µF 後（τ = 10 秒）：10 秒 3.3V、20 秒 1.2V、30 秒 0.45V。

步驟 6 把 10kΩ 拔掉後，電壓幾乎不動，一分鐘可能才掉零點幾伏。因為三用電表的輸入電阻大約 10MΩ，τ = 10MΩ × 100µF = 1000 秒！這也說明了：三用電表量東西時幾乎不會「偷」電流，所以不會干擾電路。

**觀察與記錄**

| 時間（秒） | 預測電壓（V） | 100µF 實際（V） | 470µF 實際（V）（每 5 秒） | 1000µF 實際（V）（每 10 秒） |
|---|---|---|---|---|
| 0 | 9.0 | | | |
| 1τ | 3.3 | | | |
| 2τ | 1.2 | | | |
| 3τ | 0.45 | | | |
| 4τ | 0.17 | | | |
| 5τ | 0.06 | | | |

### 實驗 5-3：用示波器看充放電曲線（Arduino 方波經過 RC）

三用電表每秒只能看兩三次，τ = 1 秒已經快到很難讀；如果 τ 只有 1 毫秒，電表完全來不及。這時候就要請出示波器：讓 Arduino 不停地「接上電池、拔掉電池」（也就是輸出方波），示波器就能把一次次的充放電曲線畫出來。

**材料**

- Arduino UNO 與 USB 線
- 10kΩ 電阻 1 顆
- 100nF 陶瓷電容（印 104）1 顆；另外準備 100µF 電解電容做慢速版本
- 麵包板、杜邦線
- 示波器（雙通道，探棒 2 支）

**接線**

```
 Arduino D9 ──┬──[ 10kΩ ]──┬──────── 
              │            │
          CH1 探棒      ══╧══ 100nF      CH2 探棒
              │            │
 Arduino GND ─┴────────────┴──── 接地夾（兩支都夾這裡）
```

- Arduino D9 → 10kΩ 一端
- 10kΩ 另一端 → 節點 B → 100nF 一腳
- 100nF 另一腳 → Arduino GND
- CH1 探棒鉤在 D9（方波輸入），CH2 探棒鉤在節點 B（電容電壓）
- **兩支探棒的接地夾都夾在 Arduino GND**

**程式**

```cpp
// 第 5 章 實驗 5-3：Arduino 產生方波，用示波器看 RC 充放電
const int squarePin = 9;       // 方波輸出腳位 D9
const int halfPeriodMs = 5;    // 半個週期的長度（毫秒）
                               // 5 → 週期 10ms，頻率 100Hz（配 10kΩ + 100nF）
                               // 改成 500 → 週期 1 秒，頻率 1Hz（配 10kΩ + 100µF 或 LED）

void setup() {
  pinMode(squarePin, OUTPUT);  // 把 D9 設成輸出
}

void loop() {
  digitalWrite(squarePin, HIGH);   // D9 輸出 5V，開始充電
  delay(halfPeriodMs);             // 等半個週期
  digitalWrite(squarePin, LOW);    // D9 輸出 0V，開始放電
  delay(halfPeriodMs);             // 再等半個週期
}
```

如果你想要更快的方波，也可以用 `tone()`，它會在背景自動產生方波，`loop()` 裡什麼都不用寫：

```cpp
// 第 5 章 實驗 5-3（替代版）：用 tone() 產生 100Hz 方波
const int squarePin = 9;       // 方波輸出腳位 D9

void setup() {
  tone(squarePin, 100);        // 在 D9 輸出 100Hz 方波，改成 1000 就是 1kHz
}

void loop() {
  // 不用做任何事，tone() 會自己一直輸出
}
```

**步驟**

1. 先算 τ = 10kΩ × 100nF = 1ms。方波半個週期是 5ms = 5τ，所以每次充電都來得及充飽、每次放電都來得及放光。
2. 上傳程式。接好線，兩支探棒的接地夾都夾 GND。
3. 示波器設定：CH1 與 CH2 都開啟，都設 1V/div（探棒若是 10×，示波器該通道也要設 10×）；水平 1ms/div；觸發來源 CH1、上升邊緣、準位 2.5V；觸發模式 Auto。
4. 畫面上 CH1 應該是乾淨的方波，CH2 是圓弧形的充放電曲線。
5. 用游標（Cursor）量時間：把一條游標放在 CH1 由 0V 跳到 5V 的那一瞬間，另一條放在 CH2 爬到 3.2V（5V 的 63%）的地方，兩條游標的時間差應該約 1ms，就是 τ。
6. 把 100nF 換成 100µF（注意極性：長腳接節點 B），程式的 `halfPeriodMs` 改成 500 重新上傳，水平改成 500ms/div。這時 τ = 1 秒，但半個週期只有 0.5 秒，電容還沒充飽就要放電，看看波形變成什麼樣。
7. 再把 `halfPeriodMs` 改成 5000（5 秒），水平改成 2s/div，看看是不是又變回完整的圓弧。

**你應該看到**

```
CH1：D9 的方波（1V/div，1ms/div）
 5V ┤    ┌─────────┐         ┌─────────┐
    │    │         │         │         │
    │    │         │         │         │
 0V ┼────┘         └─────────┘         └──── 時間

CH2：電容電壓（1V/div，1ms/div）
 5V ┤       ╭──────╮            ╭──────╮
    │     ╱         ╲         ╱         ╲
3.2V┤  ╱            ╲      ╱            ╲
    │  ╱               ╲   ╱               ╲
 0V ┼─╯                 ╰─╯                 ╰── 時間
      ◄─►
      1ms = τ（CH2 爬到 3.2V 的時間）
      ◄────────►
        5ms = 5τ（充飽）
```

方波一跳上去，電容電壓就開始「往上爬」，一開始陡、越來越平，5ms 後幾乎貼到 5V；方波一掉下來，電容電壓就「往下滑」，一樣先快後慢。步驟 6 的慢速版本，因為只有 0.5τ 就換方向，曲線會變成一個圓圓的三角波，高度到不了 5V。步驟 7 把半週期拉長到 5τ，又會看到完整的圓弧。

## 用儀器看看

**三用電表**：有些數位三用電表有電容檔（符號是「F」或「─┤├─」）。把電容兩腳插進電表專用的小孔或用探棒夾住（電解電容要先放電、注意極性），就能直接讀出電容值。你會發現電解電容的實際值可能和標示差 10%～20%，這是正常的。如果你的電表沒有這個檔位，用實驗 5-2 的方法反推也可以：量出放電到 37% 需要幾秒，再用 C = τ ÷ R 算出來。例如放電到 3.3V 花了 4.5 秒，R = 10kΩ，C = 4.5 ÷ 10000 = 0.00045F = 450µF，表示那顆「470µF」的實際值差不多。

**示波器**：實驗 5-3 就是示波器的第一次登場。重點提醒三件事：

1. 兩支探棒的接地夾都只能夾 GND。
2. 探棒的 1×/10× 開關和示波器的設定要一致，否則讀值會差 10 倍（第 6 章會詳細說明）。
3. 看慢速訊號（500ms/div 以上）時，示波器會進入「滾動模式」，波形像心電圖一樣從右邊往左邊流過去，這是正常的。

下一章我們會把示波器的每一個旋鈕都講清楚。

## 常見錯誤與除錯

- **實驗 5-1 按住按鈕 LED 也不亮** → 電容接反（接反的電解電容會像短路，把電壓拉到 0）、LED 接反、或按鈕插在麵包板上沒有接通 → 拔掉電池，檢查電容白帶是否在 GND 側、LED 長腳是否接電阻；按鈕四支腳換一組試試。
- **放開按鈕 LED 立刻熄滅，沒有慢慢變暗** → 電容沒接到節點 A，或電容太小（拿到 100µF 而不是 1000µF） → 看電容上印的數字，用電表量節點 A 的電壓是否會慢慢掉。
- **電容發熱、鼓起、有怪味** → 接反了或超過耐壓 → 立刻拔掉電池，那顆電容不要再用。
- **實驗 5-2 電壓掉得比預測快很多** → 電表轉在電阻檔或電流檔、或電容的實際值偏小 → 確認電表在 DCV；換一顆電容比較。
- **實驗 5-2 電壓完全不掉** → 10kΩ 沒接好，變成只有電表在放電（τ = 1000 秒） → 檢查 10kΩ 兩端是否真的跨在電容上。
- **實驗 5-3 CH2 看起來和 CH1 一樣是方波** → 探棒鉤錯地方（鉤到 D9 而不是節點 B），或電容沒接上 → 重新確認探棒位置；把 10kΩ 換成 100kΩ，曲線應該變得更圓更慢。
- **實驗 5-3 波形一直左右跑、停不下來** → 觸發來源不是 CH1，或準位不在 0～5V 之間 → 設觸發來源 CH1、上升邊緣、準位 2.5V。
- **實驗 5-3 讀出來的電壓只有 0.5V** → 探棒是 10× 但示波器設 1× → 把示波器的探棒設定改成 10×。

## 想一想

1. 10kΩ 配 100µF 的 τ 是多少？要幾秒才算充飽？

<details><summary>參考答案</summary>

τ = 10000 × 0.0001 = 1 秒。5τ = 5 秒充飽。

</details>

2. 你想要一個放開按鈕後大約 5 秒才熄滅的延遲關燈，手上只有 1000µF 電容。應該用幾 Ω 的放電電阻？

<details><summary>參考答案</summary>

τ = R × C，R = τ ÷ C = 5 ÷ 0.001 = 5000Ω。手邊最接近的是 4.7kΩ（τ = 4.7 秒）。注意 LED 在 2V 以下就看不到了，所以實際「看起來亮著」的時間會比 τ 短一些，想要更久可以用 10kΩ。

</details>

3. 一顆充到 9V 的電容開始放電，經過 1τ 剩多少伏特？2τ 呢？

<details><summary>參考答案</summary>

1τ：9 × 0.37 ≈ 3.3V。2τ：9 × 0.14 ≈ 1.2V（也可以算 3.3 × 0.37 ≈ 1.2V）。

</details>

4. 示波器上，你量到 CH2 從 0V 爬到 3.2V（5V 的 63%）花了 2ms，電阻是 10kΩ。電容是多少？

<details><summary>參考答案</summary>

τ = 2ms = 0.002 秒。C = τ ÷ R = 0.002 ÷ 10000 = 0.0000002F = 200nF。可能是兩顆 100nF 並聯（並聯電容值相加）。

</details>

5. 為什麼電解電容接反會爆，陶瓷電容卻沒有方向？

<details><summary>參考答案</summary>

電解電容靠一層很薄的化學膜當絕緣層，這層膜只有在正確方向的電壓下才存在；接反會把膜破壞，電容變短路、發熱、產生氣體而爆開。陶瓷電容的絕緣層是陶瓷本身，兩個方向都一樣，所以沒有極性。

</details>

6. （開放挑戰）實驗 5-3 步驟 6 的波形為什麼到不了 5V？如果想用 1Hz 方波（半週期 0.5 秒）看到完整的圓弧，R 和 C 要怎麼選？寫出一組可行的數值並算出 τ。

<details><summary>參考答案</summary>

因為半週期只有 0.5τ，電容充到 5V 的 39% 左右（約 2V）就被拉下來放電，放電也只有 0.5τ，所以電壓在中間來回晃，爬不到頂。要看到完整圓弧，半週期要有 5τ，也就是 τ ≤ 0.1 秒。例如 10kΩ + 10µF：τ = 10000 × 0.00001 = 0.1 秒，剛好；或 1kΩ + 100µF：τ = 1000 × 0.0001 = 0.1 秒，也可以。

</details>

## 本章小結

- 電容像水桶，存的是電荷；電容值的單位是法拉（F），常用 µF、nF、pF，每級差 1000 倍。
- 陶瓷電容的三位數字「104」= 100nF；電解電容直接印 µF 和耐壓。
- 電解電容有極性：長腳是 +、白帶是 −，接反會爆。
- 充電與放電都是「先快後慢」的圓弧曲線。
- 時間常數 τ = R × C（Ω × F = 秒）；kΩ × µF 直接等於 ms。
- 每過一個 τ，放電剩 37%、充電到 63%；5 個 τ 就充飽或放光。
- 三用電表看得到秒等級的充放電；毫秒等級要用示波器，用 Arduino 方波當「不停開關的電池」。
- 示波器接地夾只能夾 GND；探棒 1×/10× 要和示波器設定一致。
