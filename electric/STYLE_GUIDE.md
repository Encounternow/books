# 《動手玩電》寫作規範（給所有章節作者）

## 讀者
- 台灣國小高年級到國中生（11–15 歲），數學程度：會四則運算、簡單代數（a = b × c 可以移項）、看得懂折線圖。不會對數、不會微積分、不會三角函數。
- 可能有老師或家長陪同，但內容必須讓學生自己讀也看得懂。
- 用繁體中文（台灣用語）：三用電表、麵包板、杜邦線、示波器、邏輯分析儀、電阻、電容、電感、電晶體、微控制器、序列埠、腳位。
- 專有名詞第一次出現時附英文，例如「電壓（Voltage）」。之後只用中文。

## 語氣
- 像一位熱情、有耐心的社團老師在旁邊講話。可以說「你」、「我們」。
- 每個新概念都先給一個生活比喻或故事，再給定義，再給公式。
- 公式一定要用數字算一次範例給學生看。
- 不要嚇人，但安全要講清楚。

## 安全紅線（每章動手做之前要遵守）
- 全書只用 12V 以下的直流電（電池、USB、Arduino/ESP32 供電）。絕對不碰家用插座 110V。
- 電解電容有極性，接反會爆。電池不可短路。馬達、繼電器接線圈要加飛輪二極體。
- 示波器探棒的接地夾（黑色鱷魚夾）必須接電路的 GND，不可以隨便夾。

## 每一章固定結構（請照順序，標題用這些字）
1. `# 第 N 章　章名`
2. `## 本章目標`：3–5 條「學完你會……」
3. `## 開場：……`：一段 150–300 字的生活情境或故事，引出問題。
4. `## 核心概念`：可以分多個 `###` 小節。每個概念：比喻 → 定義 → 公式（若有）→ 算一個例子。
5. `## 動手做`：至少 2 個實驗（專題章可以是 1 個大實驗）。每個實驗用 `### 實驗 N-1：名稱` 格式，內含：
   - **材料**：條列（型號、數值要寫清楚，例如 220Ω 電阻、100µF 電解電容、2N2222 電晶體）。
   - **接線**：用 ASCII 電路圖放在 ``` 程式碼區塊裡，並用文字逐條說明接哪裡。麵包板接線要寫「Arduino D9 → 220Ω → LED 長腳，LED 短腳 → GND」這種格式。
   - **步驟**：編號步驟。
   - **你應該看到**：預期結果。
   - **觀察與記錄**：給一個空白表格讓學生填量測值。
6. `## 用儀器看看`：示波器、邏輯分析儀、三用電表的使用。寫清楚：接哪裡、旋鈕/設定調多少（V/div、s/div、觸發）、畫面應該長什麼樣（用文字描述或 ASCII 波形）。如果本章真的沒有適合的儀器觀察，可以寫三用電表量測。
7. `## 常見錯誤與除錯`：條列「症狀 → 可能原因 → 怎麼查」。
8. `## 想一想`：4–6 題，由易到難，最後 1–2 題是開放挑戰。題目後面用 `<details><summary>參考答案</summary> ... </details>` 附答案。
9. `## 本章小結`：5–8 條重點。
10. `## 名詞表`：本章新名詞，`| 中文 | 英文 | 一句話解釋 |` 表格。

## 程式碼
- Arduino / ESP32 程式用 ```cpp 區塊，每個程式要完整可以直接上傳（含 setup/loop）。
- 程式裡每 2–3 行要有繁體中文註解。
- 變數命名用英文，但要有意義（ledPin、sensorValue）。
- 腳位預設：Arduino UNO 的 LED 用 D9（PWM）、按鈕用 D2、類比輸入用 A0；ESP32 DevKit 的 LED 用 GPIO 2（板上 LED）或 GPIO 18、類比輸入用 GPIO 34。

## 器材假設（全書共用，不要用這個清單以外的東西）
麵包板、杜邦線（公公/公母）、數位三用電表、電阻包（10Ω–1MΩ 常用值，含 220Ω、330Ω、1kΩ、4.7kΩ、10kΩ、100kΩ）、陶瓷電容（100nF）與電解電容（10µF、100µF、470µF、1000µF）、電感（100µH、1mH）與漆包線/鐵釘（自製線圈）、LED（紅、綠、藍、白）、整流二極體 1N4007、小訊號二極體 1N4148、NPN 電晶體 2N2222、N 通道 MOSFET IRLZ44N、按鈕開關、10kΩ 可變電阻、光敏電阻（LDR）、DHT11 溫濕度感測器、無源蜂鳴器、小直流馬達（3–6V）、SG90 伺服馬達、5V 繼電器模組、9V 電池與電池扣、3 號電池盒、Arduino UNO、ESP32 DevKit V1、0.96 吋 OLED（SSD1306，I2C）、示波器（雙通道，含 10× 探棒）、USB 邏輯分析儀（8 通道，搭配 PulseView 或 Saleae Logic 軟體）、電腦。

## 圖
- 不能放圖片檔。電路圖、波形圖一律用 ASCII art 放在 ``` 區塊裡。
- ASCII 電路圖範例：
```
 Arduino D9 ──[ 220Ω ]──►|── GND
                        LED
```
- 波形圖範例：
```
電壓
 5V ┤    ┌────┐    ┌────┐
    │    │    │    │    │
 0V ┼────┘    └────┘    └──── 時間
        ◄────►
         1 ms
```

## 長度
- 一般章節 3000–5000 字（不含程式碼）。專題章可以更長。
- 不要灌水，但每個實驗要寫到學生能照著做出來。

## 不要做的事
- 不要用微積分、複數、拉普拉斯、傅立葉這些字（可以說「把波拆成很多正弦波加起來」但不要用名詞）。
- 不要只講理論不做實驗。
- 不要假設學生有本書器材清單以外的東西。
- 不要寫「如圖所示」然後沒有圖。
