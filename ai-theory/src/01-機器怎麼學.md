## 開場：阿嬤的水果攤

小安的阿嬤在市場賣水果。暑假小安想幫阿嬤寫一個手機程式：拍一張照片，程式就說出這是蘋果、橘子還是香蕉，方便結帳。

小安先寫規則：「紅色的是蘋果，橘色的是橘子，黃色長長的是香蕉。」第一顆紅蘋果就對了。第二顆是青蘋果，程式說「不知道」。阿嬤再拿出一根沒熟的綠香蕉，又不知道。小安補了「綠色長長的也是香蕉」，阿嬤拿出一顆黃色的金冠蘋果，程式說「香蕉」。

規則越補越多，可是阿嬤每拿出一顆新水果，規則就破功。阿嬤笑著說：「我沒背過什麼規則啊，我就是看多了。」

「看多了」這三個字，就是這本書要講的事。能不能讓電腦也「看多了」？能，那就叫**機器學習**。

## 核心概念

### 規則寫死 vs 從例子學

小安一開始的做法叫**規則式（Rule-based）**：人想好規則，一條一條寫進程式。規則很清楚的事情這樣做很好，例如「60 分以上及格」、「滿 500 元免運」。但像「這是不是蘋果」、「這封是不是垃圾信」，規則多到寫不完，例外永遠比你想的多。

**機器學習（Machine Learning）**反過來：人不寫規則，人給**例子**。給電腦兩百張蘋果、兩百張橘子的照片並告訴它哪張是哪種，電腦自己找出「什麼樣的照片比較像蘋果」。規則不是人寫的，是電腦從例子裡「學」出來的。

兩種做法比一比：

| | 規則式 | 機器學習 |
|---|---|---|
| 誰想規則 | 人 | 電腦從例子裡找 |
| 需要什麼 | 想得出規則的人 | 大量有答案的例子 |
| 遇到新狀況 | 常常破功，要人再補規則 | 看過類似的就能猜，但沒看過的也會猜錯 |
| 規則看得懂嗎 | 看得懂，一條一條 | 有的看得懂（第 2 章的決策樹），有的看不懂（第 7 章的神經網路） |
| 適合的事 | 規則清楚、例外少 | 規則說不清楚、例子很多 |

重點不是誰比較好，而是**什麼時候用哪個**：算運費用規則，認水果用學習。

### 三種學法：監督式、非監督式、強化學習

機器學習依照「例子長什麼樣」分成三大類，每一類都有一個你早就做過的生活版本。

**監督式學習（Supervised Learning）**：每個例子都附答案，像有正解的練習卷，寫錯了就對答案修正。阿嬤的水果攤就是這種：這顆是蘋果、那顆是橘子，一顆一顆告訴電腦。垃圾信過濾、手寫數字辨識、用腳長猜身高，都是監督式。**本書第 1–9 章幾乎全部是監督式學習。**

**非監督式學習（Unsupervised Learning）**：例子沒有答案，電腦自己把像的歸在一起。像整理衣櫃，沒人告訴你哪件放哪，你自然會把 T 恤放一堆、外套放一堆。音樂 App 把聽歌習慣相似的人分群，就是這種。

**強化學習（Reinforcement Learning）**：沒有答案卷，但做對有獎勵、做錯有懲罰，電腦靠一次次嘗試學會「怎麼做分數最高」。像教狗坐下：坐對了給零食，久了牠就會。下棋 AI、走路的機器人、第 12 章「讓聊天 AI 學會有禮貌」，都用這類方法。

| 學法 | 例子長什麼樣 | 生活版本 | AI 版本 |
|---|---|---|---|
| 監督式 | 題目 + 答案 | 寫有正解的練習卷 | 認水果、認數字、猜身高 |
| 非監督式 | 只有題目 | 自己整理衣櫃 | 把客人分群、找出異常刷卡 |
| 強化學習 | 做了才知道得幾分 | 教狗坐下、打電動練技巧 | 下棋、機器人走路 |

做機器學習的人看這張表，會用五個詞描述它：

1. **訓練資料（Training Data）**：整張表，這 20 筆是拿來「讓電腦學」的例子。
2. **特徵（Feature）**：描述一個人的欄位，身高、腳長、運動天數、閱讀小時都是。特徵就是「電腦看得到的線索」。
3. **標籤（Label）**：想要電腦猜的那一欄答案。問題是「猜他喜歡哪一科」，標籤就是最後一欄；問題是「從腳長猜身高」，標籤就變成身高。**哪一欄是標籤，看你想猜什麼。**
4. **模型（Model）**：「輸入特徵、輸出猜測」的東西，可以是一條規則、一棵樹、一條直線、一個神經網路。模型裡可以調的數字叫**參數（Parameter）**。
5. **預測（Prediction）**：模型對某個人吐出的猜測。把新同學的腳長丟進去，模型說「大概 160 公分」，160 就是預測。

畫成一條流程：

```
  訓練資料（特徵 + 標籤）
          │
          ▼  學（調參數）
       ┌──────┐
       │ 模型 │
       └──────┘
          │
   新的特徵 ──▶ 模型 ──▶ 預測
```

一句話記住：**用訓練資料教出一個模型，再用模型對新的特徵做預測。**

### 「學」就是調整參數，讓錯誤變小

現在回答本章最核心的問題：電腦「學」的時候，到底在做什麼？

答案比你想的樸素：**它在調整模型裡的數字（參數），讓模型在訓練資料上的錯誤變小。**就這樣。後面所有看起來很厲害的東西，都是這句話的不同版本。

用最簡單的例子看。問題：**猜一位同學的身高**，但你什麼都不知道，只能猜一個數字。

模型零：「不管誰，一律猜 160。」它有一個參數（160），是隨便訂的。錯多少？把每個人的身高減掉 160、取絕對值（只看差幾公分，不管正負），20 個人平均：

```
平均誤差 = (|152−160| + |165−160| + … + |161−160|) ÷ 20 = 5.6 公分
```

模型一：「一律猜全班平均。」全班身高加起來是 3156，除以 20 得到平均 157.8。這次參數不是隨便訂的，是**從資料算出來的**：

```
平均誤差 = (|152−157.8| + |165−157.8| + … + |161−157.8|) ÷ 20 = 5.32 公分
```

5.32 比 5.6 小。只改了一個數字，猜得更準了。這就是最小的一次「學習」：**用資料把參數從 160 調成 157.8，錯誤變小了。**（在《從資料看世界》第 4 章你學過「平均數是讓總誤差平方最小的那個數」，這裡是同一件事換個說法。）

模型二：「腳長小於 24 公分的猜那一組的平均，24 以上的猜另一組的平均。」這個模型用到了一個特徵（腳長），參數變成兩個。腳長小於 24 的有 8 人（小安、小芸、小潔、小美、小婷、小晴、小慧、小雯），平均 151.9；24 以上的有 12 人，平均 161.75。

```
平均誤差 = 3.2 公分
```

從 5.6 → 5.32 → 3.2。三個模型，一個比一個多用一點資料、多一個參數，錯誤一路往下掉。第 3 章我們會用「一條直線」取代「分兩組」，誤差會再掉到 1.7 公分左右。

| 模型 | 用了什麼特徵 | 參數 | 平均誤差（公分） |
|---|---|---|---|
| 零：一律猜 160 | 無 | 160（亂訂的） | 5.6 |
| 一：一律猜平均 | 無 | 157.8（算出來的） | 5.32 |
| 二：腳長分兩組 | 腳長 | 151.9、161.75 | 3.2 |
| （第 3 章）直線 | 腳長 | 斜率、截距 | 約 1.7 |

所以「訓練（Training）」這個詞，本書從頭到尾只有一個意思：**調整參數，讓錯誤變小。**平均數是這樣、第 2 章的決策樹是這樣、第 7 章幾百萬個參數的神經網路也是這樣，差別只在參數多少，以及「怎麼調」。

### 背答案不算學會：訓練與測試

最後一個觀念。如果模型把訓練資料整個背起來——看到小安就答 152、看到阿凱就答 165——它在訓練資料上誤差是 0，看起來完美，但來了一位沒看過的新同學，它就傻了。

所以評估模型，**不能只看它在訓練資料上錯多少，要看它在沒看過的資料上錯多少。**沒看過的那份資料叫**測試資料（Test Data）**。第 2 章講決策樹時會看得很清楚，第 8 章會正式用上。先記住：**訓練資料上很準不代表學會了；沒看過的資料上也準，才是學會了。**

### 活動 1-2：試算表做「平均預測」

**材料／工具**：Google 試算表（或 Excel）、本章的 20 位同學資料表。

**步驟**：

1. 開一個新試算表。A 欄輸入暱稱、B 欄輸入身高、C 欄輸入腳長，第 1 列當標題，資料從第 2 列到第 21 列。
2. 在 E1 輸入「猜的值」，E2 輸入 `160`。在 D1 輸入「誤差」，D2 輸入 `=ABS(B2-$E$2)`，往下拉到 D21。`ABS` 是取絕對值，`$E$2` 的錢字號表示往下拉時固定看 E2 那一格。
3. 在 D23 輸入 `=AVERAGE(D2:D21)`，這就是「一律猜 160」的平均誤差。
4. 把 E2 改成 `=AVERAGE(B2:B21)`，試算表會算出全班平均 157.8，D23 會自動變成新的平均誤差。
5. 把 E2 再改成其他數字試試看：155、158、162。觀察 D23 怎麼變，找出讓 D23 最小的數字大概在哪裡。
6. 進階：在 F2 輸入 `=IF(C2<24, AVERAGEIF($C$2:$C$21,"<24",$B$2:$B$21), AVERAGEIF($C$2:$C$21,">=24",$B$2:$B$21))`，往下拉到 F21。這一格的意思是：腳長小於 24 的人，猜「腳長小於 24 那組的平均身高」；否則猜另一組的平均。在 G2 輸入 `=ABS(B2-F2)` 往下拉，G23 輸入 `=AVERAGE(G2:G21)`。

**你應該看到／得到**：

- 步驟 3：D23 = 5.6。
- 步驟 4：E2 變 157.8，D23 = 5.32。
- 步驟 5：猜 155 大約 5.7、猜 158 大約 5.3、猜 162 大約 6.3。平均附近最小，離平均越遠誤差越大。
- 步驟 6：F 欄會出現 151.875 或 161.75 兩種值，G23 = 3.2。

## 用工具看看

第一次用 Google Colab：打開 https://colab.research.google.com ，登入後按「檔案 → 新增筆記本」，把整段程式貼進灰色方格，按左邊的播放鍵（或 Shift + Enter）。

```python
import numpy as np

# 20 位同學的身高（公分），順序跟第 1 章的資料表一樣
height = np.array([152,165,148,158,158,170,150,165,156,160,
                   153,167,149,163,154,159,154,163,151,161])
# 20 位同學的腳長（公分）
foot = np.array([23.0,25.5,22.5,24.0,23.5,26.5,22.0,25.0,24.0,24.5,
                 23.0,26.0,22.5,25.5,24.5,24.0,23.5,26.0,23.0,25.0])

# 模型零：不管是誰，一律猜 160
guess = 160
print("一律猜 160，平均差：", np.abs(height - guess).mean(), "公分")

# 模型一：用全班平均當預測（這就是「學」出來的參數）
mean_h = height.mean()

# 模型二：腳長小於 24 的一組、24 以上的一組，各猜自己那組的平均
small = foot < 24
pred = np.where(small, height[small].mean(), height[~small].mean())
print("腳長 <24 那組平均：", height[small].mean(), "；>=24 那組平均：", height[~small].mean())
print("分兩組猜，平均差：", np.abs(height - pred).mean(), "公分")
```

**你應該看到**：

```
一律猜 160，平均差： 5.6 公分
全班平均身高： 157.8
一律猜平均，平均差： 5.3199999999999985 公分
腳長 <24 那組平均： 151.875 ；>=24 那組平均： 161.75
分兩組猜，平均差： 3.2 公分
```

那個 5.3199999999999985 就是 5.32，電腦算小數時尾巴會有一點點誤差，不是你跑錯。

幾個說明：`np.array` 把一串數字變成 numpy 陣列，之後 `height - 160` 會自動幫 20 個人各減 160，不用寫迴圈。`np.abs` 取絕對值、`.mean()` 取平均、`np.where(條件, A, B)` 是「條件成立用 A，否則用 B」。不用現在記住，之後每章都會再看到。

試著改一改：把 `guess = 160` 改成 170 再跑一次（平均差會變 12.2）。把 `foot < 24` 改成 `foot < 25`，分組的線移一下，誤差會變好還是變差？

## 常見錯誤與迷思

- **「AI 很聰明，它會自己想規則。」** → 它不會「想」，它是調參數讓錯誤變小。看起來像有規則，是因為參數調完之後行為剛好有規律。→ 正確理解：AI 的「聰明」來自資料與調參數的過程，不是來自理解。
- **「只要規則寫得夠多，就不用機器學習。」** → 活動 1-1 已經示範，例外永遠補不完，而且每補一條都可能弄壞之前的。→ 正確理解：規則清楚的事用規則，說不清楚的事給例子。
- **「標籤就是那張表的最後一欄。」** → 哪一欄是標籤，由你想猜什麼決定。同一張表，猜科目時標籤是科目，猜身高時標籤是身高。→ 正確理解：特徵是線索，標籤是想猜的答案，兩者是角色，不是固定的欄位。
- **「模型在訓練資料上誤差 0，所以它很厲害。」** → 背答案也能做到誤差 0。→ 正確理解：要看它在沒看過的資料上錯多少。
- **「例子越多一定越好。」** → 例子多當然好，但如果 20 顆水果裡沒有任何一顆「紅色的小蘋果」，再多類似的例子也教不會這件事。→ 正確理解：例子要多，也要「夠不一樣」，涵蓋你將來會遇到的情況。

## 想一想

1. 下面三件事各屬於哪一種學習？(a) 給 AI 一萬張標好「有貓／沒貓」的照片；(b) 讓 AI 自己玩一萬局貪食蛇，吃到食物加分、撞牆扣分；(c) 把班上同學的喜好資料丟給 AI，請它分成幾群。

<details><summary>參考答案</summary>

(a) 監督式，因為每張照片都有答案。(b) 強化學習，沒有答案卷，靠加分扣分。(c) 非監督式，沒有標籤，只是分群。

</details>

2. 用本章的資料表，如果問題是「從運動天數猜他喜歡哪一科」，哪一欄是特徵？哪一欄是標籤？

<details><summary>參考答案</summary>

特徵是「每週運動天數」，標籤是「最喜歡的科目」。其他欄位這次沒用到。

</details>

3. 小安的阿嬤說「我沒背規則，我就是看多了」。用本章的五個關鍵詞說明阿嬤的腦袋在做什麼。

<details><summary>參考答案</summary>

阿嬤看過的幾萬顆水果是訓練資料；顏色、形狀、大小、手感是特徵；每顆水果「其實是什麼」是標籤；她腦中那個一看就知道的判斷力是模型；對一顆新水果說出名字是預測。她多年來在做的，就是從例子裡調整自己的判斷（參數）。

</details>

4. 「一律猜 160」平均誤差 5.6，「一律猜 157.8」是 5.32。如果改成「一律猜 150」，誤差會比 5.6 大還是小？先想再算（可以用活動 1-2 的試算表）。

<details><summary>參考答案</summary>

會更大。150 離全班平均 157.8 更遠，幾乎每個人都比 150 高，平均誤差會到 8.1。離平均越遠，平均誤差越大。

</details>

5. 一個模型把 20 位同學全部背起來（看到小安答 152、看到阿凱答 165），它在訓練資料上誤差是 0。這算學會了嗎？你要怎麼證明它有沒有學會？

<details><summary>參考答案</summary>

不算。要找幾位它沒看過的同學（測試資料），量他們的腳長，讓模型預測身高，再跟真實身高比。如果它只會背，對沒看過的人會答不出來或亂猜；真的學會的模型（例如第 3 章的直線）對新同學也會猜得差不多準。

</details>

6. 開放挑戰：活動 1-1 的規則「圓的看重量，160 以上是蘋果、150 以下是橘子」，在 150 到 160 之間是空的。請設計一條處理「155 公克的圓水果」的辦法，並說明你需要什麼額外的例子或特徵才有把握。

<details><summary>參考答案</summary>

參考做法：(1) 把分界線訂在中間 155，155 以上算蘋果——但這只是猜，沒有例子支持。(2) 加入顏色當第二線索：圓、155 公克、紅或綠 → 蘋果；橘 → 橘子。(3) 最好的辦法是去收集更多 150–160 公克的圓水果例子，看它們實際上是什麼。這題的重點是：模型在「例子稀少的區域」不可靠，補例子比硬訂規則好。

</details>

## 本章小結

- 規則式是人寫規則，機器學習是人給例子、電腦從例子裡找規則。規則說不清楚、例外很多的事，適合用機器學習。
- 三種學法：監督式（例子附答案）、非監督式（只有例子，自己分群）、強化學習（做了才知道得幾分）。本書前半段都是監督式。
- 五個關鍵詞：訓練資料是全部例子；特徵是線索；標籤是想猜的答案；模型是「輸入特徵、輸出猜測」的東西，裡面有參數；預測是模型對新資料的猜測。
- 「學」＝「訓練」＝調整參數，讓模型在訓練資料上的錯誤變小。
- 最簡單的模型是「一律猜平均」，它只有一個參數。多用一個特徵（腳長分兩組），誤差從 5.32 降到 3.2。
- 在訓練資料上很準不等於學會了，要看沒看過的測試資料。
- 從例子學出來的規則，只在「跟例子相像的範圍」裡可靠。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 規則式 | Rule-based | 人把判斷規則一條一條寫進程式。 |
| 機器學習 | Machine Learning | 人給例子，電腦從例子裡調整參數、找出規律。 |
| 監督式學習 | Supervised Learning | 每個例子都附標籤（答案）的學習。 |
| 非監督式學習 | Unsupervised Learning | 例子沒有標籤，電腦自己把像的歸在一起。 |
| 強化學習 | Reinforcement Learning | 靠獎勵與懲罰，從一次次嘗試中學會怎麼做分數最高。 |
| 訓練資料 | Training Data | 拿來讓模型學的那批例子。 |
| 測試資料 | Test Data | 模型沒看過、用來檢查它是否真的學會的例子。 |
| 特徵 | Feature | 描述一個例子的線索，例如身高、腳長。 |
| 標籤 | Label | 我們想讓模型猜的答案，例如喜歡的科目。 |
| 模型 | Model | 輸入特徵、輸出預測的東西，裡面有可調的參數。 |
| 參數 | Parameter | 模型裡可以調的數字，訓練就是在調它。 |
| 預測 | Prediction | 模型對某筆資料吐出的猜測。 |
| 訓練 | Training | 調整參數，讓模型在訓練資料上的錯誤變小。 |
| 誤差 | Error | 實際值與預測值的差距。 |
