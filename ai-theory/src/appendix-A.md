# 附錄 A　數學速查

這一份把全書用到的數學工具集中在一處，每一條都附一個算好的例子。你不需要從頭讀到尾；當某一章的公式忘了，翻來對一下。每條都標了它第一次出現的章節。

## A.1　向量（第 4 章）

**是什麼**：一串排好順序的數字，寫成 (3, 4) 或直的一欄。在 AI 裡，一個人的特徵、一張圖的像素、一個詞的意義，都是向量。

**向量加法**：對應位置相加。

```
(3, 4) + (1, −2) = (3+1, 4+(−2)) = (4, 2)
```

**縮放（乘一個數）**：每個位置都乘。

```
2 × (3, 4) = (6, 8)
```

**長度**：平方和再開根號（畢氏定理）。

```
|(3, 4)| = √(3² + 4²) = √(9 + 16) = √25 = 5
```

**距離**：兩個向量相減後的長度（第 2 章的歐幾里得距離）。

```
(3, 4) 和 (1, −2) 的距離 = |(3−1, 4−(−2))| = |(2, 6)| = √(4 + 36) = √40 ≈ 6.32
```

## A.2　內積與相似度（第 4、10 章）

**內積（Dot Product）**：對應位置相乘再全部加起來，結果是一個數。

```
(3, 4) · (1, −2) = 3×1 + 4×(−2) = 3 − 8 = −5
```

**意義**：兩個向量「方向多一致」。同方向內積大、垂直內積 0、反方向內積負。

```
(1, 2) · (−2, 1) = −2 + 2 = 0   → 垂直
```

**餘弦相似度（Cosine Similarity）**：內積除以兩個長度，結果介於 −1 到 1，去掉長度的影響只看方向。詞向量的相似度就是這個。

```
a = (1, 2)，b = (2, 3)
a·b = 1×2 + 2×3 = 8
|a| = √5 ≈ 2.236，|b| = √13 ≈ 3.606
相似度 = 8 ÷ (2.236 × 3.606) = 8 ÷ 8.062 ≈ 0.992   → 非常像
```

**加權相加就是內積**：一個神經元的「加權相加」 w₁x₁ + w₂x₂ + … 就是 w · x。

```
權重 w = (0.5, −1)，輸入 x = (2, 1)，偏差 b = 0.5
w·x + b = 0.5×2 + (−1)×1 + 0.5 = 1 − 1 + 0.5 = 0.5
```

## A.3　矩陣（第 4 章）

**是什麼**：數字排成的表格，m 列 n 欄叫 m×n 矩陣。可以看成「一堆向量疊在一起」，也可以看成「一個把向量變成另一個向量的變換」。

**矩陣乘向量**：結果的第 i 個數 = 矩陣第 i 列和向量的內積。

```
┌ 2  0 ┐   ┌ 1 ┐   ┌ 2×1 + 0×1 ┐   ┌ 2 ┐
│      │ × │   │ = │           │ = │   │     → 把 x 拉長 2 倍、y 拉長 3 倍
└ 0  3 ┘   └ 1 ┘   └ 0×1 + 3×1 ┘   └ 3 ┘

┌ 0 −1 ┐   ┌ 1 ┐   ┌ 0 ┐
│      │ × │   │ = │   │     → 把 (1, 0) 轉成 (0, 1)：逆時針轉 90°
└ 1  0 ┘   └ 0 ┘   └ 1 ┘
```

**矩陣乘矩陣**：結果第 i 列第 j 欄 = 左邊第 i 列 · 右邊第 j 欄。左邊的欄數要等於右邊的列數。

```
┌ 1 2 ┐   ┌ 5 6 ┐   ┌ 1×5+2×7  1×6+2×8 ┐   ┌ 19 22 ┐
│     │ × │     │ = │                  │ = │       │
└ 3 4 ┘   └ 7 8 ┘   └ 3×5+4×7  3×6+4×8 ┘   └ 43 50 ┘
```

**為什麼 AI 需要它**：一層神經網路有很多神經元，每個神經元各做一次內積；把所有神經元的權重疊成矩陣 W，整層就是一次「W 乘 x」。一次算完，而且電腦（尤其 GPU）算矩陣乘法非常快。

**numpy 寫法**：`A @ B` 是矩陣乘法；`A * B` 是對應位置相乘，不一樣。

## A.4　斜率與梯度（第 3、5 章）

**斜率**：函數在某一點「往右走一小步，往上升多少」。正斜率往右上升，負斜率往右下降，斜率 0 是平的（可能是最低點）。

**用數值估斜率**：

```
f(x) = x²，在 x = 3 的斜率
取一小步 h = 0.01：
斜率 ≈ (f(3.01) − f(3)) ÷ 0.01 = (9.0601 − 9) ÷ 0.01 = 6.01 ≈ 6
```

（正確答案是 6；《數學這樣想（進階）》第 9 章會說 x² 的斜率是 2x。）

**梯度（Gradient）**：有很多個變數時，對每個變數各算一個斜率，排成向量。它指向「上升最快」的方向。

```
f(x, y) = x² + 2y²，在 (1, 1)
對 x 的斜率 = 2x = 2，對 y 的斜率 = 4y = 4
梯度 = (2, 4)
```

**梯度下降（Gradient Descent）**：往梯度的反方向走一小步，重複。步伐大小叫學習率 η。

```
新參數 = 舊參數 − η × 梯度

f(x) = x²，從 x = 3 開始，η = 0.1，斜率 = 2x：
第 1 步：x = 3 − 0.1 × 6 = 2.4，     f = 5.76
第 2 步：x = 2.4 − 0.1 × 4.8 = 1.92，f = 3.69
第 3 步：x = 1.92 − 0.1 × 3.84 = 1.536，f = 2.36
第 4 步：x = 1.229，f = 1.51
第 5 步：x = 0.983，f = 0.97
```

一直往 0 靠近，損失一直下降。η 太大會跳過頭（試 η = 1.1 會發散），太小會走很慢。

**損失對參數的梯度**（第 3 章直線 y = wx，均方誤差）：

```
資料：x = (1, 2, 3)，y = (2, 4, 6)，目前 w = 1.5
預測 = (1.5, 3, 4.5)，誤差 = 預測 − 真實 = (−0.5, −1, −1.5)
損失對 w 的斜率 = (2/n) × Σ 誤差 × x = (2/3) × (−0.5×1 + −1×2 + −1.5×3) = (2/3) × (−7) ≈ −4.67
斜率是負的 → w 要變大 → 新 w = 1.5 − 0.1 × (−4.67) ≈ 1.97
```

## A.5　啟動函數（第 6 章）

神經元加權相加之後，再過一個「啟動函數」決定輸出。沒有它，多層網路疊起來還是一條直線。

**階梯函數（Step）**：大於 0 輸出 1，否則 0。感知器用這個。

**sigmoid**：把任何數壓到 0 到 1 之間，常當「機率」。

```
sigmoid(z) = 1 ÷ (1 + e^(−z))，e ≈ 2.718

sigmoid(0)  = 1 ÷ (1 + 1)       = 0.5
sigmoid(2)  = 1 ÷ (1 + 0.135)   ≈ 0.881
sigmoid(−2) = 1 ÷ (1 + 7.389)   ≈ 0.119
sigmoid(4)  ≈ 0.982，sigmoid(−4) ≈ 0.018
```

形狀像拉平的 S，中間最陡、兩端平。兩端平表示「斜率接近 0」，梯度下降會變慢，這是深層網路少用它的原因。

**ReLU**：負數變 0，正數照舊。簡單、快、斜率不會消失（正數那邊永遠是 1）。

```
ReLU(z) = max(0, z)
ReLU(−3) = 0，ReLU(0) = 0，ReLU(2) = 2
```

**softmax**：把一組分數變成一組加起來等於 1 的機率。多類別分類的最後一層用。

```
分數 z = (2, 1, 0)
e² ≈ 7.389，e¹ ≈ 2.718，e⁰ = 1，合計 ≈ 11.107
機率 = (7.389, 2.718, 1) ÷ 11.107 ≈ (0.665, 0.245, 0.090)
```

分數最大的類別機率最大，而且差距被放大（2 比 1 只多 1 分，機率卻多 2.7 倍）。

## A.6　損失函數（第 3、7、8 章）

**損失（Loss）**：一個數字，表示「現在的預測錯多少」。訓練就是調參數讓它變小。

**均方誤差（MSE）**：迴歸用。每個誤差平方、取平均。平方讓大錯更被重視，也讓負誤差不會抵銷正誤差。

```
預測 (2, 4, 6)，真實 (3, 4, 5)
誤差 (−1, 0, 1)，平方 (1, 0, 1)
MSE = (1 + 0 + 1) ÷ 3 ≈ 0.667
```

**平均絕對誤差（MAE）**：誤差取絕對值再平均，比較不受極端值影響。

```
同上：|−1| + |0| + |1| = 2，MAE = 2 ÷ 3 ≈ 0.667
```

**交叉熵（Cross-Entropy）**：分類用。只看「正確答案那一類」被模型給了多少機率 p，損失 = −ln(p)。ln 是自然對數，計算機上的 ln 鍵；你只要記住這張表的感覺：

| 模型給正確答案的機率 p | 損失 −ln(p) | 感覺 |
|---|---|---|
| 0.99 | 0.01 | 幾乎沒錯 |
| 0.8 | 0.22 | 小錯 |
| 0.5 | 0.69 | 一半一半 |
| 0.1 | 2.30 | 大錯 |
| 0.01 | 4.61 | 超級錯 |

機率越接近 1 損失越接近 0；機率越接近 0 損失衝到很大。「很有信心地答錯」會被罰得特別重，這正是我們要的。

**訓練時的平均損失**：一批資料各算一個損失，取平均；第 8 章和第 14 章程式裡印出來的「損失」就是這個數字，看它有沒有一直下降。

## A.7　常用符號

| 符號 | 讀法 | 意思 |
|---|---|---|
| Σ | sigma | 全部加起來，Σ xᵢ 就是 x₁ + x₂ + … |
| √ | 根號 | 開平方 |
| ‖v‖ 或 \|v\| | 長度 | 向量的長度 |
| a · b | 內積 | 對應相乘再相加 |
| A @ B | 矩陣乘 | numpy 的矩陣乘法寫法 |
| η | eta | 學習率 |
| e | 自然常數 | ≈ 2.718，sigmoid 與 softmax 用到 |
| ln | 自然對數 | 交叉熵用到，計算機的 ln 鍵 |
| ≈ | 約等於 | 四捨五入後的值 |
| argmax | 最大值的位置 | 機率最大的那個類別是第幾個 |
