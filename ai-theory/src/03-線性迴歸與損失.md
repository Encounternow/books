# 第 3 章　線性迴歸與損失

## 本章目標

學完這一章，你會：

- 用一條直線「身高 ≈ a × 腳長 + b」做預測，並說出斜率 a 和截距 b 各代表什麼。
- 定義損失函數，親手算出一條直線在幾個人身上「錯多少」。
- 說出為什麼損失要用「平方」而不是直接相加，以及損失隨參數變化會畫出一個碗形。
- 用最小平方法的公式，一次算出最佳直線。
- 用一句話把前三章串起來：訓練就是「調參數讓損失最小」。

## 開場：鞋印能說出身高嗎

偵探小說裡常有這種橋段：地上留了一個鞋印，偵探量一量說「嫌犯身高大約一百七」。這不是魔法，是**從一個數字猜另一個數字**：腳越長的人通常越高。

小安想用班上的資料試試看。她把 20 位同學的腳長和身高畫成散布圖，點大致排成一條往右上走的帶子。她拿尺比了一條線，說：「新同學腳長 24.8 公分，照這條線看大約 160。」

阿哲問：「你那條線是用眼睛畫的，我畫的跟你不一樣，誰的對？」

小安答不出來。「對」是什麼意思？如果能把一條線「錯多少」算成一個數字，就能比較兩條線，甚至找出所有直線裡錯最少的那一條。這一章就是在做這件事。做完你會發現，它和第 1 章「猜一個數」、和後面訓練神經網路，是同一件事。

## 核心概念

### 用直線預測：斜率與截距

第 1 章的模型二把腳長分成兩組，各猜一個平均，誤差 3.2 公分。它的問題是太粗：腳長 23.9 和 24.0 的人被分到不同組，預測差 10 公分；腳長 24.0 和 26.5 的人卻猜一樣。

更合理的想法：腳長每多 1 公分，身高就多一點，而且多的量固定。這就是一條直線：

```
預測身高 = a × 腳長 + b
```

a 叫**斜率（Slope）**，意思是「腳長每多 1 公分，身高多幾公分」。b 叫**截距（Intercept）**，是直線在腳長 = 0 時的高度——沒有人腳長是 0，所以 b 本身沒有意義，它只是用來把整條線上下搬到對的位置。a 和 b 就是這個模型的兩個**參數**。

用一條直線去配合資料做預測，叫**線性迴歸（Linear Regression）**。《從資料看世界》第 11 章教過怎麼在試算表裡按一個鍵畫出迴歸線；這一章要講的是那個鍵背後在算什麼。

先隨便試一條：a = 6.5、b = 0，也就是「身高 ≈ 6.5 × 腳長」。對小安（腳長 23.0）預測 149.5，實際 152，差 2.5；對阿宏（26.5）預測 172.25，實際 170，差 −2.25。有的猜低、有的猜高。這條線好不好？要先有一把尺。

### 損失函數：把「錯多少」變成一個數字

每個人的**誤差（Error）**定義成「實際值 − 預測值」。要把 20 個誤差合併成一個數字，第一個想法是直接加起來，但正負會互相抵消：猜高 5 公分和猜低 5 公分加起來是 0，看起來完美，其實兩個都錯了。

第 1 章用的是取絕對值再平均。這一章改用另一種：**每個誤差先平方，再加總**。

```
損失 = (誤差₁)² + (誤差₂)² + … + (誤差₂₀)²
     = (y₁ − 預測₁)² + (y₂ − 預測₂)² + … + (y₂₀ − 預測₂₀)²
```

這個數字叫**損失（Loss）**，算出它的規則叫**損失函數（Loss Function）**。「函數」的意思是：你給它一組參數 (a, b)，它就還你一個數字——這條線錯多少。損失越小，線越好。這種「平方加總」的損失有個專門名字叫**平方和誤差（Sum of Squared Errors）**。

為什麼用平方，不用絕對值？兩個理由：

1. **大錯罰更重。**錯 2 公分平方是 4，錯 6 公分平方是 36，是 9 倍而不是 3 倍。平方損失很討厭「某一個人錯很多」，會逼直線盡量照顧每個人。
2. **數學上好算。**平方加總的損失會畫出一個光滑的碗形，碗底可以用公式直接算出來（本章後面），也可以用「往下坡走」找到（第 5 章）。絕對值的損失有尖角，不好處理。

### 用 5 個人算一次損失

20 個人手算太累，先挑 5 位腳長從小到大的同學：

| 暱稱 | 腳長 x | 身高 y |
|---|---|---|
| 小美 | 22.0 | 150 |
| 小安 | 23.0 | 152 |
| 阿哲 | 24.0 | 158 |
| 阿豪 | 25.0 | 161 |
| 阿宏 | 26.5 | 170 |

為了讓參數只有一個，先用最簡單的直線 `身高 = k × 腳長`（b 固定為 0）。試 k = 6.5：

| 暱稱 | x | y | 預測 6.5x | 誤差 y − 預測 | 誤差² |
|---|---|---|---|---|---|
| 小美 | 22.0 | 150 | 143.0 | 7.0 | 49.00 |
| 小安 | 23.0 | 152 | 149.5 | 2.5 | 6.25 |
| 阿哲 | 24.0 | 158 | 156.0 | 2.0 | 4.00 |
| 阿豪 | 25.0 | 161 | 162.5 | −1.5 | 2.25 |
| 阿宏 | 26.5 | 170 | 172.25 | −2.25 | 5.06 |
| | | | | **損失** | **66.56** |

換 k = 6.6 再算一次，損失是 63.25。再換幾個 k：

| k | 損失（5 人） |
|---|---|
| 6.0 | 958.00 |
| 6.2 | 426.45 |
| 6.4 | 128.20 |
| 6.5 | 66.56 |
| 6.6 | 63.25 |
| 6.8 | 231.60 |

把損失畫出來：

```
k      損失
6.0    ████████████████████████████████████████ 958
6.2    ██████████████████ 426
6.4    █████ 128
6.5    ███ 67
6.6    ███ 63
6.8    ██████████ 232
```

這就是**損失曲線**：橫軸是參數，縱軸是損失，形狀像一個碗。碗底在 6.5 和 6.6 之間，那裡的 k 就是「只用一個參數時」最好的斜率。**訓練，就是在這個碗裡找最低點。**第 1 章活動 1-2 你改 E2 的猜測值、看平均誤差變化，其實也是在碗裡摸索；第 5 章會教電腦自己走到碗底。

### 兩個參數：碗變成山谷

直線有 a 和 b 兩個參數，損失函數就變成「給 (a, b) 一對數字，還你一個損失」。畫出來不是一條曲線，是一個三維的碗（像一個山谷），a 和 b 是地面上的兩個方向，損失是高度。找最佳直線 = 找山谷最低點。

兩個參數會互相影響。剛才 b 固定 0 時最好的斜率是 6.5 左右；但如果允許 b 不是 0，最好的斜率會完全不同——因為截距可以把線整個往上抬，斜率就不需要那麼陡。等一下你會看到，20 人的最佳直線斜率只有 4.6，截距卻是 46.55。「身高 ≈ 6.5 × 腳長」和「身高 ≈ 4.6 × 腳長 + 46.55」在腳長 22 到 27 這段範圍裡其實很接近，但後者損失小很多。

### 最小平方法：一次算出碗底

碗底可以一步算出來，這個方法叫**最小平方法（Least Squares）**，兩百年前就有了。公式長這樣（x̄ 是 x 的平均，ȳ 是 y 的平均）：

```
a = Σ (x − x̄)(y − ȳ) ÷ Σ (x − x̄)²
b = ȳ − a × x̄
```

Σ 念「sigma」，意思是「把每個人的這一項算出來，全部加起來」。分子是「x 偏離平均多少」乘上「y 偏離平均多少」的加總；分母是「x 偏離平均多少」的平方加總。白話版：**x 和 y 一起偏的程度，除以 x 自己偏的程度，就是斜率。**（讀過《從資料看世界》第 10 章的人會認出來：分子跟相關係數的分子是同一個東西。）

用 5 人的小資料算一遍。x̄ = (22 + 23 + 24 + 25 + 26.5) ÷ 5 = 24.1，ȳ = (150 + 152 + 158 + 161 + 170) ÷ 5 = 158.2。

| 暱稱 | x − x̄ | y − ȳ | (x − x̄)(y − ȳ) | (x − x̄)² |
|---|---|---|---|---|
| 小美 | −2.1 | −8.2 | 17.22 | 4.41 |
| 小安 | −1.1 | −6.2 | 6.82 | 1.21 |
| 阿哲 | −0.1 | −0.2 | 0.02 | 0.01 |
| 阿豪 | 0.9 | 2.8 | 2.52 | 0.81 |
| 阿宏 | 2.4 | 11.8 | 28.32 | 5.76 |
| **加總** | | | **54.90** | **12.20** |

```
a = 54.90 ÷ 12.20 = 4.5
b = 158.2 − 4.5 × 24.1 = 158.2 − 108.45 = 49.75
```

5 人的最佳直線是 `身高 ≈ 4.5 × 腳長 + 49.75`，損失只有 5.75——比剛才「只調 k」最好的 63 小了十倍。多一個參數，碗底低很多。

對 20 人做一樣的事（「用工具看看」會讓電腦算），得到：

```
身高 ≈ 4.60 × 腳長 + 46.55     損失 = 86.0
```

20 人平均每人只差 1.66 公分，比第 1 章的分組模型（3.2 公分）好一倍。

這個公式為什麼對？完整推導要用微分，本書不做。但你可以說服自己：隨便挑別的 (a, b) 算損失，永遠比它大。「用工具看看」裡試了四條線，損失是 212、301、165、122，沒有一條贏過 86。

### 預測，以及預測的邊界

有了直線就能預測。新同學腳長 24.8：`4.60 × 24.8 + 46.55 ≈ 160.7` 公分。

但要記得第 1 章的教訓：**模型只在例子涵蓋的範圍裡可靠。**班上腳長從 22 到 26.5，你問它腳長 30 公分的人多高，它會算出 184.6，但班上沒有任何一個人腳長接近 30，這個數字只是把直線硬延長出去，叫**外推（Extrapolation）**。問腳長 10 公分的嬰兒，它會答 92.6 公分，顯然錯了——嬰兒的身高和腳長關係根本不是這條線。

另外，平均差 1.66 公分不代表每個人都差不到 2 公分。小恩腳長 24.5，直線預測 159.3，她實際 154，差了 5.3。直線抓的是整體趨勢，個別的人永遠會有偏差。

### 三章串起來：訓練就是調參數讓損失最小

回頭看這三章做了什麼：

| 章 | 模型 | 參數 | 錯多少怎麼算 | 怎麼找最好的參數 |
|---|---|---|---|---|
| 1 | 一律猜一個數 | 1 個 | 平均絕對誤差 | 算平均 |
| 2 | 最近鄰、決策樹 | 記住資料；樹的問題 | 答錯幾個 | 一層一層挑最純的問題 |
| 3 | 直線 | a、b 共 2 個 | 平方和損失 | 最小平方公式 |
| 5 | 直線 | 2 個 | 平方和損失 | 往碗底走（梯度下降） |
| 7 | 神經網路 | 幾百到幾百萬個 | 平方和或其他損失 | 往碗底走 |

每一列都是同一個句型：**選一個模型 → 定義損失 → 調參數讓損失最小。**從第 5 章起，「調參數」從「套公式」換成「往碗底一步一步走」，因為神經網路的碗沒有公式能直接算出底在哪。但「碗」的概念，你已經在本章親手畫出來了。

## 用工具看看

打開 Google Colab，新增筆記本，貼上整段程式：

```python
import numpy as np

# x 是腳長（公分），y 是身高（公分），20 位同學，順序同第 1 章資料表
x = np.array([23.0,25.5,22.5,24.0,23.5,26.5,22.0,25.0,24.0,24.5,
              23.0,26.0,22.5,25.5,24.5,24.0,23.5,26.0,23.0,25.0])
y = np.array([152,165,148,158,158,170,150,165,156,160,
              153,167,149,163,154,159,154,163,151,161])

# 定義損失函數：給一組 (a, b)，算 20 個誤差的平方和
def loss(a, b):
    pred = a * x + b                # 用直線 y = a·x + b 預測每個人的身高
    return ((y - pred) ** 2).sum()  # 誤差平方加總

# 先試幾條「用猜的」直線，看損失
for a, b in [(6.5, 0), (6.0, 10), (5.0, 35), (4.0, 60)]:
    print(f"a={a}, b={b}：損失 = {loss(a, b):.1f}")

# 用最小平方公式一次算出最佳直線
x_mean, y_mean = x.mean(), y.mean()
a_best = ((x - x_mean) * (y - y_mean)).sum() / ((x - x_mean) ** 2).sum()
b_best = y_mean - a_best * x_mean
print(f"最佳直線：身高 ≈ {a_best:.2f} × 腳長 + {b_best:.2f}")
print(f"最佳直線的損失 = {loss(a_best, b_best):.1f}")

# 用 numpy 內建的 polyfit 驗算（1 代表一次式，也就是直線）
print("polyfit 算出的 a, b：", np.polyfit(x, y, 1).round(2))
# 用最佳直線預測腳長 24.8 公分的新同學
print("腳長 24.8 的預測身高：", round(a_best * 24.8 + b_best, 1))
```

**你應該看到**：

```
a=6.5, b=0：損失 = 212.3
a=6.0, b=10：損失 = 301.0
a=5.0, b=35：損失 = 165.2
a=4.0, b=60：損失 = 122.0
最佳直線：身高 ≈ 4.60 × 腳長 + 46.55
最佳直線的損失 = 86.0
polyfit 算出的 a, b： [ 4.6  46.55]
腳長 24.8 的預測身高： 160.7
```

幾個說明：`def loss(a, b):` 定義了一個函數，之後寫 `loss(6.5, 0)` 就會回傳那條線的損失，跟數學上「損失函數」的意思一樣。`((x - x_mean) * (y - y_mean)).sum()` 就是 Σ(x − x̄)(y − ȳ)，numpy 會對 20 個人各算一次再加總。`np.polyfit(x, y, 1)` 是 numpy 內建的最小平方法，拿來驗算你的公式沒寫錯。

試著改一改：在 `for` 那行的清單裡加上 `(4.6, 46.55)`，確認它的損失剛好是 86.0。把 `24.8` 改成 `30`，看外推會給你什麼數字。把 y 裡小恩的 154 改成 164（假裝資料輸入錯誤），再跑一次，看最佳直線被一個錯誤的點拉動多少——這就是「平方損失很在意大錯」的代價。

## 常見錯誤與迷思

- **「把誤差直接加起來就是損失。」** → 正負會抵消，猜高 5 和猜低 5 加起來是 0。→ 正確理解：要先平方（或取絕對值）再加。
- **「損失是 86，所以平均每人錯 86 公分。」** → 86 是 20 個誤差的平方加總，單位是「公分的平方」。→ 正確理解：要看平均每人差幾公分，另外算絕對誤差的平均（這裡是 1.66）；損失是拿來比較、拿來調參數的，不是拿來直接解讀的。
- **「截距 46.55 代表腳長 0 的人身高 46.55。」** → 腳長 0 沒有人，那是外推。→ 正確理解：截距只是把線搬到對的高度，常常沒有實際意義。
- **「斜率 6.5 的線和 4.6 的線差很多，一定有一個是錯的。」** → 一個 b = 0，一個 b = 46.55，在腳長 22–27 的範圍裡兩條線很接近。→ 正確理解：兩個參數會互相補償，要一起看。
- **「最佳直線對每個人都很準。」** → 小恩差 5.3 公分。→ 正確理解：直線抓整體趨勢，個別偏差一定存在；平均誤差小不代表沒有離群的人。
- **「資料看起來是直線，就一定可以用直線外推。」** → 嬰兒的腳長身高關係不在這條線上。→ 正確理解：模型只在訓練資料的範圍裡可靠。

## 想一想

1. 一條直線對 3 個人的誤差是 +3、−1、−2。損失（平方和）是多少？如果直接相加會得到多少，為什麼那個數字會誤導人？

<details><summary>參考答案</summary>

損失 = 9 + 1 + 4 = 14。直接相加是 0，會讓人以為這條線完美，其實三個人都猜錯了。

</details>

2. 用 5 人小資料的最佳直線 `身高 ≈ 4.5 × 腳長 + 49.75`，預測小葳（腳長 24.0，實際 156）。誤差是多少？

<details><summary>參考答案</summary>

預測 = 4.5 × 24 + 49.75 = 108 + 49.75 = 157.75，誤差 = 156 − 157.75 = −1.75，猜高了 1.75 公分。

</details>

3. 在活動 3-1 的損失表裡，k 從 6.0 到 6.2 損失降了五百多，從 6.5 到 6.6 只差 3。用「碗」的形狀說明為什麼。

<details><summary>參考答案</summary>

損失曲線是碗形，碗邊很陡、碗底很平。6.0 在碗邊，動一點損失就掉很多；6.5 和 6.6 都在碗底附近，坡幾乎是平的，動一點損失幾乎不變。這也表示碗底附近「差不多好」的參數有一整段，不是只有一個點。

</details>

4. 如果把身高單位從公分改成公尺（152 變 1.52），最佳直線的 a 和 b 會變成多少？損失會變成多少？這告訴你什麼？

<details><summary>參考答案</summary>

y 全部除以 100，所以 a 變成 0.046、b 變成 0.4655，預測值也全部除以 100。每個誤差變成原來的 1/100，平方後變 1/10000，損失變成 0.0086。損失的大小跟單位有關，所以**損失只能在同一組資料、同樣單位下互相比較**，不能跨資料說「86 比 0.0086 差」。

</details>

5. 假設把小恩的身高誤打成 194（多了 40 公分）。你預期最佳直線會怎麼動？損失會大約變多少？先猜，再用 Colab 程式改數字驗證。

<details><summary>參考答案</summary>

小恩腳長 24.5 在中間偏右，直線會被她往上拉：實際跑出來最佳直線變成 5.00 × 腳長 + 38.9，斜率和截距都動了。更明顯的是損失暴增到約 1177，是原本 86 的 13 倍多，而且幾乎全來自她一個人（誤差三十幾公分，平方就上千）。這就是平方損失對離群值敏感的代價：一筆錯誤資料可以主宰整個模型。實務上訓練前一定要先檢查資料有沒有打錯。

</details>

6. 開放挑戰：本章只用腳長一個特徵。如果想同時用「腳長」和「每週運動天數」預測身高，直線會變成什麼樣子？參數有幾個？你覺得運動天數會幫上忙嗎？用活動 3-2 的試算表試試看（提示：多加一個參數 c，預測 = a × 腳長 + c × 運動天數 + b）。

<details><summary>參考答案</summary>

模型變成 `身高 ≈ a × 腳長 + c × 運動天數 + b`，參數三個，幾何上是三維空間裡的一個平面而不是直線。試算表裡多一欄運動天數、多一個參數格就能手調。這組資料手調（或用程式算）會得到 a ≈ 4.27、c ≈ 0.39、b ≈ 53.3，損失從 86 降到約 79：運動天數只幫了一點點忙。多一個特徵不一定讓模型好很多，卻一定多一個可以亂調的參數，20 筆資料養三個參數，過度擬合的風險也跟著上升。第 4 章會用向量與矩陣把「很多特徵」寫成一行式子。

</details>

## 本章小結

- 直線模型：預測 = a × 腳長 + b。a 是斜率（腳長每多 1 公分身高多幾公分），b 是截距（把線搬到對的高度），兩者是參數。
- 誤差 = 實際 − 預測。損失 = 所有誤差的平方加總。用平方是為了不讓正負抵消、讓大錯罰更重，並且讓損失曲線是光滑的碗形。
- 損失函數：給一組參數，還你一個「錯多少」。畫出來一個參數是碗、兩個參數是山谷，訓練就是找最低點。
- 最小平方法：a = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)²，b = ȳ − a × x̄，一步算出碗底。
- 20 位同學的最佳直線是 身高 ≈ 4.60 × 腳長 + 46.55，損失 86.0，平均每人差 1.66 公分。
- 碗底附近坡很平，碗邊很陡；兩個參數會互相補償，要一起看。
- 直線只在訓練資料的範圍內可靠；外推、離群值、資料打錯都會讓它失準。
- 前三章的共同句型：選模型 → 定義損失 → 調參數讓損失最小。第 5 章起改用「往碗底走」來調。
