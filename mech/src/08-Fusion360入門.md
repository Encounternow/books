# 第 8 章　Fusion 360 入門

## 本章目標
- 學完你會說出 Fusion 360 是什麼樣的軟體、為什麼本書選它，並且自己申請到個人免費版，把它裝好、把建模方向設成 Z 向上。
- 學完你會認得介面的四個區域——瀏覽器、工具列、時間軸、視角方塊——並用滑鼠自在地旋轉、平移、縮放視角。
- 學完你會走完「選平面 → 畫草圖 → 給尺寸 → 拉伸」這條最基本的建模路線，做出有準確尺寸的實體。
- 學完你會用合併、切除、相交把形狀加減起來，用倒角、圓角、抽殼修飾它，並用文字工具在零件上寫字。
- 學完你會把設計匯出成 3MF 或 STL，送進 Bambu Studio 準備列印。

## 開場：想要一個「剛好」的東西

小翔的書桌上放著一個從文具店買來的手機架，可是它的角度太躺，看影片時脖子得一直往前伸；他試過把一本書墊在後面，結果手機從旁邊滑下去。阿姊看了一眼說：「這種東西自己畫一個，印出來就好了。」

「畫？用什麼畫？」

「用 Fusion 360。它就像一個數位的黏土工作檯：你先在一張平面上畫出形狀，再把它『拉』出厚度，就變成一個立體的零件。想挖洞就畫個圓切掉，想圓一點就把邊磨圓。畫完存成檔案，交給印表機，幾小時後你桌上就會多一個世界上獨一無二、角度剛好的手機架。」

小翔心動了，但也有點怕：「這不是工程師才會用的軟體嗎？」

是工程師在用，但入門的那一小段路，其實只需要會畫矩形、畫圓、輸入幾個數字。這一章我們先把這條路走通，做出兩個真的有用的東西：一個刻著你名字的鑰匙圈，和一個角度可以換的手機架。

## 核心概念

### Fusion 360 是什麼

**Fusion 360** 是 Autodesk 公司做的 **CAD（Computer-Aided Design，電腦輔助設計）** 軟體。CAD 和畫圖軟體最大的不同是：畫圖軟體畫的是「看起來像」的圖，CAD 畫的是「尺寸精確」的物體。你說這條邊 60 mm，它就是 60.000 mm；你說這個孔直徑 5 mm，印出來的孔就會依照 5 mm 去走（扣掉第 7 章講的縮水）。

本書選它，有三個原因：

1. **免費**：個人非商業用途有免費版；學生可以申請教育版。
2. **參數式**：每一步都記錄在「時間軸」裡，可以回頭改。尺寸打錯了不用重畫，改一個數字整個模型跟著變（第 9 章會細講）。
3. **做得到裝配**：零件可以互相接合，在電腦裡先讓齒輪轉起來、讓鉸鏈開合，再去列印。

它只有 Windows 和 Mac 版，手機、平板、Chromebook 都不能裝。檔案存在雲端（Autodesk 的伺服器），所以第一次登入和存檔都需要網路。

### 怎麼取得個人免費版

1. 到 Autodesk 官網搜尋「Fusion 個人使用（Fusion for personal use）」。
2. 建立一個 Autodesk 帳號（需要 email；未滿 13 歲請用家長的 email 申請，並由家長陪同）。
3. 申請個人使用授權，下載安裝程式，安裝後用同一個帳號登入。
4. 個人版的授權是**一年一次**，到期前會提醒你免費續約。
5. 個人版有些限制：不能商業使用、同時能編輯的設計檔數量有上限（通常是 10 個，把舊的「封存」就能騰出位置）、某些進階功能關閉。本書用到的功能全部都在免費版裡。

如果你有學校的 email，可以改申請**教育版（Education）**，功能完整，但要上傳學生證或在學證明做驗證。兩種版本的操作方式完全一樣。

安裝好第一件事：把建模方向設成 **Z 向上**。打開「偏好設定」，在「一般」裡找到「預設建模方向」，改成「Z 向上」。這樣 XY 平面就是地板、Z 就是高度，和 Bambu Studio 的列印板方向一致，之後匯出不會躺倒。改完之後**新建的設計**才會生效。

### 介面：四個區域

```
 ┌─────────────────────────────────────────────────────────────┐
 │ 工具列：  實體 │ 曲面 │ 網格 │ 鈑金 │ 公用程式                  │
 │          建立 ▾   修改 ▾   組合 ▾   構造 ▾   檢查 ▾   插入 ▾    │
 ├───────────┬─────────────────────────────────────────────────┤
 │ 瀏覽器    │                                                 │
 │ ▸ 文件設定 │                                       ┌─────┐   │
 │ ▸ 原點    │               畫布（3D 視圖）           │ 上  │   │
 │ ▸ 本體    │                                       │前 右│   │
 │ ▸ 草圖    │                      Z                 └─────┘   │
 │           │                      │  Y                 視角方塊 │
 │           │                      └──X                        │
 ├───────────┴─────────────────────────────────────────────────┤
 │ 時間軸： ◄ ◄ ▶ ▶  [草圖1][拉伸1][草圖2][切除1][圓角1] ─────●   │
 └─────────────────────────────────────────────────────────────┘
```

- **工具列（Toolbar）**：上面一排分頁（實體、曲面、網格……），本書幾乎只用「實體」分頁；分頁下面是「建立」「修改」「組合」「構造」「檢查」這幾組下拉功能表。本書描述操作時會寫成「建立 → 拉伸」「修改 → 圓角」這種形式，意思是在「建立」那組功能表裡找「拉伸」。
- **瀏覽器（Browser）**：左邊的樹狀清單，列出這個設計裡的所有東西：文件設定（單位在這裡改）、原點（XYZ 三個平面）、本體、草圖、元件。點旁邊的眼睛可以隱藏或顯示。
- **時間軸（Timeline）**：畫面最下面一排小方塊，每做一個動作就多一格。它是 Fusion 360 的靈魂：雙擊任何一格就能回去改那一步，後面的步驟會自動重算。
- **視角方塊（ViewCube）**：右上角的小立方體。點它的「上」就從正上方看，點「前」就從正前方看，拖它就旋轉視角；點旁邊的小房子回到預設的斜視角。

工具找不到時，按鍵盤的 `S` 會跳出「快捷工具搜尋」，打工具名字的前兩個字就找得到。附錄 C 有完整的快捷鍵表。

### 滑鼠：轉、移、縮

| 想做什麼 | 怎麼做 |
|---|---|
| 旋轉視角 | 按住 Shift + 滑鼠中鍵拖曳；或直接拖曳視角方塊 |
| 平移（畫面整個搬動） | 按住滑鼠中鍵拖曳 |
| 縮放 | 滾動滾輪（往滑鼠指的地方放大） |
| 整個模型放到畫面中間 | 連按兩下滑鼠中鍵，或按 `F6` |
| 正對著某個面看 | 對那個面按右鍵 → 「以此面檢視」 |

沒有中鍵的筆電，可以在偏好設定裡把滑鼠操作改成「觸控板」模式，或用畫布下方那一排導覽圖示（手掌＝平移、放大鏡＝縮放、軌道＝旋轉）。**建議初學者花 300 元買一支有中鍵滾輪的滑鼠**，建模速度會快一倍。

### XYZ 與工作平面

3D 空間用三條軸描述：**X** 往右、**Y** 往後、**Z** 往上（設成 Z 向上之後）。三條軸兩兩組成三個平面：

```
          Z
          │   YZ 平面（側面，像一面牆）
          │  ╱
          │ ╱
          │╱________ Y
         ╱│
        ╱ │  XY 平面（地板，列印板就是它）
       X  │
       XZ 平面（正面，像另一面牆）
```

- **XY 平面**：地板。本書 90% 的草圖都畫在這裡，因為畫在地板上再往上拉伸，零件的底面就是平的，印表機最喜歡。
- **XZ、YZ 平面**：兩面牆。畫側面輪廓時用（例如第 9 章旋轉出圓柱的半邊輪廓）。
- **實體的任何平面**：零件做出來之後，它的每個平面都可以當新的草圖平面。「在盒子頂面上畫個圓再切下去」就是這樣做的。

三個平面都從**原點（Origin）** 出發。畫第一個草圖時，把形狀的一角或中心放在原點上，之後對齊、鏡射、量測都會方便很多。

### 從草圖到實體：拉伸

Fusion 360 做零件的基本套路只有四步：

```
  ① 選平面        ② 畫草圖         ③ 給尺寸          ④ 拉伸
                   ┌──────┐        ┌──60──┐          ╱──────╱│
   ┌──────┐        │      │        │      │25       ╱──────╱ │ 3
   │  XY  │   →    │      │   →    │      │    →   │      │  │
   └──────┘        └──────┘        └──────┘        │      │ ╱
                   藍線（還沒定）     黑線（定了）      └──────┘
```

1. **建立草圖**：按「建立 → 建立草圖」，點 XY 平面。畫面會自動轉成正對這個平面，工具列切換成草圖工具，右邊出現「草圖面板」。
2. **畫形狀**：用「建立 → 矩形 → 兩點矩形」（快捷鍵 `R`）從原點拉出一個矩形；用「中心圓」（`C`）點一下圓心再拉出圓。這時候不用畫得準，大概就好。
3. **給尺寸**：按「草圖尺寸」（`D`），點一條邊，拉出來，輸入數字，按 Enter。或者畫矩形時直接打數字：拉矩形時輸入 `60`，按 `Tab` 跳到下一個欄位，輸入 `25`，按 Enter。線條從藍色變成黑色，表示這條線「被定住了」。
4. **完成草圖**，然後「建立 → 拉伸」（`E`）：點草圖裡要拉的那塊封閉區域（會變成淡藍色），輸入高度 `3`，Enter。一塊 60 × 25 × 3 mm 的板子就出現了。

拉伸對話框裡最重要的三個欄位：

| 欄位 | 意思 | 常用值 |
|---|---|---|
| 距離 | 拉多高；負數就是往反方向 | `3`、`-5` |
| 方向 | 單側、雙側（往兩邊各拉一半）、對稱 | 單側 |
| 操作 | 新本體／接合／切除／相交 | 第一塊用新本體，之後看情況 |

### 尺寸輸入的小技巧

- **單位是 mm**。Fusion 360 的新設計預設就是公釐，在瀏覽器的「文件設定 → 單位」可以確認。輸入 `60` 就是 60 mm，不用打單位。
- **可以打算式**：輸入 `60/2` 會得到 30，`25-2*1.6` 會得到 21.8。要讓一個孔在板子正中間，就輸入「板長/2」。
- **小數點用 `.`**：`2.5` 不是 `2,5`。
- **尺寸可以改**：雙擊草圖上的任何一個尺寸數字，輸入新的，整個形狀跟著變。這就是「參數式」的第一個甜頭。

### 加、減、交：合併

兩個實體碰在一起時，有三種處理方法。它們在「修改 → 合併」裡，也出現在拉伸對話框的「操作」欄位：

```
   A ┌─────┐          接合（Join）       切除（Cut）        相交（Intersect）
     │  ┌──┼──┐       ┌─────┐           ┌──┐              ┌──┐
     │  │  │  │ B  →  │     └──┐   或   │  │        或     │  │
     └──┼──┘  │       │        │        │  │              └──┘
        └─────┘       └────────┘        └──┘           只留重疊的部分
                     A + B 黏成一塊    A 挖掉 B 的形狀
```

- **接合（Join）**：把新形狀加到舊的本體上，變成一塊。鑰匙圈上的凸起文字就是「接合」。
- **切除（Cut）**：用新形狀當刀，把舊本體挖掉。鑰匙圈的穿孔、手機架的插槽都是「切除」。
- **相交（Intersect）**：只留下兩個形狀重疊的部分，其他都丟掉。做複雜曲面才會用，本書很少碰。
- **新本體（New Body）**：不加不減，獨立成一塊。要印成兩個分開的零件時用。

### 修飾：倒角、圓角、抽殼

```
   原來的邊      圓角（Fillet）      倒角（Chamfer）      抽殼（Shell）
   ┌──────┐      ╭──────╮          ╱──────╲          ┌──────┐
   │      │      │      │          │      │          │┌────┐│
   │      │      │      │          │      │          ││    ││ ← 牆厚 1.6
   └──────┘      ╰──────╯          ╲──────╱          │└────┘│
                 邊變成圓弧         邊切成 45° 斜面     實心變成空心盒
```

- **圓角（Fillet）**：「修改 → 圓角」（`F`），點要變圓的邊，輸入半徑。手摸的邊、容易撞到的角都該圓角；零件底部的四個角圓一點，印的時候比較不會翹邊。
- **倒角（Chamfer）**：「修改 → 倒角」，點邊，輸入距離，邊會變成 45° 的斜面。零件底邊倒 0.5 mm，第一層被壓扁多出來的那一圈就不會凸出來，也更好從列印板拿起來（第 10 章會解釋）。
- **抽殼（Shell）**：「修改 → 抽殼」，點要「打開」的面（例如盒子的頂面），輸入牆厚，實心塊就變成空心盒。做盒子千萬不要一片一片牆去畫，先做實心再抽殼，三秒鐘搞定。

### 在零件上寫字

「草圖 → 建立 → 文字」：在草圖裡點一下放置點，輸入文字、高度、字型。文字會變成草圖的一部分，可以像矩形一樣被拉伸。拉伸正值（例如 1 mm，接合）是凸字，負值（例如 −0.6 mm，切除）是凹字。

列印文字的幾個經驗數字：

| 項目 | 建議 | 為什麼 |
|---|---|---|
| 字高 | 至少 6–8 mm | 太小筆畫會糊成一團 |
| 筆畫粗細 | 至少 0.8 mm（約兩條噴嘴線） | 選粗體或黑體 |
| 凸起高度 | 0.6–1.0 mm | 太高容易被碰斷，太低看不出來 |
| 中文字型 | Windows 用「微軟正黑體」、Mac 用「蘋方」 | 有些英文字型沒有中文字，會顯示空白 |

### 匯出：交給 Bambu Studio

設計畫好了，要變成印表機看得懂的檔案：

1. 在瀏覽器最上面的設計名稱上按右鍵 → 「匯出」，或用「檔案 → 匯出」。
2. 格式選 **3MF**（推薦）或 **STL**。一個設計裡有好幾個本體時，3MF 會把它們當成不同零件帶過去，在 Bambu Studio 裡可以分開擺。
3. 「細化」選「高」，曲面才會圓；單位確認是 mm。
4. 存到你找得到的資料夾。然後打開 Bambu Studio，把檔案拖進去（第 11 章）。

也可以在某一個本體上按右鍵 → 「另存為網格」，只匯出那一個本體。如果電腦裡裝了 Bambu Studio，匯出對話框裡可能會直接出現「送到列印公用程式」的選項，勾了會自動打開 Bambu Studio。

設計本身請用 `Ctrl/Cmd + S` 存成 F3D（雲端自動保存）。STL 和 3MF 是「印出來的樣子」，不能回頭改尺寸；F3D 才是「可以改」的原稿。附錄 C 比較了四種格式。

## 動手做

### 活動 8-1：名牌鑰匙圈

**材料／工具**
- 電腦與 Fusion 360（已設成 Z 向上）
- 一個鑰匙圈（量一下圈的線徑，通常 1.5–2 mm）
- 尺或游標卡尺

**步驟**
1. 「檔案 → 新建設計」。在瀏覽器確認「文件設定 → 單位」是 mm。
2. 「建立 → 建立草圖」，點 XY 平面。
3. 按 `R` 兩點矩形，第一點點在原點，拉出去時輸入 `60`、`Tab`、`25`、Enter。這就是鑰匙圈的底板：60 mm 長、25 mm 寬。
4. 按 `C` 中心圓，圓心大約放在左邊，拉出來後輸入直徑 `5`，Enter。
5. 按 `D` 草圖尺寸，把圓心定位：點圓心再點左邊那條邊，輸入 `6`；點圓心再點下面那條邊，輸入 `12.5`。圓心現在在距左邊 6 mm、上下正中間的位置。孔邊到板邊剩 6 − 2.5 = 3.5 mm，夠結實。
6. 「完成草圖」。
7. 「建立 → 拉伸」，點矩形**不含圓孔**的那塊區域（圓裡面不要點到），距離 `3`，操作「新本體」，確定。你會得到一塊已經有孔的板子。
8. 「修改 → 圓角」，點板子的四條直立邊（轉動視角才點得到），半徑 `5`，確定。四個角變圓。
9. 在板子的**頂面**上「建立草圖」（點頂面當草圖平面）。「建立 → 文字」，在孔的右邊點一下，輸入你的名字（英文或中文都可以），高度 `10`，字型選有中文的黑體，勾選粗體，確定。用「移動」把文字拖到孔右邊、上下置中的位置（文字左邊離孔邊至少 3 mm）。
10. 「完成草圖」。「建立 → 拉伸」，點文字（每個字都要點到，或框選整組文字），距離 `1`，操作「接合」，確定。文字凸起 1 mm。
11. 檢查：轉動視角從側面看，文字是凸的；從底面看，底面是平的。
12. 匯出 3MF：設計名稱右鍵 → 匯出 → 3MF → 細化高 → 存檔。`Ctrl/Cmd + S` 把設計存起來，取名「鑰匙圈」。

**你應該看到／得到**
- 一塊 60 × 25 × 3 mm、四角圓滑、左邊有 Ø 5 mm 孔、右邊有凸字的板子。
- 時間軸上有五到六格：草圖、拉伸、圓角、草圖、拉伸。
- 拖進 Bambu Studio 之後，用 0.20mm Standard 切片，大約 5 g、20–30 分鐘。

| 寬 (mm) | 25 | | |

### 活動 8-2：可調角度手機架

這個手機架有兩個零件：一塊**底座**，上面有三條插槽和一道擋住手機的前唇；一片**背板**，插進不同的槽，手機靠上去的角度就不一樣。

```
   側視（從右邊看）                             俯視
                                           ┌──────────────┐ 90
      手機                                 │ ═══ 槽 3 (65)│
       ╲                                   │              │
        ╲   ┌┐ 背板（80 高）                │ ═══ 槽 2 (50)│
         ╲  ││                             │              │
          ╲ ││                             │ ═══ 槽 1 (35)│
   前唇 ┌┐  ╲││                            │              │
   10 高│├───┴┴─────┐ 底座 6 厚             │▓▓▓▓▓  ▓▓▓▓▓▓│ ← 前唇，中間缺口 12
        └──────────┘                       └──────────────┘
        ←── 90 ──→                            ←─── 80 ───→
```

**材料／工具**
- 電腦與 Fusion 360
- 你的手機（量一下寬度與厚度，大部分手機寬 70–78 mm、厚 8–10 mm）

**步驟（底座）**
1. 新建設計，在 XY 平面建立草圖。畫兩點矩形，從原點拉出 `80`（X 方向）× `90`（Y 方向）。完成草圖。
2. 拉伸 `6` mm，新本體。這是底座。
3. 在底座**頂面**建立草圖。沿著前面那條邊（Y = 0 的那邊）畫一個矩形：`80` × `6`，貼齊前緣。完成草圖，拉伸 `10` mm，操作「接合」。前唇完成，總高 16 mm。
4. 在**前唇的頂面**建立草圖，畫一個 `12` 寬、`6` 深（和前唇一樣深）的矩形，用尺寸把它定在正中間（左邊離板邊 `34`，因為 (80 − 12) ÷ 2 = 34）。完成草圖，拉伸 `-10`（往下），操作「切除」。這是充電線的缺口。
5. 回到**底座頂面**建立草圖。畫三個橫跨整個寬度的矩形，每個 `80` 長（X 方向）× `3.5` 寬（Y 方向）。用尺寸把它們的前緣定在離前邊 `35`、`50`、`65` mm 的位置。完成草圖，拉伸 `-3`，操作「切除」。三條插槽完成，槽底還剩 6 − 3 = 3 mm 厚。
6. 「修改 → 圓角」，點底座後面兩個直角的直立邊，半徑 `5`。
7. 「修改 → 倒角」，點底座底面外圍的所有邊，距離 `0.5`。

**步驟（背板）**
8. 「組合 → 新元件」，取名「背板」（或直接在同一個設計畫成新本體也可以）。在 XY 平面建立草圖，畫 `70` × `80` 的矩形，離底座遠一點不要重疊。完成草圖，拉伸 `3`，新本體。
9. 圓角背板的兩個頂角（短邊的兩個角），半徑 `5`。
10. 想要的話，在背板的一面用文字工具寫上名字，拉伸 `0.8` 接合。

**步驟（檢查與匯出）**
11. 用「檢查 → 量測」點插槽的兩個側壁，應該讀到 3.5 mm；背板厚 3 mm，插進去有 0.5 mm 的餘裕——第 7 章講過，印出來槽會縮 0.2–0.4 mm，所以留 0.5 剛好。
12. 匯出 3MF（兩個零件會一起帶進 Bambu Studio）。在 Bambu Studio 裡底座平放、背板平躺，0.20mm Standard，壁數 3，填充 15%，不需要支撐。

**你應該看到／得到**
- 底座 80 × 90 × 6 mm，前面一道 10 mm 高的唇、中間有 12 mm 的缺口，後面三條 3.5 mm 寬、3 mm 深的槽。
- 背板 70 × 80 × 3 mm。插進槽 1 手機最直立，插進槽 3 最躺。
- 兩件一起大約 40–50 g，1.5–2.5 小時（依機型與設定）。

## 用工具看看

這一節用 Fusion 360 自己的「檢查」工具，在印之前就讀出數字。

**1. 量測（`I`）**
「檢查 → 量測」。點鑰匙圈的一條邊，面板顯示長度 60.00 mm；點孔的內壁，顯示直徑 5.00 mm；先點一個面再點另一個面，顯示兩面之間的距離。所有你設計時打的數字，這裡都能再讀出來。在手機架上點槽的兩個側壁，確認是 3.5 mm。

**2. 角度**
在手機架底座的側面（YZ 平面）建立一個草圖，畫一條線：從前唇內側、底座頂面的點（Y = 6，Z = 6）畫到槽 1 裡背板頂端的前緣（背板插在槽裡時頂端在 Z = 3 + 80 = 83，前緣大約在 Y = 35.5）。用量測工具點這條線和底座頂面，讀到的角度大約是 69°。再對槽 2、槽 3 各畫一條，大約是 60° 和 52°。每往後一格，手機大約躺 8–10°。看影片常用 55–65°，打字用 70° 左右。

## 常見錯誤與迷思

- **「單位打錯沒關係，等一下再縮放」** → 60 打成 60 cm，匯進 Bambu Studio 會變成 600 mm 的巨物；縮放回去之後文字、圓角全部跟著變。→ 開始前先看文件設定的單位是 mm；匯入 Bambu Studio 時先看尺寸合不合理。
- **「草圖線是藍色的，反正看起來對就好」** → 藍線表示還沒被尺寸定住，之後任何一個動作都可能把它拖歪。→ 每條邊都給尺寸或約束，讓它變黑色（第 9 章）。
- **「拉伸的時候點到孔裡面也沒差」** → 點到圓裡面，圓也會一起被拉成實心，孔就不見了。→ 拉伸前看哪些區域變成淡藍色；拉伸完轉動視角檢查。
- **「文字用什麼字型都一樣」** → 細字型的筆畫比噴嘴線還細，切片軟體會直接把它忽略，印出來沒有字。→ 用粗體黑體，字高 6 mm 以上。
- **「反正可以用 Ctrl + Z，不用存檔」** → Fusion 360 的雲端存檔不會自動存，關掉視窗時沒存就全部不見。→ 每做完一個階段就 `Ctrl/Cmd + S`。
- **「匯出 STL 選『低』細化比較快」** → 低細化的圓會變成看得出來的多邊形，孔會變成八角形。→ 匯出一律選「高」。
- **「Fusion 360 要學很久才能印東西」** → 這一章的兩個活動只用了矩形、圓、文字、拉伸、圓角、倒角六個工具。→ 先用這六個工具做出十個東西，再去學其他的。

## 想一想

1. 鑰匙圈底板 60 × 25 × 3 mm，忽略孔和文字，體積是多少 mm³？換成 cm³ 是多少？PLA 密度 1.24 g/cm³，重量大約幾公克？

<details><summary>參考答案</summary>

60 × 25 × 3 = 4,500 mm³ = 4.5 cm³（1 cm³ = 1,000 mm³）。4.5 × 1.24 = 5.58，大約 5.6 g。

</details>

2. 你在一塊 6 mm 厚的板子頂面畫了一個圓，想挖一個 4 mm 深、不穿透的凹槽。拉伸對話框裡的「距離」和「操作」應該填什麼？

<details><summary>參考答案</summary>

距離填 `-4`（負號表示往板子裡面、也就是往下），操作選「切除」。如果填 `4`，會往上長出一根 4 mm 的圓柱；如果操作選「接合」，就不會挖洞。

</details>

3. 手機架的缺口要在前唇正中間，前唇寬 80 mm、缺口 12 mm。缺口左邊離板邊幾 mm？如果把底座改成 76 mm 寬，這個數字變成多少？

<details><summary>參考答案</summary>

(80 − 12) ÷ 2 = 34 mm。改成 76 mm 寬：(76 − 12) ÷ 2 = 32 mm。在草圖尺寸裡直接輸入算式 `(76-12)/2` 也可以。

</details>

4. 小翔把鑰匙圈的孔畫在離板邊 3 mm 的地方（孔徑 5 mm）。印出來會有什麼問題？

<details><summary>參考答案</summary>

孔邊到板邊只剩 3 − 2.5 = 0.5 mm，大約只有一條噴嘴線寬，一掛上鑰匙圈就會被扯斷。孔邊到板邊至少留 2–3 mm（本書用 3.5 mm）。

</details>

5. 阿姊把手機架的三條槽都畫成 3.0 mm 寬，背板也是 3.0 mm 厚。印出來會發生什麼事？她應該改哪個數字？

<details><summary>參考答案</summary>

第 7 章講過，列印的槽會縮 0.2–0.4 mm，槽變成 2.6–2.8 mm，背板插不進去。槽要畫成 3.4–3.5 mm（背板厚度 + 0.4–0.5）。改槽比改背板好，因為背板留 3 mm 才夠硬。

</details>

6. （開放挑戰）設計一個「耳機線整理夾」：一塊小板子，兩端各有一個缺口可以把線繞上去卡住。請寫出你會畫的草圖形狀、每個尺寸、用到哪些工具（拉伸、切除、圓角……）和順序。

<details><summary>參考答案</summary>

參考做法：XY 平面畫 50 × 20 矩形，拉伸 3 mm；在頂面畫兩個缺口（例如兩端各一個 8 mm 寬、6 mm 深的矩形，開口朝外）切除；再在缺口的入口處畫兩個小半圓切除，讓線容易進去；四個角圓角 R3，所有頂面邊圓角 R1 避免割線。合理的答案要有：封閉的草圖形狀、每個尺寸、切除方向、圓角半徑，以及「先做大形再做細節」的順序。

</details>

## 本章小結

- Fusion 360 是參數式 CAD 軟體，個人非商業使用免費（一年一續），學生可申請教育版；只有 Windows 與 Mac 版，檔案存雲端。
- 安裝後先把「預設建模方向」改成 Z 向上，XY 平面就是列印板。
- 介面四區：工具列（建立、修改、組合、構造、檢查）、瀏覽器（樹狀清單）、時間軸（每一步可回頭改）、視角方塊。
- 滑鼠：Shift + 中鍵旋轉、中鍵平移、滾輪縮放、雙擊中鍵全部置中。
- 建模套路：選平面 → 畫草圖 → 給尺寸（`D`，線變黑） → 完成草圖 → 拉伸。拉伸的操作有新本體、接合、切除、相交。
- 修飾三寶：圓角（手摸的邊）、倒角（底邊 0.5 mm）、抽殼（實心變盒子）。
- 文字：粗體黑體、字高 6 mm 以上、凸 0.6–1 mm；中文要選有中文的字型。
- 匯出 3MF（推薦）或 STL，細化選高，單位 mm；設計本身存 F3D 才能回頭改。
