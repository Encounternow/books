# 附錄 C　建模工具與檔案格式速查

這份附錄分三部分：**C.1 Fusion 360 操作與快捷鍵速查**、**C.2 檔案格式（STL / 3MF / STEP / F3D）**、**C.3 MakerWorld 與其他免費模型網站**。介面用通用的功能名稱描述，按鈕的位置會隨版本改變，找不到時用介面右上角的搜尋或按 `S` 開啟「快捷工具搜尋」打關鍵字。

## C.1　Fusion 360 操作速查

### 介面的五個區域

```
 ┌─────────────────────────────────────────────────────────┐
 │ 工具列（實體 / 曲面 / 網格 / 草圖 ... 分頁）                │
 ├──────────┬──────────────────────────────────────────────┤
 │ 瀏覽器   │                                              │
 │ （樹狀） │               畫布（3D 視圖）                  │
 │ 元件     │                                 ┌────┐       │
 │ 本體     │                                 │視角│ ← 方塊 │
 │ 草圖     │                                 └────┘       │
 ├──────────┴──────────────────────────────────────────────┤
 │ 時間軸（每個操作一格，可以回去改）                           │
 └─────────────────────────────────────────────────────────┘
```

- **瀏覽器**：你畫過的每個元件、本體、草圖都在這裡；點眼睛圖示可以隱藏。
- **時間軸**：Fusion 360 的核心。每個特徵一格，雙擊就能回頭改，後面的全部跟著重算（第 9 章）。
- **視角方塊**：點面、邊、角切換視角；點「首頁」回預設視角。

### 滑鼠與視角

| 動作 | 操作 |
|---|---|
| 旋轉視角 | 按住滑鼠中鍵 + Shift 拖曳（或按住視角方塊拖曳） |
| 平移 | 按住滑鼠中鍵拖曳 |
| 縮放 | 滾輪 |
| 全部放到畫面中 | 連按兩下滑鼠中鍵，或快捷鍵 `F6` |
| 正對一個面 | 在那個面上點右鍵 → 「以此面檢視」 |
| 筆電沒中鍵 | 設定裡可改成「觸控板模式」或用畫布下方的導覽列 |

### 草圖的基本流程

1. 「建立草圖」→ 點一個平面（XY、XZ、YZ 或任何實體的平面）。
2. 畫形狀（`L`、`R`、`C`），不用一開始就準。
3. 按 `D` 給尺寸，一個一個點，輸入數字。線條從藍色變黑色表示「完全約束」（第 9 章）。
4. 「完成草圖」。
5. 按 `E` 拉伸，選輪廓，輸入高度。操作選「新本體」（獨立零件）、「接合」（加到既有本體）、「切除」（挖掉）。

### 常用修改工具

| 工具 | 做什麼 | 本書用在哪 |
|---|---|---|
| 圓角 `F` | 邊變圓 | 第 10 章讓零件不刮手、角不翹 |
| 倒角 | 邊切成 45° 斜面 | 第 10 章底邊倒角、第 12 章水滴形孔 |
| 抽殼 | 實心變成殼，選要開口的面 | 第 8、12 章盒子 |
| 合併 | 兩個本體接成一個／相減／相交 | 第 12 章銷與盒身 |
| 分割本體 | 用平面或草圖把本體切兩半 | 大件分割列印 |
| 鏡射 | 對稱複製 | 手爪的左右指 |
| 陣列 | 直線或環形重複 | 齒輪齒、多個孔 |
| 變更參數 | 建立使用者參數 | 第 9、12、13 章 `gap`、`wall` |

### 齒輪：Spur Gear 工具

「工具 → 附加模組 → 腳本與附加模組」裡找 **SpurGear**（Fusion 360 內建）。執行後填：模數（本書用 2）、齒數、壓力角（20°）、厚度、軸孔直徑、齒隙（0.2）。產生的是一個新元件，可以直接用。

### 裝配：接合

1. 每個會動的零件做成獨立「元件」（瀏覽器裡右鍵 → 從本體建立元件）。
2. 其中一個元件右鍵「固定」（不然整個裝配會飄走）。
3. 按 `J`，先點動件上的點／軸（例如軸孔的圓心），再點固定件上的對應點，選類型：**旋轉**（鉸鏈、齒輪）、**滑塊**（抽屜）、**球**（球關節）。
4. 「運動連結」把兩個接合綁在一起，填比例（齒輪比）。
5. 拖動任何零件看它動；「干涉」檢查有沒有互相穿透。

### 匯出給 Bambu Studio

1. 瀏覽器最上層的設計名稱右鍵 → 「匯出」，或「檔案 → 匯出」。
2. 格式選 **3MF**（推薦）或 **STL**。一個設計有多個本體時，3MF 會把它們當成不同零件帶過去。
3. 單位 mm；精細度選「高」（曲面才圓）。
4. 也可以在本體上右鍵 → 「另存為網格」，只匯出那一個本體。
5. 如果安裝了 Bambu Studio，Fusion 360 匯出時可能直接出現「用 Bambu Studio 開啟」的選項。

## C.2　檔案格式：STL、3MF、STEP、F3D

| 格式 | 裡面有什麼 | 優點 | 缺點 | 什麼時候用 |
|---|---|---|---|---|
| **STL** | 表面的三角形網格；沒有單位、顏色、設定 | 所有軟體都能讀，網站上最常見 | 不能回頭改尺寸；曲面是多邊形近似；單位會跑掉 | 給任何切片軟體、代印服務、上傳模型網站 |
| **3MF** | 網格 + 單位 + 顏色 + 多零件 + 列印設定 | Bambu Studio 的專案格式；一個檔案帶走全部；比 STL 小 | 舊軟體可能不支援 | Fusion 360 → Bambu Studio；保存你的切片專案；MakerWorld 上傳 |
| **STEP（.step / .stp）** | 真正的幾何（圓是圓、平面是平面）；可編輯 | 跨 CAD 軟體交換的標準，Fusion 360 開了可以繼續改 | 不含列印設定；切片軟體要先轉成網格（Bambu Studio 可直接匯入） | 和用其他 CAD 的人交換零件；下載廠商提供的螺絲、馬達模型 |
| **F3D** | Fusion 360 原生檔，含完整時間軸與參數 | 可以回頭改任何一步 | 只有 Fusion 360 能開 | 備份自己的設計；和同學分享可改的版本 |

```
 可以改 ◄──────────────────────────────────► 只能印
   F3D          STEP           3MF           STL
 （時間軸）   （幾何）     （網格+設定）    （網格）
```

**本書的建議**：設計存 F3D（Fusion 360 自動雲端存檔），交給 Bambu Studio 用 3MF，給別人或上傳網站用 3MF 或 STL，需要別人改尺寸就給 STEP。

## C.3　免費模型網站（只列名稱與用途）

| 網站 | 用途 | 備註 |
|---|---|---|
| **MakerWorld** | Bambu Lab 官方模型平台；模型多半附 Bambu Studio 專案（3MF 含設定），一鍵送印 | 需 Bambu 帳號；可以直接看別人用什麼設定印成功 |
| **Printables** | Prusa 經營的模型平台，社群大、分類清楚 | 很多附列印設定與照片 |
| **Thingiverse** | 歷史最久的模型庫，數量最多 | 舊模型多，品質參差，下載前看評論 |
| **Thangs** | 模型搜尋引擎，可以用形狀搜尋 | 整合多個來源 |
| **Cults3D** | 設計師作品平台 | 有免費也有付費，注意標示 |
| **NASA 3D Resources** | 太空船、探測器、行星地形模型 | 教育用途 |
| **Smithsonian 3D** | 博物館文物的掃描模型 | 教育用途 |
| **GrabCAD** | 工程零件、機構的 CAD 檔（多為 STEP） | 需註冊；適合找馬達、軸承、螺絲的模型 |
| **McMaster-Carr** | 五金零件目錄，每個螺絲、軸承都可下載 STEP | 第 6 章認螺絲、第 13 章畫伺服座旁邊的螺絲孔時用 |
| **Fusion 360 Gallery** | Autodesk 官方的作品展示 | 看別人怎麼用 Fusion 360 |

下載別人的模型時：
1. 看授權（Creative Commons 的標示），有的不能商業使用、有的要標作者。
2. 看「列印設定」和「評論」，有沒有人印成功。
3. 下載 3MF 優先，其次 STL；拿到 STL 先在 Bambu Studio 確認大小合理。
4. 模型只是起點，本書的目標是你自己畫。
