# 附錄 E　名詞對照表

依主題分組，同一組內大致依章節出現順序排列。專有名詞在正文第一次出現時附英文，之後只用中文；這裡集中收錄方便查。

## E.1　機械基礎（第 1 章）

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 機械 | Machine | 把力與運動換成另一種形式的裝置 |
| 簡單機械 | Simple Machine | 槓桿、輪軸、滑輪、斜面、楔、螺旋六種基本機械 |
| 槓桿 | Lever | 繞支點轉動的硬棒 |
| 支點 | Fulcrum | 槓桿轉動的點 |
| 施力 | Effort | 你出的力 |
| 抗力／負載 | Load | 要移動的重物或阻力 |
| 力臂 | Lever Arm | 支點到施力（或負載）的距離 |
| 輪軸 | Wheel and Axle | 大輪帶小軸，像門把、方向盤 |
| 滑輪 | Pulley | 繞著繩子轉的輪子 |
| 斜面 | Inclined Plane | 用較長的路換較小的力 |
| 楔 | Wedge | 兩個斜面背靠背，像斧頭 |
| 螺旋 | Screw | 捲起來的斜面 |
| 機械利益 | Mechanical Advantage | 輸出力除以輸入力 |
| 功 | Work | 力 × 距離 |
| 能量守恆 | Conservation of Energy | 省力就費距離，功不會憑空變多 |
| 摩擦 | Friction | 兩個表面相對運動時的阻力 |
| 機構 | Mechanism | 一組零件組合起來傳遞運動的系統 |
