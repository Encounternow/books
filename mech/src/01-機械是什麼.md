# 第 1 章　機械是什麼

## 本章目標
- 學完你會用一句話說出機械在做什麼：把「力與運動」換成另一種大小、方向或形式。
- 學完你會認出六種簡單機械（槓桿、輪軸、滑輪、斜面、楔、螺旋），並在家裡每一種都找到至少一個例子。
- 學完你會算機械利益，並說明為什麼機械可以省力卻不能省功。
- 學完你會把一個日常用品拆開，用「桿、關節、固定端」三種符號畫出它的機構圖。
- 學完你會親手用冰棒棍做出第一、二、三類槓桿，量出它們各自省力或費力幾倍。

## 開場：阿婕的開瓶器

阿婕的阿公愛喝玻璃瓶裝的黑松沙士。有一次家裡的開瓶器找不到，阿公拿湯匙柄卡在瓶蓋邊緣，手指當支點，往上一撬，「啵」一聲就開了。阿婕試著直接用手指摳瓶蓋，摳到指甲痛都打不開。

「湯匙又沒有馬達，力氣是從哪裡來的？」阿婕問。

阿公說：「不是力氣變大，是你的力氣被『換』了形狀。你手指按下去的那一小段力，被湯匙變成瓶蓋那邊的一大段力。」

這句話其實就是整本書的第一句話。從湯匙、剪刀、腳踏車，到工地的挖土機、工廠裡的機械手臂，所有機械做的事都一樣：**把你給它的力和運動，換成另一種大小、方向、速度或形式的力和運動**。它不會憑空變出能量，但它可以把能量「重新包裝」。這一章我們先把最簡單的六種包裝方法認識一遍，再動手拆開兩樣東西，看看裡面藏了什麼。

## 核心概念

### 機械：把力與運動換個形式

先給一個定義。**機械（Machine）**是一個裝置，你在**輸入端**給它一個力和一段運動，它在**輸出端**給你另一個力和另一段運動。中間那些桿子、輪子、齒輪，就是負責「換」的零件，我們叫它們**機構（Mechanism）**。

```
   你出的力、你移動的距離            對方得到的力、對方移動的距離
   ┌──────────┐      ┌──────────────┐      ┌──────────┐
   │  輸入端   │ ───▶ │   機構        │ ───▶ │  輸出端   │
   │ 小力、長距 │      │ 槓桿/齒輪/連桿 │      │ 大力、短距 │
   └──────────┘      └──────────────┘      └──────────┘
```

「換」可以換四種東西：

| 換什麼 | 例子 |
|---|---|
| 力的大小 | 開瓶器：小力變大力；釣竿：大力變小力但魚竿尖端動得快 |
| 力的方向 | 滑輪：往下拉繩子，重物往上升 |
| 運動的速度或距離 | 腳踏車：踏板轉一圈，後輪轉 2.75 圈 |
| 運動的形式 | 引擎：活塞上下直線跑，變成曲軸轉圈；雨刷：馬達轉圈，變成雨刷左右擺 |

這本書前半的每一章，就是在講一種「換」的零件：第 2 章齒輪換速度與力，第 3 章連桿與凸輪換運動形式，第 4 章皮帶與鏈條把力送到遠處。

### 六種簡單機械回顧

所有複雜的機械拆到最後，都是下面六種**簡單機械（Simple Machine）**的組合。《動手玩物理》第 7 章（https://book.vichuang.tw/physics/ ）用實驗一個一個驗證過，這裡用機械設計者的眼光快速回顧一遍，重點放在「它在換什麼」。

**1. 槓桿（Lever）**：一根繞著**支點（Fulcrum）**轉的硬棒。按支點、施力、抗力三者的位置分三類：

```
 第一類：支點在中間（剪刀、蹺蹺板、撬棍）
   施力↓                       ↑抗力
   ═══════════════▲═══════════
                 支點

 第二類：抗力在中間（開瓶器、手推車、胡桃鉗）→ 一定省力
   施力↓             ↑抗力
   ═════════════════════════▲
                           支點

 第三類：施力在中間（鑷子、釣竿、掃把、你的手臂）→ 費力但換速度
          施力↓                  ↑抗力
   ▲═══════════════════════════
  支點
```

**2. 輪軸（Wheel and Axle）**：一個大輪子和一根小軸固定在一起同心轉。轉大輪省力（門把、方向盤、水龍頭），轉小軸費力但大輪轉得快（腳踏車後輪：鏈條帶動小飛輪，大輪子在地上跑得快）。

**3. 滑輪（Pulley）**：繩子繞過一個會轉的輪子。定滑輪只換方向，動滑輪省一半力但繩子要拉兩倍長。

**4. 斜面（Inclined Plane）**：用長距離換高度。坡道、樓梯、山路。

**5. 楔（Wedge）**：兩個背對背的斜面，往前推就把東西往兩邊撐開。斧頭、菜刀、圖釘尖、拉鍊頭裡的那個小斜塊。

**6. 螺旋（Screw）**：把斜面捲在一根圓柱上。轉一圈，螺絲只前進一個**螺距（Pitch）**，所以非常省力，而且不會自己倒退（第 6 章會講 M3 螺絲螺距 0.5 mm 是什麼意思）。

### 機械利益：放大了幾倍

我們用一個數字說機械把力放大了幾倍，叫**機械利益（Mechanical Advantage，MA）**：

> MA ＝ 輸出的力 ÷ 輸入的力

對槓桿來說，MA 也等於**施力臂 ÷ 抗力臂**（施力點到支點的距離，除以抗力點到支點的距離）。

**算一個例子：** 開瓶器長 12 cm，前端頂住瓶蓋的鉤子離支點 1 cm，你的手握在離支點 11 cm 處。MA ＝ 11 ÷ 1 ＝ 11。瓶蓋要 55 N 才撬得開，你只要出 55 ÷ 11 ＝ 5 N，大約是提一瓶 500 mL 水的力。

MA 大於 1 叫省力，小於 1 叫費力。費力不是壞事：釣竿的 MA 大約 0.1，你出 10 倍的力，但竿尖動的距離是你手的 10 倍，魚才拉得上來得快。**機械設計的第一個選擇題，就是「這裡要力，還是要速度」。**

### 省力不省功：能量不會變多

機械最重要的規則：**它不會給你能量**。

功（Work）＝ 力 × 距離。開瓶器那個例子：你出 5 N、手移動 2.2 cm，做的功是 5 × 2.2 ＝ 11（N·cm）；瓶蓋那邊得到 55 N、移動 0.2 cm，55 × 0.2 ＝ 11（N·cm）。一樣多。力放大 11 倍，距離就縮小 11 倍，乘起來永遠一樣。

真實機械還有摩擦，一部分的功變成熱跑掉了，所以輸出永遠比輸入少一點。我們用**效率（Efficiency）**＝ 輸出功 ÷ 輸入功 來形容。紙板和冰棒棍做的機構效率很差，常常只有 50–70%，這不是你做錯，是材料的關係；第 4 章講軸承時會教你怎麼把摩擦降下來。

### 從開瓶器到挖土機：機械是疊出來的

一個開瓶器是一個簡單機械。一支指甲剪是兩個槓桿疊起來。一輛腳踏車是輪軸（踏板帶大齒盤）＋鏈條（把力送到後面）＋輪軸（小飛輪帶大輪子）＋槓桿（煞車把手）。一台挖土機是好幾十個槓桿（每一節手臂都是）、好幾個斜面（鏟斗的齒是楔）、加上油壓缸推動一切。

設計機械的人不是一次想出整台機器，而是**一個簡單機械接一個簡單機械地疊**：這裡要把力放大，加一支槓桿；那裡要改方向，加一個滑輪；要讓轉圈變成直線，加一組齒條（第 2 章）。你拆開家裡任何一樣會動的東西，都能把它拆回這六種。

### 怎麼畫機構圖

工程師看機械不看外型，看「哪裡是桿、哪裡會轉、哪裡固定住」。本書用三個符號畫機構圖：

```
  ───────   桿（Link）：不會變形的一段硬物，冰棒棍、筆桿、剪刀的一葉
     ●      關節（Joint）：兩根桿可以互相轉動的地方，兩腳釘、鉚釘、竹籤
   ─┬┬┬─    固定端（Ground）：接在不動的東西上（桌子、機殼、你的手）
```

用這三個符號畫剪刀：

```
        刀刃A ──────────●────────── 握把A
                        │ 鉚釘（關節）
        刀刃B ──────────●────────── 握把B
                 兩葉各是一根第一類槓桿，共用一個支點
```

畫機構圖的好處是：外型完全不同的東西，機構圖可能一模一樣。剪刀、老虎鉗、曬衣夾的機構圖都是「兩根桿共用一個關節」。到了第 8 章用 Fusion 360 建模時，你會先畫這種圖，再決定每根桿要多長、多厚。

## 動手做

### 活動 1-1：拆解一支原子筆與一個夾子，畫機構圖

**材料／工具**
- 一支按壓式原子筆（按一下筆芯出來、再按一下縮回去那種；挑便宜的，拆了可能裝不回去）
- 一個曬衣夾（木頭或塑膠皆可）、一個長尾夾
- 直尺、鉛筆、白紙
- 一個小盤子（裝小零件，彈簧很容易彈不見）

**步驟**
1. 把原子筆旋開，所有零件放到盤子裡排成一列：筆蓋、按壓頭、彈簧、筆芯、筆管。數一數共幾個零件，一一畫下來並寫上名稱。
2. 把按壓頭單獨拿起來，用手指壓住彈簧再放開，感覺它彈回來的力。按壓頭下方通常有一圈斜斜的鋸齒，那就是讓筆芯「按一下卡住、再按一下放開」的祕密：鋸齒是斜面，每按一下，斜面讓一個小套筒轉過一格，卡進或離開凹槽。
3. 在白紙上用「桿、關節、固定端」三種符號畫原子筆的機構圖。筆管是固定端，筆芯是沿直線滑的桿（滑動的關節畫成一個小方框 □），彈簧畫成鋸齒線 ∿∿∿。
4. 拿曬衣夾。找出它的支點（中間那根鐵絲繞的地方）、你捏的地方（施力點）、夾衣服的地方（抗力點）。用尺量施力點到支點、抗力點到支點各幾公分。
5. 畫曬衣夾的機構圖：兩根桿、一個關節、一個彈簧。判斷它是第幾類槓桿，算 MA。
6. 拿長尾夾做同樣的事。注意它的「桿」是一片摺成三角形的鐵皮，支點在鐵皮的兩個摺角；把手扳開的那兩根鐵絲是另一組槓桿。

**你應該看到**
- 原子筆至少有 5 個零件，其中會動的只有三個：按壓頭、筆芯、彈簧。
- 曬衣夾是第一類槓桿（支點在中間）。一般曬衣夾的施力臂（捏的地方到支點）約 3.5 cm，抗力臂（夾口到支點）約 2.5 cm，MA ≈ 3.5 ÷ 2.5 ＝ 1.4。它不是為了省力設計的，而是為了讓彈簧把夾口夾緊。
- 長尾夾扳開時很費力，因為它的施力臂短、彈簧又很硬；但夾住之後靠彈簧，不靠你。

**觀察與記錄**

| 物品 | 零件數 | 會動的零件 | 支點位置 | 施力臂 (cm) | 抗力臂 (cm) | 第幾類槓桿 | MA |
|---|---|---|---|---|---|---|---|
| 原子筆 | | | （直線滑動，無） | — | — | — | — |
| 曬衣夾 | | | | | | | |
| 長尾夾 | | | | | | | |
| （自選一樣） | | | | | | | |

**安全提醒**：彈簧會彈飛，拆原子筆時手指壓著按壓頭慢慢放開，臉不要湊近。長尾夾夾到手指會很痛，扳開時手指不要放在夾口。

### 活動 1-2：用冰棒棍做三種槓桿

**材料／工具**
- 寬冰棒棍 3 支（長約 15 cm）
- 一個瓶蓋（當支點）、膠帶
- 一枚 10 元硬幣與一枚 1 元硬幣（10 元約 7.5 g，1 元約 3.8 g，差不多是 2 : 1）
- 直尺、鉛筆
- 一疊書（墊高用）

**步驟**
1. 在一支冰棒棍上，從一端開始每 1 cm 畫一條刻度，共 15 格。
2. **第一類槓桿**：把瓶蓋側放，用膠帶黏在桌上當支點，冰棒棍的 7.5 cm 刻度（正中間）放在瓶蓋上，像蹺蹺板。把 10 元硬幣放在支點一邊 3 cm 處，再把 1 元硬幣放在另一邊，慢慢移動它直到棍子平衡。記下 1 元硬幣離支點的距離。
3. 換一個位置：10 元硬幣放在離支點 2 cm，再找 1 元硬幣的平衡位置。
4. **第二類槓桿**：把冰棒棍的一端用膠帶黏在桌邊當支點（只黏一點點，讓它還能微微翹起），10 元硬幣放在離支點 5 cm 處（抗力在中間），你用一根手指在最遠端 15 cm 處往上頂，感覺要出多少力。再把硬幣移到 10 cm 處頂一次，比較哪一次輕。
5. **第三類槓桿**：同樣支點在一端，這次 10 元硬幣放在最遠端 15 cm，你的手指在 5 cm 處往上頂。感覺一下，然後把手指移到 10 cm 處再頂一次。
6. 用第 2 支冰棒棍把第 4、5 步的「手指」換成一根冰棒棍壓著，請家人用手機從側面拍慢動作，看硬幣那一端與你出力那一端各移動了多少距離。

**你應該看到**
- 第 2 步：10 元硬幣在 3 cm 處，1 元硬幣大約要放在 6 cm 處才平衡（7.5 × 3 ≈ 3.8 × 6，也就是 22.5 ≈ 22.8）。第 3 步，10 元在 2 cm，1 元約在 4 cm。重量 2 倍，距離就要 1/2。
- 第二類槓桿：硬幣越靠近支點，手指越輕鬆。硬幣在 5 cm、手指在 15 cm 時，MA ＝ 15 ÷ 5 ＝ 3。
- 第三類槓桿：手指在 5 cm、硬幣在 15 cm 時，MA ＝ 5 ÷ 15 ≈ 0.33，手指要出 3 倍的力，但硬幣那端動的距離是手指的 3 倍。慢動作影片裡看得很清楚。

**觀察與記錄**

| 槓桿類型 | 支點位置 | 抗力（硬幣）離支點 (cm) | 施力點離支點 (cm) | MA（施力臂÷抗力臂） | 感覺：省力／費力 | 施力端移動 (cm) | 抗力端移動 (cm) |
|---|---|---|---|---|---|---|---|
| 第一類（10 元在 3 cm） | 中間 | 3 | | | | | |
| 第一類（10 元在 2 cm） | 中間 | 2 | | | | | |
| 第二類 | 一端 | 5 | 15 | | | | |
| 第二類 | 一端 | 10 | 15 | | | | |
| 第三類 | 一端 | 15 | 5 | | | | |
| 第三類 | 一端 | 15 | 10 | | | | |

**安全提醒**：冰棒棍邊緣有時有毛刺，先用指甲或砂紙磨一下。瓶蓋黏在桌上用紙膠帶，撕下來不留痕。

## 用工具看看

**1. 用尺和試算表算全家的機械利益**

在家裡找 8 樣有槓桿的東西（剪刀、指甲剪、開瓶器、老虎鉗、掃把、湯勺、門、腳踏車煞車把手）。每一樣用尺量施力臂與抗力臂，打開 Google 試算表：

- A 欄：物品名稱；B 欄：施力臂 (cm)；C 欄：抗力臂 (cm)。
- D2 輸入 `=B2/C2`，往下拉，這就是每樣東西的 MA。
- E2 輸入 `=IF(D2>1,"省力","費力")`，往下拉。
- 選取 A、D 兩欄，插入長條圖。

你會看到剪刀、開瓶器、老虎鉗的 MA 在 2–10 之間；掃把、湯勺、你的前臂都小於 1。想一想：費力的那幾樣東西，為什麼設計者寧願費力？（提示：它們都要「動得快、動得遠」。）

**2. 用手機慢動作看「距離換力」**

把活動 1-2 的第三類槓桿架好，開手機的慢動作模式（iPhone 相機左右滑到「慢動作」；Android 多數叫「慢動作」或「超慢動作」），從正側面拍你用手指把冰棒棍頂起來的過程。暫停在最高點，用尺（或螢幕上的格線）比較施力端與抗力端各升高多少。抗力端的距離 ÷ 施力端的距離，應該接近 抗力臂 ÷ 施力臂，也就是 1 ÷ MA。

**3. 用量角器看槓桿的轉角**

槓桿轉動時，兩端轉過的**角度**一樣，但**距離**不一樣。把量角器的圓心對準支點，拍一張照片，量槓桿從水平轉到最高點的角度（通常 10–20°）。兩端轉過同樣的角度，離支點越遠的那端走過的弧長越長：弧長 ＝ 距離 × 角度（弧度）。這就是「距離換力」的幾何原因，也是第 2 章齒輪「大輪帶小輪」的原理。

## 常見錯誤與迷思

- **「機械讓我做的功變少了。」** → 功 ＝ 力 × 距離，機械讓力變小，距離就等比例變長，乘起來不變；再加上摩擦，你做的功其實更多一點。→ 正確理解：機械省力不省功，效率永遠小於 100%。
- **「槓桿一定省力。」** → 鑷子、釣竿、掃把、你的前臂都是費力的第三類槓桿。→ 正確理解：施力臂比抗力臂長才省力；設計者有時故意選費力，換取速度與距離。
- **「只有大機器才叫機械。」** → 原子筆的按壓頭、拉鍊頭、曬衣夾都是機械。→ 正確理解：只要把力或運動換了形式，就是機械。
- **「畫機構圖要畫得像。」** → 機構圖是給「會動的地方」看的，不是給「外型」看的。剪刀與曬衣夾外型不同，機構圖一樣。→ 正確理解：先找桿、關節、固定端，外型最後才畫。
- **「紙板做的機構卡卡的，是我做壞了。」** → 紙板有厚度誤差、竹籤孔會變大、摩擦大，卡住很正常。→ 正確理解：卡住的原因是摩擦與公差，第 4 章與第 7 章會專門處理。
- **「MA 越大越好。」** → MA ＝ 100 的槓桿，你的手要移動瓶蓋的 100 倍距離，長到不切實際。→ 正確理解：機械設計是在力、距離、體積之間取捨。

## 想一想

1. 一把剪刀握把長 8 cm、刀刃長 4 cm（都從鉚釘量起）。你握把上出 10 N 的力，刀刃能出多少力？MA 是多少？

<details><summary>參考答案</summary>

MA ＝ 施力臂 ÷ 抗力臂 ＝ 8 ÷ 4 ＝ 2。刀刃上的力 ＝ 10 × 2 ＝ 20 N。剪厚紙板時把紙塞到最靠近鉚釘的地方，抗力臂變短，力更大，這就是為什麼剪硬東西要用刀刃根部。

</details>

2. 開瓶器全長 15 cm，鉤子離支點 1.5 cm。瓶蓋要 60 N 才撬開，你的手握在最遠端要出多少力？你的手往上移動 3 cm，瓶蓋被撬起多少？

<details><summary>參考答案</summary>

施力臂 ＝ 15 − 1.5 ＝ 13.5 cm（手在最遠端，離支點 13.5 cm）。MA ＝ 13.5 ÷ 1.5 ＝ 9。需要的力 ＝ 60 ÷ 9 ≈ 6.7 N。瓶蓋移動 ＝ 3 ÷ 9 ≈ 0.33 cm，也就是 3.3 mm，剛好夠讓瓶蓋邊緣脫開。

</details>

3. 活動 1-2 第一類槓桿裡，如果改用兩枚 10 元硬幣（一邊一枚），一枚放在離支點 4 cm，另一枚要放在哪？如果一邊放兩枚疊在一起、另一邊放一枚呢？

<details><summary>參考答案</summary>

同樣重量，另一枚也放在 4 cm 處。一邊兩枚（2 倍重）放在 d 處，另一邊一枚放在 2d 處才平衡，例如兩枚在 3 cm、一枚在 6 cm。這和活動裡 10 元對 1 元的結果一樣：重量比 2 : 1，距離比就是 1 : 2。

</details>

4. 腳踏車的煞車把手：你捏的地方離轉軸 9 cm，煞車線鉤在離轉軸 2 cm 的地方。你捏 30 N，煞車線被拉的力多大？你的手指移動 2 cm，煞車線被拉動多少？這是第幾類槓桿？

<details><summary>參考答案</summary>

MA ＝ 9 ÷ 2 ＝ 4.5，煞車線被拉的力 ＝ 30 × 4.5 ＝ 135 N。煞車線移動 ＝ 2 ÷ 4.5 ≈ 0.44 cm。支點（轉軸）在一端、抗力（煞車線）在中間、施力在另一端，是第二類槓桿，所以一定省力。

</details>

5. 一個機械的輸入是「出 20 N、移動 50 cm」，輸出是「出 80 N、移動 10 cm」。它的 MA、輸入功、輸出功、效率各多少？少掉的功去哪裡了？

<details><summary>參考答案</summary>

MA ＝ 80 ÷ 20 ＝ 4。輸入功 ＝ 20 × 50 ＝ 1000 N·cm，輸出功 ＝ 80 × 10 ＝ 800 N·cm，效率 ＝ 800 ÷ 1000 ＝ 80%。少掉的 200 N·cm 變成關節與接觸面摩擦產生的熱。

</details>

6. （開放挑戰）找一樣家裡「會動但你不知道裡面怎麼動」的東西：訂書機、捲尺、滑鼠滾輪、指甲剪、拉鍊、自動鉛筆。不拆開它，只靠觀察它動的方式，畫出你猜的機構圖（桿、關節、固定端），並寫下它把什麼換成了什麼。再上網找它的剖面圖對答案。

<details><summary>參考答案</summary>

答案不唯一。例如訂書機：上蓋是第二類槓桿（支點在後端鉸鏈、釘書針在中間、你的手在前端），把你的壓力放大後推針穿過紙，底座的凹槽是把針腳彎曲的「模具」。指甲剪是兩層槓桿：上面的壓柄是第二類槓桿，把力傳給下面的刀刃，刀刃又是第三類槓桿，兩層相乘後 MA 大約 3–5。重點是你有沒有找到支點與會動的桿。

</details>

## 本章小結

- 機械是把「力與運動」換成另一種大小、方向、速度或形式的裝置；中間負責換的零件叫機構。
- 六種簡單機械：槓桿、輪軸、滑輪、斜面、楔、螺旋。所有複雜機械都是它們疊出來的。
- 槓桿分三類：第一類支點在中間（剪刀），第二類抗力在中間（開瓶器，一定省力），第三類施力在中間（鑷子，費力換速度）。
- 機械利益 MA ＝ 輸出力 ÷ 輸入力 ＝ 施力臂 ÷ 抗力臂。MA 大於 1 省力，小於 1 費力但動得快。
- 省力不省功：力放大幾倍，距離就縮小幾倍；真實機械有摩擦，效率小於 100%。
- 機構圖用三種符號：桿、關節、固定端。外型不同的東西常有一樣的機構圖。
- 設計機械的第一個選擇題是「這裡要力，還是要速度」。
