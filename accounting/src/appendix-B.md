# 附錄 B　借貸速查卡與三張報表範本

這一份附錄是給你印出來貼在書桌前的。第一部分是借貸規則與常見分錄，第二部分是三張報表的空白範本，第三部分用小明文具行第一個月的數字示範填法。

## B.1　借貸速查卡

### 一句話記住

```
┌───────────────────────────────────────────────────────┐
│   資產、費用、成本 ── 借方是家（增加記借、減少記貸）    │
│   負債、權益、收入 ── 貸方是家（增加記貸、減少記借）    │
│                                                       │
│   每一筆分錄：借方金額總和 = 貸方金額總和              │
└───────────────────────────────────────────────────────┘
```

### 增減規則表

| 類別 | 增加 | 減少 | 正常餘額 | 出現在哪張報表 |
|---|---|---|---|---|
| 資產 | 借 | 貸 | 借 | 資產負債表 |
| 負債 | 貸 | 借 | 貸 | 資產負債表 |
| 權益 | 貸 | 借 | 貸 | 資產負債表 |
| 收入 | 貸 | 借 | 貸 | 損益表 |
| 成本 | 借 | 貸 | 借 | 損益表 |
| 費用 | 借 | 貸 | 借 | 損益表 |

### T 字帳怎麼看

```
          現金（資產）                    應付帳款（負債）
    ────────────┬────────────        ────────────┬────────────
      借（增加）│ 貸（減少）            借（減少）│ 貸（增加）
    ────────────┼────────────        ────────────┼────────────
      50,000    │ 24,000               10,000    │ 15,000
      20,000    │ 12,000              ───────────┼────────────
    ────────────┼────────────                    │  5,000 餘額
     餘額 34,000│
```

（數字是第 4 章小明文具行 10 月前幾筆交易：投入 50,000、向銀行借 20,000、預付租金 24,000、買電腦 12,000；賒購 15,000、還了 10,000。）

左邊叫借方、右邊叫貸方，跟「借錢」「貸款」沒有關係，只是左右的名字。

### 會計方程式與五大類的關係

```
  資產 = 負債 + 權益
                 └── 權益 = 期初權益 + 收入 − 費用 − 業主提取

  展開：資產 + 費用 + 業主提取 = 負債 + 期初權益 + 收入
        └──── 借方是家 ────┘   └──────── 貸方是家 ────────┘
```

### 分錄思考三步驟

1. 這筆交易碰到哪**兩個（以上）科目**？
2. 每個科目是**哪一類**？它是**增加還是減少**？
3. 查上面的表，決定記借還是記貸。最後確認借方合計 = 貸方合計。

### 找錯速查

| 試算表差額的特徵 | 可能的錯 |
|---|---|
| 差額是某筆交易金額的 2 倍 | 那筆借貸寫反 |
| 差額能被 9 整除 | 數字顛倒（270 寫成 720）或少一個 0 |
| 差額剛好等於某科目餘額 | 那個科目漏抄進試算表 |
| 差額等於某筆交易金額 | 那筆只記了一邊 |

## B.3　範例：小明文具行第一個月

數字來自第 5 章的 20 筆交易加第 7 章的 4 筆調整（第 14 章專題二用的也是這一套）：資本 50,000、銀行借款 20,000、預付 3 個月租金 24,000、電腦 12,000、進貨 20,000（其中 15,000 賒帳，月底還欠 5,000）、銷貨 30,000（其中 5,000 賒銷給補習班，已收回 3,000）、工讀生薪資 3,000、開幕傳單 500、雜項 700、利息 100、業主提取 2,000、水電 1,500 未付、折舊 200、期末存貨 5,000。

注意這個月**賺了 1,000 元，但營業活動現金是流出 15,300 元**：因為一次預付了三個月租金 24,000（只有 8,000 算 10 月的費用）、進的貨有 5,000 元還在架上、補習班還有 2,000 元沒付。反過來，水電 1,500 和欠批發商的 5,000 還沒付、折舊 200 不用付現，這些讓差距小一點。這就是第 10 章說的「利潤和現金不是同一件事」。
