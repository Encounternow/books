# 第 1 章　為什麼要記帳

## 本章目標
- 學完你會用一句話說出「會計」是什麼，也知道「簿記」和「會計」差在哪裡。
- 學完你會說出至少四種「會看帳的人」，以及他們各自想從帳裡知道什麼。
- 學完你會說出記帳的三個好處，而且每一個都能舉自己的例子。
- 學完你會分辨什麼事情算「一筆交易」、什麼不算，知道記一筆帳要寫哪些東西。
- 學完你會記下自己三天的每一筆收支，算出結餘，並且驗算它對不對。
- 學完你會認識小明文具行的開店設定，後面每一章都會用到它。

## 開場：錢怎麼不見了

星期天晚上，小安把口袋翻出來，只剩 120 元。他明明星期一才拿到 300 元零用錢，阿嬤星期三還塞給他 200 元。「我這週有花 380 元嗎？花在哪？」他想了半天，只想得起來買過一杯飲料、一盒筆芯，還有扭過兩次蛋。其他的，完全沒印象。

同一個晚上，小安的表哥小明正坐在餐桌前，面前攤著一張租約。小明 25 歲，下個月要在一所國中旁邊開一家小文具行。他把存款 50,000 元全拿出來，還向銀行借了 20,000 元。媽媽聽到他要開店，只問了一句：「你開了店之後，要怎麼知道自己是賺還是賠？」

小明愣住了。他本來以為「收銀機裡的錢變多就是賺」，但仔細一想，收銀機裡的錢有一部分是要付房租的、有一部分是要還銀行的、有一部分要拿去補貨……到底哪一部分才是真的賺到的？

小安的問題是「錢去哪了」，小明的問題是「我到底賺不賺」。這兩個問題，答案都是同一件事：**記帳**。這一章，我們先搞清楚記帳到底在記什麼、誰需要看、有什麼用，然後你會記下自己人生的第一本帳。

## 核心概念

### 會計是什麼：錢的行車記錄器

汽車上的行車記錄器會把路上發生的每一件事錄下來，出事的時候可以回頭看。**會計（Accounting）**就是錢的行車記錄器：它把每一筆錢的進出**記錄**下來，**整理**成有條理的樣子，**彙總**成幾張表，最後讓人能**看懂**錢發生了什麼事。

把這四個動作排成一排，就是會計的全部：

```
  記錄  ──►  分類  ──►  彙總  ──►  報告
 (每一筆)   (同類放    (加總成    (給人看、
            一起)      幾個數字)   做決定)
```

其中「記錄」這一步，有一個專門的名字叫**簿記（Bookkeeping）**。簿記是把每一筆交易寫進帳本，像是把每一段路錄下來；會計則是整套方法，包括錄完之後怎麼剪輯、怎麼看出意義。所以簿記是會計的一部分，不是全部。本書前半段教的主要是簿記（怎麼記），後半段教的是會計（怎麼看懂）。

一個常見的誤會是「會計就是算數學」。其實會計用到的數學只有加減乘除和百分比，難的不是計算，而是**判斷**：這筆錢該算在哪一類？這件事該不該記？什麼時候記？這本書大部分篇幅都在練這種判斷。

### 誰在看帳

你可能以為帳只有老闆自己在看，其實一家店的帳有很多人關心，每個人想知道的事都不一樣：

| 誰 | 他們和這家店的關係 | 最想從帳裡知道什麼 |
|---|---|---|
| 老闆（小明） | 自己開的店 | 有沒有賺？錢夠不夠用？哪些東西好賣？ |
| 銀行 | 借了 20,000 元給他 | 利息和本金收得回來嗎？這家店穩不穩？ |
| 家人（小明媽媽） | 關心他 | 這家店撐得下去嗎？要不要幫忙？ |
| 政府（稅務機關） | 要收稅 | 這家店今年賺了多少？該繳多少稅？ |
| 供應商（批發文具的廠商） | 把貨賣給他 | 這家店付得出貨款嗎？可以讓他賒帳嗎？ |
| 員工（將來請的工讀生） | 在這裡工作 | 這家店會不會倒？薪水發得出來嗎？ |

你會發現，除了老闆之外，其他人都是「局外人」，他們看不到店裡每天發生什麼事，**帳是他們唯一能看到的東西**。這就是為什麼會計要有一套大家共用的規則：如果每家店都用自己的方式記，銀行就沒辦法比較哪一家比較穩。本書教的規則，就是全世界的公司都在用的那一套（當然是最基本的版本）。

換到個人的零用錢，看帳的人就簡單多了：你自己，還有可能是爸媽。但道理一樣：爸媽看不到你每天花了什麼，一本清楚的帳是你證明「我有好好管錢」最好的方法。

### 記帳的三個好處

**好處一：看見。** 沒記帳之前，小安的 380 元像蒸發一樣消失了；記了帳之後，他會發現原來一週買了 6 杯飲料，光飲料就花了 210 元。錢不會憑空不見，它只是流到你沒注意的地方。記帳的第一個用處，就是把這些地方照亮。

**好處二：衡量。** 小明收銀機裡有 30,000 元，這算賺還是賠？光看這個數字不知道。要把收進來的錢和付出去的錢分開、再扣掉要還的、要補貨的，才能算出一個叫「淨利」的數字。有了這個數字，「賺不賺」就不再是感覺，而是可以比較的事實：這個月賺 5,000、上個月賺 3,000，進步了。

**好處三：決定。** 看見了、衡量了，接下來就能做決定。小安發現飲料花太多，決定一週最多買三杯；小明發現原子筆比螢光筆好賣三倍，決定下次進貨多進原子筆、少進螢光筆。沒有帳，決定只能靠猜；有了帳，決定有根據。

還有一個附帶的好處：**證據**。帳是白紙黑字的紀錄。小明向批發商賒帳進了 15,000 元的貨，月底批發商說「你是不是欠 20,000？」帳本可以回答。你跟同學借了 50 元，過兩週誰都忘了，帳本也可以回答。清楚的帳能避免很多吵架。

### 什麼事情算「一筆交易」

會計不是什麼都記。它只記**交易（Transaction）**，而交易有兩個條件：

1. 這件事讓你擁有的錢或東西、或你欠別人的錢，**真的改變了**（不是打算、不是可能）。
2. 這個改變**可以用金額衡量**。

用這兩條去檢查下面幾件事：

| 事件 | 是不是交易？ | 為什麼 |
|---|---|---|
| 買了一杯 35 元的飲料 | 是 | 錢少了 35 元，金額明確 |
| 想買一支 500 元的筆，但還沒買 | 不是 | 什麼都還沒改變 |
| 阿嬤給了 200 元 | 是 | 錢多了 200 元 |
| 同學說下週會還你 50 元 | 不是 | 他說歸說，錢還沒回來。（但你之前借他的那一刻，是交易） |
| 今天心情很好 | 不是 | 沒辦法用金額衡量 |
| 小明一次付了 24,000 元租金（10、11、12 月） | 是 | 錢少了 24,000 元 |
| 小明跟廠商「談好」下個月進貨 | 不是 | 談好不等於貨到、也不等於付錢 |
| 小明的書包被弄壞，要花 600 元修 | 還不是 | 要等真的付了修理費才記 |

記住這個口訣：**錢或東西真的動了，才記；只是想、只是說，不記。**

### 記一筆帳要寫什麼

一筆最基本的帳，要有五個東西：

1. **日期**：哪一天發生的。
2. **摘要**：發生了什麼事，寫到一個月後的你看得懂就好（「飲料」可以，「東西」不行）。
3. **收入**：進來多少錢。
4. **支出**：出去多少錢。
5. **結餘**：記完這筆之後，手上剩多少錢。

結餘的算法是：

> 這一筆的結餘 ＝ 上一筆的結餘 ＋ 這一筆的收入 － 這一筆的支出

這是小安這週前三天的帳（他從星期一開始記，星期天晚上口袋裡有 120 元，當作「期初」）：

| 日期 | 摘要 | 收入 | 支出 | 結餘 |
|---|---|---|---|---|
| 10/5 | 期初（口袋裡原本的） | | | 120 |
| 10/6 | 零用錢 | 300 | | 420 |
| 10/6 | 早餐飲料 | | 35 | 385 |
| 10/6 | 自動鉛筆筆芯 | | 25 | 360 |
| 10/7 | 午餐加點 | | 50 | 310 |
| 10/7 | 借給同學阿哲 | | 50 | 260 |
| 10/8 | 阿嬤給的 | 200 | | 460 |
| 10/8 | 扭蛋 | | 100 | 360 |
| 10/8 | 夾娃娃 | | 60 | 300 |
| **合計** | | **500** | **320** | |

驗算一下：期初 120 ＋ 收入 500 － 支出 320 ＝ 300，和最後一行的結餘一樣，表示這三天的帳是對的。這個驗算方法你以後每次記完帳都要做一次：

> 期初 ＋ 收入合計 － 支出合計 ＝ 期末結餘

如果算出來不一樣，就表示某一行的結餘算錯了，或是漏記了一筆。

注意「借給同學阿哲 50 元」這一筆：錢確實從口袋出去了，所以要記在支出；但這 50 元不是花掉，它會回來。第 2 章我們會學到，這種「別人欠你的錢」其實還是你的財產，到時候帳會記得更精確。現在先把它當成「口袋裡的錢變少了」就好。

### 小明文具行的故事開始

從這一章起，本書會一路跟著小明的店記帳。為了讓後面每一章的數字都接得起來，我們先把這家店的設定寫清楚。**這張表是全書的基礎，後面的章節都會用這些數字**，請把這一頁折起來做記號。

| 項目 | 設定 |
|---|---|
| 店名 | 小明文具行 |
| 老闆 | 小明，25 歲，一個人獨資經營 |
| 地點 | 一所國中旁邊的小店面（租的） |
| 開店日 | 10 月 1 日（10 月 1 日到 5 日進貨、佈置，10 月 6 日開幕）；第一個會計期間是 10 月 1 日到 10 月 31 日 |
| 老闆投入的資本 | 現金 50,000 元 |
| 銀行借款 | 20,000 元，10 月 1 日借，年利率 6%，每月付利息 100 元，本金兩年後一次還 |
| 店面租金 | 每月 8,000 元；10 月 1 日一次預付 10、11、12 月三個月，共 24,000 元 |
| 收銀電腦 | 12,000 元，10 月 2 日付現，預計用 5 年，用完不值錢 |
| 第一個月進貨 | 20,000 元的文具：10 月 3 日向批發商賒帳 15,000 元，10 月 4 日向另一家批發商付現 5,000 元 |
| 商品進價 | 平均約是售價的一半（也就是賣 100 元的東西，進貨成本 50 元） |
| 第一個月銷售 | 30,000 元：收現 25,000 元，另外 5,000 元賒銷給隔壁補習班 |
| 工讀生薪資 | 每月 3,000 元，週末來幫忙的高中生 |
| 水電費 | 每月約 1,500 元，帳單下個月才會寄來 |
| 月底盤點存貨 | 5,000 元（10 月 31 日數出來還沒賣掉的商品成本） |
| 老闆薪水 | 不領薪水；需要生活費時從店裡拿，記成「業主提取」（第 3 章會解釋） |
| 會計期間 | 每個月結一次帳；為了算起來簡單，一個月當 4 週 |

開幕前的那幾天（10 月 1 日到 4 日），小明的錢是這樣流動的：

```
 錢從哪裡來                          錢變成了什麼
 ─────────────                      ─────────────
 自己的存款   50,000 ──┐        ┌──► 預付 3 個月租金  24,000
                      ├─ 70,000 ─┤──► 買收銀電腦      12,000
 跟銀行借的   20,000 ──┘        ├──► 現金進貨         5,000
                                └──► 留在收銀機      29,000
                                                   ───────
                                                    70,000
```

左邊加起來 70,000，右邊加起來 24,000 ＋ 12,000 ＋ 5,000 ＋ 29,000 ＝ 70,000。**左右一定要相等**，因為錢不會憑空出現，也不會憑空消失；每一塊錢都有來處，也都有去處。這個「左右相等」的想法，就是整本書最核心的觀念，第 2 章會把它變成一條公式。

（另外有一筆 10 月 3 日向批發商賒帳進的 15,000 元文具，貨到了但錢還沒付，所以沒有動到現金，這張圖上看不到它。第 2 章會教你怎麼把「欠的錢」也記進帳裡。）

小明看著收銀機裡的 29,000 元，有點緊張：「我的 70,000 怎麼只剩 29,000？」其實他的錢沒有不見，只是從「現金」變成了「電腦」、「一整櫃的文具」，還有「10 月到 12 月可以使用這間店面的權利」。記帳最重要的功能之一，就是讓你隨時看得到錢**變成了什麼**，而不只是看到剩多少現金。

## 動手做

### 活動 1-1：記錄自己三天的每一筆收支

**材料／工具**
- 筆記本一本（格線本最好）、筆
- 計算機（手機的就可以）

**步驟**
1. 今天晚上，把你身上所有的現金數清楚（口袋、錢包、書包夾層都翻一翻），把這個數字寫在表格第一行，摘要寫「期初」，填在結餘欄。如果你有悠遊卡，先不要算進來，只算現金。
2. 從明天開始，連續三天，**每花一筆錢或收到一筆錢，當天晚上就寫一行**：日期、摘要、收入或支出的金額。
3. 每寫一行，就算出這一行的結餘：上一行結餘 ＋ 收入 － 支出。
4. 三天結束後，把收入欄全部加起來、支出欄全部加起來，填在「合計」列。
5. 驗算：期初 ＋ 收入合計 － 支出合計，是不是等於最後一行的結餘？
6. 再把身上的現金**實際數一次**，和最後一行的結餘比較。

**你應該看到／得到**
- 一張至少 5 到 10 行的收支表，每一行都有結餘。
- 步驟 5 的驗算應該相等；如果不等，從頭一行一行重算，通常是某一行的加減算錯。
- 步驟 6 如果實際現金比帳上少，表示有某筆支出你忘了記；比帳上多，表示有收入沒記（或你把不是現金的東西記進去了）。把差額寫下來，想一想是哪一筆。

### 活動 1-2：追蹤小明的 70,000 元

**材料／工具**
- 紙、筆、計算機
- 本章的「小明文具行設定表」

**步驟**
1. 用活動 1-1 的表格格式，幫小明記下開幕前（10 月 1 日到 4 日）每一筆**動到現金**的交易。期初是 0 元（開店前，店裡沒有任何錢）。
2. 收進來的錢有兩筆：小明自己投入的、跟銀行借的。先記這兩筆，算出結餘。
3. 付出去的錢有三筆：預付 3 個月租金、收銀電腦、現金進貨。按照設定表的日期一筆一筆記，每記一筆算一次結餘。注意 10 月 3 日賒帳進的 15,000 元貨，錢還沒付，所以**不會**出現在現金的帳上。
4. 算出收入合計、支出合計，驗算期末結餘。
5. 回答：10 月 4 日晚上，收銀機裡應該有多少錢？和本章「錢從哪裡來／錢變成了什麼」那張圖的數字一樣嗎？
6. 挑戰：如果銀行不借他 20,000 元，小明只有 50,000 元，照設定表買完所有東西之後，錢夠不夠？剩多少？想一想 10 月 10 日他要付給批發商 10,000 元，到時候付得出來嗎？

**你應該看到／得到**
- 一張 5 筆交易的收支表，期末結餘 29,000 元。
- 收入合計 70,000、支出合計 41,000。
- 步驟 6 你會發現錢還夠，但只剩 9,000 元；10 月 10 日要付批發商 10,000 元就付不出來了。可能的調整例如第一批少進一點貨，或跟批發商談晚一點付。

## 用工具看看

這一節我們把活動 1-1 的手寫帳本搬進 Google 試算表，讓它自己算結餘。以後每一章都會在這份檔案上加東西，所以請好好保存。

**步驟**

1. 打開瀏覽器，進入 [sheets.google.com](https://sheets.google.com)，登入 Google 帳號，點左上角的「＋」（空白試算表）。
2. 點左上角的檔名「未命名的試算表」，改成「我的帳本」。
3. 在第 1 列輸入標題：A1 打 `日期`、B1 打 `摘要`、C1 打 `收入`、D1 打 `支出`、E1 打 `結餘`。
4. 第 2 列是期初：B2 打 `期初`，E2 打你的期初現金（例如 `120`）。
5. 從第 3 列開始，把活動 1-1 的每一筆帳打進去：日期打在 A 欄、摘要打在 B 欄、金額打在 C 欄或 D 欄。
6. 在 E3 輸入公式：`=E2+C3-D3`，按 Enter。你會看到 E3 自動算出第一筆之後的結餘。
7. 點一下 E3，把游標移到儲存格右下角的小方塊，游標會變成「＋」，按住往下拉到你最後一筆帳的那一列。每一列的結餘就都自動算好了。
8. 在最後一筆的下一列，B 欄打 `合計`，C 欄打 `=SUM(C3:C20)`，D 欄打 `=SUM(D3:D20)`（把 20 換成你最後一筆的列號，或者乾脆多留幾列也沒關係，空白格 SUM 會當成 0）。
9. 再往下一列，B 欄打 `驗算`，E 欄打 `=E2+C21-D21`（21 是你合計那一列的列號）。這一格的數字應該和最後一筆的結餘一模一樣。

**你應該看到**

| | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | 日期 | 摘要 | 收入 | 支出 | 結餘 |
| 2 | | 期初 | | | 120 |
| 3 | 10/6 | 零用錢 | 300 | | 420 |
| 4 | 10/6 | 早餐飲料 | | 35 | 385 |
| … | | | | | |
| 11 | | 合計 | 500 | 320 | |
| 12 | | 驗算 | | | 300 |

試著改一個數字，例如把 10/6 的飲料從 35 改成 45，看結餘欄怎麼一路跟著變。這就是試算表的好處：公式拉好之後，改一個數字，後面全部自動重算。手寫帳本改一個數字要重算後面每一行，試算表只要改一格。

## 常見錯誤與迷思

- **「小錢不用記，記大的就好」→** 小安蒸發的 380 元裡，沒有一筆超過 100 元。錢最常從小筆、頻繁的支出漏掉。→ **每一筆都記，尤其是小的。** 一杯飲料 35 元，一週 6 杯就 210 元。
- **「我月底再一次補記」→** 三天前買了什麼你都記不得了，一個月後只會更糟；補記出來的帳一定有遺漏，驗算就會不平。→ **當天記，最晚隔天早上記。** 養成「付完錢就寫一行」的習慣，比什麼技巧都有用。
- **「打算要花的錢先記進去」→** 小安想買一支 500 元的筆，先記了一筆支出 500，結果沒買，帳就錯了。→ **錢真的動了才記。** 計畫是預算（第 13 章），不是帳。
- **「記帳是為了省錢」→** 不一定。記帳是為了**看見**；看見之後你可能決定省，也可能決定「這筆值得」。小明買電腦花 12,000 元不是浪費，是投資。→ **記帳是讓你做決定時有根據，不是叫你什麼都不要買。**
- **「會計只有公司需要」→** 你的零用錢、一個社團的經費、一次班遊的費用，全都需要。規模不同，道理一樣。→ **只要有錢進出，就有帳可記。**
- **「結餘不對，差一點點沒關係」→** 差 5 元看起來沒什麼，但表示有某一筆你不知道去哪了，下次可能是 500。→ **帳不平就找出原因。** 真的找不到，寫一筆「不明差額」，至少讓帳平回來，並且知道自己哪一天漏記。

## 想一想

1. 下面哪些是「交易」？哪些不是？說出理由。
   (a) 你用 60 元買了一本筆記本。
   (b) 你看到一雙 1,200 元的球鞋很想買。
   (c) 媽媽答應下個月零用錢加 50 元。
   (d) 你把 500 元存進郵局帳戶。
   (e) 小明的店今天來了 30 個客人逛逛，但沒人買東西。

<details><summary>參考答案</summary>

(a) 是，現金少了 60 元、筆記本多了一本。(b) 不是，什麼都沒改變。(c) 不是，承諾不是錢，等下個月真的拿到才記。(d) 是，雖然錢沒有變少（從口袋移到帳戶），但你擁有的錢換了地方，要記下來，否則口袋的帳會不平。(e) 不是，逛逛沒有讓錢或東西改變。

</details>

2. 小安的帳本裡，如果 10/7 他沒有借阿哲 50 元，三天結束後結餘會是多少？請用「期初 ＋ 收入 － 支出」驗算。

<details><summary>參考答案</summary>

支出合計變成 320 － 50 ＝ 270，結餘 ＝ 120 ＋ 500 － 270 ＝ 350 元。

</details>

3. 小明如果不向銀行借錢，只用自己的 50,000 元，照設定表買完東西之後錢夠不夠？剩多少？接下來會遇到什麼問題？

<details><summary>參考答案</summary>

開幕前的現金支出 24,000 ＋ 12,000 ＋ 5,000 ＝ 41,000，50,000 － 41,000 ＝ 9,000，買得完，但收銀機只剩 9,000 元。10 月 10 日他要付給批發商 10,000 元，到時候就付不出來了（除非開幕後的一週賣得夠多）。所以不是「買不買得起」的問題，而是「之後撐不撐得住」的問題；實際上開店要留更多現金才安全。

</details>

4. 請列出三種會看小明文具行的帳的人，並寫出每一種人「最想知道的一個問題」。

<details><summary>參考答案</summary>

例如：銀行想知道「每個月的利息、兩年後的 20,000 元本金收得回來嗎」；供應商想知道「這家店付得出貨款嗎」；政府想知道「今年賺多少、該繳多少稅」；小明自己想知道「哪些文具最好賣」。答案不只一種，重點是不同的人看同一本帳想問的事不一樣。

</details>

5. （開放挑戰）小明如果只記「收銀機裡的現金」，有哪些重要的事情是他會看不到的？至少舉兩件。

<details><summary>參考答案</summary>

例如：(1) 他欠銀行 20,000 元、欠批發商 15,000 元這兩件事，在現金帳裡看不出來，到了要還的時候才發現錢不夠。(2) 架上還有多少貨、值多少錢，現金帳看不到；他可能以為錢變少是賠了，其實錢變成了貨。(3) 電腦值多少、用舊了之後值多少，現金帳也看不到。第 2 章要解決的就是這個問題：不只記現金，而是記「所有你擁有的」和「所有你欠的」。

</details>

6. （開放挑戰）幫你們家設計一張「家庭一週收支表」。除了日期、摘要、收入、支出、結餘，你覺得還應該加哪些欄位？為什麼？和家人討論看看。

<details><summary>參考答案</summary>

常見的加法有：「類別」（飲食、交通、教育……這樣月底可以看哪一類花最多，第 3 章會用到）、「誰花的」、「付款方式」（現金、信用卡、悠遊卡，因為信用卡是先消費後付錢，第 2 章的負債概念）。沒有標準答案，但每加一欄都要說得出「月底我想用它看出什麼」。

</details>

## 本章小結

- 會計是「記錄 → 分類 → 彙總 → 報告」錢的流動的一套方法；其中「記錄」這一步叫簿記。
- 看帳的人不只老闆：出錢的人、銀行、政府、供應商、員工都靠帳來了解一家店，所以記帳要用大家共用的規則。
- 記帳的三個好處是看見（錢去哪了）、衡量（賺或賠）、決定（下一步怎麼做），附帶的好處是留下證據。
- 只有「錢或東西真的改變、而且可以用金額衡量」的事才是交易，才要記帳；計畫和承諾不記。
- 一筆帳要有日期、摘要、收入、支出、結餘；每次記完都要驗算：期初 ＋ 收入合計 － 支出合計 ＝ 期末結餘。
- 小明文具行的設定表是全書的基礎：資本 50,000、銀行借款 20,000、月租 8,000（一次預付 3 個月 24,000）、收銀電腦 12,000、第一個月進貨 20,000（15,000 賒帳、5,000 付現），開幕前剩現金 29,000。
- 錢不會憑空出現或消失，每一塊錢都有來處和去處；「來處合計 ＝ 去處合計」是整本書最核心的觀念。
