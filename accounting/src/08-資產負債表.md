# 第 8 章　資產負債表

## 本章目標

- 學完你會說出資產負債表是「某一天的財務照片」，而不是「一段時間的紀錄」。
- 學完你會從調整後試算表挑出資產、負債、權益科目，三個步驟編出一張資產負債表。
- 學完你會分辨「流動」與「非流動」，知道為什麼要分、分錯會有什麼問題。
- 學完你會把累計折舊正確地放在資產底下當減項，算出設備的帳面價值。
- 學完你會看懂一家真實上市公司的資產負債表（簡化版）的大結構。

## 開場：媽媽問「所以店裡現在到底有多少錢？」

小明文具行開張滿一個月的那天晚上，媽媽端著水果走進房間，看到小明桌上攤著厚厚一疊日記帳、分類帳、試算表，密密麻麻全是數字。

媽媽問：「所以呢？你這家店現在到底值多少？你欠別人多少？別人欠你多少？」

小明愣住了。這些問題的答案全都在帳本裡沒錯，可是他得翻好幾頁、加好幾次才答得出來。媽媽要的不是一疊帳，而是「一張紙就能看懂的總結」。

這就是**財務報表（Financial Statements）**存在的理由。前面七章做的所有事——記分錄、過帳、試算、調整——都是在「整理食材」；從這一章開始，我們把食材端上桌，做成三道菜：資產負債表、損益表、現金流量表。第一道菜，就是回答媽媽那個問題的**資產負債表（Balance Sheet）**。

## 核心概念

### 資產負債表是「某一天的照片」

資產負債表回答的問題是：**在某一個特定的日子，這家店擁有什麼、欠什麼、真正屬於老闆的有多少。**

注意「某一個特定的日子」這幾個字。資產負債表不是記「這個月發生了什麼」，而是像拍照一樣，在 10 月 31 日晚上打烊那一刻「喀嚓」一聲，把店裡所有東西的狀態凍結起來。所以報表標題一定寫「10 月 31 日」，而不是「10 月」。

你在第 2 章學過的會計方程式，就是資產負債表的骨架：

```
資產 = 負債 + 權益

  你擁有的   =   你欠別人的   +   真正是你的
```

資產負債表就是把這條方程式攤開來寫：左邊（或上面）列資產，右邊（或下面）列負債和權益，兩邊的總數一定要一樣。「Balance Sheet」這個英文名字裡的 Balance，就是「平衡」的意思。

### 從試算表到資產負債表：三個步驟

把調整後試算表變成資產負債表，只要三步：

**第一步：把科目分成兩堆。**

試算表上有 20 個科目，其中有一堆是「照片型」的（資產、負債、權益），另一堆是「影片型」的（收入、費用，記錄一段時間的流動）。資產負債表只要照片型的那堆。

| 照片型（留下來） | 影片型（下一章用） |
|---|---|
| 現金、應收帳款、存貨、預付租金、設備、累計折舊 | 銷貨收入、銷貨成本 |
| 應付帳款、應付費用、銀行借款 | 租金費用、水電費、薪資費用、廣告費、折舊費用、利息費用、雜項費用 |
| 業主資本、業主提取 | |

**第二步：算出本期淨利，加進權益。**

影片型的科目雖然不直接上資產負債表，但它們的「結果」會。收入減掉所有成本和費用，剩下的叫**淨利（Net Income）**，它會讓老闆的權益變多（如果是虧損就變少）。

```
淨利 = 30,000 − 15,000 − 8,000 − 1,500 − 3,000 − 500 − 200 − 100 − 700 = 1,000
```

權益還有一個減項要處理：小明 10/28 從店裡拿走的 2,000 元**業主提取**。它不是費用（不是為了做生意花的），所以不進淨利；但它確實讓真正屬於小明的那一份變少了，所以要從權益裡扣掉。期末的權益是：

```
期末權益 = 期初權益 0 + 業主投入 50,000 + 本期淨利 1,000 − 業主提取 2,000 = 49,000
```

這個 1,000 下一章會在損益表上再出現一次。記住它：**損益表的淨利會加進資產負債表的權益**（期末權益 = 期初權益 + 投入 + 淨利 − 提取），這是三張報表互相勾稽的第一條線。

**第三步：排版、分類、加總。**

把資產放一邊、負債和權益放另一邊，各自分組、加總，確認兩邊相等。分組的規則就是接下來要講的「流動」與「非流動」。

### 流動與非流動：一年內會不會變成現金、要不要付掉

想像你要去旅行一年，出門前你會想：「我身上的東西，哪些是一年內就會用掉或變成錢的？哪些是放著很久的？」

資產負債表用同樣的想法把資產和負債各分成兩類：

- **流動資產（Current Assets）**：一年內（或一個營業週期內）會變成現金或被用掉的東西。現金本身當然是；應收帳款下個月收回來就是現金；存貨賣掉就是現金；預付租金在 11、12 月就會「用掉」。
- **非流動資產（Non-current Assets）**：打算用超過一年的東西。電腦、店裡的貨架、冷氣、如果有買店面的話也算。
- **流動負債（Current Liabilities）**：一年內要還的錢。欠批發商的應付帳款、月底的水電費。
- **非流動負債（Non-current Liabilities）**：超過一年才要還的錢。小明跟銀行借的 20,000 元說好兩年後才還本金，所以是非流動。

為什麼要分？因為看報表的人最關心的一個問題是：「這家店**最近**付得出錢嗎？」把一年內要付的（流動負債）跟一年內會變成現金的（流動資產）放在一起比，馬上就看得出來。小明文具行流動資產 63,700 對上流動負債 6,500，很安全；如果反過來是 6,500 對 63,700，店很可能撐不過幾個月。第 11 章會把這個比較變成一個正式的比率。

習慣上，資產照「變成現金的速度」由快到慢排：現金最先，然後應收帳款、存貨、預付費用，最後才是設備。負債照「要付的時間」由近到遠排。

### 累計折舊：寫在資產下面的減項

電腦買的時候是 12,000 元，用了一個月之後，帳上要承認它「用掉」了一點點價值，這就是第 7 章學的折舊。但我們**不會直接把設備改成 11,800**。會計的做法是另開一個科目**累計折舊（Accumulated Depreciation）**，讓它一直累積，然後在資產負債表上寫成：

```
設備                12,000
減：累計折舊          (200)
設備淨額            11,800
```

這樣看報表的人同時看得到兩件事：這台電腦原來花了多少（12,000），以及到目前為止已經用掉多少（200）。扣完之後的 11,800 叫做**帳面價值（Book Value）**。累計折舊是「資產的減項」，它在試算表上在貸方，但它不是負債，別把它排到負債那邊去。

### 看一張真實公司的資產負債表（簡化版）

小明文具行的表只有十幾行，真正的上市公司動輒上百行，但骨架一模一樣。下面用台灣最大的公司台積電做例子，數字是從它公開的年度財報整理出來的**概數**，單位是「兆元」（1 兆 = 10,000 億）。真實數字每季都在變，請務必到「公開資訊觀測站」（網址 mops.twse.com.tw）查最新的財報，不要直接引用這裡的數字。

| 項目 | 約略金額（新台幣） | 對應小明文具行的 |
|---|---:|---|
| 流動資產（現金、應收帳款、存貨……） | 約 2 兆多 | 現金、應收帳款、存貨、預付租金 |
| 非流動資產（廠房、機器設備……） | 約 3 兆多 | 電腦 |
| **資產總計** | **約 5 兆多** | 75,500 |
| 流動負債 | 約 1 兆 | 應付帳款、應付費用 |
| 非流動負債 | 約 1 兆 | 銀行借款 |
| **負債合計** | **約 2 兆** | 26,500 |
| **權益合計** | **約 3 兆多** | 49,000 |

你會發現幾件事：

1. 台積電的非流動資產比流動資產多，因為它的錢大部分砸在蓋晶圓廠、買機器上；小明文具行相反，大部分是現金、貨和預付的租金。產業不同，資產的長相就不同。
2. 不管公司多大，「資產總計 = 負債合計 + 權益合計」一定成立。
3. 真實財報的權益會分成股本、資本公積、保留盈餘等好幾項，意思都是「真正屬於股東的那一塊」。先抓住大結構就好。

## 動手做

### 活動 8-1：用剪貼法編小明文具行的資產負債表

**材料／工具**：一張 A4 白紙、剪刀、膠水或紙膠帶、筆、本章的調整後試算表。

**步驟**：

1. 把調整後試算表的 20 個科目，每個科目連同金額抄在一張小紙條上（共 20 張）。
2. 先把「影片型」的 9 張（銷貨收入、銷貨成本、租金費用、水電費、薪資費用、廣告費、折舊費用、利息費用、雜項費用）挑出來放在旁邊，用它們算出淨利：收入減掉其他八個，應該得到 1,000。再寫一張新紙條「本期淨利 1,000」。
3. 把 A4 紙對折，左半邊寫「資產」，右半邊寫「負債與權益」。
4. 把剩下的 11 張紙條（含業主提取）加上「本期淨利」那張，一張一張貼到正確的那一半。貼之前先問自己：這是我擁有的（資產）、欠人的（負債）、還是真正屬於老闆的（權益）？業主提取要貼在權益區，但金額加上括號，表示要扣掉。
5. 在左半邊畫一條線，把資產分成「流動」與「非流動」兩區；右半邊的負債也分成兩區。累計折舊要貼在設備正下方，金額加上括號。
6. 每一區分別加總，再算左右總計。

**你應該看到／得到**：左邊總計 75,500、右邊總計 75,500。如果不相等，最常見的原因是累計折舊貼錯邊（貼到負債去了）、忘了加本期淨利，或是把業主提取當成加項。

**觀察與記錄**：

| 區塊 | 我貼了哪些科目 | 合計 |
|---|---|---:|
| 流動資產 | | |
| 非流動資產 | | |
| 流動負債 | | |
| 非流動負債 | | |
| 權益 | | |
| 左邊總計／右邊總計 | | |
| 第一次有沒有平衡？不平的原因是？ | | |

### 活動 8-2：幫自己拍一張財務照片，並分流動／非流動

**材料／工具**：筆記本、筆、計算機（手機的就可以）。

**步驟**：

1. 選定一個日期，例如「今天」。寫上標題：「（你的名字）的資產負債表　X 月 X 日」。
2. 列出你擁有的每一樣東西和它大概值多少錢：錢包和撲滿裡的現金、存在銀行或郵局的錢、別人欠你還沒還的錢、你準備拿去賣的二手書或遊戲卡、你的腳踏車、手機、電腦（用現在能賣多少來估，不要用當初買的價錢）。
3. 把它們分成兩堆：一年內會變成錢或用掉的放「流動資產」，會用很久的放「非流動資產」。
4. 列出你欠別人的：跟同學借的錢、答應要還爸媽的、分期付款還沒付完的。一年內要還的放「流動負債」，更久的放「非流動負債」。
5. 資產總計減掉負債總計，就是你的「權益」，也就是真正屬於你的淨值。
6. 把它排成跟小明文具行一樣的格式。

**你應該看到／得到**：一張兩邊總計相等的表（因為權益是用減法算出來的，所以一定會相等）。你可能會發現，很多「擁有的東西」其實一賣就不值錢了，這就是會計師常說的「資產要用能變成現金的價值來看」。

## 用工具看看

這一節我們在 Google 試算表做一張「會自己加總、自己檢查有沒有平衡」的資產負債表。

**步驟**：

1. 打開瀏覽器，到 sheets.google.com，按「＋」新增一個空白試算表，左上角把檔名改成「小明文具行-資產負債表」。
2. 在第 1 列打標題：A1 填「資產」、B1 填「金額」、D1 填「負債與權益」、E1 填「金額」。
3. 在 A 欄從 A2 開始依序填（A2 到 A12）：流動資產、現金、應收帳款、存貨、預付租金、流動資產合計、非流動資產、設備、減：累計折舊、設備淨額、資產總計。B 欄對應填金額：現金 40700、應收帳款 2000、存貨 5000、預付租金 16000、設備 12000、累計折舊填 **-200**（用負數，這樣加總時會自動扣掉）。
4. 在「流動資產合計」那一列（B7）輸入 `=SUM(B3:B6)`，應該出現 63700。
5. 在「設備淨額」那一列（B11）輸入 `=B9+B10`（設備加上負的累計折舊），應該出現 11800。
6. 在「資產總計」那一列（B12）輸入 `=B7+B11`（流動資產合計加設備淨額），應該出現 75500。
7. 在 D 欄從 D2 開始依序填（D2 到 D14）：流動負債、應付帳款、應付費用、流動負債合計、非流動負債、銀行借款、負債合計、權益、業主資本、本期淨利、減：業主提取、權益合計、負債與權益總計。E 欄填對應金額：應付帳款 5000、應付費用 1500、流動負債合計 `=SUM(E3:E4)`、銀行借款 20000、負債合計 `=E5+E7`（應該是 26500）、業主資本 50000、本期淨利 1000、業主提取填 **-2000**（一樣用負數）、權益合計 `=SUM(E10:E12)`（應該是 49000）、負債與權益總計 `=E8+E13`（應該是 75500）。
8. 在最下面空一列，A16 填「檢查」，B16 輸入 `=IF(B12=E14,"平衡 OK","不平衡！差 "&ABS(B12-E14))`（如果你的格子位置不同，把 B12 和 E14 換成你表上資產總計和負債與權益總計實際所在的格子）。

**你應該看到**：B16 顯示「平衡 OK」。接著試著把現金改成 37700，B16 會立刻變成「不平衡！差 3000」。改回來，又變回 OK。這就是試算表的好處：**公式會幫你盯著方程式**。

再多做一件事：把「本期淨利」那格先不要打 1000，改成輸入 `=30000-15000-8000-1500-3000-500-200-100-700`，試算表會算出 1000。下一章做完損益表之後，我們會把這一格直接連到損益表的淨利格子，讓兩張表自動勾稽。

## 常見錯誤與迷思

- **錯誤想法：資產負債表的標題寫「10 月」。** → 為什麼錯：資產負債表是某一天的照片，不是一段時間的影片。 → 正確理解：標題要寫「10 月 31 日」這種明確的日期；損益表和現金流量表才寫「10 月 1 日至 10 月 31 日」。
- **錯誤想法：累計折舊在貸方，所以是負債。** → 為什麼錯：累計折舊代表「設備已經用掉的部分」，它不是欠誰的錢。 → 正確理解：它是資產的減項，寫在設備正下方，用括號表示要扣掉；設備減累計折舊才是帳面價值。
- **錯誤想法：收入和費用也要列在資產負債表上。** → 為什麼錯：收入和費用是「影片型」科目，記的是一段時間內的流動。 → 正確理解：它們先在損益表算出淨利，淨利再以一個數字進入權益；資產負債表上只看得到結果。
- **錯誤想法：資產負債表上的現金 40,700 就是這個月賺的錢。** → 為什麼錯：現金裡有老闆投入的 50,000 和跟銀行借來的 20,000，跟賺不賺錢無關。 → 正確理解：賺多少看損益表的淨利（1,000）；現金是什麼都混在一起的「餘額」，兩者是不同的問題。
- **錯誤想法：老闆拿回家的 2,000 元是費用，要從淨利裡扣。** → 為什麼錯：費用是為了做生意花的錢，老闆的生活費不是。 → 正確理解：業主提取不進損益表，但它會讓權益變少，所以在資產負債表的權益區用括號寫成減項。
- **錯誤想法：設備要照「現在能賣多少」來記。** → 為什麼錯：會計一般用「當初花了多少」（成本）扣掉折舊來記，這樣數字才有憑有據。 → 正確理解：資產負債表上的設備淨額 11,800 是帳面價值，不等於市價；活動 8-2 幫自己估身價時用市價，是因為那是「給自己看」的表。

## 想一想

1. 小明文具行 10 月 31 日的流動資產有哪四項？合計多少？

<details><summary>參考答案</summary>

現金 40,700、應收帳款 2,000、存貨 5,000、預付租金 16,000，合計 63,700 元。

</details>

2. 如果小明跟銀行借的 20,000 元改成「說好下個月就還」，資產負債表哪裡會變？總計會變嗎？

<details><summary>參考答案</summary>

銀行借款要從「非流動負債」搬到「流動負債」。流動負債變成 26,500、非流動負債變成 0，但負債合計還是 26,500，資產總計和負債與權益總計都不變，仍然是 75,500。變的是「分類」，不是「金額」。

</details>

3. 電腦再用 11 個月之後（也就是開店滿一年時），累計折舊會是多少？設備淨額會是多少？

<details><summary>參考答案</summary>

每月折舊 200 元，12 個月共 2,400 元，累計折舊 2,400；設備淨額 = 12,000 − 2,400 = 9,600 元。

</details>

4. 11 月 5 日，小明用店裡的現金 3,000 元買了一個二手貨架，打算用好幾年。請寫出這筆交易會改變哪些科目、資產負債表的流動資產合計與非流動資產合計各變成多少。

<details><summary>參考答案</summary>

現金 −3,000（流動資產），設備 +3,000（非流動資產）。流動資產合計 63,700 − 3,000 = 60,700；非流動資產 11,800 + 3,000 = 14,800。資產總計仍是 75,500，因為只是資產內部搬家。

</details>

5. （挑戰）有一家店的資產負債表上，流動資產 20,000、流動負債 60,000、非流動資產 500,000、非流動負債 100,000。請算出它的權益，然後說說看：這家店「有錢」嗎？「安全」嗎？為什麼這兩個問題的答案可能不一樣？

<details><summary>參考答案</summary>

資產總計 520,000，負債合計 160,000，權益 360,000。從權益看，這家店「很有錢」（淨值 36 萬）；但從流動性看，它一年內要付 60,000，手上一年內能變成現金的只有 20,000，差了 40,000，除非把非流動資產（可能是店面或機器）賣掉，否則很可能付不出錢。所以「有錢」看權益，「安全」要看流動資產對流動負債，兩個答案可以完全不同。這就是為什麼資產負債表一定要分流動與非流動。

</details>

6. （挑戰）設計一筆交易，讓小明文具行的資產總計不變、負債總計不變、權益總計也不變，但資產負債表的內容確實變了。再設計另一筆交易，讓資產總計變少但權益不變。

<details><summary>參考答案</summary>

第一種：資產內部搬家，例如補習班付清 2,000 元應收帳款（現金 +2,000，應收帳款 −2,000），或是用現金買設備。第二種：用資產還負債，例如付清 5,000 元應付帳款（現金 −5,000，應付帳款 −5,000），資產總計與負債總計同時少 5,000，權益不動。答案不只一種，只要符合條件都算對。

</details>

## 本章小結

- 資產負債表是「某一天」的財務照片，標題要寫明確的日期；它就是會計方程式「資產 = 負債 + 權益」攤開來寫。
- 編製三步驟：挑出資產、負債、權益科目 → 用收入與費用算出淨利加進權益（再扣掉業主提取）→ 分類排版加總。
- 小明文具行 10 月 31 日：資產總計 75,500 = 負債 26,500 + 權益 49,000；權益裡的本期淨利 1,000 會跟下一章損益表的淨利一樣，業主提取 2,000 是權益的減項。
- 流動＝一年內會變現或要付掉；非流動＝超過一年。分開寫是為了看出公司「最近付不付得出錢」。
- 累計折舊是資產的減項，寫在設備下面，不是負債；設備減累計折舊 = 帳面價值。
- 現金餘額不等於賺的錢；賺多少要看損益表。
- 真實上市公司的資產負債表再長，骨架都跟小明文具行一樣；要看真實數字請上公開資訊觀測站。

|---|---|---|
| 財務報表 | Financial Statements | 把帳本整理成一兩張紙就能看懂的總結，主要有資產負債表、損益表、現金流量表三張。 |
| 資產負債表 | Balance Sheet | 某一天公司擁有什麼、欠什麼、真正屬於老闆多少的照片。 |
| 調整後試算表 | Adjusted Trial Balance | 做完期末調整分錄之後的試算表，是編所有報表的起點。 |
| 流動資產 | Current Assets | 一年內會變成現金或被用掉的資產，例如現金、應收帳款、存貨、預付費用。 |
| 非流動資產 | Non-current Assets | 打算用超過一年的資產，例如設備、房屋。 |
