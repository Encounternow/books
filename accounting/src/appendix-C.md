# 附錄 C　試算表帳本怎麼做

這一份附錄把全書「用工具看看」裡用到的試算表技巧整理成一套完整的做法：三張核心工作表（科目表、日記帳、分類帳）加上自動彙總。第 14 章專題二就是用這套方法做的；這裡講得更慢、更細，每一個公式都解釋它在做什麼。

全部用 Google 試算表示範，Excel 的函式名稱和寫法完全一樣。

## C.1　先懂三個函式

### SUM：把一段範圍加起來

```
=SUM(E2:E100)
```

把 E2 到 E100 全部加總。寫成 `=SUM(E:E)` 表示整個 E 欄，以後加資料不用改範圍。

### SUMIF：只加「符合條件」的

```
=SUMIF(條件範圍, 條件, 要加的範圍)
=SUMIF(日記帳!C:C, 1001, 日記帳!E:E)
```

讀法：「到日記帳的 C 欄找每一列，如果那一格等於 1001，就把同一列 E 欄的數字加進來。」這就是**過帳**：把日記帳裡所有「現金」的借方金額一次加總，等於分類帳現金科目的借方合計。

條件可以寫死（1001），也可以指向一格（A2），這樣往下拉時每一列會自動換成自己的代號。

### VLOOKUP：用代號查名稱

```
=VLOOKUP(要找的值, 查找範圍, 回傳第幾欄, FALSE)
=VLOOKUP(1001, 科目表!A:D, 2, FALSE)
```

讀法：「到科目表 A 到 D 欄，在**第一欄**（A）找 1001，找到後回傳那一列的第 2 欄（B，科目名稱）。」最後的 FALSE 表示「要完全相等才算找到」，記帳一定要用 FALSE。

找不到會顯示 `#N/A`。用 `IFERROR` 包起來可以改顯示空白：

```
=IFERROR(VLOOKUP(C2,科目表!$A:$D,2,FALSE),"")
```

### 錢字號 `$` 是什麼

`$A:$D` 的 `$` 叫**絕對參照**：公式往下拉或往右拉的時候，這部分不會跟著移動。查找範圍、條件範圍都要加 `$`；要變動的（例如每一列自己的代號 A2）不加。

## C.2　第一張：科目表

1. 新增試算表，命名「我的帳本」。把第一張工作表改名「科目表」。
2. 第 1 列填表頭：A1 代號、B1 科目名稱、C1 類別、D1 正常餘額。
3. 從第 2 列開始填科目。可以直接用附錄 A，或用下面這組小明文具行的 20 個科目（和第 5 章一樣，占第 2 到 21 列）：

| 代號 | 科目名稱 | 類別 | 正常餘額 |
|---|---|---|---|
| 1001 | 現金 | 資產 | 借 |
| 1101 | 應收帳款 | 資產 | 借 |
| 1201 | 存貨 | 資產 | 借 |
| 1301 | 預付租金 | 資產 | 借 |
| 1501 | 設備 | 資產 | 借 |
| 1502 | 累計折舊－設備 | 資產 | 貸 |
| 2001 | 應付帳款 | 負債 | 貸 |
| 2101 | 應付費用 | 負債 | 貸 |
| 2201 | 銀行借款 | 負債 | 貸 |
| 3001 | 業主資本 | 權益 | 貸 |
| 3002 | 業主提取 | 權益 | 借 |
| 4001 | 銷貨收入 | 收入 | 貸 |
| 5001 | 銷貨成本 | 成本 | 借 |
| 5101 | 租金費用 | 費用 | 借 |

4. 選取 A 欄，「格式 → 數字 → 數字」，確定代號是數字格式，不是文字。這是最常見的 `#N/A` 原因。

## C.3　第二張：日記帳

這是你**唯一要手動輸入**的工作表。

1. 新增工作表，改名「日記帳」。
2. 表頭：A1 日期、B1 編號、C1 科目代號、D1 科目名稱、E1 借方、F1 貸方、G1 摘要。
3. D2 輸入：

   ```
   =IF(C2="","",VLOOKUP(C2,科目表!$A:$D,2,FALSE))
   ```

   往下拉到第 500 列（選 D2，複製，選 D3:D500，貼上）。C 欄空白時 D 欄也空白，不會滿頁 `#N/A`。
4. 讓 C 欄變成下拉選單：選取 C2:C500，「資料 → 資料驗證」，條件選「下拉式選單（來自範圍）」，範圍填 `科目表!$A$2:$A$21`（有幾個科目就填到第幾列）。以後點一下就能選代號。
5. 做借貸檢查：I1 填「借方合計」、I2 填 `=SUM(E:E)`；J1 填「貸方合計」、J2 填 `=SUM(F:F)`；K1 填「檢查」、K2 填：

   ```
   =IF(I2=J2,"✓ 借貸相等","✗ 差 "&ABS(I2-J2))
   ```

6. 輸入規則：
   - 一筆交易用**同一個編號**，占兩列以上。
   - 借方那一列只填 E，貸方那一列只填 F。
   - 日期用「2026/10/1」這種格式，試算表會認得。
   - 摘要寫一樣的字，方便之後篩選。

範例（小明文具行前兩筆）：

| 日期 | 編號 | 科目代號 | 科目名稱 | 借方 | 貸方 | 摘要 |
|---|---|---|---|---|---|---|
| 2026/10/1 | 001 | 1001 | 現金 | 50,000 | | 投入資本 |
| 2026/10/1 | 001 | 3001 | 業主資本 | | 50,000 | 投入資本 |
| 2026/10/1 | 002 | 1001 | 現金 | 20,000 | | 向銀行借款 |
| 2026/10/1 | 002 | 2201 | 銀行借款 | | 20,000 | 向銀行借款 |

### 檢查每一筆分錄是否平衡（加分）

在 H1 填「本筆檢查」，H2 填：

```
=IF(B2="","",IF(SUMIF($B:$B,B2,$E:$E)=SUMIF($B:$B,B2,$F:$F),"","✗"))
```

意思：把同一個編號的借方加總、貸方加總，不相等就顯示 ✗。往下拉。這樣哪一筆分錄少記一邊，當場看得到。

## C.4　第三張：分類帳（用 SUMIF 自動過帳）

1. 新增工作表，改名「分類帳」。
2. 表頭：A1 代號、B1 科目名稱、C1 類別、D1 正常餘額、E1 借方合計、F1 貸方合計、G1 餘額。
3. 第 2 列：

   ```
   A2: =科目表!A2
   B2: =科目表!B2
   C2: =科目表!C2
   D2: =科目表!D2
   E2: =SUMIF(日記帳!$C:$C,A2,日記帳!$E:$E)
   F2: =SUMIF(日記帳!$C:$C,A2,日記帳!$F:$F)
   G2: =IF(D2="借",E2-F2,F2-E2)
   ```

4. 選取 A2:G2，往下拉到科目表的最後一列（20 個科目就拉到第 21 列）。
5. 第 23 列做總檢查：E23 `=SUM(E2:E21)`、F23 `=SUM(F2:F21)`。這兩個數應該等於日記帳的 I2、J2。

每一格在做什麼：

- A 到 D 欄直接「抄」科目表，以後科目表改名，這裡自動跟著改。
- E 欄：到日記帳找所有代號等於 A2 的列，把借方加起來。這一格就是傳統分類帳裡「借方那一欄的合計」。
- F 欄：同樣的事，加貸方。
- G 欄：餘額。正常餘額在借方的科目（資產、成本、費用）用借減貸；在貸方的（負債、權益、收入）用貸減借。正常情況下 G 欄都是正數；如果出現負數，通常表示記錯方向（例如現金變負的，表示付出去的比收進來的多，現實上不可能）。

### 想看某一個科目的明細（T 字帳）

Google 試算表有 `FILTER` 函式。新增工作表「明細」，A1 填你要看的代號（例如 1001），A3 填：

```
=FILTER(日記帳!A:G, 日記帳!C:C=A1)
```

它會列出日記帳裡所有這個科目的分錄，就像翻開傳統分類帳的那一頁。改 A1 的代號就換科目。（Excel 2021 以後也有 FILTER；舊版 Excel 可以改用「資料 → 篩選」手動篩。）

## C.5　第四張：試算表

1. 新增工作表「試算表」。表頭：A1 代號、B1 科目名稱、C1 借方餘額、D1 貸方餘額。
2. 第 2 列：

   ```
   A2: =分類帳!A2
   B2: =分類帳!B2
   C2: =IF(分類帳!$D2="借",分類帳!$G2,0)
   D2: =IF(分類帳!$D2="貸",分類帳!$G2,0)
   ```

3. 往下拉到第 21 列。
4. 第 22 列：B22「合計」、C22 `=SUM(C2:C21)`、D22 `=SUM(D2:D21)`、E22 `=IF(C22=D22,"✓ 平衡","✗ 差 "&ABS(C22-D22))`。

跟日記帳的借貸檢查有什麼不同？日記帳檢查的是「每一筆有沒有兩邊都記」，試算表檢查的是「過帳和餘額計算有沒有錯」。兩個都通過，帳才算乾淨。

## C.6　報表：用 VLOOKUP 抓餘額

### 損益表

新增工作表「損益表」。每一行用 VLOOKUP 到分類帳抓第 7 欄（G，餘額）：

| A | B |
|---|---|
| 銷貨收入 | `=VLOOKUP(4001,分類帳!$A:$G,7,FALSE)` |
| 銷貨成本 | `=VLOOKUP(5001,分類帳!$A:$G,7,FALSE)` |
| 毛利 | `=B1-B2` |
| 毛利率 | `=IF(B1=0,"",B3/B1)` |
| 租金費用 | `=VLOOKUP(5101,分類帳!$A:$G,7,FALSE)` |
| 水電費 | `=VLOOKUP(5102,分類帳!$A:$G,7,FALSE)` |
| 薪資費用 | `=VLOOKUP(5103,分類帳!$A:$G,7,FALSE)` |
| 廣告費 | `=VLOOKUP(5104,分類帳!$A:$G,7,FALSE)` |
| 折舊費用 | `=VLOOKUP(5105,分類帳!$A:$G,7,FALSE)` |
| 雜項費用 | `=VLOOKUP(5107,分類帳!$A:$G,7,FALSE)` |
| 營業費用合計 | `=SUM(B5:B10)` |
| 營業利益 | `=B3-B11` |
| 利息費用 | `=VLOOKUP(5106,分類帳!$A:$G,7,FALSE)` |
| 本期淨利 | `=B12-B13` |

科目多的時候，一行一行 VLOOKUP 很累。另一個做法是按**類別**彙總：

```
收入合計 =SUMIF(分類帳!$C:$C,"收入",分類帳!$G:$G)
成本合計 =SUMIF(分類帳!$C:$C,"成本",分類帳!$G:$G)
費用合計 =SUMIF(分類帳!$C:$C,"費用",分類帳!$G:$G)
```

這就是「用類別當條件的 SUMIF」。只要科目表的類別填對，新加的科目會自動被算進去。

### 資產負債表

新增工作表「資產負債表」：

| A | B | C | D |
|---|---|---|---|
| 現金 | `=VLOOKUP(1001,分類帳!$A:$G,7,FALSE)` | 應付帳款 | `=VLOOKUP(2001,分類帳!$A:$G,7,FALSE)` |
| 應收帳款 | `=VLOOKUP(1101,分類帳!$A:$G,7,FALSE)` | 應付費用 | `=VLOOKUP(2101,分類帳!$A:$G,7,FALSE)` |
| 存貨 | `=VLOOKUP(1201,分類帳!$A:$G,7,FALSE)` | 銀行借款 | `=VLOOKUP(2201,分類帳!$A:$G,7,FALSE)` |
| 預付租金 | `=VLOOKUP(1301,分類帳!$A:$G,7,FALSE)` | 負債合計 | `=D1+D2+D3` |
| 設備 | `=VLOOKUP(1501,分類帳!$A:$G,7,FALSE)` | 業主資本 | `=VLOOKUP(3001,分類帳!$A:$G,7,FALSE)` |
| 減：累計折舊 | `=-VLOOKUP(1502,分類帳!$A:$G,7,FALSE)` | 本期淨利 | `=損益表!B14` |
| 資產合計 | `=SUM(B1:B6)` | 減：業主提取 | `=-VLOOKUP(3002,分類帳!$A:$G,7,FALSE)` |
| 檢查 | `=IF(B7=D8,"✓ 平衡","✗ 差 "&ABS(B7-D8))` | 負債＋權益 | `=D4+D5+D6+D7` |

兩個地方要注意：

- **累計折舊加負號**。它在分類帳的餘額是正的 200（因為正常餘額在貸方，公式用貸減借），放進資產要扣掉，所以前面加 `-`。業主提取也是同樣的道理：它是權益的減項，放進權益要扣掉，前面也加 `-`。
- **本期淨利直接連到損益表**，不要手打。這樣損益表一動，資產負債表自動跟著動，而且這條連結正是「三張報表相連」的證明。

### 用類別彙總做資產負債表的檢查（加分）

```
資產合計（含減項） =SUMIF(分類帳!$C:$C,"資產",分類帳!$G:$G) - 2*VLOOKUP(1502,分類帳!$A:$G,7,FALSE)
```

為什麼減兩倍？因為 SUMIF 把累計折舊當正數加進去了，要先減掉一次變成「沒算它」，再減一次才是「扣掉它」。權益裡的業主提取也是減項，用類別彙總時要一樣處理。這種減項科目一多就很容易漏，所以本書主要用一行一行 VLOOKUP 的方法，看得清楚。

## C.7　每個月怎麼用

1. 月初：複製上個月的檔案（檔案 → 建立副本），改名「帳本 2026-11」。清空日記帳的交易，但**不要**清公式。
2. 把上月底的資產負債表餘額當「開帳分錄」打進日記帳第一筆：借各項資產（累計折舊記貸方）、貸各項負債和業主資本；上月淨利併進業主資本。
3. 整個月只打日記帳。
4. 月底打調整分錄（折舊、應付、預付、盤點）。
5. 看試算表是否「✓ 平衡」、資產負債表是否「✓ 平衡」。
6. 把損益表、資產負債表列印或截圖存檔。

## C.8　常見問題排除

| 症狀 | 原因 | 解法 |
|---|---|---|
| D 欄顯示 `#N/A` | 代號在科目表裡沒有，或代號是文字格式 | 檢查科目表；把日記帳 C 欄和科目表 A 欄都設成「數字」 |
| SUMIF 算出 0 | 條件範圍和加總範圍不在同一張工作表、或代號格式不一致 | 兩個範圍都要寫 `日記帳!`；代號格式統一 |
| 分類帳餘額是負數 | 這個科目記反方向，或正常餘額欄填錯 | 用 FILTER 看明細，找哪一筆方向反了 |
| 試算表差一個偶數 | 某筆借貸寫反 | 差額 ÷ 2，找這個金額的分錄 |
| 試算表差額能被 9 整除 | 數字顛倒 | 找兩個數字對調後剛好差這麼多的分錄 |
| 資產負債表不平、試算表卻平 | 淨利手打、或漏了某個科目的 VLOOKUP | 確認本期淨利是公式；把試算表每個科目對一次 |
| 加新科目後報表沒變 | 分類帳和試算表沒往下拉到新科目那一列 | 往下拉公式；下拉選單範圍也要擴大 |
