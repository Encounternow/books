# 第 13 章　預算與控制

## 本章目標

- 學完你會說出預算是什麼、為什麼「先寫下來」比「心裡有數」有用。
- 學完你會替自己和小明文具行編一份下個月的營業預算。
- 學完你會做預算與實際的差異分析，分辨「有利差異」和「不利差異」，並用彈性預算把差異拆成「賣得少」和「花得多」兩部分。
- 學完你會編一張三個月的現金預算，看出哪個月會缺錢。
- 學完你會用「例外管理」的原則決定哪些差異值得追、哪些可以放過。

## 開場：月底的錢去哪了？

小明文具行開張第一個月，帳結出來賺了 1,000 元。小明很開心，想第二個月多進一點貨、再買一台冷氣，讓店裡夏天涼一點。但他爸爸問了一句：「你算過下個月要花多少、會收多少嗎？冷氣買下去，月底付貨款的時候錢夠不夠？」

小明愣住了。他每一筆帳都記得清清楚楚，可是那些都是「已經發生」的事。爸爸問的是「還沒發生」的事。

小明的妹妹小美也有一樣的困擾。她每個月有 2,000 元零用錢，常常到了月底只剩幾十塊，但問她錢花去哪，她只能說「吃東西吧」。她明明每天都有記帳，為什麼還是不知道？

答案是：記帳只告訴你**過去**，要管住錢，還需要一張寫下**未來打算怎麼花**的表。這張表叫**預算（Budget）**。這一章我們學怎麼做預算、怎麼在月底對照、怎麼用這個差距改善下個月。

## 核心概念

### 預算是什麼：把「打算」寫成數字

**預算（Budget）** 是一份用數字寫的計畫：下個月（或下一年）預計收多少、花多少、剩多少。它和帳本的差別只有一個字：帳本記「已經」，預算寫「打算」。

為什麼要寫下來？因為人腦對錢的感覺非常不準。小美「覺得」自己一個月吃東西花 500 元，實際記帳一算是 950 元。寫下預算，等於先跟自己約定「吃東西最多 800 元」，月中發現已經花 700 元，就知道要收手。

預算在公司裡還有第二個用途：**協調**。進貨的人要知道能花多少、賣東西的人要知道目標多少、管錢的人要知道哪天付款。大家看同一份預算，才不會各做各的。

### 預算、執行、比較、修正：控制的循環

光有預算沒用，要搭配**控制（Control）**：執行完回頭對照，找出差距，改進下一次。這四步繞成一個圈：

```
        ┌─────────────┐
   ┌───►│ 1. 編預算   │
   │    └──────┬──────┘
   │           ▼
   │    ┌─────────────┐
   │    │ 2. 照著執行 │
   │    └──────┬──────┘
   │           ▼
   │    ┌─────────────┐
   │    │ 3. 月底比較 │ ← 預算 vs 實際，算差異
   │    └──────┬──────┘
   │           ▼
   │    ┌─────────────┐
   └────│ 4. 找原因、 │
        │    修正下月 │
        └─────────────┘
```

第 3 步就是本章的重點：**差異分析（Variance Analysis）**。

### 先從自己開始：小美的零用錢預算

小美月初先把 2,000 元分配好：

| 項目 | 預算（元） | 怎麼估的 |
|---|---|---|
| 午餐加點心 | 800 | 上個月記帳是 950，這個月打算少買飲料 |
| 文具 | 300 | 月中要買新的筆記本和筆 |
| 交通 | 200 | 公車卡每週儲值 50 |
| 娛樂（遊戲、看電影） | 400 | 跟同學約好看一場電影 |
| 儲蓄 | 300 | 存給半年後的畢業旅行 |
| **合計** | **2,000** | 剛好等於收入 |

月底把實際的帳拿來對照：

| 項目 | 預算 | 實際 | 差異（預算 − 實際） | 判斷 |
|---|---|---|---|---|
| 午餐加點心 | 800 | 950 | −150 | 不利 |
| 文具 | 300 | 250 | +50 | 有利 |
| 交通 | 200 | 200 | 0 | — |
| 娛樂 | 400 | 550 | −150 | 不利 |
| 儲蓄 | 300 | 50 | −250 | 不利 |
| **合計** | **2,000** | **2,000** | **0** | |

這裡要先講清楚什麼叫**有利差異（Favorable Variance）** 和**不利差異（Unfavorable Variance）**：

- 費用：實際比預算**少**，是有利（省到錢）；實際比預算**多**，是不利。
- 收入：實際比預算**多**，是有利；實際比預算**少**，是不利。
- 儲蓄跟收入一樣，存得比預算少是不利。

小美看到表格就明白了：她多吃了 150、多玩了 150，這 300 元直接從儲蓄裡被挖走，加上本來就沒存滿，儲蓄只剩 50 元。沒有預算的時候，她只知道「錢不見了」；有了預算，她知道「不見的是娛樂和點心」。下個月她可以決定：娛樂預算提高到 500 比較實際，點心真的要忍一下。

### 小明文具行的營業預算

公司的預算比零用錢多幾行，但邏輯一樣。小明根據第一個月（10 月）的經驗，編第二個月的**營業預算（Operating Budget）**。他的假設是：營業額成長 20%（第一個月 30,000 → 36,000）、進貨成本維持售價的 50%、固定支出不變。

| 項目 | 怎麼估 | 預算（元） |
|---|---|---|
| 銷貨收入 | 30,000 × 1.2 | 36,000 |
| 銷貨成本 | 36,000 × 50% | 18,000 |
| **毛利** | 36,000 − 18,000 | **18,000** |
| 租金 | 合約 | 8,000 |
| 水電 | 上月 | 1,500 |
| 薪資 | 工讀生 | 3,000 |
| 折舊 | 12,000 ÷ 60 個月 | 200 |
| 利息 | 銀行借款 | 100 |
| 雜項 | 網路費等 | 700 |
| **淨利** | 18,000 − 13,500 | **4,500** |

這份預算同時告訴他**進貨預算**：要賣 36,000 元的貨，成本 18,000 元，月初架上還剩 5,000 元存貨（10 月底盤點的數字），所以這個月要進 13,000 元的貨才夠（18,000 − 5,000）。如果想月底也留 5,000 元存貨，就進 18,000 元。這就是預算的「協調」功能：賣的目標決定了進的數量。

### 月底對照：差異分析

第二個月結束，實際數字出來了：

| 項目 | 預算 | 實際 | 差異（實際 − 預算） | 判斷 |
|---|---|---|---|---|
| 銷貨收入 | 36,000 | 33,000 | −3,000 | 不利 |
| 銷貨成本 | 18,000 | 17,000 | −1,000 | 有利？ |
| **毛利** | **18,000** | **16,000** | **−2,000** | 不利 |
| 租金 | 8,000 | 8,000 | 0 | — |
| 水電 | 1,500 | 2,100 | +600 | 不利 |
| 薪資 | 3,000 | 3,000 | 0 | — |
| 折舊 | 200 | 200 | 0 | — |
| 利息 | 100 | 100 | 0 | — |
| 雜項 | 700 | 700 | 0 | — |
| **淨利** | **4,500** | **1,900** | **−2,600** | 不利 |

注意這裡收入我用「實際 − 預算」，收入少了就是負數；費用也用「實際 − 預算」，費用多了是正數但是不利。為了不搞混，直接看「判斷」那一欄就好：**對淨利有好處的叫有利，有壞處的叫不利**。

驗算一下：毛利差異 −2,000、水電差異 −600，加起來 −2,600，剛好等於淨利差異 ✓。

小明看到兩件事：營業額少了 3,000，水電多了 600。水電多 600 很好解釋，天氣熱、電風扇開整天。營業額少 3,000 才是大事——是客人變少，還是每個客人買得少？這就要回去翻銷售紀錄。

### 彈性預算：把「賣得少」和「花得多」分開

上面有一格我打了問號：銷貨成本「有利」1,000 元。真的有利嗎？成本變少是因為**賣得少**啊，貨賣得少當然成本少，這不是省錢，是生意差。

要看清楚，得用**彈性預算（Flexible Budget）**：先問「如果當初就知道只賣 33,000，成本應該是多少？」

```
彈性預算的銷貨成本 = 33,000 × 50% = 16,500
```

實際成本是 17,000，比 16,500 多了 500。所以成本其實是**不利** 500 元——進價變貴了（成本率從 50% 跑到約 52%），或是有貨損壞報廢。

把毛利差異 −2,000 拆成兩塊：

| 差異來源 | 算法 | 金額 |
|---|---|---|
| 銷量差異（賣得少） | (33,000 − 36,000) × 50% 毛利率 | −1,500 |
| 成本差異（進價變貴） | 16,500 − 17,000 | −500 |
| **毛利差異合計** | | **−2,000** ✓ |

這樣就把兩件事分開了：「賣得少」要去找業務面的原因（促銷、天氣、對面開了新店）；「進價變貴」要去找採購面的原因（大盤漲價、換了供應商、有破損）。混在一起看，永遠只能說「生意不好」。

### 例外管理：不是每個差異都要追

差異表上每一行都有數字，如果每一塊錢都要追，老闆會累死。管理上用**例外管理（Management by Exception）** 的原則：先訂一個門檻，超過門檻的才追。

小明給自己的規則：**金額超過 500 元，或比例超過 10%，才要寫下原因。**

| 項目 | 差異 | 比例 | 超過門檻？ | 要追嗎 |
|---|---|---|---|---|
| 銷貨收入 | −3,000 | −8.3% | 金額超過 | 要 |
| 銷貨成本（彈性後） | −500 | −3.0% | 金額超過 | 要 |
| 水電 | −600 | −40% | 兩個都超過 | 要 |
| 租金 | 0 | 0% | 否 | 不用 |

門檻怎麼訂沒有標準答案，原則是「追這個差異花的時間，要值得它能省下的錢」。

### 現金預算：賺錢不等於有錢

第 10 章講過，賺錢的公司也可能倒，因為帳上有利潤、口袋沒現金。所以除了營業預算，還要編**現金預算（Cash Budget）**：一個月一個月算「期初有多少、收進多少、付出多少、月底剩多少」。

小明的狀況：第一個月（10 月）月底現金 40,700 元；補習班還欠 2,000 元，第 2 個月會收到；10 月賒帳進貨還欠批發商 5,000 元，第 2 個月要付清；10 月的水電費 1,500 元（已經估列成應付費用）第 2 個月付，以後每個月的水電也都是下個月才付；工讀生薪資 3,000、銀行利息 100、網路費等雜項 700，每個月照付。10 月 1 日預付的三個月租金到 12 月底用完，所以第 2、3 個月不用付租金，但第 4 個月（1 月）要再一次預付三個月 24,000 元。他打算第三個月買一台 15,000 元的冷氣。營業額預計 36,000 → 40,000 → 44,000，進貨維持營業額的 50%、貨到付現（存貨水位不變）。

**情境 A：客人都付現金**

| 項目 | 第 2 個月 | 第 3 個月 | 第 4 個月 |
|---|---|---|---|
| 期初現金 | 40,700 | 50,400 | 50,100 |
| ＋ 收到現金銷售 | 36,000 | 40,000 | 44,000 |
| ＋ 收到上月賒帳 | 2,000 | 0 | 0 |
| － 付進貨 | 18,000 | 20,000 | 22,000 |
| － 付 10 月欠批發商 | 5,000 | 0 | 0 |
| － 付租金（預付三個月） | 0 | 0 | 24,000 |
| － 付上月水電 | 1,500 | 1,500 | 1,500 |
| － 付薪資 | 3,000 | 3,000 | 3,000 |
| － 付利息 | 100 | 100 | 100 |
| － 付雜項 | 700 | 700 | 700 |
| － 買冷氣 | 0 | 15,000 | 0 |
| **期末現金** | **50,400** | **50,100** | **42,800** |

驗算第 2 個月：40,700 + 36,000 + 2,000 − 18,000 − 5,000 − 1,500 − 3,000 − 100 − 700 = 50,400 ✓。

看起來很安全。但小明想到一件事：補習班最近很喜歡跟他訂貨，而且都是月底結帳、下個月才付。假設以後每個月有 30% 的營業額是這種賒帳：

**情境 B：30% 營業額下個月才收到**

| 項目 | 第 2 個月 | 第 3 個月 | 第 4 個月 |
|---|---|---|---|
| 期初現金 | 40,700 | 39,600 | 38,100 |
| ＋ 當月現金銷售（70%） | 25,200 | 28,000 | 30,800 |
| ＋ 收到上月賒帳 | 2,000 | 10,800 | 12,000 |
| － 付進貨 | 18,000 | 20,000 | 22,000 |
| － 付 10 月欠批發商 | 5,000 | 0 | 0 |
| － 付租金（預付三個月） | 0 | 0 | 24,000 |
| － 付上月水電 | 1,500 | 1,500 | 1,500 |
| － 付薪資 | 3,000 | 3,000 | 3,000 |
| － 付利息 | 100 | 100 | 100 |
| － 付雜項 | 700 | 700 | 700 |
| － 買冷氣 | 0 | 15,000 | 0 |
| **期末現金** | **39,600** | **38,100** | **29,600** |

驗算第 3 個月：39,600 + 28,000 + 10,800 − 20,000 − 1,500 − 3,000 − 100 − 700 − 15,000 = 38,100 ✓。

兩個情境的營業額、利潤**完全一樣**，但情境 B 第 4 個月現金只剩 29,600 元。如果小明給自己訂的**安全現金水位**是 30,000 元（大約是一次三個月的預付租金再加一點零錢），第 4 個月就破線了。這時候他有幾個選擇：冷氣晚一點買、跟房東談改成每月付租金、或是請補習班改成貨到付款。重點是：**他在第 1 個月就知道第 4 個月會缺錢**，有三個月的時間準備，而不是到時候才發現付不出房租。

### 預算常見的「坑」

- **預算太樂觀**：營業額寫成長 50%，結果沒達到，整張表都歪。保守一點，寧可被實際數字驚喜。
- **忘記不常發生的支出**：保險費一年付一次、設備三年換一次，不放進預算就會某個月突然爆掉。
- **只做營業預算，沒做現金預算**：就是小明爸爸問的問題。
- **做了不比**：預算做完收進抽屜，月底沒拿出來對照，等於沒做。

## 動手做

### 活動 13-1：做自己下個月的預算，月底比較

**材料／工具**
- 你前面幾章記的零用錢帳本（至少有一個月的紀錄）
- 紙、筆、計算機，或一份 Google 試算表

**步驟**
1. 把上個月的實際收支按項目加總（午餐點心、文具、交通、娛樂、其他、儲蓄）。
2. 寫下下個月的收入（零用錢、幫忙家事、過年紅包的分期？）。
3. 替每一項支出寫預算，並在旁邊寫「怎麼估的」。原則：先寫一定要花的（交通、午餐），再寫想花的（娛樂），最後把剩下的放進儲蓄。
4. 檢查：所有支出加儲蓄是否等於收入？不等於就調整。
5. 把預算表貼在書桌前或存在手機裡。
6. 整個月照常記帳。月中（15 號）先對照一次，看哪一項已經花掉超過一半。
7. 月底把實際金額填進表格，算差異，標出有利、不利。
8. 用例外管理：差異超過 100 元或 20% 的項目，寫一句原因。
9. 根據原因，調整下下個月的預算。

**你應該看到／得到**
- 第一次做預算，通常有兩三項會超過，而且「點心」和「娛樂」幾乎一定超。這很正常。
- 月中對照那一次最有用，因為還來得及踩煞車。
- 第二個月開始，差異會明顯縮小，不是因為你更省，而是因為你的預算估得更準了。

### 活動 13-2：幫小明文具行做第三個月的差異分析

**材料／工具**
- 紙、筆、計算機
- 本章「小明文具行的營業預算」與「彈性預算」兩節

**步驟**
1. 小明編第三個月預算：營業額 40,000、成本 50%、租金 8,000、水電 2,500（天氣更熱，他學乖了）、薪資 3,000、折舊 200（冷氣還沒買，只有電腦的折舊）、雜項 700、利息 100。算出預算毛利和淨利。
2. 第三個月實際：營業額 42,000、銷貨成本 21,840、租金 8,000、水電 2,400、薪資 3,000、折舊 200、雜項 700、利息 100。算出實際毛利和淨利。
3. 做差異表，每一行標有利或不利。
4. 用彈性預算把毛利差異拆成「銷量差異」和「成本差異」。
5. 用門檻「金額 500 元或 10%」判斷哪些要追。
6. 替每個要追的差異，想出兩個可能的原因。

**你應該看到／得到**
- 預算毛利 20,000、淨利 5,500；實際毛利 20,160、淨利 5,760。
- 營業額多賣 2,000（有利），但毛利只多了 160，因為成本率從 50% 跑到 52%：彈性預算成本 21,000，實際 21,840，成本差異不利 840。銷量差異有利 1,000，兩個加起來毛利差異 +160 ✓。水電省了 100（有利），淨利差異 +260。
- 這題的教訓：營業額成長的喜悅，可能被進價悄悄上漲吃掉；不拆開看根本發現不了。

## 用工具看看

用 Google 試算表做一張「會自己算差異」的預算表，以後每個月只要填兩欄數字。

1. 打開 Google 試算表，新增「我的預算」。
2. 第 1 列表頭：A1「項目」、B1「預算」、C1「實際」、D1「差異」、E1「比例」、F1「判斷」、G1「類型」。
3. A2 到 A8 填項目：收入、午餐點心、文具、交通、娛樂、其他、儲蓄。G 欄填類型：收入和儲蓄填「收入」，其他填「費用」（判斷有利不利要用）。
4. B 欄填預算、C 欄月底填實際。
5. D2 輸入 `=C2-B2`，往下拉到 D8。
6. E2 輸入 `=IF(B2=0,"",D2/B2)`，往下拉；選取 E 欄，按工具列的「%」把它變成百分比。
7. F2 輸入判斷公式，往下拉：

   ```
   =IF(D2=0,"—",IF(G2="收入",IF(D2>0,"有利","不利"),IF(D2<0,"有利","不利")))
   ```

   意思是：差異為零顯示「—」；收入類的實際比預算多是有利；費用類的實際比預算少是有利。
8. 第 10 列做門檻：A10「門檻金額」、B10 填 100；A11「門檻比例」、B11 填 20%。
9. H1 填「要追？」，H2 輸入 `=IF(OR(ABS(D2)>=$B$10,ABS(E2)>=$B$11),"要","")`，往下拉。`ABS` 是取絕對值，負 150 也會變 150 來比。
10. 把「要」那一欄用「格式 → 條件式格式設定」設成紅底，一眼看到要追的項目。
11. 每個月複製一份這張工作表（右鍵分頁 → 建立副本），改名「2026-11」，只要填 B 欄和 C 欄，差異、判斷、要不要追全部自動出來。

想做現金預算的話，另外開一張工作表，列「期初現金、收入各項、支出各項、期末現金」，期末現金用 `=SUM(收入範圍)-SUM(支出範圍)+期初`，下個月的期初用 `=上個月的期末那一格`，三個月就能串起來。

## 常見錯誤與迷思

- **「我都有記帳，不需要預算。」** → 記帳是看過去，預算是管未來。只記帳的人到月底才知道錢沒了，有預算的人月中就知道要踩煞車。正確理解：記帳和預算是一對，少一個都不完整。
- **「預算做了就要死守。」** → 預算是估計，不是法律。估錯了就調整，重點是知道「為什麼和當初想的不一樣」。正確理解：預算的價值在比較和學習，不在百分之百達成。
- **「費用比預算少，一定是好事。」** → 不一定。銷貨成本少可能是因為賣得少；廣告費少可能是因為根本沒打廣告，下個月客人就變少。正確理解：先用彈性預算排除「量」的影響，再判斷。
- **「有利潤就不會缺錢。」** → 利潤是損益表的事，現金是現金預算的事。賒帳收不回來、設備付大筆款，都會讓有利潤的月份現金見底。正確理解：營業預算和現金預算要一起做。
- **「差異很小不用管。」** → 單月小差異如果每個月都往同一個方向跑，累積起來就大了。正確理解：門檻可以放過單次小差異，但連續三個月同方向的差異要追。
- **「預算是老闆的事，員工不用懂。」** → 誰在花錢，誰就該知道自己的預算。小美管自己的零用錢、小明管店，道理一樣。

## 想一想

1. 小美下個月零用錢 2,000 元，她把娛樂預算提高到 500 元、點心維持 800、文具 300、交通 200。儲蓄還剩多少？這樣存半年，夠不夠付 1,500 元的畢業旅行？

<details><summary>參考答案</summary>

儲蓄 = 2,000 − 800 − 300 − 200 − 500 = 200 元。半年存 1,200 元，不夠 1,500 元。她要嘛把某項預算再砍 50 元，要嘛找額外收入。

</details>

2. 小明文具行某月預算水電 1,500 元，實際 2,100 元；預算廣告費 1,000 元，實際 0 元。請各標出有利或不利，並說明哪一個「有利」其實可能是壞事。

<details><summary>參考答案</summary>

水電：實際多 600，不利。廣告費：實際少 1,000，形式上是有利。但沒打廣告可能是這個月客人變少的原因，下個月營業額可能掉，所以這個「有利」要打問號。差異分析一定要搭配「為什麼」。

</details>

3. 文具行某月預算營業額 40,000、成本率 50%，實際營業額 38,000、實際成本 18,620。請算：(a) 原預算成本；(b) 彈性預算成本；(c) 銷量差異；(d) 成本差異；(e) 毛利總差異，並驗算 (c)+(d)=(e)。

<details><summary>參考答案</summary>

(a) 40,000 × 50% = 20,000。(b) 38,000 × 50% = 19,000。(c) 銷量差異 = (38,000 − 40,000) × 50% = −1,000，不利。(d) 成本差異 = 19,000 − 18,620 = +380，有利（進價變便宜，成本率 49%）。(e) 預算毛利 20,000，實際毛利 38,000 − 18,620 = 19,380，總差異 −620。驗算：−1,000 + 380 = −620 ✓。賣得少被進價便宜補回了一部分。

</details>

4. 承本章「情境 B」。(a) 如果小明把冷氣延到第 4 個月才買，第 3、第 4 個月的期末現金各是多少？有沒有跌破 30,000 元？(b) 如果冷氣照原計畫第 3 個月買，但跟房東談成第 4 個月起改成每月付 8,000（不用一次預付三個月），第 3、第 4 個月的期末現金又各是多少？

<details><summary>參考答案</summary>

(a) 第 3 個月：39,600 + 28,000 + 10,800 − 20,000 − 1,500 − 3,000 − 100 − 700 = 53,100。第 4 個月：53,100 + 30,800 + 12,000 − 22,000 − 24,000 − 1,500 − 3,000 − 100 − 700 − 15,000 = 29,600。第 4 個月還是跌破 30,000，跟原本一模一樣，因為總共要付的錢沒變，只是時間點不同——延後支出只是把問題往後推。(b) 第 3 個月不變，38,100。第 4 個月：38,100 + 30,800 + 12,000 − 22,000 − 8,000 − 1,500 − 3,000 − 100 − 700 = 45,600，安全。改變付款方式才真正解決了問題，所以「跟房東談」比「晚點買冷氣」有用。

</details>

5. 小明想知道「每個月賒帳比例最多能到幾成，第 4 個月現金才不會跌破 30,000」（冷氣照原計畫第 3 個月買、租金照原計畫第 4 個月預付三個月）。請用代數或試誤法找出大約的上限。

<details><summary>參考答案</summary>

設賒帳比例為 r。第 2 個月期末 = 40,700 + 36,000(1 − r) + 2,000 − 28,300 = 50,400 − 36,000r。第 3 個月期末 = (50,400 − 36,000r) + 40,000(1 − r) + 36,000r − 40,300 = 50,100 − 40,000r。第 4 個月期末 = (50,100 − 40,000r) + 44,000(1 − r) + 40,000r − 51,300 = 42,800 − 44,000r。要 ≥ 30,000：44,000r ≤ 12,800，r ≤ 0.291。賒帳比例最多約 29%。超過這個比例，就得延後買冷氣、跟房東談月付，或另外找錢。

</details>

6. 【開放挑戰】找一個你參加過的活動（班級旅行、社團成發、家庭聚餐），替它編一份預算：收入從哪裡來、要花哪些項目、哪些是固定的、哪些跟人數有關。然後想一想：如果報名人數比預期少三成，哪些項目會出問題？要先準備什麼應變？

<details><summary>參考答案</summary>

沒有標準答案。好的回答會：(1) 把費用分成固定（遊覽車、場地）和變動（餐費、保險、門票）；(2) 算出人數減少三成時，每人要分攤的固定費用增加多少；(3) 提出應變，例如先跟遊覽車公司談「人數不足可改小車」、訂金分兩次付、或設定最低成團人數。這其實就是把損益兩平（第 12 章）和現金預算（本章）用在真實生活上。

</details>

## 本章小結

- 帳本記過去，預算寫未來；兩個一起用才管得住錢。
- 控制是一個循環：編預算 → 執行 → 比較 → 找原因修正。
- 差異 = 實際 − 預算。對淨利有好處的是有利差異，有壞處的是不利差異；收入多是有利，費用多是不利。
- 彈性預算先問「如果當初知道只賣這麼多，成本應該是多少」，才能把「賣得少」和「花得多」分開。
- 例外管理：訂門檻，只追超過門檻的差異，但注意連續同方向的小差異。
- 現金預算按月算「期初＋收入－支出＝期末」，能提早幾個月看到缺錢的時間點。
- 賒帳比例、大筆設備支出，是最容易讓有利潤的店缺現金的兩件事。
- 預算不是要死守，是要學會下次估得更準。

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 預算 | Budget | 用數字寫下來的未來收支計畫。 |
| 控制 | Control | 執行後對照預算、找差距、改進的過程。 |
| 營業預算 | Operating Budget | 預計的收入、成本、費用、淨利。 |
| 進貨預算 | Purchases Budget | 依照銷售目標與存貨水準算出來的進貨金額。 |
| 現金預算 | Cash Budget | 按月算期初現金、收入、支出、期末現金的表。 |
| 差異分析 | Variance Analysis | 比較預算與實際，找出差距與原因。 |
| 有利差異 | Favorable Variance | 對淨利有好處的差異。 |
| 不利差異 | Unfavorable Variance | 對淨利有壞處的差異。 |
| 彈性預算 | Flexible Budget | 依實際銷量重算的預算，用來排除「量」的影響。 |
| 銷量差異 | Volume Variance | 因為賣的數量和預算不同造成的差異。 |
| 例外管理 | Management by Exception | 只追超過門檻的差異。 |
| 安全現金水位 | Minimum Cash Balance | 自己訂的現金最低存量，低於它就要採取行動。 |
