# 第 6 章　試算表

## 本章目標
- 學完你會說出會計的「試算表」是什麼、它和 Google 試算表這種軟體有什麼不同。
- 學完你會從分類帳的餘額編出一張試算表，並解釋為什麼借方合計一定要等於貸方合計。
- 學完你會用「算差額」的四個招式（找原數、除以 2、除以 9、回頭對帳）有系統地找出錯在哪裡。
- 學完你會說出哪幾種錯誤是試算表抓不到的，以及該怎麼防。
- 學完你會在 Google 試算表裡做一張會自動報告「平衡／不平衡」的試算表。

## 開場：數字對不起來的那一晚

10 月 31 日晚上，小明把 14 個科目的餘額抄在一張紙上，借方餘額一欄、貸方餘額一欄，打算明天拿給表姊看。他把借方那欄加起來：111,300。貸方那欄加起來：105,000。

不一樣。差了 6,300。

小明心裡一沉。20 筆交易、14 個科目、每一筆都要過兩邊，到底哪裡錯了？他想從頭再過一次帳，但已經十一點了。

表姊傳來訊息：「先別重做。差多少？」

「6,300。」

「6,300 除以 9 是 700，整除。你有哪個科目的數字裡面有 7 跟 0 連在一起的？去看那個。」

小明看了一眼現金：47,000。他翻開分類帳，現金最後一列餘額寫的是 40,700。他抄的時候把 0 和 7 寫顛倒了。

改回 40,700，借方合計 105,000，貸方合計 105,000。平了。

表姊是怎麼只憑「差 6,300」就猜到是數字顛倒的？這一章就來學這個：試算表為什麼一定要平、不平的時候怎麼有系統地找錯，以及哪些錯它根本抓不到。

## 核心概念

### 兩種「試算表」

先把一個會混淆的詞講清楚。

- **會計的試算表（Trial Balance）**：一張表，列出某一天所有科目的餘額，借方餘額一欄、貸方餘額一欄，用來「試著算算看」帳有沒有平。這一章講的是它。
- **電子試算表（Spreadsheet）**：Google 試算表、Excel 這類軟體，裡面是格子和公式。本書「用工具看看」一直在用的是它。

兩個中文都叫試算表，但一個是會計文件，一個是軟體。你可以「用電子試算表來做會計的試算表」，就像這一章最後要做的事。以後看到「試算表」三個字，先想一下是哪一個。

### 試算表長什麼樣

試算表就是把第 5 章分類帳裡每個科目的餘額抄成一張表。借方餘額的科目放左欄，貸方餘額的科目放右欄，最後兩欄各自加總。下面是小明文具行 10 月 31 日的試算表（還沒做第 7 章的調整，所以叫調整前試算表）：

**小明文具行　試算表　10 月 31 日**

| 編號 | 科目 | 借方餘額 | 貸方餘額 |
|------|------|----------|----------|
| 1001 | 現金 | 40,700 | |
| 1101 | 應收帳款 | 2,000 | |
| 1201 | 存貨 | 20,000 | |
| 1301 | 預付租金 | 24,000 | |
| 1501 | 設備 | 12,000 | |
| 2001 | 應付帳款 | | 5,000 |
| 2201 | 銀行借款 | | 20,000 |
| 3001 | 業主資本 | | 50,000 |
| 3002 | 業主提取 | 2,000 | |
| 4001 | 銷貨收入 | | 30,000 |
| 5103 | 薪資費用 | 3,000 | |
| 5104 | 廣告費 | 500 | |
| 5106 | 利息費用 | 100 | |
| 5107 | 雜項費用 | 700 | |
| | **合計** | **105,000** | **105,000** |

幾個規矩：

1. **按科目編號排**：資產、負債、權益、收入、費用的順序，之後編報表才好找。
2. **每個科目只出現在一欄**：正常餘額在借方的放左邊，正常餘額在貸方的放右邊。
3. **餘額為零的科目可以不列**（例如還沒用到的租金費用）。
4. **標題寫清楚是哪一天**：試算表是「某一天」的快照，不是「某段期間」。

### 為什麼借方合計一定等於貸方合計

這不是巧合，是數學上必然的。想一想：

1. 第 4 章說過，**每一筆分錄**的借方金額 ＝ 貸方金額。
2. 把 20 筆分錄全部加起來，**所有借方的總和** ＝ **所有貸方的總和**（第 5 章驗算過，都是 175,300）。
3. 過帳只是把同樣的數字搬到不同的頁面，沒有多也沒有少，所以**分類帳所有借方的總和**還是 175,300，**所有貸方的總和**也還是 175,300。
4. 每個科目的餘額是「借方合計 － 貸方合計」（或反過來）。把所有科目的餘額按借、貸分欄加起來，兩欄的差，剛好等於第 3 點的「總借方 － 總貸方」，也就是 0。

所以，**只要每一筆分錄都借貸相等、每一筆都兩邊過完，試算表就一定平**。反過來說，試算表不平，一定是這條鏈子某個環節斷了。

### 試算表不平：四招找錯

試算表不平的時候，**不要從頭重做**。先算出差額 D ＝ 借方合計 － 貸方合計（取正數），然後依序試這四招，通常第一、二招就抓到了。

**第一招：差額本身是不是某一筆的金額？** → 很可能那一筆只過了一邊。

例如差額是 3,000，而日記帳裡有一筆「薪資費用 3,000」。去看薪資費用和現金兩個科目，是不是只有一個記到了。

**第二招：差額除以 2，是不是某一筆的金額？** → 很可能那一筆記反邊了。

例如差額 10,000，除以 2 是 5,000。應付帳款餘額 5,000 本來該在貸方，如果抄到借方，借方會多 5,000、貸方會少 5,000，差額就是 10,000。「記錯邊」的錯永遠讓差額變成兩倍。

**第三招：差額能不能被 9 整除？** → 很可能是數字顛倒或滑位。

- **數字顛倒（Transposition）**：40,700 寫成 47,000，或 1,200 寫成 2,100。
- **滑位（Slide）**：4,000 寫成 400（少一個零），或 500 寫成 5,000。

為什麼跟 9 有關？拿兩位數來看：十位 a、個位 b 的數字是 10a ＋ b，寫顛倒變成 10b ＋ a，兩者相差 9a － 9b ＝ 9 × (a － b)，一定是 9 的倍數。滑位也一樣：4,000 － 400 ＝ 3,600 ＝ 9 × 400。所以差額能被 9 整除，就優先懷疑這兩種錯。

開場的例子：差額 6,300 ÷ 9 ＝ 700，整除。去找哪個數字裡有相鄰的數位顛倒會差 6,300，就找到 47,000 和 40,700。

**第四招：倒著對回去。**

前三招都沒中，就依序檢查：

1. 試算表兩欄重新加一次（最常見的錯其實是加錯）。
2. 試算表上每個餘額，和分類帳上的餘額對一次。
3. 分類帳每個科目的餘額重算一次。
4. 日記帳每一筆，檢查有沒有都過到分類帳，而且過在對的那一邊。
5. 日記帳每一筆，檢查借貸是否相等。

這個順序是從「最後做的事」倒回「最先做的事」，因為越後面做的步驟越容易出錯（抄寫、加總），而且檢查起來越快。

```
  找錯流程

  算差額 D
     │
     ├─ D ＝ 某筆金額？ ──→ 那筆只過了一邊
     │
     ├─ D ÷ 2 ＝ 某筆金額？ ──→ 那筆記反邊
     │
     ├─ D ÷ 9 整除？ ──→ 找數字顛倒或滑位
     │
     └─ 都不是 ──→ 倒著對：重加 → 對餘額 → 重算分類帳 → 對過帳 → 對分錄
```

### 試算表平了，帳就一定對嗎？

不一定。試算表只能抓到「借貸兩邊不一樣」的錯。下面這些錯，兩邊一樣，試算表看起來完全正常：

| 錯誤類型 | 例子 | 為什麼試算表抓不到 |
|----------|------|--------------------|
| 整筆漏記 | 10/27 買紙袋 300 元忘了記 | 兩邊都沒記，兩邊一樣少 |
| 整筆重複記 | 10/25 薪資記了兩次 | 兩邊都多 3,000 |
| 科目用錯 | 薪資 3,000 記成廣告費 | 都是借方費用，借方合計不變 |
| 兩邊金額一起錯 | 銷貨 4,000 兩邊都寫 400 | 兩邊一樣錯 |
| 借貸整筆對調 | 銷貨收現記成「借 銷貨收入、貸 現金」 | 兩邊金額還是一樣 |
| 抵銷的兩個錯 | 一筆借方多 500，另一筆貸方也多 500 | 剛好抵消 |

所以試算表平了，只代表「沒有少記一半」。要抓這些錯，得靠別的方法：

- **對單據**：每筆分錄旁邊註明單據編號，月底把單據一張張勾掉，沒勾到的就是漏記。
- **對外部紀錄**：帳上的現金和實際數錢的結果比；帳上的應付帳款和批發商寄來的對帳單比；帳上的應收帳款和補習班說的欠款比。
- **看合理性**：廣告費這個月突然變成 3,500，是真的多印了傳單，還是把薪資記錯科目？

### 試算表在整個流程裡的位置

```
  日記帳 → 分類帳 → 調整前試算表 → 調整分錄（第 7 章）→ 調整後試算表 → 報表（第 8、9 章）
                        ▲
                     你在這裡
```

試算表不是給外人看的報表，是會計師自己用的檢查站。但它同時也是編報表的「原料清單」：資產負債表要的資產、負債、權益餘額，損益表要的收入、費用餘額，全部都在這張表上。先把它編對，後面才有得做。

### 活動 6-3：這些錯，試算表抓得到嗎？

**材料／工具**
- 筆、下面的表格

**步驟**
1. 對每一個情境，先不要算，憑直覺猜「試算表抓得到／抓不到」。
2. 然後實際想：這個錯會讓借方合計變多少、貸方合計變多少？兩者還一樣嗎？
3. 填表，再和參考答案對。
4. 對於「抓不到」的，寫下一個可以抓到它的方法（對單據、對外部紀錄、看合理性）。

**你應該得到**
- 6 個情境裡，只有 2 個試算表抓得到。
- 你會發現「抓不到」的錯反而比較常見，所以月底對單據、數現金很重要。

**觀察與記錄**

| 情境 | 直覺 | 借方合計變成 | 貸方合計變成 | 抓得到？ | 抓不到的話怎麼辦 |
|------|------|--------------|--------------|----------|------------------|
| A. 10/14 網路費 400 完全忘了記 | | | | | |
| B. 10/25 薪資記成「借 廣告費 3,000、貸 現金 3,000」 | | | | | |
| C. 10/6 銷貨 4,000 只過了現金，沒過銷貨收入 | | | | | |
| D. 10/12 銷貨 6,000 記了兩次 | | | | | |
| E. 10/28 業主提取 2,000 記成「借 現金、貸 業主提取」 | | | | | |
| F. 10/2 買電腦 12,000 過帳時設備寫成 21,000 | | | | | |

**參考答案**

| 情境 | 借方合計 | 貸方合計 | 抓得到？ | 說明 |
|------|----------|----------|----------|------|
| A | 105,000 | 105,000 | 抓不到 | 雜項費用少 400，但現金多 400，兩個都在借方欄，借方合計不變。對單據可抓到。 |
| B | 105,000 | 105,000 | 抓不到 | 廣告費多 3,000、薪資少 3,000，借方合計不變。看合理性（薪資怎麼是 0？）可抓到。 |
| C | 105,000 | 101,000 | 抓得到 | 差額 4,000，第一招就中。 |
| D | 111,000 | 111,000 | 抓不到 | 現金多 6,000、收入多 6,000。數現金、對收銀紀錄可抓到。 |
| E | 107,000 | 107,000 | 抓不到 | 現金少減 2,000 又多加 2,000，變成 44,700（借方多 4,000）；業主提取跑到貸方 2,000。借方欄 105,000 － 2,000 ＋ 4,000 ＝ 107,000，貸方欄 105,000 ＋ 2,000 ＝ 107,000，還是平的。看正常餘額（提取怎麼會在貸方？）可抓到。 |
| F | 114,000 | 105,000 | 抓得到 | 差額 9,000，÷ 9 ＝ 1,000，第三招：數字顛倒 12 ↔ 21。 |

情境 E 值得多看一眼：一筆分錄整個借貸對調，兩邊金額還是一樣，所以試算表永遠平。但它會讓「業主提取」出現貸方餘額，這在正常情況下不可能發生。所以編試算表時順手檢查「每個科目的餘額是否在正常餘額那一邊」，可以抓到不少試算表合計抓不到的錯。

## 用工具看看：讓 Google 試算表自動告訴你「平衡」還是「不平衡」

接續第 5 章做好的「小明文具行-帳本」檔案（裡面已經有「日記帳」和「分類帳」兩個工作表）。

**步驟**
1. 打開那個檔案，新增第三個工作表，改名「試算表」。
2. 第 1 列輸入標題：A1「科目編號」、B1「科目」、C1「借方餘額」、D1「貸方餘額」。
3. A2 輸入 `=分類帳!A2`，B2 輸入 `=分類帳!B2`，把編號和科目名稱從分類帳抓過來。
4. C2 輸入 `=IF(分類帳!E2>0, 分類帳!E2, "")`，意思是「如果分類帳的餘額（借－貸）是正的，就顯示它，否則留空」。
5. D2 輸入 `=IF(分類帳!E2<0, -分類帳!E2, "")`，意思是「如果餘額是負的（貸方餘額），就把它變成正數放這裡」。
6. 選取 A2:D2，往下拉到第 15 列。
7. B16 輸入「合計」，C16 輸入 `=SUM(C2:C15)`，D16 輸入 `=SUM(D2:D15)`。
8. B18 輸入「檢查」，C18 輸入：`=IF(C16=D16, "平衡", "不平衡，差額 " & ABS(C16-D16))`。
9. B19 輸入「差額÷2」，C19 輸入 `=ABS(C16-D16)/2`；B20 輸入「差額÷9」，C20 輸入 `=ABS(C16-D16)/9`。

**你應該看到**
- C16 和 D16 都是 105,000，C18 顯示「平衡」。
- 回到「日記帳」工作表，把傳票 009 的貸方 10000 刪掉（只刪貸方那一列的數字）。切回試算表：C18 變成「不平衡，差額 10000」，C19 顯示 5000，C20 顯示 1111.11（不整除）。差額 10,000 剛好等於一筆交易的金額，第一招就中：那筆只過了一邊。把 10000 填回去。
- 再試一次：把傳票 004 的借方 12000 改成 21000。C18 顯示「不平衡，差額 9000」，C20 顯示 1000（整除）。這是第三招：數字顛倒。改回來。

**進一步玩玩看**
- 在 E 欄加「正常餘額」（借或貸），F 欄用 `=IF(AND(E2="借", D2<>""), "注意", IF(AND(E2="貸", C2<>""), "注意", ""))` 標出「餘額跑錯邊」的科目。這能抓到活動 6-3 情境 E 那種錯。
- 試算表平衡不代表帳對。把傳票 015 的科目編號 5103 改成 5104（薪資記成廣告費），C18 還是「平衡」，但分類帳裡薪資費用變 0、廣告費變 3,500。這就是「看合理性」要做的事。

## 常見錯誤與迷思

- **錯誤想法：試算表就是 Excel 或 Google 試算表。** → 為什麼錯：中文剛好同名，但會計的試算表（Trial Balance）是一張列出所有科目餘額的檢查表。→ 正確理解：可以「用電子試算表軟體做會計的試算表」，兩者是工具與文件的關係。
- **錯誤想法：試算表不平就要從第一筆重做。** → 為什麼錯：太慢，而且重做時可能犯一樣的錯。→ 正確理解：先算差額，用「等於某筆、除以 2、除以 9」三招縮小範圍，再倒著對回去。
- **錯誤想法：試算表平了，帳就對了。** → 為什麼錯：漏記、重複記、科目錯、兩邊一起錯都不會讓試算表不平。→ 正確理解：試算表只保證「沒有少記一半」，還要對單據、對外部紀錄、看合理性。
- **錯誤想法：試算表是給老闆或銀行看的報表。** → 為什麼錯：它是記帳人員自己的檢查工具，外人看不懂也不需要看。→ 正確理解：給外人看的是第 8、9 章的資產負債表和損益表，試算表是編那兩張表的原料。
- **錯誤想法：每個科目在試算表上借方、貸方兩欄都要填。** → 為什麼錯：試算表填的是「餘額」，一個科目只有一個餘額，落在一邊。→ 正確理解：借方餘額填左欄、貸方餘額填右欄，另一欄空白。
- **錯誤想法：差額能被 9 整除，一定是數字顛倒。** → 為什麼錯：9,000 也可能是一筆 9,000 元的交易只過一邊（第一招）。→ 正確理解：三招都是「提示」不是「證明」，找到可疑處還是要回分類帳確認。

## 想一想

1. 為什麼試算表的借方合計一定等於貸方合計？用兩句話說明。

<details><summary>參考答案</summary>

因為每一筆分錄借貸相等，所以全部分錄加起來借貸也相等。過帳只是把同樣的數字搬到各科目頁面，沒有增減，所以把各科目餘額按借貸分欄加總，兩欄差額就是 0。

</details>

2. 小明的試算表借方合計 105,000、貸方合計 104,300，差 700。日記帳裡有一筆雜項費用 300 和一筆 400。你會先懷疑什麼？

<details><summary>參考答案</summary>

差額 700 剛好是雜項費用的餘額（300 ＋ 400），所以可能是雜項費用這個科目整個沒抄到試算表的借方，或是雜項費用的兩筆都只過到現金那一邊。先去看試算表上有沒有雜項費用這一行，再看分類帳。另外 700 ÷ 9 不整除，不像顛倒。

</details>

3. 差額是 1,800。請分別用三招推論可能是什麼錯。

<details><summary>參考答案</summary>

第一招：有沒有一筆 1,800 的交易？小明的帳上沒有。第二招：1,800 ÷ 2 ＝ 900，有沒有 900 的科目或交易記反邊？也沒有。第三招：1,800 ÷ 9 ＝ 200，整除，可能是數字顛倒或滑位：例如 2,000 寫成 200（滑位，差 1,800），業主提取 2,000 寫成 200 就會這樣。優先去檢查業主提取和應收帳款這兩個 2,000。

</details>

4. 為什麼「記反邊」會讓差額變成兩倍，而「只過一邊」只差一倍？

<details><summary>參考答案</summary>

只過一邊：例如貸方的 5,000 沒記，貸方少 5,000，借方沒變，差 5,000。記反邊：本該在貸方的 5,000 跑到借方，貸方少 5,000 而且借方多 5,000，一來一往差 10,000。所以差額 ÷ 2 等於某個數字，就要懷疑那個數字記反邊。

</details>

5. 試算表平衡的情況下，小明想確認「現金 40,700」是真的。請列出兩個不靠帳本本身的檢查方法。

<details><summary>參考答案</summary>

（一）實際數錢：把店裡的現金和銀行存款餘額加起來，看是不是 40,700。（二）對銀行對帳單：銀行寄來的明細裡每一筆存入、提出，和日記帳一筆一筆勾。（三）對收銀紀錄：收銀機每週的銷售總額和日記帳裡的四筆週銷貨對一次。任兩個都算對。

</details>

6. （開放挑戰）有人提議：「既然電子試算表會自動加總，就不會有抄錯、加錯的問題，那會計的試算表以後就沒用了。」你同意嗎？請舉出至少一個「用電腦記帳還是會出現、而且試算表能抓到」的錯，以及一個「電腦也抓不到、要靠人」的錯。

<details><summary>參考答案</summary>

不完全同意。電腦確實消除了「加錯」和「抄錯餘額」這兩種錯，所以真實的會計軟體通常會強制每筆分錄借貸相等，試算表幾乎永遠是平的。但「只打了一列、另一列忘了打」「借方金額打成 4000、貸方打成 400」這種輸入錯，在像我們這樣自己用試算表軟體做的帳本裡還是會發生，這時「檢查」那一格就會跳出不平衡。而「科目選錯」「整筆漏打」「同一張單據打兩次」，電腦怎麼算都是平的，必須靠人對單據、對銀行紀錄、看合理性。所以試算表的「平衡檢查」功能被電腦接手了，但「把所有餘額列在一張表上讓人一眼看出不合理」這個功能還是有用。

</details>

## 本章小結

- 會計的試算表（Trial Balance）是某一天所有科目餘額的清單，借方餘額一欄、貸方餘額一欄；它和 Google 試算表、Excel 這種軟體是不同的東西。
- 因為每筆分錄借貸相等、過帳不增減數字，所以試算表的借方合計一定等於貸方合計；不平就表示某個環節出錯。
- 小明文具行 10 月 31 日調整前試算表：借貸合計各 105,000 元。
- 找錯四招：差額等於某筆金額（只過一邊）、差額 ÷ 2（記反邊）、差額 ÷ 9 整除（數字顛倒或滑位）、倒著對回去（重加 → 對餘額 → 重算分類帳 → 對過帳 → 對分錄）。
- 試算表抓不到：整筆漏記、重複記、科目用錯、兩邊金額一起錯、借貸整筆對調、互相抵銷的錯；要靠對單據、對外部紀錄、看合理性。
- 試算表不是給外人看的報表，是記帳人員的檢查站，也是第 8、9 章編報表的原料。
- 在電子試算表裡用 IF 把分類帳餘額分到借貸兩欄、用 SUM 加總、用 IF 顯示「平衡／不平衡」，改一筆分錄馬上看到結果。

|------|------|------------|
| 試算表（會計） | Trial Balance | 某一天所有科目餘額的清單，用來檢查借貸是否相等。 |
| 電子試算表 | Spreadsheet | Google 試算表、Excel 這類有格子和公式的軟體。 |
| 調整前試算表 | Unadjusted Trial Balance | 還沒做期末調整分錄之前編的試算表。 |
| 調整後試算表 | Adjusted Trial Balance | 做完調整分錄之後編的試算表，第 7 章會做。 |
| 差額 | Difference | 試算表借方合計與貸方合計的差，用來找錯。 |
| 數字顛倒 | Transposition Error | 相鄰數位寫反，例如 40,700 寫成 47,000，差額是 9 的倍數。 |
| 滑位 | Slide Error | 多寫或少寫一個零，例如 4,000 寫成 400，差額也是 9 的倍數。 |
| 只過一邊 | Single-Sided Posting | 一筆分錄只有借方或只有貸方過到分類帳，差額等於該筆金額。 |
| 記反邊 | Reversed Posting | 應該在借方的記到貸方（或相反），差額是該金額的兩倍。 |
| 漏記 | Omission | 整筆交易沒有記，試算表抓不到。 |
| 對帳 | Reconciliation | 把帳本和外部紀錄（銀行、供應商、實際現金）一筆筆核對。 |
| ABS | ABS | 試算表函式，取絕對值（去掉負號）。 |
