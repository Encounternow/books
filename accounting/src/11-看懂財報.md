# 第 11 章　看懂財報

## 本章目標

- 學完你會用一張圖說出三張報表怎麼連在一起，並找出至少三條勾稽線。
- 學完你會算四個最基本的財務比率：毛利率、淨利率、負債比、流動比，並說出每個比率在回答什麼問題。
- 學完你會知道比率要「跟自己過去比、跟同行比」才有意義，單看一個數字容易誤判。
- 學完你會到公開資訊觀測站找一家台灣上市公司的財報，並從裡面抓出算比率需要的數字。
- 學完你會像一位小小分析師，對一家公司做一次簡單的「健康檢查」。

## 開場：姑姑說「我可以投資你，但先把報表拿來」

小明的姑姑在銀行上班。聽說文具行開得不錯，她說：「我可以投資十萬元幫你把店做大。不過我在銀行看了二十年的報表，投資之前有四個問題一定要問清楚。」

她掰著手指：「第一，你賺不賺錢？賣的東西好不好賺？第二，你手上有沒有現金？會不會像你表哥那樣賺錢卻付不出貨款？第三，你欠別人多少？欠太多的店我不敢投。第四，你最近幾個月付得出錢嗎？」

小明把三張報表攤在桌上：「都在這裡。」

姑姑笑了：「報表只是數字，我要的是答案。你能不能用幾個比率，一分鐘內回答我這四個問題？」

這一章就是要教你姑姑那一分鐘的本事：把三張報表串起來，算幾個簡單的比率，回答「這家公司健不健康」。學會之後，你不只能看小明文具行，還能看台積電、統一超這些真實的上市公司。

## 核心概念

### 三張表的關係：一張圖看懂

前三章我們分別編了三張表，現在把它們放在一起：

```
  資產負債表              損益表                  資產負債表
  10/1（期初）        10/1 ～ 10/31（期間）         10/31（期末）
 ┌────────────┐      ┌──────────────┐         ┌──────────────┐
 │ 現金     0  │      │ 收入   30,000 │         │ 現金   40,700 │◀─┐
 │ ……         │      │ 成本費用      │         │ ……           │  │
 │ 權益     0  │      │      (29,000) │   ┌────▶│ 權益   49,000 │  │
 └────────────┘      │ 淨利    1,000 ├───┘     └──────────────┘  │
                     └──────────────┘                            │
                     ┌──────────────┐                            │
                     │ 現金流量表     │                            │
                     │ 營業  −15,300 │                            │
                     │ 投資  −12,000 │                            │
                     │ 籌資  +68,000 │                            │
                     │ 期末現金 40,700├────────────────────────────┘
                     └──────────────┘
```

讀法是這樣：期初的照片（10/1，什麼都還沒有）經過一個月的影片（損益表記錄賺了多少、現金流量表記錄現金怎麼動），變成期末的照片（10/31）。兩段影片各自「接」到期末照片上的一個地方：

| 勾稽線 | 從哪裡 | 到哪裡 | 小明文具行的數字 |
|---|---|---|---:|
| 第一條 | 損益表的本期淨利 | 資產負債表的權益（期初權益 + 業主投入 + 淨利 − 業主提取 = 期末權益） | 0 + 50,000 + 1,000 − 2,000 = 49,000 |
| 第二條 | 現金流量表的期末現金 | 資產負債表的現金 | 40,700 |
| 第三條 | 損益表的折舊費用 | 資產負債表的累計折舊（期初累計折舊 + 本期折舊） | 0 + 200 = 200 |

第三條線你可能沒想到：每個月損益表上扣的折舊費用，會一個月一個月堆進資產負債表的累計折舊裡，11 月底會是 400，開店滿一年會是 2,400。損益表每一期的「流量」，累積起來就是資產負債表的「存量」。這三條線是檢查報表有沒有編錯最快的方法：任何一條對不上，一定有地方錯了。

### 看財報的四個問題，四個比率

姑姑的四個問題，每個都可以用一個簡單的比率回答。這四個比率只需要除法和百分比，但它們是全世界的分析師每天在用的。

| 姑姑的問題 | 比率 | 公式 | 從哪張表拿數字 |
|---|---|---|---|
| 賣的東西好不好賺？ | 毛利率 | 毛利 ÷ 收入 | 損益表 |
| 最後真的賺多少？ | 淨利率 | 淨利 ÷ 收入 | 損益表 |
| 欠別人的多不多？ | 負債比 | 負債總額 ÷ 資產總額 | 資產負債表 |
| 最近付不付得出錢？ | 流動比 | 流動資產 ÷ 流動負債 | 資產負債表 |

前兩個第 9 章已經算過，後兩個是新的。

### 毛利率與淨利率：賺錢的能力

複習一下，小明文具行 10 月：

```
毛利率 = 15,000 ÷ 30,000 = 50%
淨利率 =  1,000 ÷ 30,000 ≈ 3.3%
```

毛利率看「東西本身好不好賺」，淨利率看「扣掉開店所有開銷後真的留下多少」。兩者的差距（46.7 個百分點）是營業費用和利息吃掉的。如果毛利率還不錯但淨利率很低（小明就是這樣），問題通常在費用，或是營業額還太小、攤不掉固定費用；如果毛利率本身就很低，問題在進價或售價。

### 負債比：欠別人的占多少

**負債比（Debt Ratio）**回答：「這家公司的東西，有幾成是靠借來的錢買的？」

```
負債比 = 負債總額 ÷ 資產總額 × 100%
       = 26,500 ÷ 75,500 × 100% ≈ 35.1%
```

意思是：小明文具行的資產裡，每 100 元大約有 35 元是欠別人的（主要是銀行的 20,000），其餘 65 元是小明自己的。

負債比越高，代表公司越依賴別人的錢。好處是可以用別人的錢做更大的生意；壞處是生意稍微不順，還款壓力就會把公司壓垮。負債比沒有絕對的「好數字」，但有幾個直覺：

- 超過 50% 代表「欠的比自己的多」，一般小店就要小心。
- 不同行業差很多：銀行的負債比可能超過 90%（存款人的錢都是銀行的負債）；製造業通常 30–50%。
- 比「數字高不高」更重要的是「越來越高還是越來越低」。

### 流動比：最近付不付得出錢

**流動比（Current Ratio）**回答：「一年內要付的錢，用一年內會變成現金的東西，付得出來嗎？」

```
流動比 = 流動資產 ÷ 流動負債
       = 63,700 ÷ 6,500 ≈ 9.8
```

9.8 的意思是：一年內要付的每 1 元，小明手上有 9.8 元可以應付，非常寬裕。這麼高是因為剛投入和借來的現金大部分還在、三個月的房租也預付了，而一年內要付的只有欠批發商的 5,000 和水電 1,500（銀行借款要兩年後才還）。安全是安全，但現金放著不動也賺不到錢，剛開店這樣比較安心。

一般的直覺是：

- 小於 1：一年內該付的錢比能變現的還多，有付不出來的風險，就是第 8 章想一想第 5 題那家「有錢但不安全」的店。
- 1.5 到 2 左右：大多數行業覺得舒服的範圍。
- 太高（例如 5 以上）：安全，但可能代表錢沒有好好運用。
- 便利商店這類「現金天天進來、貨款月底才付」的行業，流動比常接近 1 卻活得很好。所以還是那句話：要跟同行比。

### 比率要「比」才有意義

一個比率單獨看很難說好壞。「毛利率 50%」對文具店算不錯，對飲料店算低；「負債比 70%」對製造業偏高，對便利商店很正常。比率要放在兩種脈絡裡看：

1. **跟自己過去比**：小明文具行 10 月淨利率只有 3.3%，11 月如果升到 5.8%（第 9 章想一想第 3 題那個假設）是好消息；但如果 12 月又掉回 3%，就算每個月都在賺，也要找出哪個費用越來越重。
2. **跟同行比**：小明文具行跟附近另一家文具店比，統一超跟全家比，才看得出誰經營得好。

分析師的習慣是：**先看趨勢，再看數字**。

### 用兩家真實的台灣公司練習

下面用兩家你一定聽過的公司做練習：台積電（股票代號 2330，做晶片）和統一超（股票代號 2912，就是 7-ELEVEN）。表裡的數字是從它們某一年的年度財報整理出來的**概數**，目的只是讓你看「不同行業的比率長什麼樣」。這些數字每年都在變，**請務必到公開資訊觀測站查最新的財報，用最新數字自己算一次**，不要把這裡的概數當成答案。

| 比率 | 台積電（約） | 統一超（約） | 小明文具行 10 月 |
|---|---:|---:|---:|
| 毛利率 | 約 50% 多 | 約 30% 多 | 50% |
| 淨利率 | 約 35–40% | 約 4% 上下 | 3.3% |
| 負債比 | 約 40% 上下 | 約 70% 以上 | 35.1% |
| 流動比 | 約 2 倍多 | 約 1 倍上下 | 9.8 倍 |

幾個觀察：

- **毛利率**：台積電的晶片全世界最先進，客戶願意付高價，毛利率很高。統一超賣的是便當、飲料、日用品，大家都能賣，毛利率自然低得多。小明文具行的 50% 是因為我們設定它用進價的兩倍賣，真實文具店通常沒這麼好。
- **淨利率**：統一超毛利率三成多，淨利率卻只有百分之幾，中間被店租、人事、水電吃掉了——便利商店是「薄利多銷」，靠的是全台灣幾千家店累積出來的巨大收入。小明文具行的 3.3% 比統一超還低，原因是剛開店、營業額還小：光房租 8,000 就吃掉收入的 27%，工讀生再吃掉 10%。台積電費用占收入的比例小，淨利率驚人。
- **負債比**：統一超的負債比高，很大一部分是因為它租了幾千家店面，依現在的會計規則，長期租約也要算成負債，這不代表它快倒了。台積電負債比中等，而且現金非常多。小明的 35% 幾乎全是那筆銀行借款。
- **流動比**：統一超接近 1，看起來「不安全」，但便利商店每天收現金、每月才付貨款，現金流穩定，在這個行業很正常。台積電 2 倍多，很穩。小明的 9.8 倍是剛開店、現金還沒用出去的樣子，等到要還銀行本金那一年，這個數字會掉很多。

同樣是「好公司」，四個比率卻完全不同。**沒有一個比率可以單獨判斷公司好壞，一定要四個一起看、跟同行一起看。**

### 財報去哪裡找：公開資訊觀測站

台灣所有上市、上櫃公司的財報都要公開放在「公開資訊觀測站」（網址 mops.twse.com.tw），任何人都可以免費看。大致的找法如下（網站版面偶爾會改，找不到時用網站上方的搜尋功能，或請大人幫忙）：

1. 打開 mops.twse.com.tw。
2. 在上方選單找「財務報表」，再找「採 IFRSs 後」底下的「財務報告書」或「資產負債表／綜合損益表」查詢。
3. 輸入公司代號（台積電 2330、統一超 2912）、年度和季別，按查詢。
4. 你會看到很長的資產負債表和綜合損益表。找這幾行：資產總計、負債總計、流動資產合計、流動負債合計、營業收入、營業毛利、本期淨利（找「歸屬於母公司業主」的那個）。
5. 把數字抄下來，用本章的四個公式算。

看真實財報時有幾件事要先知道：

- **單位**：上市公司財報的單位通常是「新台幣千元」，看到「2,161,735,841」要在心裡加三個零，是 2 兆多。
- **合併**：大公司的財報叫「合併財務報表」，把旗下所有子公司加在一起看，看「合併」那一份就好。年報的數字比季報完整。
- **讀不懂的科目先跳過**：真實財報有幾十個科目，你只要抓到算四個比率需要的那六、七個數字就夠了。

## 動手做

### 活動 11-1：三張表勾稽連連看

**材料／工具**：第 8、9、10 章你自己編的三張小明文具行報表（手寫或列印出來）、三種顏色的筆、尺。

**步驟**：

1. 把三張報表並排放在桌上：左邊損益表、中間資產負債表、右邊現金流量表。
2. 用第一種顏色，從損益表的「本期淨利 1,000」畫一條線到資產負債表權益區的「本期淨利 1,000」。在線旁邊寫「期初權益 0 + 投入 50,000 + 淨利 1,000 − 提取 2,000 = 49,000」。
3. 用第二種顏色，從現金流量表的「期末現金 40,700」畫一條線到資產負債表的「現金 40,700」。
4. 用第三種顏色，從損益表的「折舊費用 200」畫一條線到資產負債表的「累計折舊 (200)」。
5. 再找一找：現金流量表的「購買設備 (12,000)」「銀行借款 20,000」「業主投入 50,000」「業主提取 (2,000)」，在資產負債表上各對到哪一行？把找到的每一條都畫出來。
6. 數數看你總共畫了幾條線。

**你應該看到／得到**：至少七條線：淨利、現金、折舊、設備、銀行借款、業主資本、業主提取。現金流量表的投資和籌資活動，幾乎每一項都能在資產負債表上找到對應的「存量」。三張報表是同一套帳的三個角度。

### 活動 11-2：小明文具行的健康檢查卡

**材料／工具**：筆、紙、計算機、三張報表。

**步驟**：

1. 在紙上畫一張「健康檢查卡」，四列：毛利率、淨利率、負債比、流動比。
2. 從報表上找出每個比率需要的兩個數字，抄下來，算出比率。毛利率、淨利率、負債比用百分比，流動比用「倍」。
3. 每個比率旁邊，用一句話寫下它回答的是姑姑哪個問題，以及你的判斷（好、普通、要注意）。
4. 現在假設 11 月的數字變成（延續第 9、10 章想一想裡的假設）：收入 33,000、毛利 16,000、淨利 1,900；資產總計 76,000、負債總額 25,100、流動資產 64,400、流動負債 5,100。再算一次四個比率，填在第二欄。
5. 比較 10 月和 11 月：哪些比率變好、哪些變差？如果你是姑姑，看到 11 月的變化會問小明什麼問題？

**你應該看到／得到**：10 月：50%、3.3%、35.1%、9.8 倍。11 月：48.5%、5.8%、33.0%、12.6 倍。淨利率、負債比、流動比都變好了，只有毛利率從 50% 掉到 48.5%。看起來是好消息，但姑姑一定會問：「進價是不是漲了？賣的組合有沒有變？」毛利率每掉一個百分點，營業額大了以後都是很多錢。

### 活動 11-3：到公開資訊觀測站找一家公司的財報

**材料／工具**：能上網的電腦或平板、筆、紙、計算機。約需 30 到 60 分鐘，第一次做建議請大人一起。

**步驟**：

1. 選一家你有興趣、生活中接觸得到的台灣上市公司，例如統一超（2912）、全家（5903）、台積電（2330）、巨大（9921，捷安特）。先上網查它的股票代號。
2. 打開 mops.twse.com.tw，照本章「財報去哪裡找」的方法，查出它最近一個年度的合併財報。
3. 從資產負債表抄下：流動資產合計、資產總計、流動負債合計、負債總計。
4. 從綜合損益表抄下：營業收入、營業成本（或營業毛利）、本期淨利（歸屬母公司業主）。
5. 注意單位是「千元」。為了好算，可以先全部除以 1,000,000，換成「十億元」再算。
6. 算出四個比率，填進健康檢查卡。
7. 用同樣的方法再查一家「同行」（例如統一超對全家、台積電對聯電 2303），把兩家並排比較。
8. 寫下三句話：這家公司最漂亮的比率是哪個？最需要注意的是哪個？跟同行比它哪裡不一樣？

**你應該看到／得到**：一張用真實數字算出來的健康檢查卡。你算出的台積電或統一超數字應該跟本章的概數「差不多但不完全一樣」；如果差很多，先檢查單位（千元）和有沒有抄錯行。

## 用工具看看

延續前三章的 Google 試算表檔案，新增一張「比率」分頁，讓四個比率直接從三張報表自動算出來，並用顏色提示。

**步驟**：

1. 打開「小明文具行-資產負債表」檔案，新增工作表，命名為「比率」。
2. A1 到 A4 依序填：毛利率、淨利率、負債比、流動比。B 欄直接放公式。
3. B1 輸入 `='損益表'!B3/'損益表'!B1`（毛利 ÷ 收入）。
4. B2 輸入 `='損益表'!B13/'損益表'!B1`（淨利 ÷ 收入）。
5. B3 輸入負債合計除以資產總計。照第 8 章的排法，負債合計在 E8、資產總計在 B12，就輸入 `='資產負債表'!E8/'資產負債表'!B12`。請依你實際的格子位置調整。
6. B4 輸入流動資產合計除以流動負債合計，例如 `='資產負債表'!B7/'資產負債表'!E5`。
7. 選取 B1 到 B3，按工具列的「%」按鈕變成百分比；B4 保持小數，顯示「倍」。
8. 加紅綠燈：選取 B4，點上方選單「格式」→「條件式格式」。規則設定「小於 1」時背景填紅色；再新增一條規則「大於或等於 1」填綠色。同樣幫 B3 設「大於 0.5」填紅色。

**你應該看到**：B1 顯示 50.00%、B2 顯示 3.33%、B3 顯示 35.10%、B4 顯示 9.80，B3 和 B4 都是綠的。現在到「損益表」把銷貨收入改成 20000（其他不動），毛利率會變成 25%、淨利率變成負的。再到「資產負債表」把銀行借款改成 60000、現金改成 80700（想像多借了 4 萬），負債比跳到約 57.6%，B3 變紅。改回來又會變綠。這是一張「活的」健康檢查卡：帳一改，體檢報告馬上更新。

## 常見錯誤與迷思

- **錯誤想法：淨利率高的公司一定比淨利率低的公司好。** → 為什麼錯：不同行業的淨利率天生就不同，便利商店 4% 可能已經是同行第一。 → 正確理解：比率要跟同行比、跟自己過去比，不能跨行業直接比大小。
- **錯誤想法：負債比高就是快倒了。** → 為什麼錯：有些行業（銀行、租很多店面的零售業）負債比本來就高，而且借錢做生意本身不是壞事。 → 正確理解：看負債比的趨勢、看它付不付得出利息、搭配流動比和營業現金流一起看。
- **錯誤想法：流動比越高越好。** → 為什麼錯：流動比太高可能代表現金或存貨堆著沒用，沒有在幫公司賺錢。 → 正確理解：流動比要「夠」（大多數行業 1.5–2 左右）就好，不是越大越好。
- **錯誤想法：三張報表不相干，看一張就夠。** → 為什麼錯：損益表漂亮但現金流量表很慘（表哥的滷味攤），是只看一張表會錯過的危險。 → 正確理解：三張表是同一套帳的三個角度，要串起來一起看。
- **錯誤想法：本章表裡的台積電、統一超數字可以直接拿去用。** → 為什麼錯：那些是某一年的概數，每一季都在變。 → 正確理解：永遠以公開資訊觀測站上最新的財報為準，自己算一次。

## 想一想

1. 一家店資產總計 200,000、負債總額 80,000、流動資產 60,000、流動負債 40,000。負債比和流動比各是多少？

<details><summary>參考答案</summary>

負債比 = 80,000 ÷ 200,000 = 40%；流動比 = 60,000 ÷ 40,000 = 1.5 倍。

</details>

2. 小明文具行 11 月如果向銀行多借 20,000 元現金（其他不變），負債比和流動比會怎麼變？（提示：這筆借款也是兩年後才還，算非流動負債；現金是流動資產。）

<details><summary>參考答案</summary>

資產總計 95,500、負債總額 46,500，負債比 = 46,500 ÷ 95,500 ≈ 48.7%（從 35.1% 上升）。流動資產變 83,700，流動負債不變 6,500，流動比 ≈ 12.9 倍（從 9.8 上升）。借長期的錢會讓負債比變高、但流動比反而變高，因為現金多了而一年內要還的沒變。

</details>

3. 用本章的三條勾稽線檢查：某人編的報表，損益表淨利 6,000，資產負債表期初權益 50,000、期末權益 55,200，中間老闆沒有投入也沒領錢。哪裡錯了？可能的原因是什麼？

<details><summary>參考答案</summary>

期末權益 − 期初權益 = 5,200，但損益表淨利 6,000，差 800。可能是損益表漏了一筆 800 元的費用（例如少扣了折舊或水電），或資產負債表的某個負債少記了 800。要回頭核對試算表。

</details>

4. 甲公司毛利率 60%、淨利率 5%；乙公司毛利率 25%、淨利率 10%。你會問這兩家公司各什麼問題？

<details><summary>參考答案</summary>

甲公司：東西很好賺，但扣完費用只剩 5%，中間 55 個百分點的費用花到哪裡去了？是店租太貴、人太多、還是廣告花太兇？乙公司：東西本身不好賺，但費用控制得很好，問題在能不能把毛利率拉高一點（談到更便宜的進價、或賣更高價的商品），一旦進價上漲它會很快沒有利潤。

</details>

5. （挑戰）一家公司連續三年：淨利率 15%、14%、13%；負債比 30%、45%、60%；流動比 2.0、1.4、0.9；營業活動現金流 +50 萬、+10 萬、−30 萬。每一年單看數字都「還可以」，但你會不會投資它？為什麼？

<details><summary>參考答案</summary>

不會，至少要先問清楚。四條線全部朝壞的方向走：賺錢能力下降、越來越依賴借款、一年內的償債能力從安全變成不足（流動比低於 1）、做生意本身開始燒現金。單看第三年「淨利率 13%」還是賺錢的公司，但趨勢顯示它可能正在用借來的錢撐住一個越來越不賺錢的生意，是黑字倒閉的前兆。重點：先看趨勢，再看數字。

</details>

6. （挑戰）選一家你在活動 11-3 查過的公司，寫一段 150 字給「完全沒學過會計的朋友」的介紹：它是做什麼的、賺不賺錢、安不安全、你最想提醒朋友注意哪一點。不能出現「毛利率」「負債比」這些詞，要用生活的話講。

<details><summary>參考答案</summary>

開放題。好的回答會把比率「翻譯」成生活語言，例如：「這家便利商店每賣 100 元的東西，最後大概只留下 4 元，靠的是全台灣幾千家店加起來的量。它欠的錢看起來很多，但大部分是未來要付的店租。它每天收現金、月底才付貨款，不太會付不出來。要注意的是，如果店租或人事費用漲很多，那 4 元可能就不見了。」

</details>

## 本章小結

- 三張報表是同一套帳的三個角度：期初照片 → 一段期間的影片（損益表、現金流量表）→ 期末照片。
- 三條主要勾稽線：淨利 → 權益（期初 + 投入 + 淨利 − 提取 = 期末）；期末現金 → 資產負債表現金；折舊費用 → 累計折舊。任何一條對不上就是有錯。
- 四個基本比率：毛利率、淨利率看賺錢能力；負債比看依賴借款的程度；流動比看短期付不付得出錢。
- 小明文具行 10 月：毛利率 50%、淨利率 3.3%、負債比 35.1%、流動比 9.8 倍。
- 比率要跟自己過去比、跟同行比；先看趨勢，再看數字。台積電和統一超都是好公司，但四個比率長得完全不同。
- 上市公司財報都在公開資訊觀測站免費公開，單位通常是千元；書裡的真實公司數字只是概數，永遠以最新財報為準。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 財務比率 | Financial Ratio | 把報表上兩個數字相除得到的比例，用來快速判斷公司的狀況。 |
| 毛利率 | Gross Margin | 毛利 ÷ 收入，看賣的東西本身好不好賺。 |
| 淨利率 | Net Margin | 淨利 ÷ 收入，看扣掉所有開銷後每 1 元收入留下多少。 |
| 負債比 | Debt Ratio | 負債總額 ÷ 資產總額，看公司的東西有幾成是靠借來的錢買的。 |
| 流動比 | Current Ratio | 流動資產 ÷ 流動負債，看一年內要付的錢付不付得出來。 |
| 勾稽 | Articulation | 三張報表之間互相對得起來的關係，例如淨利對權益、期末現金對現金。 |
| 存量與流量 | Stock and Flow | 存量是某一天的數量（資產負債表），流量是一段期間的變動（損益表、現金流量表）。 |
| 趨勢 | Trend | 同一個比率連續好幾期的變化方向，比單一數字更重要。 |
| 公開資訊觀測站 | Market Observation Post System (MOPS) | 台灣證券交易所提供的網站，所有上市上櫃公司的財報都在上面免費公開。 |
| 合併財務報表 | Consolidated Financial Statements | 把母公司和它所有子公司加在一起編的財報，看大公司時看這一份。 |
| 股票代號 | Stock Code | 每家上市公司的四位數編號，例如台積電 2330、統一超 2912。 |
