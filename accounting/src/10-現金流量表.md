# 第 10 章　現金流量表

## 本章目標

- 學完你會解釋為什麼「有賺錢」的公司也可能因為沒現金而倒閉。
- 學完你會把每一筆現金進出分到營業、投資、籌資三個籃子裡。
- 學完你會用最簡單的直接法，從現金帳編出一張現金流量表。
- 學完你會把現金流量表的期末現金跟資產負債表的現金對起來，並說出「淨利」和「營業現金流」為什麼不一樣。
- 學完你會看懂一家真實上市公司現金流量表的三大段落。

## 開場：表哥的滷味攤「明明有賺錢」

小明的表哥在夜市擺滷味攤，生意非常好，每天排隊。有一天表哥愁眉苦臉地來找小明：「我帳算過了，上個月賺了四萬多，可是我現在連付給批發商的三萬都拿不出來，他說再不付就不送貨了。賺錢的攤子怎麼會沒錢？」

小明翻了表哥的帳本，很快就找到原因。表哥上個月花了十五萬買了一台新的大型冷凍櫃，又讓好幾家熟客的辦公室「月結」（吃了先記帳，月底一次付），結果收入都還在人家口袋裡，自己的現金卻早就花光了。

損益表說表哥賺了四萬多，這是真的；但損益表不管「錢到了沒」，也不管「買冷凍櫃的錢」，因為冷凍櫃是資產，不是費用。要看表哥「口袋裡的錢怎麼進怎麼出」，需要第三張報表：**現金流量表（Cash Flow Statement）**。

這一章我們就來編小明文具行的現金流量表，你會驚訝地發現：小明 10 月明明賺了 1,000 元，光做生意的部分，現金竟然是「減少」15,300 元。

## 核心概念

### 利潤和現金是兩回事

前兩章一直在提醒：**賺多少**（損益表）和**手上有多少現金**（資產負債表的現金）是兩個不同的問題。為什麼會不一樣？因為會計用「應計基礎」記帳，而現金是「真的收到、真的付出」才算。兩者差在這幾種情況：

| 情況 | 損益表怎麼看 | 現金怎麼看 |
|---|---|---|
| 補習班賒帳買了 5,000 元文具，月底收回 3,000 | 收入 +5,000 | 現金只收到 3,000（還有 2,000 沒到） |
| 進貨 20,000 但只賣掉 15,000 | 成本只算 15,000 | 現金付了 5,000（現購）＋ 10,000（還賒帳），還欠批發商 5,000 |
| 一次預付三個月房租 24,000 | 費用只算這個月的 8,000 | 現金付了 24,000 |
| 水電費 1,500 月底帳單還沒來 | 費用 +1,500 | 現金 0 |
| 電腦折舊 200 | 費用 +200 | 現金 0（錢是買的那天付的） |
| 買電腦 12,000 | 不是費用（是資產） | 現金 −12,000 |
| 老闆投入 50,000、向銀行借款 20,000 | 不是收入 | 現金 +70,000 |
| 老闆拿 2,000 回家當生活費 | 不是費用 | 現金 −2,000 |

你看，每一行左右兩邊都不一樣。一家公司可能損益表很漂亮，現金卻快見底；也可能損益表虧損，現金卻很多（例如剛借了一大筆錢）。能撐住一家公司的是現金，不是帳面利潤。生意人有句話：「**利潤是意見，現金是事實**。」公司因為付不出錢而倒閉，就算帳上有賺，叫做「黑字倒閉」，表哥的滷味攤差一點就是這樣。

### 現金流量表回答的問題

現金流量表跟損益表一樣是「一段期間的影片」，標題寫「10 月 1 日至 10 月 31 日」。它只盯著一個科目：現金。它要回答：

```
期初現金 + 這段期間流進來的 − 這段期間流出去的 = 期末現金
   0     +         ?        −         ?         =  40,700
```

小明文具行 10 月 1 日開店前現金是 0，10 月 31 日資產負債表上現金是 40,700。現金流量表就是要把中間那個「+40,700」拆開來講清楚：是做生意賺來的？賣東西收來的？還是借來的？

### 三個籃子：營業、投資、籌資

現金流量表最重要的設計，是把所有現金進出分成三個籃子：

**籃子一：營業活動（Operating Activities）**——「做生意本身」的現金進出。賣東西收到的錢、付給供應商的貨款、付房租、付水電、付薪水、付利息，全部放這裡。這個籃子回答：「光靠做生意，現金是變多還是變少？」健康的公司，這個籃子長期一定要是正的。

**籃子二：投資活動（Investing Activities）**——買賣「用很久的東西」的現金進出。買電腦、買貨架、買店面是流出；把舊設備賣掉是流入。這個籃子回答：「公司在為未來花多少錢？」成長中的公司這裡常常是負的，那不是壞事。

**籃子三：籌資活動（Financing Activities）**——跟「出錢的人」之間的現金進出。老闆投入資本、跟銀行或家人借錢是流入；還借款本金、老闆領錢出去（或公司發股利給股東）是流出。這個籃子回答：「錢是從哪裡來的？有沒有還回去？」

```
                  ┌──────────────────┐
   顧客付錢 ──────▶│                  │──────▶ 付供應商、房租、水電   ┐ 營業
                  │                  │                              ┘
   賣掉舊設備 ────▶│    現  金        │──────▶ 買電腦、買設備        ┐ 投資
                  │                  │                              ┘
   老闆投入、借款 ─▶│                  │──────▶ 還錢、老闆領走        ┐ 籌資
                  └──────────────────┘                              ┘
```

怎麼判斷一筆錢該放哪個籃子？問自己三個問題，依序問：

1. 這是跟「出錢給公司的人」（老闆、銀行、家人）之間的來往嗎？→ 是：籌資。
2. 這是買或賣「要用超過一年的東西」嗎？→ 是：投資。
3. 都不是？→ 營業。

一個小細節：付給銀行的**利息**算營業活動（它是這個月做生意的開銷之一），還**本金**才算籌資。小明 10 月只付了利息 100，沒還本金。

### 最簡單的直接法：翻現金帳，一筆一筆分

編現金流量表有兩種方法。**直接法（Direct Method）**就是把現金帳裡的每一筆進出翻出來，貼標籤分籃子，然後加總。這是最直覺的方法，也是本書用的方法。另一種叫間接法，從淨利倒推回去，這一章的後面會用它來解釋淨利和現金的差距，但不要求你會編。

小明文具行 10 月所有動到現金的交易如下（從第 5 章的 20 筆交易挑出來，共 18 筆；第 5 筆賒購、第 12 筆賒銷和四筆調整分錄都沒動到現金，所以不在裡面）：

| 傳票 | 日期 | 事情 | 現金 | 籃子 |
|---|---|---|---:|---|
| 001 | 10/1 | 小明投入資本 | +50,000 | 籌資 |
| 002 | 10/1 | 向銀行借款 | +20,000 | 籌資 |
| 003 | 10/1 | 預付三個月房租 | −24,000 | 營業 |
| 004 | 10/2 | 買收銀電腦 | −12,000 | 投資 |
| 006 | 10/4 | 現金進貨 | −5,000 | 營業 |
| 007 | 10/5 | 開幕傳單 | −500 | 營業 |
| 008 | 10/6 | 開幕日銷貨 | +4,000 | 營業 |
| 009 | 10/10 | 償還批發商賒帳 | −10,000 | 營業 |
| 010 | 10/12 | 第一週銷貨 | +6,000 | 營業 |
| 011 | 10/14 | 網路費 | −400 | 營業 |
| 013 | 10/19 | 第二週銷貨 | +6,000 | 營業 |
| 014 | 10/20 | 補習班付來部分賒帳 | +3,000 | 營業 |
| 015 | 10/25 | 工讀生薪資 | −3,000 | 營業 |
| 016 | 10/26 | 第三週銷貨 | +5,000 | 營業 |
| 017 | 10/27 | 紙袋、收據本 | −300 | 營業 |
| 018 | 10/28 | 老闆拿回家當生活費 | −2,000 | 籌資 |
| 019 | 10/31 | 第四週銷貨 | +4,000 | 營業 |
| 020 | 10/31 | 付 10 月借款利息 | −100 | 營業 |
| | | **合計** | **+40,700** | |

注意幾個容易搞錯的地方：

- 付房租是 24,000 而不是 8,000。損益表只認這個月的 8,000，但現金真的付出去 24,000。
- 付給供應商是 15,000（現金進貨 5,000 ＋ 償還賒帳 10,000）而不是 20,000。另外 5,000 還欠著，沒有現金流出。
- 收款是 28,000（現銷 25,000 ＋ 補習班付來的 3,000）而不是 30,000。補習班的 2,000 還沒收到。
- 水電費 1,500 和折舊 200 完全不出現，因為這個月沒有為它們付出任何現金。
- 老闆拿走的 2,000 不是費用，是跟「出錢的人」之間的來往，放籌資。

### 完成品：小明文具行的現金流量表

把三個籃子各自加總：

**小明文具行　現金流量表　10 月 1 日至 10 月 31 日**

| 項目 | 金額 |
|---|---:|
| **營業活動之現金流量** | |
| 　收自顧客的現金 | 28,000 |
| 　付給供應商的現金 | (15,000) |
| 　付房租的現金（預付三個月） | (24,000) |
| 　付薪資的現金 | (3,000) |
| 　付廣告費的現金 | (500) |
| 　付雜項（網路費、紙袋）的現金 | (700) |
| 　付利息的現金 | (100) |
| 營業活動淨現金流入（流出） | (15,300) |
| **投資活動之現金流量** | |
| 　購買設備（電腦） | (12,000) |
| 投資活動淨現金流入（流出） | (12,000) |
| **籌資活動之現金流量** | |
| 　業主投入資本 | 50,000 |
| 　銀行借款 | 20,000 |
| 　業主提取 | (2,000) |
| 籌資活動淨現金流入（流出） | 68,000 |
| **本期現金增加（減少）** | **40,700** |
| 加：期初現金 | 0 |
| **期末現金** | **40,700** |

最後一行期末現金 40,700，翻回第 8 章的資產負債表，現金也是 40,700，對上了。這是三張報表的第二條勾稽線：**現金流量表的期末現金 = 資產負債表的現金**。

再看這張表在說什麼故事：小明 10 月做生意的現金流是 −15,300（營業活動），主要是因為一次預付了三個月房租 24,000、又進了 20,000 的貨而大部分貨款都付了；為了開店買電腦又花了 12,000（投資活動），這兩個洞全靠老闆投入和銀行借款的 68,000（籌資活動，已扣掉老闆拿走的 2,000）補起來。換句話說，**10 月文具行的現金完全是靠「外面給的錢」在撐，做生意本身還沒開始帶來現金**。這對剛開的店很正常（預付三個月房租的效果，11、12 月就會反過來），但如果到了第三、第四個月營業活動還是負的，就要警覺了。

### 為什麼賺了 1,000，營業現金卻是 −15,300？

這是本章最重要的一個問題。淨利 1,000 和營業現金流 −15,300 差了 16,300，這 16,300 去哪了？我們可以一項一項找回來：

| 淨利和營業現金的差異來源 | 對現金的影響 | 說明 |
|---|---:|---|
| 本期淨利 | 1,000 | 起點 |
| 加回折舊 | +200 | 它是費用，但沒付現金 |
| 應收帳款增加 | −2,000 | 收入裡有 2,000 還沒收到錢 |
| 存貨增加 | −5,000 | 買了 5,000 元的貨還沒賣掉，錢已經付（或欠著） |
| 預付租金增加 | −16,000 | 多付了 11、12 月的房租 |
| 應付帳款增加 | +5,000 | 進貨有 5,000 先欠著，現金還沒付 |
| 應付費用增加 | +1,500 | 水電費還沒付 |
| **營業活動淨現金流** | **−15,300** | 終點，跟直接法算出來的一樣 |

驗算：1,000 + 200 − 2,000 − 5,000 − 16,000 + 5,000 + 1,500 = −15,300。

這張表就是「間接法」的現金流量表，你不必會編，但要看得懂它的邏輯：**從淨利出發，把「沒動到現金的費用」加回來，再把「資產負債表上流動資產、流動負債的變化」調整進去**。口訣是：

- 折舊這類「不用付錢的費用」：加回來。
- 應收帳款、存貨、預付費用這些流動資產**增加**：現金被卡在裡面，減掉。
- 應付帳款、應付費用這些流動負債**增加**：錢先欠著沒付，加回來。

小明最大的一筆是預付租金 16,000：這是 11、12 月的房租，錢已經出去了，但損益表要到那兩個月才會認成費用。表哥的滷味攤則是「應收帳款增加」（辦公室月結）和「投資活動流出」（冷凍櫃）同時發生，才會賺錢卻沒錢。

### 看一張真實公司的現金流量表（簡化版）

台積電某一年的現金流量表三大段落，**概數**，單位「兆元」。真實數字請查公開資訊觀測站（mops.twse.com.tw），這裡只看結構：

| 項目 | 約略金額 | 小明文具行 |
|---|---:|---:|
| 營業活動淨現金流入 | 約 +1.2 兆 | −15,300 |
| 投資活動淨現金流出（主要是蓋廠、買機器） | 約 −0.9 兆 | −12,000 |
| 籌資活動淨現金流出（主要是發股利給股東、還債） | 約 −0.4 兆 | +68,000 |
| 期末現金 | 約 1.7 兆 | 40,700 |

對比一下很有意思：台積電是「營業正、投資負、籌資負」，意思是做生意賺進大把現金，一部分拿去蓋新廠，一部分還給股東，是一家成熟又在成長的公司的典型樣子。小明文具行是「營業負、投資負、籌資正」，是一家剛開張、靠外來資金撐著的店的典型樣子。光看三個籃子的正負號，就能大致猜出一家公司處在什麼階段：

| 營業 | 投資 | 籌資 | 可能是什麼情況 |
|---|---|---|---|
| ＋ | − | − | 成熟賺錢的公司：賺錢、投資、還錢給股東 |
| ＋ | − | ＋ | 快速成長的公司：賺錢但不夠花，還在借錢擴張 |
| − | − | ＋ | 剛起步的公司（小明文具行）：靠外來資金撐 |
| − | ＋ | − | 危險訊號：做生意賠錢，靠賣資產來還債 |

## 動手做

### 活動 10-1：三個籃子分類卡

**材料／工具**：12 張小紙卡（便利貼也可以）、三個碗或三張寫著「營業」「投資」「籌資」的紙、筆。

**步驟**：

1. 把下面 12 筆交易各抄在一張紙卡上（只抄事情和金額，不要抄答案）：
   (1) 顧客付現金買筆 500 元；(2) 付店租 8,000 元；(3) 買一台二手影印機 6,000 元；(4) 老闆從店裡拿走 2,000 元買自己的晚餐；(5) 還銀行 5,000 元借款本金；(6) 把壞掉的舊電腦賣了 1,000 元；(7) 付上個月欠供應商的貨款 8,000 元；(8) 收到補習班付的賒帳 5,000 元；(9) 跟銀行借 30,000 元；(10) 付員工薪水 3,000 元；(11) 付了下個月的水電費 1,200 元；(12) 老闆再投入 10,000 元。
2. 一張一張拿起來，用本章的三個問題判斷（先問是不是跟出錢的人來往→再問是不是買賣長期資產→都不是就是營業），丟進對應的碗。
3. 每個碗裡分「流入」和「流出」兩疊，各自加總。
4. 算出三個籃子的淨流量，再加總，看看現金總共變多少。

**你應該看到／得到**：營業籃子：(1)(2)(7)(8)(10)(11)，淨流量 = 500 − 8,000 − 8,000 + 5,000 − 3,000 − 1,200 = −14,700。投資籃子：(3)(6)，淨流量 = −6,000 + 1,000 = −5,000。籌資籃子：(4)(5)(9)(12)，淨流量 = −2,000 − 5,000 + 30,000 + 10,000 = +33,000。總計 +13,300。最容易放錯的是 (4) 老闆拿錢走（這是跟出錢的人來往，屬籌資）和 (7)(8) 付貨款、收賒帳（雖然是以前的交易，但都是做生意的錢，屬營業）。

**觀察與記錄**：

| 籃子 | 我放了哪幾張 | 流入合計 | 流出合計 | 淨流量 |
|---|---|---:|---:|---:|
| 營業 | | | | |
| 投資 | | | | |
| 籌資 | | | | |
| 合計 | | | | |
| 我放錯的是哪幾張？為什麼？ | | | | |

### 活動 10-2：編小明文具行的現金流量表，並和資產負債表對帳

**材料／工具**：筆、紙、計算機、第 5 章的 20 筆交易表與第 8 章的資產負債表。

**步驟**：

1. 從第 5 章的 20 筆交易裡，把動到「現金」的那幾筆圈出來（應該有 18 筆）。第 7 章的四筆調整分錄都沒有現金，跳過。
2. 每一筆標上籃子名稱和正負號。
3. 寫標題「小明文具行　現金流量表　10 月 1 日至 10 月 31 日」，分三段列出，每段加總。
4. 三段相加得到本期現金增減，加上期初現金 0，得到期末現金。
5. 翻到資產負債表，看現金那一行，確認相同。
6. 再翻到損益表，把淨利 1,000 和你算出的營業活動淨現金流並排寫下來，照本章「為什麼賺了 1,000，營業現金卻是 −15,300」那張表，一項一項把差額找回來。

### 活動 10-3：「賺錢卻沒錢」桌上模擬

**材料／工具**：一疊硬幣或遊戲代幣（代表現金，至少 60 枚，1 枚 = 100 元）、紙、筆。找一個家人或同學當「批發商」兼「顧客」會更好玩。

**步驟**：

1. 設定：你開一家小店，手上現金 2,000 元（20 枚）。每個月跟批發商進 10 件貨，每件 100 元，**進貨要當場付現**。每個月賣出 10 件，每件 150 元，但顧客都是學校，**兩個月後才付錢**。沒有其他費用。
2. 第 1 個月：付 1,000 給批發商（手上剩 10 枚）。賣出 10 件，在紙上記「應收帳款 1,500（第 3 個月收）」。記下這個月的淨利：收入 1,500 − 成本 1,000 = 500。手上現金：10 枚。
3. 第 2 個月：付 1,000 給批發商（手上剩 0 枚）。賣出 10 件，記應收 1,500（第 4 個月收）。淨利 500。手上現金：0 枚。
4. 第 3 個月：要付 1,000 給批發商，但手上 0 枚！這時第 1 個月的應收 1,500 剛好收到，付掉 1,000，剩 5 枚。賣出 10 件，記應收。淨利 500。
5. 現在改一個條件重玩：顧客改成「三個月後」才付錢。重新從第 1 個月開始，看你在第幾個月付不出貨款。
6. 再改一次：你想在第 2 個月花 1,500 買一台展示櫃。看看會發生什麼事。

**你應該看到／得到**：三個月下來你「每個月都賺 500」，損益表很漂亮，但現金一路從 2,000 掉到 0，第 3 個月全靠收回舊帳才活下來。顧客改成三個月後付款，你在第 3 個月就付不出貨款，店會倒，即使帳上一直在賺。這就是「黑字倒閉」。

## 用工具看看

在 Google 試算表裡，我們用「現金帳＋分類欄＋SUMIF」的方式，讓現金流量表從現金帳自動長出來。

**步驟**：

1. 打開前兩章的「小明文具行-資產負債表」檔案，新增一張工作表，命名為「現金帳」。
2. 第 1 列打標題：A1「日期」、B1「事情」、C1「金額」、D1「籃子」。
3. 從第 2 列開始，把 10 月 18 筆現金交易填進去。金額流入填正數、流出填負數；D 欄填「營業」「投資」或「籌資」三個字之一（要完全一樣，不要多打空格）。例如：A2「10/1」、B2「投入資本」、C2「50000」、D2「籌資」；A4「10/1」、B4「預付三個月房租」、C4「-24000」、D4「營業」……18 筆都填完。
4. 再新增一張工作表「現金流量表」。A1 填「營業活動」、A2 填「投資活動」、A3 填「籌資活動」、A4 填「本期現金增減」、A5 填「期初現金」、A6 填「期末現金」、A7 填「資產負債表現金」、A8 填「檢查」。
5. B1 輸入 `=SUMIF('現金帳'!D:D,"營業",'現金帳'!C:C)`。意思是：在現金帳的 D 欄找「營業」，把對應 C 欄的金額加起來。應該顯示 -15300。
6. B2、B3 照樣輸入，把 "營業" 換成 "投資"、"籌資"。應顯示 -12000 和 68000。
7. B4 輸入 `=SUM(B1:B3)`，B5 填 0，B6 輸入 `=B4+B5`。
8. B7 輸入 `='資產負債表'!B3`（B3 是第 8 章資產負債表分頁裡現金所在的格子，如果你放在別格請改成那一格）。
9. B8 輸入 `=IF(B6=B7,"現金對得上","對不上！差 "&ABS(B6-B7))`。

**你應該看到**：B6 和 B7 都是 40700，B8 顯示「現金對得上」。現在到「現金帳」再新增一筆：「11/1，收到補習班剩下的賒帳，2000，營業」。回到「現金流量表」，B1 會變成 -13300、B6 變成 42700，而 B8 顯示「對不上！差 2000」——因為資產負債表的現金還是 40700。去資產負債表把現金改成 42700、應收帳款改成 0，B8 又會變回「現金對得上」，資產負債表也還是平衡的。做完記得把這筆刪掉。

這個檔案現在有四張分頁：資產負債表、損益表、現金帳、現金流量表，而且三張報表之間有兩條公式接線（淨利、現金）。第 14 章的專題會把它擴充成完整的帳務系統。

## 常見錯誤與迷思

- **錯誤想法：公司有賺錢就不會倒。** → 為什麼錯：倒閉的直接原因是「付不出錢」，不是「帳上虧損」。 → 正確理解：淨利和現金是兩回事；賒銷太多、投資太猛、存貨囤太多，都會讓賺錢的公司沒現金，叫黑字倒閉。
- **錯誤想法：現金流量表上的房租是 8,000。** → 為什麼錯：損益表才認「這個月該算的費用」，現金流量表只認「這個月真的付的錢」。 → 正確理解：10 月真的付了 24,000，就寫 24,000。
- **錯誤想法：折舊要列在現金流量表的營業活動流出。** → 為什麼錯：折舊從來不是現金流出，買電腦那天付的 12,000 才是，而且它屬投資活動。 → 正確理解：直接法裡折舊根本不出現；間接法裡它是從淨利「加回來」的項目。
- **錯誤想法：老闆從店裡拿回家的 2,000 元是「費用」，放營業活動。** → 為什麼錯：老闆不是員工，拿走的錢是減少權益，不是開店的費用。 → 正確理解：這是跟「出錢的人」之間的來往，屬籌資活動流出。
- **錯誤想法：投資活動是負的代表公司不好。** → 為什麼錯：投資活動負的意思只是「花錢買了長期資產」，成長中的公司幾乎都是負的。 → 正確理解：要搭配營業活動一起看：營業正、投資負是健康的擴張；營業負、投資正（在賣資產）才是警訊。
- **錯誤想法：現金流量表的期末現金和資產負債表的現金可以不一樣。** → 為什麼錯：兩者說的是同一天、同一個東西。 → 正確理解：一定要相等，不相等就是有現金交易漏了或分類錯了。

## 想一想

1. 下面哪些是 10 月的現金流出？預付租金 24,000、水電費 1,500、折舊 200、進貨還欠的 5,000、買電腦 12,000、付工讀生薪資 3,000。

預付租金 24,000、買電腦 12,000 和付工讀生薪資 3,000 是 10 月的現金流出。水電費還沒付，折舊不是現金，欠的 5,000 還沒付。

</details>

2. 11 月 1 日補習班付清剩下的 2,000 元，小明同時付清欠批發商的 5,000 元。這兩筆各屬哪個籃子？11 月 1 日結束時現金多少？

<details><summary>參考答案</summary>

兩筆都是營業活動（收顧客的錢、付供應商的錢）。現金 = 40,700 + 2,000 − 5,000 = 37,700 元。

</details>

3. 一家公司某年營業活動 +80 萬、投資活動 −120 萬、籌資活動 +50 萬，期初現金 30 萬。期末現金多少？這家公司可能處在什麼階段？

<details><summary>參考答案</summary>

本期增減 = 80 − 120 + 50 = +10 萬，期末現金 40 萬。營業正、投資負、籌資正：做生意有賺現金但不夠投資，還在借錢擴張，像是快速成長期的公司。

</details>

4. 假設 11 月小明文具行淨利 1,900（第 9 章想一想第 3 題），折舊 200，應收帳款從 2,000 變成 0（減少 2,000），存貨從 5,000 變成 6,000（增加 1,000），預付租金從 16,000 變成 8,000（減少 8,000，因為用掉了一個月但沒付錢），應付帳款從 5,000 變成 3,000（減少 2,000），應付費用從 1,500 變成 2,100（增加 600）。用間接法的口訣算 11 月營業活動現金流。

<details><summary>參考答案</summary>

1,900 + 200（折舊加回）+ 2,000（應收減少，收回了現金）− 1,000（存貨增加，錢卡在貨裡）+ 8,000（預付租金減少：這個月的房租是用 10 月預付的，沒有付現金，所以要加回）− 2,000（應付帳款減少，把欠的錢付掉了）+ 600（應付費用增加，水電又欠著）= +9,700。11 月賺了 1,900，但營業現金流有 +9,700，比淨利高很多，主要是因為房租早在 10 月就付了。10 月預付三個月房租讓營業現金流很難看，11、12 月就會反過來變漂亮。

</details>

5. （挑戰）表哥的滷味攤上個月淨利 42,000，買冷凍櫃 150,000，辦公室月結讓應收帳款增加 60,000，折舊 2,000，其他不變，期初現金 180,000。請編出三段式的現金流量表（營業活動可用間接法算），並說明表哥為什麼付不出 30,000 的貨款。

<details><summary>參考答案</summary>

營業活動：42,000 + 2,000 − 60,000 = −16,000。投資活動：−150,000。籌資活動：0。本期現金增減 −166,000，期末現金 = 180,000 − 166,000 = 14,000。表哥手上只剩 14,000，付不出 30,000。解法可以是：先跟批發商談延後付款、向辦公室客戶催收、或暫時借一筆短期的錢（籌資活動）撐過去；下次買大型設備前要先算現金夠不夠。

</details>

6. （挑戰）幫小明設計三個「不用多賣任何東西」就能讓 11 月營業活動現金流變正的方法，並說說每個方法的副作用。

<details><summary>參考答案</summary>

例如：(1) 請補習班改成月初付款或付現，副作用是補習班可能改去別家買；(2) 跟批發商談把付款期限延到 60 天，副作用是批發商可能不給折扣或不再賒帳；(3) 少進一點貨、不要囤存貨，副作用是熱門商品可能缺貨；(4) 不要一次預付好幾個月房租，副作用是房東可能不願意或租金較高。重點是：現金流可以靠「收快一點、付慢一點、少囤一點」改善，但每一招都有代價。

</details>

## 本章小結

- 利潤和現金是兩回事：損益表用應計基礎，現金流量表只認真的收到、真的付出的錢。帳上賺錢卻付不出錢而倒閉，叫黑字倒閉。
- 現金流量表是「一段期間的影片」，公式是：期初現金 + 本期增減 = 期末現金。
- 三個籃子：營業（做生意本身，含付利息）、投資（買賣長期資產）、籌資（跟出錢的人來往，含老闆投入、借款、還本金、業主提取）。判斷順序：先問是不是籌資，再問是不是投資，都不是就是營業。
- 直接法：翻現金帳，每一筆貼標籤、分籃子、加總。調整分錄（折舊、應付、預付、盤點）都不動現金，不會出現在直接法裡。
- 小明文具行 10 月：營業 −15,300、投資 −12,000、籌資 +68,000，期末現金 40,700 = 資產負債表的現金。這是第二條勾稽線。
- 淨利 1,000 和營業現金流 −15,300 的差距 16,300，可以用「加回折舊、流動資產增加要減、流動負債增加要加」一項一項找回來，最大的一項是預付租金 16,000。
- 看三個籃子的正負號組合，可以猜出公司處在起步、成長、成熟或危險的哪個階段。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 現金流量表 | Cash Flow Statement | 一段期間內現金從哪裡來、到哪裡去的總結，分營業、投資、籌資三段。 |
| 營業活動 | Operating Activities | 做生意本身帶來的現金進出：收顧客的錢、付貨款、付房租水電薪水利息。 |
| 投資活動 | Investing Activities | 買或賣「用超過一年的資產」的現金進出，例如買電腦、賣舊設備。 |
| 籌資活動 | Financing Activities | 跟出錢的人（老闆、銀行、股東）之間的現金來往：投入、借款、還款、領錢、發股利。 |
| 直接法 | Direct Method | 把現金帳每一筆翻出來分類加總，編出現金流量表的方法。 |
| 間接法 | Indirect Method | 從淨利出發，加回非現金費用、調整流動資產負債的變化，推算出營業活動現金流的方法。 |
| 黑字倒閉 | Insolvency despite Profit | 帳上有賺錢（黑字）卻因為現金不足付不出錢而倒閉。 |
| 應計基礎 | Accrual Basis | 交易發生就記帳、不管現金到了沒的記帳方式，損益表用的就是它。 |
| 現金基礎 | Cash Basis | 只有現金真的進出才記的方式，現金流量表看的是這個。 |
| 期末現金 | Ending Cash | 期間結束那天手上的現金，必須等於同一天資產負債表上的現金。 |
