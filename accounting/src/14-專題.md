# 第 14 章　專題

## 本章目標

- 學完你會獨立完成一個月的個人零用錢帳，並從帳本編出資產負債表、損益表、現金流量表三張報表。
- 學完你會用 Google 試算表替小明文具行建一套「輸入日記帳，其他全部自動算」的帳務系統。
- 學完你會用檢查清單自己驗帳：借貸相等、報表相連、數字對得起來。
- 學完你會寫一份格式完整的專題報告，把你的帳本和報表講給別人聽。

## 開場：從「會做題目」到「做出一整套」

前面十三章，每一章你都做了一小段：第 5 章寫分錄、第 6 章編試算表、第 8 到 10 章編三張報表。但真正的會計工作不是一段一段的，是一整條線從頭做到尾：交易發生 → 記日記帳 → 過帳 → 試算 → 調整 → 編報表 → 看報表做決定。

這一章有兩個專題，就是要讓你把這條線走完一次。

**專題一**用你自己的錢。你會記一整個月的零用錢，月底編出屬於你自己的三張報表。這是全世界最真實的練習，因為每一塊錢都是你的。

**專題二**用小明文具行。你會在試算表裡建一套帳務系統，科目表、日記帳、分類帳、試算表、報表全部連動，之後只要在日記帳打一筆，三張報表就自動更新。做完它，你就有了一套可以拿來記任何小生意的工具。

兩個專題各有目標、步驟、範本表格和檢查清單。可以先做一個，也可以兩個都做。最後一節告訴你怎麼寫專題報告。

## 開始之前：好專題的三個條件

**第一，數字要對得起來。** 會計最棒的地方是它會自我檢查：借方總額等於貸方總額、資產等於負債加權益、損益表的淨利要出現在資產負債表的權益裡、現金流量表的期末現金要等於資產負債表的現金。四個檢查點只要有一個對不上，一定有地方錯了。專題報告裡要**寫出**你做了這些檢查。

**第二，過程要能重做。** 別人拿你的日記帳，照你寫的步驟，要能做出一樣的報表。所以步驟要寫清楚，公式要留在試算表裡，不要手算完直接填數字。

**第三，要有一個「所以呢」。** 報表做出來不是結束。你的零用錢結餘是正是負？文具行第一個月毛利率幾趴？接下來要改什麼？會計是拿來做決定的，報告最後要有這一段。

## 專題一：記錄我自己一個月的零用錢，編三張報表

### 目標

- 用正式的會計方法（科目、借貸、日記帳、分類帳、試算表）記一整個月的個人收支。
- 月底編出個人的資產負債表、損益表、現金流量表。
- 算出本月結餘與月底淨值，並和月初比較。

### 你需要的東西

- 一本小筆記本或手機的記事 App（隨手記每一筆）
- 一份 Google 試算表（週末整理用）
- 計算機
- 一個月的時間

### 步驟

**第 0 步：設計你的科目表（開始記帳前一天）**

個人的帳不需要幾十個科目，下面這套夠用。你可以增減，但增減後要一路用到底。

| 代號 | 科目 | 類別 | 增加記哪邊 | 說明 |
|---|---|---|---|---|
| 101 | 現金 | 資產 | 借 | 口袋和錢包裡的錢 |
| 102 | 悠遊卡 | 資產 | 借 | 卡片裡的餘額 |
| 103 | 存款 | 資產 | 借 | 撲滿或銀行帳戶 |
| 104 | 應收款 | 資產 | 借 | 借給別人還沒收回的 |
| 201 | 應付款 | 負債 | 貸 | 欠別人還沒還的 |
| 301 | 期初淨值 | 權益 | 貸 | 月初「擁有的減欠的」 |
| 401 | 零用錢收入 | 收入 | 貸 | 固定零用錢 |
| 402 | 其他收入 | 收入 | 貸 | 家事報酬、紅包、賣二手書 |
| 501 | 餐飲 | 費用 | 借 | 午餐、點心、飲料 |
| 502 | 文具 | 費用 | 借 | |
| 503 | 交通 | 費用 | 借 | 公車、捷運（刷卡時記） |

| 505 | 其他費用 | 費用 | 借 | 分不進去的 |

**第 1 步：月初盤點，做期初資產負債表（第 1 天早上）**

把所有錢數一遍：錢包現金、悠遊卡餘額（去便利商店查或用 App）、撲滿、銀行；再想想有沒有借人或欠人。填進下面這張表：

| 資產 | 金額 | 負債與淨值 | 金額 |
|---|---|---|---|
| 現金 | | 應付款（欠別人） | |
| 悠遊卡 | | | |
| 存款 | | 期初淨值（資產合計 − 負債） | |
| 應收款（別人欠我） | | | |
| **資產合計** | | **負債＋淨值合計** | |

這張表的數字就是你帳本的「開帳分錄」：借各項資產、貸應付款和期初淨值。

**第 2 步：每天記流水帳（整個月）**

每花一筆、收一筆，當天就寫下：日期、什麼事、金額、從哪個口袋出去（現金？悠遊卡？）。不用當場想借貸，先記住「事實」最重要。晚上睡前回想一次有沒有漏掉。

**第 3 步：每週末轉成日記帳分錄（每週日）**

把這週的流水帳翻成正式分錄。幾個常見寫法：

| 事情 | 借方 | 貸方 |
|---|---|---|
| 收到零用錢 2,000 現金 | 現金 2,000 | 零用錢收入 2,000 |
| 午餐 60 付現 | 餐飲 60 | 現金 60 |
| 悠遊卡儲值 200 | 悠遊卡 200 | 現金 200 |
| 搭公車刷卡 15 | 交通 15 | 悠遊卡 15 |
| 把 50 元放進撲滿 | 存款 50 | 現金 50 |
| 還同學 50 | 應付款 50 | 現金 50 |
| 借同學 100 | 應收款 100 | 現金 100 |

注意**儲值和存撲滿不是費用**，只是錢從一個口袋搬到另一個口袋，兩邊都是資產。刷卡搭公車那一刻才是費用。

**第 4 步：每週末過帳到分類帳**

替每個用到的科目開一個 T 字帳或一張小表，把分錄的金額填進去。用試算表的話，第 5 章和附錄 C 的 SUMIF 方法可以自動過帳。

**第 5 步：月底編試算表（最後一天）**

列出每個科目的餘額，借方放一欄、貸方放一欄，兩欄加總必須相等。不相等的話，用第 6 章的方法找錯：差額除以 2 看有沒有借貸寫反、差額除以 9 看有沒有數字顛倒。

**第 6 步：編三張報表**

- **損益表**：所有收入科目合計 − 所有費用科目合計 = 本月結餘（可能是負的）。
- **資產負債表**：月底各項資產、負債；淨值 = 期初淨值 + 本月結餘。檢查資產合計是否等於負債加淨值。
- **現金流量表**：只看「現金」這個科目的進出。分三類：日常收支（零用錢、吃喝、文具、娛樂）叫營業活動；搬到悠遊卡、撲滿的叫投資活動；借人、還人的叫籌資活動。期初現金 + 三類淨額 = 期末現金，要等於資產負債表上的現金。

**第 7 步：寫下三個發現**

例如：「我以為餐飲花 500，結果 950」、「結餘 70 元，比我以為的少」、「下個月要把娛樂預算改成 500」。

### 範本：小美的範例

小美的月初盤點：現金 350、悠遊卡 120、撲滿 1,800、欠同學 50。期初淨值 = 2,270 − 50 = 2,220。

這個月她的分錄彙總後：收零用錢 2,000；餐飲付現 950；文具付現 250；悠遊卡儲值 200、刷卡交通共用掉 180；娛樂付現 550；還同學 50；存撲滿 50。

- [ ] 科目表在記帳前就定好，整個月沒有中途改名。

## 專題二：用試算表為小明文具行建立完整帳務系統

### 目標

- 在一份 Google 試算表裡建立六張工作表：科目表、日記帳、分類帳、試算表、損益表、資產負債表。
- 用 SUMIF 和 VLOOKUP 讓後面五張全部由日記帳自動算出。
- 輸入小明文具行第一個月（10 月）的 20 筆交易加 4 筆調整分錄（就是第 5 章與第 7 章的那一套），驗證報表數字正確。
- 新增一筆交易，看到報表自動更新。

這個專題用的資料和第 5、6、7 章完全一樣，所以每一個數字都可以翻回那三章對答案：日記帳合計、分類帳餘額、試算表合計、淨利，全部要對得起來。

### 你需要的東西

- Google 帳號與 Google 試算表（Excel 也可以，函式名稱相同）
- 附錄 A 的科目表、附錄 C 的逐步做法
- 本節的 24 筆分錄（第 5 章的 20 筆交易＋第 7 章的 4 筆調整）

### 系統長什麼樣

```

 │ 代號/名稱│VLOOKUP│ 你只打   │SUMIF │ 每科目   │      │ 借=貸？  │

 └──────────┘      └──────────┘      └────┬─────┘      └──────────┘
                                          │ VLOOKUP 取餘額
                                   ┌──────┴──────┐
                                   ▼             ▼
                             ┌──────────┐  ┌──────────┐
                             │  損益表  │─►│資產負債表│
```

**第 2 步：建立「日記帳」工作表**

表頭（第 1 列）：A 日期、B 編號、C 科目代號、D 科目名稱、E 借方、F 貸方、G 摘要。

D2 輸入公式，然後往下拉到至少第 200 列：

```
=IF(C2="","",VLOOKUP(C2,科目表!$A:$D,2,FALSE))
```

意思是：C2 有代號時，去科目表的 A 到 D 欄找這個代號，把第 2 欄（科目名稱）抓回來；沒代號就留空。

在 H1 填「借貸合計」，H2 填 `=SUM(E:E)`，H3 填 `=SUM(F:F)`，H4 填 `=IF(H2=H3,"借貸相等 ✓","不相等！差 "&ABS(H2-H3))`。這是你的第一道檢查。

選取 C 欄，用「資料 → 資料驗證 → 下拉式選單（來自範圍）」指定 `科目表!$A$2:$A$21`，以後輸入代號只能從清單選，不會打錯。

## 常見錯誤與迷思

- **「我用手算比較快，公式太麻煩。」** → 第一次是比較慢，但第二個月開始，手算要重做全部，公式只要打日記帳。正確理解：專題二做的是工具，工具做好一次用很久。
- **「儲值悠遊卡是花錢，所以是費用。」** → 錢只是換了地方，還是你的。正確理解：資產之間的移動不影響淨值，刷卡用掉才是費用。
- **「試算表平衡了，帳就一定對。」** → 借貸相等只能抓到「一邊有記一邊沒記」這種錯；兩邊都記錯科目、或整筆漏掉，試算表還是平的。正確理解：試算表平衡是必要條件，不是充分條件，月底還是要盤點現金和存貨。
- **「VLOOKUP 回傳 #N/A。」** → 通常是代號打成文字（例如前面有空格），或科目表裡沒有這個代號。正確理解：先檢查科目表有沒有、再檢查儲存格格式是不是數字。
- **「累計折舊為什麼是負的／為什麼變成資產加項？」** → 它的類別是資產但正常餘額在貸方，分類帳餘額公式用「貸減借」才會是正數；放進資產負債表時要加負號。正確理解：照第 1 步和第 7 步做就不會錯。
- **「淨利 1,000，所以現金多了 1,000。」** → 現金從 0 變成 40,700，而且其中 70,000 是資本和銀行借款、−12,000 是買電腦、−24,000 是預付三個月租金。正確理解：淨利和現金增減是兩回事，這正是第 10 章的重點。

## 專題報告格式

不管做專題一還是專題二，報告都用同一個格式。長度 2–4 頁（A4）或一份有 6 個分頁的試算表加一頁說明。

### 1. 封面

- 專題名稱（例如「我的十月零用錢帳」或「小明文具行試算表帳務系統」）
- 姓名、班級（或「自學」）、日期
- 一句話說明這份報告在做什麼

### 2. 目標（3–5 行）

你想透過這個專題回答什麼問題？例如「我一個月的錢到底花去哪」「能不能做一套只打日記帳就自動出報表的系統」。

### 3. 方法與步驟（半頁到一頁）

- 用了哪些科目（附科目表）
- 記帳的頻率和工具
- 從日記帳到報表的流程（可以用本章的流程圖改畫）
- 用到哪些試算表函式

### 4. 結果（一到兩頁）

- 試算表（含借貸合計）
- 三張報表（專題一：個人版；專題二：小明文具行版）
- 主要數字：本月結餘或淨利、毛利率、期末現金、期末淨值
- 四個檢查點的結果（試算平衡、資產負債平衡、淨利連到權益、現金連到資產負債表）各寫一行「✓ 通過」或「✗ 未通過，原因是……」

### 5. 分析與發現（半頁）

至少三點。要有數字支持，例如「餐飲占費用 49%（950 ÷ 1,930）」「文具行毛利率 50%，損益兩平營業額 27,000 元，本月 30,000 元只高出 11%」。

### 6. 下一步（3–5 行）

根據發現，下個月要改什麼？用第 13 章的方法寫成預算數字，例如「餐飲預算 800、娛樂 500」或「第二個月營業額目標 36,000、進貨 18,000」。

### 7. 遇到的困難與怎麼解決（3–5 行）

這一段最能看出你真的做過。例如「試算表差 90 元，用除以 9 的方法找到 270 寫成 720」「VLOOKUP 一直 #N/A，後來發現代號是文字格式」。

### 8. 附錄

- 完整日記帳（專題一可以用照片或表格；專題二放試算表連結或截圖）
- 流水帳原稿（專題一）
- 試算表檔案連結（專題二，記得開「知道連結的人可以檢視」）
