# 第 2 章　資產負債與權益

## 本章目標
- 學完你會分辨什麼是資產、什麼是負債、什麼是業主權益，而且能舉出自己身邊的例子。
- 學完你會寫出會計方程式「資產 ＝ 負債 ＋ 權益」，並且用「你擁有的 － 你欠的 ＝ 真正是你的」解釋它。
- 學完你會說明為什麼每一筆交易記完之後，方程式永遠是平的。
- 學完你會列出自己的個人資產負債表，算出自己的「淨值」。
- 學完你會編出小明文具行開幕前的資產負債表，並驗算左右相等。

## 開場：你到底有多少錢？

小安被問了一個簡單的問題：「你現在有多少錢？」

他想了一下：口袋裡 300 元，存錢筒裡大概 1,200 元，郵局帳戶有 5,000 元，悠遊卡還剩 180 元。阿哲欠他 50 元還沒還。喔，不過他上週跟媽媽預支了 200 元零用錢，還答應要還姐姐 150 元。還有一台去年生日買的腳踏車，3,000 元。

「所以我到底有多少錢？是 300？6,500？還是要把腳踏車也算進去？欠的錢要扣掉嗎？」

同一時間，小明站在開幕前一晚的文具行裡，看著收銀機裡的 29,000 元發呆。上一章結尾他已經知道錢沒有不見，只是「變成了別的東西」。可是媽媽問他：「那你現在到底值多少？你欠銀行的 20,000、欠批發商的 15,000 要算進去吧？」

這兩個問題，其實是同一個問題：**你擁有什麼、你欠什麼、扣掉之後真正屬於你的是多少。** 會計用三個名詞來回答它，而且把這三個名詞放進一條全世界都在用的公式。這一章我們就來學這條公式。

## 核心概念

### 資產：你擁有、以後用得到的東西

**資產（Asset）**是你擁有（或控制）、可以用金額衡量、而且**以後會帶給你好處**的東西。

這個定義有三個關鍵字，缺一不可：

1. **你擁有或控制它**：小明租的店面不是他的資產，因為店面是房東的；但他買的電腦是。
2. **可以用金額衡量**：你的好人緣很有價值，但沒辦法標價，所以不是會計上的資產。
3. **以後會帶來好處**：架上的文具以後可以賣錢，是資產；昨天吃掉的午餐已經沒有「以後」了，不是資產。

資產不只是現金。把小安和小明的資產排出來看：

| 小安的資產 | 金額 | 小明文具行的資產（開幕前，10 月 4 日晚上） | 金額 |
|---|---|---|---|
| 口袋現金 | 300 | 現金（收銀機） | 29,000 |
| 存錢筒 | 1,200 | 存貨（架上的文具） | 20,000 |
| 郵局帳戶 | 5,000 | 預付租金（10 到 12 月的店面使用權） | 24,000 |
| 悠遊卡餘額 | 180 | 電腦 | 12,000 |
| 應收款（阿哲欠的） | 50 | | |
| 腳踏車 | 3,000 | | |
| **合計** | **9,730** | **合計** | **85,000** |

幾個值得注意的地方：

- **應收款（Accounts Receivable）**：阿哲欠小安的 50 元，雖然不在小安手上，但那是小安的錢，以後會回來，所以是資產。第 1 章我們把它記成「支出」，現在你知道那不夠精確了。
- **存貨（Inventory）**：架上準備要賣的文具，以後賣掉會變成錢，是資產。
- **預付租金（Prepaid Rent）**：小明 10 月 1 日一次付了 10、11、12 月三個月的房租 24,000 元，開幕前連 10 月都還沒用到，這 24,000 元買到的是「三個月可以用這間店」的權利，這個權利以後會帶來好處（讓他有地方做生意），所以在開幕前它還是資產。等日子一天一天過去，它才會慢慢「用掉」。這件事第 3 章和第 7 章會再談。
- **腳踏車要算多少？** 會計的規矩是用「買的時候的價錢」記（叫做歷史成本），所以小安寫 3,000。二手賣掉可能只值 1,500，沒錯，用舊的東西會貶值，第 7 章的「折舊」就是處理這件事。

### 負債：你欠別人的

**負債（Liability）**是你**欠別人、以後要用錢或東西去償還**的義務。

| 小安的負債 | 金額 | 小明文具行的負債（開幕前，10 月 4 日晚上） | 金額 |
|---|---|---|---|
| 跟媽媽預支的零用錢 | 200 | 應付帳款（欠批發商的貨款） | 15,000 |
| 答應要還姐姐的 | 150 | 銀行借款 | 20,000 |
| **合計** | **350** | **合計** | **35,000** |

負債常見的樣子有：

- **借款（Loan）**：直接跟人或銀行借的錢。小明向銀行借的 20,000 元就是。
- **應付帳款（Accounts Payable）**：東西先拿、錢之後付。小明 10 月 3 日跟批發商賒帳進了 15,000 元的貨，貨在架上、錢還沒付，就是這一項。
- **應付費用（Accrued Expenses）**：已經用了、帳單還沒來或還沒付。例如 10 月的水電費，要到 11 月才收到帳單。

負債有一個很重要的特性：**它不會因為你忘了就消失。** 小安欠姐姐的 150 元，他忘了，姐姐不會忘。所以負債一定要記進帳裡，否則你會以為自己比實際上有錢。

### 業主權益：真正屬於你的

把你擁有的全部加起來，減掉你欠的全部，剩下的才真正是你的。這個數字叫**業主權益（Owner's Equity）**，有時候簡稱「權益」，生活上常叫「淨值」或「身價」。

> 業主權益 ＝ 資產 － 負債

小安：9,730 － 350 ＝ **9,380 元**。這才是「小安到底有多少錢」的正確答案。不是口袋裡的 300，也不是全部加起來的 9,730，而是扣掉欠的之後的 9,380。

小明文具行：85,000 － 35,000 ＝ **50,000 元**。你有沒有發現，這剛好等於小明自己投入的資本？這不是巧合。開幕前，店裡所有的東西要嘛是小明自己出錢買的，要嘛是用銀行的錢買的，要嘛是先欠著批發商的；扣掉銀行和批發商的那份，剩下的當然就是小明的那份。以後店開始賺錢或賠錢，權益才會離開 50,000 這個數字（第 3 章）。

「業主」這個詞的意思是「店的主人」。一個人開的店，業主就是老闆一個人；公司的話業主是所有股東，所以公司的報表上會寫「股東權益」。意思一樣。

### 會計方程式：一條永遠平的公式

把「權益 ＝ 資產 － 負債」的負債移到左邊，就得到會計裡最重要的一條公式，叫**會計方程式（Accounting Equation）**：

> **資產 ＝ 負債 ＋ 業主權益**

為什麼要寫成這個樣子，而不是「權益 ＝ 資產 － 負債」？因為這樣寫的時候，等號兩邊各自在回答一個問題：

```
         資產            ＝        負債        ＋      業主權益
  ─────────────────────        ─────────────────────────────────
   錢「變成了什麼」                    錢「從哪裡來」
  （現金、存貨、電腦…）          （別人的錢）       （自己的錢）
```

還記得第 1 章那張「錢從哪裡來／錢變成了什麼」的圖嗎？左邊 70,000，右邊 70,000。會計方程式就是那張圖，再把「賒帳進的貨」也放進來：**店裡的每一樣東西，都是用某個人的錢買的**，要嘛是債主的（銀行、批發商），要嘛是老闆的。所以「東西的總值」一定等於「債主的份 ＋ 老闆的份」。這不是什麼定律，只是一個事實：錢不會憑空出現。

小明文具行開幕前：29,000 ＋ 20,000 ＋ 24,000 ＋ 12,000 ＝ 85,000 ＝ 15,000 ＋ 20,000 ＋ 50,000。平。

小安：9,730 ＝ 350 ＋ 9,380。平。

它永遠是平的。如果你算出來不平，不是公式錯，是你某個地方記錯或漏記了。

### 交易來了，方程式還是平的

這是本章最重要的一節。我們把小明開幕前（10 月 1 日到 4 日）的六筆交易，一筆一筆放進方程式，看它每一步會不會平。開店前，店裡什麼都沒有，三邊都是 0。

| 交易 | 現金 | 存貨 | 預付租金 | 電腦 | ＝ | 應付帳款 | 銀行借款 | 權益 |
|---|---|---|---|---|---|---|---|---|
| 開店前 | 0 | 0 | 0 | 0 | | 0 | 0 | 0 |
| ① 10/1 小明投入 50,000 | +50,000 | | | | | | | +50,000 |
| 小計 | 50,000 | 0 | 0 | 0 | ＝ | 0 | 0 | 50,000 |
| ② 10/1 向銀行借 20,000 | +20,000 | | | | | | +20,000 | |
| 小計 | 70,000 | 0 | 0 | 0 | ＝ | 0 | 20,000 | 50,000 |
| ③ 10/1 預付 3 個月租金 24,000 | −24,000 | | +24,000 | | | | | |
| 小計 | 46,000 | 0 | 24,000 | 0 | ＝ | 0 | 20,000 | 50,000 |
| ④ 10/2 買電腦 12,000 | −12,000 | | | +12,000 | | | | |
| 小計 | 34,000 | 0 | 24,000 | 12,000 | ＝ | 0 | 20,000 | 50,000 |
| ⑤ 10/3 賒帳進貨 15,000 | | +15,000 | | | | +15,000 | | |
| 小計 | 34,000 | 15,000 | 24,000 | 12,000 | ＝ | 15,000 | 20,000 | 50,000 |
| ⑥ 10/4 現金進貨 5,000 | −5,000 | +5,000 | | | | | | |
| **開幕前結束** | **29,000** | **20,000** | **24,000** | **12,000** | ＝ | **15,000** | **20,000** | **50,000** |

每一列小計，左邊四格加起來都等於右邊三格加起來。你可以自己驗算：第 ⑤ 筆之後，34,000 ＋ 15,000 ＋ 24,000 ＋ 12,000 ＝ 85,000 ＝ 15,000 ＋ 20,000 ＋ 50,000。

仔細看每一筆交易影響的格子，你會發現交易只有三種樣子：

1. **左邊增加、右邊也增加**（①、② 和 ⑤）：東西進來了，而且有人因此「擁有這家店的一部分」——小明投入，權益增加；銀行借錢，負債增加；批發商先把貨給你，你欠他錢，負債也增加。
2. **左邊一個增加、另一個減少**（③④⑥）：錢換成了別的東西。現金變少、電腦變多，左邊的總和不變，右邊完全沒動。
3. **左邊減少、右邊也減少**（本章的六筆裡還沒出現）：例如 10 月 10 日小明付 10,000 元給批發商，現金 −10,000、應付帳款 −10,000。活動 2-2 的挑戰題會做這一筆。

無論哪一種，等號兩邊永遠一起動、或是同一邊一加一減。這就是為什麼它永遠平：**每一筆交易一定同時動到兩個地方**。這個「一定動兩個地方」的觀念，就是第 4 章要學的「借貸記帳法」的根。

還有一件事值得注意：③④⑥ 小明花掉了 41,000 元現金，但他的權益一直是 50,000，一毛都沒少。**花錢買資產不會讓你變窮，只是把錢換成另一種形式。** 什麼時候才會變窮？當資產被「用掉」或「消耗」的時候，例如 10 月過完了、預付租金少掉一個月的份。那是第 3 章的事。

### 資產負債表：方程式的照片

把某一天的資產、負債、權益整理成一張表，就叫**資產負債表（Balance Sheet）**。它像一張照片，拍下「這一天結束時」這家店的樣子。小明文具行開幕前（10 月 4 日晚上）的資產負債表長這樣：

| 資產 | 金額 | 負債與業主權益 | 金額 |
|---|---|---|---|
| 現金 | 29,000 | 應付帳款（欠批發商） | 15,000 |
| 存貨 | 20,000 | 銀行借款 | 20,000 |
| 預付租金 | 24,000 | **負債合計** | **35,000** |
| 電腦 | 12,000 | 業主資本（小明） | 50,000 |
| | | **業主權益合計** | **50,000** |
| **資產總計** | **85,000** | **負債及權益總計** | **85,000** |

左邊是資產，右邊是負債加權益，兩邊的總計一定相等，所以英文叫 Balance（平衡）Sheet。這張表的正式畫法（什麼放上面、什麼放下面、流動和非流動）第 8 章會教，現在只要會把三類東西放對邊、算出總計、確認兩邊相等就好。

小安的個人資產負債表也可以這樣畫：

| 資產 | 金額 | 負債與權益 | 金額 |
|---|---|---|---|
| 口袋現金 | 300 | 預支零用錢（欠媽媽） | 200 |
| 存錢筒 | 1,200 | 欠姐姐 | 150 |
| 郵局帳戶 | 5,000 | **負債合計** | **350** |
| 悠遊卡餘額 | 180 | | |
| 應收款（阿哲） | 50 | 小安的淨值 | 9,380 |
| 腳踏車 | 3,000 | | |
| **資產總計** | **9,730** | **負債及淨值總計** | **9,730** |

注意右下角的 9,380 不是某個東西，它是**算出來的**：資產總計減負債合計。權益從來不是一個你可以摸到的東西，它是一個「差額」，代表「扣掉欠的之後，真正屬於你的部分」。

## 動手做

### 活動 2-1：列出自己的個人資產負債表

**材料／工具**
- 紙、筆、計算機
- 你的存摺或郵局／銀行 App（請家長幫忙查餘額）、悠遊卡（到便利商店或 App 查餘額）

**步驟**
1. 在紙上畫一張兩邊的表：左邊標題「資產」，右邊標題「負債與淨值」。
2. 左邊列出你**擁有**的每一樣能換成錢的東西：口袋現金、存錢筒（真的倒出來數）、銀行或郵局帳戶、悠遊卡餘額、別人欠你的錢。
3. 想一想你有沒有「以後用得到、而且值得記」的大東西：腳踏車、平板、遊戲機、樂器。用「買的時候的價錢」記，不確定的問家長。衣服、文具、課本這類很快會用掉或不值什麼錢的，不用記。
4. 右邊列出你**欠**的每一筆：跟爸媽預支的、跟兄弟姐妹或同學借的、答應要付還沒付的（例如班費）。
5. 算出資產總計、負債合計。
6. 淨值 ＝ 資產總計 － 負債合計，寫在右邊負債下面。
7. 驗算：負債合計 ＋ 淨值 應該等於資產總計。
8. 在表的最上面寫上今天的日期。這是你人生第一張資產負債表，請留著，第 14 章還要用。

**你應該看到／得到**
- 一張兩邊總計相等的表。
- 淨值是一個比「口袋現金」大很多的數字（如果你有存款），或是一個比你想像中小的數字（如果你欠很多）。這兩種結果都很正常，重點是你現在**知道**了。
- 如果你的負債比資產多，淨值會是負數。這在會計上叫「資不抵債」，對一個學生來說通常只是暫時的（例如預支了下個月的零用錢），但值得警覺。

### 活動 2-2：小明文具行開幕前，一步一步填平方程式

**材料／工具**
- 紙、筆、計算機
- 第 1 章的小明文具行設定表

**步驟**
1. 先不要看本章「交易來了，方程式還是平的」那張表，自己畫一張同樣格式的空表：左邊四欄（現金、存貨、預付租金、電腦），右邊三欄（應付帳款、銀行借款、權益）。
2. 按照設定表的日期順序，把開幕前的六筆交易一筆一筆填進去。每一筆只能動到兩個格子，想清楚是哪兩個、一個加一個減還是兩個都加。
3. 每填一筆就算一次小計，確認左邊四格的和等於右邊三格的和。
4. 填完之後，把最後一列整理成一張資產負債表（左邊資產、右邊負債與權益）。
5. 和本章的表對答案。
6. 挑戰：10 月 10 日小明付了 10,000 元給批發商，償還一部分賒帳。這筆交易動到哪兩個格子？新的資產總計、負債合計、權益各是多少？方程式還平嗎？（先不管開幕後賣東西的事，那是第 3 章。）

**你應該看到／得到**
- 六筆交易填完，最後一列是：現金 29,000、存貨 20,000、預付租金 24,000、電腦 12,000；應付帳款 15,000、銀行借款 20,000、權益 50,000。
- 資產負債表兩邊總計都是 85,000。
- 步驟 6：現金 −10,000、應付帳款 −10,000。現金變 19,000、應付帳款變 5,000；資產總計 75,000、負債 25,000、權益還是 50,000。平。還錢讓你「擁有的」和「欠的」同時變少，真正屬於你的沒變。

## 常見錯誤與迷思

- **「有錢就是有現金」→** 小明只剩 29,000 現金，但他的資產有 85,000。現金只是資產的一種，存貨、設備、別人欠你的錢都是資產。→ **問「有多少錢」的時候，要問清楚是問現金、資產總計、還是淨值。** 三個答案可以差很多。
- **「負債是壞事，越少越好」→** 小明如果不向銀行借 20,000、不跟批發商賒帳，開幕後第一次付貨款就會付不出來。借來的錢如果能買到會賺錢的資產，是好的負債。→ **負債本身不好不壞，重點是借來的錢變成了什麼、還不還得起。** 當然，借錢買不會賺錢也不會留下來的東西（例如用信用卡吃大餐），就是壞的負債。
- **「權益就是老闆放在店裡的現金」→** 權益不是某一樣東西，它是「資產減負債」的差額。小明的權益 50,000 並不是「某個地方放著 50,000 元現金」，它散在電腦、存貨、現金裡面。→ **權益是算出來的份額，不是摸得到的東西。**
- **「花錢就是變窮」→** 小明花了 41,000 現金，權益一毛沒少，因為錢換成了資產。→ **花錢買資產是「換形式」，花錢買會消耗掉的東西才是「變少」（第 3 章的費用）。** 分辨這兩種是會計最基本的判斷。
- **「方程式有時候會不平」→** 永遠不會。只要每筆交易都正確地動到兩個格子，左右一定相等。→ **不平一定是記錯：漏了一邊、數字抄錯、或加減方向反了。** 把「不平」當成帳本在幫你抓錯。
- **「租的店面也算資產，因為我在用」→** 店面是房東的，小明只是租。→ **你「用」的東西不一定是你「擁有」的。** 但他已經付的 10 到 12 月租金所換到的「使用權」是他的，所以「預付租金」是資產。

## 想一想

1. 下面每一項，對小明文具行來說是資產（A）、負債（L）、還是權益（E）？
   (a) 收銀機裡的零錢　(b) 跟廠商賒帳還沒付的貨款　(c) 架上的筆記本　(d) 小明投入的 50,000 元　(e) 下個月才要付的水電費（這個月已經在用）　(f) 一位客人預訂了 500 元的禮盒並先付了錢，貨還沒給他

<details><summary>參考答案</summary>

(a) A，現金。(b) L，應付帳款。(c) A，存貨。(d) E，業主資本。(e) L，應付費用：已經用了電，欠台電的錢。(f) L，這叫「預收款」：錢收了但東西還沒給，等於欠客人一個禮盒，是負債；要等貨交出去才變成收入（第 3 章）。

</details>

2. 小安從郵局帳戶領出 1,000 元，拿 200 元還媽媽，剩下 800 元放進存錢筒。請重新算他的資產總計、負債合計和淨值。淨值有變嗎？

<details><summary>參考答案</summary>

郵局帳戶 5,000 → 4,000；存錢筒 1,200 → 2,000；資產總計 9,730 － 1,000 ＋ 800 ＝ 9,530。負債 350 － 200 ＝ 150。淨值 9,530 － 150 ＝ 9,380，**沒變**。還錢是「資產減少、負債也減少」，真正屬於你的部分不動。

</details>

3. 如果銀行願意借小明 40,000 元而不是 20,000 元，其他設定都一樣，開幕前結束時：現金多少？資產總計多少？負債多少？權益多少？小明有「變有錢」嗎？

<details><summary>參考答案</summary>

現金 29,000 ＋ 20,000 ＝ 49,000；資產總計 105,000；負債 55,000；權益還是 50,000。他沒有變有錢，只是手上多了 20,000 元可以周轉，同時多欠了 20,000 元。借錢不會改變你的淨值。

</details>

4. 小明的電腦買的時候 12,000 元，預計用 5 年。你覺得用了一年之後，資產負債表上還應該寫 12,000 嗎？如果不應該，大概寫多少比較合理？這會讓方程式的哪一邊動？

<details><summary>參考答案</summary>

不應該。用了一年，五年的壽命過了五分之一，大約「用掉」了 2,400 元，剩下 9,600 元比較合理。資產減少 2,400，左邊變小；要讓方程式平，右邊也要少 2,400，少的是權益，因為電腦磨損是老闆的損失。這就是第 7 章的「折舊」。

</details>

5. （開放挑戰）有兩家小店。甲店資產 100 萬、負債 95 萬；乙店資產 30 萬、負債 0。如果你是銀行，比較願意借錢給哪一家？為什麼？有沒有什麼情況下你會改變主意？

<details><summary>參考答案</summary>

一般會選乙店：甲店權益只有 5 萬，資產稍微跌價就可能資不抵債；乙店權益 30 萬、沒有債務，很穩。但如果甲店每年能賺 30 萬、乙店每年只賺 1 萬，你可能會改變主意，因為還錢靠的是賺錢能力。這就是為什麼第 11 章要同時看三張報表。

</details>

6. （開放挑戰）會計方程式說交易一定同時動兩個地方。請想一個「不是交易（沒有錢或東西實際移動），但會讓小安的淨值在現實中改變」的事件，並說說會計為什麼通常不記它。

<details><summary>參考答案</summary>

例如：小安的腳踏車因為同款停產，二手價從 1,500 元漲到 4,000 元。他沒有買賣任何東西，但「真實的身價」變了。會計通常不記，因為這個漲價沒有真的發生（他沒賣），而且金額只是猜的；要等真的賣掉，差額才會進帳。會計寧可保守一點，只記「真的發生、金額確定」的事，這樣不同的人看同一本帳才不會各說各話。

</details>

## 本章小結

- 資產是你擁有、可以用金額衡量、以後會帶來好處的東西；現金只是其中一種，存貨、設備、應收款、預付租金都是。
- 負債是你欠別人、以後要償還的義務：借款、應付帳款、應付費用、預收款。負債不會因為你忘了就消失。
- 業主權益 ＝ 資產 － 負債，是「扣掉欠的之後真正屬於你的」，它是算出來的差額，不是某一樣東西。
- 會計方程式：資產 ＝ 負債 ＋ 業主權益。左邊回答「錢變成了什麼」，右邊回答「錢從哪裡來」。
- 每一筆交易一定同時動到兩個地方，所以方程式永遠是平的；不平就是記錯。
- 花錢買資產只是換形式，權益不變；借錢讓資產和負債同時增加，權益也不變。
- 資產負債表是某一天方程式的「照片」，左邊資產、右邊負債與權益，兩邊總計相等。
- 小明文具行開幕前：資產 85,000 ＝ 負債 35,000 ＋ 權益 50,000。
