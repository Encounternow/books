# 第 11 章　電與磁

> 這一章是「簡版」：用三個實驗帶你認識靜電、電流和磁。如果你做完覺得意猶未盡，同一個書架上有一整本《動手玩電》（https://book.vichuang.tw/electric/ ），從麵包板、三用電表一路玩到 Arduino，那裡有完整的接線圖和每一章的實驗。本章會標出對應的章節，讓你知道去哪裡深入。

## 開場：冬天的那一下「啪」

冬天穿毛衣脫下來的時候，頭髮會豎起來、還會聽到劈哩啪啦的聲音；摸門把的瞬間「啪」一下被電到；氣球在頭上摩擦幾下之後可以貼在牆上不掉下來。

這些都是「靜電」。小安覺得奇怪：靜電會電人，插座的電也會電人，手機電池的電卻摸了沒感覺；磁鐵可以吸冰箱門，但吸不起銅板；馬達裡面有磁鐵，發電機裡面也有磁鐵……電和磁到底是什麼關係？

這一章我們用家裡就有的東西，做三個小實驗：讓氣球帶電、用檸檬發電、用電池做磁鐵。做完你會發現，電和磁其實是一體兩面——電流會生磁，磁也能生電，這就是整個現代電力世界的基礎。

## 核心概念

### 靜電：電荷被搬家了

所有東西都是由原子組成的，原子裡有帶正電的質子和帶負電的電子（Electron）。平常正負一樣多，互相抵消，東西「不帶電」。

兩種材料互相摩擦時，電子會從一邊跑到另一邊：失去電子的那邊帶正電，多了電子的那邊帶負電。這叫摩擦起電。氣球摩擦頭髮，電子從頭髮跑到氣球上，氣球帶負電、頭髮帶正電，所以頭髮會被氣球吸起來。

電荷只有一條規則：**同性相斥、異性相吸**。

那為什麼帶電的氣球可以吸起「不帶電」的小紙片？因為氣球靠近時，紙片裡的電荷會被「推開」：負電荷被氣球的負電推到遠端，正電荷留在近端，近端的正電和氣球的負電互相吸引，就把紙片吸起來了。這叫靜電感應（Electrostatic Induction）。

靜電為什麼會「啪」？摩擦累積的電荷電壓可以到幾千伏特，一碰到門把就瞬間跳過去，產生小火花和聲音；但電荷量非常少，所以只是痛一下。

### 電流、電壓、電阻：用水管來想

靜電是「電荷待在那裡」，電流是「電荷流動」。想像一條水管：

| 水管 | 電路 | 單位 |
|------|------|------|
| 水流量（每秒幾公升） | 電流 I（Current） | 安培 A |
| 水壓（水塔有多高） | 電壓 V（Voltage） | 伏特 V |
| 水管有多細、多塞 | 電阻 R（Resistance） | 歐姆 Ω |

三者的關係是歐姆定律（Ohm's Law）：

> V ＝ I × R　　（電壓 ＝ 電流 × 電阻）

水壓越大、水管越粗（電阻越小），水流越大。

**算一個例子：** 兩顆 3 號電池串起來是 3 V，接一個 150 Ω 的電阻，電流 I ＝ V ÷ R ＝ 3 ÷ 150 ＝ 0.02 A ＝ 20 mA（毫安培）。這剛好是讓一顆 LED 發亮的典型電流。

常見電壓：3 號電池 1.5 V、9 V 方型電池 9 V、USB 充電孔 5 V、手機電池約 3.7 V、家用插座 110 V。本章只用 9 V 以下的電池，摸到沒有感覺，很安全。**家用插座 110 V 會致命，本書任何實驗都不碰插座。**

電要流動，需要一條「繞成圈」的路，叫閉合迴路（Closed Circuit）：從電池正極出發，經過導線和燈泡，回到負極。中間只要斷掉一點，電就不流了（第 1 章小安的手電筒）。

導電的材料叫導體（金屬、鹽水、人體），不導電的叫絕緣體（塑膠、橡膠、乾木頭、空氣）。

**電功率** P ＝ V × I，單位瓦特（W）。USB 充電器 5 V × 2 A ＝ 10 W。第 6 章的功率概念在這裡又出現了。

### 電池：把化學反應變成電壓

電池是用兩種不同的金屬插在導電的液體裡（叫電解液），兩種金屬「搶電子」的能力不一樣，就在兩端產生電壓。檸檬裡的酸就是電解液，鋅和銅是兩種金屬，這就是實驗 11-2。

一顆檸檬電池大約 0.9 V，不夠點亮 LED（紅色 LED 需要約 1.8 V）。解決方法是串聯（Series）：第一顆的銅接第二顆的鋅，像疊水塔一樣電壓相加。四顆串起來理論上 3.6 V。不過檸檬電池能給的電流非常小，所以 LED 只會微微亮。

### 磁鐵與磁場

磁鐵有兩個極：N 極（北）和 S 極（南）。規則和電荷一樣：**同極相斥、異極相吸**。而且磁極永遠成對出現——把磁鐵切成兩半，不會得到一個 N 和一個 S，而是兩個都有 N 和 S 的小磁鐵。

磁鐵周圍有一個看不見的作用範圍，叫磁場（Magnetic Field）。把紙放在磁鐵上面撒鐵粉，鐵粉會排成一條條曲線，從 N 極出來繞回 S 極，那就是磁場的樣子。

```
          ╭──────────────────╮
        ╭─┤                  ├─╮
       ╱  │   ┌──────────┐   │  ╲
      │   │   │  N    S  │   │   │      磁力線：從 N 出發、回到 S
       ╲  │   └──────────┘   │  ╱
        ╰─┤                  ├─╯
          ╰──────────────────╯
```

磁鐵只吸鐵、鈷、鎳這幾種金屬（和它們的合金），不吸銅、鋁、金、銀。這就是為什麼冰箱磁鐵吸不起銅板或鋁箔。地球本身就是一顆大磁鐵，所以指南針會指北。

磁場的強度單位是特斯拉（Tesla，T），日常用的是微特斯拉（µT，百萬分之一特斯拉）。台灣的地磁大約 45 µT，冰箱磁鐵表面大約 5,000～10,000 µT。

### 電流會生磁：電磁鐵

1820 年，丹麥的奧斯特在上課時發現：導線一通電，旁邊的指南針就轉了。**電流的周圍會產生磁場。** 這是電和磁第一次被連在一起。

一根直導線的磁場很弱，但把導線繞成一圈一圈的線圈（Coil），每一圈的磁場疊在一起就強多了；再在中間塞一根鐵釘（鐵心），磁場會被集中、放大好幾十倍。這就是電磁鐵（Electromagnet）：**通電才有磁力，斷電就沒有。**

電磁鐵的強度大致和「圈數 × 電流」成正比。想要更強，就多繞幾圈，或用更大的電流（但電池會更快發熱、沒電）。

電磁鐵到處都是：門鈴、喇叭、硬碟、廢鐵場吊車、磁浮列車，以及每一顆馬達。馬達就是用電磁鐵和永久磁鐵互相推、互相吸，讓軸轉起來。

**反過來也成立：** 磁鐵在線圈裡動，線圈會產生電壓，這叫電磁感應，是法拉第在 1831 年發現的。發電廠就是用水或蒸氣推動線圈在磁場裡轉。所以馬達和發電機是同一個東西的兩個方向：給電就轉，用手轉就發電。

## 動手做

### 實驗 11-1：氣球靜電三連發

**安全提醒：** 沒有危險。靜電實驗在乾燥的天氣（冬天、開冷氣的房間）效果最好，潮濕的天氣電荷會很快跑掉。

**材料／工具**
- 氣球 2 顆、線一條
- 小紙片（把紙撕成米粒大小）、胡椒粉或細鹽
- 水龍頭
- 毛衣或你的頭髮（乾的）

**步驟**
1. **吸紙片：** 氣球吹好綁緊，在頭髮或毛衣上用力摩擦 20 下，靠近桌上的小紙片，看紙片會不會跳上來。靠近多遠就開始跳？用尺量一下。
2. **彎水流：** 打開水龍頭，調成一條細細的、連續不斷的水流。把摩擦過的氣球慢慢靠近水流（不要碰到水），看水流會不會彎向氣球。
3. **兩球互斥：** 兩顆氣球各綁一條線，提著線讓它們並排垂下，先看它們靜止時距離多少。兩顆都用頭髮摩擦之後再提起來，看距離有沒有變。
4. **貼牆：** 摩擦過的氣球貼到牆上，放手，計時看它能停多久。
5. 用手把氣球整個摸一遍（把電荷導走），再做一次步驟 1，紙片還會跳嗎？

**你應該看到／得到**
紙片會在氣球距離 2～5 公分時跳起來貼上去；水流會明顯彎向氣球；兩顆帶電的氣球會互相推開、保持距離（同性相斥）；氣球可以貼在牆上幾分鐘到幾十分鐘（乾燥時更久）。用手摸過的氣球電荷被你的身體導走，就失去吸力了。

**觀察與記錄**

| 測試 | 摩擦前 | 摩擦 20 下 | 摩擦 40 下 |
|------|------|------|------|
| 紙片開始跳的距離（cm） | | | |
| 水流有沒有彎 | | | |
| 兩球距離（cm） | | | |
| 貼牆時間（秒） | | | |

### 實驗 11-2：檸檬電池

**安全提醒：** 鐵釘和銅線的尖端小心別刺到手。實驗完的檸檬不要吃。

**材料／工具**
- 檸檬 4 顆（或馬鈴薯、橘子也可以）
- 鍍鋅鐵釘 4 根（五金行說「鍍鋅釘」就有；外觀銀白色，這層鋅就是我們要的）
- 銅線或銅片 4 段（五金行的裸銅線剪 5 公分；或用舊的 1 元硬幣，台灣 1 元硬幣主要成分是銅）
- 導線數條（有鱷魚夾的最方便，電子材料行或網路可買；沒有就用鋁箔捲成細條）
- 三用電表（五金行、電子材料行約一百多元起；《動手玩電》第 1 章教你怎麼用）
- 紅色 LED 一顆（電子材料行，幾塊錢）

**步驟**
1. 把檸檬在桌上用力滾幾下，讓裡面的汁出來。
2. 在一顆檸檬上插入一根鐵釘和一段銅線，兩者相距約 2 公分，**不要互相碰到**。
3. 三用電表轉到直流電壓檔（DCV，20 V 檔），紅棒碰銅、黑棒碰鋅釘，讀出電壓。
4. 四顆檸檬都插好之後，用導線把「第一顆的銅」接到「第二顆的鋅」、「第二顆的銅」接「第三顆的鋅」……串成一條鏈。量最前端的鋅和最後端的銅之間的電壓。
5. 把 LED 接到鏈的兩端：LED 比較長的腳接銅（正極），短的腳接鋅（負極）。關燈看 LED 有沒有微微亮。接反的話不會亮，交換一下就好。
6. 試試看：一顆檸檬插兩根鐵釘（沒有銅），有電壓嗎？

**你應該看到／得到**
一顆檸檬約 0.8～1.0 V；四顆串聯約 3.2～3.8 V（通常比 4 × 0.9 ＝ 3.6 低一點，因為每個接點都會損失一些）。LED 會非常微弱地亮（要在暗的房間才看得到），因為檸檬能提供的電流只有零點幾毫安。兩根鐵釘的檸檬電壓接近 0——電池一定要用**兩種不同的金屬**。

**觀察與記錄**

|------|------|
| 1 顆檸檬（鋅 ＋ 銅） | |
| 2 顆串聯 | |
| 3 顆串聯 | |
| 4 顆串聯 | |
| 1 顆檸檬（鋅 ＋ 鋅） | |

### 實驗 11-3：鐵釘電磁鐵

**安全提醒：** 線圈直接接電池等於把電池短路，**電池和線會發熱**。每次通電不要超過 10 秒，手感覺到熱就馬上拔掉。只用 3 號、4 號這種一般乾電池，**絕對不要用鋰電池或行動電源**。請大人在場。

**材料／工具**
- 大鐵釘一根（10 公分左右，五金行）
- 漆包線 2～3 公尺（電子材料行或網路；沒有的話用有塑膠皮的細電線也可以，但繞的圈數會少一點）
- 3 號電池 1～2 顆、膠帶
- 迴紋針一盒
- 指南針（或手機 Phyphox 的磁力計，見「用儀器看看」）

**步驟**
1. 漆包線留 15 公分不繞，然後在鐵釘上從釘頭往釘尖密密地繞，繞 50 圈，另一端也留 15 公分。用膠帶固定線圈，不要散掉。
2. 漆包線的兩端用砂紙或美工刀背把表面的漆刮掉約 1 公分（漆是絕緣的，不刮掉接不通）。
3. 把兩端分別用膠帶貼到一顆 3 號電池的正負極。
4. 用釘尖去碰迴紋針，看能吸起幾個。數完**馬上拔掉電池**。
5. 拔掉電池，再碰迴紋針，還吸得起來嗎？
6. 再繞 50 圈（總共 100 圈），重做步驟 3～4，吸起的迴紋針有沒有變多？
7. 用兩顆電池串聯（頭尾相接變 3 V）再試一次。注意會更熱，更要快。
8. 把指南針（或手機）放在釘尖附近，通電時指針怎麼轉？把電池反接，指針轉的方向會變嗎？

**你應該看到／得到**
50 圈、1 顆電池大約可以吸起 3～8 個迴紋針；斷電後幾乎全部掉下來（鐵釘可能還有一點點殘留磁性）；100 圈會明顯多一些；兩顆電池又更多。指南針會在通電時偏轉，電池反接時往反方向偏——因為電流方向反了，磁場的 N、S 也對調。

**觀察與記錄**

| 圈數 | 電池數 | 吸起的迴紋針數 | 斷電後還吸幾個 | 指南針偏轉方向 |
|------|------|------|------|------|
| 50 | 1 | | | |
| 100 | 1 | | | |
| 100 | 2 | | | |
| 100 | 1（反接） | | | |

## 用儀器看看

### Phyphox：磁力計

手機裡有一顆磁力計（Magnetometer），平常是給地圖 App 當電子羅盤用的。打開 Phyphox，找「Magnetometer（磁力計）」，按「▶」，畫面顯示 x、y、z 三個方向的磁場和「Absolute（總強度）」，單位 µT。

1. **看地磁：** 手機放在桌上、遠離任何金屬和磁鐵，總強度應該在 40～50 µT 左右（台灣約 45 µT）。慢慢轉動手機，x、y 的數字會變，但總強度幾乎不變——因為地磁的方向固定，只是你的手機轉了。
2. **磁鐵靠近：** 拿一顆冰箱磁鐵從 20 公分外慢慢靠近手機，看總強度怎麼飆升。靠到 1 公分可能破 1,000 µT 以上。**不要把強力磁鐵貼在手機上超過幾秒**，可能會干擾羅盤的校正。
3. **電磁鐵：** 把實驗 11-3 的電磁鐵釘尖對著手機背面、距離 3 公分，通電前、通電中、斷電後各記一次數字。你會看到通電瞬間跳上去、斷電馬上掉回來。
4. **距離實驗：** 磁鐵放在 2、4、6、8、10 公分處各量一次，記下來。

範例數據（一顆小的冰箱磁鐵，扣掉地磁 45 µT）：

| 距離（cm） | 總強度（µT） | 扣掉地磁後（µT） |
|------|------|------|
| 2 | 1,245 | 1,200 |
| 4 | 195 | 150 |
| 6 | 90 | 45 |
| 8 | 64 | 19 |
| 10 | 55 | 10 |

磁場隨距離掉得比光（平方反比）還快：距離加倍（2 → 4 公分），強度不是剩 1/4，而是剩約 1/8。（這是因為磁鐵的 N 和 S 永遠成對出現，遠處看兩極的效果互相抵消，所以是「立方反比」，你只要知道「磁場離遠一點就幾乎沒了」就好。）

### 試算表：畫出磁場與距離的關係

A 欄距離、B 欄扣掉地磁的強度。C 欄打 `=B2*A2^3`，如果 C 欄數字差不多，就是立方反比。畫散佈圖看曲線，和第 10 章光的曲線比一比，磁的曲線掉得更陡。

## 常見錯誤與迷思

- **「靜電電壓幾千伏特，所以很危險」** → 電壓高不等於能量多。→ 靜電的電荷量極少，瞬間就放完，只會痛一下；插座的 110 V 電壓低很多，但可以持續供應大電流，才是真正致命的。
- **「磁鐵什麼金屬都吸」** → 只吸鐵、鈷、鎳。→ 銅、鋁、金、銀、不含鐵的不鏽鋼都不會被吸。可以用磁鐵檢查家裡的「不鏽鋼」湯匙，有的會吸有的不會，成分不同。
- **「電池裡面存著電」** → 電池存的是化學能，用的時候才轉成電。→ 所以電池放久了化學反應慢慢進行，會自己沒電；檸檬電池的「電」其實來自鋅被檸檬酸慢慢吃掉。
- **「串聯越多顆電池，LED 就越亮，無上限」** → 電壓太高會把 LED 燒掉。→ LED 需要搭配電阻限制電流，這是《動手玩電》第 2 章的重點。檸檬電池因為電流太小所以不會燒。

## 想一想

**1.** 一顆 9 V 電池接一個 450 Ω 的電阻，電流是多少 mA？

<details><summary>參考答案</summary>

I ＝ V ÷ R ＝ 9 ÷ 450 ＝ 0.02 A ＝ 20 mA。

</details>

**2.** 實驗 11-2 中，你把第一顆檸檬的「銅」接到第二顆的「銅」（接錯了），兩顆串起來量到的電壓會是多少？為什麼？

<details><summary>參考答案</summary>

接近 0 V。兩顆電池方向相反，像兩座一樣高的水塔對著推，電壓互相抵消（0.9 − 0.9 ＝ 0）。串聯一定要「正接負」。

</details>

**3.** 用氣球摩擦頭髮後，氣球帶負電。那小紙片本來不帶電，為什麼會被吸過來而不是沒反應？

<details><summary>參考答案</summary>

靜電感應：氣球的負電把紙片裡的負電荷推到遠端，正電荷留在靠近氣球的那端。近端的正電被吸的力，比遠端負電被推的力大一點（因為距離比較近），總效果是吸引。

</details>

**4.** 想讓實驗 11-3 的電磁鐵吸起更多迴紋針，有哪三種做法？各有什麼代價？

<details><summary>參考答案</summary>

（1）多繞幾圈：需要更多線，線圈電阻變大一點。（2）用更大的電流（多串一顆電池）：電池和線更快發熱、更快沒電。（3）換更粗、更長的鐵釘當鐵心：電磁鐵變重。另外，把線繞得密、不要鬆散，效果也會更好。

</details>

**5.（開放挑戰）** 用實驗 11-3 的電磁鐵、一片薄鐵片（例如罐頭蓋剪下來的一條）和一個會彈回來的東西（橡皮筋或彈簧），設計一個「電池一接上就會自己一直響」的電鈴。畫出設計圖，說明為什麼它會自己斷電再接通。

<details><summary>參考答案</summary>

把鐵片本身當成開關的一部分：電池正極 → 鐵片（鐵片平常靠橡皮筋拉著，碰在一個固定的金屬接點上）→ 線圈 → 電池負極。一接上電池，電流流過線圈，電磁鐵把鐵片吸過去；鐵片一被吸走，就離開了接點，電路斷掉，磁力消失；橡皮筋把鐵片拉回來，又碰到接點，電路再接通……如此不斷重複，鐵片每來回一次就敲一下旁邊的杯子或鈴。這就是老式電鈴的原理，《動手玩電》第 7 章的想一想也有這一題。

</details>

## 本章小結

- 摩擦讓電子搬家，產生靜電；同性相斥、異性相吸；帶電體靠「靜電感應」可以吸起不帶電的小東西。
- 電流 I（安培）像水流，電壓 V（伏特）像水壓，電阻 R（歐姆）像水管的阻力；歐姆定律 V ＝ I × R。
- 電要流動需要閉合迴路；本書只用 9 V 以下的電池，絕不碰 110 V 插座。
- 電池用兩種不同金屬加電解液產生電壓；串聯時電壓相加（正接負）。檸檬電池約 0.9 V，電流極小。
- 磁鐵有 N、S 兩極，同極相斥異極相吸，只吸鐵鈷鎳；磁場單位特斯拉，台灣地磁約 45 µT。
- 電流會產生磁場；線圈加鐵心就是電磁鐵，通電才有磁力，強度約與「圈數 × 電流」成正比。
- 磁場變化也能產生電（電磁感應），馬達和發電機是同一個原理的兩個方向。
- 想深入：《動手玩電》 https://book.vichuang.tw/electric/ ，第 1～4 章講電路基礎，第 7 章講電磁。
