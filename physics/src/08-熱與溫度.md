# 第 8 章　熱與溫度

## 本章目標
- 學完你會分清楚「溫度」和「熱」是兩件不同的事，並且說出它們的單位。
- 學完你會用 Q = m·c·ΔT 算出把一壺水燒熱需要多少能量，也會預測冷熱水混合後的溫度。
- 學完你會解釋為什麼金屬摸起來比木頭冰，但其實它們是同一個溫度。
- 學完你會說出熱傳遞的三種方式（傳導、對流、輻射），並且在廚房裡各找到一個例子。
- 學完你會用廚房溫度計和試算表，畫出一杯熱水的冷卻曲線，比較哪種杯子最保溫。

## 開場：為什麼湯匙比桌子冰？

冬天的早上，小安赤腳踩在磁磚地板上，冷得直跳；踩到旁邊的木頭地墊，就覺得還好。他伸手去拿桌上的不鏽鋼湯匙，又是冰冰的，可是旁邊的木筷子摸起來一點也不冰。

「磁磚和湯匙是不是比較冷？」小安拿廚房溫度計去量：磁磚 18°C，木地墊 18°C，湯匙 18°C，筷子 18°C。全部一樣！

明明溫度一樣，為什麼摸起來差那麼多？這個問題的答案，就藏在「溫度」和「熱」的差別裡。溫度是物體「有多熱」的刻度；而你的手感覺到的，其實是「熱跑得多快」。金屬把你手上的熱很快地帶走，所以你覺得冰；木頭帶走熱的速度很慢，所以你覺得還好。

這一章，我們要把這兩個常常被搞混的觀念拆開來講清楚，再用廚房裡的熱水、杯子和溫度計做實驗，親眼看到熱是怎麼跑的、跑得多快，以及怎麼讓它跑慢一點——這正是保溫杯的全部秘密。

## 核心概念

### 溫度：分子動得有多激烈

所有東西都是由非常小的分子組成的，而分子永遠在動：固體裡的分子在原地抖動，液體裡的分子互相擠來擠去，氣體裡的分子到處亂飛。

溫度（Temperature）就是在描述**分子平均動得有多激烈**。分子動得越激烈，溫度越高。一杯 80°C 的水，裡面的水分子就是比 20°C 的水分子跑得更快、撞得更用力。

台灣日常用的溫標是攝氏（Celsius），符號 °C：水結冰是 0°C，水沸騰是 100°C（在平地）。科學上還有一個克氏溫標（Kelvin），符號 K，它的零點是「分子幾乎完全不動」的絕對零度，換算很簡單：

> K ＝ °C ＋ 273

**算一個例子：** 室溫 25°C 換成克氏就是 25 ＋ 273 ＝ 298 K。

美國用的華氏（Fahrenheit）本書不用，只要知道 °F 的數字看起來比較大就好（體溫 37°C 大約是 98.6°F）。

### 熱：從高溫跑到低溫的能量

熱（Heat）不是「東西有多熱」，而是**從高溫物體傳到低溫物體的那一份能量**。熱是能量，單位就是第 6 章學過的焦耳（Joule），符號 J。另一個常見單位是卡（Calorie），符號 cal，食品包裝上的「大卡」就是 1000 cal。

> 1 cal ＝ 4.18 J　　（讓 1 公克的水升高 1°C 所需要的熱）

請把這句話記牢：**溫度是「狀態」，熱是「流動的能量」。** 一杯熱水「溫度很高」，但它「有很多熱」這種說法在物理上是不精確的；正確的說法是「它可以放出很多熱」。

熱永遠從高溫流向低溫，直到兩邊溫度一樣，這個狀態叫熱平衡（Thermal Equilibrium）。熱水倒進冷水，熱水會變涼、冷水會變溫，最後兩邊一樣，這就是熱平衡。

### 比熱：誰比較「耐燒」？

同樣是曬一整天太陽，海邊的沙子燙得不能踩，海水卻還是涼的。為什麼？因為升高同樣的溫度，水需要吸收的熱比沙子多很多。

比熱（Specific Heat）就是「讓 1 公克的某種東西升高 1°C，需要多少焦耳」，符號 c，單位 J/(g·°C)。常見材料的比熱：

| 材料 | 比熱 c（J/(g·°C)） | 比較 |
|------|------|------|
| 水 | 4.18 | 最耐燒的常見材料 |
| 食用油 | 約 2.0 | 水的一半 |
| 空氣 | 約 1.0 | |
| 鋁 | 0.90 | |
| 沙子、磚塊 | 約 0.8 | 所以沙灘很燙 |
| 鐵、不鏽鋼 | 0.45 | |
| 銅 | 0.39 | 容易熱也容易涼 |

有了比熱，就可以算「要讓某個東西升溫需要多少熱」：

> Q ＝ m × c × ΔT
>
> Q：熱量（J）　m：質量（g）　c：比熱（J/(g·°C)）　ΔT：溫度變化（°C）

ΔT 唸作「delta T」，就是「後來的溫度 − 原來的溫度」。

**算一個例子：** 把 250 g 的水（大約一個馬克杯）從 25°C 燒到 100°C：
Q ＝ 250 × 4.18 × (100 − 25) ＝ 250 × 4.18 × 75 ＝ 78,375 J，大約 78 kJ。

**再算一個：** 同樣是 50 g，鐵湯匙從 25°C 升到 100°C 只需要 50 × 0.45 × 75 ＝ 1,687.5 J；但 50 g 的水要 50 × 4.18 × 75 ＝ 15,675 J，是鐵的 9 倍多。這就是為什麼鍋子一下就燙了，鍋裡的水卻還要等好久。

### 預測冷熱水混合後的溫度

熱水倒進冷水，熱水放出的熱 ＝ 冷水吸收的熱（假設熱沒有跑到杯子和空氣裡）。因為兩邊都是水、比熱一樣，可以約掉，剩下一個很好用的公式：

> 混合後溫度 T ＝ (m₁ × T₁ ＋ m₂ × T₂) ÷ (m₁ ＋ m₂)

說白了就是「用質量當權重的加權平均」。

**算一個例子：** 300 g 的 60°C 熱水加上 100 g 的 20°C 冷水：
T ＝ (300 × 60 ＋ 100 × 20) ÷ 400 ＝ (18,000 ＋ 2,000) ÷ 400 ＝ 20,000 ÷ 400 ＝ 50°C。

**檢查一下合不合理：** 熱水比較多，所以答案應該比較靠近 60°C 而不是 20°C。50°C 確實比較靠近 60，合理。等一下的實驗 8-1，你就要先算再量，看預測準不準。

### 熱怎麼跑：傳導、對流、輻射

熱從高溫跑到低溫有三條路：

```
  傳導（Conduction）        對流（Convection）        輻射（Radiation）
  靠「接觸」傳              靠「流體流動」傳          靠「光（電磁波）」傳
                                                       不需要任何介質
  火 → 鍋底 → 鍋把          鍋底熱水往上升 ↑         太陽 → 太空 → 地球
  ████████████             ╭─────╮                   太陽 ～～～→ 地球
  熱 → → → → 手            │↑ ↓ ↑│ 冷水往下沉 ↓
                           ╰─────╯
```

- **傳導**：分子撞分子，一個傳一個。金屬的傳導特別快（所以叫「良導體」），木頭、塑膠、保麗龍、空氣的傳導很慢（叫「絕熱體」）。開場的湯匙和筷子就是這個道理：湯匙把你手上的熱快速帶走，所以感覺冰。
- **對流**：熱的液體或氣體膨脹變輕往上跑，冷的往下補，形成循環。燒開水時鍋底的水往上翻滾、冷氣要裝高處、暖氣要放低處，都是對流。
- **輻射**：任何有溫度的東西都會往外發出看不見的紅外線。站在營火旁邊不用碰到火就覺得臉熱，太陽的熱穿過真空來到地球，都是輻射。深色、粗糙的表面吸收與發出輻射比較多；亮面、銀色的表面會把輻射反射回去。

保溫杯就是同時對付這三條路：雙層不鏽鋼中間抽真空（沒有分子，傳導和對流都不行），內壁鍍成鏡面（反射輻射）。

### 熱脹冷縮

分子動得越激烈，彼此需要的「活動空間」就越大，所以東西加熱通常會膨脹、冷卻會收縮，這叫熱脹冷縮（Thermal Expansion）。

生活例子：
- 鐵軌每隔一段要留縫，夏天才不會擠彎。一條 100 公尺的鋼軌，溫度上升 30°C 大約會變長 3.6 公分。
- 玻璃罐的金屬蓋轉不開，用熱水沖一下蓋子：金屬膨脹得比玻璃多，蓋子就鬆了。
- 溫度計裡的液體就是靠熱脹冷縮在玻璃管裡上升下降。
- 氣體膨脹得最明顯，等一下實驗 8-3 你會讓一枚硬幣自己「跳」起來。

## 動手做

### 實驗 8-1：冷熱水混合——先預測，再量

**安全提醒：** 熱水用大約 50～60°C 就夠了（熱水瓶的水加一些冷水），不要用剛煮沸的水。倒熱水時請大人在旁邊，手不要放在杯口上方。

**材料／工具**
- 廚房溫度計（探針式，烘焙用那種，五金行或大賣場約一百多元）
- 廚房秤
- 三個杯子（最好是保麗龍杯或紙杯，比較不會把熱吸走）
- 熱水、冷水（自來水）

**步驟**
1. 用廚房秤量出 200 g 的冷水倒進 A 杯，量溫度 T₁，記下來。
2. 量出 100 g 的熱水倒進 B 杯，量溫度 T₂，記下來。動作要快，熱水放著會一直涼。
3. **先算：** 用公式 T ＝ (200 × T₁ ＋ 100 × T₂) ÷ 300 算出預測溫度，寫在表格裡。
4. 把 B 杯的熱水全部倒進 A 杯，用溫度計攪拌幾下，等讀數穩定（約 10 秒），記下實際溫度。
5. 換不同的比例再做兩次：100 g 冷 + 200 g 熱；150 g 冷 + 150 g 熱。

**你應該看到／得到**
實際溫度通常會比預測**低一點點**（差 1～3°C），因為有一些熱跑到杯子、溫度計和空氣裡了。如果差到 5°C 以上，請檢查是不是熱水倒之前又涼掉了，或是杯子太冰（陶瓷杯會吸走不少熱）。

**觀察與記錄**

| 冷水質量 (g) | 冷水溫度 T₁ | 熱水質量 (g) | 熱水溫度 T₂ | 預測溫度 | 實際溫度 | 差多少 |
|------|------|------|------|------|------|------|
| 200 | | 100 | | | | |
| 100 | | 200 | | | | |
| 150 | | 150 | | | | |

### 實驗 8-2：保溫杯大賽——哪種杯子最會留住熱？

**安全提醒：** 同樣用 60°C 左右的熱水即可，請大人幫忙倒。

**材料／工具**
- 家裡找得到的各種杯子，每種一個：紙杯、保麗龍杯、陶瓷馬克杯、玻璃杯、單層不鏽鋼杯、真空保溫杯（有的話）
- 廚房溫度計
- 廚房秤、碼表（手機）
- 可以蓋住杯口的小盤子或鋁箔（每杯一個）

**步驟**
1. 每個杯子都倒入**一樣重**的熱水（例如 150 g），越快越好。
2. 立刻量每一杯的起始溫度，記下來，然後蓋上蓋子（蓋子中間戳一個小洞讓溫度計插進去，或是每次量完再蓋回去）。
3. 每 5 分鐘量一次所有杯子的溫度，連續量 30 分鐘。
4. 量的時候溫度計要插到一樣的深度，不要碰到杯底。
5. 同時也量一次房間的室溫，記在表格最下面。

**你應該看到／得到**
所有杯子一開始都降得很快，後來越降越慢（因為和室溫差距變小，熱跑得慢了）。保麗龍杯和真空保溫杯通常是最保溫的；單層不鏽鋼杯和玻璃杯通常最快涼。陶瓷杯一開始會掉特別快（杯子本身很重，先吸走一大口熱），之後就比較穩。

**觀察與記錄**

| 時間（分） | 紙杯 | 保麗龍杯 | 陶瓷杯 | 玻璃杯 | 不鏽鋼杯 | 保溫杯 |
|------|------|------|------|------|------|------|
| 0 | | | | | | |
| 5 | | | | | | |
| 10 | | | | | | |
| 15 | | | | | | |
| 20 | | | | | | |
| 25 | | | | | | |
| 30 | | | | | | |
| 室溫 | | | | | | |

### 實驗 8-3：會跳的硬幣——看見空氣的熱脹冷縮

**安全提醒：** 這個實驗沒有熱水也沒有火，只需要你的手。

**材料／工具**
- 一個空的玻璃瓶（瓶口要比硬幣小一點，例如小瓶裝飲料或調味料瓶，洗乾淨）
- 一枚 10 元硬幣（要能蓋住瓶口）
- 冰箱、一點水

**步驟**
1. 把空瓶（不蓋蓋子）放進冰箱冷藏 10 分鐘。
2. 拿出來，馬上在瓶口沾一點水，把硬幣放在瓶口上蓋住（水是為了把縫隙封住）。
3. 兩隻手握住瓶身，不要動，等 30 秒到 1 分鐘。
4. 仔細看硬幣。

**你應該看到／得到**
硬幣會「咔」一聲跳一下，然後過幾秒又跳一下。因為你的手把瓶子裡的冷空氣加熱，空氣膨脹，壓力變大，就把硬幣頂開跑出去一點。試試看：手握得越緊、瓶子越冰，跳得越快。

**觀察與記錄**

| 瓶子狀態 | 1 分鐘內跳幾次 | 第一次跳在第幾秒 |
|------|------|------|
| 冷藏 10 分鐘 | | |
| 冷藏 10 分鐘，用吹風機吹 | | |
| 沒冰過的瓶子 | | |

## 用儀器看看

### 廚房溫度計：怎麼用才準

探針式溫度計要注意三件事：
1. **插夠深**：探針的感溫點在尖端 1～2 公分，要整段泡進水裡。
2. **不要碰杯壁、杯底**：杯子的溫度和水不一樣。
3. **等讀數穩定**：通常要 5～10 秒。看到數字不再跳動才記錄。

可以用冰水檢查你的溫度計準不準：杯子裝滿碎冰再加一點水，攪拌 1 分鐘，插進去應該讀到 0°C（±1°C）。如果差很多，以後量到的數字都要加減同樣的修正值。

### 試算表：畫出冷卻曲線

1. 打開 Google 試算表（或 Excel），A 欄打「時間（分）」，B 欄起每一欄一種杯子，把實驗 8-2 的數據填進去。
2. 全選數據，點「插入 → 圖表」，圖表類型選「折線圖」。橫軸是時間，每條線是一種杯子。
3. 你會看到每條線都是「先陡後緩」的下降曲線，而且越保溫的杯子線越平。

想算出「平均每分鐘降幾度」，在最後一列下面打：`=(B2-B8)/30`，就是（起始溫度 − 30 分鐘後溫度）÷ 30。把這個公式往右拉，每種杯子都算一次，就可以排名了。

下面是一組範例數據（不同家的杯子會不一樣，請以你的實驗為準）：

| 時間（分） | 紙杯 | 保麗龍杯 | 陶瓷杯 | 保溫杯 |
|------|------|------|------|------|
| 0 | 60.0 | 60.0 | 60.0 | 60.0 |
| 10 | 51.5 | 56.0 | 49.0 | 59.0 |
| 20 | 45.5 | 52.5 | 44.0 | 58.2 |
| 30 | 41.0 | 49.5 | 40.5 | 57.5 |
| 平均每分鐘降（°C） | 0.63 | 0.35 | 0.65 | 0.08 |

驗算一下保麗龍杯：(60.0 − 49.5) ÷ 30 ＝ 10.5 ÷ 30 ＝ 0.35°C/分，沒錯。

## 常見錯誤與迷思

- **「金屬比木頭冷」** → 兩者放在同一個房間久了，溫度是一樣的。→ 金屬傳導快，把手上的熱帶走得快，所以「感覺」冷。你的手是在量「熱流速度」，不是在量溫度。
- **「溫度高就是熱很多」** → 一根點燃的火柴溫度上千度，但它能放出的熱連一杯水都燒不開；一個 40°C 的溫泉池溫度不高，放出的熱卻很多。→ 熱的多寡還要看質量和比熱（Q ＝ m·c·ΔT），不是只看溫度。
- **「冷會流進來」** → 開冰箱時感覺「冷氣跑出來」。→ 物理上只有「熱」在流動，是你身體和房間的熱流進冰箱裡，沒有「冷」這種東西在跑。
- **「穿毛衣是因為毛衣會發熱」** → 毛衣自己不會產生熱。→ 毛衣裡卡了很多不流動的空氣，空氣是很差的導體，所以把你身體的熱留住。溫度計包在毛衣裡並不會升溫。
- **「混合後的溫度是兩個溫度的平均」** → 只有兩杯水「一樣重」時才對。→ 要用質量加權：T ＝ (m₁T₁ ＋ m₂T₂) ÷ (m₁ ＋ m₂)。
- **「保溫杯只能保熱」** → 保溫杯擋的是熱的流動，不分方向。→ 裝冰水它一樣能保冰。

## 想一想

**1.** 把 500 g 的水從 20°C 加熱到 70°C，需要多少焦耳？

<details><summary>參考答案</summary>

Q ＝ m × c × ΔT ＝ 500 × 4.18 × (70 − 20) ＝ 500 × 4.18 × 50 ＝ 104,500 J，大約 105 kJ（也就是 25,000 cal ＝ 25 大卡）。

</details>

**2.** 400 g 的 80°C 熱水，倒進 200 g 的 20°C 冷水裡，混合後大約幾度？

<details><summary>參考答案</summary>

T ＝ (400 × 80 ＋ 200 × 20) ÷ (400 ＋ 200) ＝ (32,000 ＋ 4,000) ÷ 600 ＝ 36,000 ÷ 600 ＝ 60°C。熱水比較多，所以答案靠近 80 那邊，合理。

</details>

**3.** 夏天中午，游泳池旁邊的水泥地燙得不能踩，池水卻是涼的。請用「比熱」解釋。

<details><summary>參考答案</summary>

兩者接收到差不多的太陽熱量，但水的比熱（4.18）是水泥（約 0.8）的五倍多，吸收同樣的熱，水的溫度只上升五分之一左右。而且池水很深、質量很大，熱還會靠對流分散到整池，所以升溫更少。

</details>

**4.** 同樣一杯熱咖啡，你想在 10 分鐘後喝到最熱的狀態。牛奶要「一開始就加」還是「10 分鐘後再加」？為什麼？

<details><summary>參考答案</summary>

一開始就加。咖啡越熱，和室溫差越大，熱跑得越快（實驗 8-2 的曲線先陡後緩就是這個意思）。先加牛奶把溫度降下來，這 10 分鐘內散熱就比較慢；最後再加牛奶的話，咖啡在這 10 分鐘以高溫快速散熱，最後再被牛奶降一次，反而更涼。你可以用兩杯熱水和溫度計實際比比看。

</details>

**5.（開放挑戰）** 請用家裡的材料，設計一個「自製保溫杯」：以一個普通紙杯為基礎，你可以在外面包東西、放在別的容器裡、加蓋子……但不能用市售保溫杯。先畫出設計圖，說明你針對傳導、對流、輻射各做了什麼，然後用實驗 8-2 的方法和原本的紙杯比一比。

<details><summary>參考答案</summary>

一個效果不錯的設計：紙杯外面先包一層鋁箔（亮面朝內，反射輻射），再包兩三層氣泡紙或毛巾（卡住空氣，擋傳導），放進一個更大的紙杯或碗裡（中間留空氣層），最上面用保鮮膜或蓋子封住杯口（擋住最大的對流散熱出口）。杯口通常是散熱最多的地方，所以「加蓋」往往是最有效的一步。第 13 章的專題四就是正式的保溫杯設計比賽。

</details>

**6.（開放挑戰）** 實驗 8-1 量到的實際溫度幾乎都比預測低。請想出三個讓熱「漏掉」的地方，並想辦法用實驗證明其中一個。

<details><summary>參考答案</summary>

可能的漏洞：（1）杯子本身吸熱（陶瓷杯特別明顯）；（2）倒水、攪拌的過程中熱水持續對空氣散熱；（3）溫度計本身也吸了一點熱；（4）熱水從 B 杯倒到 A 杯時有幾滴留在杯壁上。證明（1）的方法：用陶瓷杯和保麗龍杯各做一次同樣的混合，看陶瓷杯的誤差是不是明顯比較大。也可以先用熱水把杯子「預熱」一下再做，看誤差會不會變小。

</details>

## 本章小結

- 溫度描述分子平均動得多激烈，單位 °C（或 K ＝ °C ＋ 273）；熱是從高溫流向低溫的能量，單位 J（1 cal ＝ 4.18 J）。
- 比熱 c 是讓 1 g 物質升高 1°C 所需的熱；水的比熱 4.18 J/(g·°C) 特別大，所以升溫慢、降溫也慢。
- 加熱或冷卻所需的熱量：Q ＝ m × c × ΔT。
- 冷熱水混合的溫度是質量加權平均：T ＝ (m₁T₁ ＋ m₂T₂) ÷ (m₁ ＋ m₂)，實測通常略低於預測，因為有熱漏掉。
- 熱傳遞三條路：傳導（靠接觸，金屬快、空氣慢）、對流（靠流體流動，熱的往上）、輻射（靠紅外線，不需要介質，亮面會反射）。
- 物體與環境的溫差越大，散熱越快；冷卻曲線先陡後緩。
- 大多數物質熱脹冷縮，氣體最明顯。
