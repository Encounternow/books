# 附錄 C　材料清單與替代品

這一份清單把全書每一章實驗用到的東西列出來，並告訴你**家裡沒有的時候可以用什麼代替**。全書的原則是：所有材料在家裡廚房、客廳、文具店、生活百貨（五金行）或超市就買得到，不需要上網訂購實驗器材。

幾個約定：
- 「全書通用」那一張表的東西幾乎每一章都會用，建議一開始就準備好，放在一個鞋盒裡。
- 「替代品」是真的可以用的替代，不是將就；替代後要注意的事寫在括號裡。
- 標 **★** 的是安全相關，請一定要照做。
- 有 Arduino 的讀者才需要「進階（選配）」那一欄，沒有也能做完全書。
