# 第 9 章　波與聲音

## 本章目標
- 學完你會說出波的四個基本量：頻率、週期、波長、振幅，並且用 v ＝ f × λ 算出聲音的波長。
- 學完你會解釋聲音是怎麼產生、怎麼傳到耳朵的，以及為什麼太空裡聽不到聲音。
- 學完你會分辨「音高」和「響度」各由什麼決定，並且說出人耳聽得到的頻率範圍。
- 學完你會用橡皮筋和玻璃杯做出樂器，並且預測怎麼調音會變高或變低。
- 學完你會用手機的 Phyphox 看到聲音的頻譜，讀出一個音的頻率是幾赫茲。

## 開場：先看到閃電，再聽到雷聲

夏天的午後，小安站在窗邊看雷雨。天空「唰」地亮了一下，他開始數：一、二、三、四、五——「轟隆隆隆」雷聲才到。過了幾分鐘又一道閃電，這次只數到二就打雷了，而且聲音大得窗戶都在震。

「雷是不是越來越近了？」小安問。

沒錯。閃電和雷聲其實是同一瞬間發生的，但光跑得太快，幾乎馬上到；聲音每秒只跑大約 343 公尺，所以會慢慢來。數到五，代表雷離你大約 5 × 343 ＝ 1,715 公尺，快 2 公里；數到二，就只剩 686 公尺了。

聲音為什麼要「跑」？它是什麼東西在跑？為什麼有些聲音尖、有些聲音低，有些大聲、有些小聲？這一章我們要把聲音當成一種「波」來看，先用橡皮筋和水杯做樂器，再用手機把聲音畫成圖，你會發現每一個音都有它的數字。

## 核心概念

### 波：傳遞能量，但不搬運物質

把一條繩子的一端綁在門把上，另一端拿在手裡抖一下，你會看到一個「凸起」沿著繩子跑過去。繩子本身沒有跑到門那邊，但「抖動」這件事傳過去了。

這就是波（Wave）：**振動在空間中傳播，傳的是能量和訊息，不是物質本身。** 池塘的水波、繩波、聲波、光波，都是波。

波分成兩種：

```
  橫波（Transverse）：質點上下動，波往右跑（繩波、水波）
       ∧     ∧     ∧
      / \   / \   / \     →→→ 波的方向
     /   \ /   \ /   \
          ∨     ∨

  縱波（Longitudinal）：質點前後動，波也往右跑（聲波、彈簧的「疏密波」）
   ||||  |  |  |  ||||  |  |  |  ||||     →→→
   密    疏         密    疏         密
```

聲波是縱波：空氣分子被推擠、變密，再彈回來、變疏，這一疏一密往前傳，就是聲音。

### 描述一個波：頻率、週期、波長、振幅

```
             波長 λ
         ◄──────────►
         ∧          ∧          ∧
   振幅 A│ \        / \        / \
   ──────┼──\──────/───\──────/───\────  平衡位置
         │   \    /     \    /     \
              ∨          ∨          ∨
```

- **振幅（Amplitude）A**：離平衡位置最遠的距離。振幅越大，波帶的能量越多，聲音就越大聲。
- **波長（Wavelength）λ**（唸「lambda」）：相鄰兩個波峰的距離，單位公尺。
- **頻率（Frequency）f**：每秒鐘振動幾次，單位赫茲（Hertz），符號 Hz。1 Hz 就是每秒 1 次。
- **週期（Period）T**：振動一次要花幾秒。週期和頻率互為倒數：T ＝ 1 ÷ f。

**算一個例子：** 鋼琴中央偏右的 A 音是 440 Hz，每秒振動 440 次，週期 T ＝ 1 ÷ 440 ≈ 0.00227 秒，大約 2.3 毫秒。

這四個量之中，最重要的關係是：**波每秒跑多遠 ＝ 每秒幾個波 × 每個波多長**：

> v ＝ f × λ
>
> v：波速（m/s）　f：頻率（Hz）　λ：波長（m）

**算一個例子：** 空氣中的聲速約 343 m/s，440 Hz 的 A 音波長 λ ＝ 343 ÷ 440 ≈ 0.78 公尺。低音 100 Hz 的波長是 343 ÷ 100 ＝ 3.43 公尺；高音 10,000 Hz 的波長只有 343 ÷ 10,000 ＝ 0.0343 公尺，大約 3.4 公分。頻率越高，波長越短。

### 聲音的產生與傳播

**聲音是振動產生的。** 把手放在喉嚨上說話，你會感覺到在震；敲一下桌子，桌面在震；吉他弦撥下去看得到它在抖。

振動的東西推擠旁邊的空氣，空氣一疏一密地往外傳，傳到你的耳膜，耳膜跟著振動，你就聽到了。所以聲音需要介質（Medium）——空氣、水、固體都可以，但**真空不行**。太空裡沒有空氣，太空船爆炸是沒有聲音的（電影裡有聲音是為了好看）。

聲音在不同介質裡的速度：

| 介質 | 聲速（約） | 備註 |
|------|------|------|
| 空氣（20°C） | 343 m/s | 本書一律用這個數字 |
| 空氣（0°C） | 331 m/s | 越冷越慢 |
| 水 | 1,480 m/s | 空氣的 4 倍多 |
| 鋼鐵 | 5,000 m/s 以上 | 把耳朵貼在鐵軌上可以提早聽到火車 |

**算一個例子：** 運動會 100 公尺賽跑，你站在終點，看到發令槍冒煙之後多久才聽到槍聲？100 ÷ 343 ≈ 0.29 秒。所以正式比賽的計時是從槍響的電子訊號開始，不是從聽到聲音開始。

**回音測距：** 對著遠處的牆拍手，聲音去一趟、回一趟。如果 0.4 秒後聽到回音，聲音總共跑了 343 × 0.4 ≈ 137 公尺，牆的距離是一半：約 69 公尺。第 13 章專題二會用這個方法測聲速。

### 音高、響度、音色

同樣是「聲音」，為什麼有這麼多不同？三個關鍵：

| 聽起來的感覺 | 對應的物理量 | 例子 |
|------|------|------|
| 音高（Pitch）：尖或低 | 頻率 f | 小鳥叫頻率高，牛叫頻率低 |
| 響度（Loudness）：大聲或小聲 | 振幅 A | 輕敲和重敲同一個杯子，頻率一樣，振幅不同 |
| 音色（Timbre）：是什麼樂器 | 波的形狀（含有哪些泛音） | 鋼琴和長笛彈同一個 A，一聽就分得出來 |

人耳大約聽得到 **20 Hz 到 20,000 Hz**。年紀越大，聽得到的上限越低，很多大人聽不到 15,000 Hz 以上的聲音，但你可能還聽得到。狗聽得到 45,000 Hz，所以有「狗哨」。

響度常用分貝（Decibel，dB）表示：悄悄話約 30 dB、一般講話 60 dB、吵鬧的馬路 80 dB、演唱會 110 dB。分貝的數學超過本書範圍，你只要知道：**每多 10 dB，聲音的能量多 10 倍**，所以 80 dB 不是 60 dB 的「多一點」，而是能量 100 倍。長時間超過 85 dB 會傷害聽力。

### 弦怎麼決定音高

吉他、小提琴、鋼琴都是「弦」在振動。弦的頻率由三件事決定：

| 改變什麼 | 頻率怎麼變 | 樂器上的例子 |
|------|------|------|
| 弦越**短** | 越高 | 手指按在高把位，聲音變高 |
| 弦拉得越**緊** | 越高 | 轉調音鈕把弦轉緊 |
| 弦越**細**（越輕） | 越高 | 吉他最細的弦是最高音 |

其中「長度」的規則特別漂亮：**弦長減半，頻率加倍**（高八度）。更一般的說法是頻率和弦長成反比。

**算一個例子：** 一條橡皮筋撐開 30 公分時量到 200 Hz。用手指壓在 15 公分處（只剩一半在振動），應該變成 400 Hz；壓在 20 公分處，頻率 ＝ 200 × 30 ÷ 20 ＝ 300 Hz。

### 共鳴：每個東西都有自己喜歡的頻率

盪鞦韆的時候，你要在「對的時間點」推，鞦韆才會越盪越高；亂推只會把它搞停。每個會振動的東西都有一個它最喜歡的頻率，叫自然頻率（Natural Frequency）。用剛好這個頻率去推它，振幅會變得很大，這叫共鳴（Resonance）。

- 用手指沾水摩擦高腳杯的杯緣，杯子會唱歌，那是你的手指以杯子的自然頻率在推它。
- 吉他的木箱是共鳴箱，把弦那一點點振動放大成一整個房間都聽得到。
- 實驗 9-2 的水杯琴：玻璃杯裡的水越多，杯子振動時要帶著更多水一起動，動得慢，頻率就越低。

音階參考頻率（中央 C 那個八度）：

| 音名 | C | D | E | F | G | A | B | 高八度 C |
|------|------|------|------|------|------|------|------|------|
| 簡譜 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 1̇ |
| 頻率（Hz） | 262 | 294 | 330 | 349 | 392 | 440 | 494 | 523 |

注意高八度的 C 剛好是 262 的 2 倍。

## 動手做

### 實驗 9-1：橡皮筋吉他

**安全提醒：** 橡皮筋拉太緊可能會斷掉彈到眼睛，不要把臉湊太近，也不要用力拉超過兩倍長。

**材料／工具**
- 一個硬的空盒（面紙盒、鞋盒、或保鮮盒），開口朝上
- 粗細不同的橡皮筋 3～4 條（文具店一包就有）
- 兩枝鉛筆（當琴橋）
- 尺
- 手機裝好 Phyphox（用法見本章「用儀器看看」）

**步驟**
1. 把橡皮筋一條一條套在盒子上，橫跨開口。
2. 在開口兩側各塞一枝鉛筆到橡皮筋下面，把橡皮筋架高，讓它可以自由振動。兩枝鉛筆之間的距離就是「弦長」，用尺量下來。
3. 撥動每一條橡皮筋，聽聽看哪一條音高、哪一條音低。用 Phyphox 的頻譜量出每條的頻率。
4. **改變長度：** 選一條橡皮筋，用手指把它按在盒子邊緣某一點（例如弦長的一半處），再撥動沒被按住的那段。先預測頻率會變成幾倍，再量。
5. **改變鬆緊：** 把其中一枝鉛筆往外移，橡皮筋被拉得更緊（長度也會變），撥動聽聽看。
6. **改變粗細：** 比較一條粗的和一條細的，拉到差不多一樣緊，哪一條高？

**你應該看到／得到**
弦越短、越緊、越細，頻率越高。按在一半處的頻率應該接近原本的 2 倍（例如 180 Hz → 350 Hz 左右，因為橡皮筋按下去也會多拉緊一點，所以常常略高於 2 倍）。

**觀察與記錄**

| 橡皮筋 | 粗細 | 弦長（cm） | 頻率（Hz） | 弦長 × 頻率 |
|------|------|------|------|------|
| A（全長） | | | | |
| A（按在一半） | | | | |
| A（按在 1/3 處，振動 2/3） | | | | |
| B（全長） | | | | |
| C（全長） | | | | |

最後一欄「弦長 × 頻率」在同一條橡皮筋、同樣鬆緊的情況下應該差不多是固定的——這就是「頻率和弦長成反比」的證據。

### 實驗 9-2：水杯琴

**安全提醒：** 玻璃杯不要敲太用力，用筷子或鉛筆敲杯緣就好，不要用金屬湯匙。

**材料／工具**
- 一樣的玻璃杯 5～8 個（越一樣越好）
- 水、量杯
- 一根筷子或鉛筆
- 手機 Phyphox

**步驟**
1. 把空杯排成一排，用筷子輕敲杯緣，先聽「空杯」的聲音，用 Phyphox 量頻率。
2. 第一杯裝 50 mL 水，第二杯 100 mL，第三杯 150 mL……依序加多。
3. 依序敲每一杯，聽音高怎麼變，並量出頻率記下來。
4. 挑戰：調整水量，讓八個杯子敲出 Do Re Mi Fa So La Si Do。對照上面的音階表，用 Phyphox 幫你調。
5. 換一個方法：對著空杯口「吹」（像吹瓶子那樣），聽聽看加水之後音高是變高還是變低。

**你應該看到／得到**
用「敲」的：水越多，音越**低**（杯子要帶著更多水一起振動）。
用「吹」的：水越多，音越**高**（吹的時候振動的是杯子裡的空氣柱，水越多、空氣柱越短，頻率越高——和短弦音高是同一個道理）。
兩種方法方向相反，這是很多人會搞錯的地方。

**觀察與記錄**

| 杯號 | 水量（mL） | 敲：頻率（Hz） | 吹：頻率（Hz） | 最接近的音名 |
|------|------|------|------|------|
| 1 | 0 | | | |
| 2 | 50 | | | |
| 3 | 100 | | | |
| 4 | 150 | | | |
| 5 | 200 | | | |

### 實驗 9-3：看見聲音——會跳舞的鹽

**安全提醒：** 用手機或小喇叭放聲音就好，不要把音量開到最大，保護耳朵。

**材料／工具**
- 一個碗或大杯子
- 保鮮膜、橡皮筋
- 一小撮鹽或細砂糖
- 手機（用 Phyphox 的「Tone Generator」發聲，或任何能放音樂的 App）

**步驟**
1. 把保鮮膜緊緊繃在碗口，用橡皮筋固定，繃得越平越好，像一個小鼓。
2. 在膜上撒一層薄薄的鹽。
3. 把手機喇叭靠近膜（不要碰到），播放 100 Hz 的低音，音量慢慢加大。
4. 換 200 Hz、400 Hz、800 Hz，觀察鹽的反應。
5. 也可以不用手機，直接對著膜大聲「嗡——」，看看鹽會不會動。

**你應該看到／得到**
鹽粒會在膜上跳動，低頻、大聲時跳得最明顯；有些頻率鹽會自己聚集成一條一條的線或圖案（那是膜上振動最小的地方）。這證明聲音真的是空氣在推擠——你沒有碰到膜，膜卻被「空氣的振動」推動了。

**觀察與記錄**

| 頻率（Hz） | 鹽有沒有跳 | 跳的高度（沒有／小／大） | 有沒有出現圖案 |
|------|------|------|------|
| 100 | | | |
| 200 | | | |
| 400 | | | |
| 800 | | | |
| 用嘴巴哼 | | | |

## 用儀器看看

### Phyphox：把聲音畫成頻譜

Phyphox 是免費的手機物理實驗 App（Android、iPhone 都有），它把手機裡的麥克風、加速度計等感測器變成儀器。打開後往下捲到「Acoustics（聲學）」，有幾個工具：

**1. Audio Spectrum（聲音頻譜）**
1. 點進去，按右上角的「▶」開始。
2. 畫面會出現一張圖：橫軸是頻率（Hz），縱軸是強度。安靜時幾乎是平的。
3. 撥一下橡皮筋或敲一下杯子，圖上會冒出一個或幾個尖峰。**最左邊、最高的那個尖峰就是這個音的基本頻率**（右邊那些比較小的尖峰是泛音，是音色的來源）。
4. 用手指在圖上按住，上方會顯示你按的位置的頻率。
5. 想看得更穩定，可以在設定裡把「Exponential filter」開大一點，圖就不會一直抖。

**2. Audio Autocorrelation（自相關）**
這個工具專門抓「單一個音」的頻率，比頻譜更準。按「▶」，對著手機發出聲音，畫面上方直接顯示「Frequency：xxx Hz」。實驗 9-1、9-2 用這個最方便。

**3. Tone Generator（音頻產生器）**
拉動滑桿或輸入數字，手機就會發出那個頻率的純音。可以用它：
- 做實驗 9-3。
- 測自己的聽力上限：從 10,000 Hz 往上調，調到你聽不到為止，再找家裡的大人試試看，比一比。

**4. Sound Meter（音量計）**
顯示現在環境的分貝數。試試看：安靜的房間、講話、拍手、開電視，各是幾 dB？（手機麥克風沒有校正過，數字只能相對比較，不是精準值。）

### 試算表：驗證「頻率和弦長成反比」

1. 打開 Google 試算表，A 欄打「弦長（cm）」，B 欄打「頻率（Hz）」，把實驗 9-1 同一條橡皮筋、不同按壓位置的數據填進去。
2. C 欄打「乘積」，C2 打 `=A2*B2`，往下拉。如果 C 欄的數字都差不多，就證明兩者成反比。
3. 再加 D 欄「1/弦長」，D2 打 `=1/A2`。全選 B、D 欄插入「散佈圖」，點會大致排成一條通過原點的直線。

範例數據（一條橡皮筋，鬆緊固定）：

| 弦長（cm） | 頻率（Hz） | 弦長 × 頻率 |
|------|------|------|
| 30 | 200 | 6,000 |
| 20 | 305 | 6,100 |
| 15 | 410 | 6,150 |
| 10 | 620 | 6,200 |

乘積都在 6,000 左右，略微上升是因為按壓時橡皮筋又被拉緊了一點。

## 常見錯誤與迷思

- **「聲音大就是頻率高」** → 大聲是振幅大，不是頻率高。→ 用力敲杯子只會變大聲，音高不變。響度看振幅，音高看頻率。
- **「聲音在空氣裡最快」** → 空氣其實是傳聲最慢的常見介質。→ 水裡 1,480 m/s、鋼鐵 5,000 m/s 以上，越硬、越密的材料通常傳得越快。
- **「太空電影裡的爆炸聲是真的」** → 真空沒有分子可以推擠。→ 太空中聽不到任何聲音。
- **「波在跑，所以空氣也跟著跑到耳朵裡」** → 波傳遞的是振動，不是物質。→ 空氣分子只在原地前後抖動，就像海浪推過來，水面上的葉子只是上下起伏並沒有被沖上岸。
- **「水杯琴水越多音越高」** → 只有「吹」的時候才對。→ 用「敲」的話，水越多音越低。兩種方法振動的東西不一樣（一個是空氣柱，一個是杯子本身）。
- **「Phyphox 顯示好幾個尖峰，是量錯了」** → 那些是泛音，每個樂器都有。→ 看最左邊的主峰就是基本頻率；泛音的頻率通常是主峰的 2 倍、3 倍……。

## 想一想

**1.** 聲音在空氣中 343 m/s。一個 686 Hz 的音，波長是多少？

<details><summary>參考答案</summary>

λ ＝ v ÷ f ＝ 343 ÷ 686 ＝ 0.5 公尺。

</details>

**2.** 看到閃電後數了 8 秒才聽到雷聲，閃電大約在幾公尺外？

<details><summary>參考答案</summary>

343 × 8 ＝ 2,744 公尺，大約 2.7 公里。光的那一小段時間可以忽略不計（光跑 2.7 公里只要約 0.00001 秒）。

</details>

**3.** 實驗 9-1 有一條橡皮筋全長 24 cm 時是 250 Hz。如果按在離一端 8 cm 的地方，撥動長的那一段（16 cm），頻率應該變成多少？

<details><summary>參考答案</summary>

頻率和弦長成反比：250 × 24 ÷ 16 ＝ 375 Hz。實際量到的可能略高一點，因為按壓時又把橡皮筋拉緊了。

</details>

**4.** 吉他手想把一條弦的音調高，有哪三種做法？在彈奏中（不轉調音鈕的情況下），實際上用的是哪一種？

<details><summary>參考答案</summary>

（1）把弦縮短、（2）把弦拉緊、（3）換一條更細的弦。彈奏中用的是「縮短」：手指按在琴格上，讓振動的弦變短。「推弦」技巧則是把弦往旁邊推、拉得更緊，也會讓音變高一點。

</details>

**5.（開放挑戰）** 設計一個方法，只用手機和一面大牆（例如學校操場旁的建築），量出聲速。寫下步驟、你需要記錄什麼、怎麼算，以及可能的誤差來源。

<details><summary>參考答案</summary>

方法一：站在離牆 D 公尺的地方（用捲尺或腳步量），拍手並用手機錄音（或 Phyphox 的「Acoustic Stopwatch」），從錄音波形上讀出「拍手聲」和「回音」之間的時間差 t，聲速 v ＝ 2D ÷ t。距離越遠越好量（50 公尺以上 t 才有 0.3 秒）。方法二：兩支手機都開 Phyphox「Acoustic Stopwatch」，相隔 D 公尺放好，在一端拍手，兩支手機各記錄聽到聲音的時間，時間差就是聲音跑 D 的時間。誤差來源：距離量不準、拍手聲不夠短、風、手機時鐘沒對準。第 13 章專題二有完整做法。

</details>

**6.（開放挑戰）** 用 Phyphox 的 Tone Generator 找出家裡每個人「聽得到的最高頻率」，做成一張表，並且推測年齡和這個數字的關係。再想想：為什麼手機的喇叭在超過某個頻率之後，可能根本發不出聲音，這會怎麼影響你的測量？

<details><summary>參考答案</summary>

通常年紀越大上限越低：小學生可能到 18,000～20,000 Hz，三四十歲的大人常在 14,000～16,000 Hz，六十歲以上可能低於 12,000 Hz。但手機喇叭本身在 16,000～18,000 Hz 以上輸出會變很弱甚至沒有，所以「聽不到」可能是喇叭發不出來，不是耳朵不行。可以把 Phyphox 的 Audio Spectrum 開在另一支手機上，確認喇叭真的有發出那個頻率，再來判斷。

</details>

## 本章小結

- 波傳遞振動和能量，不搬運物質。橫波質點上下動，縱波質點前後動；聲波是縱波。
- 描述波的四個量：振幅 A（能量、響度）、波長 λ、頻率 f（Hz，每秒幾次）、週期 T ＝ 1/f。
- 波速 v ＝ f × λ。空氣中聲速約 343 m/s，水裡約 1,480 m/s，真空中沒有聲音。
- 音高由頻率決定，響度由振幅決定，音色由波形（泛音）決定；人耳約聽 20～20,000 Hz。
- 弦越短、越緊、越細，頻率越高；弦長減半頻率加倍，頻率和弦長成反比。
- 每個物體有自然頻率，用相同頻率去推它會共鳴，振幅變很大。
- 敲水杯：水多音低；吹水杯：水多音高。
- Phyphox 的 Audio Spectrum 看頻譜、Audio Autocorrelation 讀單音頻率、Tone Generator 發純音。
