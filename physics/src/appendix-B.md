# 附錄 B　手機 Phyphox 與慢動作錄影操作速查

這一頁是手機拿在手上的時候看的。Phyphox 的部分照 App 畫面順序寫，每一個本書用到的功能都有「打開哪裡、按什麼、看什麼」；慢動作錄影的部分 iPhone 和 Android 分開寫，最後教你怎麼從影片裡「數格子」算時間。不同手機、不同版本的畫面會差一點，但按鈕的名字大致相同。

> **一開始就要知道的事**：手機裡的感測器都在機身裡，不在螢幕上。加速度計量的是「手機本身」的加速度，磁力計量的是手機所在位置的磁場。所以做實驗時要固定的是手機，不是你的手。

---

## B.1　安裝與第一次打開 Phyphox

1. 在 App Store（iPhone）或 Google Play（Android）搜尋 **phyphox**（德國亞琛工業大學做的免費 App，沒有廣告）。安裝。
2. 第一次打開會問權限：**麥克風**（聲音實驗要用）、**位置**（只有 GPS 實驗要用，可以先不給）。相機、通知可以不給。
3. 首頁是一長串實驗清單，按類別分組：Raw Sensors（原始感測器）、Acoustics（聲學）、Mechanics（力學）、Timers（計時）、Everyday（日常）等。
4. 右上角「⋮」或「…」→ Settings 可以切換語言；本書用英文名稱，括號裡給中文，因為中文翻譯在不同版本不太一樣。
5. 每個實驗畫面都長一樣：上方幾個分頁（例如 Graph、Simple、Raw Data），右上角有 **▶ 開始／⏸ 暫停**、**🗑 清除**、**⋮ 更多**（裡面有 Export data 匯出、Timed run 定時、Allow remote access 遠端）。

```
 ┌────────────────────────────────────┐
 │ ← Acceleration (without g)   ▶ 🗑 ⋮ │
 ├────────────────────────────────────┤
 │  Graph │ Simple │ Multi │ Raw Data │
 ├────────────────────────────────────┤
 │  Absolute  ╱╲      ╱╲              │
 │  a (m/s²) ╱  ╲____╱  ╲____         │
 │           ─────────────────► t (s) │
 │  x: 0.12   y: −0.05   z: 9.81      │
 └────────────────────────────────────┘
```

## B.2　三個每次都會用到的功能

**定時啟動（Timed run）**：手機放好以後你需要時間走開，或是要量固定長度的一段。
1. 實驗畫面右上 ⋮ → **Timed run**。
2. 設 Start delay（延遲幾秒開始，例如 5 s）和 Experiment duration（量幾秒，例如 10 s）。
3. 按 ▶，手機會倒數，然後自動量、自動停。

**遠端操作（Allow remote access）**：手機綁在擺上、放在滑車上時，你用電腦或另一支手機看數據、按開始。
1. 兩台裝置連同一個 Wi-Fi。
2. 實驗畫面 ⋮ → **Allow remote access** 打開，畫面下方會出現網址，例如 `http://192.168.1.23:8080`。
3. 在電腦瀏覽器輸入那個網址，就會看到一樣的圖，可以按開始、暫停、匯出。

**匯出數據（Export data）**：把數據拿到試算表畫圖。
1. 量完後 ⋮ → **Export data**。
2. 選格式：**CSV (Comma, decimal point)** 最通用；Excel 也可以。
3. 用 AirDrop、Email、LINE 或存到檔案，再用 Google 試算表「檔案 → 匯入」打開。
4. 每一欄是一個量（時間、x、y、z……），第一列是欄名。

下面是幾個操作細節最多的實驗。

### B.3.1　Acceleration (without g)：量加速度

1. Mechanics → **Acceleration (without g)**。「without g」表示已經扣掉重力，手機靜止放桌上時三軸都接近 0。
2. 把手機用橡皮筋固定在玩具車上，螢幕朝上、**手機長邊沿著車子前進方向**。
3. 看畫面：x 是短邊方向、y 是長邊方向、z 是垂直螢幕方向。車子前進時看 **y** 那條線（或 Absolute 絕對值）。
4. 設 Timed run 延遲 3 s、長度 10 s，按 ▶，倒數結束時放開車子。
5. 讀圖：加速時 y 往上凸，等速時回到 0 附近，煞車時往下凹。曲線下的「高度 × 時間」大約就是速度變化。
6. 想看數字：切到 **Raw Data** 分頁，或匯出 CSV。

### B.3.2　Acceleration with g：看自由落體

1. Raw Sensors → **Acceleration with g**。手機靜止平放時 z ≈ 9.8 m/s²（這就是重力）。
2. 把手機放進厚襪子或包毛巾，再放進有軟墊的箱子上方……**不要真的讓手機摔到地上**。最安全的做法：手拿著手機從床上 30 cm 高放手掉到厚棉被上。
3. 按 ▶，放手。看 Absolute 那條線：拿在手上時 9.8，放手的一瞬間掉到 **接近 0**（自由落體，失重），落到棉被時彈出一個大尖峰。
4. 接近 0 的那一段有多長，就是掉落時間。30 cm 約 0.25 s（2 × 0.3 ÷ 9.8 = 0.061，開根號 ≈ 0.25）。

### B.3.3　Acoustic Stopwatch：聲音碼表

1. Timers → **Acoustic Stopwatch**。
2. 畫面有 **Threshold（門檻）** 滑桿：聲音超過門檻就觸發。先按 ▶，拍手，看有沒有啟動；講話應該不會啟動。太敏感就調高門檻，拍手不觸發就調低。
3. 還有 **Minimum delay（最短間隔）**：兩次觸發之間最少隔多久，預設 0.1 s 左右。量回音（間隔很短）時把它調小；量兩次拍手（間隔幾秒）時可以調大一點避免雜音誤觸發。
4. 第一聲啟動、第二聲停止，畫面顯示間隔秒數。
5. 第 13 章專題二兩支手機的用法：兩支都開著等，拍手的人站在自己那支手機外側。

### B.3.4　Audio Autocorrelation：讀頻率

1. Acoustics → **Audio Autocorrelation**。按 ▶。
2. 對著麥克風彈橡皮筋、敲水杯、吹瓶口、或播放音叉聲。
3. 畫面上方直接顯示 **Frequency（頻率，Hz）**。聲音要持續至少半秒，太短讀不到。
4. 用 Tone generator 從另一支手機發 440 Hz 來檢查：這支應該讀到 440 左右。
5. 記錄時多讀幾次取平均，雜音大的時候數字會跳。

### B.3.5　Magnetometer：磁場

1. Raw Sensors → **Magnetometer**。
2. 靜止時會讀到地球磁場，台灣約 40–45 µT（Absolute）。
3. 把磁鐵慢慢靠近手機頂端（大部分手機的磁力計在機身上半部，不同手機位置不同，可以自己用磁鐵找），讀數會暴增到幾百、幾千 µT。
4. **注意**：強力磁鐵不要貼在手機上超過幾秒，也不要放在手機的相機旁邊。

### B.3.6　Inclination：傾角

1. Everyday → **Inclination**。
2. 顯示兩個角度：**Tilt up/down**（長邊和水平面的夾角）、**Tilt left/right**（短邊的）。
3. 手機平放桌上兩個都接近 0°；直立靠牆 Tilt up/down 是 90°。
4. 量斜坡角度：手機長邊沿著斜坡放，讀 Tilt up/down。
5. 量月亮高度角（第 12 章）：手機直立、頂端指向月亮，讀 Tilt up/down。

### B.3.7　Pendulum：擺

1. Mechanics → **Pendulum**。
2. 手機放進小袋子，用繩子綁住袋子吊起來，繩長從吊點量到手機中心。
3. 按 ▶（或用遠端），把手機拉開一個小角度（10° 以內）放手。
4. 畫面會自動算出 **Period（週期）** 和 **Frequency**。繩長 1.0 m 的週期約 2.0 s。

## B.4　慢動作錄影

### B.4.1　設定

**iPhone**
1. 設定 → 相機 → **錄製慢動作影片** → 選 **1080p 240 fps**（舊機型可能只有 120 fps）。
2. 打開相機，模式左右滑到 **慢動作**。
3. 錄影時畫面右上會顯示 240。

**Android（以常見品牌為例）**
- Samsung：相機 → 更多 → **超慢動作**（960 fps，只錄 0.4–0.8 秒）或 **慢動作**（240 fps）。本書用「慢動作」就夠，超慢動作時間太短很難抓。
- Google Pixel：相機 → 更多 → 慢動作，選 1/8（240 fps）。
- 其他品牌：找「慢動作」「Slow motion」「Slo-mo」，進去後通常可以選 120 或 240 fps。
- 如果不確定自己拍到的是幾 fps，用檔案的「詳細資訊」看，或拍一段碼表（手機 A 拍手機 B 的碼表），看影片裡碼表走 1 秒時影片過了幾秒。

### B.4.2　拍攝的七個規矩

1. **手機固定**：放在書堆上、用橡皮筋綁在杯子上、或用三腳架。手持的影片無法量距離。
2. **鏡頭正對運動平面**：拍彈珠滾斜坡就從側面平視，鏡頭和斜坡垂直。斜著拍會讓距離變形。
3. **畫面裡放尺**：一把 30 cm 尺放在**和運動物體同一個平面**（同一個距離）。尺放前面或後面都會讓比例錯掉。
4. **光要夠**：240 fps 每格只曝光 1/240 秒，室內燈太暗會糊。開大燈、靠窗、或用檯燈補光。日光燈可能會閃爍，看到畫面一明一暗是正常的。
5. **物體要對比**：白桌子上滾深色彈珠，或貼一小塊有色膠帶。
6. **留頭留尾**：按錄影後等 1 秒再放手，動作結束後再等 1 秒才停。
7. **一次只拍一件事**：影片短才好找格子。

### B.4.3　怎麼數格子

慢動作影片播放時是用 30 fps 播的，所以 240 fps 拍 1 秒的真實動作，播放會變成 8 秒。這是關鍵：**影片播放器顯示的時間 ÷ 8 = 真實時間**（120 fps 則 ÷ 4）。

**方法一：用播放器的時間軸（最簡單）**
1. iPhone：相簿打開影片，按「編輯」，下方會有時間軸和慢動作範圍的兩條直線；把兩條線拉到最兩端，讓整段都是慢動作，存檔。然後播放，慢慢拖曳進度條。
2. 找到彈珠在尺 0 cm 的那一刻，記下播放器時間 t₁（例如 3.2 s）；拖到 20 cm 的那一刻，記 t₂（例如 4.0 s）。
3. 播放時間差 0.8 s ÷ 8 = **真實時間 0.1 s**。速度 = 0.20 m ÷ 0.1 s = 2.0 m/s。
4. 進度條拖不準是最大的誤差來源，所以多做幾次。

**方法二：逐格 App（比較準）**
1. 搜尋免費的「frame by frame」「逐格播放」App，或把影片傳到電腦用 VLC（按 E 鍵可逐格）。
2. 逐格前進，數從 0 cm 到 20 cm 經過了 N 格。
3. 真實時間 = N ÷ 240。例如 24 格：24 ÷ 240 = 0.1 s。

**方法三：Tracker（電腦，最專業）**
1. 到 physlets.org/tracker 下載免費的 Tracker（Windows/Mac），把影片拖進去。
2. 先用「校正棒」在畫面的尺上標 0.30 m，再逐格點彈珠的位置。
3. 它會自動畫出位置—時間圖和速度—時間圖，還能匯出到試算表。第 2 章和第 13 章專題一用它最方便。

### B.4.4　算例

彈珠滾斜坡，240 fps。影片裡彈珠從尺的 10 cm 到 30 cm，逐格數了 32 格。

- 真實時間 = 32 ÷ 240 = 0.133 s
- 距離 = 0.20 m
- 平均速度 = 0.20 ÷ 0.133 = 1.5 m/s

接著從 30 cm 到 50 cm 數了 24 格：
- 時間 = 24 ÷ 240 = 0.100 s，速度 = 0.20 ÷ 0.100 = 2.0 m/s
- 加速度 ≈ (2.0 − 1.5) ÷ (兩段中點的時間差 ≈ (0.133 + 0.100) ÷ 2 = 0.117 s) ≈ 4.3 m/s²

## B.5　常見問題

| 狀況 | 原因 | 怎麼辦 |
|---|---|---|
| Phyphox 找不到某個實驗 | 那支手機沒有該感測器（例如 iPhone 沒有照度計、有些便宜手機沒陀螺儀） | 首頁灰色的實驗代表沒感測器；換一支手機或改用別的方法 |
| 加速度數據全是鋸齒雜訊 | 手機沒固定、或桌子在晃 | 用橡皮筋綁緊；離開洗衣機、冷氣 |
| 聲音碼表自己亂啟動 | 門檻太低、環境太吵 | 調高 Threshold；關窗；調大 Minimum delay |
| Audio Autocorrelation 讀數亂跳 | 聲音太短或有兩個音同時響 | 讓聲音持續；一次只響一個音 |
| 磁力計讀數一直偏 | 手機旁有磁鐵、喇叭、金屬桌 | 遠離 30 cm 以上；手機在空中畫 8 字校正 |
| 遠端網址打不開 | 不在同一個 Wi-Fi、或手機螢幕關了 | 確認同一個網路；把手機螢幕自動鎖定關掉 |
| 慢動作影片很暗、很糊 | 曝光時間太短 | 加燈；靠窗；改用 120 fps |
| 影片裡的尺和實際距離對不上 | 尺沒放在運動平面、或鏡頭斜拍 | 尺和物體放同一個距離；鏡頭正對 |
| 播放時間和真實時間不符 | 忘了除以 8（240 fps）或 4（120 fps） | 先拍碼表確認自己手機的倍率 |
