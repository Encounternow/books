# 第 4 章　重力、摩擦與壓力

## 本章目標
- 學完你會分辨「質量」與「重量」，並用 W = mg 算出任何東西受到的重力有幾牛頓。
- 學完你會說出自由落體的特性：不管輕重，落下時的加速度都差不多是 9.8 m/s²，也知道空氣阻力什麼時候會來攪局。
- 學完你會分辨靜摩擦與動摩擦，知道摩擦力跟什麼有關、跟什麼無關，並且親手量出鞋底的摩擦係數。
- 學完你會用 P = F/A 算壓力，解釋為什麼圖釘尖和高跟鞋的鞋跟那麼「厲害」。
- 學完你會用手機裡的加速度計，親眼看到「失重」的那一瞬間。

## 開場：體重計上的數字到底是什麼？

早上，小潔站上浴室的體重計，螢幕顯示 45 kg。阿公在旁邊說：「你要是到月球上，體重計大概只會顯示 7 點多，瘦超多。」小潔覺得奇怪：人還是同一個人，身上的肉一克也沒少，數字為什麼會變？

出門時下著雨，小潔穿拖鞋踩上濕濕的磁磚，「咻」地滑了一下，差點跌倒；換上運動鞋就穩穩的。同樣是地板、同樣是她，為什麼差這麼多？

到了學校，老師指著木地板上的一個個小凹洞說，那是以前有人穿細跟高跟鞋走過留下的。一個人才幾十公斤，大象幾千公斤踩過去都不會留洞，為什麼細細的鞋跟反而會？

這三個問題，分別藏著這一章的三個主角：重力、摩擦力、壓力。它們每天都在你身上作用，只是你還沒有用物理的眼睛看過它們。這一章看完，你會知道體重計到底在量什麼、鞋子為什麼會滑、還有為什麼「尖」的東西特別厲害。

## 核心概念

### 質量與重量：不是同一件事

先把兩個常常被混在一起的詞分開。

- **質量（Mass）**：東西「有多少料」。單位是公斤（kg）。你的質量在地球、在月球、在太空船裡都一樣，因為你的身體沒有變。
- **重量（Weight）**：地球「拉你的力」有多大。它是一種力，單位是牛頓（N）。到了月球，拉你的力變小，重量就變小。

這兩者之間有一條很簡單的公式：

> 重量 W ＝ 質量 m × 重力加速度 g　　（g ≈ 9.8 N/kg）

g 這個數字在地球表面大約是 9.8，意思是「每 1 公斤的東西，地球用 9.8 牛頓的力拉它」。

**算一個例子：** 小潔的質量是 45 kg，她的重量是 45 × 9.8 ＝ 441 N。到了月球，g 只剩大約 1.6 N/kg，重量變成 45 × 1.6 ＝ 72 N，但她的質量還是 45 kg。

一個很好用的口訣：**100 公克的東西，重量差不多是 1 牛頓**（精確一點是 0.98 N）。手上拿一顆蘋果，感受到的大概就是 1 N 左右。

| 東西 | 質量 | 重量（地球） |
|------|------|------|
| 1 元硬幣 | 3.8 g | 0.037 N |
| 手機 | 200 g | 1.96 N |
| 1 公升的水 | 1 kg | 9.8 N |
| 小潔 | 45 kg | 441 N |
| 一位大人 | 70 kg | 686 N |

那體重計在量什麼？其實體重計和廚房秤量的都是「你壓下去的力」，也就是重量，只是它偷偷幫你除以 9.8，把數字換算成公斤顯示給你看。所以到了月球，同一台體重計會被騙，顯示 45 × 1.6 ÷ 9.8 ≈ 7.3 kg。阿公說的「7 點多」就是這麼來的。

### 自由落體：重的和輕的誰先落地？

把一枚硬幣和一張攤平的紙從同樣高度放開，硬幣先落地。但把紙揉成一團再試一次，兩個幾乎同時落地！差別不在重量，而在**空氣阻力**：攤平的紙被空氣托住了。

如果把空氣拿掉，所有東西落下的方式都一模一樣：這叫**自由落體（Free Fall）**。它的加速度就是剛才那個 g，只是這次我們把單位寫成 9.8 m/s²，意思是**每過一秒，往下的速度就增加 9.8 m/s**。

| 落下時間 t | 速度 v ＝ g × t | 落下距離 d ＝ ½ × g × t² |
|------|------|------|
| 0.1 s | 0.98 m/s | 0.049 m（約 5 cm） |
| 0.2 s | 1.96 m/s | 0.196 m（約 20 cm） |
| 0.3 s | 2.94 m/s | 0.441 m |
| 0.4 s | 3.92 m/s | 0.784 m |
| 0.5 s | 4.9 m/s | 1.225 m |
| 1.0 s | 9.8 m/s | 4.9 m |

**算一個例子：** 0.3 秒時，距離是 ½ × 9.8 × 0.3 × 0.3 ＝ ½ × 9.8 × 0.09 ＝ 0.441 m。你也可以反過來查表：東西從 1 公尺高的桌子掉到地上，落下距離 1 m 介於 0.784 m 和 1.225 m 之間，所以時間大約是 0.45 秒（0.45 × 0.45 × 4.9 ≈ 0.99 m）。一眨眼就到了，難怪杯子掉下去來不及接。

空氣阻力會隨速度變大。雨滴從幾百公尺高的雲掉下來，照理說應該快得像子彈，但它掉到某個速度之後，空氣阻力就和重力一樣大，不再加速，這個速度叫**終端速度（Terminal Velocity）**。降落傘就是故意把空氣阻力做得很大，讓終端速度小到人可以安全落地。

### 摩擦力：讓你走得動，也讓你停得住

兩個表面互相接觸、想要相對滑動時，會出現一個反抗滑動的力，叫**摩擦力（Friction）**。它有兩種：

- **靜摩擦力（Static Friction）**：東西還沒動的時候。你推一個大紙箱，一開始推不動，是靜摩擦力撐住它。你越用力，它也跟著變大，直到某個極限（最大靜摩擦力）就撐不住了。
- **動摩擦力（Kinetic Friction）**：東西已經在滑的時候。通常**比最大靜摩擦力小一點**，所以紙箱一旦推動了，反而比較輕鬆。

```
        推力 F →   ┌────────┐
                   │  紙箱   │   ← 摩擦力 f（方向永遠跟滑動方向相反）
   ─────────────┴────────┴─────────── 地板
                      ↓ 重量 W
                      ↑ 正向力 N（地板把紙箱托住的力，平地上 N ＝ W）
```

摩擦力的大小跟什麼有關？

1. **正向力 N**：兩個面被壓得越緊，摩擦越大。箱子裡裝越多東西，越難推。
2. **材質**：橡膠對地板很黏，冰對冰很滑。

跟什麼**無關**？這點很多人會嚇一跳：**跟接觸面積幾乎無關**。一本書平放著推和立著推，需要的力差不多。

我們用一個數字來形容「兩種材質有多黏」，叫**摩擦係數（Coefficient of Friction）**，記作 μ（念「mu」）：

> 摩擦係數 μ ＝ 摩擦力 f ÷ 正向力 N

**算一個例子：** 一隻 300 g 的運動鞋放在木地板上，正向力 N ＝ 0.3 × 9.8 ＝ 2.94 N。用彈簧秤慢慢拉，剛要滑動前讀到 2.0 N，所以靜摩擦係數 μ ＝ 2.0 ÷ 2.94 ≈ 0.68。滑動中讀到 1.5 N，動摩擦係數 ≈ 0.51。

| 兩種材質 | 摩擦係數大約是 |
|------|------|
| 橡膠鞋底／乾地板 | 0.6～1.0 |
| 橡膠鞋底／濕磁磚 | 0.2～0.4 |
| 木頭／木頭 | 0.3～0.5 |
| 冰刀／冰 | 0.03～0.1 |

小潔的拖鞋底是硬塑膠，碰到濕磁磚摩擦係數可能掉到 0.2 以下，所以會滑。

### 壓力：同樣的力，分給多大的面積

同樣用 5 N 的力去壓，用手掌壓桌子沒感覺，用圖釘尖壓桌子會戳出一個洞。力一樣，差別在**面積**。

> 壓力 P ＝ 力 F ÷ 面積 A

單位是帕斯卡（Pascal），記作 Pa，1 Pa ＝ 1 N/m²（每平方公尺 1 牛頓）。因為 1 Pa 很小，常用 kPa（1 kPa ＝ 1000 Pa）。

要特別小心的是面積的單位：公式裡要用**平方公尺**。1 m ＝ 100 cm，所以 1 m² ＝ 100 × 100 ＝ 10000 cm²，反過來 1 cm² ＝ 0.0001 m²。

**算一個例子：** 一本 1 kg 的書（重量 9.8 N）平放，底面 20 cm × 15 cm ＝ 300 cm² ＝ 0.03 m²，壓力 ＝ 9.8 ÷ 0.03 ≈ 327 Pa。把書立起來，底面只剩 20 cm × 2 cm ＝ 40 cm² ＝ 0.004 m²，壓力 ＝ 9.8 ÷ 0.004 ＝ 2450 Pa，是平放的 7.5 倍。

**再算一個：** 小潔（441 N）雙腳站立，兩隻腳底加起來約 300 cm² ＝ 0.03 m²，壓力 ＝ 441 ÷ 0.03 ＝ 14700 Pa。如果她穿細跟高跟鞋，重心落在一個 1 cm²（0.0001 m²）的鞋跟上，壓力 ＝ 441 ÷ 0.0001 ＝ 4410000 Pa，整整 300 倍。大象有 5000 kg（49000 N），四隻腳底共約 6000 cm² ＝ 0.6 m²，壓力只有 49000 ÷ 0.6 ≈ 81700 Pa。所以高跟鞋踩得出洞、大象踩不出來，老師那題解開了。

人類很懂得利用壓力：刀子磨得薄是為了讓壓力變大、好切；雪鞋做得寬大是為了讓壓力變小、不陷進雪裡；坦克用履帶、卡車用很多輪子，都是把力分散到大面積上保護地面。

## 動手做

### 實驗 4-1：量鞋底的摩擦力

**材料／工具**
- 2～3 雙鞋底材質不同的鞋（運動鞋、拖鞋、雨鞋或皮鞋）
- 彈簧秤（文具店或網路可買到 5 N 或 10 N 的款式），或第 3 章做的橡皮筋拉力計
- 細繩約 50 cm
- 廚房秤
- 一瓶 500 mL 的水（加重用）
- 平坦的桌面或地板（木地板、磁磚、地毯各試一種更好）
- 抹布、紙筆

**步驟**
1. 把鞋放上廚房秤，記下質量（g）。換算成重量：g ÷ 1000 × 9.8 ＝ N。這就是鞋子放在平面上時的正向力。
2. 用細繩繞過鞋子靠近鞋底的地方綁好，繩子另一端勾上彈簧秤。繩子要盡量和桌面平行，不要往上提。
3. **非常慢**地拉彈簧秤，眼睛盯著指針。鞋子剛要動的那一瞬間，指針到達的最大值就是「最大靜摩擦力」。記下來。
4. 繼續拉，讓鞋子用很慢、很穩定的速度滑動，這時的讀數就是「動摩擦力」。記下來。
5. 步驟 3、4 各重複 3 次，取平均。
6. 把水瓶放進鞋子裡，再做一次。正向力變成（鞋子＋水）的重量。
7. 換另一雙鞋、換另一種地面，重複以上步驟。如果要試「濕磁磚」，用抹布沾一點水抹在磁磚上就好，做完馬上擦乾。
8. 算摩擦係數：μ ＝ 摩擦力 ÷ 正向力。

**你應該看到／得到**
- 每次最大靜摩擦力都比動摩擦力大一點。
- 加了水瓶之後，摩擦力明顯變大，但算出來的 μ 差不多一樣。這證明摩擦力跟正向力成正比，而 μ 是材質的特性。
- 拖鞋在濕磁磚上的 μ 會小得多，這就是會滑倒的原因。

**觀察與記錄**

| 鞋子 | 地面 | 質量 (g) | 正向力 N (N) | 最大靜摩擦 (N) | 動摩擦 (N) | μ靜 | μ動 |
|------|------|------|------|------|------|------|------|
| 運動鞋 | 木地板 | | | | | | |
| 運動鞋＋水瓶 | 木地板 | | | | | | |
| 拖鞋 | 乾磁磚 | | | | | | |
| 拖鞋 | 濕磁磚 | | | | | | |
| | | | | | | | |

**安全提醒**：不要讓彈簧秤超過它的最大刻度，彈簧會壞掉。濕磁磚做完一定要立刻擦乾，自己也不要踩上去。繩子只能用來拉鞋子，不要繞在手指或脖子上。

### 實驗 4-2：用 Phyphox 看自由落體

**材料／工具**
- 裝好 Phyphox 的手機
- 厚棉被或床墊（落點）
- 一隻厚襪子（包住手機當緩衝）
- 尺或捲尺

**步驟**
1. 打開 Phyphox，選「加速度（含重力）」（Acceleration with g）。畫面上有 x、y、z 三個方向的圖和一個「絕對值」（Absolute）圖。
2. 把手機平放在桌上，按右上角的 ▶ 開始。你會看到 z 大約是 9.8，x 和 y 接近 0，絕對值接近 9.8。這就是手機「感覺到」的重力。
3. 把手機慢慢傾斜、立起來、翻面。三個方向的數字會互相轉移，但絕對值一直都在 9.8 附近。按 ⏸ 暫停。
4. 把手機塞進厚襪子裡。量好高度，把手機拿到床墊上方 30 cm 的位置。
5. 按 ▶，數三秒，**放手讓它掉**（不要往下丟）。掉到床上後按 ⏸。
6. 看絕對值的圖。放手前是 9.8；手機在空中的那一小段，數字會掉到幾乎 0；撞到床墊時會出現一根很高的尖峰；最後回到 9.8。
7. 用兩指在圖上放大，看「接近 0 的那一段」持續了多久，跟核心概念裡的表格比較：30 cm 大約要 0.25 秒（0.25 × 0.25 × 4.9 ≈ 0.31 m）。
8. 換 50 cm 再做一次（表格預測約 0.32 秒）。

**你應該看到／得到**
- 手機靜止時讀 9.8，不是 0。因為桌子（或你的手）在托著它，加速度計其實是在量「托住它的力」。
- 掉落的途中讀數接近 0：這就是**失重（Weightlessness）**。不是重力消失了，而是沒有東西托著它。太空人在太空站裡飄，也是同樣的狀態：他們一直在「掉」。
- 掉的時間跟表格相近，但通常會差一點點，因為你很難剛好在放手那一刻按下按鈕，而且襪子會增加一點空氣阻力。

**觀察與記錄**

| 高度 (cm) | 表格預測的落下時間 (s) | 圖上讀數接近 0 的時間 (s) | 撞擊時的最大讀數 (m/s²) |
|------|------|------|------|
| 30 | 約 0.25 | | |
| 50 | 約 0.32 | | |

**安全提醒**：手機一定要落在厚軟的棉被或床墊上，高度不要超過 50 cm，而且一定要先得到手機主人的同意。螢幕已經有裂痕的手機只做步驟 1～3 就好，不要丟。做這個實驗時旁邊不要有人，避免手機彈起來打到人。

### 實驗 4-3：躺在釘床上的氣球

**材料／工具**
- 圖釘 50～100 枚
- 厚紙板或瓦楞紙一塊（約 15 cm × 15 cm），或一片保麗龍板
- 氣球 2 顆
- 一本書（約 500 g）
- 護目鏡（氣球爆掉時碎片會噴）

**步驟**
1. 吹好兩顆差不多大的氣球，打結。
2. 先在桌上放**一枚**圖釘（尖端朝上），把氣球放上去，用手指輕輕往下壓。氣球應該一下就破了。這一步請戴護目鏡，而且臉不要靠太近。
3. 把圖釘一枚一枚插進紙板，尖端朝上，排成一格一格、間隔約 1 cm 的方陣，至少 50 枚。做出一張「釘床」。
4. 把第二顆氣球輕輕放在釘床上，不要壓。
5. 把書平放在氣球上面，再用手慢慢往下壓一點。氣球不會破。
6. 算一算：書的重量約 500 g → 4.9 N。如果氣球和 50 枚圖釘接觸，每枚圖釘只分到 4.9 ÷ 50 ≈ 0.1 N。而步驟 2 時，整個力都壓在一枚圖釘上。

**你應該看到／得到**
- 一枚圖釘：力集中在很小的面積上，壓力極大，氣球破。
- 五十枚圖釘：同樣的力分散到 50 個尖端，每個尖端的壓力只有原來的 1/50，氣球撐得住。印度苦行僧「躺釘床」用的是同一個原理。

**觀察與記錄**

| 圖釘數量 | 壓上去的東西 | 估計壓的力 (N) | 每枚圖釘分到的力 (N) | 破了嗎？ |
|------|------|------|------|------|
| 1 | 手指輕壓 | | | |
| 50 | 一本書 | | | |
| 50 | 書＋手壓 | | | |

**安全提醒**：圖釘很尖，插的時候請大人在旁邊，插完一枚就數一枚，做完要全部拔下來收回盒子裡，掉在地上的一定要找到。氣球爆開時碎片可能噴到眼睛，壓氣球的人戴護目鏡，其他人離遠一點。

## 用儀器看看

**1. 廚房秤其實在量「力」**

把一個碗放上廚房秤，按歸零（TARE）。用一根手指往碗裡輕輕壓，螢幕可能顯示 200 g。碗沒有變重，是你用手指「壓」了它，壓的力就是 0.2 × 9.8 ≈ 1.96 N。廚房秤把力換成公克顯示給你看。接著用兩根手指壓，試著讓數字停在 500 g，感受一下 4.9 N 是多大的力。這個感覺以後很有用：你會知道「5 N」大概是多少。

**2. 把 Phyphox 的資料匯出到試算表**

做完實驗 4-2 後，在 Phyphox 畫面右上角按「⋮」→「匯出資料」（Export Data）→ 選「CSV」或「Excel」，用 LINE 或 AirDrop 傳到電腦，再用 Google 試算表或 Excel 開啟。你會看到一個表，第一欄是時間（秒），後面幾欄是 x、y、z 和絕對值。

在試算表裡：
1. 找到「絕對值」那一欄（Absolute）。
2. 往下捲，找出第一列數值小於 1 的時間 t₁，和撞擊尖峰出現前最後一列數值小於 1 的時間 t₂。
3. 在空白格輸入 `=t₂ 那格 - t₁ 那格`，就是落下時間。
4. 再輸入 `=0.5*9.8*(落下時間那格)^2`，算出手機「應該」落下的距離，跟你用尺量的高度比一比。

**3. 用試算表算摩擦係數**

把實驗 4-1 的資料打進試算表：A 欄鞋子、B 欄質量 (g)、C 欄最大靜摩擦 (N)、D 欄動摩擦 (N)。在 E2 輸入 `=B2/1000*9.8` 算正向力，F2 輸入 `=C2/E2` 算 μ靜，G2 輸入 `=D2/E2` 算 μ動，往下拉填滿。選取 A 欄和 F 欄，插入「長條圖」，哪雙鞋最防滑一眼就看出來。

## 常見錯誤與迷思

- **「重的東西掉得比較快。」** → 掉得快慢主要看空氣阻力，不看重量。把紙揉成團後，它和硬幣幾乎同時落地；在沒有空氣的月球上，鐵鎚和羽毛真的會同時落地（太空人做過這個實驗）。→ 正確理解：自由落體的加速度對所有物體都是 g，空氣阻力才是讓輕飄飄的東西變慢的原因。
- **「體重計量的是質量。」** → 體重計是用彈簧或感測器量你「壓下去的力」，也就是重量，然後除以 9.8 顯示成公斤。到了月球它會顯示錯的數字。→ 正確理解：質量不會變，重量會隨 g 改變；體重計量的是重量，再換算成質量給你看。
- **「接觸面積越大，摩擦力越大。」** → 把書平放和立起來推，需要的力幾乎一樣。面積大了，每一點被壓的程度就小了，兩相抵消。→ 正確理解：摩擦力只跟正向力和材質有關。賽車用寬輪胎是為了散熱和耐磨，不是為了增加摩擦係數。
- **「摩擦力都是壞事。」** → 沒有摩擦力你連站都站不穩，走路、拿筆、煞車全都靠它。→ 正確理解：摩擦力有時要減少（加潤滑油），有時要增加（輪胎刻花紋）。
- **「壓力和力是同一件事。」** → 同樣 5 N，用手掌壓沒事，用圖釘尖壓會戳洞。→ 正確理解：壓力是力除以面積，面積越小壓力越大。
- **「自由落體的時候沒有重力。」** → 重力還在，不然手機怎麼會往下掉？→ 正確理解：失重是「沒有東西托住你」的感覺，重力本身一直都在。

## 想一想

1. 一位 60 kg 的大人，在地球上的重量是多少牛頓？在月球上（g ≈ 1.6 N/kg）呢？

<details><summary>參考答案</summary>

地球：60 × 9.8 ＝ 588 N。月球：60 × 1.6 ＝ 96 N。質量在兩個地方都是 60 kg。

</details>

2. 一顆彈珠從 20 cm 高的桌邊掉下來，大約要幾秒落地？請查核心概念裡的表格。

<details><summary>參考答案</summary>

表格中 0.2 秒對應 0.196 m，差不多就是 20 cm，所以大約 0.2 秒。

</details>

3. 一個 10 kg 的紙箱放在地板上，靜摩擦係數 0.4，動摩擦係數 0.3。要用多大的力才推得動？推動之後要用多大的力才能讓它等速滑行？

<details><summary>參考答案</summary>

正向力 N ＝ 10 × 9.8 ＝ 98 N。推動它至少要克服最大靜摩擦力：0.4 × 98 ＝ 39.2 N。推動之後，等速滑行只要抵消動摩擦力：0.3 × 98 ＝ 29.4 N。所以「一開始最難推」是真的。

</details>

4. 一個 5 kg 的書包（重量 49 N）。背帶 A 是兩條寬 3 cm、和肩膀接觸長 20 cm 的帶子；背帶 B 只有一條寬 1 cm、長 20 cm 的細帶子。請算兩種背帶壓在肩膀上的壓力，哪一種比較痛？

<details><summary>參考答案</summary>

背帶 A 面積：3 × 20 × 2 條 ＝ 120 cm² ＝ 0.012 m²，壓力 ＝ 49 ÷ 0.012 ≈ 4083 Pa。背帶 B 面積：1 × 20 ＝ 20 cm² ＝ 0.002 m²，壓力 ＝ 49 ÷ 0.002 ＝ 24500 Pa。B 的壓力是 A 的 6 倍，所以細帶子勒肩膀會很痛。寬背帶就是為了降低壓力。

</details>

5. （開放挑戰）跳傘的人打開降落傘之後，會以固定的速度慢慢落下。請畫出這時候他受到的力（重力和空氣阻力），說明為什麼速度不再增加。如果降落傘更大，終端速度會變大還是變小？

<details><summary>參考答案</summary>

打開降落傘後，往上的空氣阻力增加到和往下的重力一樣大，兩個力互相抵消，合力為零，根據第 3 章的牛頓第一定律，速度就不再改變。降落傘越大，空氣阻力越容易「追上」重力，在更低的速度就達到平衡，所以終端速度變小、落地更安全。

</details>

6. （開放挑戰）請設計一雙「不會在濕磁磚上滑倒」的拖鞋。從材質、鞋底花紋、面積三個角度想一想，哪些會有效、哪些其實沒用？用這一章學到的理由說明。

<details><summary>參考答案</summary>

有效的：換成軟橡膠鞋底（提高摩擦係數）、鞋底刻深溝紋把水排開（讓橡膠真的碰到磁磚而不是碰到水膜，等於恢復乾地板的摩擦係數）。沒什麼用的：單純把鞋底做大（摩擦力和接觸面積幾乎無關）。另外可以提醒：濕地板的摩擦係數是乾地板的三分之一左右，所以走路步伐放小、腳放平，讓需要的摩擦力變小，也是一種辦法。

</details>

## 本章小結

- 質量是「有多少料」，單位 kg，到哪裡都一樣；重量是地球拉你的力，單位 N，W ＝ mg，g ≈ 9.8 N/kg。
- 100 g 的東西重量約 1 N；體重計量的是重量，再換算成公斤顯示。
- 自由落體的加速度是 9.8 m/s²，跟輕重無關；空氣阻力才是讓羽毛慢下來的原因，阻力和重力平衡時就達到終端速度。
- 摩擦力分靜摩擦與動摩擦，最大靜摩擦略大於動摩擦；摩擦力 ＝ μ × 正向力，和接觸面積幾乎無關。
- 壓力 P ＝ F ÷ A，單位 Pa ＝ N/m²，算的時候面積要換成平方公尺（1 cm² ＝ 0.0001 m²）。
- 面積越小壓力越大：圖釘、刀刃、高跟鞋都是；雪鞋、履帶、寬背帶則是反過來把壓力變小。
- 手機加速度計靜止時讀 9.8，自由落下時讀 0，這就是失重：重力還在，只是沒東西托著你。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|------|------|------|
| 質量 | Mass | 物體含有多少物質，單位 kg，到哪裡都不變。 |
| 重量 | Weight | 地球（或其他星球）拉物體的力，W ＝ mg，單位 N。 |
| 重力加速度 | Gravitational Acceleration (g) | 地表約 9.8 m/s²，也可寫成 9.8 N/kg。 |
| 自由落體 | Free Fall | 只受重力、不受空氣阻力的落下運動。 |
| 終端速度 | Terminal Velocity | 空氣阻力和重力平衡後，物體不再加速的固定速度。 |
| 靜摩擦力 | Static Friction | 物體還沒滑動時，阻止它開始滑動的力。 |
| 動摩擦力 | Kinetic Friction | 物體滑動中，阻礙它繼續滑動的力。 |
| 正向力 | Normal Force | 接觸面垂直頂住物體的力，平地上等於重量。 |
| 摩擦係數 | Coefficient of Friction (μ) | 摩擦力除以正向力，代表兩種材質有多「黏」。 |
| 壓力 | Pressure | 力除以受力面積，P ＝ F/A。 |
| 帕斯卡 | Pascal (Pa) | 壓力的單位，1 Pa ＝ 1 N/m²。 |
| 失重 | Weightlessness | 沒有支撐力時的狀態，自由落體中就會發生。 |
