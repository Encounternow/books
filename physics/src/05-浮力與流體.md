# 第 5 章　浮力與流體

## 本章目標
- 學完你會用「密度 ＝ 質量 ÷ 體積」判斷一樣東西放進水裡會沉還是浮。
- 學完你會說出阿基米德原理：浮力等於被排開的液體重，並用它算出浮力有幾牛頓。
- 學完你會解釋為什麼幾萬噸的鐵船浮得起來、為什麼潛水艇可以自由上下。
- 學完你會知道大氣壓力有多大、水壓怎麼隨深度變化，以及吸管到底是怎麼把飲料「吸」上來的。
- 學完你會親手做出密度柱和沉浮子，並用廚房秤直接「看到」浮力。

## 開場：泡澡的時候，水為什麼會滿出來？

阿哲最討厭放洗澡水放太滿，因為每次一坐進浴缸，水就嘩啦嘩啦溢出來。他媽媽在門外喊：「你排開多少水，水就會多出多少！」阿哲心想：排開的水和我有什麼關係？

但他發現一件更奇怪的事：坐在水裡的時候，身體變得好輕，抬腿一點都不費力；手撐住浴缸邊緣站起來，一離開水面馬上又變重了。那個「變輕的感覺」是哪裡來的？

兩千多年前，希臘的阿基米德也是在泡澡時想到這件事。他要替國王檢查金冠有沒有摻銀，想了很久想不出來，坐進浴缸看到水溢出來的那一刻突然大叫「Eureka！（我找到了！）」，據說還光著身子跑上街。他發現的東西，就是這一章的主角：**浮力**。

泡澡、游泳、船、熱氣球、吸管、倒過來不會漏的水杯，全都跟同一組概念有關：密度、浮力和壓力。這一章我們一樣一樣拆開來看。

## 核心概念

### 密度：同樣大小，誰比較「紮實」

一塊鐵和一塊同樣大小的木頭，鐵重很多。我們說鐵的**密度（Density）**比較大。

> 密度 ρ ＝ 質量 m ÷ 體積 V

ρ 念「rho」。國中最常用的單位是 g/cm³（每立方公分幾公克）。水的密度剛好是 1 g/cm³，也就是 1 cm³ 的水重 1 g，1 公升（1000 cm³）的水剛好 1 kg，非常好記。

**算一個例子：** 一塊木頭長 10 cm、寬 5 cm、高 4 cm，體積 ＝ 10 × 5 × 4 ＝ 200 cm³。放上廚房秤量到 120 g。密度 ＝ 120 ÷ 200 ＝ 0.6 g/cm³。

| 物質 | 密度（g/cm³） | 放進水裡 |
|------|------|------|
| 保麗龍 | 約 0.02 | 浮 |
| 軟木塞 | 約 0.24 | 浮 |
| 75% 藥用酒精 | 約 0.86 | （液體）浮在水上 |
| 冰 | 0.92 | 浮 |
| 食用油 | 約 0.92 | （液體）浮在水上 |
| 水 | 1.00 | — |
| 洗碗精 | 約 1.05 | （液體）沉在水下 |
| 葡萄 | 約 1.1 | 沉 |
| 蜂蜜 | 約 1.4 | （液體）沉到最底 |
| 鋁 | 2.7 | 沉 |
| 鐵 | 7.9 | 沉 |

看出規律了嗎？**密度比水大的沉，比水小的浮。** 液體也一樣：密度小的液體會浮在密度大的液體上面，這就是等一下要做的密度柱。

### 浮力：水往上托你的力

把東西放進水裡，水會從四面八方壓它。但越深的地方水壓越大，所以**從底下往上壓的力，比從上面往下壓的力大**，兩者相減，剩下一個往上的力，這就是**浮力（Buoyancy）**。

```
          ↓ 上面的水壓（小）
      ┌─────────┐
      │  物體    │  ← 兩側的壓力互相抵消
      └─────────┘
          ↑ 下面的水壓（大）
      合起來 ＝ 往上的浮力
```

浮力到底有多大？阿基米德在浴缸裡發現的答案簡單得驚人：

> 浮力 ＝ 被物體排開的液體的重量

這叫**阿基米德原理（Archimedes' Principle）**。你的身體泡進水裡，擠走了多少水，那些水有多重，浮力就有多大。

**算一個例子：** 一個 100 cm³ 的鐵塊整個沉進水裡，它擠走了 100 cm³ 的水，這些水的質量是 100 g，重量是 0.1 × 9.8 ＝ 0.98 N。所以鐵塊受到的浮力是 0.98 N。鐵塊本身重 790 g（7.74 N），浮力遠遠托不住它，所以它沉下去，但在水裡拿它會覺得輕了 0.98 N，只剩 6.76 N。

**再算一個：** 剛才那塊 200 cm³、120 g 的木頭（重量 1.18 N）放進水裡。如果整塊壓進水中，浮力是 200 g 的水重 ＝ 1.96 N，比木頭的重量大，所以它會往上浮。浮到水面後，它只需要「剛剛好」的浮力：排開 120 g 的水就夠了，也就是 120 cm³ 泡在水下，剩下 80 cm³ 露出水面。120 ÷ 200 ＝ 60%，你會發現：**浮在水面的東西，泡在水下的比例剛好等於它的密度除以水的密度。** 冰的密度 0.92，所以冰山有 92% 在水面下。

### 為什麼鐵船浮得起來？

鐵的密度 7.9，一塊鐵丟進水裡一定沉。但一艘 10000 噸的鐵船浮得好好的，為什麼？

因為船不是「一塊鐵」，它是「一層薄薄的鐵殼包著一大團空氣」。船泡進水裡的部分，排開的水只要有 10000 噸，浮力就有 10000 噸重，剛好撐住整艘船。重點是**整艘船（連裡面的空氣算在一起）的平均密度比水小**。把同一艘船壓扁成鐵塊，裡面的空氣沒了，它就沉了。

潛水艇反過來利用這一點：它的船殼裡有「壓載水艙」，想下潛就讓海水灌進去（平均密度變大），想上浮就用壓縮空氣把水排出去（平均密度變小）。魚的魚鰾也是同樣的道理。這一章的沉浮子實驗，就是一台手動潛水艇。

### 大氣壓力：我們活在空氣的海底

空氣也是流體，它也有重量。你頭上頂著幾十公里厚的空氣，它們壓下來的壓力叫**大氣壓力（Atmospheric Pressure）**，在海平面大約是 101300 Pa，也寫成 101.3 kPa 或 1013 hPa（百帕，氣象報告用這個）。

這有多大？用第 4 章的公式反推：1 cm² ＝ 0.0001 m²，所以每平方公分受到的力是 101300 × 0.0001 ≈ 10 N，**大約等於 1 公斤重的東西壓在每一平方公分上**。你的手掌約 100 cm²，上面壓著大約 1000 N，相當於 100 公斤！一張 A4 紙（約 624 cm²）上面壓著 6300 N 左右。

那我們為什麼沒被壓扁？因為空氣不只從上面壓，它從四面八方壓，而且你身體裡面也有同樣的壓力往外頂，裡外抵消。只要有辦法讓某一邊的壓力變小，大氣壓力就會露出它的威力：吸管就是這樣。你用嘴巴把吸管裡的空氣吸掉，吸管裡的壓力變小，外面的大氣壓力就把飲料**推**上來。不是你「吸」上來的，是空氣推上來的。

水壓也是同樣的道理，而且水比空氣重得多：

> 水壓 ＝ 水的密度 × g × 深度 ＝ 1000 kg/m³ × 9.8 × h

**算一個例子：** 游泳池底 2 m 深，水壓 ＝ 1000 × 9.8 × 2 ＝ 19600 Pa。每往下 10 m 就多一個大氣壓力（98000 Pa），所以潛水員在 10 m 深的地方，承受的總壓力是海面的兩倍。潛到深海要用很厚的潛水艇，就是這個原因。

### 伯努利的直覺：流得快的地方，壓力小

最後一個概念不需要公式，只需要一個直覺：**流體流得越快的地方，壓力越小**。這叫**伯努利原理（Bernoulli's Principle）**。

拿一張紙條放在下嘴唇下方，往紙條上方吹氣，紙條會往上飄起來。因為紙條上方的空氣流得快、壓力小，下方的空氣壓力沒變，就把紙推上去了。飛機的機翼、棒球的曲球、洗澡時浴簾往你身上貼，都和這個直覺有關。

## 動手做

### 實驗 5-1：自製密度柱

**材料／工具**
- 一個透明、細長的玻璃杯或量杯（高一點效果好）
- 蜂蜜（或玉米糖漿、黑糖漿）
- 洗碗精
- 水，加幾滴食用色素或水彩（方便看）
- 食用油
- 75% 藥用酒精（選用，要有大人在）
- 廚房秤、量杯（量每種液體的密度用）
- 小東西：硬幣、葡萄或小番茄、冰塊、軟木塞或保麗龍小球、塑膠瓶蓋
- 湯匙、抹布

**步驟**
1. 先量密度。把量杯放上廚房秤，按歸零，倒 100 mL 的蜂蜜，讀出公克數，除以 100 就是密度（g/cm³，因為 1 mL ＝ 1 cm³）。倒回瓶子、洗乾淨，依序量洗碗精、水、油、酒精。把結果填進表格，先**預測**它們由下到上的順序。
2. 把杯子放在抹布上。先倒蜂蜜到大約 3 cm 高，倒在正中間，不要碰到杯壁。
3. 倒洗碗精：把湯匙背面貼著杯壁，讓洗碗精順著湯匙慢慢流下去，這樣才不會衝進蜂蜜裡。一樣倒 3 cm 高。
4. 同樣用湯匙，依序慢慢倒入有顏色的水、食用油、酒精。每一層都要慢，倒完等 30 秒再倒下一層。
5. 看看分層順序和你的預測一不一樣。
6. 一樣一樣把小東西輕輕放進去，看它停在哪一層。放之前先猜。

**你應該看到／得到**
- 由下到上：蜂蜜、洗碗精、水、油、酒精，密度大的在下、小的在上。
- 硬幣沉到最底；葡萄會穿過水，停在洗碗精或蜂蜜的上面；冰塊會穿過油層，浮在水的表面（冰的密度 0.92，剛好和油差不多，它可能卡在油水交界）；軟木塞或保麗龍浮在最上面。
- 每個東西都停在「上面那層比它輕、下面那層比它重」的地方。

**觀察與記錄**

| 液體 | 100 mL 的質量 (g) | 密度 (g/cm³) | 預測的層次（由下往上） | 實際的層次 |
|------|------|------|------|------|
| 蜂蜜 | | | | |
| 洗碗精 | | | | |
| 水 | | | | |
| 食用油 | | | | |
| 酒精 | | | | |

| 小東西 | 猜它停在哪 | 實際停在哪 | 推算它的密度大約是 |
|------|------|------|------|
| 硬幣 | | | |
| 葡萄 | | | |
| 冰塊 | | | |
| 塑膠瓶蓋 | | | |
| 軟木塞 | | | |

**安全提醒**：藥用酒精會燃燒，離瓦斯爐和任何火源遠一點，用完蓋緊，由大人倒；做完的液體不能喝，直接倒掉並洗手。玻璃杯放穩，桌上鋪抹布防滑。

### 實驗 5-2：沉浮子（手動潛水艇）

**材料／工具**
- 1.5 L 或 2 L 的透明寶特瓶（含瓶蓋）
- 一個「沉浮子」：便當附的魚形醬油瓶最好用；沒有的話，用一段 4 cm 的吸管對折，用迴紋針夾住開口端當配重
- 水、一個大碗
- 迴紋針或少許黏土（調整重量用）

**步驟**
1. 先在大碗裡調整沉浮子。魚形醬油瓶：擠進一些水，放進碗裡，要讓它**剛剛好浮著**，只有一點點露出水面。太浮就多吸一點水，太沉就擠掉一點水。吸管版：夾迴紋針調整，一樣調到剛好浮。
2. 把寶特瓶裝水，裝到滿到瓶口。
3. 把沉浮子放進瓶子（開口朝下），把瓶蓋鎖緊，不要留空氣。
4. 用雙手捏瓶身。沉浮子會往下沉。放手，它會浮回來。
5. 練習控制捏的力道，讓沉浮子停在瓶子正中間不動。
6. 仔細看沉浮子裡面：捏瓶子的時候，裡面的水位是不是上升了？

**你應該看到／得到**
- 捏瓶子，沉浮子下沉；放開，上浮。捏得剛好，它會懸浮在中間。
- 捏的時候，沉浮子裡的空氣被壓小，水跑進去更多。空氣變小 → 排開的水變少 → 浮力變小 → 浮力小於重量 → 下沉。放手後空氣彈回原來大小，浮力又變大，就浮上來。
- 關鍵在於：**水幾乎壓不縮，但空氣可以**。你捏瓶子的壓力透過水傳到沉浮子裡，把裡面的空氣壓小了。

**觀察與記錄**

| 捏的力道 | 沉浮子的動作 | 沉浮子裡的水位（高／中／低） |
|------|------|------|
| 不捏 | | |
| 輕捏 | | |
| 用力捏 | | |
| 用力捏之後放開 | | |

**安全提醒**：寶特瓶裝滿水後很重，放在桌上做，不要舉高。瓶蓋一定要鎖緊，否則捏的時候水會噴出來。小的沉浮子和迴紋針不要讓幼兒拿到。

### 實驗 5-3：倒過來不會漏的水杯

**材料／工具**
- 一個杯口平整的玻璃杯或塑膠杯
- 一張比杯口大的厚紙片（明信片、厚一點的卡片）
- 水、水槽或臉盆
- 加碼用：一張紙條（約 3 cm × 15 cm）、兩個空鋁罐、兩根吸管

**步驟**
1. 在水槽上方把杯子裝滿水，滿到快溢出來。
2. 把紙片蓋在杯口，用手掌壓住，確定紙片和杯口之間沒有縫。
3. 一手壓著紙片，一手拿杯子，快速把整個杯子翻過來，杯口朝下。
4. 深呼吸，慢慢把壓紙片的手移開。紙片會貼著杯口，水不會掉下來。
5. 再做一次，但這次只裝半杯水。你會發現還是可以！
6. 加碼：拿紙條放在下嘴唇下，往紙條上方吹氣，看紙條往哪動。再把兩個鋁罐放在兩根吸管上（讓它們容易滾動），相距 2 cm，從中間吹氣，看它們是靠近還是分開。

**你應該看到／得到**
- 紙片貼住杯口不掉，水留在杯子裡。這是大氣壓力從下面把紙片往上推。
- 算一算：杯口直徑 7 cm，面積 ≈ 3.14 × 3.5 × 3.5 ≈ 38 cm²，空氣從底下往上推的力 ≈ 38 × 10 ＝ 380 N。杯子裡的水只有 250 g，重 2.45 N。往上推的力是水重的一百多倍，紙片當然掉不下來。
- 半杯水也行，因為杯子裡那一點空氣在翻過來時被稍微拉大，壓力比外面小一點，還是外面的大氣壓力贏。
- 加碼：紙條往上飄，兩個罐子靠在一起，吹氣的地方空氣流得快、壓力小。

**觀察與記錄**

| 情況 | 紙片掉了嗎？ | 你的解釋 |
|------|------|------|
| 整杯水 | | |
| 半杯水 | | |
| 紙片先弄皺再試 | | |
| 加碼：吹紙條上方 | 紙條往（上／下） | |
| 加碼：吹兩罐中間 | 罐子（靠近／分開） | |

**安全提醒**：一定在水槽或臉盆上方做，第一次通常會失敗（紙片沒貼好就會漏），地板濕了馬上擦乾。用玻璃杯時雙手要握穩，手滑就換塑膠杯。

## 用儀器看看

**1. 用廚房秤直接「看到」浮力**

這是本章最漂亮的示範，三分鐘就能做。把一個裝了半杯水的杯子放上廚房秤，按歸零。用棉線綁一顆石頭、一把鐵湯匙或一顆大螺絲，用手提著線，把它慢慢放進水裡，**不要碰到杯底和杯壁**。你會看到廚房秤的數字上升，例如變成 50 g。

石頭並沒有壓在杯子上，為什麼秤會多出 50 g？因為水往上托石頭 50 g 重的浮力，石頭就用同樣大的力往下壓水（牛頓第三定律），水再壓給秤。所以**秤上多出來的 50 g，就是浮力：0.05 × 9.8 ＝ 0.49 N**。而且根據阿基米德，被排開的水正好也是 50 g ＝ 50 cm³，你順便量到了石頭的體積。

接著放手讓石頭沉到底，數字會跳到石頭完整的質量，例如 135 g。那石頭的密度就是 135 ÷ 50 ＝ 2.7 g/cm³，這是鋁的密度，說不定它是一顆鋁螺絲。

**2. 用量杯和廚房秤算不規則東西的密度**

量杯裝 200 mL 的水，記下刻度。把東西整個放進去（會浮的用筷子壓到水面下），讀新的刻度，兩次相減就是體積（mL ＝ cm³）。再用廚房秤量它的質量。密度 ＝ 質量 ÷ 體積。算出來大於 1 就會沉，小於 1 就會浮，拿回水裡驗證。

**3. 用 Phyphox 的氣壓計量樓層高度**

打開 Phyphox，選「氣壓」（Pressure）。有些手機沒有氣壓感測器，會顯示找不到感測器，那就跳過這段。有的話，你會看到大約 1000 hPa 左右的數字（視當天天氣在 990～1030 之間變動）。按 ▶，拿著手機從一樓走到三樓，看數字變化：每上升 1 公尺，氣壓大約減少 0.12 hPa，三層樓約 10 公尺，數字會少掉 1.2 hPa 左右。你可以反過來用它估樓層高度：下降的 hPa 數 ÷ 0.12 ＝ 高度（m）。颱風來的時候再開一次，你會看到氣壓明顯變低，這就是「低氣壓」。

**4. 用試算表整理密度資料**

把實驗 5-1 的資料打進試算表：A 欄液體名稱，B 欄 100 mL 的質量。C2 輸入 `=B2/100` 算密度，往下拉。選取 A、C 兩欄，用「資料」→「排序」依 C 欄由大到小排，排出來的順序就是密度柱由下到上的順序。再插入長條圖，一眼看出每層差多少。

## 常見錯誤與迷思

- **「重的東西會沉，輕的會浮。」** → 一根 5 g 的鐵釘會沉，一艘幾萬噸的船會浮。→ 正確理解：沉或浮看的是密度（整體平均密度）和液體密度的比較，不是重量。
- **「只有浮著的東西才有浮力。」** → 沉在水底的石頭也有浮力，只是浮力比它的重量小。在水裡搬石頭比在陸地上輕，就是浮力在幫忙。→ 正確理解：只要有排開液體，就有浮力。
- **「東西沉得越深，浮力越大。」** → 一個完全沒入水中的鐵塊，在 1 m 深和 5 m 深排開的水一樣多，浮力一樣大。→ 正確理解：浮力只看排開的液體重，和深度無關（除非東西被壓縮變小，像沉浮子裡的空氣）。
- **「吸管是把飲料『吸』上來的。」** → 你只是把吸管裡的空氣移走，是外面的大氣壓力把飲料推上去。在太空站裡用吸管是行不通的。→ 正確理解：壓力差產生推力，大氣壓力才是真正的推手。
- **「大氣壓力這麼大，我們應該會被壓扁。」** → 身體裡面也有同樣的壓力往外頂。→ 正確理解：壓力只有在「不平衡」時才會造成明顯效果，例如倒過來的水杯、吸盤、吸管。
- **「冰浮在水上是因為它比較輕。」** → 一大塊冰比一小杯水重得多，還是浮。→ 正確理解：冰的密度（0.92）比水小，所以浮，而且 92% 在水下。

## 想一想

1. 一個 200 cm³ 的石頭完全沉在水裡，它受到的浮力是多少牛頓？

<details><summary>參考答案</summary>

排開 200 cm³ 的水，質量 200 g，重量 0.2 × 9.8 ＝ 1.96 N。浮力就是 1.96 N。

</details>

2. 一塊木頭質量 240 g、體積 400 cm³。它會沉還是浮？如果浮，有多少體積在水面下？

<details><summary>參考答案</summary>

密度 ＝ 240 ÷ 400 ＝ 0.6 g/cm³，比水小，會浮。浮著的時候浮力等於重量，所以排開的水要有 240 g，也就是 240 cm³ 在水面下，占 60%；露出水面 160 cm³。

</details>

3. 一顆雞蛋的密度約 1.1 g/cm³，放進清水會沉。要讓它浮起來，可以怎麼做？死海為什麼能讓人輕鬆漂著看報紙？

<details><summary>參考答案</summary>

往水裡加鹽，鹽水的密度可以超過 1.1，雞蛋就會浮。死海的鹽度極高，海水密度約 1.24 g/cm³，比人體（約 1.0）大很多，所以人不用動也會浮起來。

</details>

4. 用一張 50 g 的鋁箔紙摺成小船，可以浮在水上；把同一張鋁箔揉成緊緊的一球，就沉了。請用密度和阿基米德原理解釋。鋁的密度是 2.7 g/cm³。

<details><summary>參考答案</summary>

小船要浮，只要排開 50 g 的水（50 cm³）就夠了，船體包住的空間遠大於 50 cm³，很容易做到，整艘船平均密度比水小。揉成球以後，鋁本身只有 50 ÷ 2.7 ≈ 18.5 cm³，就算整顆沉進水裡，浮力最多也只有 18.5 g 重，托不住 50 g 的鋁，所以沉下去。

</details>

5. 潛水員潛到 15 m 深，水壓比水面多了多少 Pa？大約等於幾個大氣壓力？

<details><summary>參考答案</summary>

水壓 ＝ 1000 × 9.8 × 15 ＝ 147000 Pa。一個大氣壓力約 101300 Pa，所以多了大約 1.5 個大氣壓力；加上水面原本的 1 個，潛水員身上總共約 2.5 個大氣壓力。

</details>

6. （開放挑戰）熱氣球沒有馬達，靠什麼飛起來？請用「密度」和「浮力」兩個詞，解釋為什麼加熱氣球裡的空氣就會上升，為什麼放冷了就會下降。再想一想：氦氣球不用加熱為什麼也會飛？

<details><summary>參考答案</summary>

空氣也是流體，氣球泡在空氣裡也會受到浮力，浮力等於它排開的空氣的重量。把氣球裡的空氣加熱，空氣會膨脹、變稀，密度比外面的冷空氣小，整顆氣球（氣囊＋熱空氣＋吊籃）的平均密度一旦小於外面空氣，浮力就大於重量，氣球上升。冷卻後裡面的空氣密度變回和外面一樣，浮力不夠就下降。氦氣的密度本來就只有空氣的七分之一左右，不用加熱就比空氣輕，所以氦氣球直接飛。

</details>

## 本章小結

- 密度 ＝ 質量 ÷ 體積，水是 1 g/cm³；密度比液體大的沉，比液體小的浮，液體之間也一樣會分層。
- 浮力是液體往上托物體的力，來自上下水壓的差，大小等於被排開的液體重（阿基米德原理）。
- 浮在水面的東西，水下的部分排開的液體重剛好等於它自己的重量；泡在水下的比例 ＝ 物體密度 ÷ 液體密度。
- 鐵船能浮，是因為整艘船的平均密度比水小；潛水艇和沉浮子靠改變平均密度上下。
- 大氣壓力約 101300 Pa，每平方公分約 10 N（約 1 公斤重）；吸管、倒水杯、吸盤都是大氣壓力在推。
- 水壓 ＝ 1000 × 9.8 × 深度，每深 10 m 多一個大氣壓力。
- 伯努利的直覺：流體流得快的地方壓力小。
- 廚房秤上的水杯多出來的公克數就是浮力，也是物體排開的水的體積。
