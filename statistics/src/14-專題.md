# 第 14 章　專題

## 本章目標

學完這一章，你會：

- 把前面 13 章的工具串起來，從「提出問題」一路做到「寫出報告」。
- 完成三個專題中的至少一個：班級或家庭調查、一個月的手機數據、檢驗一個迷思。
- 設計自己的記錄表，知道每一種資料該用哪些圖和哪些數字來分析。
- 照著固定格式寫一份 4 到 8 頁的統計專題報告，並用 3 分鐘講給別人聽。
- 說出自己專題的「限制」：哪些結論可以下，哪些不行。

## 開場：從「我覺得」到「資料說」

學期快結束了，老師宣布：「這學期的統計課，期末不考試，每個人交一份專題。」

全班一陣歡呼，然後安靜下來：「專題……是要做什麼？」

老師說：「很簡單。找一個你平常會說『我覺得』的事情，把它變成『資料說』。」

阿凱平常最常說的是「我覺得星期一特別累」。小潔常說「我覺得我手機用得沒有很多」。小美則一直想知道「我們班到底有多少人沒吃早餐」。

這三句「我覺得」，剛好就是這一章的三個專題。做完你會發現：有些「我覺得」資料會幫你背書，有些會狠狠打臉，而最有趣的往往是第二種。

## 核心概念

### 專題的六個步驟

不管題目是什麼，統計專題都走同一條路：

```
  ① 提問 ──▶ ② 計畫 ──▶ ③ 蒐集 ──▶ ④ 整理 ──▶ ⑤ 分析 ──▶ ⑥ 報告
   第 1 章     第 2 章     第 2 章    第 3 章   第 4–12 章   本章最後一節
     ▲                                              │
     └──────────── 做完常常會冒出新問題 ◀───────────┘
```

| 步驟 | 要做的事 | 常見的坑 |
|---|---|---|
| ① 提問 | 把「我覺得……」改寫成一個**可以用數字回答**的問題 | 問題太大（「大家快樂嗎？」）或沒辦法量（「誰比較帥？」） |
| ② 計畫 | 決定要問誰、問什麼、怎麼記、記多久；先畫好空白記錄表 | 沒先想好分析方法，蒐集完才發現少問一題 |
| ③ 蒐集 | 照計畫做，過程中不改規則 | 中途改問法、漏記、憑印象補填 |
| ④ 整理 | 輸入試算表、清理錯誤、做次數表和圖 | 單位不統一（分鐘 vs 小時）、錯字讓同一類變兩類 |
| ⑤ 分析 | 算集中與離散、比較分組、看相關、必要時做檢定 | 只放圖不解釋；或把相關說成因果 |
| ⑥ 報告 | 照格式寫，誠實寫出限制 | 只寫對自己有利的結果 |

### 一個好的研究問題長什麼樣

比較下面幾組：

| 不好的問題 | 為什麼不好 | 改成 |
|---|---|---|
| 我們班健康嗎？ | 「健康」沒辦法直接量 | 我們班每天睡眠時間的平均和分布是什麼？ |
| 手機對人有害嗎？ | 太大、答不了 | 我一個月的螢幕時間，平日和週末差多少？ |
| 星期一是不是很討厭？ | 「討厭」太主觀 | 星期一早上的反應速度，是不是比星期三慢？ |

好問題的三個條件：**有明確的對象**（誰）、**有可以量的變數**（量什麼）、**有比較的對象或範圍**（跟什麼比）。

### 三種常見的分析套路

你蒐集到的資料，大致會落在這三種情況，每一種有固定的分析套路：

| 情況 | 例子 | 該用的工具 | 章 |
|---|---|---|---|
| 描述一個變數 | 全班睡眠時數 | 次數表、直方圖、平均、中位數、標準差、盒鬚圖 | 3、4、5 |
| 比較兩組 | 吃早餐 vs 沒吃早餐的精神分數 | 兩組各算平均與標準差、並排盒鬚圖、洗牌法 p 值 | 4、5、12 |
| 看兩個變數的關係 | 睡眠時數 vs 精神分數 | 散布圖、相關係數、趨勢線 | 10、11 |

### 蒐集別人資料時的規矩

專題一和專題三會用到同學或家人的資料。三個規矩：

1. **先說明、再徵求同意。** 告訴對方這是統計作業、資料會怎麼用、不想答可以不答。
2. **匿名。** 記錄表上用編號，不寫名字。報告裡絕對不出現「小明睡最少」這種句子。
3. **不問會讓人不舒服的問題。** 家裡收入、身體隱私、成績排名這類問題，不要問。

## 動手做

三個專題各自獨立，選一個做就好；時間夠的話做兩個，會發現很多技巧是共通的。

### 專題一：班級或家庭調查報告

**目標**：對 20 人以上（班級）或 5 人以上（家庭，可以把親戚算進來）做一份小問卷，寫出一份描述「我們是一群什麼樣的人」的報告，並比較其中兩組人的差別。

**材料／工具**：紙本問卷或 Google 表單、Google 試算表、計算機。

**步驟**：

1. **決定主題與 5 到 6 題問題。** 每種變數至少一題。範例主題「睡眠與早餐」：

| 題號 | 問題 | 變數種類 | 答案格式 |
|---|---|---|---|
| Q1 | 你昨晚睡了幾小時？ | 數值（連續） | 填數字，可填小數，例如 7.5 |
| Q2 | 你今天有吃早餐嗎？ | 類別 | 有／沒有 |
| Q3 | 你今天早上的精神狀況？ | 順序 | 1（很累）到 5（很好） |
| Q4 | 你昨天用手機大約幾分鐘？ | 數值 | 填數字 |
| Q5 | 你最喜歡的科目？ | 類別 | 國／英／數／自／社／藝／體 |
| Q6 | 你通常幾點上床？ | 數值 | 填時間，例如 22:30 |

2. **先用 2 個人試填。** 看看有沒有看不懂的題目、答案格式會不會亂（例如 Q6 有人填「十點半」）。修好再正式發。
3. **正式蒐集。** 同一天、同一個時段做，不然「今天精神」沒辦法比。至少 20 份。
4. **輸入試算表。** 一人一列、一題一欄，第一欄是編號。類別的答案統一寫法（都寫「有」不要有的寫「有吃」）。
5. **清理。** 用 `=MAX()` 和 `=MIN()` 找出不合理的值（睡 70 小時？手機 0 分鐘？），回頭確認或標記為遺漏。
6. **分析**（見下方）。
7. **寫報告。**

**記錄表**（試算表版面）：

| 編號 | Q1 睡眠（小時） | Q2 早餐 | Q3 精神（1–5） | Q4 手機（分） | Q5 科目 | Q6 上床時間 |
|---|---|---|---|---|---|---|
| 01 | | | | | | |
| 02 | | | | | | |
| … | | | | | | |
| 24 | | | | | | |

**分析方法**：

- **每個類別變數**：做次數分配表與長條圖（Q2、Q5）。例如 24 人裡 15 人有吃早餐（62.5%）、9 人沒吃（37.5%）。
- **每個數值變數**：算平均、中位數、標準差、最大最小，畫直方圖（Q1、Q4）。寫一句話描述形狀：「大多數人睡 6.5 到 8 小時，有 2 位不到 5 小時，是離群值。」
- **比較兩組**：用 Q2 把人分成「有吃」和「沒吃」，各算 Q3 的平均。假設有吃的平均 3.6 分、沒吃的 2.9 分，差 0.7 分。接著用第 12 章的洗牌法（試算表 RANDARRAY 版）算 p 值，判斷 0.7 分是不是巧合。
- **看關係**：Q1 對 Q3 畫散布圖，算相關係數。睡得多的人精神比較好嗎？r 有多大？
- **誠實的限制**：只問一天、人數少、都是同一班，不能推到「所有國中生」。

**分析結果整理表**（填進報告）：

| 變數 | 人數 | 平均 | 中位數 | 標準差 | 最小 | 最大 | 圖 |
|---|---|---|---|---|---|---|---|
| 睡眠（小時） | | | | | | | 直方圖 |
| 手機（分鐘） | | | | | | | 直方圖 |
| 精神（有吃早餐） | | | | | | | 盒鬚圖 |
| 精神（沒吃早餐） | | | | | | | 盒鬚圖 |

**延伸**：

- 隔兩週再做一次同樣的問卷，看結果穩不穩定（第 9 章：樣本會變動）。
- 對另一個班做，比較兩班（注意：班級不同可能還有很多其他差異）。
- 把「有沒有吃早餐」改成隨機分組實驗：抽籤決定誰明天吃、誰不吃（都要徵得同意），再比精神分數。這才能談「造成」。

### 專題二：分析自己一個月的手機螢幕時間或步數

**目標**：連續記錄 28 天（剛好 4 週）自己的每日螢幕時間或步數，找出自己的規律：平日和週末差多少？哪一天最多？有沒有慢慢變多或變少？

**材料／工具**：手機（iPhone：設定 → 螢幕使用時間；或健康 App 的步數。Android：設定 → 數位健康；或 Google Fit 的步數）、Google 試算表。沒有智慧型手機的話，可以改記「每天看電視分鐘數」或「每天讀書分鐘數」，用家裡的時鐘記。

**步驟**：

1. **選一個變數。** 螢幕時間（分鐘）或步數，擇一。選你比較在意的那個。
2. **決定記錄時間。** 每天固定時間（例如晚上睡前）打開手機抄下「今天」的數字。28 天不能中斷，中斷的那天在備註寫「漏記」，分析時當遺漏值。
3. **記錄表先畫好**，每天只花 30 秒。
4. **第 7 天先做一次小分析**，確認記錄方式沒問題。
5. **28 天後，全部輸入試算表，開始分析。**

**記錄表**：

| 日期 | 星期 | 螢幕時間（分）或步數 | 上課日？（是／否） | 備註（生病、出遊、漏記） |
|---|---|---|---|---|
| 3/2 | 一 | | 是 | |
| 3/3 | 二 | | 是 | |
| … | | | | |
| 3/29 | 日 | | 否 | |

**分析方法**：

- **折線圖看趨勢**：x 軸是日期、y 軸是數值。看有沒有慢慢上升或下降、有沒有一天特別突出。
- **整體描述**：28 天的平均、中位數、標準差、全距。平均和中位數差很多，表示有幾天特別極端。
- **平日 vs 週末**：用「上課日」欄分兩組（20 天 vs 8 天），各算平均。範例一週：

| 星期 | 一 | 二 | 三 | 四 | 五 | 六 | 日 |
|---|---|---|---|---|---|---|---|
| 步數 | 6200 | 5800 | 7100 | 6500 | 8300 | 11200 | 9800 |

這一週平均 54900 ÷ 7 ≈ 7843 步，中位數 7100，全距 11200 − 5800 = 5400。平日平均 33900 ÷ 5 = 6780 步，週末平均 21000 ÷ 2 = 10500 步，週末多了 3720 步。
- **星期幾最多**：用樞紐分析表（列 = 星期，值 = 平均），畫長條圖。4 週的資料，每個星期幾各有 4 天。
- **抹平起伏**：算 7 日移動平均，也就是「今天和前 6 天的平均」，在試算表用 `=AVERAGE(C2:C8)` 往下拉。移動平均的折線比原始折線平滑，更容易看出趨勢。
- **週末差距是巧合嗎**：用第 12 章的洗牌法。把 28 個數字洗牌，前 20 個當「平日」、後 8 個當「週末」，算差距；重複 100 次以上，看有幾次差距 ≥ 實際差距。
- **離群值要追問**：某天步數 25000，備註寫「校外教學」，就解釋得通；沒備註的離群值，要想想是不是記錯了。

**分析結果整理表**：

| 項目 | 數值 |
|---|---|
| 記錄天數（扣掉漏記） | |
| 平均 | |
| 中位數 | |
| 標準差 | |
| 最大值（哪一天、為什麼） | |
| 最小值（哪一天、為什麼） | |
| 平日平均 | |

| 平日 − 週末 | |
| 洗牌法 p 值 | |
| 第 1 週平均 vs 第 4 週平均 | |

**延伸**：

- 記錄一個月前，先寫下你「猜」的平均值。最後比對，你的直覺準嗎？（這是最有趣的部分。）
- 把「螢幕時間」拆成 App 類別（影片、遊戲、社群、學習），做圓餅圖。
- 找一位家人也記 28 天，兩個人的折線圖疊在一起比較。
- 第 2 個月故意改變一件事（例如睡前不帶手機進房間），比較前後兩個月，這就是一個「前後實驗」，但要記得還有很多其他事情也在變。

### 專題三：檢驗一個迷思（星期一比較累？）

**目標**：選一個大家常說、但沒人驗證過的說法，設計一個可以測量的比較，用資料判斷這個說法站不站得住腳。

**材料／工具**：依迷思而定。「星期一比較累」用一支 30 公分的尺和一位搭檔；Google 試算表。

**可以挑的迷思**（挑一個，或自己想一個）：

| 迷思 | 可量的變數 | 比較的兩組 |
|---|---|---|
| 星期一比較累 | 尺落下反應測驗的公分數（愈大愈慢） | 星期一 vs 星期三 |
| 吃完午餐會想睡 | 精神自評 1–5 | 午餐前 vs 午餐後 30 分鐘 |
| 穿幸運色考試會比較好 | 小考分數 | 有穿 vs 沒穿（需要隨機決定） |
| 聽音樂讀書比較專心 | 10 分鐘內做對的算術題數 | 有音樂 vs 安靜（隨機決定順序） |
| 下雨天大家比較不想動 | 全班當天平均步數 | 雨天 vs 晴天 |

**步驟**（以「星期一比較累」為例）：

1. **把迷思改寫成虛無假設。** 虛無假設：星期一和星期三的反應速度沒有差別。對立假設：有差別。
2. **決定測量方法：尺落下反應測驗。** 搭檔拿著尺的上端，0 公分那一端朝下、懸在你張開的拇指與食指之間（不碰到）。搭檔不預警放手，你看到尺掉就夾住，讀出你手指夾住的刻度（公分）。公分數愈大，表示反應愈慢。每次測 3 回，取平均，這就是一筆資料。
3. **固定條件。** 每次都在同一個時段（例如早自習）、同一個搭檔、同一支尺、同一隻手。
4. **連續 4 週，每週一和週三各測一次。** 全班一起做的話，20 人 × 4 週 = 80 筆星期一資料、80 筆星期三資料。一個人做的話，只有 4 對 4，人太少很難顯著（第 12 章），所以建議至少找 5 位同學一起。
5. **輸入試算表**，一列一筆：編號、週次、星期、三回公分數、平均。
6. **分析。**

**記錄表**：

| 編號 | 第幾週 | 星期 | 第 1 回（cm） | 第 2 回 | 第 3 回 | 平均（cm） | 備註 |
|---|---|---|---|---|---|---|---|
| 01 | 1 | 一 | | | | | |
| 01 | 1 | 三 | | | | | |
| 01 | 2 | 一 | | | | | |
| … | | | | | | | |
| 20 | 4 | 三 | | | | | |

**分析方法**：

- **兩組描述**：星期一所有資料的平均、中位數、標準差；星期三同樣算一次。畫並排盒鬚圖（試算表沒有內建盒鬚圖的話，就把兩組的最小、Q1、中位數、Q3、最大列成表格比較）。
- **差距有多大**：星期一平均 − 星期三平均。例如 19.0 − 15.8 = 3.2 公分，星期一慢一點。
- **是不是巧合**：洗牌法。把所有資料（80 + 80 筆）洗牌，前 80 筆當「星期一」，算差距，重複 100 次以上，看有幾次 ≥ 3.2。p 值小於 0.05 就可以說「星期一確實比較慢，不太像巧合」。
- **個人層次**：每個人自己的「星期一平均 − 星期三平均」，看有幾個人是正的（星期一比較慢）。20 人裡如果有 17 人是正的，這本身就很說明問題（如果真的沒差，每個人正負的機會應該各半，像擲 20 次硬幣出現 17 次正面，第 7 章）。
- **誠實的限制**：反應速度不等於「累」；只測早上；只有 4 週；同學知道自己在測什麼，可能星期一特別努力（或特別放鬆）。

**分析結果整理表**：

| | 星期一 | 星期三 |
|---|---|---|
| 筆數 | | |
| 平均（cm） | | |
| 中位數 | | |
| 標準差 | | |
| 最小／最大 | | |
| 差距（一 − 三） | | |
| 洗牌法 p 值 | | |
| 「星期一比較慢」的人數／總人數 | | |

**延伸**：

- 加測星期五，看是不是「愈接近週末反應愈快」，畫一週的折線。
- 同時記錄每個人前一晚的睡眠時數，看「睡眠」和「反應」的相關，星期一比較慢會不會只是因為週日晚睡？這就是在找潛在變數（第 6 章）。
- 把迷思換成「吃完午餐想睡」，同一個人午餐前後各測，這種「同一個人前後比」比「兩群人比」更不容易被個人差異干擾。

## 用工具看看

三個專題都會用到這幾個試算表動作，這裡一次整理（詳細函式見附錄 B）：

**1. 建立乾淨的資料表**

- 第一列是欄位名稱，每一列一筆資料，不要合併儲存格、不要在資料中間留空列。
- 類別答案用「資料驗證」限制選項：選取整欄 → 資料 → 資料驗證 → 「下拉式選單」，輸入「有,沒有」。這樣就不會出現「有吃」「yes」混在一起。

**2. 一次算出描述統計**

在資料旁邊空白處做一個小表，例如 Q1 睡眠在 B 欄、第 2 到 25 列：

| 統計量 | 公式 |
|---|---|
| 人數 | `=COUNT(B2:B25)` |
| 平均 | `=AVERAGE(B2:B25)` |
| 中位數 | `=MEDIAN(B2:B25)` |
| 標準差 | `=STDEV(B2:B25)` |
| 最小／最大 | `=MIN(B2:B25)`／`=MAX(B2:B25)` |
| Q1／Q3 | `=QUARTILE(B2:B25, 1)`／`=QUARTILE(B2:B25, 3)` |

**3. 分組比較**

Q2 早餐在 C 欄、Q3 精神在 D 欄：

- 有吃早餐的精神平均：`=AVERAGEIF(C2:C25, "有", D2:D25)`
- 沒吃的：`=AVERAGEIF(C2:C25, "沒有", D2:D25)`
- 有吃的人數：`=COUNTIF(C2:C25, "有")`

或者用樞紐分析表：插入 → 樞紐分析表 → 列選「Q2 早餐」、值選「Q3 精神」並把「摘要方式」改成 AVERAGE。

**4. 畫圖**

- 選取資料 → 插入 → 圖表 → 右側「圖表類型」選：類別次數用**直條圖**、比例用**圓餅圖**、數值分布用**直方圖**、時間用**折線圖**、兩個數值的關係用**散布圖**。
- 散布圖加趨勢線：圖表編輯器 → 自訂 → 數列 → 勾「趨勢線」，再勾「顯示 R 平方」（R 平方開根號就是相關係數的絕對值）。
- 每張圖都要有標題、兩個軸的名稱和單位。

**5. 洗牌法 p 值**

照第 12 章「用工具看看」的進階版，把 `$A$2:$A$17` 換成你的資料範圍，`RANDARRAY(16, 1)` 的 16 換成你的總筆數，`AVERAGE(B20:I20)` 的範圍換成第一組的筆數。

**6. 匯出給 Python（選配）**

檔案 → 下載 → 逗號分隔值（.csv），再照第 13 章練習 13-7 上傳 Colab。

## 專題報告格式

報告用 A4 直式，4 到 8 頁（含圖表），依下面順序，每一節都要有標題。

**1. 標題與作者**
一行標題要包含研究問題，例如「我們班的睡眠與早餐：吃早餐的人精神比較好嗎？」下面寫姓名、班級、日期。

**2. 摘要（100 字以內）**
用 3 到 4 句話說完：問了什麼、怎麼做、發現什麼、結論是什麼。這一段最後寫，但放最前面。

**3. 問題與動機（半頁）**
- 你想回答的問題（一句話）。
- 為什麼想知道（你的「我覺得」是什麼）。
- 你事先的猜測。

**4. 資料蒐集方法（半頁到一頁）**
- 對象：誰、幾個人、怎麼找的。
- 變數：每個變數的名稱、種類（類別／數值／順序）、單位、怎麼量。
- 時間與地點。
- 問卷題目或測量步驟（放附錄也可以）。
- 遇到的問題與處理方式（例如有 2 份問卷沒填完，怎麼處理）。

**5. 資料整理（一頁）**
- 整理後的資料表（人數多的話放附錄，正文放摘要表）。
- 每個變數的次數分配表或描述統計表。
- 至少 2 張圖，每張圖要有編號、標題、軸名稱、單位，正文裡要提到「見圖 1」。

**6. 分析與發現（一到兩頁）**
這是報告的主體。每一個發現用「圖或表 → 數字 → 一句話解釋」的方式寫：

> 圖 2 是有吃與沒吃早餐兩組的精神分數盒鬚圖。有吃早餐的 15 人平均 3.6 分，沒吃的 9 人平均 2.9 分，差 0.7 分。洗牌法 1000 次中，有 48 次差距達到 0.7 分以上，p = 0.048。這個差距隨機分組不太容易出現，但也只是剛好跨過 0.05，證據算是「有一點」。

**7. 結論與限制（半頁）**
- 回答第 3 節的問題，用一句話。
- 你的猜測對了嗎？
- 限制：至少寫 3 條。人數？時間？是不是隨機分組？有沒有潛在變數？哪些結論「不能」下？
- 如果再做一次，你會改什麼？

**8. 反思（幾句話）**
做這個專題最意外的事、最難的事、學到的事。

**9. 附錄**
原始資料表、問卷原件、試算表或 Colab 的連結。

**自我檢查表**（交之前逐條打勾）：

| 項目 | 打勾 |
|---|---|
| 研究問題是一句可以用數字回答的話 | |
| 寫清楚對象、人數、怎麼找的 | |
| 每個變數都標了種類和單位 | |
| 每張圖有編號、標題、軸名稱，正文有提到 | |
| 每個數字都說了它代表什麼意思 | |
| 用了至少一種集中量數和一種離散量數 | |
| 比較兩組時有給 p 值或說明為什麼沒做 | |
| 沒有把「相關」寫成「造成」 | |
| 限制至少 3 條 | |
| 沒有出現任何人的名字 | |

**3 分鐘口頭報告**：第 1 分鐘講問題和為什麼（給大家看你的「我覺得」）；第 2 分鐘給一張最關鍵的圖，指著圖說數字；第 3 分鐘講結論、限制和一句你最意外的發現。練習時用手機計時，超過 3 分鐘就砍內容，不要講快。

## 常見錯誤與迷思

- **「題目愈大愈厲害。」** → 大題目答不完，報告會變成空話。 → 題目小到你一個月做得完，答得明確，才是好專題。
- **「資料蒐集完再想怎麼分析。」** → 常常發現少問一題、或格式沒辦法算。 → 畫記錄表時就想好每一欄要畫什麼圖、算什麼數。
- **「結果和我猜的不一樣，一定是資料有問題。」** → 資料打臉直覺才是統計最有價值的時候。 → 先檢查有沒有輸入錯誤；沒有的話，誠實寫出來，說明你原本的猜測為什麼錯。
- **「兩組平均不一樣，所以我證明了迷思是對的。」** → 隨便分組平均也會不一樣（第 12 章）。 → 做洗牌法給 p 值，並且在限制裡寫人數夠不夠。
- **「p < 0.05，所以 A 造成 B。」** → 沒有隨機分組就只能說「有關」。 → 想談「造成」，設計時就要用抽籤分組。
- **「圖放愈多愈好。」** → 10 張圖沒人看得完，每張都沒解釋等於沒放。 → 每張圖都要有一段文字說它在說什麼，一張好圖勝過十張湊數的。
- **「只寫對我有利的數字。」** → 這是第 6 章「圖表會說謊」的作者版。 → 把不利的結果也寫進去，反而讓讀者更相信你。

## 想一想

1. 把「我們班同學是不是都很晚睡？」改寫成一個可以用數字回答的研究問題，並說出要量的變數和它的種類。

<details><summary>參考答案</summary>

例如：「我們班同學昨晚的上床時間平均是幾點？有多少比例在 11 點以後上床？」變數是「上床時間」，數值變數（連續）；「11 點以後」是用它做出來的類別變數。

</details>

2. 小美的專題二記錄了 28 天步數，但有 3 天忘了記。她想把這 3 天填 0，可以嗎？應該怎麼做？

<details><summary>參考答案</summary>

不可以，填 0 會把平均拉低、也會製造假的離群值。應該把那 3 天標成遺漏值（留空、備註「漏記」），分析時用 25 天算，並在報告的限制裡寫明。

</details>

3. 專題三裡，阿凱一個人測了 4 個星期一和 4 個星期三，星期一平均慢 3 公分。他用洗牌法，4 對 4 全部列舉共 70 種分法，最極端的 2 種就是他的結果。p 值是多少？能下什麼結論？

<details><summary>參考答案</summary>

p = 2 ÷ 70 ≈ 0.029，小於 0.05。但要注意：8 筆資料非常少，而且是同一個人，結論只能是「阿凱自己這 4 週星期一比較慢」，不能推到「大家星期一比較累」。找更多同學一起做會更有說服力。

</details>

4. 專題一發現「睡眠時數和精神分數的相關係數 r = 0.6」。報告裡可以寫「多睡覺會讓精神變好」嗎？

<details><summary>參考答案</summary>

不行，這是觀察資料，只能寫「睡得較多的同學精神分數也較高，兩者有中度正相關」。可能有潛在變數（例如身體健康的人既睡得好也精神好），也可能方向相反（精神好所以睡得好）。要談因果需要隨機分組實驗。

</details>

5. （開放）用專題二的範例一週資料（6200、5800、7100、6500、8300、11200、9800），畫出 ASCII 折線圖或長條圖，並寫 3 句話描述這一週的規律。

<details><summary>參考答案</summary>

參考方向：平日在 5800 到 8300 之間、週末跳到 9800 以上；星期五已經開始上升；最高的星期六比最低的星期二多將近一倍（11200 ÷ 5800 ≈ 1.93）。

</details>

6. （開放挑戰）幫下面這個「我覺得」設計一個完整專題：「我覺得全班都比我早到學校」。寫出研究問題、虛無假設、要量的變數、記錄表的欄位、分析方法，以及至少兩個限制。

<details><summary>參考答案</summary>

參考方向：研究問題「我的到校時間在全班排第幾？比我早到的人占多少比例？」虛無假設「我的到校時間和全班中位數沒有差別」。變數：每人到校時間（數值，記成「幾點幾分」再換算成「7:00 之後的分鐘數」）。記錄表欄位：編號、日期、到校時間、換算分鐘數。連續記 5 天，算每個人的平均到校時間，畫直方圖，標出自己的位置，算出比自己早的人數比例；也可以算自己的 z 分數。限制：只記一週、只有自己班、大家知道在記錄可能刻意早到、遲到的人可能不願意填。

</details>

## 本章小結

- 專題走六步：提問、計畫、蒐集、整理、分析、報告；計畫時就要畫好記錄表並想好分析方法。
- 好的研究問題有明確的對象、可以量的變數、以及比較的對象或範圍。
- 三種分析套路：描述一個變數（表、直方圖、平均、標準差）、比較兩組（分組統計、盒鬚圖、洗牌法）、看關係（散布圖、相關係數、趨勢線）。
- 蒐集別人的資料要說明、徵求同意、匿名，不問讓人不舒服的問題。
- 遺漏值不能填 0；離群值要追問原因；單位與寫法要統一。
- 兩組有差要用洗牌法給 p 值；沒有隨機分組就只能說「有關」，不能說「造成」。
- 報告固定九節，結論要誠實寫出至少三條限制；不利的結果也要寫。
