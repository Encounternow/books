## 核心概念

### 什麼是 Google Colab

**Google Colab（Colaboratory）** 是 Google 提供的免費網頁，讓你在瀏覽器裡寫 Python、跑 Python。它長得像一本筆記本（Notebook），裡面一格一格的叫做**儲存格（Cell）**。你在儲存格裡打程式，按左邊的播放鍵（或鍵盤 Shift + Enter），結果就出現在那一格的正下方。

你需要的只有：一個 Google 帳號、一台能上網的電腦。手機也能用，但打字不方便。

### 程式的三個基本觀念

你只需要先懂三件事，就能看懂這一章所有程式。

**1. 變數（Variable）：給一個值取名字。**

```python
# 把 80 這個數字取名叫 average
average = 80
# 把名字印出來看看裡面裝什麼
print(average)
```

**2. 清單（List）：把一堆值裝在一起，用中括號和逗號。**

```python
# 8 個分數裝成一個清單
scores = [82, 75, 90, 68, 88, 79, 85, 73]
# len() 算清單有幾個，sum() 把清單全部加起來
print(len(scores), sum(scores))
# 平均 = 總和 ÷ 個數
print(sum(scores) / len(scores))
```

跑出來應該是 `8 640` 和 `80.0`。

**3. 函式（Function）：別人寫好的工具，名字後面加括號就能用。** 像 `print()`、`sum()`、`len()` 都是函式。括號裡放的東西叫**參數（Argument）**。

另外還有一個習慣：**井字號 `#` 後面的字是註解（Comment）**，電腦會跳過不執行，是寫給人看的說明。這一章的程式每隔兩三行就有註解，幫你看懂每一段在做什麼。

### 工具箱：pandas 與 matplotlib

Python 本身只會加減乘除，統計和畫圖要靠別人寫好的**套件（Package）**。本章用兩個，Colab 都已經裝好了：

| 套件 | 用途 | 匯入的寫法 |

| pandas | 讀 CSV、整理表格、算統計量 | `import pandas as pd` |

`import ... as pd` 的意思是「把 pandas 搬進來，以後簡稱 pd」。這一行每個筆記本只要打一次。

### CSV 是什麼

**CSV（Comma-Separated Values，逗號分隔值）** 是最簡單的表格檔案格式：一行一筆資料，欄位用逗號隔開，第一行是欄位名稱。Google 試算表可以「檔案 → 下載 → 逗號分隔值（.csv）」直接匯出。例如：

```
編號,身高,腳長,讀書分鐘,成績
1,152,23.0,30,62
2,158,24.0,45,70
```

本章的程式會先用程式自己造一個 CSV 檔（這樣你不用先準備檔案），最後再教你上傳自己的 CSV。

### 什麼時候用試算表、什麼時候用程式

學到這裡你已經會用試算表做完本書所有計算，那為什麼還要學程式？三個理由：

1. **資料一多，試算表會卡。** 幾百筆資料試算表很順，幾萬筆就會開始轉圈圈；程式讀十萬筆也只要一秒。
2. **換資料不用重做。** 試算表的公式綁在格子上，換一份新資料常常要重拉一次。程式寫好後，換一個 CSV 檔名，按一次執行，所有數字和圖全部重新算好。
3. **做的事可以被別人檢查。** 試算表裡的公式藏在格子裡，別人很難看出你怎麼算的；程式是一行一行的文字，每一步都看得到，錯了也容易找。

不過，對本書大部分的小資料來說，試算表完全夠用，而且看得到每一格、比較安心。建議的做法是：**先用試算表做一次、再用程式做一次，兩邊對答案。** 數字一樣，你就同時確認了程式和公式都沒問題。

### 練習 13-2：平均、中位數、標準差

### 練習 13-5：畫趨勢線並預測

**步驟**：

```python
# numpy 是 pandas 底下的數學套件，polyfit 可以找最適直線
import numpy as np

# 用讀書分鐘預測成績：polyfit(..., 1) 的 1 表示找「一次」的直線
slope, intercept = np.polyfit(df["讀書分鐘"], df["成績"], 1)
print("斜率 =", round(slope, 3), " 截距 =", round(intercept, 2))

# 用直線預測：每天讀 100 分鐘，預測成績是多少
print("每天讀 100 分鐘，預測成績 =", round(slope * 100 + intercept, 1))

# 把散布圖和趨勢線畫在一起
plt.scatter(df["讀書分鐘"], df["成績"])
x_line = np.array([10, 95])                    # 直線的兩個端點（x 值）
plt.plot(x_line, slope * x_line + intercept, color="red")   # 畫紅色直線
plt.title("Trend Line")
plt.xlabel("Study minutes per day")
plt.ylabel("Score")
plt.show()
```

**你應該看到／得到**：斜率約 0.478（每多讀 1 分鐘，成績約多 0.48 分），截距約 47.16，預測每天讀 100 分鐘約 95.0 分。注意 100 分鐘已經超出資料範圍（最多 90），這種預測要小心（第 11 章）。

### 練習 13-6：洗牌法一萬次

**步驟**：用第 12 章的巧克力資料。

```python
import numpy as np

# 兩組原始分數
group_a = [82, 75, 90, 68, 88, 79, 85, 73]
group_b = [70, 78, 65, 84, 72, 60, 76, 71]

# 實際觀察到的差距
observed = np.mean(group_a) - np.mean(group_b)
print("實際差距 =", observed)

# 把 16 個分數合併成一疊牌
all_scores = np.array(group_a + group_b)

# 固定亂數種子，讓每次執行結果一樣（想看不同結果可以把這行刪掉）
rng = np.random.default_rng(seed=2024)

# 洗 10000 次，每次算前 8 張平均減後 8 張平均
times = 10000
count = 0
for i in range(times):
    shuffled = rng.permutation(all_scores)
    diff = shuffled[:8].mean() - shuffled[8:].mean()
    # 差距的絕對值 ≥ 實際差距，就算一次「稀奇」
    if abs(diff) >= observed:
        count += 1

# p 值 = 稀奇次數 ÷ 總次數
print(times, "次洗牌中，有", count, "次差距 ≥", observed, "分")
print("p 值約 =", count / times)
```

**你應該看到／得到**：`實際差距 = 8.0`，`10000 次洗牌中，有 609 次差距 ≥ 8.0 分`，`p 值約 = 0.0609`（把所有 12870 種分法全部列出來算的精確值是 0.0589；第 12 章洗 1000 次得到 0.067，一萬次就更接近精確值了）。把 `seed=2024` 改成別的數字，稀奇次數會稍微變動，但 p 值都在 0.055 到 0.065 之間。

## 常見錯誤與迷思

- **「程式要全部打對才會動，我一定學不會。」** → 寫程式本來就是不斷出錯、看錯誤訊息、修正的過程，老手也一樣。 → 看紅字的最後一行，對照上面的表，多半幾秒就能修好。
- **「圖上的中文變成方框。」** → Colab 預設的字型沒有中文，標題和座標軸的中文會顯示成 □□□。 → 最簡單的做法是圖上用英文（本章就是這樣做），資料欄位名稱用中文沒關係，因為它們不畫在圖上。進階做法是在第一格執行 `!apt-get -qq install fonts-noto-cjk` 安裝中文字型，再設定 matplotlib 使用它，可以上網搜尋「Colab matplotlib 中文」。
- **「我的標準差和第 5 章手算的不一樣。」** → pandas 的 `.std()` 預設除以 n−1（樣本標準差），第 5 章手算是除以 n（母體標準差）。 → 兩個都對，只是用途不同。要除以 n 的話寫 `df["成績"].std(ddof=0)`。
- **「我每次跑洗牌法，p 值都不一樣。」** → 洗牌本來就是隨機的，每次會差一點點。 → 次數夠多（一萬次）差異就很小；要完全一樣就固定 `seed`。
- **「程式算出來的數字一定對。」** → 程式只會照你說的做，資料有錯、欄位選錯、公式打錯，它都照算。 → 永遠要用小資料手算一次或用試算表對一次，確認程式沒誤會你的意思。

<details><summary>參考答案</summary>

兩組都只是觀察資料，嚴格說都不能直接說「造成」。身高與腳長高度相關是因為兩者都跟「整個人長大」有關，不是身高造成腳長。讀書分鐘與成績的相關比較可能有因果方向（讀書 → 成績），但也可能是「本來成績好的人更願意讀書」，要用第 12 章的隨機分組實驗才能確定。

</details>

<details><summary>參考答案</summary>

## 本章小結

- Google Colab 是免費的網頁版 Python 筆記本，不用安裝，按 Shift + Enter 就能執行一格程式。
- 看懂程式只需要三個觀念：變數（取名字）、清單（裝一堆值）、函式（別人寫好的工具）。
- pandas 的 `read_csv()` 讀表格，`.mean()`、`.median()`、`.std()`、`.corr()` 算統計量，`.describe()` 一次算全部。
- matplotlib 的 `plt.hist()` 畫直方圖、`plt.scatter()` 畫散布圖、`plt.plot()` 畫直線。
- `np.polyfit(x, y, 1)` 找最適直線，`rng.permutation()` 洗牌，一萬次只要一秒。
- 出錯時看紅字的最後一行；圖上的中文會變方框，先用英文標籤。
- 程式算得快，但不會幫你檢查資料對不對，永遠要用小資料驗算一次。
