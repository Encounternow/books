# 附錄 C　台灣經濟數據去哪查

書裡很多活動要你「查數據」：台灣的 GDP、物價指數、匯率、失業率、稅收。這些資料都是政府或公開機構免費提供的，不用猜、不用抄新聞的二手數字。這一份清單告訴你**哪個機構管哪種數據**，以及到了那裡大概要找什麼。

**三個使用原則：**

1. **用機構名稱搜尋最保險。** 網站常常改版，底下只列機構名稱與一般首頁；進去之後找「統計」「資料」「查詢」之類的選單，或直接在搜尋引擎打「機構名稱 + 你要的數據」（例如「主計總處 消費者物價指數」）。
2. **看清楚單位、時間與基期。** GDP 的單位可能是「百萬元」或「億元」；物價指數要知道「哪一年 = 100」；匯率要分「買入」「賣出」「現金」「即期」。
3. **記下來源與查詢日期。** 專題報告裡的每一個數字都要能說出「從哪裡、什麼時候查到的」。

## C.7　怎麼讀一張政府統計表

拿到資料後，照這五步走：

1. **先看標題與單位**：「國內生產毛額（名目，百萬元）」和「經濟成長率（%）」是完全不同的東西。
2. **找基期**：物價指數會註明「基期：民國 XXX 年 = 100」。不同基期的指數不能直接相減。
3. **看年份是民國還是西元**：政府網站多用民國年，民國年 + 1911 = 西元年。
4. **分清「年增率」和「月增率」**：年增率是和去年同月比，月增率是和上個月比。新聞說「通膨 2.5%」通常是年增率。
5. **下載成 CSV 再處理**：用附錄 B 的方法匯進試算表，自己畫圖，不要只看網站的圖。

## C.8　找不到的時候

- 換關鍵字：「物價」可能叫「消費者物價指數」或「CPI」；「薪水」可能叫「經常性薪資」。
- 看網站的「網站導覽」或「統計資料」選單。
- 用政府資料開放平臺搜一次，常常會直接找到資料集。
- 問圖書館員：公共圖書館的參考諮詢櫃台可以幫你找統計年鑑。
- 真的找不到，就在報告裡誠實寫「查不到官方數據，改用新聞報導的數字，來源為……」，並註明這是二手資料。
