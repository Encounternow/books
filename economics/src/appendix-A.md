# 附錄 A　名詞總表

這一份表把全書出現過的名詞依章節整理，中英對照，每個給一句話解釋。同一個名詞若在好幾章出現，只列在第一次出現的章節。找不到時，可以用瀏覽器的「尋找」功能（Ctrl+F 或 ⌘+F）直接搜中文或英文。

## 第 1 章　稀少與選擇

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 稀少性 | Scarcity | 資源有限、慾望無限，所以每樣東西都不夠分。 |
| 資源 | Resources | 能拿來生產或消費的東西：時間、錢、土地、人力、材料。 |
| 慾望 | Wants | 想要的東西，永遠比能得到的多。 |
| 選擇 | Choice | 因為稀少，所以必須決定要哪一個、放棄哪一個。 |
| 取捨 | Trade-off | 要得到一樣東西就得少拿另一樣。 |
| 機會成本 | Opportunity Cost | 做一個選擇時，放棄的「次好選項」的價值。 |
| 邊際 | Marginal | 「再多一個」的意思，例如多吃一口、多買一件。 |
| 邊際效益 | Marginal Benefit | 多做一單位得到的額外好處。 |
| 邊際成本 | Marginal Cost | 多做一單位要付出的額外成本。 |
| 誘因 | Incentive | 讓人想做或不想做某件事的獎勵或懲罰。 |
| 效用 | Utility | 消費某樣東西得到的滿足感。 |

## 第 2 章　需求

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 需求 | Demand | 在各種價格下，買方願意且能夠購買的數量關係。 |
| 需求法則 | Law of Demand | 其他條件不變時，價格越高，需求量越少。 |
| 需求量 | Quantity Demanded | 在某一個特定價格下想買的數量。 |
| 需求表 | Demand Schedule | 把價格與對應需求量列成的表格。 |
| 需求曲線 | Demand Curve | 需求表畫成的線，通常由左上往右下。 |
| 替代品 | Substitute | 可以互相取代的東西，例如珍奶與紅茶。 |
| 互補品 | Complement | 常一起用的東西，例如手機與保護殼。 |
| 正常財 | Normal Good | 所得增加時會買更多的東西。 |
| 劣等財 | Inferior Good | 所得增加時反而買更少的東西，例如泡麵。 |
| 偏好 | Preference | 個人的喜好，會改變需求。 |
| 預期 | Expectation | 對未來價格或所得的猜測，會影響現在的決定。 |
| 消費者 | Consumer | 買東西來使用的人。 |

## 第 3 章　供給

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 供給 | Supply | 在各種價格下，賣方願意且能夠提供的數量關係。 |
| 供給法則 | Law of Supply | 其他條件不變時，價格越高，供給量越多。 |
| 供給量 | Quantity Supplied | 在某一個特定價格下願意賣的數量。 |
| 供給曲線 | Supply Curve | 供給表畫成的線，通常由左下往右上。 |
| 生產者 | Producer | 做東西或提供服務來賣的人或公司。 |
| 投入 | Input | 生產時用掉的原料、人力、設備。 |
| 技術 | Technology | 生產的方法；技術進步讓同樣投入做出更多東西。 |
| 生產成本 | Cost of Production | 做出一樣東西要花的所有錢。 |

## 第 4 章　市場價格怎麼決定

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 市場 | Market | 買方與賣方碰面交易的地方，不一定是實體的。 |
| 均衡 | Equilibrium | 需求量等於供給量、價格不再變動的狀態。 |
| 均衡價格 | Equilibrium Price | 供需交會點的價格。 |
| 均衡數量 | Equilibrium Quantity | 供需交會點的數量。 |
| 短缺 | Shortage | 價格低於均衡，想買的比想賣的多。 |
| 過剩 | Surplus | 價格高於均衡，想賣的比想買的多。 |
| 價格機能 | Price Mechanism | 價格自動調整、讓供需趨向平衡的過程。 |
| 拍賣 | Auction | 由買方出價競爭、價高者得的交易方式。 |
| 價格上限 | Price Ceiling | 政府規定的最高價，低於均衡時會造成短缺。 |
| 價格下限 | Price Floor | 政府規定的最低價，高於均衡時會造成過剩。 |

## 第 5 章　彈性

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 彈性 | Elasticity | 一個東西變動時，另一個東西跟著變動的敏感程度。 |
| 需求的價格彈性 | Price Elasticity of Demand | 價格變 1%，需求量變幾 %。 |
| 有彈性 | Elastic | 價格一動，數量變很多（彈性大於 1）。 |
| 無彈性 | Inelastic | 價格動了，數量變不多（彈性小於 1）。 |
| 必需品 | Necessity | 非買不可的東西，需求通常無彈性。 |
| 奢侈品 | Luxury | 可有可無的東西，需求通常有彈性。 |
| 總收入 | Total Revenue | 價格 × 賣出數量。 |

## 第 6 章　生產與成本

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 固定成本 | Fixed Cost | 不管做幾個都要付的成本，例如攤位費。 |
| 變動成本 | Variable Cost | 多做一個就多花的成本，例如原料。 |
| 總成本 | Total Cost | 固定成本加變動成本。 |
| 平均成本 | Average Cost | 總成本除以數量。 |
| 規模經濟 | Economies of Scale | 做得越多，平均成本越低。 |
| 收入 | Revenue | 賣東西收到的錢。 |
| 利潤 | Profit | 收入減總成本。 |
| 損益兩平點 | Break-even Point | 收入剛好等於總成本、不賺不賠的數量。 |
| 沉沒成本 | Sunk Cost | 已經花掉、拿不回來的錢，做決定時不應該考慮。 |

## 第 7 章　競爭與市場結構

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 市場結構 | Market Structure | 一個市場裡有幾家廠商、產品像不像、進出容不容易。 |
| 完全競爭 | Perfect Competition | 很多賣家賣一樣的東西，沒有人能決定價格。 |
| 獨占 | Monopoly | 只有一家賣家，可以自己決定價格。 |
| 寡占 | Oligopoly | 少數幾家大廠商主導市場，例如電信公司。 |
| 獨占性競爭 | Monopolistic Competition | 很多賣家，但各有特色，例如手搖飲店。 |
| 進入障礙 | Barrier to Entry | 讓新廠商難以加入市場的東西，例如執照、巨額設備。 |
| 品牌 | Brand | 讓消費者認得、願意多付錢的名字與形象。 |
| 廣告 | Advertising | 廠商用來影響偏好、增加需求的宣傳。 |
| 產品差異化 | Product Differentiation | 讓自己的產品和別人不一樣，避免只能比價格。 |
| 價格接受者 | Price Taker | 只能接受市場價格、無法自己決定的賣家。 |

## 第 8 章　貨幣與銀行

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 以物易物 | Barter | 不用錢，直接用東西換東西。 |
| 貨幣 | Money | 大家都接受、用來交易的東西。 |
| 交易媒介 | Medium of Exchange | 貨幣的功能一：用來買賣。 |
| 計價單位 | Unit of Account | 貨幣的功能二：用來標價和比較價值。 |
| 價值儲存 | Store of Value | 貨幣的功能三：可以存起來以後再用。 |
| 銀行 | Bank | 收存款、放貸款、賺利差的機構。 |
| 存款 | Deposit | 放在銀行的錢。 |
| 貸款 | Loan | 向銀行借的錢。 |
| 利率 | Interest Rate | 借錢或存錢一年的利息占本金的百分比。 |
| 利息 | Interest | 借錢要付、存錢可收的費用。 |
| 本金 | Principal | 一開始存入或借出的金額。 |
| 單利 | Simple Interest | 只用本金算利息。 |
| 複利 | Compound Interest | 利息也加進本金再算利息，時間越長越明顯。 |

## 第 9 章　物價與通貨膨脹

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 物價 | Price Level | 整體商品與服務價格的平均水準。 |
| 物價指數 | Price Index | 把某一年的物價設為 100，用來比較其他年份的數字。 |
| 消費者物價指數 | Consumer Price Index (CPI) | 衡量一般家庭常買的東西價格變化的指數。 |
| 通貨膨脹 | Inflation | 物價普遍、持續上漲。 |
| 通貨緊縮 | Deflation | 物價普遍、持續下跌。 |
| 通膨率 | Inflation Rate | 物價指數一年的變動百分比。 |
| 購買力 | Purchasing Power | 同樣的錢能買到多少東西。 |
| 中央銀行 | Central Bank | 發行貨幣、管理利率與匯率、維持物價穩定的機構。 |
| 貨幣政策 | Monetary Policy | 央行用利率等工具影響經濟的做法。 |
| 名目 | Nominal | 用當時的錢計算、沒有扣掉物價變動的數字。 |
| 實質 | Real | 扣掉物價變動之後的數字。 |

## 第 10 章　GDP 與景氣

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 國內生產毛額 | Gross Domestic Product (GDP) | 一個國家一年內生產的所有最終商品與服務的總價值。 |
| 人均 GDP | GDP per Capita | GDP 除以人口。 |
| 經濟成長率 | Economic Growth Rate | 實質 GDP 一年的變動百分比。 |
| 景氣循環 | Business Cycle | 經濟好壞交替的波動。 |
| 擴張 | Expansion | 景氣循環中經濟成長的階段。 |
| 衰退 | Recession | 景氣循環中經濟萎縮的階段。 |
| 失業 | Unemployment | 想工作、在找工作，但找不到。 |
| 失業率 | Unemployment Rate | 失業人數占勞動力的百分比。 |
| 勞動力 | Labor Force | 有工作的人加上正在找工作的人。 |
| 景氣燈號 | Business Indicator Lights | 用紅、黃紅、綠、黃藍、藍五種燈號表示景氣好壞。 |

## 第 11 章　政府與稅

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 政府 | Government | 提供公共財、制定規則、收稅與重分配的機構。 |
| 公共財 | Public Good | 大家都能用、也很難阻止別人用的東西，例如路燈。 |
| 外部性 | Externality | 一個人的行為影響到沒參與交易的別人，例如污染。 |
| 稅 | Tax | 政府依法向人民與企業收的錢。 |
| 所得稅 | Income Tax | 依收入課的稅。 |
| 營業稅 | Business Tax / VAT | 買東西時含在價格裡、由商家代收的稅，台灣是 5%。 |
| 累進稅率 | Progressive Tax | 收入越高，稅率越高。 |
| 統一發票 | Uniform Invoice | 台灣的消費憑證，上面能看到營業稅。 |
| 補貼 | Subsidy | 政府給錢鼓勵某種行為或產業。 |
| 管制 | Regulation | 政府用規定限制或要求某些行為。 |
| 財政政策 | Fiscal Policy | 政府用收稅與花錢來影響經濟的做法。 |

## 第 12 章　國際貿易與匯率

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 絕對利益 | Absolute Advantage | 同樣時間內做得比別人多。 |
| 比較利益 | Comparative Advantage | 做某樣東西的機會成本比別人低。 |
| 貿易的好處 | Gains from Trade | 依比較利益分工再交換後，總產量增加的部分。 |
| 出口 | Export | 本國生產、賣到國外的商品或服務。 |
| 進口 | Import | 國外生產、買進本國的商品或服務。 |
| 貿易餘額 | Trade Balance | 出口總值減進口總值。 |
| 貿易順差 | Trade Surplus | 出口大於進口。 |
| 貿易逆差 | Trade Deficit | 進口大於出口。 |
| 關稅 | Tariff | 政府對進口商品課的稅。 |
| 自由貿易協定 | Free Trade Agreement (FTA) | 兩國或多國互相降低關稅與貿易障礙的協議。 |
| 匯率 | Exchange Rate | 一種貨幣用另一種貨幣表示的價格。 |
| 升值 | Appreciation | 一種貨幣相對另一種貨幣變貴。 |
| 貶值 | Depreciation | 一種貨幣相對另一種貨幣變便宜。 |
| 銀行買入價 | Bid Rate | 你把外幣賣給銀行時銀行付的價格。 |
| 銀行賣出價 | Ask Rate | 你向銀行買外幣時要付的價格。 |
| 買賣價差 | Spread | 銀行賣出價與買入價的差，是換匯的隱藏成本。 |

## 第 13 章　個人理財入門

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 支出 | Expense | 花出去的錢。 |
| 儲蓄 | Saving | 收入減去支出後留下來的錢。 |
| 儲蓄率 | Saving Rate | 儲蓄占收入的比例。 |
| 投資 | Investment | 把儲蓄拿去買以後可能值更多、也可能變少的東西。 |
| 預算 | Budget | 事先決定錢怎麼分配的計畫。 |
| 先付給自己 | Pay Yourself First | 收入一到就先把儲蓄拿走，剩下的才花。 |
| 記帳 | Bookkeeping | 記錄每一筆收入與支出。 |
| 緊急預備金 | Emergency Fund | 平常不動、專門應付意外支出的錢。 |
| 風險 | Risk | 結果不確定的程度；可能賠錢的可能性。 |
| 報酬 | Return | 投入的錢賺到或賠掉的比例。 |
| 波動 | Volatility | 價格上下起伏的幅度。 |
| 分散 | Diversification | 同時持有很多不同的資產，降低單一資產出事的影響。 |
| 指數型基金 | Index Fund | 一次買進某個指數裡全部公司的基金，費用低、分散。 |
| 管理費 | Expense Ratio | 基金每年從你的資產裡收走的費用比例。 |
| 龐氏騙局 | Ponzi Scheme | 用後加入者的本金冒充獲利付給先加入者的詐騙。 |
| 槓桿 | Leverage | 借錢來投資，會同時放大賺與賠。 |
| 定期存款 | Time Deposit | 約定一段時間不領的存款，利率比活存高一點。 |
| 活期存款 | Demand Deposit | 隨時可以領的存款。 |

## 第 14 章　專題

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 每份貢獻 | Contribution Margin | 單價減每份變動成本，用來攤固定成本與賺利潤。 |
| 成本加成定價 | Cost-plus Pricing | 成本加上固定比例的利潤來定價。 |
| 損益表 | Income Statement | 列出收入、成本與利潤的表。 |
| 固定支出 | Fixed Expense | 每月金額差不多的家庭支出，例如房租。 |
| 變動支出 | Variable Expense | 每月金額不同的家庭支出，例如外食。 |
