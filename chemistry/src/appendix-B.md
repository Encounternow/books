# 附錄 B　安全總表與急救

這一頁請印出來貼在做實驗的地方。做任何實驗之前，先看 B.1 確認你的等級；出事的時候，直接翻 B.3。

> **緊急電話只有一個：119。** 有人呼吸困難、失去意識、大量出血、大面積燙傷、誤食腐蝕性物質，不要猶豫，立刻撥 119。誤食或接觸化學品但狀況穩定時，請撥打醫院毒物科諮詢專線（各大醫院網站可查），把包裝拿在手上，照著標籤唸給對方聽。

---

## B.1　安全等級的意思

| 等級 | 標示 | 意思 | 本書的例子 |
|---|---|---|---|
| ★ | 自己做 | 材料是食物等級或日用品，不加熱、不碰火、不會噴濺 | 紫高麗菜指示劑、糖的溶解、濾水器、鐵釘生鏽 |
| ★★ | 大人在場 | 有其中一項：加熱、用火、用刀、同時開好幾種清潔劑、熱的液體 | 蠟燭與倒扣杯、焦糖化、融化皂基、清潔劑 pH 排行 |
| ★★★ | 戴護目鏡且大人在場 | 會噴濺、會放熱、或用到雙氧水、漂白水 | 大象牙膏、稀釋漂白水褪色 |

不管哪一級，這六條都適用：

1. **先讀完整個實驗再開始。** 材料擺好、記錄表畫好、知道做完要怎麼收。
2. **所有容器貼標籤。** 沒標籤的液體一律當成危險品倒掉。
3. **不吃、不喝、不聞。** 實驗區不放食物飲料，要聞味道用手搧，不把鼻子湊過去。
4. **長髮綁起來，穿有袖子的衣服，不穿拖鞋。**
5. **做完洗手、擦桌、通風。**
6. **不確定就停下來問大人。** 停下來永遠不會出事。

## B.2　絕對不能混的組合

這張表在第 13 章講過，這裡再印一次。貼在清潔櫃門內側。

| 絕對不能混 | 產生什麼 | 後果 |
|---|---|---|
| 漂白水 + 任何酸（廁所清潔劑、醋、檸檬酸、檸檬汁、鹽酸） | 氯氣 Cl₂ | 黃綠色刺鼻毒氣，咳嗽、呼吸困難，密閉空間可致命 |
| 漂白水 + 氨（玻璃清潔劑、某些地板清潔劑、尿液、貓砂） | 氯胺 | 刺激眼睛與呼吸道 |
| 漂白水 + 酒精 | 氯仿等有機氯化物 | 有毒；酒精本身易燃 |
| 雙氧水 + 醋（同一密閉容器） | 過氧乙酸 | 強烈刺激眼睛與皮膚 |
| 雙氧水 + 任何東西，裝進密閉瓶 | 氧氣與壓力 | 瓶子爆開 |
| 小蘇打 + 醋，裝進密閉瓶 | 二氧化碳與壓力 | 瓶子爆開（氣體無毒，但碎片與噴濺會傷眼） |
| 發泡錠或酵母 + 雙氧水，裝進密閉瓶 | 氣體與壓力 | 同上 |
| 水管疏通劑（氫氧化鈉）+ 任何東西 | 放熱、噴濺 | 本書不用；它碰到水就發熱，碰到鋁會放氫氣 |
| 任何兩種不同品牌、不同用途的清潔劑 | 不知道 | 成分不公開，你無法預測 |

本書的規則：**一次只開一瓶；用完蓋好、沖乾淨，再開下一瓶。** 本書從頭到尾沒有任何實驗需要把漂白水和另一種東西混在一起。

還有幾樣東西「不是混」也不能做：

- 不加熱任何密閉容器（連蓋上蓋子的鍋子加小蘇打和醋也不行）。
- 不把雙氧水、漂白水、酒精放在爐火旁邊。酒精會燒，雙氧水和漂白水加熱會分解噴出。
- 不燒塑膠、保麗龍、電池。
- 不用嘴吸任何管子。
- 不自己做「大一點」的版本。書上寫 100 mL 就是 100 mL。

## B.3　出事了怎麼辦

每一種狀況都分三段：**立刻做、不要做、什麼時候要就醫**。

### 誤食（吃到或喝到不該喝的東西）

**立刻做**
1. 把嘴裡剩下的吐掉，用清水漱口幾次，不要吞。
2. 看是什麼東西：拿著包裝或瓶子。
3. 如果是**本書的 ★ 材料**（小蘇打水、醋、鹽水、糖水、紫高麗菜汁、肥皂水一小口）：喝一兩口清水，觀察。通常不會有事，但要告訴大人。
4. 如果是**清潔劑、漂白水、雙氧水、酒精、藥品、或任何不確定的東西**：立刻告訴大人，撥打醫院毒物科諮詢專線，照包裝標籤唸成分和喝了多少。對方會告訴你要不要去醫院。
5. 如果人**意識不清、呼吸困難、抽搐、嘴唇或喉嚨灼傷**：撥 119。

**不要做**
- **不要催吐**。腐蝕性的東西（漂白水、廁所清潔劑、水管疏通劑）吐出來會把食道再燒一次；泡泡類的東西（洗碗精）吐出來的泡沫會嗆進肺。
- 不要喝牛奶「解毒」。除非專線人員叫你喝。
- 不要自己判斷「應該沒事」就不說。

**要就醫**：喝到任何清潔劑或藥品、吐血、持續嘔吐、嘴巴或喉嚨痛、呼吸聲怪怪的、吃到的量不確定。

### 沾到眼睛

**立刻做**
1. 馬上到水龍頭，用**微溫或常溫的清水**沖洗眼睛**至少 15 分鐘**。頭側向沾到的那一邊，讓水從鼻子那側流向耳朵那側，才不會沖進另一隻眼睛。
2. 用手指撐開眼皮，眼球上下左右轉動，讓水沖到每一個角落。
3. 有戴隱形眼鏡的話，沖幾分鐘後把它拿掉再繼續沖。
4. 沖完 15 分鐘還痛、看不清楚、畏光：去醫院，帶著那瓶東西的包裝。

**不要做**
- 不要揉。
- 不要用手帕、衛生紙擦。
- 不要點眼藥水「中和」。
- 不要因為「只沾到一點」就少沖幾分鐘。

**要就醫**：沾到的是漂白水、清潔劑、雙氧水、酒精或任何不確定的東西（一律就醫，沖完再去）；沾到醋、鹽水、小蘇打水沖完還痛；視力模糊。

### 燙傷（熱水、熱皂基、蠟燭、焦糖、發熱的暖暖包）

**立刻做**（口訣：沖、脫、泡、蓋、送）
1. **沖**：流動的冷水沖燙到的地方 15 到 30 分鐘。水不要太冰，不要用冰塊直接敷。
2. **脫**：在水裡小心把燙到部位的衣物、手錶、戒指脫掉。黏在皮膚上的不要硬撕，剪開旁邊的布。
3. **泡**：繼續泡在冷水裡，直到不那麼痛。
4. **蓋**：用乾淨的紗布或乾淨的布輕輕蓋住。
5. **送**：下面「要就醫」的情況就去醫院。

**不要做**
- 不要塗牙膏、醬油、麻油、蘆薈、任何藥膏。
- 不要刺破水泡。
- 不要用冰塊直接敷（會凍傷）。

**要就醫**：燙傷面積比自己的手掌大；臉、手、腳、關節、生殖器燙到；皮膚變白或焦黑（這代表傷得深，反而可能不太痛）；有水泡而且很大；燙到的是化學品（熱皂基、焦糖黏在皮膚上）；小孩或老人燙傷。

### 割傷（剪寶特瓶、切皂基、碎玻璃）

**立刻做**
1. 用乾淨的布或紗布**直接壓住傷口**，壓 5 到 10 分鐘不要一直掀開看。
2. 血止住後，用清水沖掉髒東西。
3. 擦乾、貼 OK 繃或蓋紗布。
4. 如果是玻璃割的，先確認傷口裡沒有碎片。看到碎片插在裡面**不要拔**，直接去醫院。

**不要做**
- 不要倒雙氧水或酒精進傷口，會傷組織（第 13 章）。
- 不要用嘴吸。
- 不要在傷口還在流血的時候做下一個實驗。

**要就醫**：壓 10 分鐘還在流；傷口很深、看得到裡面（黃色脂肪或白色組織）；傷口在臉上或關節；是被生鏽的鐵釘刺到（可能需要打破傷風疫苗，看最近一次打是幾年前）；傷口裡有碎片。

### 吸入刺激氣體（混到漂白水、聞到氯味、大象牙膏的霧氣）

**立刻做**
1. **立刻離開那個房間**，到通風的地方或戶外。
2. 開窗，開門，讓房間通風，但**不要回去「處理」那攤東西**，等味道散掉再說。
3. 坐著慢慢呼吸。
4. 咳嗽、喉嚨痛通常幾十分鐘會好。如果呼吸困難、胸悶、嘴唇變紫、咳不停：撥 119。

**不要做**
- 不要衝回去把東西倒掉或沖掉。
- 不要關在廁所裡用水沖，水沖漂白水會讓氣體揮發更快。

**要就醫**：呼吸困難、胸痛、持續咳嗽超過一小時、本來就有氣喘的人。

### 皮膚沾到（漂白水、清潔劑、雙氧水、醋）

**立刻做**
1. 脫掉沾到的衣服。
2. 流動清水沖至少 10 分鐘。
3. 沖完用肥皂輕輕洗一次再沖。
4. 雙氧水沾到會讓皮膚暫時變白、有點刺，沖水後幾十分鐘會恢復。

**要就醫**：皮膚紅腫起水泡、沖完還持續灼痛、沾到的面積很大、沾到的是廁所清潔劑或水管疏通劑（本書不用，但家裡可能有）。

### 小火（蠟燭倒了、酒精噴到火、鍋子起火）

**立刻做**
1. 先叫大人。
2. 蠟燭火：用鍋蓋或濕布蓋住，火沒有氧氣就滅。
3. 鍋裡的油火：**關火、蓋鍋蓋**，不要用水。
4. 衣服著火：停、躺下、滾。
5. 火比一個鍋蓋大、或 10 秒內滅不掉：所有人離開房子，到外面撥 119。

**不要做**
- 油火不要用水潑（會爆開）。
- 不要搬著著火的鍋子跑。
- 不要在火旁邊用酒精噴瓶。

## B.4　急救箱該有什麼

放在做實驗的地方附近，所有人都知道在哪裡。

| 東西 | 用途 |
|---|---|
| OK 繃（各種大小） | 割傷 |
| 無菌紗布、透氣膠帶 | 止血、蓋燙傷 |
| 生理食鹽水（藥局） | 沖洗傷口與眼睛（沒有就用清水） |
| 乾淨的小毛巾 2 條 | 燙傷蓋、壓迫止血 |
| 剪刀 | 剪膠帶、剪衣物 |
| 一次性手套 | 幫別人處理傷口時戴 |
| 一張紙，寫著 | 「119」、附近醫院的名字與地址、家長電話、「醫院毒物科諮詢專線」四個字（電話當場查） |
