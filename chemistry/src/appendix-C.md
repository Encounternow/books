# 附錄 C　常見物質化學式與性質速查

這一頁是「忘了那個東西的化學式」或「這個東西到底酸的還鹼的」時翻的。分四張表：**C.1 本書會用到的物質**、**C.2 家裡有但本書刻意不用的物質**、**C.3 常見液體的 pH**、**C.4 常見物質在水裡的溶解度**。最後 C.5 是幾個計算用的常數。

分子量的算法：把化學式裡每個原子的原子量加起來（第 3 章）。常用原子量（四捨五入）：H 1、C 12、N 14、O 16、Na 23、Mg 24、Al 27、S 32、Cl 35.5、K 39、Ca 40、Fe 56、Cu 63.5、Zn 65。

## C.3　常見液體的 pH

數值是常見範圍，實際測到的會因品牌、溫度而不同。紫高麗菜指示劑的顏色附在旁邊，方便對照（第 6 章）。

| 檸檬汁 | 2–2.5 | 酸 | 紅 |
| 白醋（5%） | 2.5–3 | 酸 | 紅到粉紅 |
| 可樂 | 2.5–3 | 酸 | 粉紅 |
| 柳橙汁 | 3.5–4 | 酸 | 粉紅 |

| 黑咖啡 | 5 | 弱酸 | 紫紅 |
| 自然雨水 | 5.6 | 弱酸 | 紫紅 |
| 牛奶 | 6.5–6.8 | 接近中性 | 紫 |
| 純水 | 7 | 中性 | 紫 |
| 自來水 | 6.5–8 | 接近中性 | 紫到藍紫 |
| 海水 | 8 | 弱鹼 | 藍紫 |
| 小蘇打水 | 8.3 | 弱鹼 | 藍 |

## C.4　常見物質在水裡的溶解度

單位是「每 100 mL 的水最多能溶多少公克」（第 5 章）。

| 物質 | 0 ℃ | 20 ℃ | 60 ℃ | 100 ℃ | 趨勢 |
|---|---|---|---|---|---|
| 蔗糖 | 179 | 204 | 287 | 487 | 溫度越高溶越多，變化很大 |
| 食鹽 | 35.7 | 36.0 | 37.1 | 39.2 | 幾乎不受溫度影響 |
| 小蘇打 | 6.9 | 9.6 | 16.4 | （分解） | 溫度越高溶越多，但超過 50 ℃ 開始分解 |
| 碳酸鈣（蛋殼） | 0.001 | 0.001 | 0.001 | 0.001 | 幾乎不溶，所以是沉澱 |
| 二氧化碳（氣體） | 0.34 | 0.17 | 0.06 | 0 | 溫度越高溶越少，所以汽水要冰 |
| 氧氣（氣體） | 0.007 | 0.004 | 0.002 | 0 | 同上，熱水裡的魚會缺氧 |
