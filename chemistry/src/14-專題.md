# 第 14 章　專題

## 本章目標
- 學完你會照著「問題 → 假設 → 設計 → 做 → 記錄 → 分析 → 報告」七個步驟，把一個小問題變成一份有數據的研究。
- 學完你會分辨操縱變因、應變變因和控制變因，並設計一個「公平的比較」。
- 學完你會獨立完成四個專題中的至少兩個，每一個都有自己量到的數字和表格。
- 學完你會寫一份有標題、方法、數據、結論和誤差討論的專題報告，並在三分鐘內講清楚。

## 開場：從「好玩」到「我知道為什麼」

小祐做過第 8 章的小蘇打加醋，氣球鼓起來，他很開心。社團老師問他：「要讓氣球最大，小蘇打要放多少？」他說：「越多越好吧？」老師說：「真的嗎？你量過嗎？」

小祐回去做了五次，每次小蘇打放不同的量，醋都是 100 mL，用棉線量氣球的圓周。結果出乎他意料：小蘇打從 2 公克加到 6 公克，氣球一直變大；但加到 8 公克、10 公克，氣球幾乎沒有再大。他翻回第 7 章，算了一下，發現 100 mL 的 5% 醋大概只能「吃掉」7 公克的小蘇打，多放的都是白放。

他把五次的數據畫成一張長條圖，加上這段計算，寫成兩頁的報告。老師說：「這就是研究。你不只做了一個實驗，你回答了一個問題，而且有證據。」

前面十三章你學了物質、反應、酸鹼、速率、氧化、環境。這一章要你把它們組合起來，自己提問、自己設計、自己量、自己下結論。四個專題難度相近，你可以挑一個做，也可以全部做完。最後一節教你怎麼把它寫成報告、講給別人聽。

## 核心概念

### 研究的七個步驟

```
 ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐
 │ 問題 │─►│ 假設 │─►│ 設計 │─►│ 動手 │─►│ 記錄 │─►│ 分析 │─►│ 報告 │
 └──────┘  └──────┘  └──────┘  └──────┘  └──┬───┘  └──┬───┘  └──────┘
                          ▲                 │         │
                          └── 數據怪怪的就回頭改設計 ──┘
```

**1. 問題**：用一句能「量」的話寫出來。「哪種條件生鏽最快」可以量（看幾天出現鏽、鏽的面積），「鐵為什麼會生鏽」不能量，那是查資料的題目。

**2. 假設（Hypothesis）**：你猜答案是什麼，以及為什麼。「我猜鹽水裡的鐵釘最快生鏽，因為鹽水導電，第 9 章說生鏽是電子在跑。」猜錯沒關係，猜錯反而學得多。

**3. 設計**：決定三種變因（下一節），列材料，畫記錄表，想好「量什麼、用什麼量、量幾次」。

**4. 動手**：照設計做，中途不要臨時改條件。想改就記下來，做完再做一輪。

**5. 記錄**：當場寫，不要「等一下再補」。拍照要固定位置、距離、光線。

**6. 分析**：把數字變成表格和圖，找出趨勢，用前面章節的化學解釋它，然後老實寫出哪裡不準。

**7. 報告**：給別人看的版本，格式在本章最後一節。

### 公平的比較：三種變因

比喻：賽跑要公平，所有人要在同一條跑道、同一個時間起跑、跑同樣的距離，只能有一件事不同（誰跑得快）。實驗也一樣。

| 變因 | 意思 | 生鏽專題的例子 |
|---|---|---|
| 操縱變因（Manipulated Variable） | 你故意改變的那一件事，一次只改一個 | 鐵釘泡在哪種液體 |
| 應變變因（Responding Variable） | 你量的結果 | 幾天出現鏽、鏽的等級 |
| 控制變因（Controlled Variable） | 所有你刻意保持一樣的事 | 鐵釘的種類與大小、液體的量、溫度、光線、觀察的時間 |

一句話記住：**只改一件事，量一件事，其他全部一樣。** 如果你同時改了小蘇打的量又改了醋的溫度，氣球變大了，你不知道是誰的功勞。

另外兩個習慣讓結果更可信：

- **對照組（Control Group）**：什麼都不處理的那一組，例如泡在純水裡的鐵釘、沒加洗碗精的那瓶油水。沒有對照組，你不知道「變化」是不是本來就會發生。
- **重複與平均**：同一個條件至少做 3 次，取平均。三次的結果差很多，代表你的方法不穩，要先改方法。平均的算法：三次相加除以 3。

### 怎麼量才算「量」

「看起來比較多」不是數據。每個專題都要挑一種可以寫成數字的方法：

| 想量的東西 | 廚房裡的方法 |
|---|---|
| 氣體的多寡 | 氣球的圓周（棉線繞一圈再用尺量） |
| 泡沫的多寡 | 泡沫在量杯裡的高度（cm 或 mL 刻度） |
| 生鏽的程度 | 0 到 5 分的等級表，每天同角度拍照 |
| 顏色 | 對照色階估 pH，或和已知液體並排拍照 |
| 快慢 | 手機碼表，記「到某個狀態」花的秒數 |
| 重量變化 | 廚房秤（最好有 0.1 g） |

## 專題一：自製 pH 試紙組與全家液體地圖

### 目標
做出一組自己的 pH 試紙和色階卡，用它測出家裡至少 15 種液體的 pH，畫成一張「全家酸鹼地圖」，回答「我家哪個房間最酸、哪個最鹼」。

### 安全等級
**★ 自己做**。如果要測清潔劑，那一部分升級為 **★★ 大人在場**，並照第 13 章的規矩：不測漂白水、廁所清潔劑、水管疏通劑、玻璃清潔劑，濃的要稀釋。

### 材料
- 紫高麗菜半顆、熱水、鍋子、濾網或咖啡濾紙、碗
- 咖啡濾紙或白色濾紙 5 張（剪成 1 × 5 公分的條狀，約 40 條）
- 夾鏈袋或不透光的小罐（存放試紙）
- 白色小碟或白色湯匙、滴管
- 色階用的標準液：檸檬汁（pH 約 2）、醋（約 3）、氣泡水（約 4–5）、自來水（約 7）、小蘇打水（1 茶匙溶在 200 mL 水，約 8.5）、肥皂水（約 10）
- 可選：藥局或水族店買的市售 pH 試紙一盒，用來校正
- 薑黃粉 1 小匙（延伸用）
- 家裡的格局圖（自己畫）

### 步驟
**A. 做濃縮指示劑**
1. 紫高麗菜切碎，放進鍋子，加熱水剛好蓋過，請大人幫忙小火煮 10 分鐘，或用熱水泡 20 分鐘。
2. 濾出紫色汁液。要做試紙的話顏色要比平常濃，所以把汁再小火煮到剩一半（大人在場）。放涼。

**B. 做試紙**
3. 濾紙條一條一條浸進濃縮汁裡，泡 1 分鐘，夾起來平鋪在盤子上，放在陰涼、沒有陽光的地方晾乾（約 2 小時）。陽光和空氣會讓它變色，所以晾乾後立刻裝進夾鏈袋，擠掉空氣，放抽屜。
4. 乾的試紙應該是淡紫色或藍紫色。

**C. 做色階卡**
5. 六種標準液各倒一點在白碟上，各放一條試紙，10 秒後拿起來，貼在一張紙上，旁邊寫 pH。這張紙就是你的色階卡。如果有市售 pH 試紙，同時測一次，把真正的 pH 寫上去，你的色階就被「校正」了。
6. 色階卡拍照存起來，因為試紙貼久了會褪色。

**D. 畫全家液體地圖**
7. 畫一張家裡的平面圖（廚房、浴室、客廳、陽台……）。
8. 每個房間找 3 到 5 種液體：廚房（牛奶、醬油、可樂、果汁、茶、食用油）、浴室（洗髮精、沐浴乳、漱口水、洗手乳，各稀釋 10 倍）、客廳（礦泉水、運動飲料）、陽台（雨水、花盆裡滴出來的水）。
9. 每種液體滴一滴在試紙上，10 秒後對照色階，記錄 pH。每種測 2 次。
10. 把 pH 寫在地圖上對應的位置，酸的用紅筆、中性用黑筆、鹼的用藍筆。

| 編號 | 液體 | 房間 | 第 1 次顏色 | 第 2 次顏色 | 估計 pH | 酸／中／鹼 | 備註（是否稀釋） |
|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |  |
| … |  |  |  |  |  |  |  |

色階卡記錄：

| 標準液 | 試紙顏色 | 估計 pH | 市售試紙讀到的 pH（有的話） |
|---|---|---|---|
| 檸檬汁 |  | 2 |  |
| 醋 |  | 3 |  |
| 氣泡水 |  | 4–5 |  |
| 自來水 |  | 7 |  |
| 小蘇打水 |  | 8.5 |  |
| 肥皂水 |  | 10 |  |

### 分析
1. 算一算：15 種液體裡有幾種是酸、幾種中性、幾種鹼？算成百分比（例如 9 ÷ 15 = 60% 是酸）。
2. 哪個房間平均最酸？把同房間的 pH 相加除以種數。
3. 找規律：吃的喝的是不是大多偏酸？直接碰皮膚的是不是接近中性？用來清潔的是不是偏鹼？用第 13 章的「用相反的對付它」解釋。
4. 誤差討論：你的試紙能分辨差 1 的 pH 嗎？兩次測的結果一樣嗎？放了三天的試紙顏色有沒有變？哪些液體本身有顏色（可樂、醬油）讓你很難判斷？
5. 如果有市售試紙，比較你的色階和它差多少，寫出「我的試紙平均偏差 ± 多少」。

### 延伸
- **薑黃試紙**：薑黃粉 1 小匙泡在 2 湯匙酒精（或熱水）裡，濾出黃色液體，照同樣方法做試紙。薑黃在 pH 8 以上會從黃變紅，只對鹼有反應，是「鹼的偵測器」。用它再測一次所有液體，看看和紫高麗菜的結果合不合。
- **一週追蹤**：同一杯牛奶放在室溫，每天測 pH，看它酸化的速度（乳酸菌把乳糖變成乳酸）。
- **試紙保存實驗**：三組試紙分別放在抽屜、窗邊、冰箱，一週後各測一次自來水，比較哪一組還準。

## 專題二：哪種條件生鏽最快

### 目標
把一樣的鐵釘放在 8 種不同的環境裡 7 天，每天評分，找出哪種條件最快生鏽、哪種幾乎不生鏽，並用第 9 章的「生鏽三要素」解釋。

### 安全等級
**★ 自己做**（鐵釘尖端小心；用砂紙磨釘子時請大人示範）。

### 材料
- 一般鐵釘 8 支以上（五金行買「鐵釘」，不要買不鏽鋼或鍍鋅的；用磁鐵吸得住、表面灰黑色的那種）
- 砂紙 1 小張、洗碗精
- 一樣大小的透明杯或小玻璃罐 8 個、保鮮膜、橡皮筋
- 自來水、純水、食鹽、醋、小蘇打、沙拉油
- 乾燥劑 1 包（海苔或餅乾包裝裡的）、夾鏈袋 1 個
- 鋁箔紙 1 小片
- 標籤貼紙、手機（每天固定位置拍照）、廚房秤（可選，最好有 0.1 g）

### 步驟
1. 所有鐵釘用砂紙把表面磨亮，再用洗碗精洗掉油，擦乾。這樣每一支的起點一樣。有秤的話，每一支秤重記下來。
2. 8 個杯子貼標籤，照下表準備環境，每杯液體都是 100 mL：

| 編號 | 環境 | 做法 | 你在測什麼 |
|---|---|---|---|
| A | 乾燥空氣 | 鐵釘和乾燥劑一起放夾鏈袋，封好 | 沒有水會不會生鏽 |
| B | 純水全泡 | 釘子完全泡在純水裡 | 水 + 少量溶氧 |
| C | 自來水半泡 | 釘子一半在水裡一半露出 | 水線處同時有水和空氣 |
| D | 鹽水全泡 | 3.5 g 鹽溶在 100 mL 水（和海水差不多） | 電解質會不會加速 |
| E | 煮沸過的水 + 油封 | 水煮沸 5 分鐘放涼（趕走溶氧），放入釘子後倒 1 公分厚的沙拉油蓋住水面 | 有水但沒有氧氣 |
| F | 醋全泡 | 釘子泡在醋裡 | 酸會怎樣 |
| G | 小蘇打水全泡 | 1 茶匙小蘇打溶在 100 mL 水 | 鹼會怎樣 |
| H | 鹽水 + 包鋁箔 | 釘子用鋁箔緊緊包一半，再泡 3.5% 鹽水 | 另一種金屬能不能「犧牲」保護鐵（第 9 章） |

3. 杯口蓋保鮮膜、用橡皮筋套住，減少蒸發。全部放在同一個不會曬到太陽的地方。
4. 每天同一個時間，把杯子拿到同一個位置、同樣的光線下拍照，然後照下面的等級表給分：

| 分數 | 看到的樣子 |
|---|---|
| 0 | 完全亮，沒有變化 |
| 1 | 有一兩個小褐點 |
| 2 | 多處小點，或液體開始變黃 |
| 3 | 約一半的表面有鏽，液體明顯變色 |
| 4 | 大部分表面有鏽，有紅褐色沉澱 |
| 5 | 整支鏽掉，鏽皮剝落 |

5. 連續 7 天。第 7 天把釘子取出，用紙巾輕輕吸乾（不要擦掉鏽），有秤的話再秤一次。

### 記錄表

| 環境 | 第 1 天 | 第 2 天 | 第 3 天 | 第 4 天 | 第 5 天 | 第 6 天 | 第 7 天 | 起始重量（g） | 結束重量（g） |
|---|---|---|---|---|---|---|---|---|---|
| A 乾燥 |  |  |  |  |  |  |  |  |  |
| B 純水全泡 |  |  |  |  |  |  |  |  |  |
| C 自來水半泡 |  |  |  |  |  |  |  |  |  |
| D 鹽水 |  |  |  |  |  |  |  |  |  |
| E 無氧水 + 油封 |  |  |  |  |  |  |  |  |  |
| F 醋 |  |  |  |  |  |  |  |  |  |
| G 小蘇打水 |  |  |  |  |  |  |  |  |  |
| H 鹽水 + 鋁箔 |  |  |  |  |  |  |  |  |  |

### 分析
1. 畫一張折線圖：橫軸是天數，縱軸是分數，8 條線。或者用 ASCII 畫：

```
分數
 5 │                              D
 4 │                        D   C
 3 │                  D   C   F
 2 │            D   C   B   F
 1 │      D   C   B       F   G
 0 │ A E  B               G   H
   └──┬───┬───┬───┬───┬───┬───┬── 天
      1   2   3   4   5   6   7
      （這是示意，請畫你自己的）
```

2. 排出「生鏽速度排行榜」：通常是 D 鹽水、C 半泡 最快，F 醋 泡久了也快，B 純水 中等，G 小蘇打水 慢，A 乾燥、E 無氧、H 包鋁箔 幾乎不生鏽。
3. 用生鏽三要素（鐵、水、氧氣）解釋 A 和 E：少了水或少了氧，就不生鏽。再解釋 C 為什麼比 B 快：水線那一圈同時碰到水和空氣。
4. 解釋 D：鹽讓水變成好的導電體，生鏽其實是鐵把電子交給氧的過程（第 9 章），導電越好，電子跑得越快。這也是為什麼海邊的鐵欄杆鏽得特別快。
5. 解釋 H：鋁比鐵更容易失去電子，它先被氧化，替鐵「擋了一槍」。船底和熱水器裡真的有這種「犧牲陽極」。
6. 重量：生鏽的釘子通常會變重（鐵 + 氧 = 氧化鐵，氧的重量加上去了），但鏽掉下來會變輕。討論你量到的結果和質量守恆（第 7 章）的關係。
7. 誤差討論：釘子真的一樣嗎？評分是你一個人判斷的嗎（請家人盲評一次，比較分數）？溫度一樣嗎？

### 延伸
- **溫度**：D 鹽水再做兩杯，一杯放冰箱、一杯放室溫，比較速度（第 8 章：溫度升高反應變快）。
- **防鏽塗層比賽**：鐵釘分別塗沙拉油、指甲油、凡士林、什麼都不塗，泡鹽水 7 天。
- **包銅線**：把 H 的鋁箔換成銅線（電線剝皮），看鐵會不會反而鏽得更快。這和檸檬電池的原理相通。

## 專題三：最強發泡配方

### 目標
用小蘇打和醋，找出「產生最多氣體」和「反應最快」的配方，並用第 7 章的比例計算來預測與驗證。

### 安全等級
**★ 自己做**（★★ 如果用溫熱的醋；用發泡錠的延伸也是 ★）。只用氣球，不用蓋子，不用任何密閉容器。

### 材料
- 500 mL 空寶特瓶 5 個（同款）、氣球 10 個以上（同款、同尺寸）
- 小蘇打、白醋（標籤寫 5% 或「酸度 5」的那種）
- 廚房秤（最好有 0.1 g）、量杯、漏斗或自製紙漏斗
- 棉線、尺（量氣球圓周）
- 手機碼表
- 溫度計、冰塊、熱水（溫度組用）
- 洗碗精（泡沫組用）、1 公升量杯
- 可選：藥局買的發泡錠（維生素 C 發泡錠）

### 步驟
**實驗 3-1：小蘇打的量（操縱變因：小蘇打克數）**
1. 先算理論值。第 7 章算過：84 g 小蘇打剛好和 60 g 醋酸反應，放出 44 g 二氧化碳。100 mL 的 5% 醋大約含 5 g 醋酸，能吃掉的小蘇打是 5 × 84 ÷ 60 = 7 g。所以我們預測：小蘇打超過 7 g 之後，氣球就不會再變大。
2. 5 個寶特瓶各倒 100 mL 醋（室溫）。
3. 5 個氣球分別裝 2 g、4 g、6 g、8 g、10 g 小蘇打（用漏斗裝、用秤量）。
4. 氣球套在瓶口，先不要讓粉掉下去。準備好後，把氣球提起來讓小蘇打一次倒進去，同時按碼表。
5. 輕輕搖瓶子讓反應完全。記錄「氣球不再變大」花的秒數。
6. 用棉線繞氣球最胖的地方一圈，剪斷，用尺量，這是圓周。
7. 每個克數重複 3 次，取平均。

**實驗 3-2：溫度（操縱變因：醋的溫度）**
8. 固定小蘇打 3 g、醋 100 mL。三瓶醋分別調成約 5 ℃（冰水浴）、25 ℃（室溫）、45 ℃（溫水浴，大人在場，不要更熱），用溫度計確認。
9. 照同樣方法做，這次重點記「氣球不再變大」的秒數，以及最後圓周。

**實驗 3-3：濃度（操縱變因：醋的濃度）**
10. 固定小蘇打 1 g（刻意少放，讓醋永遠是過量的那一方）。三瓶分別是：100 mL 純醋、50 mL 醋 + 50 mL 水、25 mL 醋 + 75 mL 水。
11. 記錄秒數與圓周。

**實驗 3-4：噴泉配方（操縱變因：洗碗精的量）**
12. 1 公升量杯放 2 g 小蘇打和 0、1、2、3 湯匙洗碗精（四組），一次倒入 50 mL 醋，記錄泡沫衝到最高的刻度（mL）。這一組是「火山」要用的配方。

### 分析
1. 把實驗 3-1 的「小蘇打克數 vs 體積」畫成長條圖。你應該看到體積從 2 g 到 6 g 一路上升，到 8 g、10 g 之後幾乎平的。那個轉折點就是「醋用完了」，理論上在 7 g 附近。這叫**限量試劑（Limiting Reagent）**：誰先用完，反應就停在誰那裡。
2. 檢查理論值：1 g 小蘇打放出 44 ÷ 84 ≈ 0.52 g 二氧化碳；室溫下二氧化碳每公升約 1.8 g，所以 1 g 小蘇打最多產生 0.52 ÷ 1.8 ≈ 0.29 L = 290 mL 的氣體。2 g 就是 580 mL。你量到的氣球體積通常比這小很多，想一想為什麼（氣球本身要撐開需要壓力、一部分二氧化碳溶在液體裡、氣體在瓶子裡也佔了空間）。這種「理論值 vs 實際值」的差距，就是報告裡最好寫的一段。
3. 實驗 3-2：三組的最後圓周應該差不多（反應物一樣多），但秒數差很多，溫度越高越快。這證明溫度改變的是「速率」不是「總量」（第 8 章）。
4. 實驗 3-3：因為小蘇打只放 1 g，三組的醋都夠用，所以最後圓周應該差不多，但稀的那組比較慢：濃度影響速率。如果你把小蘇打改成 5 g，25% 那組的醋就不夠了，圓周會變小，你可以試試看並解釋。
5. 實驗 3-4：洗碗精不參與反應，它只是把二氧化碳留在泡泡裡，讓體積「看起來」變大。這是化學反應和物理現象的差別。
6. 誤差討論：氣球每一顆的鬆緊一樣嗎？棉線量圓周準嗎（量三次看差多少）？秤的精度是 1 g 還是 0.1 g？

### 延伸
- **發泡錠版本**：固定 100 mL 水，一顆發泡錠整顆、剝成四塊、磨成粉，比較氣球長到最大的秒數（表面積）。
- **預測挑戰**：用你實驗 3-1 的數據，預測「50 mL 醋配 5 g 小蘇打」會得到多大的氣球，然後做一次驗證。
- **最省錢的火山**：算出每種配方的成本（小蘇打、醋、洗碗精各多少錢），找出「每元噴最高」的配方。

## 專題四：用現成皂基做手工皂與泡沫洗手乳

### 目標
用市售的「皂基」做出自己的肥皂，調整配方（顏色、香味、加料），用專題一的試紙測它的 pH，用第 12 章的方法比較它在硬水和軟水裡的起泡力，再把皂絲變成泡沫洗手乳。

### 安全等級
**★★ 大人在場**。傳統肥皂是油脂加氫氧化鈉煮出來的，氫氧化鈉是強鹼，本書不用它。皂基是工廠已經皂化完成的肥皂，安全得多。但融化皂基需要加熱到 60 ℃ 以上，熔化的皂基像熱蠟一樣會燙傷，所以加熱、倒模要大人操作，學生戴隔熱手套。

### 材料
- 透明或白色的「皂基」（Melt & Pour Soap Base）500 g。手工藝材料行、大型文具店、網路都買得到
- 可微波的玻璃碗或量杯、或小鍋子隔水加熱用的大鍋
- 筷子或矽膠刮刀、菜刀與砧板（切皂基）
- 矽膠冰塊盒或小紙杯當模具
- 食用色素（紅、藍、黃）、香草精或食用等級的精油幾滴
- 加料：燕麥片、乾燥咖啡渣、乾燥花瓣、蜂蜜（各 1 小匙）
- 酒精噴瓶（可選，消除表面氣泡；噴的時候遠離火源）
- 廚房秤、溫度計、隔熱手套
- 專題一的 pH 試紙、肥皂起泡測試用的瓶子（第 12 章實驗 12-3）
- 泡沫壓頭瓶 1 個（網購或把用完的泡沫洗手乳瓶洗乾淨）

### 步驟
**A. 做肥皂**
1. 皂基切成 1 到 2 公分的小塊（大人示範刀法）。秤出 100 g 當一塊肥皂的量。
2. **大人操作**：小塊皂基放進玻璃碗，微波 20 秒、拿出來攪拌、再 20 秒，重複到全部融化，不要一次加熱超過 30 秒（會噴）。或者隔水加熱：皂基碗放在裝水的鍋裡小火加熱，攪拌到融化。用溫度計量，融化的皂基大約 60 到 70 ℃。
3. 離火。加 2 到 3 滴食用色素、3 到 5 滴香草精或精油，攪拌。想加燕麥或咖啡渣就現在加，1 小匙。
4. **大人操作**：倒進模具。表面有小氣泡的話，噴一下酒精（這一步沒有火源才能做）。
5. 室溫放 1 到 2 小時凝固（或冰箱 30 分鐘），脫模。
6. 用保鮮膜包好，標上配方和日期。手工皂基的皂放一兩天比較硬、比較耐用。
7. 做至少 3 種配方：例如「原味」「加燕麥」「加蜂蜜」，每種 100 g。

**B. 測試你的肥皂**
8. **pH**：每塊肥皂刨一點溶在 10 mL 溫水裡，用專題一的試紙測，記錄。
9. **起泡力**：照第 12 章實驗 12-3，刨 1 g 肥皂溶在 100 mL 水做肥皂水，分別用純水和礦泉水（硬水）各 100 mL，加 1 茶匙肥皂水，搖 20 下，量泡沫高度。
10. **去油力**：三個小碟子各塗一樣薄的一層沙拉油，分別用三種肥皂水（各 1 茶匙）加 50 mL 水泡 1 分鐘再沖掉，比較殘留的油（用手摸、對光看）。拿洗碗精做同樣的事當對照。
11. **耐用度**：每塊肥皂秤重，每天洗手一次（固定搓 20 秒），一週後再秤，算減少的百分比。

**C. 做泡沫洗手乳**
12. 刨 10 g 肥皂絲，加 100 mL 熱水（大人倒），攪拌到溶解，放涼就是「液態皂」。
13. 泡沫壓頭瓶裝 1 份液態皂加 4 份水（例如 40 mL 液態皂 + 160 mL 水），搖勻。泡沫壓頭會把稀的皂液打成泡沫。
14. 太稠壓不出來就加水；泡沫太稀就加液態皂。記錄你最後的比例。

### 分析
1. 肥皂的 pH 應該在 9 到 10，是弱鹼。說明為什麼鹼性有助於去油（第 13 章：油污偏酸，用相反的對付它），也說明為什麼有些人覺得肥皂洗完會乾（皮膚本身是弱酸，pH 約 5.5）。
2. 硬水的泡沫應該明顯比純水少，而且可能有浮渣。洗碗精在兩種水裡差不多。用第 13 章的「肥皂 vs 合成清潔劑」表解釋。
3. 添加物會不會影響泡沫和去油？燕麥和咖啡渣是「物理去角質」，不參與化學。蜂蜜可能讓肥皂比較軟、消耗比較快。
4. 耐用度：100 g 一週用掉幾公克？算一塊肥皂能用幾週。再把皂基的價格除以能做的塊數，算每塊成本，和超市肥皂比。
5. 誤差討論：每次洗手的時間和水量一樣嗎？泡沫高度用尺量，誤差 ± 幾公分？

### 延伸
- **分層皂**：第一層倒好、等表面微凝（約 15 分鐘），再倒第二種顏色，做出雙色皂。
- **皂基種類**：買一小塊「乳皂基」或「甘油皂基」，同樣配方做一次，比較透明度、硬度、泡沫。
- **連結專題二**：把一支鐵釘泡在你的肥皂水裡 7 天，看鹼性環境會不會減緩生鏽。

## 專題報告格式

一份好的報告讓「沒看過你做實驗的人」能看懂、能相信、能重做。照這個順序寫，每一段都要有：

**1. 題目**：一句話，含操縱變因和應變變因。例如「醋的溫度對小蘇打反應速率的影響」。

**2. 摘要（100 字以內）**：你做了什麼、量到什麼、結論是什麼。寫在最後，放在最前。

**3. 問題與假設**：問題一句話；假設一句話加「因為」。

**4. 材料與安全**：材料清單（含數量與規格），安全等級，誰在場，有沒有戴手套護目鏡，哪些東西刻意不用（例如「本專題不使用氫氧化鈉」）。

**5. 方法**：步驟要細到別人能照做。寫出三種變因各是什麼、每個條件重複幾次。

**6. 結果**：原始數據表（每一次的數字，不是只有平均）、平均表、一張圖（長條或折線，手畫、試算表或 ASCII 都可以）。圖要有標題、兩個軸的名稱與單位。

**7. 分析與結論**：結果說了什麼？假設對不對？用哪一章的化學解釋？回答你的問題，不要超出數據能支持的範圍（「鹽水裡生鏽最快」可以，「所有金屬在鹽水裡都會最快生鏽」不行）。

**8. 誤差與改進**：至少寫三個「哪裡不準」和「下次怎麼做更好」。這一段是老師最想看的，因為它證明你知道自己在做什麼。

**9. 延伸問題**：做完之後你想到的下一個問題。

**10. 參考資料**：你用了本書哪幾章、查了什麼網站或書。

## 本章小結

- 研究的七步：問題、假設、設計、動手、記錄、分析、報告。問題要能「量」。
- 只改一件事（操縱變因）、量一件事（應變變因）、其他全部一樣（控制變因）；要有對照組，每個條件至少做 3 次取平均。
- 專題一：紫高麗菜試紙加自製色階卡，測 15 種液體畫成全家酸鹼地圖。
- 專題二：8 種環境泡鐵釘 7 天評分，用鐵、水、氧三要素和導電解釋快慢，鋁箔可以犧牲保護。
- 專題三：100 mL 的 5% 醋大約只能反應 7 g 小蘇打，超過就是限量試劑的問題；溫度和濃度改的是速率不是總量。
- 專題四：用皂基代替氫氧化鈉做肥皂，肥皂 pH 約 9 到 10，硬水會讓它起泡變差。
- 報告十段：題目、摘要、問題與假設、材料與安全、方法、結果、分析與結論、誤差與改進、延伸、參考資料。誤差那一段最重要。
