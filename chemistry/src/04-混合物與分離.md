# 第 4 章　混合物與分離

## 本章目標

學完這一章，你會：

- 分得出「純物質」和「混合物」，並舉出廚房裡各三個例子。
- 說出均勻混合物與不均勻混合物的差別，解釋為什麼鹽水看起來「只有一種東西」。
- 說明過濾、蒸發、結晶、層析四種分離方法各自利用了物質的哪一種性質。
- 自己動手做出鹽的結晶、用咖啡濾紙濾出乾淨的水、讓彩色筆的墨水「跑」出好幾種顏色。
- 看到一個混合物時，能提出至少一種合理的分離方法。

## 開場：掉進沙子的鹽罐

週末幫忙煮晚餐，你從櫃子裡拿出鹽罐，結果手一滑，鹽罐倒在陽台的花盆旁邊，一半的鹽倒出來，混進了一些細沙和泥土。媽媽說：「算了，丟掉吧。」你卻盯著那堆灰灰白白的粉末想：鹽還是鹽，沙還是沙，它們只是「混在一起」，為什麼不能把它們分開？

你先試著用手挑，馬上放棄，顆粒太小了。那用篩子？鹽粒和沙粒差不多大，篩不出來。那……加水呢？鹽會溶在水裡，沙不會。然後把水倒掉？不行，鹽跟著水一起走了。那把水煮乾呢？

恭喜你，你剛剛在腦子裡走完了化學家分離混合物的基本思路：**找出兩種東西「不一樣的地方」，用那個不一樣來把它們分開。** 這一章我們就要把這個思路練熟，而且全部用廚房裡的東西來做。

## 核心概念

### 純物質與混合物

先回想第 3 章：水是 H₂O，每一個水分子都長得一樣；食鹽是 NaCl，每一粒都是鈉離子和氯離子排成的格子。像這種「從頭到尾只含一種物質」的東西，叫做**純物質（Pure Substance）**。純物質有固定的性質，例如純水在一大氣壓下一定是 100 °C 沸騰、0 °C 結冰，不會今天 98 °C 明天 103 °C。

把兩種以上的純物質放在一起，但彼此**沒有發生化學反應**、各自還是原來的自己，這就是**混合物（Mixture）**。海水是水加鹽加很多別的東西；空氣是氮氣、氧氣、二氧化碳和水蒸氣的混合物；一碗滷肉飯更是一大堆混合物疊在一起。

混合物最重要的特徵有兩個：

1. **比例可以隨便變。** 一杯水放一匙鹽是鹽水，放兩匙也是鹽水；但水分子裡氫和氧的比例永遠是 2：1，不能改。
2. **可以用物理方法分開。** 不需要發生化學反應，用溶解、過濾、加熱這些「不改變物質本身」的手段就能分。

| 廚房裡的東西 | 純物質還是混合物？ | 為什麼 |
|---|---|---|
| 蒸餾水 | 純物質 | 只有 H₂O |
| 自來水 | 混合物 | 水加上少量礦物質與消毒用的氯 |
| 白糖（蔗糖） | 幾乎是純物質 | 主要成分都是 C₁₂H₂₂O₁₁ |
| 沙拉油 | 混合物 | 好幾種油脂分子混在一起 |
| 小蘇打粉 | 純物質 | NaHCO₃ |
| 醋 | 混合物 | 水加上大約 5% 的醋酸 |
| 鋁箔 | 幾乎是純物質 | 鋁（Al） |
| 牛奶 | 混合物 | 水、脂肪、蛋白質、乳糖 |

### 均勻與不均勻：看得出來嗎？

把鹽放進水裡攪一攪，鹽「不見了」，整杯水每一口都一樣鹹，用放大鏡也找不到鹽粒。這種每個地方都一樣、看不出界線的混合物，叫**均勻混合物（Homogeneous Mixture）**。鹽水、糖水、醋、空氣都是。

把沙放進水裡，攪完放一下，沙沉到底部，上面是水，一眼就看得出有兩種東西。這叫**不均勻混合物（Heterogeneous Mixture）**。泥水、沙拉、有果粒的果汁都是。

有一個簡單的判斷法：**均勻混合物不管你從哪裡舀一匙，成分都一樣；不均勻混合物從上面舀和從下面舀，拿到的東西不一樣。**

```
   均勻混合物（鹽水）          不均勻混合物（沙水）
   ┌──────────┐              ┌──────────┐
   │ · · · ·  │              │          │  ← 上層幾乎是水
   │  · · · · │              │  ~  ~  ~ │
   │ · · · ·  │              │ ▒▒▒▒▒▒▒▒ │  ← 沙沉在底
   └──────────┘              └──────────┘
   每一匙都一樣鹹              上下不一樣
```

### 溶解：鹽去哪裡了？

鹽放進水裡「消失」，它沒有變成別的東西，只是被拆成一顆一顆的離子，散開在水分子之間。這個過程叫**溶解（Dissolving）**，鹽水就是一種**溶液（Solution）**。下一章會專門談溶液，這裡你只要記住兩件事：

- 溶解是物理變化，鹽還是鹽，把水弄走它就會回來。
- 不是所有東西都溶於水：鹽、糖溶，沙、麵粉、油不溶。「溶不溶」正是分離的第一個好用的差別。

### 分離的原則：找出「不一樣的地方」

每一種分離方法，背後都有一個「兩種物質不一樣的性質」。把這張表記下來，之後遇到任何混合物都能套用：

| 分離方法 | 利用什麼差別 | 廚房例子 |
|---|---|---|
| 手挑、篩網 | 顆粒大小 | 篩麵粉、撈水餃 |
| 沉澱後倒掉上層 | 密度（重的沉下去） | 洗米時倒掉混濁的水 |
| 過濾（Filtration） | 顆粒能不能穿過孔洞 | 咖啡濾紙、濾茶網 |
| 蒸發（Evaporation） | 一個會變成氣體跑掉、一個不會 | 曬鹽、熬醬汁收乾 |
| 結晶（Crystallization） | 溶解度隨溫度或水量改變 | 糖漿冷卻後長出糖晶 |
| 層析（Chromatography） | 不同物質「黏」紙和「跟水跑」的程度不同 | 彩色筆墨水分出好幾色 |
| 分層後倒出 | 不互溶且密度不同 | 油浮在湯上，用湯匙撇掉 |

### 過濾

過濾就是「讓小的通過、大的留下」。咖啡濾紙上有很多肉眼看不見的小孔，水分子、溶在水裡的鹽離子都比孔小，可以穿過去；沙粒、咖啡渣、麵粉顆粒比孔大，被擋在紙上。穿過去的液體叫**濾液（Filtrate）**，留在紙上的叫**濾渣（Residue）**。

注意一個重點：**過濾只能分開「溶解」和「不溶解」的東西。** 鹽水過濾一百次，濾液還是鹹的，因為鹽已經溶了，比孔小得多。

### 蒸發與結晶

鹽水裡的鹽濾不掉，但水可以「跑掉」。加熱或放著讓水慢慢變成水蒸氣，留下來的就是鹽。這是蒸發。

如果水跑得很慢，鹽離子有足夠的時間一顆一顆排好隊，就會長成有規則形狀的**晶體（Crystal）**。食鹽的晶體是小正立方體，用放大鏡或手機微距拍照可以看得很清楚。蒸發得越慢，晶體越大、越漂亮；用火快速煮乾，則會得到一堆細細的粉。

```
   慢慢蒸發                    快速煮乾
   ┌────────┐                  ┌────────┐
   │ ■  ■   │  大方塊晶體       │ ░░░░░░ │  細粉末
   │   ■  ■ │                  │ ░░░░░░ │
   └────────┘                  └────────┘
   離子有時間排隊                來不及排隊
```

### 層析：讓顏色跑步

一支黑色水性彩色筆的墨水，其實是好幾種色素混在一起調出來的。怎麼知道？用**層析**。

把一滴墨水點在咖啡濾紙上，讓紙的下緣碰到水。水會沿著紙往上爬（紙纖維之間的細縫會吸水），爬過墨水點的時候，把色素一起帶著走。但每一種色素「願意跟水走」的程度不同：有的很溶於水、跟紙不太黏，就跑得遠；有的不太溶、很黏紙，就跑得慢。走一段路之後，原本疊在一起的顏色就被拉開成好幾條色帶。

```
            ←── 水的前緣（最高）
   │        │
   │  ▒▒▒   │  ← 跑最遠的色素（最溶於水）
   │        │
   │  ▓▓▓   │
   │        │
   │  ███   │  ← 跑最慢的色素（最黏紙）
   │   •    │  ← 原本的墨水點
   ├────────┤  ← 鉛筆畫的起跑線
   │~~~~~~~~│  ← 水面（要低於起跑線！）
   └────────┘
```

化學家會算一個數字來描述每個色素「跑多遠」：

**跑步比例 = 色素前進的距離 ÷ 水前進的距離**

例如水爬了 8 公分，某個藍色色素爬了 6 公分，跑步比例就是 6 ÷ 8 = 0.75。同一種色素在同樣的紙和水裡，這個比例幾乎固定，所以可以拿來「認人」——兩支不同廠牌的黑筆，比一比跑步比例，就知道它們用的色素是不是一樣。

## 動手做

### 實驗 4-1：鹽水蒸發結晶

安全等級：★

**材料／工具**

- 食鹽 2 大匙
- 溫水約 100 mL（量杯量）
- 透明玻璃杯或碗 1 個
- 淺盤子（白色最好看）1 個
- 湯匙、咖啡濾紙或濾茶網
- 可選：一小段棉線、一根筷子
- 廚房秤（有的話）

**步驟**

1. 在玻璃杯裡倒入 100 mL 溫水，加入 1 大匙鹽，攪拌到完全看不見鹽粒。
2. 再加第 2 大匙，繼續攪。如果杯底開始留下攪不掉的鹽，就停止（這叫飽和，下一章會教）。
3. 用咖啡濾紙把鹽水濾一次，去掉灰塵和沒溶的鹽粒，濾液倒進淺盤子，液面高度大約 0.5 公分就好。
4. 把盤子放在窗邊不會被碰到的地方，不要加蓋，等 2～4 天。
5. 每天用手機拍一張照片，觀察盤子邊緣和底部出現的變化。
6. 進階版：另外準備一杯鹽水，把棉線一端綁在筷子上、一端垂進鹽水裡，筷子橫放在杯口，等一週，看線上長出什麼。

**你應該看到／得到**

- 第一天：盤子邊緣開始出現一圈白色小點。
- 第二、三天：盤底出現一顆顆透明或白色的小方塊，用手機微距鏡頭拍，會看到幾乎是正立方體。
- 水全乾以後，盤裡剩下的白色固體嚐起來（這是鹽，可以嚐）就是鹹的——鹽真的回來了。

**觀察與記錄**

### 實驗 4-2：咖啡濾紙救回一杯髒水

安全等級：★

**材料／工具**

- 咖啡濾紙 2～3 張，或一個漏斗加濾紙
- 透明杯子 3 個
- 水、一小匙麵粉、一小匙黑胡椒粒或洗乾淨的細沙
- 鹽 1 小匙
- 湯匙

**步驟**

1. 在第一個杯子裡倒半杯水，加入麵粉、胡椒（或沙）、鹽，用力攪拌 30 秒，做成一杯「髒水」。
2. 先靜置 2 分鐘，觀察：哪些東西沉下去了？哪些還浮著？哪些完全看不見？
3. 把咖啡濾紙摺成錐形放在第二個杯子口（或放進漏斗），慢慢把髒水倒進去，一次倒一點，不要滿出來。
4. 等濾液滴完，觀察濾紙上留下什麼、杯子裡的水長什麼樣。
5. 用乾淨的湯匙沾一點點濾液嚐嚐看（材料都是食物，所以安全）：鹹不鹹？
6. 把濾液再濾第二次，看看能不能把鹹味濾掉。

**你應該看到／得到**

- 胡椒或沙很快沉底，麵粉讓水變白濁、沉得很慢，鹽完全看不見。
- 濾紙上留下麵粉和胡椒，濾液幾乎透明。
- 濾液還是鹹的，而且不管濾幾次都一樣鹹——過濾對溶解的東西沒有用。

**觀察與記錄**

| 東西 | 靜置後在哪裡（沉底／浮著／看不見） | 被濾紙擋住了嗎 | 濾液裡還有嗎 |
|---|---|---|---|
| 麵粉 |  |  |  |
| 胡椒／沙 |  |  |  |
| 鹽 |  |  |  |

### 實驗 4-3：彩色筆的秘密配方（紙層析）

安全等級：★

**材料／工具**

- 咖啡濾紙 1～2 張，剪成寬 2 公分、長 10 公分的紙條，至少 4 條
- 水性彩色筆：黑、棕、綠、紫各一支（一定要「水性」，油性的跑不動）
- 鉛筆、尺
- 透明高杯子 1 個、筷子或鉛筆 1 支（橫放在杯口用）、膠帶
- 水

**步驟**

1. 用鉛筆（不能用原子筆，會一起跑）在每張紙條距離底端 1.5 公分處畫一條橫線，這是起跑線。
2. 用一支彩色筆在起跑線中央點一個小圓點，直徑約 3 毫米。等乾，再點一次，讓顏色夠深。每條紙用不同顏色的筆，在紙條頂端用鉛筆寫上筆的顏色。
3. 杯子裡倒水，水深約 0.5～1 公分，**一定要比起跑線低**，否則墨水會直接溶進水裡。
4. 把紙條用膠帶貼在筷子上，筷子橫放杯口，讓紙條底端剛好碰到水、起跑線在水面上方。可以一次放多條，但紙條不要互相碰到。
5. 開手機計時，看著水往上爬。每 2 分鐘拍一張照片。
6. 水爬到距離頂端 1 公分時，把紙條拿出來，馬上用鉛筆標記水的前緣位置，平放晾乾。
7. 用尺量：起跑線到水前緣的距離、起跑線到每一條色帶中央的距離，算跑步比例。

**你應該看到／得到**

- 黑筆通常會分出藍、紫、紅、黃等 3～5 種顏色，最讓人驚訝。
- 棕色常分出紅、黃、藍；綠色分出黃和藍；紫色分出紅和藍。
- 不同廠牌的黑筆分出來的顏色與順序可能不一樣。

**觀察與記錄**

| 棕 |  |  |  |  |
| 綠 |  |  |  |  |

## 用儀器看看

**廚房秤：鹽有沒有回來？**

把實驗 4-1 升級成有數字的實驗。先把空的淺盤放到廚房秤上「歸零」，再倒入濾好的鹽水，記下總重量。例如盤子歸零後顯示 60.0 g（這是水加鹽）。等全部蒸發乾了，再秤一次，假設顯示 14.4 g，那麼跑掉的水就是 60.0 − 14.4 = 45.6 g，留下的 14.4 g 就是鹽。你可以進一步算：鹽占原本鹽水的比例 = 14.4 ÷ 60.0 = 0.24 = 24%。下一章你會知道這個數字叫「重量百分濃度」。

如果你一開始就是用秤量好「50 g 水加 14 g 鹽」做的鹽水，蒸發後秤到的鹽應該非常接近 14 g。差一點點是正常的（有些鹽黏在杯子上、秤有誤差），差很多就要想想為什麼。

**量杯：水跑了多少？**

實驗 4-1 裡，每天用量杯或尺量一次水位，做成一張表。你會發現晴天跑得快、陰天跑得慢，水越少時晶體長得越快。

**溫度計：溫度和蒸發速度**

準備兩個一樣的小盤子裝一樣多的鹽水，一盤放陰涼處、一盤放窗邊陽光下，用溫度計各量一次水溫並記下來，比較哪一盤先乾。這就是第 8 章「反應速率」裡「溫度越高越快」的預告。

**手機：層析縮時與放大**

把手機架好對著層析杯，用「縮時攝影」模式錄 15 分鐘，播放時會看到顏色像賽跑一樣拉開。晾乾後用微距或放大功能拍紙條，再用相簿的「尺規」或直接拿尺對照拍，量距離更準確。鹽的晶體也可以這樣拍，你會看到一顆顆的小方塊。

## 常見錯誤與迷思

- **錯誤想法：鹽溶進水裡就「消失」或「變成水」了。** → 為什麼錯：鹽只是散成肉眼看不見的離子，重量還在，味道還在。→ 正確理解：溶解是物理變化，蒸發後鹽會原樣回來，而且秤起來重量一樣。

- **錯誤想法：鹽水用濾紙多濾幾次就會變淡水。** → 為什麼錯：溶解的鹽離子比濾紙的孔小太多了，會直接穿過去。→ 正確理解：過濾只能分「不溶」的固體；要從鹽水拿回淡水，得用蒸發再把水蒸氣冷凝回來（這叫蒸餾，第 12 章會做簡易版）。

- **錯誤想法：看起來只有一種東西，就是純物質。** → 為什麼錯：均勻混合物（鹽水、空氣、醋）也看不出界線。→ 正確理解：純物質是「只有一種分子或一種離子化合物」，不是「看起來均勻」。要用性質（例如固定的沸點）或分離實驗來判斷。

- **錯誤想法：層析時水面要蓋過墨水點，才會「洗」出顏色。** → 為什麼錯：水面蓋過墨點，色素會直接溶進杯裡的水，紙上什麼都沒有。→ 正確理解：讓水從下方慢慢「爬」過墨點，色素才會被帶著在紙上跑。

- **錯誤想法：用火把鹽水快速煮乾，可以得到比較大的鹽晶體。** → 為什麼錯：晶體要長大，離子需要時間慢慢排隊；太快只會得到細粉。→ 正確理解：蒸發越慢，晶體越大。

## 想一想

**1.** 下面哪些是純物質、哪些是混合物？冰塊、可樂、鋁箔、空氣、糖水、小蘇打粉。

<details><summary>參考答案</summary>

純物質：冰塊（H₂O）、鋁箔（Al）、小蘇打粉（NaHCO₃）。混合物：可樂（水、糖、二氧化碳、色素等）、空氣（氮氣、氧氣等）、糖水（水加糖）。

</details>

**2.** 你有一杯混了麵粉和糖的水。請寫出分成「麵粉」、「糖」、「水」三樣東西的步驟，並說明每一步利用了什麼差別。

<details><summary>參考答案</summary>

第一步：過濾，利用「麵粉不溶於水、糖溶於水」的差別，濾紙上留下麵粉，濾液是糖水。第二步：把糖水蒸發，利用「水會變成氣體跑掉、糖不會」的差別，留下糖。如果要把水也留下來，要把水蒸氣收集冷凝回來（蒸餾）。

</details>

**3.** 層析時水爬了 10 公分，紅色色素爬了 2 公分，藍色爬了 8 公分。兩種色素的跑步比例各是多少？哪一種「比較愛跟水走」？

<details><summary>參考答案</summary>

紅色：2 ÷ 10 = 0.2；藍色：8 ÷ 10 = 0.8。藍色跑步比例大，表示它比較溶於水、比較不黏紙，比較愛跟水走。

</details>

**4.** 小明說：「我把鹽水放在盤子裡三天，水全乾了，只剩下白色粉末，這是化學變化，因為水『變成』鹽了。」他哪裡想錯了？你會用什麼實驗說服他？

<details><summary>參考答案</summary>

水沒有變成鹽，水變成水蒸氣跑進空氣裡，鹽本來就在水裡，只是溶著看不見。用廚房秤：先秤鹽水總重，乾了再秤，少掉的重量就是跑掉的水；剩下的粉末重量，應該等於當初放進去的鹽。再把粉末加水，它會再度溶解變回鹽水，這也證明鹽沒有變成別的東西。

</details>

**5.（挑戰）** 古代沒有濾紙和冰箱，人們怎麼從海水得到鹽？想想看台灣西南部的「鹽田」是怎麼運作的，用這一章的方法名稱描述它。

<details><summary>參考答案</summary>

鹽田先把海水引進淺淺的池子，利用陽光和風慢慢蒸發；水越來越少，鹽的濃度越來越高，到飽和後開始結晶，鹽工再把結出來的鹽粒耙起來。這是「蒸發」加「結晶」。池子做得又淺又大，是為了增加水和空氣接觸的面積，讓蒸發更快。

</details>

**6.（挑戰）** 設計一個實驗，判斷兩支不同廠牌的黑色水性筆，是不是用了相同的色素配方。寫出材料、步驟和你會怎麼比較結果。

<details><summary>參考答案</summary>

用紙層析。把兩支筆的墨水點在同一張濾紙的同一條起跑線上、左右相隔 2 公分，一起放進同一杯水裡跑（這樣紙、水、時間完全相同）。跑完比較：分出的顏色數量、每一條色帶的顏色與順序、每一條色帶的跑步比例。如果全部一樣，配方很可能相同；如果色帶數量或比例不同，就是不同配方。

</details>

## 本章小結

- 純物質只含一種物質，性質固定；混合物由兩種以上純物質混在一起，比例可變，可用物理方法分開。
- 均勻混合物（鹽水、空氣）每個地方成分都一樣；不均勻混合物（泥水）看得出界線。
- 溶解是物理變化，溶掉的東西還在，重量不變，蒸發後會回來。
- 分離的原則：找出兩種物質「不一樣的性質」。
- 過濾分開「溶」與「不溶」；蒸發讓水跑掉留下溶質；慢慢蒸發會長出晶體；層析利用不同色素「跟水跑」的程度不同。
- 層析的跑步比例 = 色素距離 ÷ 水距離，可以用來比較不同墨水。
- 用廚房秤秤「前後重量」，是檢查「東西有沒有真的消失」最有力的方法。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 純物質 | Pure Substance | 只含一種物質，性質固定，例如水、食鹽。 |
| 混合物 | Mixture | 兩種以上物質混在一起、彼此沒有反應，可用物理方法分開。 |
| 均勻混合物 | Homogeneous Mixture | 每一處成分都相同、看不出界線的混合物，例如鹽水。 |
| 不均勻混合物 | Heterogeneous Mixture | 看得出不同部分的混合物，例如泥水。 |
| 溶解 | Dissolving | 物質散成極小的粒子均勻分布在液體中。 |
| 溶液 | Solution | 溶解後形成的均勻混合物。 |
| 過濾 | Filtration | 用有小孔的材料擋住不溶的固體、讓液體通過。 |
| 濾液 | Filtrate | 穿過濾紙的液體。 |
| 濾渣 | Residue | 留在濾紙上的固體。 |
| 蒸發 | Evaporation | 液體變成氣體跑掉，留下溶在裡面的固體。 |
| 結晶 | Crystallization | 溶解的物質慢慢排成有規則形狀的固體。 |
| 晶體 | Crystal | 粒子排列整齊、有固定形狀的固體，例如正立方體的鹽粒。 |
| 層析 | Chromatography | 利用不同物質被液體帶著走的速度不同來分離它們。 |
