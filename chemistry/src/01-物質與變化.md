## 本章目標

## 開場：早餐桌上的兩種變化

早上七點，小宜把冰塊丟進果汁裡，又把蛋打進平底鍋。十分鐘後，她發現兩件事：杯子裡的冰塊不見了，變成了水，果汁被稀釋了一點；鍋子裡原本透明、黏黏的蛋白，變成了白色、固體、有香味的煎蛋。

她想：如果把果汁再放回冷凍庫，冰塊會回來。那煎蛋呢？放回冰箱，會變回生蛋嗎？

當然不會。這兩件事看起來都是「東西變了」，但本質上完全不同。冰變成水，水還是水，只是狀態變了；蛋變成煎蛋，蛋白質的結構被熱打散、重新纏在一起，變成了**新的物質**，回不去了。

化學這門學問，核心問題就是：**物質是什麼？它怎麼變？什麼時候只是換個樣子，什麼時候是真的變成另一種東西？** 這一章我們先把這個問題想清楚，然後用溫度計和一杯醋，親眼看到兩種變化的差別。

## 核心概念

### 物質：有重量、佔空間的東西

物質（Matter）是所有「有質量、佔空間」的東西。水、鹽、空氣、鐵釘、你自己，都是物質。光和聲音不是物質，它們沒有質量，也不佔空間。

物質可以用兩種性質來認識：

- **物理性質（Physical Property）**：不用把它變成別的東西就看得出來的性質，例如顏色、氣味、硬度、熔點、沸點、會不會溶於水、會不會導電。
- **化學性質（Chemical Property）**：描述它「會不會變成別的東西」的性質，例如會不會燃燒、會不會生鏽、碰到醋會不會冒泡。

鐵釘是銀灰色、硬的、會被磁鐵吸，這些是物理性質；鐵釘放在潮濕的地方會生鏽，這是化學性質。

### 三態：粒子排得有多整齊

所有物質都是由非常小的粒子組成的（第 2 章會告訴你這些粒子叫原子和分子）。同一種物質可以是固體、液體或氣體，差別不在粒子本身，而在**粒子排得多緊、動得多兇**。

```
   固體（冰）          液體（水）           氣體（水蒸氣）
  ○ ○ ○ ○ ○          ○  ○ ○                 ○
  ○ ○ ○ ○ ○         ○ ○   ○  ○        ○            ○
  ○ ○ ○ ○ ○          ○  ○ ○  ○
  ○ ○ ○ ○ ○         ○ ○  ○   ○     ○                   ○
  排整齊、只在原地抖    擠在一起但會滑動     距離很遠、到處亂飛
```

| | 固體 | 液體 | 氣體 |
|---|---|---|---|
| 粒子距離 | 很近 | 很近 | 很遠（約十倍以上） |
| 粒子動作 | 在原地振動 | 互相滑動 | 高速直線飛、互相碰撞 |
| 有沒有固定形狀 | 有 | 沒有，隨容器 | 沒有，隨容器 |
| 有沒有固定體積 | 有 | 有 | 沒有，會充滿整個容器 |
| 能不能壓縮 | 幾乎不能 | 幾乎不能 | 可以 |

粒子為什麼會動？因為它們有**熱**。溫度越高，粒子抖得越兇。把冰加熱，粒子抖到掙脫原本整齊的位置，就變成液體；再加熱，粒子抖到直接飛出液面，就變成氣體。

### 狀態變化的六個名字

```
            融化（熔化）              汽化（蒸發／沸騰）
    固體  ──────────────►  液體  ──────────────►  氣體
          ◄──────────────        ◄──────────────
              凝固                     凝結
          ┌───────────── 昇華 ─────────────►┐
    固體  │                                 │  氣體
          └◄──────────── 凝華 ──────────────┘
```

- **融化（Melting）**：固體變液體。冰融化成水。
- **凝固（Freezing）**：液體變固體。水結成冰。
- **汽化（Vaporization）**：液體變氣體。有兩種方式：**蒸發（Evaporation）**是只在液體表面慢慢進行，任何溫度都會發生，所以晾衣服會乾；**沸騰（Boiling）**是整杯液體內部都有氣泡冒出來，只在沸點才發生。
- **凝結（Condensation）**：氣體變液體。冰飲料杯外面的水珠，是空氣裡的水蒸氣碰到冷杯子凝結出來的。
- **昇華（Sublimation）**：固體直接變氣體。乾冰（固態二氧化碳）在室溫會直接冒白煙消失，不會變成一灘液體。
- **凝華（Deposition）**：氣體直接變固體。冷凍庫內壁的霜，是水蒸氣直接結成冰。

水在一般大氣壓力下，**熔點**是 0°C，**沸點**是 100°C。這兩個數字是水的物理性質。不同物質的熔點、沸點不一樣，這也是為什麼我們能用它們來辨認物質：

| 物質 | 熔點 | 沸點 | 室溫（25°C）下的狀態 |
|---|---|---|---|
| 水 | 0°C | 100°C | 液體 |
| 沙拉油 | 約 −10°C 以下（會先變混濁） | 約 300°C | 液體 |
| 食鹽 | 801°C | 1413°C | 固體 |
| 蔗糖 | 約 186°C（同時開始分解） | 不能沸騰，先燒焦 | 固體 |
| 奶油 | 約 32–35°C | — | 固體（放在手上會融） |
| 二氧化碳 | — | −78°C（直接昇華） | 氣體 |

### 物理變化：東西還是那個東西

物理變化（Physical Change）是**物質本身沒有變，只是形狀、大小、狀態或位置變了**。冰融化、鹽溶在水裡、把紙撕成兩半、把鋁箔揉成一團，都是物理變化。

判斷方法：**變化之後，那個物質還在不在？** 冰融化後，水還在；鹽溶在水裡後，把水蒸發掉，鹽又回來了；紙撕成兩半，還是紙。物理變化通常可以用簡單的方法逆轉。

### 化學變化：變出新的物質

化學變化（Chemical Change），也叫**化學反應（Chemical Reaction）**，是**原本的物質消失，新的物質出現**。煎蛋、鐵生鏽、蠟燭燃燒、小蘇打加醋冒泡、蘋果切開變褐，都是化學變化。

化學變化後的新物質，性質和原來完全不同。醋是酸的、小蘇打是鹹鹹苦苦的，兩個混在一起之後會冒出二氧化碳氣體，剩下的液體既不像醋也不像小蘇打。而且**通常無法用簡單方法逆轉**：煎蛋不會變回生蛋，灰燼不會變回木頭。

| | 物理變化 | 化學變化 |
|---|---|---|
| 有沒有新物質 | 沒有 | 有 |
| 粒子怎麼了 | 只是距離、排列、位置變了 | 粒子被拆開、重新組合 |
| 容易逆轉嗎 | 通常容易 | 通常困難 |
| 例子 | 冰融化、糖溶解、揉鋁箔、剪頭髮 | 煎蛋、生鏽、燃燒、冒泡、蘋果變褐 |

### 四個線索：怎麼知道化學反應發生了

化學反應我們看不到粒子重新組合，但可以看到它留下的「痕跡」。有四個最常見的線索：

1. **顏色改變**：蘋果切面變褐、鐵釘變成紅棕色的鏽、紫高麗菜汁碰到檸檬變紅（第 6 章）。
2. **產生氣體**：小蘇打加醋冒泡、發泡錠在水裡嘶嘶作響、麵團發酵膨脹。
3. **溫度改變**：東西沒有被加熱卻變熱（燃燒、暖暖包），或變冷（小蘇打加醋）。
4. **產生沉澱（Precipitate）**：兩種清澈的液體混在一起，出現了固體顆粒或混濁。牛奶加檸檬汁會結塊，就是蛋白質被酸變性後沉澱。

有時候還會有第五個線索：**發光**，例如燃燒和螢光棒。

要小心：**這四個線索是「提示」，不是「證明」**。水燒開會冒泡，但那是水蒸氣，不是新物質；汽水開瓶會冒泡，那是原本溶在水裡的二氧化碳跑出來，也不是新物質。所以看到線索後，還要再問一次：**有沒有新的東西出現？**

### 小蘇打加醋：本書第一個化學反應

小蘇打的學名叫碳酸氫鈉，醋裡面讓它酸的成分叫醋酸。兩個碰在一起會這樣：

> 碳酸氫鈉 ＋ 醋酸 → 醋酸鈉 ＋ 水 ＋ 二氧化碳

用化學式寫（第 3 章會教你怎麼讀，現在先看個樣子）：

> NaHCO₃ ＋ CH₃COOH → CH₃COONa ＋ H₂O ＋ CO₂

反應前有兩種東西，反應後有三種新東西，其中二氧化碳是氣體，所以你會看到泡泡。這個反應還會**吸熱**，所以杯子會變涼一點。

**算一個例子：** 一平茶匙小蘇打大約 5 公克。超市白醋的醋酸濃度大約 5%，也就是 100 公克醋裡有 5 公克醋酸。50 毫升的醋大約是 50 公克，含 2.5 公克醋酸，照反應的比例算，它只「吃得下」大約 3.5 公克小蘇打，產生大約 1 公升的二氧化碳。所以 5 公克小蘇打倒進 50 毫升醋，反應停下來後，杯底會剩下一些沒反應完的小蘇打，就算再加小蘇打也不會再冒泡了。你在實驗 1-2 會親眼看到這件事。

## 動手做

### 實驗 1-1：冰→水→水蒸氣，用溫度計追蹤

安全等級：★★（步驟 1–4 是 ★ 可以自己做；步驟 5–7 要煮沸，大人在場）

**材料／工具**
- 冰塊 8–10 顆（冷凍庫拿出來直接用）
- 透明玻璃杯 1 個
- 料理溫度計（探針式，可量 −10°C 到 200°C）
- 手機（計時）
- 小鍋子、爐子（步驟 5 以後，大人在場）
- 紀錄表（下面）

**步驟**
1. 把冰塊倒進杯子，插入溫度計，探針要碰到冰但不要碰杯底。手機開始計時，馬上記下第 0 分鐘的溫度。剛從冷凍庫拿出來的冰可能是 −5°C 到 −15°C。
2. 每 2 分鐘記一次溫度，同時記下杯子裡的狀態：全部是冰、冰水混合、全部是水。可以用手輕輕晃杯子加快融化。
3. 當冰塊開始出水、變成冰水混合時，注意溫度計：它會停在 0°C 附近**很久不動**，就算你把杯子握在手裡加溫也一樣。這段期間繼續每 2 分鐘記一次。
4. 等最後一塊冰消失後，再記 10 分鐘，你會看到溫度開始慢慢往上爬，往室溫靠近。
5. **（大人在場）** 把水倒進小鍋，用溫度計夾在鍋邊或用手拿著，探針在水中但不碰鍋底。開小火，每 1 分鐘記一次溫度。
6. 當水開始冒大泡泡、整鍋翻滾，就是沸騰了。記下這時的溫度，然後**繼續記 3 分鐘**。你會發現就算火開大，溫度也不會超過 100°C 左右（台灣平地大約 99–100°C，高山會更低）。
7. 關火。看鍋子上方的「白煙」：它其實不是水蒸氣，是水蒸氣碰到冷空氣**凝結**成的小水滴。真正的水蒸氣是透明看不見的，就在鍋面上方 1–2 公分那段看起來「什麼都沒有」的地方。再看鍋蓋內側，上面的水珠也是凝結。

**你應該看到／得到**
- 溫度曲線有兩段「平台」：冰水混合時停在 0°C，沸騰時停在 100°C。
- 平台期間加熱，溫度不上升，熱都拿去把粒子從固體「鬆開」或從液體「踢出去」了。

```
溫度(°C)
 100 ┤                              ┌──────── 沸騰平台
     │                             /
  50 ┤                            /
     │                           /
   0 ┤      ┌────────────┐      /
     │     /   融化平台    \____/
 -10 ┤────/
     └────────────────────────────────► 時間
       冰    冰水混合      水      水→水蒸氣
```

**觀察與記錄**

| 時間（分） | 溫度（°C） | 狀態（冰／冰水／水／沸騰） | 備註 |
|---|---|---|---|
| 0 | | | |
| 2 | | | |
| 4 | | | |
| 6 | | | |
| 8 | | | |
| 10 | | | |
| 12 | | | |
| ... | | | |
| 沸騰後第 1 分 | | | |
| 沸騰後第 2 分 | | | |
| 沸騰後第 3 分 | | | |

### 實驗 1-2：小蘇打加醋，把四個線索找出來

安全等級：★（會噴一點泡沫，不要把臉湊太近）

**材料／工具**
- 小蘇打 2 平茶匙（約 10 公克，分成兩份）
- 白醋 50 毫升
- 透明杯 2 個（一個做反應、一個做對照）
- 清水 50 毫升（對照用）
- 料理溫度計
- 湯匙、托盤（接溢出的泡沫）
- 手機（錄影）

**步驟**
1. 把 50 毫升白醋倒進第一個杯子，50 毫升清水倒進第二個杯子。兩杯都用溫度計量溫度，記下來（應該差不多，都是室溫）。
2. 杯子放在托盤上，手機開始錄影。
3. 把 1 平茶匙小蘇打倒進**醋**那一杯。馬上觀察：聽聲音、看泡泡、看液體顏色變不變、聞一聞（用手搧，不要直接湊鼻子）。
4. 泡泡最旺的時候，把溫度計插進去量溫度，記下來。再用手摸杯子外面。
5. 等泡泡停了（大約 1–2 分鐘），再量一次溫度。看杯底有沒有白色粉末。
6. 再加半茶匙小蘇打到同一杯。有沒有再冒泡？冒得多不多？
7. 現在把 1 平茶匙小蘇打倒進**清水**那一杯，攪拌。有泡泡嗎？溫度變了嗎？粉末去哪了？
8. 把兩杯都放著 10 分鐘，再回來看一次。

**你應該看到／得到**
- 醋那杯：立刻嘶嘶作響、大量泡泡（線索 2：產生氣體）；溫度下降約 1–3°C，杯子摸起來涼涼的（線索 3：溫度改變）；液體從透明變成微微混濁；醋味變淡。
- 第二次加小蘇打：泡泡明顯變少或幾乎沒有，因為醋酸快用完了，杯底留下沒反應的小蘇打。
- 清水那杯：沒有泡泡、溫度幾乎不變，小蘇打慢慢溶解消失。這是**溶解**，物理變化，沒有新物質。

**觀察與記錄**

| 項目 | 醋 ＋ 小蘇打 | 水 ＋ 小蘇打 |
|---|---|---|
| 加入前溫度（°C） | | |
| 加入後最低溫度（°C） | | |
| 溫度變化（°C） | | |
| 有沒有泡泡（多／少／無） | | |
| 有沒有聲音 | | |
| 顏色或透明度變化 | | |
| 氣味變化 | | |
| 第二次加小蘇打還冒泡嗎 | | （不用做） |
| 10 分鐘後杯底有什麼 | | |
| 判斷：物理變化／化學變化 | | |

### 實驗 1-3：物理還是化學？六件小事分類

安全等級：★

**材料／工具**
- 砂糖 1 茶匙、鹽 1 茶匙、小碟子 2 個
- 鐵釘 1 根（沒鍍鋅）、小杯鹽水
- 牛奶 50 毫升、檸檬汁 1 茶匙
- 鋁箔一小張
- 蘋果 1 小片
- 透明杯 3 個、湯匙

**步驟**
1. **糖溶解**：半杯水加 1 茶匙糖，攪到看不見。這是全書唯一可以嚐的一杯，但請用**吃飯用的乾淨杯子和湯匙**另外泡，不要用實驗杯。嚐一小口：甜的。糖還在嗎？
2. **鹽水蒸發**：半杯水加 1 茶匙鹽，攪散後倒 2 湯匙到小碟子，放在窗邊曬 1–3 天。回來看碟子裡有什麼。
3. **鐵釘泡鹽水**：鐵釘放進小杯鹽水，水只淹一半，放 3–5 天。每天看一眼顏色。
4. **牛奶加檸檬汁**：牛奶倒進杯子，加 1 茶匙檸檬汁，輕輕攪一下，等 2 分鐘。看液體裡出現什麼。
5. **揉鋁箔**：把鋁箔揉成一團，再攤開。它還是鋁箔嗎？
6. **蘋果切面**：蘋果切一片，放在桌上 30 分鐘，每 10 分鐘拍一張照片。

**你應該看到／得到**
- 糖溶解、鹽水蒸發、揉鋁箔：物理變化。糖還在（甜的）、鹽回來了（碟子裡白色結晶）、鋁箔還是鋁箔。

## 用儀器看看

這一節用廚房秤、量杯、溫度計和手機，把上面實驗裡「看起來」的東西變成「數字」。

**廚房秤：冰融化前後，重量變了嗎？**
1. 把一個乾的杯子放在廚房秤上，按歸零（TARE）。
2. 放進 5–6 顆冰塊，記下重量，例如 112 g。
3. 用保鮮膜把杯口包起來（避免水蒸發掉），放到冰全部融化。
4. 再秤一次。你會得到幾乎一樣的數字（差距在 1 g 以內）。冰變成水，粒子沒有少，只是排法變了。這個「反應前後重量一樣」的想法，第 7 章會變成一條重要定律。

**量杯：水結冰會變大**
1. 用量杯量 100 毫升水，倒進一個有刻度的透明杯或直接用可冷凍的量杯，用膠帶在水面高度做記號。
2. 放進冷凍庫一晚。
3. 隔天看冰面高度：比記號高了大約 9%，也就是 100 毫升的水變成約 109 毫升的冰。這就是為什麼裝滿水的寶特瓶冷凍會脹破，也是為什麼冰會浮在水上：同樣重量的冰佔的空間比較大，比較「輕」。

**溫度計：把曲線畫出來**
把實驗 1-1 的表格數字畫成折線圖，橫軸是時間、縱軸是溫度。手畫就可以，或用手機的試算表 App：第一欄填時間、第二欄填溫度，選取兩欄後插入「折線圖」。你應該看到兩段平的。

## 常見錯誤與迷思

- **「水燒開冒的泡泡是空氣」** → 那些大泡泡是水蒸氣，是水本身變成氣體。小火剛加熱時鍋底的小泡泡才是溶在水裡的空氣被趕出來。→ 沸騰是物理變化，水還是水。
- **「水蒸氣是白色的」** → 真正的水蒸氣是透明的，看不見。鍋子上方的白煙是水蒸氣遇冷凝結成的小水滴，是液體。→ 離鍋面最近那段「看不到的」才是水蒸氣。
- **「冰的溫度一定是 0°C」** → 冷凍庫裡的冰可以是 −18°C。只有在**融化中**的冰水混合物才會停在 0°C。→ 0°C 是水的熔點，不是冰的溫度。
- **「糖溶在水裡不見了，所以是化學變化」** → 糖沒有不見，只是粒子散開混進水裡，嚐起來還是甜的，蒸發掉水就拿得回來。→ 溶解是物理變化。
- **「有泡泡就是化學反應」** → 汽水開瓶冒泡、水沸騰冒泡都不是化學反應。→ 泡泡只是線索，要再問「有沒有新物質」。
- **「化學變化一定很劇烈」** → 鐵生鏽要好幾天，蘋果變褐要半小時，都很慢。→ 快慢和是不是化學變化無關（第 8 章談速率）。
- **「冰融化後水變少了」** → 用廚房秤量就知道重量沒變，只是冰的體積比較大，看起來「比較多」。→ 比較「多少」要看重量，不要只看高度。

## 想一想

1. 把下面六件事分成物理變化和化學變化：冰淇淋融化、鐵生鏽、糖溶進咖啡、蛋煮熟、剪頭髮、蠟燭燃燒。

<details><summary>參考答案</summary>

物理變化：冰淇淋融化（狀態變了，成分沒變）、糖溶進咖啡（糖還在）、剪頭髮（還是頭髮，只是變短）。化學變化：鐵生鏽（變成紅棕色的新物質「鏽」）、蛋煮熟（蛋白質變性，回不去）、蠟燭燃燒（蠟變成二氧化碳和水蒸氣跑掉了）。

</details>

2. 實驗 1-1 裡，冰水混合的那段時間，就算你把杯子握在手裡加溫，溫度計還是停在 0°C。熱跑去哪裡了？

<details><summary>參考答案</summary>

熱被拿去「鬆開」冰裡的粒子了。固體的粒子排得很整齊、互相拉得很緊，要把它們鬆開變成可以滑動的液體，需要能量。這段時間加進去的熱都用在這件事上，沒有多餘的熱讓溫度上升。等最後一塊冰也鬆開了，熱才開始讓水變熱。沸騰時也是同樣的道理，熱拿去把粒子從液體「踢」成氣體了。

</details>

3. 實驗 1-2 小蘇打加醋之後杯子變涼，這是哪一個線索？如果有一個反應讓杯子變熱，它還算化學反應嗎？

<details><summary>參考答案</summary>

變涼是線索 3「溫度改變」。溫度改變包含變冷和變熱兩種，杯子變熱也一樣是線索，例如暖暖包、燃燒。重點是「沒有外面加熱或冷卻，溫度自己變了」，方向不重要。至於是吸熱還是放熱，第 10 章會細講。

</details>

4. 汽水打開瓶蓋，大量冒泡。這是物理變化還是化學變化？說出理由。

<details><summary>參考答案</summary>

物理變化。汽水裡的泡泡是原本在高壓下被「壓」進水裡的二氧化碳，打開瓶蓋壓力降低，二氧化碳就跑出來了。二氧化碳在開瓶前就已經存在，不是新產生的物質。這和小蘇打加醋不同，後者的二氧化碳是反應才產生的。

</details>

5. **開放挑戰：** 設計一個實驗，用廚房裡的東西證明「糖溶在水裡是物理變化」。要寫出步驟和你預期看到什麼。

<details><summary>參考答案</summary>

一種做法：秤 10 g 糖，溶進 50 mL 水，把糖水倒在平盤上，放在窗邊或用電風扇吹幾天讓水蒸發（不用加熱也可以，加熱請大人在場）。水乾了之後盤子裡會留下白色結晶，刮下來秤重，應該接近 10 g，嚐起來是甜的。糖沒有變成別的東西，只是和水分開又回來了，所以溶解是物理變化。還可以加一組對照：同樣的糖加熱到變焦糖（化學變化），冷卻後是褐色、硬的、味道不同，而且不會變回白糖。

</details>

6. **開放挑戰：** 你用廚房秤量 100 g 冰，等它融化後再秤，得到 98 g。粒子不會憑空消失，那 2 g 去哪裡了？想出至少兩個可能的原因，以及怎麼改進實驗。

<details><summary>參考答案</summary>

可能原因：(1) 融化過程中有水蒸發到空氣裡；(2) 冰塊剛拿出來時表面會凝結空氣中的水氣，第一次秤時其實多秤了一點霜或水珠；(3) 搬動杯子時濺出一點；(4) 廚房秤本身有 ±1 g 的誤差，兩次量測就可能差 2 g。改進方法：用保鮮膜封杯口避免蒸發、冰塊放進杯子後立刻秤、全程不移動杯子、換成精度 0.1 g 的秤、重複做三次取平均。

</details>

## 本章小結

- 物質是有質量、佔空間的東西，由很小的粒子組成。固體、液體、氣體的差別在粒子排得多緊、動得多兇。
- 六種狀態變化：融化、凝固、汽化（蒸發與沸騰）、凝結、昇華、凝華。狀態變化都是物理變化。
- 水的熔點是 0°C、沸點是 100°C。融化和沸騰時溫度會停住不動，因為熱被拿去改變粒子的排列。
- 物理變化：物質還是原來的物質，只是形狀、大小、狀態變了，通常容易逆轉。
- 化學變化（化學反應）：原物質消失，新物質出現，通常不易逆轉。
- 判斷化學反應的四個線索：顏色改變、產生氣體、溫度改變、產生沉澱。線索是提示，不是證明，最後要問「有沒有新物質」。
- 小蘇打加醋產生二氧化碳氣體並吸熱，是化學變化；小蘇打溶於水只是溶解，是物理變化。
- 冰融化前後重量不變，但 100 mL 的水結冰後體積約變成 109 mL。
