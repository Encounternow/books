# 附錄 A　提示詞範本集

這一份收錄 36 個可以直接複製貼上的提示詞（prompt），分成學習、寫作、程式、生活、創作五類。每一個都附用途說明，以及一個程式碼區塊，整段複製到聊天型 AI（例如 ChatGPT、Claude、Gemini）就能用。

## 怎麼用這些範本

**把【】裡的字換成你自己的內容。** 例如【主題】換成「光合作用」、【年級】換成「國二」。換完把【】也拿掉。

**四要素都在裡面。** 第 2 章講的提示詞四要素：角色（你是誰）、任務（要做什麼）、背景（我是誰、情況如何）、格式（怎麼輸出）。每一個範本都照這個結構寫，你熟了之後可以自己增減。

**不要貼真實個資。** 範本裡要你描述自己的地方，用「台灣的國中生」「國二」這種程度就夠，不要寫真實姓名、學校、班級、住址、家人的事。要貼文章或程式的時候，先檢查裡面有沒有別人的名字或資料。

**AI 的回答要查。** 尤其是學習類與生活類的範本，AI 會一本正經地說錯。數字、日期、人名、法條、醫療建議，一律用附錄 B 的方法查過再相信。

**可以疊加。** 先用一個範本開始，再用「追問」範本繼續。好的對話通常是五、六個來回，不是一問一答。

## A.1　學習類

### A1　用三種方式解釋一個概念

**用途**：一個概念聽一次沒懂，請它換三種方式講。通常第二或第三種會「對上」你的腦袋。

```
你是一位有耐心的國中老師。我是台灣的【年級】學生，老師上課講的「【概念】」我沒聽懂。
請用三種完全不同的方式解釋它：
1. 用一個生活中的比喻
2. 用一個具體的例子，帶數字或步驟
3. 用一張簡單的表格或文字圖
每一種不超過 150 字。最後問我一個問題，確認我有沒有懂。
```

### A2　出題給我練習

**用途**：學完一個單元想自己測。注意：答案要自己驗算，AI 出的題目與答案都可能錯。

```
請針對「【主題】」出【數量】題練習題，程度是台灣【年級】。
題目由易到難，前面是基本題，最後一題是應用題。
先不要給答案，等我作答後再批改。題目用編號列出。
```

### A3　批改我的答案

**用途**：接著 A2 用。要求它「一題一題講錯在哪」，而不是只給分數。

```
這是我的答案：
1. 【答案】
2. 【答案】
（依序填完）
請一題一題批改：對的打勾，錯的指出錯在哪一步、正確的想法是什麼。
最後告訴我這些錯誤有沒有共同的原因。先不要重新教，只要批改。
```

### A4　排一份學習計畫

**用途**：考試前或想自學一個主題時，請它把大目標切成每天做得完的小目標。

```
我想在【天數】天內學會「【主題】」，每天可以花【分鐘】分鐘。我現在的程度是：【一句話描述，例如「完全沒學過」或「課本看過但題目不會做」】。
請排一份計畫，用表格列出：第幾天、當天目標、當天怎麼自我檢查。
最後一天要是總複習與測驗。
```

### A5　費曼法：我講給你聽，你找漏洞

**用途**：檢查自己是不是真的懂。你用自己的話解釋，請 AI 當「聽不懂的學生」找出你講不清楚的地方。

```
我要用自己的話解釋「【概念】」。請你扮演一個完全沒學過這個東西的小學六年級學生。
聽完之後請告訴我：哪一句你聽不懂、哪裡好像跳過了一步、有沒有講錯的地方。
不要幫我重講，只要指出問題。
我的解釋是：【貼上你的解釋】
```

### A6　把筆記整理成重點與閃卡

**用途**：上課筆記雜亂時，請它整理。記得筆記裡不要有同學的名字。

```
下面是我的上課筆記，主題是「【主題】」。請幫我：
1. 整理成 5 到 8 條重點，每條一句話
2. 做成 10 張閃卡，格式是「正面：問題｜背面：答案」
只用筆記裡有的內容，不要補充筆記裡沒有的東西；如果筆記裡有看起來矛盾或不清楚的地方，請標出來問我。
筆記：【貼上筆記】
```

### A7　解釋一道我看不懂的題目（不要直接給答案）

**用途**：卡在一題上時用。重點是最後兩句，不然它會直接把答案倒給你，你還是沒學會。

```
我是台灣的【年級】學生，這一題我不會：
【貼上題目】
請不要直接給我答案。先告訴我這一題在考什麼觀念、第一步應該想什麼，然後停下來等我試。
我做一步你看一步，錯了就提示我，直到我自己算出來。
```

### A8　英文對話練習

**用途**：練英文口說或打字對話。它會配合你的程度，而且會糾正你。

```
Let's practice English conversation. I am a junior high school student in Taiwan at a beginner level.
Topic: 【主題，例如 ordering food at a restaurant】.
Rules:
1. You speak first, and keep each message under 3 sentences.
2. After each of my replies, first correct my mistakes briefly (in Chinese), then continue the conversation in English.
3. Use only simple words. If you must use a hard word, explain it in Chinese.
```

### A9　幫我讀懂一段困難的課文或文章

**用途**：社會、自然課本或新聞裡的長段落看不懂時用。要求它「分段」與「保留原意」。

```
下面這段文字我看不太懂。請：
1. 先用一句話說它在講什麼
2. 分成三到四小段，每段用國中生聽得懂的話重講一次
3. 列出裡面 3 個關鍵詞並解釋
請忠於原文，不要加入原文沒有的內容。
文字：【貼上】
```

## A.2　寫作類

### A10　腦力激盪：給我十個方向

**用途**：作文或報告題目拿到了但沒想法時用。要「量」不要「質」，之後自己挑。

```
我要寫一篇題目是「【題目】」的【作文／報告／演講稿】，給【對象，例如國中老師與同學】看，長度約【字數】字。
請給我 10 個不同的切入角度，每個用一句話描述，並說明這個角度適合什麼樣的人寫。
不要幫我寫內容，只要角度。
```

### A11　幫我把想法整理成大綱

**用途**：有一堆想法但不知道怎麼排。把零散的句子丟進去，請它排順序。

```
下面是我對「【題目】」的零散想法。請幫我整理成一份大綱：開頭、三到四個主要段落、結尾。
每個段落用一句話說明要講什麼。只用我給的想法，不要幫我補新內容；如果你覺得缺了什麼，另外列在「你可能想補充的地方」。
我的想法：【貼上】
```

### A12　當讀者給我回饋（不要改寫）

**用途**：自己寫完初稿，想知道讀起來的感覺。關鍵是「不要改寫」，保留你自己的聲音。

```
請你扮演【對象，例如一位嚴格但友善的國文老師】，讀我下面這篇文章。
請給我三點回饋：一點最好的地方、兩點最需要改的地方。每一點都要引用我的原文並說明理由。
請不要幫我改寫，也不要給我修改後的版本。我要自己改。
文章：【貼上】
```

### A13　只改錯字與文法，不改內容

**用途**：最後交出前的檢查。要求它列出「改了什麼」，而不是直接吐一篇新的。

```
請檢查下面這篇文章的錯字、標點與明顯的文法錯誤。
只改這些，不要改我的用詞、句子順序或內容。
請用表格列出：原句、修改後、修改理由。沒有錯的句子不用列。
文章：【貼上】
```

### A14　把一段話改成三種語氣

**用途**：同一件事要跟老師說、跟同學說、寫在公告上，語氣不同。看它怎麼改，學習語氣的差別。

```
下面這段話，請改寫成三種版本：
1. 正式版（給老師或長輩）
2. 輕鬆版（給同學）
3. 簡短版（放在公告或訊息，不超過 40 字）
請保留原本的意思，並在每一版後面用一句話說明你改了哪裡。
原文：【貼上】
```

### A15　幫我寫一封請求或道歉的信的骨架

**用途**：不知道怎麼開口的時候用。它給骨架，內容你自己填，這樣信才是你的。

```
我要寫一封【請求／道歉／感謝】的信給【對象，例如老師】，事情是：【一句話描述】。
請給我這封信的結構：開頭怎麼稱呼、第一段講什麼、中間講什麼、結尾怎麼收，每段用一句話說明。
每一段請留【】讓我自己填內容，不要幫我寫完整句子。
```

### A16　幫我標註「哪些地方用了 AI」

**用途**：學校作業要誠實標註時用。請它幫你回顧對話，列出它實際做過的事。

```
請回顧我們這段對話，列出你實際幫我做了哪些事（例如：給角度、整理大綱、挑出錯字）。
請用條列，每一條一句話，誠實且不要誇大，也不要漏掉。我要把這份清單寫進作業的「AI 使用聲明」。
```

## A.3　程式類

### A17　從描述寫出第一版程式

**用途**：做小專案的起點。先自己寫需求說明，再貼進去。要求它只用你會的語法。

```
我是台灣的國中生，剛學【語言，例如 Python】，只會【列出你會的，例如 變數、if、for、while、函式、串列】。
請根據下面的需求寫一個程式：
【貼上需求說明】
要求：
1. 只用我會的語法；非用不可的東西請在程式後面解釋
2. 每一段加中文註解
3. 告訴我怎麼執行、執行後應該看到什麼
```

### A18　解釋這段程式在做什麼

**用途**：拿到一段看不懂的程式（AI 寫的或別人的）。要求「逐行」與「流程圖」。

```
請解釋下面這段程式：
1. 先用三句話說它整體在做什麼
2. 逐行或逐段解釋，用國中生聽得懂的話
3. 用文字畫一個簡單的流程圖（用箭頭）
程式：
【貼上程式】
```

### A19　解釋錯誤訊息

**用途**：程式跑出一串紅字時用。把錯誤訊息完整貼上，不要只貼一半。

```
我執行程式時出現這個錯誤訊息：
【完整貼上錯誤訊息】
程式是：
【貼上程式】
請告訴我：
1. 這個錯誤訊息是什麼意思（翻成白話）
2. 最可能出錯的是哪一行、為什麼
3. 怎麼修。請只給我需要改的那幾行，不要重寫整個程式
```

### A20　加一個功能，只改需要改的地方

**用途**：程式穩定後要加功能。重點是「不要重寫」，否則你要重新讀一次整個程式。

```
下面的程式目前可以正常運作：
【貼上程式】
我想加一個功能：【描述功能】
請只修改需要改的地方，標出哪幾行是新的或改過的，並說明為什麼這樣改。不要重寫整個程式。
```

### A21　幫我想測試案例

**用途**：程式「可以跑」不代表「都對」。請它幫你想使用者可能怎麼亂用。

```
下面是我的程式與它的功能說明：
功能：【一句話】
程式：【貼上】
請幫我列出至少 8 個測試案例，用表格：測試情況、輸入、預期結果。
至少要有 3 個是「使用者亂用」的情況（例如空白、亂打字、很大的數字、負數）。不要幫我跑，我自己跑。
```

### A22　程式審查

**用途**：專案完成後，請它（最好是另一個 AI）用審查者的角度看一次。它說的不一定對，自己判斷。

```
請以程式審查者的角度看下面的程式，列出：
1. 可能出錯的地方（尤其是使用者輸入奇怪東西時）
2. 可以寫得更清楚、更短的地方
3. 有沒有安全或隱私的問題（例如密碼寫死在程式裡）
每一點請指出行數並說明理由。不要重寫程式。
程式：【貼上】
```

### A23　教我一個新語法，用我現在的專案當例子

**用途**：想學「函式」「字典」「迴圈裡的 break」這類東西時，請它用你正在做的程式當例子，比抽象教學好懂。

```
請教我【語法或概念，例如「函式」】。
我正在做這個程式：【貼上】
請先用兩句話說這個東西是什麼、什麼時候用，然後示範怎麼把它用在我的程式裡（只改一小段），最後出一題小練習讓我自己改。
```

## A.4　生活類

### A24　幫我做一份清單

**用途**：出遊、露營、搬教室、辦活動前列清單。它列得全，但你要自己判斷適不適合。

```
我要【做的事，例如「去三天兩夜的學校露營」】，情況是：【補充條件，例如「山上、會下雨、沒有電」】。
請幫我列一份要帶的東西與要先做的事的清單，分成「一定要」「最好有」「可以不用」三類。
每一項用一句話說為什麼。
```

### A25　幫我規劃一天的時間

**用途**：考試週或暑假想把時間排好。給它你固定的事，請它排剩下的。

```
請幫我排【日期或「明天」】的時間表。
固定的事：【例如 08:00–16:00 上課、18:30 晚餐、22:30 睡覺】
想做的事：【例如 複習數學 1 小時、運動 30 分鐘、看小說】
請用表格列出時段與事情，每 90 分鐘安排一次 10 分鐘休息。只排我列的事，不要加別的。
```

### A26　看懂一份說明書或規定

**用途**：家電說明書、比賽規則、學校公告，太長看不懂時用。要求它「指出哪一條」方便你回去對照。

```
下面是一份【說明書／規定／公告】，請幫我：
1. 用五句話說它最重要的事
2. 列出「我一定要做」和「我不能做」的事，各自用條列
3. 每一條後面標出它在原文的哪一段，方便我回去對照
不要加入原文沒有的內容。
原文：【貼上】
```

### A27　幫我比較幾個選擇

**用途**：買東西、選社團、選課時用。注意：價格與規格一定要自己查，它給的數字常常過時或錯誤。

```
我在考慮【選項 A】、【選項 B】、【選項 C】，用途是【描述】，我最在意的是【例如 價格、好不好學、耐不耐用】。
請用表格比較它們，欄位是我在意的那幾項。
如果某個欄位你不確定或可能已經過時，請在格子裡標「需查證」，不要猜。
最後不要幫我決定，只要告訴我每個選項最適合什麼樣的人。
```

### A28　把一段錄音逐字稿整理成重點

**用途**：第 7 章學過用語音轉文字整理上課內容。轉出來的文字很亂，請它整理。逐字稿裡若有同學的名字，先刪掉。

```
下面是一段上課錄音的逐字稿，語音辨識可能有錯字。請：
1. 整理成條列重點（5 到 10 條）
2. 列出老師說「會考」「很重要」「記起來」的地方
3. 標出你覺得辨識可能錯的字，用【？】標記，不要擅自猜
逐字稿：【貼上】
```

### A29　和家人討論事情前先練習

**用途**：想跟家長談手機時間、零用錢、出去玩，先讓 AI 扮演家長幫你練。練完去跟真的家人談。

```
我想跟家長談【事情，例如「把手機使用時間延長 30 分鐘」】。請你扮演一位關心但有點擔心的家長，我來練習怎麼說。
規則：你每次只說兩三句，要問我實際的問題；我講得不清楚或只有情緒的時候，請直接指出來。
練習結束後，給我三點建議。
```

### A30　幫我判斷這則訊息是不是詐騙

**用途**：收到奇怪的訊息（中獎、客服、帳號異常）時用。AI 可以幫你看出常見手法，但最後要用第 9 章的方法確認：直接打官方電話或問家長。

```
我收到這則訊息，不確定是不是詐騙：
【貼上訊息內容，把裡面的電話、連結、人名先用 X 代替】
請告訴我：
1. 裡面有哪些常見的詐騙特徵（例如製造急迫感、要求點連結、要求提供個資）
2. 我應該怎麼確認，而不是直接相信你的判斷
不要幫我回覆這則訊息。
```

## A.5　創作類

### A31　圖像生成的提示詞骨架

**用途**：第 7 章的圖像四要素：主體、風格、構圖、不要的東西。先用這個骨架寫，再一次改一項。

```
【主體：一隻戴著眼鏡的橘貓坐在書桌前】，
【風格：水彩插畫、柔和、明亮】，
【構圖：正面、中景、背景是書架、暖色燈光】，
【用途：班級讀書會海報】。
不要出現：文字、真實人物的臉、浮水印。
```

### A32　故事大綱生成器

**用途**：寫小說或劇本的開頭。要求它給「選項」而不是直接寫完，故事才是你的。

```
我想寫一個【類型，例如 校園推理】短篇故事，主角是【一句話描述】，大約【字數】字。
請給我三個不同的故事大綱，每個包含：開頭的狀況、中間的轉折、結尾。每個大綱不超過 100 字。
不要幫我寫正文。
```

### A33　幫我的角色設計背景

**用途**：故事、漫畫、桌遊裡的角色需要更立體時用。

```
我有一個角色：【名字（用假名）、年齡、身分】。請幫我設計：
1. 三個性格特點，每個附一個會表現出這個特點的小動作
2. 一個他最害怕的事
3. 一個他的小祕密
4. 他說話的口頭禪或習慣
請用表格，每格不超過 30 字。
```

### A34　寫歌詞或詩的韻腳幫手

**用途**：自己寫了幾句，押韻卡住。請它給韻腳與詞語，不要請它整首寫完。

```
我在寫一首【歌／詩】，主題是「【主題】」，目前寫到：
【貼上你的句子】
下一句我想押「【韻，例如 ㄤ】」的韻，請給我 10 個這個韻的詞，並說明哪幾個跟主題比較搭。
不要幫我寫下一句。
```

### A35　幫我設計一個小遊戲的規則

**用途**：桌遊、班級活動、派對遊戲的規則設計。先給限制，它才不會天馬行空。

```
我想設計一個【人數】人玩的【桌遊／團康遊戲】，時間【分鐘】，只能用【材料，例如 一副撲克牌和紙筆】。
主題是「【主題】」。
請給我：遊戲目標、準備、每回合做什麼、怎麼算贏，以及 2 個可能出現的規則漏洞與怎麼補。
規則總長不超過 300 字。
```

### A36　把我的想法變成簡報大綱

**用途**：要上台報告時用。只要骨架與每頁一句話，內容自己做。

```
我要做一份【分鐘】分鐘的簡報，主題是「【主題】」，聽眾是【對象】。
請給我簡報大綱：每一頁的標題與這一頁要講的一句話，總共不超過【頁數】頁。
第一頁是開場問題，最後一頁是「所以呢」（結論與行動）。
不要幫我寫講稿，也不要寫每一頁的完整內容。
```

## 最後提醒

- 這 36 個只是起點。用過幾次後，把最好用的改成你自己的版本，存在一份文件裡，這就是你的「提示詞工具箱」。
- 每個範本的最後一兩句（「不要幫我寫」「不要重寫整個程式」「不要直接給答案」）是故意的。少了這幾句，AI 很容易把事情整個做掉，你就少了學到的機會。
- 範本再好，AI 還是會錯。學習類的答案要驗算、生活類的數字要查證、程式類的輸出要測試，沒有例外。
