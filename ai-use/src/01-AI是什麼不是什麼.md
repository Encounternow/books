# 第 1 章　AI 是什麼、不是什麼

## 本章目標

學完這一章，你會：

- 用一張同心圓圖說出 AI、機器學習、生成式 AI、聊天型 AI 的關係。
- 用一句話解釋聊天型 AI 在做什麼：預測下一個字，而不是查資料、也不是思考。
- 列出聊天型 AI 擅長的三件事與不擅長的三件事。
- 說出「幻覺」是什麼、為什麼會發生，並親手讓 AI 產生一次幻覺。
- 養成第一個習慣：問完 AI 之後，先問自己「這件事我能查證嗎」。

## 開場：那個「很懂」的朋友

小晴的社會科報告要寫自己學校的歷史。她打開聊天型 AI，輸入「XX 國中是哪一年創立的？第一任校長是誰？」。

AI 馬上回答：「XX 國中創立於 1968 年，第一任校長為陳〇〇先生，創校初期僅有六個班……」語氣平穩，細節豐富，連創校初期有幾個班都寫出來了。小晴鬆了一口氣，複製貼上，報告交出去。

兩天後老師把報告退回來，上面寫著：「本校是 1983 年創立的，校史室牆上就有寫。陳〇〇是誰？」

小晴很困惑。AI 回答得那麼有把握，為什麼會錯？它是在騙她嗎？它為什麼不說「我不知道」？

這一章要回答的就是這個問題。等你知道 AI 到底是什麼東西、它在你的問題後面到底做了什麼事，你就會明白：它沒有在騙小晴，它只是在做它唯一會做的那件事——把句子接下去。

## 核心概念

### 一張同心圓：AI、機器學習、生成式 AI、聊天型 AI

「AI」這個詞被用得太廣了，先把幾個名字排好。

```
┌─────────────────────────────────────────────────┐
│ 人工智慧 AI                                      │
│   讓電腦做「看起來需要智慧」的事                   │
│  ┌──────────────────────────────────────────┐   │
│  │ 機器學習 Machine Learning                 │   │
│  │   不寫死規則，從大量例子裡自己學規律         │   │
│  │  ┌───────────────────────────────────┐   │   │
│  │  │ 生成式 AI Generative AI            │   │   │
│  │  │   學完之後能「產生」新的文字、圖、聲音 │   │   │
│  │  │  ┌────────────────────────────┐   │   │   │
│  │  │  │ 聊天型 AI（大型語言模型）    │   │   │   │
│  │  │  │  ChatGPT、Claude、Gemini…  │   │   │   │
│  │  │  └────────────────────────────┘   │   │   │
│  │  └───────────────────────────────────┘   │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

- **人工智慧（Artificial Intelligence, AI）**：最外圈，泛指「讓電腦做看起來需要智慧的事」。下棋程式、垃圾郵件過濾、手機的人臉解鎖、導航 App 算最短路線，都算。
- **機器學習（Machine Learning）**：AI 裡的一種做法。不是由人寫下所有規則，而是餵電腦大量例子，讓它自己找出規律。例如給它一萬張「貓」和一萬張「狗」的照片，它自己學會分辨。
- **生成式 AI（Generative AI）**：機器學習裡比較新的一群，特色是學完之後能**產生**新的東西：寫一段文字、畫一張圖、合成一段聲音。
- **聊天型 AI**：生成式 AI 裡專門處理文字的那一種，背後是**大型語言模型（Large Language Model, LLM）**。ChatGPT、Claude、Gemini 都是，它們能跟你一來一往地對話。

所以當有人說「AI 會取代人類」或「AI 很笨」時，先問一句：你說的是哪一圈？本書講的幾乎都是最內圈的聊天型 AI。

### 它在做什麼：預測下一個字

來玩一個接龍。我說「台灣最高的山是玉」，你接什麼？

你會接「山」。不是因為你去查了地圖，是因為你讀過太多次「玉山」，腦中「玉」後面接「山」的機率高得不得了。

聊天型 AI 做的事，本質上就是這個接龍，只是規模大到難以想像。它在訓練時讀過的文字量，相當於幾百萬本書、大半個網路。它從這些文字裡學到的，不是「事實」，而是「什麼字後面通常接什麼字」。當你輸入一個問題，它就從你的問題開始，一次接一個字（嚴格說是一個「詞元」），接出一整段回答。

| 你輸入 | 它看到的 | 它接出來的 |
|---|---|---|
| 台灣最高的山是 | 「台灣最高的山是」後面最常接什麼？ | 玉山，海拔約 3,952 公尺。 |
| 請用一句話介紹光合作用 | 「請用一句話介紹光合作用」這種句子後面通常接什麼？ | 光合作用是植物利用陽光、水和二氧化碳製造養分並放出氧氣的過程。 |
| XX 國中是哪一年創立的 | 「XX 國中是哪一年創立的」後面通常接什麼？ | XX 國中創立於 19〇〇 年……（接出一個「像答案的句子」） |

注意第三列。它沒讀過 XX 國中的校史，但它讀過幾千篇「〇〇國中創立於〇〇年」的句子，所以它知道這種問題的答案「長什麼樣子」，然後就接出一個長得很像的答案。這不是說謊，是接龍。

這樣的接龍為什麼能接得像在思考、像在推理？這背後有很多精巧的設計（注意力機制、幾千億個參數、人類回饋訓練），《AI 怎麼運作》（ https://book.vichuang.tw/ai-theory/ ）第 11、12 章用紙筆與程式一步步建給你看。本書你只要記住一句話：**它在預測合理的下一個字，不是在查資料。**

### 幻覺：一句話版

**幻覺（Hallucination）**就是 AI 一本正經地說出不存在或錯誤的東西：編一本沒有人寫過的書、一條不存在的法條、一個錯的日期、一段某名人「說過」但其實沒說過的話。

為什麼會發生？因為接龍機器的任務是「接出合理的句子」，不是「接出正確的句子」。它沒有一個「資料庫」可以去對答案；當你問的事情它讀過很多（像玉山），接出來的通常是對的；當你問的事情它沒讀過、或讀過的很少很亂（像你學校的校史、一個冷門的小人物），它還是會接，接出一個「看起來最像答案」的句子。它不會停下來說「等等，這我沒把握」——除非它被訓練成那樣，而且就算被訓練過，也只是「比較常」說不知道，不是「一定」。

這裡有一個常見的誤會要先拆掉：**AI 回答的語氣多有把握，跟答案對不對沒有關係。** 它編出來的校史和它答對的玉山，用的是同一種平穩篤定的語氣，因為它學到的就是「回答問題的句子長這樣」。你不能用「它講得很確定」來判斷真假。

順帶一提，現在有些聊天型 AI 可以「連網搜尋」，會先找幾個網頁再回答。這確實能減少一些幻覺，但它可能搜到錯的網頁、看錯網頁內容、或在整理時又接龍接錯。第 3 章會教你怎麼對付。

### 它能做什麼、不能做什麼

既然它是接龍機器，它擅長與不擅長的事就很好猜：凡是「接得像就等於做得好」的事，它很強；凡是「必須正確」的事，它需要你盯著。

| 它很擅長（接得像 = 做得好） | 它需要你盯著（必須正確） |
|---|---|
| 解釋一個概念，換三種方式講到你懂 | 說出具體的日期、數字、統計 |
| 幫你潤稿、換語氣、縮短、翻譯 | 引用某本書、某篇文章、某條法律 |
| 腦力激盪、列出十個點子、列大綱 | 關於某個特定的人、公司、學校的事實 |
| 出練習題、當對話練習對象 | 醫療、法律、金錢上的建議 |
| 寫程式草稿、解釋錯誤訊息 | 計算（它可能算錯，尤其是多位數與多步驟） |
| 把一段亂七八糟的筆記整理成條列 | 「最新」的事：它的知識有截止日期 |

右邊那一欄不是「不能問」，而是「問完要查」。第 3 章會給你一份「絕對要查」的清單。

### 它不是人

最後一件事，也許是最重要的一件。

聊天型 AI 會說「我覺得」、「我很樂意幫你」、「這個問題問得很好」。它看起來有情緒、有意見、記得你。但這些都是接龍接出來的：它學過人類對話的樣子，所以它接出來的句子就有人類對話的樣子。

它沒有想法，沒有立場，對你沒有感覺；它不知道今天是幾號（除非系統告訴它）；大部分情況下，你關掉這個對話，它就不記得你說過什麼。它的禮貌是訓練出來的，它的「道歉」也是。

這不是在貶低它。一個接龍機器能做到這樣，已經是人類工程史上很驚人的成就，而且它真的很有用。但「很有用的工具」與「會思考的人」是兩回事，把它當人，你就會像小晴一樣，相信它說的每一句話。

## 動手做

### 活動 1-1：問它三個你知道答案的問題

**材料／工具**：一個聊天型 AI 帳號、紙筆或手機記事本。

**步驟**

1. 想三個**你百分之百知道答案**的問題，而且要有三種類型：
   - 一個很多人都知道的常識（例如「水在一大氣壓下幾度會沸騰？」）。
   - 一個需要計算的題目，答案你自己先算好（例如「37 乘以 48 是多少？」，答案是 1,776）。
   - 一個只有你身邊的人知道的事（例如「〇〇國中（寫你學校的全名）的校慶是幾月幾日？」）。
2. 把下面的提示詞貼進 AI，把括號換成你的三個問題：

```
請分別回答下面三個問題。每一題回答完，請用一句話說明你對這個答案有多大把握，以及你是怎麼知道的。

1. （常識題）
2. （計算題）
3. （只有身邊的人知道的題目）
```

3. 把它的三個答案抄到下面的表格，和你知道的正確答案比對。
4. 特別看第三題：它有沒有說「我不知道」或「我無法確認」？還是直接給了一個日期？

**你應該看到**：第一題幾乎一定對；第二題多半對，但偶爾會錯，而且錯的時候語氣一樣篤定；第三題最有趣，它可能老實說不知道，也可能給你一個具體的日期——而那個日期十之八九是編的。三題的語氣通常一樣平穩，你光看語氣分不出哪題是真的。

**觀察與記錄**

| 題目類型 | 我的問題 | 正確答案 | AI 的答案 | 對／錯 | AI 說它有多大把握 |
|---|---|---|---|---|---|
| 常識 | | | | | |
| 計算 | | | | | |
| 只有身邊的人知道 | | | | | |

### 活動 1-2：問它一個不存在的東西

**材料／工具**：同上。

**步驟**

1. 編一個**不存在的東西**，要編得像真的。例如：
   - 一本不存在的書：「《月光下的電阻》這本小說」
   - 一個不存在的節日：「台灣的『海龜節』」
   - 一個不存在的科學名詞：「『逆向光合效應』」
   
   請自己編一個新的，不要用書上這三個（因為這本書也在網路上，AI 可能讀過）。
2. 先用「假設它存在」的問法貼進去：

```
請介紹《（你編的書名）》這本小說的作者、出版年份與主要劇情。
```

3. 看它的回答：它有沒有編出作者、年份與劇情？記下來。
4. 開一個**新的對話**（很重要，不要在同一個對話裡問），用第二種問法：

```
請問有一本叫《（你編的書名）》的小說嗎？如果你不確定它是否存在，請直接說不確定，不要猜。
```

5. 比較兩次的回答。

**你應該看到**：第一種問法，很多 AI 會「配合你」編出一整套作者、年份、劇情，細節豐富得像真的；第二種問法，它比較可能說「我沒有這本書的資料」。這說明兩件事：一、你的問法會影響它說不說實話（第 2 章的主題）；二、就算第二種問法它說不確定，也不代表它每次都會這麼老實。

**觀察與記錄**

| | 第一種問法（假設它存在） | 第二種問法（允許它說不確定） |
|---|---|---|
| 我編的東西 | | |
| AI 有沒有承認不確定？ | | |
| AI 編了哪些細節？（作者、年份、劇情……） | | |
| 語氣有沒有不一樣？ | | |

## 用工具看看：讓兩個 AI 回答同一題

這一章的技巧是**比較**。同一個問題丟給兩個不同的聊天型 AI（例如 ChatGPT 和 Gemini，或 Claude 和 ChatGPT），如果家裡只有一個帳號，也可以在同一個 AI 開兩個新對話問兩次。

1. 把活動 1-1 的第三題（只有身邊的人知道的那題）原封不動貼給兩個 AI。
2. 把活動 1-2 第一種問法也貼給兩個 AI。
3. 填下表。

| 問題 | AI 甲的答案 | AI 乙的答案 | 兩個答案一樣嗎？ |
|---|---|---|---|
| 校慶日期（或你的第三題） | | | |
| 不存在的書 | | | |

**你應該看到**：兩個 AI 編出來的作者、年份多半**不一樣**。這是一個非常好用的訊號：如果兩個 AI 對同一件「事實」給出不同答案，至少有一個是錯的，很可能兩個都是編的。反過來說，兩個 AI 答案一樣，也**不保證**對——它們可能讀過同一篇錯的文章。但「不一樣」是一個便宜又快速的警報器，第 3 章會把它納入正式的查證步驟。

## 常見錯誤與迷思

- **「AI 是在網路上搜尋答案給我。」** → 大部分時候不是。它是從訓練時學到的「字與字的規律」接出回答，不是即時去查。就算它有連網功能，搜到的內容也還是要經過它的接龍整理，一樣可能出錯。 → 正確理解：它是接龍機器，不是搜尋引擎；要查資料，請自己開搜尋引擎或原始網站。
- **「它講得這麼肯定，應該是真的。」** → 它編出來的答案與答對的答案用同一種語氣，因為它學的是「回答長什麼樣子」。 → 正確理解：語氣與正確性無關，判斷真假只能靠查證。
- **「它說『我不確定』，所以其他時候它說的都是確定的。」** → 它只是「有時候」會說不確定，沒說不確定的時候一樣可能錯。 → 正確理解：它的「不確定」是有用的提醒，但它的「確定」不是保證。
- **「AI 會思考，只是比人笨一點／聰明一點。」** → 它做的是機率接龍，和人腦的思考是不同的東西，沒辦法用「比人聰明幾倍」來比。 → 正確理解：它在某些事上（換十種方式解釋一個概念）比大多數人快，在另一些事上（記得你學校校慶是哪天）完全不行；是不同種類的能力，不是同一把尺上的高低。
- **「AI 記得我，它認識我。」** → 大多數情況下，關掉對話它就忘了；即使有「記憶」功能，也只是把你以前說過的話存起來再餵給它。 → 正確理解：它對你沒有認識與感情，不要因為它很親切就把不該說的事告訴它（第 9 章）。
- **「所以 AI 沒用，不要用。」** → 錯得剛好相反。接龍機器非常擅長解釋、整理、潤稿、出題、腦力激盪，這些都是學習裡很花時間的事。 → 正確理解：知道它會錯，是為了把它用得更好，不是為了不用它。

4. 活動 1-2 裡，同一個不存在的書名，用「請介紹這本書」與「如果不確定請說不確定」兩種問法，結果不同。這告訴我們什麼？這能不能完全解決幻覺？

<details><summary>參考答案</summary>

告訴我們「問法會影響 AI 說不說實話」：你在提示詞裡給它「說不確定」的選項，它接出「不確定」的機率就提高。但這不能完全解決幻覺，因為它只是「比較常」說不確定，不是「一定」；對於它誤以為自己知道的事，它還是會篤定地說錯。所以提示詞是減少幻覺的工具，查證才是最後防線。

</details>

5. 下面哪些事適合直接相信 AI 的回答，哪些一定要查證？為什麼？（a）請它把一段英文翻成中文；（b）請它告訴你某種感冒藥一天最多吃幾顆；（c）請它列出十個科展題目的點子；（d）請它說出台灣 2023 年的總人口數。

<details><summary>參考答案</summary>

（a）與（c）可以直接用：翻譯和點子屬於「接得像就等於做得好」，就算翻得不完美你也看得出來，點子好不好由你判斷。（b）與（d）一定要查：藥的劑量關係到健康，必須看藥盒或問藥師；人口數是具體數字，它可能記錯或過時，要查政府統計（內政部戶政司）。判斷標準是：錯了會不會有嚴重後果、以及答案是不是一個具體的事實或數字。

</details>

6. 開放挑戰：設計一個「讓 AI 露餡」的問題，要求是：它一定會接出一個看起來很像答案的句子，但你有辦法證明它是錯的。試三次，記錄哪一種問題最容易讓它編。

<details><summary>參考答案</summary>

開放題。通常最容易讓它編的問題有三種特徵：（1）問的是真實存在但很冷門的東西（某個小鎮的某條街何時開通）；（2）問題本身帶著錯誤的前提（「台灣的『海龜節』是幾月舉辦？」，它常會順著前提答）；（3）要求具體細節（「第幾頁」「哪一年」「誰說的」）。相對地，問很多人知道的常識，或允許它說「不確定」，就比較不容易編。你的發現會直接用在第 3 章。

</details>

## 本章小結

- AI 是最外圈，往內是機器學習、生成式 AI、聊天型 AI（大型語言模型）。本書講的幾乎都是最內圈。
- 聊天型 AI 的本質是**預測下一個字**：從你的問題開始，一個字一個字接出最合理的句子。它不是在查資料。
- 因為它接的是「合理」而不是「正確」，所以會產生**幻覺**：一本正經地說出不存在或錯誤的東西。
- 它答對和答錯時語氣一樣篤定，**不能用語氣判斷真假**。
- 它擅長解釋、潤稿、整理、出題、腦力激盪；關於日期、數字、引用、特定的人事物、醫療法律金錢，必須查證。
- 它不是人：沒有想法、沒有感情、通常不記得你。親切是訓練出來的。
- 兩個 AI 給出不同答案，是一個便宜好用的警報器；答案相同也不保證正確。
- 詳細原理請看《AI 怎麼運作》第 11、12 章；本書接下來教你怎麼用好它。
