# 附錄 D　名詞對照表

全書出現過、以及你在網路上談 AI 時常會碰到的名詞，按主題分成八組。每一條都是「中文｜英文｜一句話解釋」。想找某個詞，用瀏覽器或編輯器的搜尋功能（Ctrl + F／⌘ + F）最快。

有些英文縮寫（例如 LLM、GPT）在中文裡常常直接用英文講，表裡一起列出。

## D.1　AI 的基本概念

| # | 中文 | 英文 | 一句話解釋 |
|---|---|---|---|
| 1 | 人工智慧 | Artificial Intelligence（AI） | 讓電腦做出看起來像人在做的判斷或產出的技術總稱。 |
| 2 | 機器學習 | Machine Learning | AI 的一種做法：不寫死規則，讓電腦從大量資料裡自己找出規律。 |
| 3 | 深度學習 | Deep Learning | 機器學習的一種，用很多層的神經網路，現在的聊天型 AI 都靠它。 |
| 4 | 神經網路 | Neural Network | 一大堆簡單的數學單元連在一起，透過調整連線強度來學習。 |
| 5 | 生成式 AI | Generative AI | 會「產生」新內容（文字、圖片、聲音、程式）的 AI，不只是分類或預測。 |
| 6 | 聊天型 AI | Chatbot / AI Assistant | 用對話方式使用的生成式 AI，例如 ChatGPT、Claude、Gemini。 |
| 7 | 大型語言模型 | Large Language Model（LLM） | 用海量文字訓練出來、會預測下一個字的模型，是聊天型 AI 的核心。 |
| 8 | 模型 | Model | 訓練完成的那一大堆數字與結構，也就是「AI 本體」。 |
| 9 | 訓練 | Training | 讓模型看大量資料、反覆調整，直到它能做出想要的輸出。 |
| 10 | 訓練資料 | Training Data | 訓練時餵給模型的文字、圖片等資料，決定了模型會什麼、偏向什麼。 |
| 11 | 推論 | Inference | 模型訓練完之後，實際拿來回答問題或產生內容的過程。 |
| 12 | 預測下一個字 | Next-Token Prediction | 語言模型的基本工作：根據前面的字，猜最可能接下來的字。 |
| 13 | 詞元 | Token | 模型處理文字的最小單位，可能是一個字、半個字或一個詞。 |
| 14 | 參數 | Parameter | 模型裡可以調整的數字，數量越多通常越強，但也越耗資源。 |
| 15 | 知識截止日 | Knowledge Cutoff | 模型訓練資料的最後日期，之後發生的事它不知道。 |
| 16 | 上下文 | Context | 模型在回答時「看得到」的內容：你這段對話前面講過的所有東西。 |
| 17 | 上下文長度 | Context Window | 模型一次能記住的最大字數，超過會忘記前面的內容。 |
| 18 | 多模態 | Multimodal | 能同時處理文字、圖片、聲音、影片等多種形式的 AI。 |
| 19 | 基礎模型 | Foundation Model | 先用通用資料訓練好的大模型，之後再調整成各種用途。 |
| 20 | 微調 | Fine-tuning | 拿訓練好的模型，用少量特定資料再訓練，讓它更擅長某件事。 |
| 21 | 開源模型 | Open-Source / Open-Weight Model | 模型的數字公開讓大家下載使用，可以在自己的電腦上跑。 |
| 22 | 本地模型 | Local Model | 在你自己的手機或電腦上執行、不用連網的模型。 |
| 23 | 雲端 | Cloud | 在遠方的大型電腦上執行，你透過網路使用。多數聊天型 AI 是這樣。 |
| 24 | 演算法 | Algorithm | 解決問題的一套明確步驟，電腦照著做。 |
| 25 | 自動化 | Automation | 讓機器自己完成原本要人做的事。 |

## D.2　使用與提示

| # | 中文 | 英文 | 一句話解釋 |
|---|---|---|---|
| 26 | 提示詞 | Prompt | 你打給 AI 的指令或問題，寫得越清楚，回答越好。 |
| 27 | 提示工程 | Prompt Engineering | 研究怎麼寫提示詞才能得到想要的結果。 |
| 28 | 角色 | Role / Persona | 提示詞四要素之一：告訴 AI 它要扮演誰（老師、審查者、讀者）。 |
| 29 | 任務 | Task | 提示詞四要素之一：要它做什麼。 |
| 30 | 背景 | Context（in a prompt） | 提示詞四要素之一：你是誰、情況如何、有什麼限制。 |
| 31 | 格式 | Format | 提示詞四要素之一：要它用表格、條列、字數限制等方式輸出。 |
| 32 | 系統提示 | System Prompt | 服務或開發者預先給模型的隱藏指令，決定它的基本行為。 |
| 33 | 零樣本 | Zero-shot | 不給例子，直接要 AI 做。 |
| 34 | 少樣本 | Few-shot | 先給幾個例子，再要 AI 照著做。 |
| 35 | 思考鏈 | Chain of Thought | 要求 AI 一步一步把推理寫出來，常能減少錯誤。 |
| 36 | 追問 | Follow-up | 在同一段對話裡接著問，讓 AI 根據前面的內容修改或補充。 |
| 37 | 迭代 | Iteration | 問、看結果、改提示詞、再問，反覆幾次直到滿意。 |
| 38 | 對話 | Conversation / Chat / Thread | 一段連續的問答，AI 記得這段裡講過的事；開新對話就重來。 |
| 39 | 輸出 | Output / Response | AI 回給你的內容。 |
| 40 | 輸入 | Input | 你給 AI 的內容，包括提示詞與貼上的檔案。 |
| 41 | 溫度 | Temperature | 一個設定值，越高回答越隨機有創意，越低越固定保守。 |
| 42 | 代理 | Agent | 能自己拆解任務、使用工具、連續執行多個步驟的 AI。 |
| 43 | 工具使用 | Tool Use / Function Calling | AI 在回答過程中呼叫計算機、搜尋、程式等外部工具。 |
| 44 | 檢索增強生成 | Retrieval-Augmented Generation（RAG） | 先去查資料庫或文件，再根據查到的內容回答，減少幻覺。 |
| 45 | 上傳檔案 | File Upload | 把文件、表格、圖片給 AI 看；上傳前要檢查裡面有沒有個資。 |
| 46 | 外掛／擴充 | Plugin / Extension | 讓 AI 多一項能力的附加功能，例如連網搜尋或畫圖。 |
| 47 | 應用程式介面 | Application Programming Interface（API） | 讓程式直接和 AI 溝通的通道，寫程式的人用的。 |
| 48 | 使用額度 | Usage Limit / Quota | 一段時間內可以問幾次或用多少字，免費版通常有上限。 |

## D.3　錯誤、查證與可信度

| # | 中文 | 英文 | 一句話解釋 |
|---|---|---|---|
| 49 | 幻覺 | Hallucination | AI 一本正經地說出不存在或錯誤的內容。 |
| 50 | 編造 | Fabrication / Confabulation | 幻覺的一種：造出不存在的來源、人名、數字。 |
| 51 | 查證 | Fact-checking / Verification | 用獨立、可靠的資料確認一個說法是不是真的。 |
| 52 | 來源 | Source | 一個說法是從哪裡來的；AI 本身不是來源，它引用的資料才是。 |
| 53 | 原始資料 | Primary Source | 最源頭的資料：研究本身、官方統計、原書、當事人的紀錄。 |
| 54 | 二手資料 | Secondary Source | 轉述原始資料的東西：新聞、百科、科普文章。 |
| 55 | 交叉比對 | Cross-checking | 用兩個以上彼此獨立的來源確認同一件事。 |
| 56 | 獨立來源 | Independent Sources | 不是互相抄的來源；兩篇新聞引用同一研究只算一個。 |
| 57 | 可信度 | Credibility / Reliability | 一個來源值得相信的程度，看它是誰、有沒有審查、有沒有利益關係。 |
| 58 | 同行審查 | Peer Review | 研究發表前由其他專家檢查，是學術資料可信度的基本門檻。 |
| 59 | 把握度 | Confidence | AI 或人對一個說法有多確定；AI 的把握度可以問，但不一定準。 |
| 60 | 過時資訊 | Outdated Information | 曾經是對的、現在已經變了的資料，常見於價格、法規、職位。 |
| 61 | 偏差／偏見 | Bias | 因為訓練資料不均衡或人的成見，導致輸出偏向某一方。 |
| 62 | 錯誤資訊 | Misinformation | 不正確的資訊，不管是不是故意的。 |
| 63 | 假訊息 | Disinformation | 故意製造、用來騙人或影響人的錯誤資訊。 |
| 64 | 深偽 | Deepfake | 用 AI 做出來、看起來像真人說了或做了某事的假影片、假聲音、假照片。 |
| 65 | 反向圖片搜尋 | Reverse Image Search | 用一張圖去搜尋它最早出現在哪裡，查圖片來源的基本工具。 |
| 66 | AI 偵測工具 | AI Detector | 聲稱能判斷文字或圖片是不是 AI 做的工具，準確度有限，不能當證據。 |
| 67 | 浮水印 | Watermark | 加在內容裡的標記，用來標示來源或是否為 AI 生成。 |
| 68 | 內容標示 | AI Disclosure / Labeling | 明白說出某內容用了 AI，是誠實原則的基本要求。 |

## D.4　隱私與安全

| # | 中文 | 英文 | 一句話解釋 |
|---|---|---|---|
| 69 | 個人資料 | Personal Data / Personally Identifiable Information（PII） | 能辨認出某個人的資料：姓名、地址、電話、照片、身分證字號等。 |
| 70 | 隱私 | Privacy | 自己的資料自己決定給誰看的權利。 |
| 71 | 隱私政策 | Privacy Policy | 服務說明它會怎麼收集、使用、保存你的資料的文件。 |
| 72 | 使用條款 | Terms of Service / Terms of Use | 使用一個服務時你同意的規定，包括年齡限制。 |
| 73 | 資料保留 | Data Retention | 服務會把你的資料保存多久。 |
| 74 | 用於訓練 | Used for Training | 服務把你的對話拿去改進模型；通常可以在設定裡關掉。 |
| 75 | 暫時對話 | Temporary Chat / Incognito Mode | 不保存紀錄的對話模式。 |
| 76 | 兩步驟驗證 | Two-Factor Authentication（2FA） | 登入時除了密碼還要第二個確認（手機驗證碼等），帳號更安全。 |
| 77 | 密碼管理 | Password Management | 每個服務用不同密碼、用工具記住，不重複使用。 |
| 78 | 釣魚 | Phishing | 假冒官方的訊息或網頁，騙你輸入帳號密碼。 |
| 79 | 社交工程 | Social Engineering | 用人性弱點（急迫、害怕、信任）騙人，而不是用技術破解。 |
| 80 | 語音複製 | Voice Cloning | 用幾秒鐘的錄音做出和某人一樣的聲音，是 AI 詐騙的常見手法。 |
| 81 | 資料外洩 | Data Breach | 服務被入侵或出錯，讓使用者資料流出去。 |
| 82 | 家長監護設定 | Parental Controls | 服務提供給家長管理孩子帳號的功能，各家有無與做法不同。 |
| 83 | 內容過濾 | Content Filter / Safety Filter | 服務用來擋掉不當內容的機制，有用但不是百分之百。 |
| 84 | 通關密語 | Family Safe Word | 全家約定的一句話，電話裡說不出來就是假的。 |

## D.5　倫理、法律與社會

| # | 中文 | 英文 | 一句話解釋 |
|---|---|---|---|
| 85 | 倫理 | Ethics | 關於「什麼是對的、該不該做」的思考與原則。 |
| 86 | 著作權 | Copyright | 創作者對自己作品的權利；AI 訓練與生成都和它有關，法律還在變。 |
| 87 | 抄襲 | Plagiarism | 把別人（或 AI）的東西當成自己的交出去，沒有說明來源。 |
| 88 | 學術誠信 | Academic Integrity | 作業、考試、研究要誠實，自己做的才說是自己做的。 |
| 89 | 教練 vs 槍手 | Coach vs Ghostwriter | 本書的比喻：AI 教你做是教練，AI 替你做是槍手。 |
| 90 | 公平性 | Fairness | AI 對不同性別、族群、地區的人是否一視同仁。 |
| 91 | 刻板印象 | Stereotype | 對某一群人的固定、簡化的印象，訓練資料裡的刻板印象會被 AI 學走。 |
| 92 | 透明度 | Transparency | AI 怎麼做決定、用了什麼資料，是否能被看見與解釋。 |
| 93 | 可解釋性 | Explainability | 能不能說明 AI 為什麼給出這個答案。 |
| 94 | 對齊 | Alignment | 讓 AI 的行為符合人類的意圖與價值觀的研究。 |
| 95 | 人在迴圈中 | Human in the Loop | 重要決定由人最後確認，AI 只做建議。 |
| 96 | 數位足跡 | Digital Footprint | 你在網路上留下的所有痕跡，包括和 AI 的對話。 |
| 97 | 網路霸凌 | Cyberbullying | 用網路傷害別人；用 AI 做別人的假圖、假影片也是。 |
| 98 | 數位素養 | Digital Literacy | 會用、會判斷、會保護自己的網路能力。 |
| 99 | AI 素養 | AI Literacy | 知道 AI 能做什麼、不能做什麼、怎麼用得安全誠實的能力，就是本書要教的。 |
| 100 | 自動化取代 | Job Displacement | AI 接手部分工作導致職業內容改變，常被討論但結果還在變。 |
| 101 | 監管 | Regulation | 政府對 AI 的使用訂定的規範，各國不同、持續修改。 |

## D.6　寫作、學習與工具

| 118 | 公式 | Formula | 試算表裡用來計算的指令，例如 =SUM(A1:A10)。 |
