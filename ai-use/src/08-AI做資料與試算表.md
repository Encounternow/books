# 第 8 章　AI做資料與試算表

## 本章目標

學完這一章，你會：

- 說出 AI 在「資料工作」上最常幫得上忙的四件事：整理成表格、寫試算表公式、畫圖、做簡單分析。
- 把一份小資料用正確的方式交給聊天型 AI，並且用一句話說清楚每一欄是什麼。
- 請 AI 寫出一條試算表公式，貼進 Google 試算表或 Excel 看到結果，而且看得懂公式在做什麼。
- 對 AI 算出來的每一個數字做驗算，抓到它算錯的地方。
- 在上傳任何檔案給 AI 之前，先檢查裡面有沒有不該外流的資料。

## 開場：零用錢到底花去哪了？

小齊每個月有 1,500 元零用錢，可是每到月底總是剩不到 100 元。他明明覺得自己「沒買什麼」。媽媽說：「你把每一筆都記下來，兩個星期後我們一起看。」

兩個星期後，小齊的筆記本上有十四筆零碎的紀錄：早餐、飲料、捷運、漫畫、遊戲點數……他盯著這些數字，完全看不出「問題」在哪裡。要一筆一筆加嗎？要分類嗎？要畫圖嗎？

他想到：這不就是 AI 最擅長的事嗎？把紀錄貼給聊天型 AI，請它幫忙分類、加總、畫圖，幾秒鐘就有答案。結果 AI 真的給了一份漂亮的分析——只是其中一個總數加錯了。

這一章我們要學的，就是**怎麼讓 AI 幫你做資料工作，又不被它漂亮的格式騙過去**。如果你讀過同書架的《從資料看世界》（ https://book.vichuang.tw/statistics/ ），會發現這一章等於是把那本書的工具交給 AI 來做，而你負責當檢查員。

## 核心概念

### AI 在資料工作上最會幫的四件事

聊天型 AI（例如 ChatGPT、Claude、Gemini）面對資料，最常幫得上忙的是這四件事：

| 工作 | 你給它什麼 | 它給你什麼 | 可靠度 |
|---|---|---|---|
| 整理成表格 | 一段亂七八糟的文字 | 一張有欄位的表格 | 高，但要核對有沒有漏 |
| 寫試算表公式 | 「哪一欄是什麼」+ 你想算什麼 | 一條可以貼進試算表的公式 | 高，貼進去就能驗證 |
| 畫圖 | 一張小表格 | 文字版長條圖，或畫圖的步驟 | 中，數字要自己對 |
| 簡單分析 | 一張小表格 + 問題 | 分類加總、平均、「哪一類最多」 | 中，**每個數字都要驗算** |

注意最右邊那一欄。AI 整理文字、寫公式很可靠，因為那是「處理文字」的工作；但一旦要它**自己算數**，可靠度就下降。原因在《AI 怎麼運作》（ https://book.vichuang.tw/ai-theory/ ）裡有詳細說明，這裡用一句話講：聊天型 AI 本質上是「預測下一個字」的機器，不是計算機，所以加總十幾個數字時，它可能用「看起來很像對的」方式寫出一個錯的答案。有些 AI 目前可以在背後執行程式來算數，正確率會高很多，但你從外面不一定看得出它這次用了沒有。

所以本章的規矩只有一條：**AI 給的數字，你一定要用試算表或計算機重算一次。**

### 把資料交給 AI 的三種方式

| 方式 | 怎麼做 | 適合 |
|---|---|---|
| 直接貼文字 | 把紀錄一行一行貼進對話框 | 十幾筆到幾十筆的小資料 |
| 貼表格 | 從試算表選取範圍複製，貼進對話框（會變成用 Tab 分隔的文字） | 已經在試算表裡的資料 |
| 上傳檔案 | 用對話框的「附加檔案」功能上傳 .csv 或 .xlsx | 幾百筆以上；但要先做「上傳前檢查」 |

不管用哪一種，**第一句話都要說清楚「每一欄是什麼」**。AI 看到「10/1 45」時，不知道 45 是金額、頁數還是分數；你告訴它「第一欄是日期，第二欄是金額（元）」，它才能做對事。

### 請 AI 寫公式：先說清楚欄位，再說清楚要算什麼

試算表的公式像是一句很短的指令。例如：

```
=SUMIF(C2:C15, "飲食", D2:D15)
```

意思是：「看 C2 到 C15 這些格子，凡是寫著『飲食』的，就把同一列 D 欄的數字加起來。」

你不需要背公式，但你需要會**描述需求**。一個好的描述包含三件事：

1. 資料在哪裡：「A 欄是日期、B 欄是項目、C 欄是類別、D 欄是金額，資料在第 2 到 15 列。」
2. 想算什麼：「類別是『飲食』的金額總和。」
3. 用哪個工具：「Google 試算表」或「Excel」（兩者公式大多相同，但偶爾有差異）。

然後再加一句「請解釋這條公式每一部分的意思」，你就同時得到答案和一堂小課。

### 驗算：AI 的數字要過三關

拿到 AI 的分析後，照這三關檢查：

```
第一關：筆數對不對？
   你的資料有 14 筆 → AI 說它處理了幾筆？

第二關：總和對不對？
   自己用 SUM 加一次 → 和 AI 說的一樣嗎？

第三關：分類加起來等於總和嗎？
   飲食 + 文具 + 交通 + 娛樂 → 等於全部的總和嗎？
```

第三關特別有用：如果 AI 把某一筆分錯類，或是漏掉一筆，分類的總和就會和全部的總和對不起來，一眼就能抓到。

### 上傳檔案前的檢查清單

上傳檔案和貼文字不一樣：檔案裡常常藏著你沒注意到的東西，例如隱藏的工作表、其他同學的名字、家裡的地址。上傳前問自己：

- 檔案裡有沒有**人名、電話、地址、學號、身分證字號**？有就先刪掉或改成「甲、乙、丙」。
- 有沒有**別人的資料**（同學、家人、老師）？別人的資料不是你能決定要不要上傳的。
- 有沒有**學校或公司的內部檔案**？那些檔案通常有規定不能外傳。
- 這個平台的設定裡，「用我的對話來訓練模型」是開著還是關著？（第 9 章會教你找這個設定。）

一個簡單的原則：**先把檔案複製一份，刪到只剩下分析需要的欄位，再上傳那一份。**

## 動手做

### 活動 8-1：把零用錢紀錄交給 AI 分析並驗算

**材料／工具**：一個聊天型 AI 帳號、Google 試算表或 Excel、下面這份紀錄（你也可以換成自己真實的紀錄，但不要寫上自己和家人的名字）。

**步驟**：

1. 先把這十四筆紀錄抄進試算表，A 欄日期、B 欄項目、C 欄類別、D 欄金額，第 1 列放標題。

| 日期 | 項目 | 類別 | 金額 |
|---|---|---|---|
| 10/1 | 早餐三明治 | 飲食 | 45 |
| 10/2 | 飲料 | 飲食 | 35 |
| 10/3 | 筆 | 文具 | 30 |
| 10/4 | 捷運 | 交通 | 20 |
| 10/5 | 飲料 | 飲食 | 35 |
| 10/6 | 漫畫 | 娛樂 | 120 |
| 10/7 | 早餐 | 飲食 | 50 |
| 10/8 | 捷運 | 交通 | 20 |
| 10/9 | 飲料 | 飲食 | 35 |
| 10/10 | 遊戲點數 | 娛樂 | 150 |
| 10/11 | 筆記本 | 文具 | 60 |
| 10/12 | 早餐 | 飲食 | 45 |
| 10/13 | 飲料 | 飲食 | 35 |
| 10/14 | 捷運 | 交通 | 20 |

2. 在試算表選取整張表（含標題）複製，貼進 AI 的對話框，前面加上這段提示詞：

```
以下是我兩個星期的零用錢紀錄，每一列有四欄：日期、項目、類別、金額（元）。
請幫我做四件事：
1. 算出總共花了多少元、總共幾筆。
2. 按「類別」分別加總，並算出每一類佔總支出的百分比（四捨五入到小數第一位）。
3. 用文字畫一個長條圖，一個方塊代表 10 元。
4. 用兩句話告訴我，如果想省錢，最該注意哪一類。
請先列出你的計算步驟，再給結論。

（在這裡貼上表格）
```

3. 等 AI 回答後，**不要先看結論**，先去試算表驗算。在 D16 輸入 `=SUM(D2:D15)`，在 F2 到 F5 分別輸入四個類別名稱，在 G2 輸入 `=SUMIF($C$2:$C$15, F2, $D$2:$D$15)` 然後往下拉到 G5。
4. 把你算的數字和 AI 的數字逐一比對，填進下面的表。
5. 如果有不一樣，回頭問 AI：「你的『娛樂』總和是 XXX，但我用 SUMIF 算出來是 270，請重新檢查。」看它會不會改正。
6. 最後再看它的「省錢建議」，想一想你同不同意。

**你應該看到／得到**：

- 總支出 700 元、14 筆；四類分別是飲食 280、娛樂 270、文具 90、交通 60。
- 百分比約為飲食 40.0%、娛樂 38.6%、文具 12.9%、交通 8.6%（因為四捨五入，加起來是 100.1%，這是正常的）。
- 一個長條圖，大致像這樣：

```
飲食 ████████████████████████████ 280
娛樂 ███████████████████████████ 270
文具 █████████ 90
交通 ██████ 60
```

- AI 的結論通常會說「飲食和娛樂加起來將近八成」。有時候它會把某一筆分錯類（例如把「筆記本」算進娛樂），或是總和差個幾十元——這就是你要抓的。

**觀察與記錄**：

| 項目 | AI 說的數字 | 我驗算的數字 | 一樣嗎？ |
|---|---|---|---|
| 總支出 | | 700 | |
| 筆數 | | 14 | |
| 飲食 | | 280 | |
| 娛樂 | | 270 | |
| 文具 | | 90 | |
| 交通 | | 60 | |
| 四類加總 = 總支出？ | | | |
| AI 的省錢建議，我同意嗎？為什麼？ | | | |

### 活動 8-2：請 AI 寫一條公式，貼進試算表看結果

**材料／工具**：活動 8-1 的試算表、聊天型 AI。

**步驟**：

1. 把下面的提示詞貼給 AI：

```
我有一張 Google 試算表：A 欄是日期、B 欄是項目、C 欄是類別、D 欄是金額，資料在第 2 到第 15 列。
請幫我寫三條公式：
(1) 類別是「飲食」的金額總和；
(2) 類別是「飲食」的筆數；
(3) 類別是「飲食」的平均每筆金額（用前兩條的結果算，或用一條公式直接算都可以）。
每一條都請解釋每個部分的意思，並告訴我要貼在哪一格比較合理。
```

2. 把三條公式分別貼進試算表的空白格（例如 I2、I3、I4）。
3. 看結果：(1) 應該是 280，(2) 應該是 7，(3) 應該是 40。
4. 試著把公式裡的「飲食」改成「娛樂」，看結果有沒有變成 270、2、135。
5. 再問 AI 一個延伸問題：「如果我想知道哪一天花最多錢，要用什麼公式？」把它給的公式貼進去試。

**你應該看到／得到**：

- AI 給的三條公式大致是 `=SUMIF(C2:C15,"飲食",D2:D15)`、`=COUNTIF(C2:C15,"飲食")`、`=AVERAGEIF(C2:C15,"飲食",D2:D15)`。寫法可能略有不同，但貼進去結果應該是 280、7、40。
- 延伸問題它通常會給 `=MAX(D2:D15)`（最大金額 150），再配合 `INDEX` 和 `MATCH` 找日期；如果它給的公式貼進去出現錯誤訊息，把錯誤訊息整段貼回去請它修正，這也是一種練習。

**觀察與記錄**：

| 公式 | AI 給的寫法 | 貼進去的結果 | 正確嗎 | 我看懂了哪一部分 |
|---|---|---|---|---|
| 飲食總和 | | | | |
| 飲食筆數 | | | | |
| 飲食平均 | | | | |
| 改成娛樂之後 | | | | |
| 哪一天花最多 | | | | |

### 活動 8-3：把亂糟糟的文字整理成表格

**材料／工具**：聊天型 AI、試算表。

**步驟**：

1. 假設你是班上飲料團購的負責人，群組裡的訊息長這樣（這是虛構的，不要貼真實同學的名字）：

```
小美：我要珍奶兩杯
阿明：紅茶一杯謝謝
小華：珍奶三杯！
小齊：綠茶 2
阿明：等等我再加一杯珍奶
（價目：珍奶 50、紅茶 40、綠茶 40）
```

2. 貼給 AI，加上這段提示詞：

```
下面是一段團購訊息和價目表。請整理成表格，欄位是：姓名、品項、杯數、單價、小計。
同一個人點兩次要分成兩列或合併都可以，但請說明你怎麼處理。
最後請列出：每種飲料各幾杯、總杯數、總金額。
請先列出計算步驟，再給表格。
```

3. 自己心算或用試算表驗算：珍奶 2+3+1 = 6 杯、紅茶 1 杯、綠茶 2 杯，共 9 杯；金額 6×50 + 1×40 + 2×40 = 300 + 40 + 80 = 420 元。
4. 檢查 AI 有沒有漏掉「阿明再加一杯」那一行——這種「後來補充」的訊息最容易被漏。

**你應該看到／得到**：一張五欄的表格，總杯數 9、總金額 420。如果 AI 算出 8 杯或 370 元，幾乎一定是漏了阿明補的那一杯。

**觀察與記錄**：

| 檢查項目 | AI 的答案 | 我的驗算 | 一樣嗎 |
|---|---|---|---|
| 珍奶杯數 | | 6 | |
| 紅茶杯數 | | 1 | |
| 綠茶杯數 | | 2 | |
| 總杯數 | | 9 | |
| 總金額 | | 420 | |
| 有沒有漏掉補點的那一杯 | | | |

## 用工具看看：請 AI 用 CSV 格式輸出，直接貼進試算表

AI 整理好的表格，要怎麼搬進試算表？直接複製 AI 畫的表格，貼進去常常會擠在同一格。有一個小技巧：**請 AI 用 CSV 格式輸出**。CSV（Comma-Separated Values，逗號分隔值）就是「每一列一行、每一欄用逗號隔開」的純文字。

1. 在活動 8-3 的對話後面接著打：

```
請把剛才的表格用 CSV 格式輸出，第一列是欄位名稱，不要加任何其他說明文字。
```

2. 你會看到像這樣的東西：

```
姓名,品項,杯數,單價,小計
小美,珍奶,2,50,100
阿明,紅茶,1,40,40
小華,珍奶,3,50,150
小齊,綠茶,2,40,80
阿明,珍奶,1,50,50
```

3. 全部複製，打開 Google 試算表，點選 A1，貼上。如果所有文字都擠在 A 欄，選取 A 欄，到選單「資料 → 將文字分隔成不同欄」，選「逗號」，資料就會分成五欄。Excel 的對應功能在「資料 → 資料剖析」。
4. 在 E7 輸入 `=SUM(E2:E6)`，看到 420，表示你的驗算和 AI 的表格對上了。
5. 選取 B2 到 C6，到「插入 → 圖表」，試著畫一個長條圖，比較一下和 AI 用文字畫的圖像不像。

這個技巧的好處是：**AI 負責整理，試算表負責算數**，各自做自己最擅長的事。

## 常見錯誤與迷思

- **「AI 給的表格排得這麼整齊，數字應該不會錯」** → 整齊是格式，不是正確。AI 算錯的時候格式一樣整齊。→ 正確理解：格式漂亮和數字正確是兩件事，每個數字都要過三關驗算。
- **「直接貼一堆數字給它就好，它自己會懂」** → AI 不知道「45」是金額還是頁數，猜錯了整份分析就錯。→ 正確理解：第一句話永遠先說清楚每一欄是什麼、單位是什麼。
- **「它說總共 14 筆，那就是 14 筆」** → AI 有時會漏掉最後一行或補充的訊息，卻照樣說「我處理了全部資料」。→ 正確理解：筆數是第一關，自己數一次。
- **「公式貼進去出現錯誤，表示 AI 不會寫公式」** → 常見原因是 Google 試算表和 Excel 的小差異、全形逗號、或你的資料範圍和描述不一樣。→ 正確理解：把錯誤訊息整段貼回去請它修，通常一兩次就好。
- **「上傳整個檔案比較方便」** → 檔案裡常藏著其他工作表、別人的名字、家裡的資料。→ 正確理解：先複製一份、刪到只剩需要的欄位，再上傳。
- **「用 AI 分析就不用學統計了」** → AI 會算平均，但不會替你判斷「這份資料該用平均數還是中位數」，也不會告訴你圖表哪裡在騙人。→ 正確理解：《從資料看世界》教的判斷力，正是你檢查 AI 時最需要的。

能。四類加起來是 280 + 300 + 90 + 60 = 730，不等於它自己說的總支出 700，表示至少有一個數字錯了。這就是「第三關：分類加起來等於總和嗎」的用處。

</details>

3. 請用一句話描述這條公式在做什麼：`=COUNTIF(C2:C15, "交通")`

<details><summary>參考答案</summary>

看 C2 到 C15 這些格子，數一數有幾格寫著「交通」。在活動 8-1 的資料裡答案是 3。

</details>

4. 你想請 AI 幫忙分析全班的段考成績，檔案裡有每個同學的姓名、座號和分數。上傳之前應該怎麼處理？為什麼？

<details><summary>參考答案</summary>

把姓名和座號刪掉或換成「同學 1、同學 2」，只留分數欄；因為同學的成績是別人的個資，不是你能決定要不要上傳的。而且老師的成績檔通常屬於學校資料，最好先問過老師。

</details>

5. 有些 AI 目前可以在背後「執行程式」來算數。你覺得這樣算出來的數字，還需要驗算嗎？

<details><summary>參考答案</summary>

還是需要，只是出錯的地方不一樣。程式算加總幾乎不會錯，但「它有沒有把每一筆都讀進去」「有沒有把類別分對」「有沒有看懂你的問題」仍然可能錯。所以筆數和分類這兩關一樣要過；而且你從外面不一定看得出它這次有沒有真的執行程式。

</details>

6. 開放挑戰：記錄你自己一個星期的某件事（花費、睡眠時間、喝水杯數、讀書分鐘數都可以），交給 AI 分析，並寫下「AI 說的三件事」與「我驗算後同意／不同意」。如果 AI 全部算對，試著問它一個它答不好的問題（例如「這個星期的中位數是多少，為什麼和平均數不一樣」），看它的解釋你能不能用《從資料看世界》第 4 章的知識判斷對不對。

<details><summary>參考答案</summary>

開放題，沒有標準答案。重點是你要真的做到三件事：先說清楚欄位、每個數字都驗算、對它的解釋提出一個你自己能判斷的問題。常見發現是：AI 的加總大多正確，但「解釋為什麼」的部分有時會講得很順卻不太對，例如把平均數和中位數的差異解釋反了。

</details>

## 本章小結

- AI 在資料工作上最會幫的四件事：整理表格、寫公式、畫圖、簡單分析；前兩件很可靠，後兩件的數字一定要驗算。
- 交資料給 AI 的第一句話永遠是「每一欄是什麼、單位是什麼」。
- 請 AI 寫公式時，說清楚資料在哪一欄哪幾列、想算什麼、用哪個工具，再請它解釋每一部分。
- 驗算三關：筆數對不對、總和對不對、分類加起來等不等於總和。
- 「請先列出計算步驟再給結論」這句話能讓錯誤比較容易被看見。
- 請 AI 用 CSV 格式輸出，貼進試算表再用「將文字分隔成不同欄」，讓 AI 整理、試算表算數。
- 上傳檔案前：刪掉人名、聯絡方式、別人的資料與學校內部資料，只留分析需要的欄位。
- AI 不會替你判斷該用哪個統計量、圖表有沒有誤導；那是你從《從資料看世界》學來的本事。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 試算表 | Spreadsheet | 用格子存資料、用公式算數的軟體，例如 Google 試算表、Excel。 |
| 公式 | Formula | 試算表裡以「=」開頭的指令，告訴格子要怎麼算。 |
| 條件加總 | SUMIF | 只把符合某個條件的那些格子加起來的公式。 |
| 條件計數 | COUNTIF | 數一數有幾格符合某個條件的公式。 |
| 逗號分隔值 | CSV（Comma-Separated Values） | 每列一行、每欄用逗號隔開的純文字表格格式，幾乎所有軟體都看得懂。 |
| 驗算 | Verification | 用另一種方法把答案重算一次，確認沒錯。 |
| 去識別化 | De-identification | 把資料裡能認出是誰的部分（姓名、學號等）刪掉或改掉。 |
| 幻覺 | Hallucination | AI 一本正經地說出錯的內容，包括算錯的數字。 |
