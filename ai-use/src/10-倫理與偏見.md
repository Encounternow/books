# 第 10 章　倫理與偏見

## 本章目標

學完這一章，你會：

- 用自己的話解釋 AI 的偏見從哪裡來，並設計一個小實驗把它找出來。
- 說出 AI 生成內容和著作權的三個關係：訓練資料、生成物的歸屬、模仿特定創作者的風格。
- 知道什麼時候該標示「我用了 AI」，而且會寫一句合格的標示。
- 分辨「請 AI 當教練」和「請 AI 當槍手」的界線，說出為什麼後者是不誠實。
- 說出用 AI 傷害別人的幾種形式（霸凌、假訊息、冒充），以及為什麼不能做。
- 和同學進行一場有規則的討論，而不是只有吵架。

## 開場：五個科學家，五個都一樣

小美在做自然科報告，想要一張科學家的插圖。她打開圖像生成工具，輸入「一位科學家在實驗室裡」。出來的是一個穿白袍、戴眼鏡的中年男人。她覺得太普通，又按了四次「重新生成」。

五張圖，五個中年男人。

她換個指令：「一位護理師在照顧病人」。五張圖，五個年輕女性。

她有點不服氣，打開聊天型 AI 問：「請寫一個關於工程師的小故事，主角名字自己取。」主角叫「阿傑」。再問一次，「建宏」。再問，「大衛」。

小美把這些結果拿給姊姊看。姊姊說：「它不是故意的。它只是把網路上『最常見的樣子』學起來，再用更高的比例還給你。」

這一章要談的，就是 AI 這些「不是故意的」問題，以及一些「是人故意的」問題：偏見、著作權、誠實標示、還有用 AI 去傷害別人。這些事沒有公式可以算，但有原則可以守。

## 核心概念

### 偏見從哪裡來：AI 是訓練資料的鏡子

聊天型 AI 和圖像生成工具是從大量人類寫的文字與拍的圖片學來的（詳細的訓練方式見《AI 怎麼運作》 https://book.vichuang.tw/ai-theory/ ）。人類的資料本來就不平均：

- 網路上「科學家」的圖片，男性遠多於女性。
- 英文的內容遠多於中文；中文裡，台灣的內容又只佔一小部分。
- 寫在網路上的意見，不等於所有人的意見；會上網發言的人本來就偏向某些族群。

**偏見（Bias）**在這裡的意思是：**AI 的輸出系統性地偏向某一邊，而且這個偏向來自訓練資料，不是來自你的問題。**

更麻煩的是「放大」。用一個簡化的例子算算看：假設訓練資料裡的科學家圖片有 70% 是男性。模型學的是「最像的樣子」，所以生成時它傾向選最常見的那種，結果可能 90% 以上是男性。70% 進去，90% 出來，這就是**放大（Amplification）**。數字是示意的，但方向是真的：AI 常常比它的資料更「刻板」。

### 偏見會造成什麼實際問題

這不只是「圖畫得不夠多元」而已。想像幾個目前已經真實發生過的情境：

| 情境 | 偏見怎麼出現 | 誰受害 |
|---|---|---|
| 公司用 AI 篩選履歷 | 過去錄取的多是某一種人，AI 學會「那種人比較好」 | 其他人連面試的機會都沒有 |
| 臉部辨識 | 訓練照片裡某些膚色的人比較少，辨識那些人的錯誤率就比較高 | 被認錯、被誤攔 |
| 翻譯 | 把沒有性別的句子翻成英文時，「醫生」自動變 he、「護理師」自動變 she | 加深刻板印象 |
| 問 AI 台灣的事 | 中文資料少、台灣資料更少，它常拿別地方的規定來回答 | 你得到錯的資訊 |

最後那一列和你最有關：**問 AI 台灣的法規、學校制度、在地文化時，它特別容易用別的地方的答案來填補。** 這也是一種偏見，而且是查證（第 3 章）最常抓到的那種。

### 著作權與創作者

**著作權（Copyright）**的意思是：一個人創作出來的文字、圖畫、音樂、程式，由他決定別人能不能用、怎麼用。AI 和著作權碰在一起，有三個層次的問題：

**第一層：訓練資料**。圖像生成工具是看了幾億張圖學會畫圖的，其中很多是畫家、攝影師放在網路上的作品，而大部分人沒有被問過「可不可以拿去訓練」。這件事對不對、合不合法，各國目前還在討論和打官司，沒有定論。你可以記住的是：**AI 畫得出來，不代表那些風格是憑空來的；背後有真人的作品。**

**第二層：生成物是誰的**。你用 AI 生成的一張圖、一篇文章，著作權歸誰？目前許多地方的看法是：純粹由 AI 生成、人沒有實質創作參與的東西，可能不受著作權保護；而你有實質參與（例如你寫了文章、AI 只潤稿）的部分才算你的。規定會變，但原則很清楚：**你投入越多，它越是你的。**

**第三層：模仿特定的人**。輸入「用某某畫家的風格畫一張圖」，技術上做得到，但那位畫家可能花了二十年才練成那個風格。拿來自己欣賞和拿來比賽、拿來賣，是不同的事。一個簡單的做法：**描述你要的感覺（水彩、溫暖、黃昏），不要寫在世創作者的名字。**

### 標示：用了 AI 就要說

標示不是認罪，是誠實。就像報告要寫參考資料一樣。什麼時候要標？

| 情境 | 要不要標 | 怎麼標 |
|---|---|---|
| AI 幫你檢查錯字、建議改幾句 | 要（簡短） | 「本文由我撰寫，使用聊天型 AI 協助檢查錯字與潤飾。」 |
| AI 幫你想大綱，內容你自己寫 | 要 | 「大綱由我與聊天型 AI 討論後擬定，內文由我撰寫。」 |
| 整篇由 AI 生成，你只改幾個字 | 要，而且很多情境不允許 | 「本文主要由 AI 生成。」（先確認老師允不允許） |
| 用 AI 生成的圖放在報告裡 | 要 | 圖下方註明「圖片由圖像生成工具生成」。 |
| 用 AI 查資料，但你有去查證原始來源 | 標原始來源即可 | 列出你查證過的原始資料 |
| 自己腦袋想的、自己寫的 | 不用 | — |

一句合格的標示要有三個東西：**用了什麼類型的工具、用在哪個步驟、哪些部分是自己做的。** 不需要寫產品名稱和版本，也不需要貼整段對話（除非老師要求）。

### 抄襲與誠實：教練還是槍手

第 5 章講過，這裡再講一次，因為它是全書最重要的原則之一。

**抄襲（Plagiarism）**的本質是：**把不是你做的東西，當成你做的交出去。** 從網路抄一篇是抄襲，請同學幫你寫是抄襲，請 AI 整篇生成然後簽上你的名字，也是抄襲——即使 AI 的文章不是「抄」自任何一篇現成文章。

為什麼？因為作業的目的不是「交出一篇文章」，而是「讓你學會寫文章」。AI 代寫之後，文章有了，你的能力沒有。這就是教練與槍手的差別：

```
教練：你做，它看、它建議、它出題考你 → 能力留在你身上
槍手：它做，你交                     → 能力留在它身上
```

一個檢查方法：**交出去之後，如果老師當面問你「這段為什麼這樣寫」，你答得出來嗎？** 答得出來，就是你的；答不出來，就不是。

### AI 對工作的影響

你和家人可能會擔心「AI 會不會搶走工作」。這題沒有人能確定地回答，所以本書不預測。可以確定的只有幾件事：

- 目前 AI 擅長的，是「有明確範例、重複性高、可以用文字描述」的工作片段；不擅長的，是「要負責任、要跟真人協調、要在現場判斷」的部分。
- 大多數工作是兩者的混合。所以比較常見的情況是**「工作的內容變了」**，而不是「工作消失了」。
- 歷史上每次新工具出現，都有工作消失、也有新工作出現；差別在於這次的速度比較快。
- 會用 AI 的人，和不會用的人，做同一件事的效率會差很多。

第 11 章會請你訪問家人，親自聽聽他們工作裡 AI 到底改變了什麼。

### 不要用 AI 傷害別人

前面講的多是「AI 不小心造成的問題」。這一節講的是「人故意用 AI 做的壞事」，而且做的人可能就是國中生。

**霸凌**。用圖像生成工具做一張嘲笑同學的圖、用 AI 寫一篇攻擊某人的文章、把同學的臉合成到不雅的圖片或影片上。最後那一種在台灣已經是**犯罪**：法律把製作、散布別人的不實性影像列為刑事犯罪，未成年人一樣會被追究，家長也可能要負責。就算只是「好玩」「只傳給幾個人」，一旦傳出去就收不回來。

**假訊息**。用 AI 生成一則看起來很真的新聞、一張看起來很真的災難照片、一段某人「說過」的話，然後傳出去。這會讓真正需要幫助的事被淹沒，也會讓人對所有資訊失去信任。

**冒充**。用 AI 模仿老師、同學、家人的語氣或聲音發訊息。第 9 章的假聲音詐騙，就是這種事的犯罪版。

一條簡單的檢查原則：**如果這件事的「受害者」是一個真實存在的人，而他沒有同意，就不要做。** 做之前想像一下那個人就站在你旁邊看著螢幕。

## 動手做

### 活動 10-1：找一個 AI 偏見的例子

**材料／工具**：聊天型 AI（有圖像生成工具更好，沒有也可以做）、紙筆。

**步驟**：

1. 開一個新的對話，貼下面的提示詞，**連續做 5 次**（每次開新對話，或每次都說「再寫一個，不要和前面重複」）：

```
請寫一個 100 字以內的小故事，主角是一位工程師。主角的名字請你自己取，故事裡要提到主角的外表和下班後做的事。
```

2. 每一次記錄：主角名字、性別（從名字和代名詞判斷）、外表描述、下班後做的事。
3. 把「工程師」換成「護理師」「校長」「清潔人員」「執行長」各做 3 次，一樣記錄。
4. 如果有圖像生成工具，輸入「一位執行長在辦公室」生成 4 張，記錄性別、年齡、膚色。
5. 把全部記錄看一遍，問自己：有沒有哪個職業的結果「幾乎都一樣」？
6. 回到 AI，貼這段：

```
我剛才請你寫了 5 個工程師的故事，主角有 X 個是男性、Y 個是女性（填入你的數字）。
請問這個比例是怎麼來的？這算不算偏見？如果我希望結果更平均，提示詞應該怎麼寫？
```

7. 用它建議的新提示詞再做 3 次，看結果有沒有改變。

**你應該看到／得到**：

- 工程師、執行長、校長的主角多數是男性；護理師多數是女性；名字常是英文名或某幾個很常見的中文名。這就是訓練資料的鏡子。
- AI 在步驟 6 通常會承認「這反映了訓練資料的分布」，並建議你在提示詞裡明確指定（例如「主角是一位女性工程師」或「請隨機決定性別」）。
- 加了指定之後結果會改變——這證明偏見是可以被你的提示詞修正的，但前提是你要先知道它在那裡。

**觀察與記錄**：

| 職業 | 第 1 次 | 第 2 次 | 第 3 次 | 第 4 次 | 第 5 次 | 男／女／不明 |
|---|---|---|---|---|---|---|
| 工程師 | | | | | | |
| 護理師 | | | | — | — | |
| 校長 | | | | — | — | |
| 清潔人員 | | | | — | — | |
| 執行長 | | | | — | — | |
| AI 對偏見的解釋 | | | | | | |
| 修正後的結果 | | | | | | |

### 活動 10-2：班上討論題——這些作業能不能交？

**材料／工具**：4 到 6 個人（同學、家人都可以）、紙筆、聊天型 AI（當反方）。

**步驟**：

1. 每個人先讀下面四個情境，在自己的紙上對每一題寫「可以／不可以／要標示才可以」，不要先討論。

```
情境 A：小明用 AI 出了 10 題數學練習，自己寫完後請 AI 批改，
        再把寫錯的題目重做一次。隔天的小考他考得很好。

情境 B：小華請 AI 寫了一篇 600 字的讀書心得，自己把開頭和結尾
        各改了一句，交出去，沒有說用了 AI。

情境 C：小美自己寫了作文，請 AI 指出三個可以改進的地方，
        她照建議改了兩個，交出去時在最後註明「使用 AI 協助潤飾」。

情境 D：小齊的美術作業是「畫一張海報」。他用圖像生成工具生成，
        再用繪圖軟體加上自己的標題和配色，交出去時註明「圖片由 AI 生成，
        標題與配色由我設計」。老師沒有規定能不能用 AI。
```

2. 大家亮出答案，先找出「意見不一樣」的情境，從那一題開始討論。
3. 討論規則：每個人發言不超過 1 分鐘；要先說「我認為……因為……」；不能打斷；每一輪結束後，由一個人用一句話總結大家同意的部分和不同意的部分。
4. 討論到一個段落後，把情境貼給 AI，請它當反方：

```
下面是四個關於學生用 AI 做作業的情境。我們這組的結論是：A 可以、B 不可以、C 可以、D 要看老師（請改成你們的結論）。
請你針對每一個結論，提出一個最有力的反對理由，幫助我們想得更完整。不要直接告訴我們誰對誰錯。

（貼上四個情境）
```

5. 看 AI 提出的反對理由，再討論一輪：哪些理由讓你改變想法？哪些你覺得不成立？
6. 最後每個人寫下自己「修正後的答案」，和一開始的答案比一比。

**你應該看到／得到**：

- 情境 A 幾乎所有人都同意「可以」，因為 AI 是教練。情境 B 幾乎所有人都同意「不可以」，因為是槍手而且沒標示。
- 情境 C 和 D 最容易出現分歧，尤其是 D：有人覺得「海報的重點是設計」所以可以，有人覺得「美術課的重點是練習畫」所以不行。這個分歧是正常的，答案取決於「這份作業想練的能力是什麼」——這也是你該問老師的問題。
- AI 當反方時，常會提出像「情境 A 如果 AI 批改錯了怎麼辦」「情境 D 的老師沒規定，是不是應該先問」這類有用的角度。

**觀察與記錄**：

| 情境 | 我一開始的答案 | 組內多數意見 | AI 的反對理由 | 我修正後的答案 | 改變的原因 |
|---|---|---|---|---|---|
| A | | | | | |
| B | | | | | |
| C | | | | | |
| D | | | | | |

## 用工具看看：用兩個不同的 AI 問同一題，比較偏向

同一個問題，問兩個不同公司的聊天型 AI，常常會得到不一樣的偏向。這是找偏見最簡單的工具技巧。

1. 準備兩個不同的聊天型 AI（例如一個 ChatGPT、一個 Gemini 或 Claude；學校或家長有哪兩個就用哪兩個）。
2. 把同一段提示詞分別貼給兩個 AI，一字不改：

```
請用 150 字介紹「台灣的國中生畢業後有哪些升學管道」。請列出你引用的資料來源。
```

3. 把兩個回答並排看，記錄三件事：
   - 兩邊說的升學管道一不一樣？有沒有哪一邊講的其實是別的國家的制度？
   - 兩邊列的來源，自己去查，是真的嗎？（這就是第 3 章的查證。）
   - 兩邊的語氣有沒有偏向（例如一邊只講升高中、另一邊有講技職）？
4. 再換一個容易有立場的題目試試，例如「核能發電的優點和缺點」，看兩邊列出的優缺點數量和順序一不一樣。

你應該看到：兩個 AI 的答案常常有「一邊比較完整、一邊比較偏某個方向」的現象，來源也不一定都查得到。這告訴你：**一個 AI 的答案只是一個樣本，不是真相**；重要的事至少問兩個，再查原始資料。

| 題目 | AI 甲說了什麼 | AI 乙說了什麼 | 差異 | 查證結果 |
|---|---|---|---|---|
| 升學管道 | | | | |
| 核能優缺點 | | | | |

## 常見錯誤與迷思

- **「AI 是機器，所以它很客觀、沒有偏見」** → 它是從人類資料學來的，而人類資料不平均；而且它還會放大。→ 正確理解：AI 是訓練資料的鏡子，照出來的是「網路上最常見的樣子」，不是「公平的樣子」。
- **「偏見是 AI 公司的事，跟我沒關係」** → 你問台灣的事得到別國的答案、你生成的圖全是同一種人，這些都直接影響你的報告。→ 正確理解：知道偏見在哪裡，就能用提示詞修正、用查證補救。
- **「AI 生成的圖沒有版權問題，因為不是人畫的」** → 訓練資料裡有真人的作品，模仿特定創作者的風格更是直接牽涉到他。→ 正確理解：自己欣賞可以，拿去比賽、販售、冒充自己畫的，都有問題；不要寫在世創作者的名字。
- **「AI 寫的不算抄襲，因為沒有抄任何一篇文章」** → 抄襲的本質是「把不是你做的當成你做的」，和原文來自哪裡無關。→ 正確理解：老師問你「為什麼這樣寫」答不出來，就不是你的。
- **「標示用了 AI 會被扣分，所以不要寫」** → 不標示被發現的後果嚴重得多，而且誠實標示的作業通常老師會更願意討論。→ 正確理解：標示是誠實，像寫參考資料一樣正常。
- **「只是合成一張好玩的圖傳給朋友，沒有惡意」** → 受害者感受到的不是你的意圖，而是結果；而且傳出去就收不回來，某些類型已經是犯罪。→ 正確理解：受害者是真實的人而且沒同意，就不要做。

## 想一想

1. 小美生成「科學家」五次都是男性。請用「鏡子」和「放大」兩個詞解釋為什麼。

<details><summary>參考答案</summary>

鏡子：圖像生成工具是從網路上的圖片學來的，網路上「科學家」的圖片男性佔多數，所以它照出來的也是男性居多。放大：模型傾向生成「最常見的樣子」，所以原本資料裡可能是七成男性，生成結果卻接近全部男性，比資料更極端。

</details>

2. 下面哪一句標示是合格的？為什麼其他的不合格？
   (a)「本文使用 AI。」
   (b)「本文由我撰寫，使用聊天型 AI 協助檢查錯字與建議段落順序，內容與論點為我自己的。」
   (c)（沒有標示，但在心裡知道自己只用 AI 改了錯字）

<details><summary>參考答案</summary>

(b) 合格，因為它說了用什麼類型的工具、用在哪個步驟、哪些是自己做的。(a) 太籠統，看不出用在哪裡、用了多少。(c) 沒有標示就不是誠實，就算只改錯字也應該用一句話說明。

</details>

3. 小齊想用圖像生成工具畫一張「宮崎駿風格」的圖參加學校比賽。請給他兩個建議。

<details><summary>參考答案</summary>

第一，不要在提示詞裡寫在世創作者的名字，改用描述感覺的詞（手繪動畫風、柔和色彩、鄉村風景、雲很多）。第二，參賽前先看比賽規則允不允許 AI 生成，允許的話要標示「圖片由 AI 生成」，並且加入自己實質的創作（構圖、標題、修改）。

</details>

4. 一個公司用過去十年錄取的員工資料訓練 AI 來篩履歷。過去十年錄取的人 85% 是男性。你預測這個 AI 會怎麼做？公司應該怎麼辦？

<details><summary>參考答案</summary>

AI 會學到「男性的履歷比較像會被錄取的樣子」，於是更常把女性的履歷排在後面，甚至放大到超過 85%。公司應該：不要讓 AI 看得到性別和能推出性別的資訊（名字、社團等）、定期檢查 AI 篩出來的比例、最後由真人決定，而不是全部交給 AI。

</details>

5. 同學在群組裡傳一張用 AI 把另一個同學的臉合成到搞笑圖片上的圖，說「只是好玩」。請用本章的「檢查原則」判斷能不能做，並說出一個你會做的動作。

<details><summary>參考答案</summary>

檢查原則：受害者是一個真實的人，而他沒有同意，所以不該做。就算是「搞笑」而非不雅，被合成的同學可能並不覺得好笑，而且圖一傳出去就收不回來；如果是不雅內容，在台灣更已經是犯罪。你可以做的：不轉傳、私下跟傳圖的人說「他可能不喜歡，刪掉吧」、如果內容嚴重就告訴老師或家長。

</details>

6. 開放挑戰：找一個你常用的 AI 功能（翻譯、圖像生成、推薦、自動完成都可以），設計一個 5 次的小實驗，試著找出它的一種偏見，寫下你的提示詞、五次結果、你的結論，以及一個可以減輕這個偏見的提示詞寫法。

<details><summary>參考答案</summary>

開放題。好的答案會有：固定不變的提示詞、至少五次結果的紀錄、一個可以用數字描述的現象（例如「五次裡四次是男性」「五次裡三次給的是美國的規定」），以及一個真的試過、有效或無效都誠實寫出來的修正方式。沒找到偏見也是一個結論，只要紀錄完整。

</details>

## 本章小結

- AI 的偏見來自訓練資料不平均，而且會被放大；它是訓練資料的鏡子，不是公平的裁判。
- 偏見會造成真實的傷害：履歷篩選、臉部辨識、翻譯的刻板印象，以及「問台灣的事得到別國的答案」。
- 知道偏見在哪裡，就能用明確的提示詞修正、用兩個 AI 比較、用查證補救。
- 著作權的三層：訓練資料裡有真人的作品；你投入越多，生成物越是你的；不要寫在世創作者的名字來模仿風格。
- 用了 AI 就標示：說明用什麼類型的工具、用在哪個步驟、哪些是自己做的。
- 抄襲的本質是「把不是你做的當成你做的」；老師問你為什麼這樣寫答不出來，就不是你的。
- AI 對工作的影響更多是「內容改變」而非「消失」，但沒人能準確預測；會用的人效率差很多。
- 不用 AI 霸凌、造假訊息、冒充別人。受害者是真實的人而且沒同意，就不要做；某些行為在台灣是犯罪。
