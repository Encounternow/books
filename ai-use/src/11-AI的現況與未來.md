# 第 11 章　AI的現況與未來

## 本章目標

學完這一章，你會：

- 用一張表說出目前的 AI「做得好、做得不穩、做不到」各有哪些事，並且自己測試過。
- 用自己的話解釋「多模態」「AI 代理」「本地模型」這三個概念是什麼、各自的好處與風險。
- 面對一則「AI 又會做什麼了」的新聞時，用三個問題判斷它有多可信、對自己有什麼差別。
- 說出國中生現在最值得練的幾項能力，以及為什麼 AI 越強這些能力越重要。
- 完成一次訪問，親耳聽到家人工作上怎麼用 AI。

## 開場：阿公的問題

吃飯的時候，阿公看著新聞問小齊：「現在的 AI 這麼厲害，你以後長大還有工作嗎？」

小齊愣住。他會用 AI 寫作業、寫程式、整理資料，但他真的不知道這題的答案。他反問：「阿公，你工作的時候有用過什麼新機器嗎？」

阿公笑了：「我年輕時在工廠，後來有了電腦，大家都說要失業了。結果是不會用電腦的人比較辛苦，會用的人換了工作內容。」

媽媽接著說：「我們醫院現在有 AI 幫忙看片子，但最後簽名的還是醫生。」爸爸說：「我寫程式一半靠 AI 補，可是它寫的東西我每一行都要看。」

小齊發現，家裡每個人都有一段「AI 怎麼改變我的工作」的故事，而且都不是新聞上那種「全部取代」的版本。這一章我們要把「現在的 AI 到底到哪裡了」講清楚，然後學會一件更重要的事：**怎麼在它一直變的時候，不慌張地跟上。**

## 核心概念

### 目前的 AI：做得好、做得不穩、做不到

注意「目前」這兩個字。這一節寫的是本書寫作時的狀態，而 AI 的能力每隔幾個月就會變；所以表格的內容是讓你去測試的，不是讓你背的。

| 做得好 | 做得不穩 | 目前做不到 |
|---|---|---|
| 改寫、摘要、翻譯一段文字 | 算多位數的加減乘除（除非它背後執行程式） | 知道「現在」發生的事（除非它有連網搜尋） |
| 解釋一個概念、換三種方式再解釋 | 引用真實存在的來源、法條、數據 | 為自己說的話負責任 |
| 寫一段短程式、找出程式錯誤 | 長篇文章的前後一致 | 真的「理解」你是誰、你的處境 |
| 把亂的文字整理成表格 | 台灣在地的規定與細節 | 記住上個月的對話（除非平台有記憶功能） |
| 看懂一張圖、描述圖的內容 | 生成圖片裡的文字（常常拼錯） | 替你判斷什麼是對的、什麼是重要的 |
| 出練習題、批改、當對話練習的對象 | 判斷自己哪裡不確定（常常過度自信） | 感受到你的情緒，或對你的人生負責 |

中間那一欄最重要。「做得不穩」的意思是：**它有時候對、有時候錯，而且錯的時候一樣有自信。** 這就是為什麼第 3 章的查證永遠不會過時。

### 多模態：不只讀字，也看圖、聽聲音

早期的聊天型 AI 只處理文字。**多模態（Multimodal）**的意思是一個 AI 同時能處理多種「形式」的輸入與輸出：

```
輸入：文字 ─┐                    ┌─→ 文字
      圖片 ─┤                    ├─→ 圖片
      聲音 ─┼──→  同一個 AI  ──→ ├─→ 聲音
      影片 ─┘                    └─→ 程式、表格……
```

目前對你最實用的用法：拍一張課本的題目請它解釋、拍一張錯誤訊息請它看、錄一段上課內容請它整理（第 7 章做過）。注意第 9 章的規則：**拍照上傳前，看看照片裡有沒有名字、臉、學號。**

### AI 代理：從「回答」到「去做」

到目前為止，你用 AI 的方式都是「你問、它答、你去做」。**AI 代理（AI Agent）**的概念是：你給它一個目標，它自己拆成步驟、使用工具、檢查結果、再繼續，直到完成。

```
一般聊天型 AI：
  你：幫我查這三本書圖書館有沒有  → AI：你可以去圖書館網站查……（然後你自己去查）

AI 代理：
  你：幫我查這三本書圖書館有沒有
  AI：第一步，打開圖書館網站 → 第二步，搜尋第一本 → 第三步，記錄結果
      → 第四步，搜尋第二本 → …… → 回報：兩本在架上，一本外借中
```

它用的「工具」可能是：網路搜尋、打開網頁、執行程式、讀寫檔案、寄信、操作其他軟體。

這很方便，但也多了一種新的風險：**它會真的做事。** 一般聊天型 AI 說錯了，你看到再判斷就好；AI 代理做錯了，事情已經發生（例如寄出了一封錯的信、刪掉了一個檔案）。所以用 AI 代理的原則是：

1. **給的權限越小越好**：只讓它讀，不讓它寫；只讓它在一個資料夾裡動。
2. **重要動作要先問你**：寄信、付款、刪除之前一定要停下來確認。
3. **事後看紀錄**：它做了哪些步驟，要看得到。

本書不教你用任何特定的代理工具，因為它們變得太快；但「先想權限、重要的事要確認、事後看紀錄」這三個原則，不管工具怎麼變都適用。

### 本地模型：在你自己的手機或電腦上跑

你平常用的聊天型 AI，是把你的文字送到遠方的伺服器處理。**本地模型（Local Model）**的意思是：模型本身就裝在你的手機或電腦裡，所有運算在自己的裝置上完成，不需要連網，文字也不會送出去。

| | 雲端的 AI | 本地模型 |
|---|---|---|
| 資料去哪裡 | 送到公司的伺服器 | 留在自己的裝置 |
| 需不需要網路 | 要 | 不用 |
| 能力 | 目前最強的模型都在這裡 | 目前通常比較小、比較「笨」一些 |
| 需要的設備 | 任何能上網的裝置 | 記憶體夠大的電腦或較新的手機 |
| 適合 | 一般大多數用途 | 私密資料、沒網路的地方、想自己研究 |

目前本地模型的能力還明顯落後雲端最強的模型，但差距在縮小。它的意義在於：**隱私問題有另一種解法**——不是「相信公司不會亂用」，而是「資料根本不出門」。如果你對這個有興趣，《AI 怎麼運作》會告訴你模型裡面裝的是什麼。

### 怎麼持續跟上而不焦慮

AI 的新聞幾乎每週都有，「某某 AI 又會做什麼了」「某某工作要消失了」。你不需要每一則都追，只要學會問三個問題：

| 問題 | 為什麼要問 |
|---|---|
| 誰說的？他賣不賣這個東西？ | 賣 AI 的公司當然說 AI 很厲害；反過來，怕被取代的人也可能說得太悲觀。 |
| 有沒有可以自己試的示範？ | 「展示影片」和「你自己打開來用」常常差很多。能自己試的才算數。 |
| 這對「我正在做的事」有什麼差？ | 大多數新聞對你的作業、你的興趣沒有直接影響。有影響的那幾個，再花時間看。 |

另外兩個習慣：**每隔幾個月，把本章的「能力表」重做一次**，自己看看哪一格變了；**看原理、不看名字**——產品名稱年年換，但「它是預測下一個字的機器」「它會幻覺」「它反映訓練資料」這些原理很久不會變。學原理的人，不會被名字嚇到。

### 國中生現在該學什麼

既然 AI 會的事越來越多，你該學什麼？答案可能和你想的相反：**AI 越強，下面這些能力越值錢。**

| 能力 | 為什麼 AI 越強它越重要 | 這本書哪裡在練 |
|---|---|---|
| 會問問題 | AI 的答案品質取決於你問得好不好；問不出好問題的人，拿到的是平庸的答案 | 第 2 章 |
| 會查證 | AI 會一本正經地說錯；分得出真假的人才能安心用它 | 第 3 章 |
| 基礎程式 | 看得懂 AI 寫的程式才敢用；而且會寫一點的人能讓 AI 做十倍的事 | 第 6 章 |
| 基礎數學與資料 | AI 算出來的數字要有人驗算；看得懂圖表的人不會被騙 | 第 8 章、《從資料看世界》 |
| 表達與合作 | 把想法說清楚給人聽、和人一起做事，這是 AI 目前做不到的部分 | 第 10 章的討論活動 |
| 某個你真的有興趣的領域 | AI 是放大器：你在一個領域懂得越多，它放大的就越多；什麼都不懂，它放大的是零 | 第 12 章專題 |

有一句話值得記住：**AI 是放大器，不是替代品。** 它放大你已經會的東西。所以現在最重要的事，是讓「你已經會的東西」變多。

## 動手做

### 活動 11-1：訪問家人工作上怎麼用 AI

**材料／工具**：一位有工作的家人（父母、哥哥姊姊、叔叔阿姨都可以）、紙筆或手機錄音（要先問對方可不可以錄）、聊天型 AI（用來準備與整理）。

**步驟**：

1. 先請 AI 幫你準備訪談題目。貼這段：

```
我是國中生，要訪問一位家人「AI 怎麼改變他的工作」。他的職業是：＿＿＿（填一個大概的類別就好，例如「護理師」「工程師」「開店」「老師」，不要填公司名稱）。
請幫我設計 8 個訪談問題，由淺到深，前面問具體的事（用了什麼、做什麼），後面問感受和想法（擔心什麼、建議什麼）。
每個問題後面加一句「如果對方答得很短，可以追問什麼」。
```

2. 從 AI 給的問題裡挑 6 個，加上你自己最想問的 1 到 2 個。下面是一組參考，可以直接用：

```
1. 你工作上第一次用到 AI 是什麼時候、做什麼事？
2. 現在每天或每週會用 AI 做哪些事？
3. 有沒有一次 AI 幫了大忙？有沒有一次它害你出錯？
4. 公司或單位對用 AI 有什麼規定？哪些資料不能貼？
5. 你覺得你的工作哪些部分 AI 做得到、哪些做不到？
6. 和幾年前比，你的工作內容變了什麼？
7. 你擔心什麼？期待什麼？
8. 如果我以後想做你這一行，你覺得我現在該學什麼？
```

3. 約一個 20 分鐘的時間，面對面問。對方回答時，記重點就好，不要急著寫完整句子；答得短就用追問。
4. 訪問完，把你的筆記整理成文字。**整理前先去識別化**：把人名、公司名、客戶的資料拿掉，只留「一位護理師」「一家科技公司」。然後貼給 AI：

```
下面是我訪問一位家人「AI 怎麼改變他的工作」的筆記（已去除人名與公司名）。
請幫我整理成三段：(1) 他用 AI 做什麼；(2) AI 做得到與做不到的；(3) 他給國中生的建議。
只整理我寫的內容，不要補充我沒寫的事。如果有不清楚的地方，請列出來讓我回去問。

（貼上筆記）
```

5. 看 AI 整理的結果，對照你的筆記，確認它沒有「補充」你沒寫的東西。有不清楚的地方，回去再問家人一次。
6. 把最後的三段念給受訪的家人聽，問他「這樣寫對不對」。

**你應該看到／得到**：

- 一份 300 到 500 字的訪談整理，受訪者看過說「對」。
- 很常見的發現：家人用 AI 做的事比你想的「小」（寫信、整理會議紀錄、查資料），而且幾乎每個人都會說「最後還是要自己看過」。這和本書一直強調的事是一致的。
- AI 整理時偶爾會「順手」加上筆記裡沒有的句子（例如「他認為 AI 將大幅改變產業」），這就是為什麼步驟 5 要對照。

**觀察與記錄**：

| 項目 | 內容 |
|---|---|
| 受訪者的職業類別 | |
| 用 AI 做的三件事 | |
| 一次幫了大忙 | |
| 一次出錯 | |
| 單位的規定、不能貼的資料 | |
| 做得到／做不到 | |
| 給我的建議 | |
| AI 整理時有沒有多加東西？加了什麼？ | |

### 活動 11-2：畫出「目前的能力邊界圖」

**材料／工具**：聊天型 AI、紙筆、日曆（三個月後要再做一次）。

**步驟**：

1. 用下面六個測試題，一題一題貼給 AI，記錄結果。每一題都事先知道正確答案或可以查到。

```
測試 1（算術）：請計算 4,873 × 29，只給答案。
　　正確答案：141,317。你自己用計算機驗算。

測試 2（時事）：今天是幾月幾日？最近一週台灣有什麼重要新聞？
　　看它會不會說「我無法得知現在的日期」或「我的資料有截止日」。

測試 3（來源）：請給我三篇討論「國中生睡眠時間」的台灣研究，附上作者、年份、刊物名稱。
　　自己去查這三篇存不存在。

測試 4（在地）：台灣國中生升高中的主要入學管道叫什麼名字？
　　對照你學校輔導室或教育部網站的說法。

測試 5（圖中文字，若有圖像生成工具）：生成一張海報，上面要有「科學社招生」五個字。
　　看字有沒有拼對。

測試 6（長期記憶）：你還記得我上個星期問過你什麼嗎？
　　看它誠不誠實。
```

2. 每一題標記：做得好／做得不穩（答案部分對）／做不到（明確說不行或完全錯）。
3. 和本章「核心概念」的那張表對照，看有沒有不一樣的地方。AI 會變，你的表才是最新的。
4. 在日曆上三個月後的日期寫「重做能力測試」。到時候用同一組題目再做一次，比較哪些格子變了。

**你應該看到／得到**：

- 測試 1 可能對也可能錯；如果它說「我用程式計算」，通常會對。測試 2 多數 AI 會誠實說不知道日期（除非有連網功能）。測試 3 最容易出現幻覺：三篇裡常有一兩篇查不到。測試 4 要小心它給的是別的地方的名詞。測試 5 常常拼錯字。測試 6 大多會誠實說記不得，除非平台有記憶功能。
- 三個月後再做，你很可能看到一兩格從「不穩」變成「做得好」。這就是「用原理跟上變化」的感覺：題目沒變，你知道它在測什麼，所以變了也不會慌。

**觀察與記錄**：

| 測試 | 第一次（日期：＿＿） | 三個月後（日期：＿＿） | 變了嗎 |
|---|---|---|---|
| 1 算術 | | | |
| 2 時事 | | | |
| 3 來源 | | | |
| 4 在地 | | | |
| 5 圖中文字 | | | |
| 6 長期記憶 | | | |

## 用工具看看：開啟「搜尋」功能前後，比較同一題的答案

很多聊天型 AI 目前有一個可以開關的「網路搜尋」功能（名稱可能叫「搜尋」「瀏覽」「連網」）。它就是最簡單的「AI 代理」：AI 自己去搜尋、讀網頁，再回答。這個技巧讓你親眼看到「有工具」和「沒工具」的差別。

1. 先確認搜尋功能是關的（或用一個沒有搜尋功能的 AI）。問：

```
台灣目前的國中會考在每年幾月舉行？請附上你的資料來源。
```

2. 記錄它的答案和「來源」。去教育部或心測中心的網站查證。
3. 再開啟搜尋功能（通常在輸入框附近有一個地球或放大鏡的圖示，或在設定裡），問一模一樣的問題。
4. 比較三件事：
   - 答案一不一樣？
   - 這次的來源是不是真的連結？點進去看內容有沒有真的講到這件事。
   - 它有沒有說「根據某某網站」？
5. 最後問一個「今天」的問題（例如「今天台北的天氣如何」），看開了搜尋的 AI 怎麼回答、沒開的怎麼回答。

你應該看到：沒開搜尋時，AI 的答案來自訓練資料，可能過時、來源可能是編的；開了搜尋，它會列出真的網頁連結，但**連結是真的不代表它摘要得對**——你還是要點進去看。這正是 AI 代理的縮影：工具讓它更強，但檢查的責任還是在你。

| 問題 | 沒開搜尋的答案 | 來源查證 | 開了搜尋的答案 | 來源查證 |
|---|---|---|---|---|
| 會考月份 | | | | |
| 今天天氣 | | | | |

## 常見錯誤與迷思

- **「AI 已經什麼都會了」** → 它在「做得不穩」那一欄的事還很多，而且錯的時候一樣有自信。→ 正確理解：自己測過的能力表，才是你該相信的。
- **「AI 什麼都做不好，都是炒作」** → 它在改寫、解釋、寫短程式、整理資料這些事上已經很好用。→ 正確理解：兩個極端都不對；分清楚「好、不穩、做不到」三格。
- **「AI 代理可以放著讓它自己做，很省事」** → 它會真的做事，做錯了事情已經發生。→ 正確理解：權限給小、重要動作先確認、事後看紀錄。
- **「本地模型比較安全，所以也比較好」** → 目前本地模型的能力通常比雲端最強的模型弱。→ 正確理解：它解決的是隱私問題，不是能力問題；看你的需求選。
- **「新聞說某工作會消失，我就不要學那個了」** → 新聞來源可能有立場，而且「內容改變」比「消失」常見得多。→ 正確理解：問三個問題（誰說的、能不能自己試、對我有什麼差），再去訪問真的做那一行的人。
- **「既然 AI 會寫程式、會算數學，我就不用學了」** → 看不懂程式就不敢用它寫的程式；不會算就不知道它算錯。→ 正確理解：AI 是放大器，放大的是你已經會的東西。
- **「要一直追最新的 AI 工具才不會落後」** → 工具每個月換，追不完也不需要追。→ 正確理解：學原理、每隔幾個月重做一次能力測試，就夠了。

## 想一想

1. 請各舉一件「目前的 AI 做得好」「做得不穩」「做不到」的事，而且要是你自己測過的。

<details><summary>參考答案</summary>

答案依你的測試而定。常見的例子：做得好——把一段文字換三種方式解釋；做得不穩——列出真實存在的研究來源；做不到——知道今天發生的事（沒開搜尋時）。重點是「自己測過」，不是抄本章的表。

</details>

2. 「AI 代理」和一般聊天型 AI 最大的差別是什麼？這個差別帶來什麼新的風險？

<details><summary>參考答案</summary>

一般聊天型 AI 只「回答」，你自己去做；AI 代理會自己拆步驟、用工具（搜尋、開網頁、跑程式、寄信）去「做」。新的風險是：它做錯時事情已經發生，不像回答錯了你還能先判斷。所以要給小權限、重要動作先確認、事後看紀錄。

</details>

3. 小美想請 AI 幫忙整理她的日記，裡面有很多私事。「本地模型」和「雲端的 AI」她應該選哪一個？為什麼？有什麼代價？

<details><summary>參考答案</summary>

選本地模型比較適合，因為日記內容不會離開她的裝置，不需要相信任何公司的政策。代價是目前本地模型的能力通常比較弱，而且需要記憶體夠大的電腦或較新的手機。如果她的裝置跑不動，退而求其次是用雲端 AI 但先去識別化（第 9 章）。

</details>

4. 一則新聞標題：「AI 將在幾年內取代所有的翻譯工作」。請用本章的三個問題分析這則新聞。

<details><summary>參考答案</summary>

誰說的——如果是賣翻譯 AI 的公司，它有理由把話說滿；如果是翻譯工會，可能說得太悲觀。能不能自己試——可以：拿一段有雙關語或台灣在地用語的文字給 AI 翻，看它翻得如何。對我有什麼差——如果你喜歡語言，這則新聞不代表不該學；更可能的是翻譯工作的內容會變（例如變成校對與修改 AI 的翻譯），而這需要語言能力更好的人。

</details>

5. 為什麼說「AI 是放大器，不是替代品」？請用一個你自己的例子說明。

<details><summary>參考答案</summary>

因為 AI 放大的是你已經會的東西：會寫程式的人能讓它寫出十倍的程式而且看得出錯；不會的人連它寫錯了都不知道。例子（參考）：會一點英文的人請 AI 改作文，能判斷哪些建議該採納；完全不會的人只能照單全收，連 AI 改錯了也不知道。

</details>

6. 開放挑戰：根據你在活動 11-1 的訪談和活動 11-2 的測試，寫一段 200 字給「三年後的自己」的信，內容是：你現在認為 AI 到哪裡了、你決定在這三年練哪兩項能力、為什麼。把信存起來，三年後打開看哪些猜對了。

<details><summary>參考答案</summary>

開放題。一封好的信會有：具體的「目前」描述（用你自己測的結果，而不是新聞的說法）、兩項明確的能力（例如「會查證」「會寫 Python」），以及和訪談內容連結的理由（例如「因為媽媽說她們醫院最需要的是看得懂 AI 報告的人」）。不用猜對，三年後比對的過程本身就是學習。

</details>

## 本章小結

- 描述 AI 能力時永遠加上「目前」：它在改寫、解釋、短程式、整理資料上做得好；在算術、引用來源、在地細節、長篇一致上不穩；不知道現在的事、不負責任、不真的理解你。
- 「做得不穩」的意思是對錯交雜而且一樣有自信，所以查證永遠不會過時。
- 多模態：同一個 AI 能讀文字、圖、聲音、影片；上傳前記得檢查有沒有個資。
- AI 代理：給目標、它自己拆步驟用工具去做。原則是權限給小、重要動作先確認、事後看紀錄。
- 本地模型：模型在自己的裝置上跑，資料不出門；目前能力較弱，但是隱私問題的另一種解法。
- 看 AI 新聞問三題：誰說的、能不能自己試、對我有什麼差。學原理不追名字，每隔幾個月重做能力測試。
- AI 是放大器，不是替代品：會問問題、會查證、基礎程式與數學、表達與合作、一個真正有興趣的領域，AI 越強這些越值錢。
- 親自訪問做那一行的人，比任何新聞都準。
