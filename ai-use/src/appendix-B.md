# 附錄 B　查證檢查表

這一頁是「AI 說了一件事，我該不該信」的時候翻的。分五個部分：**B.1 查證五步驟**（可以印出來勾的檢查表）、**B.2「絕對要查」清單**、**B.3 辨識 AI 生成文字的線索**、**B.4 辨識 AI 生成圖片、聲音與影片的線索**、**B.5 常見幻覺類型表**。最後 B.6 是一張空白的查證記錄表。

先講一個原則：**查證不是因為 AI 很笨，而是因為它的工作是「產生看起來合理的下一個字」，不是「確認這件事是真的」。** 它說對的時候和說錯的時候，語氣一模一樣。所以不能用「聽起來有沒有道理」來判斷，要用「原始資料怎麼說」來判斷。想知道為什麼會這樣，可以看《AI 怎麼運作》（https://book.vichuang.tw/ai-theory/ ）。

---

## B.1　查證五步驟檢查表

拿到一個 AI 的回答，照這五步走。每一步後面有一個「怎麼做」與一個「過關條件」。

| 步驟 | 怎麼做 | 過關條件 | 勾 |
|---|---|---|---|
| 1. 這件事重要嗎？ | 看 B.2 的清單。如果答案會影響健康、錢、法律、成績、或要說給別人聽，就是重要。 | 重要 → 走完五步；不重要 → 可以直接用，但不要轉述給別人 | [ ] |
| 2. 問來源 | 「請列出這個說法的來源：作者或機構、標題、年份，並說明你對它存在的把握度。」 | AI 給出具體到可以搜尋的來源，而不是「許多研究顯示」 | [ ] |
| 3. 確認來源存在 | 把來源的標題與作者丟進搜尋引擎。找到就開來看，找不到就記「查無此資料」。 | 至少一個來源真的找得到，而且內容和 AI 說的一樣 | [ ] |
| 4. 交叉查 | 用另一個 AI、課本、維基百科、官方網站問同一件事，看說法一不一致。 | 兩個以上「彼此獨立」的來源說法一致（兩篇都引用同一項研究只算一個） | [ ] |
| 5. 看原始資料 | 找到最源頭的資料（研究本身、政府統計、官方公告、原書），讀它實際寫什麼，不只讀標題。 | 你能用自己的話說出原始資料的結論與限制 | [ ] |

走完五步仍然找不到足夠資料的，結論寫「無法判定」。這是誠實的答案，不是失敗。

**省力版（不重要的事）**：只做步驟 2 與 3。AI 給得出來源、來源找得到，就可以暫時相信。

## B.2　「絕對要查」清單

下面這些類型，無論 AI 講得多肯定，都要走完五步才能用。右欄是建議的「原始資料去哪裡找」。

| 類型 | 為什麼特別危險 | 原始資料去哪裡找 |
|---|---|---|
| **醫療與健康**：症狀、藥物、劑量、療法、飲食建議 | 錯了會傷身體；AI 不知道你的身體狀況 | 衛生福利部、疾病管制署、食藥署網站；醫院衛教網頁；有執照的醫師、藥師 |
| **法律與規定**：法條內容、罰則、年齡限制、合約條款 | AI 常編出不存在的條號，或引用已經修改的舊版 | 全國法規資料庫；主管機關網站；學校的正式公告 |
| **金錢**：價格、匯率、利率、手續費、優惠方案 | 這些天天變，AI 的資料是過去的 | 官方網站、實際店家、銀行公告 |
| **歷史日期與人物**：年份、誰做了什麼、引文是誰說的 | 最常見的幻覺類型之一，日期差幾年、人名張冠李戴 | 課本、百科全書、博物館與檔案館網站、原始文獻 |
| **統計數字與資料**：人口、比例、排名、「最高／最低」 | AI 會編一個聽起來合理的數字 | 政府統計（主計總處、各部會統計處）、國際組織（世界銀行、世界衛生組織等）的原始資料 |
| **科學研究的結論**：「研究顯示……」 | AI 會編研究、誇大結論、或把初步研究講成定論 | 找到研究本身；看大學、研究機構、科學中心的說明 |
| **引文與名言**：「某某人說過……」 | 很多名言根本不是那個人說的 | 原書、原演講的紀錄；可靠的名言查證網站 |
| **程式與指令**：會刪東西、改設定、連網路的指令 | 跑錯一行可能刪掉檔案或改壞電腦 | 先在測試環境跑；官方文件；問懂的大人 |
| **地點、營業時間、聯絡方式** | AI 可能給過時或根本不存在的資訊 | 官方網站、地圖 App、直接打電話 |
| **關於你自己或你認識的人** | AI 不認識你，它會「猜」 | 不要問，也不要把這些資料貼進去 |
| **任何你要轉述給別人、寫進作業、或拿來做決定的事** | 錯誤會從你身上傳出去 | 以上全部 |

**一句話版**：會影響身體、錢、法律、成績，或要說給別人聽的，一律查。

## B.3　辨識 AI 生成文字的線索

先講最重要的一件事：**沒有任何一條線索是鐵證。** 有些人寫作本來就像 AI，而且 AI 的文風一直在變。市面上的「AI 偵測工具」常常把真人寫的判成 AI、把 AI 寫的判成真人，不能當證據。這些線索的用途是「提高警覺，去查證」，不是「宣判」。

### 文字本身的線索

| 線索 | 說明 | 例子 |
|---|---|---|
| 結構太整齊 | 每段長度差不多、每段都用「首先／其次／最後」、結尾一定有總結 | 「總而言之，這個議題需要我們共同努力。」 |
| 什麼都講、什麼都不深 | 列出五個面向，每個講兩句，沒有一個講到具體細節 | 「教育、經濟、環境、科技與文化都受到影響。」 |
| 沒有具體的人、事、時、地 | 真人寫經驗會有「上禮拜三」「我阿嬤家」「那家在巷口的店」 | 「許多人在日常生活中都會遇到這樣的情況。」 |
| 平衡到沒有立場 | 每個論點後面都接「然而另一方面」，最後說「各有優缺點」 | 「雖然有好處，但也存在挑戰，需要平衡考量。」 |
| 用詞過度漂亮或抽象 | 「深入探討」「至關重要」「多元面向」「不可或缺」連續出現 | — |
| 數字與來源太剛好 | 「研究顯示 73% 的人……」卻沒說哪個研究 | — |
| 不會犯「人會犯的錯」 | 沒有錯字、沒有口語、沒有突然離題 | — |
| 和作者平常的風格落差太大 | 這是老師最常用的線索：平常寫 200 字很吃力，突然交出 800 字漂亮文章 | — |

### 情境的線索

- 文章裡的「事實」查起來不存在（B.5 的幻覺類型）。
- 問作者「這一段為什麼這樣寫」，答不出來。
- 文章用了作者不可能知道的資料，或相反，漏掉了作者明明知道的事。

### 對自己的提醒

這些線索也可以反過來用：**你用 AI 潤稿之後，檢查一下自己的文章有沒有變成上面那樣。** 如果有，代表 AI 把你的聲音洗掉了，回去把具體的例子、你的語氣、你的立場放回來（第 5 章）。

## B.4　辨識 AI 生成圖片、聲音與影片的線索

同樣先講：**這些線索每幾個月就會失效一些**，因為生成工具一直進步。今天看得出來的破綻，明年可能就沒有了。所以最可靠的方法永遠是**回到來源**：這張圖最早是誰發的？有沒有原始的新聞或機構發布？

### 圖片

| 看哪裡 | 常見破綻 |
|---|---|
| 手與手指 | 手指數量不對、關節彎的方向怪、兩隻手交握處糊成一團 |
| 文字 | 招牌、書本、衣服上的字是歪的、拼錯、像字但不是字 |
| 眼睛與牙齒 | 兩眼反光不一致、牙齒數量或排列怪、瞳孔形狀不對稱 |
| 耳環、眼鏡、飾品 | 左右不對稱、眼鏡腳消失在臉裡 |
| 背景 | 直線在遠處突然彎掉、重複的圖案、背景的人臉糊掉 |
| 光影 | 影子方向和光源不一致、物體沒有影子、反射裡的東西和實物不同 |
| 物理不合理 | 東西穿過其他東西、水面倒影不對、頭髮和背景融在一起 |
| 太完美 | 皮膚沒有毛孔、所有東西都對焦、構圖像海報 |
| 細看邊緣 | 放大看頭髮、毛髮、樹葉的邊緣，常有融化或抹開的感覺 |

### 聲音

- 語調太平，沒有真人說話的呼吸、停頓、吞口水。
- 情緒和內容不搭（講悲傷的事語氣卻很平）。
- 背景音突然消失或突然出現。
- 關鍵提醒：**熟人的聲音打電話來要錢，就算聲音一模一樣，也要掛掉用你自己存的號碼打回去確認**（第 9 章）。

### 影片

- 臉的邊緣（髮際線、下巴、脖子）有閃爍或模糊。
- 眨眼太少、太規律，或嘴型和聲音對不上。
- 臉轉側面時變形。
- 影片畫質刻意很差（用來掩蓋破綻）。
- 內容「太剛好」：某個名人說了一句極端的話、而且只有這一個來源。

### 不管圖片、聲音、影片，最重要的三個動作

1. **找最早的來源**：用圖片反向搜尋，看這張圖最早出現在哪裡、原本的說明是什麼。
2. **找第二個獨立來源**：真的發生的大事，不會只有一個帳號有。
3. **問一個大人**：尤其牽涉到錢、名人說了什麼、要你轉傳的時候。

## B.5　常見幻覺類型表

幻覺（Hallucination）是 AI 一本正經說出不存在或錯誤內容的現象。下面是最常見的八種，每一種都附「怎麼抓」。

| 類型 | 它會怎麼做 | 典型例子 | 怎麼抓 |
|---|---|---|---|
| **編造來源** | 給出作者、標題、年份、期刊都很像真的，但根本不存在的文獻或網址 | 「根據陳○○（2019）發表於《台灣教育研究》的研究……」 | 搜標題與作者；點網址看是不是 404 |
| **張冠李戴** | 事情是真的，但做的人、說的人、發生的地方錯了 | 把 A 的名言說成 B 說的 | 查原始出處 |
| **數字漂移** | 數字聽起來合理，但和真實值差一截，或單位錯 | 人口、距離、百分比、年份差個幾年 | 查官方統計；注意單位 |
| **過時資訊** | 講的是它訓練資料裡的舊狀態，現在已經變了 | 價格、法規、職位、「最新的」產品 | 查官方網站、看日期 |
| **誇大結論** | 研究是真的，但結論被講成「證實」「一定」 | 「研究證實吃 X 可以預防癌症」 | 讀研究本身：樣本多大、是不是初步研究、結論怎麼寫 |
| **編造功能或規則** | 說某個軟體有某個按鈕、某個遊戲有某條規則、某法條有某項內容 | 「在設定裡點『進階』就可以……」 | 實際去找；查官方文件或法規資料庫 |
| **順著你的話說** | 你的問題裡藏了錯誤前提，它不糾正，直接順著編 | 「為什麼台灣的 X 是全世界最高？」（其實不是） | 問題改成中性的：「台灣的 X 在世界排第幾？來源是？」 |
| **假裝算對** | 數學、單位換算、日期計算看起來有步驟，但中間算錯 | 長除法、百分比、日期差幾天 | 自己驗算；用計算機或試算表重算一次 |

### 讓 AI 幫忙抓自己的錯（有用，但不能取代你查）

```
請重新檢查你剛才的回答，逐一列出裡面的「可以被查證的事實」（人名、數字、日期、來源），並對每一項標出你的把握度（高／中／低）。把握度中或低的，請直接說「我不確定」。
```

它標「低」的地方優先查。但要記得，它標「高」的也可能錯。

## B.6　查證記錄表（空白，請自行複製）

每次查證一件事就填一列。第 3 章活動與第 12 章專題三都用這張表。

| 日期 | AI 說的事（一句話） | AI 給的來源 | 來源存在？（是／否／找不到） | 第二個來源說什麼 | 原始資料說什麼 | 判定（正確／大致正確／部分正確／錯誤／無法判定） | 備註 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |

### 判定等級說明

| 等級 | 意思 |
|---|---|
| 正確 | 至少兩份獨立原始資料支持，沒有可靠的反證 |
| 大致正確 | 核心沒錯，但數字、範圍或條件被講過頭 |
| 部分正確 | 某些情況對、某些情況錯，要看條件 |
| 錯誤 | 至少兩份獨立原始資料反駁 |
| 無法判定 | 找不到足夠的原始資料；要寫出找了哪些地方 |
