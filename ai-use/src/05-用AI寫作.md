# 第 5 章　用AI寫作

## 本章目標
- 學完你會說出寫作的五個階段，以及 AI 在每個階段「適合幫什麼、不該幫什麼」。
- 學完你會用 AI 做腦力激盪與列大綱，但題目的主張和例子仍然是自己的。
- 學完你會請 AI 當讀者給回饋、做潤稿，而不是請它代寫。
- 學完你會分辨「AI 代寫」和「AI 修改」的文章差在哪裡，並且保住自己的聲音。
- 學完你會說出學校作文與報告的誠實界線，並且會用一段話標註自己怎麼用了 AI。

## 開場：那篇不像小安的作文

國文老師出了作文題目〈一次失敗的經驗〉，600 字，週五交。週四晚上十點，小安還在盯著空白的作業簿。他打開聊天型 AI，輸入題目和字數，三秒後，一篇結構完整、辭藻優美的文章出現了：「失敗猶如夜空中的流星，短暫卻照亮前行的道路……」小安複製、抄寫、交出去。

週一發回來，分數不低，但老師在旁邊寫了一句話：「這篇文章很漂亮，但我看不到你。你上次寫的〈我的阿公〉，有一段寫阿公的手『像樹皮一樣，摸起來刺刺的』，那才是小安。」

小安有點被說中。那篇 AI 寫的文章，裡面的「失敗」是什麼失敗？他自己都講不出來。而他真正的失敗經驗——上學期籃球校隊落選，在球場邊假裝綁鞋帶不讓人看到自己紅眼睛——一個字都沒寫進去。

這一章要解決的問題是：**AI 明明這麼會寫，為什麼不該讓它替你寫？以及，它到底可以幫你什麼？**

## 核心概念

### 寫作的五個階段，AI 該站在哪裡

寫作不是「坐下來然後文章就出來」，它是一條流程：

```
  ① 想點子  ──►  ② 列大綱  ──►  ③ 寫初稿  ──►  ④ 修改  ──►  ⑤ 定稿
   (發散)        (排順序)       (自己寫)      (再讀再改)    (檢查交出)
```

AI 在每一階段的角色不一樣：

| 階段 | AI 適合做的 | AI 不該做的 |
|---|---|---|
| ① 想點子 | 丟問題幫你挖出自己的經驗、列可能的切入角度 | 替你決定要寫什麼經驗 |
| ② 列大綱 | 幫你把亂七八糟的點子排順序、指出邏輯缺口 | 把大綱直接變成文章 |
| ③ 寫初稿 | **什麼都不做**（這一段關掉它） | 寫任何一個段落 |
| ④ 修改 | 當讀者說哪裡看不懂、挑錯字與文法、建議句子怎麼更順 | 整段重寫、換掉你的例子 |
| ⑤ 定稿 | 幫你檢查格式、字數、有沒有漏掉題目要求 | 代替你決定要不要接受它的修改 |

關鍵在第三階段。**初稿一定要自己寫**，因為初稿是你的想法第一次從腦袋變成文字的地方，這一步跳過，後面的一切都是在修別人的文章。

### 用法一：腦力激盪——請 AI 問你，而不是告訴你

空白頁最可怕的不是不會寫，而是不知道要寫什麼。這時候很多人的直覺是問 AI「〈一次失敗的經驗〉可以寫什麼？」然後得到一串「考試失利、比賽落敗、友情破裂……」這些都是別人的失敗，不是你的。

更好的做法是**反過來，請 AI 問你**：

```
我要寫一篇作文〈一次失敗的經驗〉，但還不知道要寫哪一件事。
請不要給我建議的題材。請一次問我一個問題，幫我回想自己真正經歷過的失敗，
例如問我「最近一次覺得丟臉是什麼時候」。我回答之後再問下一個，問 5 個就停。
```

回答五個問題之後，你通常已經知道要寫什麼了。這種用法叫**蘇格拉底式提問（Socratic Questioning）**：用問題引出你腦袋裡本來就有的東西。點子是你的，AI 只是把它挖出來。

### 用法二：大綱——幫你排順序，不幫你寫

有了題材，把你想到的東西亂序丟給 AI：

```
我決定寫「籃球校隊落選」。我想到的片段有：
- 公布名單那天在球場邊假裝綁鞋帶
- 教練說我投籃不穩
- 後來每天早上練投 100 球
- 下學期補選進去了
- 其實我一開始是為了跟好朋友一起才去考的
請幫我把這些排成一個 600 字作文的大綱（開頭、三段主體、結尾），
每段用一句話說明重點。不要幫我寫內文。
```

AI 會排出順序、可能建議「把『為了跟好朋友』放在開頭當動機」。你可以接受，也可以說「我想把綁鞋帶那段放在最前面當開場」。大綱是骨架，骨架可以討論；但肉一定要自己長。

### 用法三：潤稿而不是代寫

初稿寫完了（恭喜，這是最難的一步），接下來 AI 才真正派上用場。但「潤稿」和「代寫」只有一線之隔，差別在**你給它多大的權限**。

| 你說的話 | 結果 | 這是 |
|---|---|---|
| 「幫我改好這篇」 | 它整篇重寫，用它的句子換掉你的 | 代寫 |
| 「幫我潤飾」 | 它大幅改寫，風格變成它的 | 多半還是代寫 |
| 「只改錯字和明顯不通的句子，用表格列出改了哪裡、為什麼，其他不要動」 | 它列出 5 到 10 處，你決定要不要接受 | 修改 |
| 「當讀者告訴我哪一段看不懂、哪裡沒說服你，不要替我改」 | 它給你三點回饋，你自己改 | 修改 |

請記住這個口訣：**請它「指出」，不要請它「改掉」。** 指出之後，改的人是你。每一處修改你都要看過、想過、決定接受或拒絕，這樣改完的文章才還是你的。

### 用法四：請 AI 當讀者

作家修改文章最需要的是一個誠實的讀者。AI 當讀者有個好處：它不怕傷你的心，也不會因為跟你很熟而放水。給它一個明確的讀者身分：

```
請你扮演一位國中國文老師，讀下面這篇作文。不要替我改寫。
請只告訴我三件事：
1. 哪一段讓你最有感覺，為什麼？
2. 哪一句你看不懂或覺得沒說清楚？
3. 如果只能改一個地方，你會建議改哪裡？
〔貼上你的作文〕
```

你也可以換讀者：「扮演一個對籃球完全沒興趣的同學」，看它會不會覺得無聊；「扮演一個很嚴格的評審」，看它挑什麼毛病。不同的讀者會給你不同的角度。

### 保留自己的聲音

每個人寫字都有一種「腔」，這叫**聲音（Voice）**。小安的聲音是「像樹皮一樣，摸起來刺刺的」；AI 的聲音是「猶如夜空中的流星」。AI 的句子漂亮但平均，因為它是從幾億篇文章學來的「大家都這樣寫」；你的句子可能不漂亮，但只有你寫得出來。

怎麼保住聲音？三個做法：

1. **具體的事留著。** AI 建議把「假裝綁鞋帶」改成「掩飾內心的失落」時，拒絕。前者是畫面，後者是口號。
2. **它改的句子念出聲音。** 念起來不像你會說的話，就不要用。
3. **每收一處修改，問自己「我學到什麼」。** 如果是「原來這裡少了主詞」，很好；如果只是「它的比較美」，小心，那不是進步，那是替換。

### 學校作業的誠實界線

第 4 章講的原則在這裡完全適用：**作業是為了讓你學會，「學會」的那部分不能外包。** 作文作業要學的是「把自己的想法變成文字」，所以這個動作必須由你做。

但寫作的灰色地帶比數學多得多，下面這張表幫你判斷：

| 做法 | 可以嗎 | 要標註嗎 |
|---|---|---|
| 請 AI 問我問題，幫我想題材 | 可以 | 建議標註 |
| 請 AI 排大綱順序 | 可以 | 要 |
| 請 AI 寫任何一段，然後自己改幾個字 | 不可以 | 這是代寫，標註了也不行 |
| 自己寫完，請 AI 挑錯字和文法 | 可以 | 要 |
| 自己寫完，請 AI 當讀者給回饋，自己修改 | 可以 | 要 |
| 請 AI 「潤飾」整篇，接受全部修改 | 不建議 | 多數老師會視為代寫 |
| 老師說這次不能用 AI | 一律不行 | — |
| 比賽、升學用的作品 | 先查比賽規則，多數禁止 | 依規則 |

兩個判斷工具：

- **關機測試**：關掉 AI，你能不能用自己的話講出這篇文章的每一段在說什麼、為什麼這樣寫？講不出來，就不是你的。
- **老師在場測試**：如果老師坐在旁邊看你操作，你會不會想把視窗縮小？會，就代表你心裡知道這不行。

**怎麼標註。** 在文章最後加一段，寫清楚工具、步驟、自己做的部分。例如：

> 使用說明：本文初稿由本人獨立完成。寫作前曾使用聊天型 AI 以問答方式協助回想題材；完稿後請 AI 指出 6 處錯字與 2 句不通順的句子，由本人自行修改，其中 1 處建議未採用。文章內容、例子與觀點皆為本人所有。

這段話有三個好處：老師知道你誠實；你自己留下了紀錄；萬一有人質疑，你拿得出證據（本章「用工具看看」會教你怎麼留證據）。

## 動手做

### 活動 5-1：自己寫 150 字，再請 AI 給三點建議

**材料／工具**：聊天型 AI、紙筆或文書軟體、計時器。

**步驟**：

1. 題目：〈我最喜歡的一個地方〉。設定 15 分鐘計時，**不開 AI**，寫 150 字左右。寫不好沒關係，寫完就好。
2. 寫完先自己讀一遍，在旁邊寫下「我覺得最弱的一句是……」。
3. 把文章貼給 AI，用這個提示詞：

```
下面是我寫的 150 字短文〈我最喜歡的一個地方〉。請你扮演一位耐心的寫作老師。
不要替我改寫任何句子。請只給我三點建議，每一點要指出是哪一句、
問題是什麼、以及一個「可以怎麼想」的方向（不要直接給改好的句子）。
最後告訴我，哪一句是這篇最好的，為什麼。
〔貼上短文〕
```

4. 看完三點建議，自己動手改。每一點決定「接受／部分接受／拒絕」，並寫下理由。
5. 把改好的版本再貼一次，問：「比起上一版，哪裡進步了？還有哪裡可以更好？」只改一輪，不要無限改下去。
6. 把它說「最好的一句」和你步驟 2 寫的「最弱的一句」比一比。

**你應該看到／得到**：AI 的回應應該是三點條列，每一點引用你的原句，說明問題，但**沒有**給你改好的句子。如果它忍不住給了改寫版，回它「我說不要改寫，請只說方向」。它說「最好的一句」通常會是你寫得最具體、最有畫面的那一句，這就是你的聲音所在。改完的版本應該還是你的句子、你的例子，只是更通順。

**觀察與記錄**：

| 項目 | 記錄 |
|---|---|
| 我自己認為最弱的一句 | |
| AI 的三點建議（簡記） | |
| 每一點我的決定（接受／部分／拒絕）與理由 | |
| AI 認為最好的一句 | |
| 修改後我的字數、改了幾處 | |
| 改完之後，念起來還像我嗎 | |

### 活動 5-2：比較「AI 代寫」與「AI 修改」

**材料／工具**：聊天型 AI、活動 5-1 寫好的短文、一位願意幫你讀的家人或同學。

**步驟**：

1. 開一個新的對話，請 AI 代寫同一題：

```
請寫一篇 150 字的短文〈我最喜歡的一個地方〉，國中生程度。
```

這是「版本 A：AI 代寫」。

2. 把活動 5-1 你自己修改完成的版本當作「版本 B：AI 修改」。
3. 把兩篇並排，自己先填下面的比較表。
4. 把兩篇（不要說哪篇是誰寫的）拿給家人或同學讀，問他們兩個問題：「哪一篇比較像真的有人去過那個地方？」「哪一篇你猜是小安寫的？」
5. 最後做一個實驗：把版本 A 貼回 AI，問它「這篇文章有哪些具體的細節是只有作者本人才知道的？」看它答得出來嗎。

**你應該看到／得到**：版本 A 通常句子漂亮、結構工整，但地點模糊（「一個寧靜的角落」）、細節通用（「陽光灑落」）、沒有只屬於你的事件。版本 B 可能句子沒那麼美，但有專屬細節（「阿嬤家的鐵皮屋頂下雨會像在炒豆子」）。家人多半能一眼認出哪篇是你寫的。步驟 5 的 AI 通常會承認版本 A「沒有專屬作者的細節」，這就是代寫文章的破綻。

**觀察與記錄**：

| 比較項目 | 版本 A（AI 代寫） | 版本 B（AI 修改） |
|---|---|---|
| 地點是否具體（有名字、有位置） | | |
| 專屬細節有幾個（只有你知道的事） | | |
| 有沒有「猶如、彷彿、灑落」這類漂亮但空的詞 | | |
| 家人猜哪篇是你寫的 | | |
| 關掉 AI 後，我講得出每一句為什麼這樣寫嗎 | | |

## 用工具看看：用對照表保留修改紀錄

誠實使用 AI 最好的證據，就是「修改紀錄」：證明文章是你寫的、AI 只改了哪幾處。做法是請 AI 把修改用表格列出來，再存到你的文件裡。

1. 把你的初稿貼給 AI，加上這句：

```
請只修正錯字、標點和明顯不通的句子，不要改寫風格或換掉例子。
用三欄表格輸出：「原句」「建議修改」「原因」。不要輸出整篇改好的文章。
```

2. AI 會給你一張表，例如：

| 原句 | 建議修改 | 原因 |
|---|---|---|
| 我每次去那裡都很開心，很放鬆。 | 我每次去那裡都很放鬆。 | 「開心」與「放鬆」重複，留一個較精準的 |
| 阿嬤家的屋頂下雨的時候很吵 | 阿嬤家的鐵皮屋頂一下雨就很吵 | 補上「鐵皮」讓讀者有畫面 |

3. 在表格右邊自己加一欄「採用？」，逐行寫 ○ 或 ×，拒絕的寫一句理由。
4. 把這張表貼在你作文文件的最後面（或另存一頁），標題寫「AI 修改紀錄」。
5. 如果用 Google 文件或 Word 寫作，再打開「版本紀錄」功能看一眼：它會自動記下你每一次的修改時間。初稿到定稿的時間軸，就是「這篇是我寫的」最好的證明。

這張表還有一個隱藏的好處：你把它們累積三個月再回頭看，會發現自己老是犯同一種錯（例如一句話塞兩個「很」）。那就是你下一步要練的東西。

## 常見錯誤與迷思

- **「AI 寫得比我好，用它的不是對讀者比較好嗎？」** → 作業的讀者是老師，老師要看的是你的想法和進步，不是一篇漂亮的文章。 → 初稿自己寫，AI 只用來指出問題。
- **「我只是請它『潤飾』，不算代寫。」** → 「潤飾」這個詞太寬，AI 常常整篇重寫。 → 把權限講窄：只改錯字、用表格列出修改處、不換例子。
- **「我把 AI 寫的改了很多，所以算我的。」** → 骨架、例子、觀點都是它的，你只是換了皮。 → 用關機測試：你講得出每一段為什麼這樣寫嗎？
- **「標註了用 AI 會被扣分，不如不說。」** → 不說被發現，後果嚴重得多；誠實的標註大多數老師會肯定。 → 不確定規定就先問老師。
- **「AI 說我的文章『情感真摯、結構完整』，所以寫得不錯。」** → AI 預設很會讚美，稱讚不等於評價。 → 要求它「只講缺點」或「扮演嚴格評審」。
- **「AI 的建議一定要全部接受。」** → 它不認識你、不知道你想表達什麼，有些建議會把你的特色改掉。 → 每一處都要自己決定，拒絕也要寫理由。

## 想一想

1. 小安問 AI「〈一次失敗的經驗〉可以寫什麼？」和問「請一次問我一個問題幫我回想」，兩種問法得到的題材有什麼不同？

<details><summary>參考答案</summary>

第一種得到的是通用的、別人的題材清單（考試失利、比賽落敗）；第二種得到的是小安自己經歷過的事（校隊落選、綁鞋帶）。前者是 AI 的點子，後者是用問題把小安自己的記憶挖出來。只有後者寫出來會有專屬細節。

</details>

2. 「幫我潤飾這篇」和「只改錯字，用表格列出改了哪裡」這兩個提示詞，為什麼結果會差那麼多？

<details><summary>參考答案</summary>

因為給 AI 的權限不同。「潤飾」沒有範圍，AI 會依自己的風格大幅重寫；「只改錯字＋表格列出」限制了它能動的範圍和輸出格式，而且逼它說明每一處理由，你才有辦法逐一決定接受或拒絕。權限越窄，文章越保得住是你的。

</details>

3. 版本 A（AI 代寫）的文章常有「陽光灑落」「寧靜的角落」這類句子。為什麼 AI 特別容易寫出這種句子？（提示：想想它是怎麼學會寫作的。）

<details><summary>參考答案</summary>

AI 是從大量文章學「最常見的寫法」，所以它寫出來的是「平均值」：大家都會用的漂亮詞、大家都寫過的場景。它沒有去過任何地方，寫不出只有你知道的細節。這也是辨識 AI 代寫文章的線索之一（附錄 B 有更多線索）。

</details>

4. 下面三種情況，各要不要標註使用了 AI？（a）請 AI 查一個成語的意思；（b）請 AI 排了大綱順序；（c）自己寫完請 AI 當讀者給三點回饋後自己改。

<details><summary>參考答案</summary>

(a) 一般不用，這和查字典相同。(b) 要，大綱影響了文章結構。(c) 要，AI 的回饋影響了修改方向。標註的原則是「AI 有沒有影響作業的內容或結構」，有就標。最保險的做法是問老師規定。

</details>

5. 小安用 AI 代寫了作文，但他把每個 AI 的句子都「改寫成自己的話」。請用「關機測試」和「老師在場測試」分析這算不算他的作品。

<details><summary>參考答案</summary>

關機測試：他能說出每一段為什麼這樣安排嗎？不能，因為結構和例子都是 AI 決定的。老師在場測試：老師看到他是從 AI 文章改寫而來，他會想縮小視窗嗎？會。兩項都沒過，所以這是代寫的換皮版，不是他的作品。真正的做法是從自己的初稿開始。

</details>

6. 開放挑戰：有人說「以後大家都用 AI 寫東西，學寫作沒意義了」。請寫 100 字反駁或贊成，然後把這 100 字貼給 AI，請它找出你論證最弱的一點，再修改一次。

<details><summary>參考答案</summary>

開放題。可參考的反駁方向：寫作練的是「想清楚」而不只是「寫出來」，想不清楚的人連提示詞都寫不好；AI 寫的是平均值，獨特的觀點和經驗仍然只有人寫得出來；而且判斷 AI 寫得好不好，本身就需要寫作能力。這一題的真正練習是第二步：讓 AI 攻擊你的論證，你再補強。這正是本章教的「指出，不要改掉」。

</details>

## 本章小結

- 寫作分五個階段：想點子、列大綱、寫初稿、修改、定稿；初稿一定自己寫，AI 在這一段要關掉。
- 腦力激盪時請 AI「問你」而不是「告訴你」，題材才會是你自己的。
- 大綱可以請 AI 排順序，但內文不能請它寫。
- 潤稿的口訣：請它「指出」，不要請它「改掉」；權限講窄、要求表格、每一處自己決定。
- 保住聲音：具體的事留著、改的句子念出聲、問自己學到什麼。
- 誠實界線：學會的那部分不外包；用關機測試與老師在場測試自我檢查；用了就在文末標註工具、步驟、自己做的部分。
- 用「原句／修改／原因」對照表和文件的版本紀錄，留下文章是你寫的證據。
