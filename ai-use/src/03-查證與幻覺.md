# 第 3 章　查證與幻覺

## 本章目標

學完這一章，你會：

- 說出 AI 最常見的四種錯法：編造來源、編造數字、編造引文、編造法條或日期。
- 用「問來源 → 交叉查 → 找原始資料」三步驟查證一段 AI 的回答。
- 背出「絕對要查」的清單：醫療、法律、金錢、歷史日期、數據、引用。
- 用三個技巧讓 AI 自己檢查，並知道這些技巧的極限。
- 親手讓 AI 說錯一次、抓到它，並完整查證一篇它寫的短文。

## 開場：那本不存在的書

小祐的國文報告要引用一本書來支持自己的論點。他請 AI 推薦，AI 給了他三本書，每一本都有書名、作者、出版社、出版年份，甚至還附了一句「書中提到……」的引文。

他挑了一本，把引文抄進報告。老師看了很有興趣，想借來讀，去圖書館查，查不到；去書店網站查，查不到；查作者的名字，是一位真的存在的教授，但他從來沒寫過那本書。

老師沒有罵小祐，但她在報告上寫了一句話：「你有沒有自己看過這本書？」

小祐沒有。他相信了一個接龍機器接出來的書名、作者和引文，然後把它放進自己的名字底下。

這一章要教你的，就是讓這件事不再發生：不是不用 AI，而是用完之後，知道哪些東西要查、怎麼查、查到什麼程度才夠。

## 核心概念

### AI 怎麼錯：四種最常見的幻覺

第 1 章說過，聊天型 AI 在預測合理的下一個字，不是在查資料。所以它最容易錯的，就是那些「格式很固定、細節很具體、但它其實沒讀過或讀得很少」的東西。整理起來有四種：

| 錯法 | 長什麼樣 | 為什麼會發生 |
|---|---|---|
| **編造來源** | 給你一本書、一篇論文、一個網址，看起來格式完美，但不存在 | 它讀過幾百萬筆書目與網址，知道「來源長什麼樣」，接出來的東西格式對、內容是拼湊的 |
| **編造數字** | 「台灣有 68% 的國中生每天用手機超過三小時」，說得很精確，但查不到出處 | 它知道「統計數字的句子長什麼樣」，數字是接出來的「合理值」，不是查到的 |
| **編造引文** | 「愛因斯坦說過：『……』」，話很有道理，但他沒說過 | 名人語錄在網路上本來就錯很多，它學到的就是錯的，或者它把「像那個人會說的話」接出來 |
| **編造法條、日期、人名** | 「根據《民法》第 1234 條……」「某某事件發生於 1987 年 3 月」「第一任校長是陳〇〇」 | 法條編號、日期、人名是「細節中的細節」，它讀過的往往不夠多或互相矛盾，就接出一個像的 |

除了這四種，還有兩種不算幻覺、但一樣會讓你出錯的情況：

- **過時**：它的訓練資料有截止日期，之後的事它不知道，但它可能用舊資料回答得很篤定（例如某個法規已經改了、某個數字已經更新了）。
- **誤讀**：有連網搜尋功能的 AI，可能搜到不可靠的網頁、看錯網頁內容、或把兩個網頁的內容混在一起。它會附上網址，看起來很有根據，但你點進去會發現網頁講的不是那回事。

為什麼接龍機器會這樣，《AI 怎麼運作》（ https://book.vichuang.tw/ai-theory/ ）第 11 章有詳細解釋。本章只要記住：**越具體的細節，越要查。**

### 查證三步驟

查證不是「每一個字都去 Google」，那樣你什麼事都做不了。查證是一套有順序的動作，從便宜到貴，做到你需要的程度就停。

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 第一步：問來源  │ →  │ 第二步：交叉查  │ →  │ 第三步：找原始  │
│ 「你是從哪知道」│    │ 另一個 AI、    │    │ 官方網站、原書、│
│ 它給得出嗎？   │    │ 搜尋引擎、     │    │ 政府統計、     │
│ 來源存在嗎？   │    │ 百科、新聞     │    │ 原論文        │
└──────────────┘    └──────────────┘    └──────────────┘
   便宜、快                中等                 貴、慢、但最可靠
```

**第一步：問來源。** 直接追問「這個數字／這本書／這條法律，你是從哪裡知道的？請給出具體來源。」它會給你一個來源。然後——這是關鍵——**去確認那個來源存在**。書名拿去圖書館系統或書店網站查，網址直接點開，論文拿去搜。如果來源不存在，整段話就要當成編的。如果它說「我無法提供具體來源」，那也是有用的答案：代表這件事它沒把握。

**第二步：交叉查。** 用一個**和這個 AI 無關的管道**再問一次：另一個 AI（第 1 章的技巧）、搜尋引擎、維基百科、新聞報導。看答案是不是一致。兩個管道答案不同，一定有一個錯；答案相同，可信度提高，但還不是保證（它們可能讀過同一篇錯的文章）。

**第三步：找原始資料。** 如果這件事很重要（要寫進報告、要據此做決定），就一路查到**最源頭**：政府統計數字去政府網站、法條去全國法規資料庫、書的引文去翻那本書、科學說法去找原始研究或教科書。原始資料不是「一篇講這件事的文章」，而是「這件事本身的紀錄」。

大多數日常問題，做到第一步或第二步就夠了。但下面這些事，請一律做到第三步。

### 什麼事絕對要查

| 類別 | 為什麼不能信 AI | 去哪裡查 |
|---|---|---|
| **醫療、健康** | 錯了會傷身體。藥名、劑量、症狀判斷、「這樣吃有沒有效」 | 藥盒說明、藥師、醫師、衛生福利部網站 |
| **法律** | 法條編號與內容它常編，而且法律會修 | 全國法規資料庫（law.moj.gov.tw）、學校老師、律師 |
| **金錢** | 投資建議、利率、費用、「這樣划不划算」 | 銀行官方網站、問大人、自己算一次 |
| **歷史日期與人名** | 細節中的細節，最容易接錯 | 教科書、博物館或機構官方網站、可靠的百科 |
| **數據與統計** | 數字是接出來的「合理值」 | 政府統計（主計總處、內政部）、原始報告 |
| **引用與來源** | 書、論文、網址、名人語錄，格式完美內容是拼的 | 圖書館系統、書店網站、直接點開網址、翻原書 |
| **關於特定的人、公司、學校** | 冷門的事它讀得少，更會編 | 該機構的官方網站、直接問當事人 |
| **聯絡資訊** | 電話、地址、Email，接錯一個數字就打給別人 | 官方網站、名片、Google 地圖 |

判斷標準只有兩個：**錯了後果嚴不嚴重？** 以及 **它是不是一個具體的事實或數字？** 兩個都是，就一定查。

### 讓 AI 自己檢查的技巧

AI 自己檢查不能取代你查證（它檢查自己的時候，用的還是同一個接龍機器），但可以當成**第零步**，幫你先挑出最可疑的地方。有三個技巧：

**技巧一：請它標出不確定的地方。**

```
請重新看一次你上面的回答，把你「不是很確定」或「可能記錯」的地方用【】標出來，並說明為什麼不確定。
```

**技巧二：請它用相反的立場挑錯。**

```
請你現在扮演一位很嚴格的事實查核員，假設上面那段回答是別人寫的。請逐句檢查，列出所有可能有錯、無法證實、或需要查證的句子。
```

**技巧三：換個問法再問一次，比對答案。** 開一個新對話，用不同的措辭問同一件事。如果兩次答案不一樣（例如年份變了、數字變了），那就是它在接龍而不是在「知道」。這個技巧對日期、數字特別有效。

**這些技巧的極限**：它標出來的「不確定」通常是真的可疑，值得優先查；但它**沒標**的地方不代表正確，它自己也會對編出來的東西很有信心。所以自我檢查是「縮小查證範圍」的工具，不是「免除查證」的工具。

### 語氣、細節、格式，都不是證據

最後再強調一次第 1 章的提醒，因為這是查證時最容易被騙的地方：

- **語氣篤定**不是證據。它編的東西一樣篤定。
- **細節豐富**不是證據。它編的書有作者、年份、出版社、引文，細節越多越像真的，但細節就是它最會接的東西。
- **格式正確**不是證據。一個長得像網址的字串、一個長得像論文引用的格式，都可能是拼出來的。

唯一的證據是：**你自己找到了那個來源，而且它真的說了那句話。**

## 動手做

### 活動 3-1：故意讓它說錯，然後抓到

**材料／工具**：一個聊天型 AI 帳號、搜尋引擎、紙筆。

**步驟**

1. 從第 1 章「想一想」第 6 題的發現，選一種最容易讓 AI 編的問題。這裡提供三種做法，選一種，或三種都試：

做法 A（錯誤前提）：在問題裡放一個假的前提，看它會不會順著接下去。

```
台灣在 1950 年代就已經有高鐵了，請問當時第一條路線是從哪裡到哪裡？
```

做法 B（要求冷門細節）：問一件真實存在、但很冷門的事，要求具體數字。

```
請告訴我（你家附近某條路或某座橋的全名）是哪一年完工的，當時的總工程費用是多少？
```

做法 C（要求引文）：請它給一句名人說過的話，並附出處。

```
請給我三句（某位你知道的歷史人物）說過的名言，每句都附上出處（哪本書、哪次演講、哪一年）。
```

2. 把它的回答原封不動抄下來。
3. **查證**：做法 A，你自己就知道答案（台灣高鐵 2007 年才通車）；做法 B，去該縣市政府或工程單位的網站查，或問家裡的大人；做法 C，把每句名言加上人名拿去搜尋，看有沒有可靠的出處（維基語錄、原書）。
4. 回到同一個對話，追問：

```
你剛才的回答裡，有哪些地方是你不確定、可能編造的？請誠實標出來。
```

5. 比較：它追問後承認的，跟你查到的錯誤，是不是同一批？

**你應該看到**：做法 A 的結果最戲劇化——有些 AI 會糾正你「台灣高鐵 2007 年才通車」，但有些會順著你編出一條 1950 年代的路線。做法 B 它幾乎一定會給你一個年份和一個金額，而且多半查不到或不對。做法 C 三句裡通常至少有一句出處是編的，或那句話根本不是那個人說的。追問之後，它會承認一部分，但常常還有你查到、它沒承認的錯。

**觀察與記錄**

| | 我的問題 | AI 的回答（重點） | 我查到的事實 | 查證的管道 | 追問後它承認了嗎？ |
|---|---|---|---|---|---|
| 做法 A | | | | | |
| 做法 B | | | | | |
| 做法 C | | | | | |

### 活動 3-2：查證一篇 AI 寫的短文裡的三個事實

**材料／工具**：同上。

**步驟**

1. 請 AI 寫一篇短文。主題選一個**有明確事實可查**的東西，例如台灣的某種動物、某個地方、某個歷史事件。下面用台灣黑熊當例子，你可以換：

```
請寫一篇 200 字左右介紹台灣黑熊的短文，給國中生看。文中至少要包含三個具體的事實（例如數字、年份、地名、學名），並在每個事實後面用（來源：……）標出你認為的來源。
```

2. 把短文印出來或抄下來，用筆圈出**三個最具體的事實**（有數字、年份、名稱的那種）。
3. 對每一個事實，走查證三步驟：
   - 第一步：它標的來源存在嗎？拿去搜。
   - 第二步：用搜尋引擎或另一個 AI 查同一件事，答案一樣嗎？
   - 第三步：找到原始資料（例如林業及自然保育署、台灣黑熊保育協會、教科書、博物館網站），確認。
4. 把每個事實標成：**正確**（原始資料證實）、**部分正確**（大致對但數字或細節不對）、**錯誤**（原始資料說的不一樣）、**查不到**（找不到任何可靠來源）。

**你應該看到**：以台灣黑熊為例，「胸前有 V 字形白色斑紋」「是台灣特有亞種」這類很常見的描述通常是對的；但「目前野外數量約 〇〇〇 隻」這種數字，不同來源差很多，AI 給的數字常常不知道從哪來；它標的來源可能是真實存在的機構，但那個機構的網站不一定有它說的那句話。三個事實裡，你很可能會得到「一個正確、一個部分正確、一個查不到」這樣的結果。這就是 AI 寫的東西的常態：**大方向通常對，細節不一定。**

## 用工具看看：請 AI 列來源，再自己查證

這一章的技巧是**把「問來源」變成習慣**：任何要用在報告、作業、決定上的回答，都請它附來源，然後自己一個一個點開。

1. 選一個你最近真的需要知道的問題（例如「青少年每天需要睡幾小時？」「台灣有幾座國家公園？」）。
2. 貼入：

```
請回答：（你的問題）。
回答時請附上 3 個可以查證的來源，每個來源要寫出：機構或作者名稱、標題、網址（如果有）。
如果你沒有把握某個來源真的存在，請直接說「我不確定這個來源是否存在」，不要編。
```

3. 把三個來源一個一個查：網址直接貼到瀏覽器；沒有網址的，把機構名稱加標題拿去搜尋。
4. 填下表。

| 來源 | 網址能打開嗎？ | 打開後，內容真的有說那句話嗎？ | 這個來源可靠嗎？（官方／學術／新聞／部落格／不明） |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

**你應該看到**：三種可能都會遇到——（1）網址打得開、內容也對，太好了；（2）網址打得開，但網頁內容沒有它說的那句話，或數字不一樣；（3）網址打不開，或根本是拼出來的。有連網功能的 AI 會比較多（1），沒有連網的會比較多（2）（3）。無論如何，**能打開的來源才算來源**；而且來源可靠程度也有差：政府機關、學校、學術機構的網站，比不知道誰寫的部落格可靠得多。

## 常見錯誤與迷思

- **「它附了來源，所以是真的。」** → 來源本身可能是編的，或來源存在但沒說那句話。 → 正確理解：附來源只是讓你「可以查」，不代表「查過了」。要自己點開。
- **「我請它自我檢查了，它說沒問題。」** → 它檢查自己用的是同一個接龍機器，對編出來的東西一樣有信心。 → 正確理解：自我檢查能挑出一部分可疑處，縮小查證範圍，但不能取代查證。
- **「兩個 AI 說的一樣，就是對的。」** → 它們可能讀過同一篇錯的文章，或用同樣的方式接出同樣合理的錯答案。 → 正確理解：一致可以提高可信度，重要的事還是要找原始資料。
- **「有連網搜尋的 AI 不會有幻覺。」** → 它可能搜到不可靠的網頁、看錯內容、或混合兩個網頁。 → 正確理解：連網減少幻覺，但「它附的網址我點開確認」這個動作還是要做。
- **「查證太麻煩，每一句都要查我什麼都做不了。」** → 不需要每一句都查。 → 正確理解：只查「具體的事實與數字」和「錯了後果嚴重的事」，大部分日常問題做到第一、二步就夠；真正重要的事才做第三步。
- **「AI 錯這麼多，不如不要用它查資料。」** → 它不適合當「資料來源」，但非常適合當「查資料的起點」：幫你列出該查什麼、該去哪查、該用什麼關鍵字。 → 正確理解：把它當成一個能快速給你方向、但說的話要驗證的嚮導。

至少三個：「衛生福利部 2022 年的調查」（來源：存不存在、是不是這一年、是不是衛福部做的）、「6.8 小時」（數據）、以及「國中生」這個範圍（調查對象是不是真的是國中生，還是所有青少年）。屬於「數據與統計」與「引用與來源」兩類。查法：到衛福部或國民健康署的網站找該年的調查報告，看原始數字。

</details>

2. 小祐的 AI 給的三本書，作者都是真實存在的教授。為什麼「作者是真的」不代表「書是真的」？用「接龍」解釋。

<details><summary>參考答案</summary>

因為接龍機器是把「合理的碎片」拼在一起：它讀過這位教授的名字、讀過這個領域常見的書名樣式、讀過出版社的名稱，於是接出一個「這位教授很可能會寫的書」。每個零件都合理，組合起來的東西卻不存在。這也是為什麼「細節豐富」不能當證據——細節正是它最會拼的東西。

</details>

3. 請把查證三步驟套用在這個情境：AI 告訴你「某某牌感冒藥，國中生一次可以吃兩顆」。你會查到第幾步？為什麼？

<details><summary>參考答案</summary>

一定查到第三步，而且第三步應該是**藥盒說明書與藥師或醫師**，不是網路文章。因為這是醫療類，錯了會傷身體。其實這類問題的正確做法是：根本不要用 AI 的答案，直接看藥盒或問藥師；AI 最多只能幫你「列出該問藥師什麼問題」。

</details>

4. 活動 3-2 裡，AI 寫的短文「大方向對、細節不一定」。如果你要拿它當報告的材料，哪些部分可以保留、哪些要重寫？請說出一個原則。

<details><summary>參考答案</summary>

原則：**結構與解釋可以保留，事實與數字一律換成你查證過的。** 它寫的段落安排、說明方式、比喻，通常可以用；但每一個年份、數字、名稱、引文，都要換成你從原始資料查到的版本，查不到的就刪掉或改成不帶數字的說法。而且要照學校規定標註使用了 AI（第 5 章）。

</details>

5. 「交叉查」的時候，為什麼要用「和這個 AI 無關的管道」？如果你只是在同一個對話裡再問一次「你確定嗎」，算不算交叉查？

<details><summary>參考答案</summary>

不算。在同一個對話裡再問一次，它看得到自己剛才的回答，會傾向維持一致（或者反過來，因為你質疑它就隨便改口，兩種都不可靠）。交叉查的意義是找一個**獨立的**來源：另一個 AI 的新對話、搜尋引擎、百科、原始網站。獨立的來源如果也這麼說，才有意義。

</details>

6. 開放挑戰：挑一個你在社群媒體上看過的「聽起來很厲害的說法」（例如「人一生會吞下 〇 隻蜘蛛」「金魚記憶只有 7 秒」）。先請 AI 告訴你這個說法對不對並附來源，然後自己用三步驟查證，最後寫一段 100 字的「查證結果」，說明 AI 說的對不對、你最後是在哪裡找到可靠答案的。

<details><summary>參考答案</summary>

開放題。你很可能會發現：（1）這類流傳很廣的說法，AI 常常知道它是錯的，因為網路上有很多闢謠文章；（2）但它附的來源不一定能打開；（3）最可靠的答案通常在學術機構、博物館、或專門做事實查核的網站。這個活動的格式就是第 12 章「AI 查證報告」專題的縮小版，先練一次。

</details>

## 本章小結

- AI 最常見的四種錯：**編造來源、編造數字、編造引文、編造法條／日期／人名**。越具體的細節越容易錯。
- 另外兩種要小心的情況：**過時**（訓練資料有截止日）與**誤讀**（連網的 AI 看錯網頁）。
- 查證三步驟：**問來源**（並確認來源存在）→ **交叉查**（用獨立的管道）→ **找原始資料**（官方、原書、原始統計）。
- **絕對要查**：醫療、法律、金錢、歷史日期、數據、引用、特定的人事物、聯絡資訊。判斷標準是「錯了後果嚴不嚴重」與「是不是具體的事實或數字」。
- 讓 AI 自我檢查（標不確定、扮演查核員、換問法再問）能縮小範圍，但不能取代查證。
- 語氣篤定、細節豐富、格式正確，都不是證據。唯一的證據是你自己找到了來源，而且它真的那麼說。
- AI 不適合當資料來源，但很適合當查資料的起點。
- 用在報告上的原則：**結構與解釋可以用，事實與數字一律換成查證過的。**

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 幻覺 | Hallucination | AI 一本正經地說出不存在或錯誤的內容 |
| 查證 | Fact-checking / Verification | 用獨立、可靠的來源確認一句話是不是真的 |
| 來源 | Source | 一句話是從哪裡來的：書、網頁、報告、人 |
| 原始資料 | Primary Source | 事情本身的紀錄，例如原書、原始統計、官方公告，而不是轉述它的文章 |
| 交叉查證 | Cross-checking | 用兩個以上互相獨立的管道查同一件事 |
| 錯誤前提 | False Premise | 問題裡藏著一個不正確的假設，AI 常會順著它回答 |
| 知識截止日期 | Knowledge Cutoff | AI 訓練資料最晚到哪一天，之後的事它不知道 |
| 連網搜尋 | Web Search / Browsing | 有些 AI 能先搜網頁再回答，可減少但不能消除錯誤 |
| 事實查核員 | Fact-checker | 專門檢查一段話是否屬實的人；本章請 AI 扮演這個角色來挑自己的錯 |
| 可靠來源 | Reliable Source | 政府機關、學術機構、原始出版物等，比不知名的部落格或轉貼可信 |
