# 第 7 章　圖像聲音與影片

## 本章目標
- 學完你會用「主體、風格、構圖、負面提示」四個零件寫出圖像生成的指令，並且會迭代修改。
- 學完你會說出 AI 修圖、去背、語音轉文字、文字轉語音、翻譯各自適合做什麼，以及它們常出錯的地方。
- 學完你會用語音轉文字把一段錄音整理成可以讀的筆記，並且知道哪些地方要回去聽原音確認。
- 學完你會說出深偽是什麼、它會造成哪些傷害，並列出至少五個辨識線索。
- 學完你會說出使用 AI 生成的圖、聲音與影片時，該遵守的三條規矩：不冒充真人、要標示、不傳不確定的東西。

## 開場：園遊會的海報和阿嬤的電話

小安被班上推派做園遊會的海報。他沒學過畫畫，打開圖像生成工具，輸入「園遊會海報」，得到一張很漂亮但完全看不出是哪個班、賣什麼的圖，上面的中文字還歪歪扭扭像是外星文。他改了三次指令，第四次終於出現一張有章魚燒攤位、有熱鬧氣氛、空出一塊可以自己打字的海報。全班都說讚。

同一週，小安的阿嬤接到一通電話，聲音是小安的表哥小明，說他出車禍急需三萬元，哭得很急。阿嬤差點就去領錢，幸好掛電話前她照家裡的約定問了一句：「你小時候養的那隻狗叫什麼？」電話那頭沉默了兩秒就掛斷了。那不是小明，是用小明的聲音做出來的假聲音。

同樣的技術，一邊幫小安做出海報，一邊差點騙走阿嬤的錢。這一章我們要學的是：**怎麼把這些工具用好，以及怎麼不被它們騙。**

## 核心概念

### 圖像生成：指令的四個零件

**圖像生成（Image Generation）**工具會根據你的文字畫出圖。它不是在資料庫裡「找」一張圖，而是「算」出一張新的。所以指令寫得越清楚，結果越接近你要的。一條好的圖像指令有四個零件：

| 零件 | 它在回答什麼 | 例子 |
|---|---|---|
| 主體（Subject） | 畫面裡有什麼 | 一個章魚燒攤位，兩個國中生在招呼客人 |
| 風格（Style） | 看起來像什麼畫法 | 扁平插畫風、水彩、像素風、照片寫實 |
| 構圖（Composition） | 東西怎麼擺、鏡頭在哪 | 正面平視、攤位置中、上方留白三分之一、直式海報比例 |
| 負面提示（Negative Prompt） | 不要出現什麼 | 不要文字、不要真人臉孔、不要太多雜物 |

把四個零件合起來：

```
主體：一個熱鬧的章魚燒攤位，兩個穿白色制服的國中生在招呼客人，攤位前排著小隊伍。
風格：明亮的扁平插畫風，暖色調，像校園活動海報。
構圖：直式海報比例，攤位在畫面中下方，上方三分之一留白給標題。
不要：畫面裡不要有任何文字或字母，不要寫實的人臉，不要暗色背景。
```

為什麼要「不要文字」？因為目前多數圖像工具畫出來的字會歪、會錯、會變成不存在的符號，尤其是中文。最穩的做法是叫它留白，之後用簡報或修圖軟體自己把字打上去。

### 迭代：第一張永遠不是最後一張

圖像生成很少一次到位，正常流程是**迭代（Iteration）**：看結果、找出一個最不滿意的地方、只改那一點、再生成。不要一次改五個地方，否則你不知道是哪個改動產生了效果。常見的迭代語句：

- 「保留整體風格，但把攤位往下移，上方留更多空白。」
- 「人物太多了，只留兩個。」
- 「顏色更暖一點，像傍晚。」
- 「同樣的指令再生成四張讓我挑。」

每一輪把你改了什麼、結果如何記下來，三輪之後你會對「這個工具聽得懂哪種話」很有感覺。

### AI 修圖與去背

修圖是圖像 AI 最實用的日常用途，常見功能有三個：

- **去背（Background Removal）**：把主體留下、背景變透明。做海報、簡報、貼圖都用得到。它在邊緣清楚的物體上很準，在頭髮、玻璃杯、半透明的東西上常會切壞，放大看邊緣檢查一下。
- **移除物件**：把照片裡路人、電線、雜物擦掉，AI 會「猜」被擋住的地方長什麼樣。背景單純時很好用，背景複雜時會留下模糊或重複的紋理。
- **放大與修復**：把模糊的小圖變清楚。注意，它是「猜」出細節，不是「還原」真實；放大後臉上的痣、文字的筆畫可能是編的。

一個重要的界線：**修自己的照片、作品可以；修別人的照片（尤其是臉和身體）要先得到同意。** 把同學的照片修成另一個樣子再傳出去，即使是開玩笑，也可能構成霸凌或侵害肖像權，第 10 章會再談。

### 語音轉文字、文字轉語音、翻譯

這三樣是「聲音與文字互換」的工具，學生用得到的場合很多：

**語音轉文字（Speech-to-Text）**：把錄音變成文字稿。上課錄音（要先經老師同意）、訪問家人、自己念的口說練習，都可以轉成文字再整理。它的弱點是：專有名詞、人名、數字常聽錯，台語或夾雜英文的句子錯更多，背景吵雜時整段會壞掉。所以轉完一定要**對照原音檢查關鍵處**，尤其是數字、日期、人名。

**文字轉語音（Text-to-Speech）**：把文字念出來。可以把自己寫的英文作文叫它念給你聽練聽力，或把長文章變成通勤時聽的音檔。它念錯的地方通常是破音字和外來語，聽到怪怪的就查一下。

**翻譯**：聊天型 AI 的翻譯已經很好用，但有三個提醒：一是它會把「不確定的地方」翻得很流暢，看不出哪裡猜的；二是專業術語、法律和醫療文件要找人確認；三是翻譯別人的文章拿去用，仍然要註明原作者。翻譯的好用法是「翻完請它逐句解釋為什麼這樣翻」，順便學語言。

### 深偽：當圖、聲音、影片都可以是假的

**深偽（Deepfake）**是「深度學習」加「偽造」的合成詞，指用 AI 做出的假圖片、假聲音、假影片，讓某個人看起來說了他沒說的話、做了他沒做的事。開場裡阿嬤接到的電話就是**聲音深偽**：只要有某人幾十秒的錄音（例如社群影片），就可以合成他說任何話的聲音。

深偽會造成的傷害，按常見程度排：

1. **詐騙**：假親人聲音借錢、假老闆要求轉帳、假客服。
2. **霸凌與性騷擾**：把同學的臉接到不雅圖片或影片上。這在台灣是犯罪，受害者多是學生。
3. **假訊息**：假的政治人物發言、假的災難畫面，在選舉或災難時大量流傳。
4. **破壞信任**：當什麼都可能是假的，真的證據也會被說成是假的。

**辨識線索。** 下面這些線索到今天還常常有效，但要記住：**工具每個月在進步，線索會失效，最可靠的永遠是「查來源」和「用另一條管道確認」。**

| 看哪裡 | 可疑的跡象 |
|---|---|
| 手與手指 | 手指數量不對、關節彎得奇怪、兩隻手黏在一起 |
| 文字與標誌 | 畫面裡的字歪斜、拼錯、像外星文；招牌和商標變形 |
| 臉的邊緣 | 髮際線、下巴與脖子的交界模糊或有一圈光暈；眼鏡的反光不一致 |
| 眨眼與嘴型 | 影片裡眨眼太少或太規律；嘴型和聲音對不上，尤其是 b、p、m 的音 |
| 光影 | 影子方向和光源不一致；臉很亮但背景很暗 |
| 背景 | 背景圖案重複、物體融在一起、對稱的東西不對稱 |
| 聲音 | 語調太平、沒有呼吸聲、停頓不自然、背景音突然消失 |
| 情境 | 要你「馬上」做某件事、要錢、要你不要告訴別人 |

最後一列最重要。深偽詐騙的共同特徵不在技術，而在**情境**：製造緊急、要錢、要你保密。只要出現這三樣，不管聲音多像，都先掛掉、用你自己知道的號碼打回去確認。

**家庭安全詞。** 阿嬤之所以沒被騙，是因為家裡事先約好了一個只有家人知道的問題。請你今天就和家人約一個，寫在第 9 章的「我家的 AI 使用規則」裡。

### 使用的三條規矩

用 AI 做圖、聲音、影片，請守三條：

1. **不冒充真人。** 不用真人的臉和聲音做他沒做過的事，包括同學、老師、藝人。
2. **要標示。** 用 AI 生成的圖放進作業、海報、社群貼文時，註明「圖片由 AI 生成」。這不是丟臉，是誠實。
3. **不確定的不傳。** 看到震撼的圖或影片，轉傳前先查來源。你轉傳的那一刻，你就成了假訊息的一部分。

想知道 AI 為什麼能做出這些東西，可以看同書架的《AI 怎麼運作》（https://book.vichuang.tw/ai-theory/ ）。

## 動手做

### 活動 7-1：生成一張海報圖並迭代三次

**材料／工具**：一個圖像生成工具（很多聊天型 AI 內建，或獨立的圖像生成服務；未滿 13 歲請家長陪同）、紙筆、能存圖的地方。

**步驟**：

1. 決定海報主題：你的班級活動、社團招生、或虛構的「我家的飲料店」都可以。
2. 在紙上先填四個零件（主體、風格、構圖、不要什麼），再組成指令。例如：

```
請生成一張直式海報用的圖。
主體：一個小小的珍珠奶茶攤位，攤位上有三杯不同顏色的飲料，一隻胖貓店長坐在櫃台後面。
風格：可愛的扁平插畫風，粉彩色系，乾淨的背景。
構圖：攤位在畫面中下方，上方三分之一留白，整體置中。
不要：畫面裡不要有任何文字，不要寫實風格，不要太多裝飾。
```

3. 看第一張，在記錄表寫下「最不滿意的一點」。只針對那一點改指令，生成第二張。
4. 重複，做到第四張（共迭代三次）。每一輪只改一件事。
5. 挑最好的一張存下來，用簡報軟體或修圖軟體在留白處打上標題文字。
6. 檢查手指、文字、物體邊緣，記錄你發現的「AI 破綻」。

**你應該看到／得到**：第一張通常會有「風格對但構圖不對」或「多了你沒說的東西」的問題。經過三輪，構圖和主體應該明顯更接近你要的。如果你忘了寫「不要文字」，很可能看到歪斜的假字，這就是正好觀察破綻的機會。最後的成品要在留白處有你自己打上的字，而不是 AI 畫的字。

**觀察與記錄**：

| 輪次 | 我改了什麼（只寫一件事） | 結果變好／變差／沒差 | 發現的破綻 |
|---|---|---|---|
| 第 1 張（原始指令） | — | | |
| 第 2 張 | | | |
| 第 3 張 | | | |
| 第 4 張 | | | |

| 項目 | 記錄 |
|---|---|
| 最後選了第幾張，為什麼 | |
| 這個工具最聽得懂哪種描述 | |
| 哪種描述它一直做不到 | |

### 活動 7-2：用語音轉文字整理一段上課錄音

**材料／工具**：一段 3 到 5 分鐘的錄音（上課錄音要先經老師同意；或錄一段家人講一個故事；或自己念一段課文）、語音轉文字工具（手機內建的語音輸入、聊天型 AI 的語音功能、或獨立的轉錄服務）、聊天型 AI。

**步驟**：

1. 準備錄音。如果是自己錄，刻意在裡面放進三個「容易聽錯」的東西：一個人名、一個數字、一個英文單字。
2. 用語音轉文字工具把錄音轉成文字稿，整段複製。
3. 先自己讀一遍，用螢光筆標出「看起來怪怪的」地方。
4. 把文字稿貼給聊天型 AI：

```
下面是一段〔上課／訪談〕錄音的自動轉錄文字，可能有聽錯的地方。
請幫我：
1. 整理成條列式筆記，分成三到五個重點。
2. 另外列出你覺得「可能是轉錄錯誤」的句子（例如不通順、專有名詞怪怪的），
   用表格列出：原文、你懷疑的原因、你猜的正確版本。
不要補上錄音裡沒有的內容。
〔貼上文字稿〕
```

5. 拿 AI 列出的「可疑句子」回去聽原音，逐一確認，在記錄表寫下真正的內容。
6. 特別檢查步驟 1 放進去的三個陷阱：轉錄工具聽對了嗎？AI 有懷疑到它們嗎？

**你應該看到／得到**：轉錄文字稿大致可讀，但人名、數字、英文會有錯（例如「陳老師」變「晨老師」，「35 分」變「3 到 5 分」）。AI 整理的筆記會很整齊，而且它標出的可疑句子多半真的有問題，但它「猜的正確版本」不一定對，有時會猜得很有信心卻猜錯，這就是為什麼要回去聽原音。如果 AI 的筆記裡出現錄音沒說過的東西，你就抓到一次幻覺，記下來。

**觀察與記錄**：

| 項目 | 記錄 |
|---|---|
| 錄音長度與內容 | |
| 我放進去的三個陷阱（人名／數字／英文） | |
| 轉錄工具聽對幾個 | |
| AI 懷疑了幾句、其中真的錯的有幾句 | |
| AI 猜的正確版本對了幾句 | |
| AI 筆記裡有沒有錄音沒說的內容 | |
| 最後筆記我改了幾處 | |

## 用工具看看：用「以圖搜圖」查一張可疑圖片的來源

辨識深偽最可靠的方法不是看手指，而是**查來源**。瀏覽器和手機都有「以圖搜圖」（反向圖片搜尋）功能，一分鐘就能查。

1. 找一張你在社群媒體或群組看到、覺得「太驚人了」的圖片，長按存下來或複製圖片網址。
2. 打開搜尋引擎的圖片搜尋（在搜尋框旁邊通常有一個相機圖示），上傳這張圖或貼上網址。手機上也可以用相機 App 內的「搜尋圖片」功能。
3. 看結果：這張圖最早出現在哪裡、什麼時候？有沒有新聞媒體或查核網站討論過它？

你會看到三種結果：

| 結果 | 代表什麼 |
|---|---|
| 找到同一張圖，來自可信的新聞或原始拍攝者，日期和內容吻合 | 大概是真的，但仍看一下有沒有被裁切或改字幕 |
| 找到同一張圖，但最早出現的時間或地點和現在的說法不同 | 舊圖新用，這是最常見的假訊息手法 |
| 完全找不到，或只在同一群轉傳的帳號出現 | 高度可疑，可能是 AI 生成，不要轉傳 |

查完把結果和轉傳給你的人說一聲。你不只保護了自己，也擋住了下一次轉傳。影片的做法類似：擷取幾個畫面截圖去搜；聲音則沒有好的搜尋方法，只能用「另一條管道確認」（直接打電話給本人）。

## 常見錯誤與迷思

- **「指令寫得越長越好。」** → 太長的指令會讓工具抓不到重點，互相矛盾的描述會讓結果更亂。 → 四個零件各一兩句，一次只改一件事。
- **「AI 畫的字看起來對就好。」** → 目前的工具常把字畫錯、畫成假字，尤其中文。 → 請它留白，字自己打。
- **「語音轉文字很準，轉完直接用。」** → 人名、數字、英文和背景噪音常出錯，AI 整理時還可能補上沒說過的內容。 → 關鍵處回去聽原音，請 AI 標出可疑句而不是直接相信。
- **「看手指就能分辨深偽。」** → 線索每個月都在失效，新工具已經能畫對手指。 → 線索是輔助，查來源和另一條管道確認才可靠。
- **「聲音這麼像，一定是本人。」** → 幾十秒的錄音就能合成任何人的聲音。 → 聽到急、要錢、要保密三樣，先掛掉，用自己知道的號碼打回去，問安全詞。
- **「我只是把同學的臉換到搞笑圖上，又沒有惡意。」** → 當事人不一定覺得好笑，傳出去就收不回來，涉及性或貶低的內容更是犯罪。 → 不用真人的臉和聲音做他沒做過的事，想做先問本人。
- **「AI 生成的圖是我下的指令，所以不用標示。」** → 讀者有權知道這張圖不是真實拍攝；作業和比賽多數要求標示。 → 註明「圖片由 AI 生成」。

1. 小安第一次輸入「園遊會海報」得到一張漂亮但沒用的圖。用四個零件的架構，說明這條指令缺了什麼。

<details><summary>參考答案</summary>

它只有一個很模糊的主體（海報），沒有說畫面裡有什麼（哪個班、賣什麼）、沒有風格、沒有構圖（哪裡要留白給文字）、也沒有負面提示（不要文字）。所以工具只能用「平均的園遊會海報」來填空，結果和任何人要的都不一樣。

</details>

2. 為什麼本章建議「請工具留白，字自己打」，而不是直接叫它把標題畫出來？

<details><summary>參考答案</summary>

目前多數圖像生成工具是「畫」出字的形狀，不是「打」字，所以筆畫會歪、會錯、會出現不存在的字，中文尤其嚴重。留白後用簡報或修圖軟體打字，字一定正確，也方便之後修改。

</details>

3. 語音轉文字把「陳老師說考試在 15 號」轉成「晨老師說考試在 5 號」。AI 整理筆記時可能發現嗎？你該怎麼做？

<details><summary>參考答案</summary>

「晨老師」AI 可能會懷疑，因為這不像常見姓氏；但「5 號」AI 幾乎不可能發現，因為它語法通順、也沒有矛盾。這就是為什麼數字、日期、人名這些「關鍵處」一定要回去聽原音確認，而不是信任 AI 的整理。

</details>

4. 阿嬤接到「小明」的電話。請列出這通電話裡符合「深偽詐騙情境特徵」的三個點，以及阿嬤做對了什麼。

<details><summary>參考答案</summary>

三個特徵：製造緊急（出車禍）、要錢（三萬元）、情緒施壓（哭得很急，讓人來不及想）。阿嬤做對的是沒有立刻行動，而是用事先約好的「只有家人知道的問題」確認身分。更完整的做法還可以掛掉後用自己手機裡小明的號碼打回去。

</details>

5. 你在群組看到一張「某地淹水到二樓」的照片，很震撼。在轉傳之前，寫出你會做的三個步驟。

<details><summary>參考答案</summary>

(1) 先看圖本身：文字、招牌、人物邊緣、倒影有沒有不對勁。(2) 以圖搜圖：查這張圖最早出現在哪裡、什麼時候，是不是舊圖新用。(3) 查有沒有可信的新聞或查核網站報導同一件事。三步做完還不確定就不轉傳，並告訴傳給你的人你查到什麼。

</details>

6. 開放挑戰：有人說「既然深偽會越來越難分辨，教辨識線索根本沒用」。你同意嗎？想一想：除了「看破綻」之外，社會上還可以用哪些方法來對付深偽？

<details><summary>參考答案</summary>

開放題。可以討論的方向：辨識線索會過時，但「查來源、另一條管道確認、安全詞、不轉傳不確定的東西」這些習慣不會過時；技術面有數位浮水印、來源認證（拍攝時就簽章）；法律面有處罰製作與散布深偽的規定；平台面有標示與下架；教育面就是這一章。結論通常是：沒有單一方法有用，要靠習慣、技術、法律一起。

</details>

## 本章小結

- 圖像指令的四個零件：主體、風格、構圖、負面提示；文字請工具留白自己打。
- 迭代：每一輪只改一件事，記錄結果，三輪之後你會知道工具聽得懂什麼。
- 去背、移除物件、放大都是「猜」出來的，邊緣和細節要檢查；修別人的照片要先同意。
- 語音轉文字在人名、數字、英文上常出錯，AI 整理時可能補上沒說的內容；關鍵處回去聽原音。
- 深偽會用在詐騙、霸凌、假訊息；辨識線索（手指、文字、邊緣、嘴型、光影、聲音）會過時，情境特徵（急、要錢、保密）和查來源不會。
- 和家人約一個安全詞；收到可疑影像先以圖搜圖。
- 三條規矩：不冒充真人、要標示 AI 生成、不確定的不轉傳。
