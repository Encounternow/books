# 第 2 章　怎麼問才問得好

## 本章目標

學完這一章，你會：

- 說出為什麼同一個問題換一種問法，AI 的回答會差很多。
- 用「角色、任務、背景、格式」四要素寫出一段清楚的提示詞。
- 會用「給例子」與「一步一步來」兩個技巧，讓 AI 的回答更接近你要的。
- 知道對話是可以追問和修改的，不用一次問到完美。
- 寫出一份自己的「提示詞範本」，以後遇到同類問題直接套用。

## 開場：兩個人問同一件事

阿凱和小芸都想請 AI 幫忙準備下週的英文口說報告，題目是「介紹一個台灣的節日」。

阿凱打的是：「幫我寫英文報告。」

AI 給了他一篇 500 字、用詞很難的文章，講的是「Taiwan's rich cultural heritage」，裡面提到的節日他一個都不熟。他看了三行就關掉，覺得 AI 沒用。

小芸打的是：「我是台灣的國二學生，下週要用英文做一分鐘的口說報告，題目是介紹端午節。請用國中程度的英文，寫一段大約 120 字的講稿，分成三段：節日是什麼、我們家怎麼過、我最喜歡的部分。最後請列出講稿裡最難的五個單字並附中文。」

AI 給了她一段剛好一分鐘、她看得懂、講得出口的講稿，還附了單字表。她改了兩句，加上自己家包粽子的細節，就準備好了。

兩個人用的是同一個 AI。差別不在 AI，而在「問法」。這一章要教你的，就是小芸會、阿凱還不會的那件事。

## 核心概念

### 為什麼問法有差：你給的字，決定它接的字

第 1 章說過，聊天型 AI 是接龍機器：它從你的提示詞開始，接出最合理的下一段。所以你的提示詞就是「龍頭」——龍頭長什麼樣，接出來的龍就長什麼樣。

「幫我寫英文報告」後面可以接的東西太多了：什麼主題？給誰看？多長？多難？AI 不知道，只好接一個「平均的、通用的」報告，也就是對誰都不太有用的那種。小芸的提示詞把這些都說清楚了，AI 接出來的東西自然就貼近她要的。

這跟你對人說話其實一樣。你跟一個剛來的助理說「幫我弄一下那個」，他也不知道要弄什麼。差別在於，人會反問你，而 AI 通常會直接猜一個答案給你。所以**你要先把人會反問的那些事，自己先說清楚**。

至於為什麼提示詞對接龍機器這麼有效，《AI 怎麼運作》（ https://book.vichuang.tw/ai-theory/ ）第 12 章有解釋；本章我們直接學怎麼用。

### 四要素：角色、任務、背景、格式

一段好的提示詞，通常包含這四樣東西。不一定每次都要四個齊全，但缺哪個，就問自己「它會不會因此猜錯」。

| 要素 | 在告訴 AI 什麼 | 例子 |
|---|---|---|
| **角色（Role）** | 請它用什麼身分、什麼口吻回答 | 「你是一位很有耐心的國中理化老師」 |
| **任務（Task）** | 到底要它做什麼，用動詞開頭 | 「請解釋」「請列出」「請改寫」「請出五題」 |
| **背景（Context）** | 它需要知道的情況：你是誰、要用在哪、已經做了什麼 | 「我是國二學生，下週段考，這個概念我看課本看不懂」 |
| **格式（Format）** | 要多長、分幾段、用表格還是條列、用什麼語言 | 「用 200 字以內，分三點，每點附一個生活例子」 |

把小芸的提示詞拆開看：

```
我是台灣的國二學生，下週要用英文做一分鐘的口說報告，題目是介紹端午節。   ← 背景
請用國中程度的英文，寫一段大約 120 字的講稿，                             ← 任務 + 格式
分成三段：節日是什麼、我們家怎麼過、我最喜歡的部分。                       ← 格式
最後請列出講稿裡最難的五個單字並附中文。                                   ← 任務（第二個）
```

她沒有特別寫「角色」，因為這題不太需要；但如果她寫「你是一位教台灣國中生的英文老師」，AI 選的單字可能會更貼近課本程度。

四要素裡**最常被忘記的是「背景」**。很多人以為 AI 什麼都知道，其實它完全不知道你是誰、你幾年級、你已經懂什麼。「我是國二學生」這六個字，就能讓它的用詞、例子、難度全部換一套。

### 技巧一：給例子

有時候你很難用文字描述「我要的感覺」，但你可以**給它一個例子**。這叫做**少量示範（Few-shot）**：你先示範一兩個，它就會照著做。

```
請幫我把下面的單字做成記憶小卡。格式照這個例子：

例子：
單字：abundant
詞性：形容詞
中文：充足的、豐富的
例句：The river is abundant in fish.
記憶法：a-bund-ant 想成「一捆螞蟻」，很多很多。

請用同樣的格式做這五個單字：curious、generous、ancient、fragile、brilliant
```

AI 看到例子，就知道你要五個欄位、要有記憶法、例句要簡單。你如果只寫「幫我做單字卡」，它可能給你完全不同的格式，還不一定有記憶法。

例子也可以用來說明「風格」：貼一段你自己寫的文字，說「請用這種語氣幫我改下面這段」，它就會模仿你的語氣，而不是用它自己那種很制式的腔調。

### 技巧二：一步一步來

接龍機器有一個特性：它是**邊接邊想**的，沒有「先在心裡想完再寫」這回事。所以當你丟一個很複雜的任務，它很容易在中途走偏。對付的方法有兩個。

**第一個方法：把大任務拆成小任務，一次做一步。** 與其說「幫我寫一篇關於塑膠微粒的報告」，不如：

```
第一步：請列出一篇國中生「塑膠微粒」報告可以寫的五個方向，每個方向一句話說明。
```

你看完選一個，再說：

```
第二步：我選第三個方向。請幫我列一個三段式的大綱，每段三個要點。
```

然後再請它展開其中一段。這樣每一步你都看得到、都能改方向，最後的成品才會是你要的，而不是它自己接龍接出來的。

**第二個方法：請它把思考過程寫出來。** 遇到需要推理或計算的題目，加一句「請一步一步寫出你的想法，最後再給答案」。因為它是邊接邊想，讓它把中間步驟寫出來，等於是讓它「用紙筆算」而不是「心算」，錯誤會少很多，而且你也能檢查它哪一步錯了。

```
一個長方形的周長是 36 公分，長是寬的 2 倍。請一步一步寫出解法，最後再給答案。
```

**你應該看到**：它會先設寬為 x、長為 2x，列出 2(x + 2x) = 36，解出 x = 6，長 12 公分、寬 6 公分。如果它直接丟一個答案，你反而要小心。

### 技巧三：追問與修改

很多人以為提示詞要一次寫到完美。不用。聊天型 AI 的好處就是**可以接著講**。它給的第一版不滿意，你就說哪裡不滿意：

- 「太長了，縮成一半。」
- 「用國中生聽得懂的話重講一次。」
- 「第二點我看不懂，換一個生活例子。」
- 「語氣太正式了，像在跟朋友講話那樣。」
- 「我不是要你幫我寫，我要你告訴我我寫的哪裡有問題。」

每一句追問都是在「修龍頭」。通常追問兩三輪，就能從「差不多」變成「就是這個」。

但有一個小陷阱：如果你追問好幾輪之後，發現它越改越亂、開始重複或自相矛盾，那是因為對話變太長，它「顧不到」前面的所有內容了。這時候最好的做法是**開一個新對話**，把你學到的東西整理成一段更完整的提示詞，重新來。

### 不好的問法 vs 好的問法

| 不好的問法 | 問題出在哪 | 好的問法 |
|---|---|---|
| 幫我寫英文報告。 | 沒主題、沒長度、沒程度 | 我是國二學生，請用國中程度的英文寫 120 字的端午節介紹，分三段。 |
| 光合作用是什麼？ | 它會給你一段百科全書式的定義，不一定是你要的程度 | 我是國一學生，課本上的光合作用看不懂。請用一個生活中的比喻解釋，100 字以內，不要用化學式。 |
| 這篇文章好嗎？ | 「好」沒有標準，它多半會說「寫得很好」 | 這是我寫的 150 字遊記。請當一個嚴格的國文老師，指出三個最需要改的地方，並說明為什麼。不要幫我改寫。 |
| 幫我解這題。 | 你會拿到答案，但學不到 | 這題我卡在第二步。請不要直接給答案，先提示我下一步該想什麼。 |
| 給我一些讀書的建議。 | 太籠統，會得到「要早睡、要專心」這種話 | 我下週五段考，科目是數學、理化、英文，每天放學後有兩小時。請幫我排一週的讀書表，用表格，每天列科目與要做的事。 |
| 寫一首詩。 | 沒主題、沒形式、沒對象 | 請寫一首四行的中文小詩，主題是「下雨天的教室」，給國中生看，不要押韻也可以，但要有一個具體的畫面。 |

你會發現，右邊那一欄其實就是「把人會反問的事先說清楚」，再加一點「我要什麼、不要什麼」。

### 提示詞不是咒語

最後提醒一件事。網路上有很多「神級提示詞」「萬用公式」，好像背下某個格式 AI 就會變聰明。不是這樣的。

提示詞的本質就是**把事情交代清楚**。你怎麼跟一個新來的、很聰明但完全不認識你的助理交代一件事，就怎麼寫提示詞。四要素、給例子、一步一步來，都只是幫你檢查「我有沒有交代清楚」的提醒，不是非照不可的咒語。寫久了，你會自然知道哪些該說、哪些不用說。

## 動手做

### 活動 2-1：同一個問題，五種問法

**材料／工具**：一個聊天型 AI 帳號、紙筆或記事本。

**步驟**

1. 選一個**你最近在學、但還沒完全懂**的概念。例如「比例」「電流與電壓」「光合作用」「現在完成式」。下面用「電流與電壓的差別」當例子，請換成你自己的。
2. **每一種問法都開一個新對話**（這很重要，不然後面的問法會受前面的影響）。依序貼入下面五段提示詞，把「電流與電壓的差別」換成你的概念。

問法一（最簡單的問法）：

```
電流與電壓的差別是什麼？
```

問法二（加上背景）：

```
我是國二學生，剛開始學電學。課本說電流與電壓不一樣，但我分不清楚。請解釋電流與電壓的差別。
```

問法三（加上格式）：

```
我是國二學生，剛開始學電學。請用 100 字以內解釋電流與電壓的差別，分成兩點，每點附一個生活中的比喻。
```

問法四（加上角色與「不要什麼」）：

```
你是一位很會用比喻的國中理化老師。我是國二學生，剛開始學電學。請用 100 字以內解釋電流與電壓的差別，分成兩點，每點附一個生活中的比喻。不要用任何公式，不要用「電位差」這種我沒學過的詞。
```

問法五（加上「確認我懂了沒」）：

```
你是一位很會用比喻的國中理化老師。我是國二學生，剛開始學電學。請用 100 字以內解釋電流與電壓的差別，分成兩點，每點附一個生活中的比喻。不要用任何公式。解釋完之後，請出一題判斷題讓我檢查自己懂了沒，但先不要給答案。
```

3. 每一種問法的回答，用下面的表格評分：看得懂嗎（1–5 分）、長度剛好嗎（太長／剛好／太短）、有沒有用到你沒學過的詞、你最喜歡哪一個。

**你應該看到**：問法一通常會給你一段像百科全書的文字，可能提到「電位差」「庫侖」這種你沒學過的詞；問法二開始用比較簡單的話；問法三變短、有比喻（水流與水壓是最常見的）；問法四幾乎不會再出現公式；問法五最後會多一題給你做。從一到五，回答會越來越像「為你量身訂做」。但也請注意：**不是越長的提示詞越好**，而是「該說的有沒有說到」——問法四和五只比三多了兩句話，差別卻很大。

### 活動 2-2：寫一個自己的提示詞範本

**材料／工具**：同上，再加一個你會長期保存的地方（記事本 App、一張紙貼在書桌前都可以）。

**步驟**

1. 想一件你**常常會想請 AI 幫忙的事**。例如：「解釋一個我看不懂的課本概念」「幫我檢查英文作文的文法」「幫我出數學練習題」。
2. 照四要素寫一段範本，把會變動的地方用【】框起來。例如「解釋概念」的範本：

```
你是一位很有耐心、很會用比喻的【科目】老師。
我是台灣的【年級】學生，正在學【單元名稱】。
我看不懂的地方是：【把你看不懂的地方寫一兩句】。
請用【字數】字以內解釋，分成【幾】點，每點附一個生活例子。
不要用【我沒學過的詞或公式】。
解釋完之後，請出一題小問題讓我檢查自己懂了沒，先不要給答案。
```

3. 用你的範本**實際測試兩次**：填入兩個不同的概念，貼進 AI，看回答。
4. 根據結果修改範本：哪一句沒用（刪掉）？哪裡它老是猜錯（補一句）？
5. 把最終版抄到你會保存的地方。以後要用，直接填空。

**你應該看到**：第一次測試通常會發現範本少了某個東西，例如你忘了說「用中文回答」，或忘了說「不要給答案」。第二次補上之後，回答會穩定很多。一份好的範本，用三次之後幾乎不需要再修。

**觀察與記錄**

|---|---|---|
| 我填入的概念 | | |
| 回答符合我要的嗎？（符合／部分／不符合） | | |
| 它猜錯了什麼？ | | |
| 我因此在範本加了或刪了哪一句？ | | |

## 用工具看看：請 AI 自己檢查你的提示詞

這一章的技巧是**讓 AI 當你的提示詞教練**。你寫的提示詞到底清不清楚，問它最快——因為它就是要讀這段文字的那個「人」。

1. 把你在活動 2-2 寫好的範本（填入一個概念）準備好。
2. 開一個新對話，貼入：

```
下面是我打算拿來問你的提示詞。請你先不要執行它，而是幫我檢查：
1. 有哪些地方不夠清楚，你會需要猜？
2. 缺了什麼資訊，補上之後你能回答得更好？
3. 請幫我改寫成更清楚的版本，但保留我原本的意思。

我的提示詞：
（貼上你的範本）
```

3. 看它指出的問題，判斷哪些有道理、哪些是它想太多。
4. 把你同意的修改加進範本。

**你應該看到**：它通常會指出一到三個你沒想到的模糊處，例如「你沒說要用中文還是英文」「你說的『簡單』是多簡單」。它改寫的版本常常會變長、變制式，不一定比你的好——**改寫版只是參考，你的範本你自己決定**。這個技巧的重點不在它的改寫，而在它指出的「我會需要猜」的地方，那正是四要素裡你漏掉的部分。

## 常見錯誤與迷思

- **「提示詞越長越好。」** → 長而沒重點的提示詞一樣會讓它猜錯，而且你自己也看不清楚到底要什麼。 → 正確理解：該說的說到就好。活動 2-1 的問法四只比問法三多兩句，效果卻差很多。
- **「我要先學會『正確的格式』才能問。」** → 沒有正確格式這回事，四要素只是檢查清單。 → 正確理解：把它當成一個聰明但不認識你的助理，用你會對人交代事情的方式寫就對了。
- **「它第一次答得不好，代表它不會。」** → 第一次答得不好，通常是因為它猜錯了你要什麼。 → 正確理解：追問、修改、補背景，兩三輪之後再下判斷。
- **「給它角色（『你是一位專家』）它就真的變成專家。」** → 角色只是讓它用那種口吻和用詞接龍，它的知識沒有因此變多，幻覺也不會因此消失。 → 正確理解：角色能改善「說話的樣子」與「難度」，不能改善「正確性」。要正確，還是得查證（第 3 章）。
- **「一個對話可以一直問下去。」** → 對話太長之後，它會開始忘記前面的內容、自相矛盾。 → 正確理解：發現它開始亂，就把學到的東西整理成新的提示詞，開新對話。
- **「問法好，它就不會錯。」** → 好的問法讓它更貼近你要的，也能降低一些幻覺（例如允許它說不確定），但接龍機器的本質沒變。 → 正確理解：問法解決「答非所問」，查證解決「答錯」，兩個都要。

## 想一想

1. 「幫我寫一篇作文」這句提示詞，四要素各缺了什麼？請補成一段完整的提示詞。

<details><summary>參考答案</summary>

缺了角色（要用誰的口吻）、背景（你幾年級、題目是什麼、要交給誰、你已經寫了什麼）、格式（幾字、幾段、記敘文還是議論文），任務也太模糊（是要它代寫、還是列大綱、還是改你的稿）。而且「幫我寫」本身違反本書第三原則。較好的版本例如：「我是國二學生，作文題目是『一次難忘的失敗』，要寫 500 字的記敘文。我已經想好要寫段考失利的事。請不要幫我寫，請先問我三個問題幫我把細節想清楚，再幫我列一個四段的大綱。」

</details>

2. 下面兩個提示詞，哪一個比較可能得到你能用的回答？為什麼？（a）「解釋牛頓第一運動定律。」（b）「我是國二學生，課本說『靜者恆靜，動者恆動』，可是我騎腳踏車不踩就會停，這不是矛盾嗎？請用 100 字解釋。」

<details><summary>參考答案</summary>

（b）。它有背景（國二、課本的說法）、有具體的困惑（腳踏車會停），有格式（100 字）。AI 會直接針對「摩擦力讓腳踏車停下來，所以定律說的是『沒有外力』的情況」來回答。（a）只會得到一段教科書式的定義，不會回應你真正卡住的地方。

</details>

3. 阿凱請 AI「幫我解這題數學」，AI 直接給了答案。阿凱抄完，考試時遇到類似的題目還是不會。請改寫阿凱的提示詞，讓他這次真的學會。

<details><summary>參考答案</summary>

例如：「這題我卡在（寫出卡在哪一步）。請不要直接給答案，先問我一個問題，引導我想下一步。等我回答之後再告訴我對不對。」或「請一步一步解這題，每一步解釋為什麼要這樣做；解完之後，請出一題類似但數字不同的題目讓我自己練習，先不要給答案。」重點是把「幫我做」改成「教我做」，而且要求它確認你學會了。

</details>

4. 為什麼「請一步一步寫出你的想法」能讓 AI 的計算題比較不容易錯？用「接龍」解釋。

<details><summary>參考答案</summary>

因為接龍機器是邊接邊想的，沒有「先在心裡算完再寫」。如果你要它直接給答案，它等於要在一個字裡「心算」出結果，很容易錯。要它寫出步驟，每一步的結果都會變成下一步接龍的「龍頭」，等於讓它用紙筆算，錯誤率就低很多；而且你也能看出它在哪一步錯。

</details>

5. 小芸請 AI 用「國中程度的英文」寫講稿，AI 還是用了幾個她不認識的單字。她可以怎麼追問？請寫出兩句不同的追問。

<details><summary>參考答案</summary>

例如：「請把 heritage、commemorate 這兩個字換成更簡單的說法。」或「請把講稿裡超出國中 1200 單字範圍的字都換掉，並列出你換了哪些。」或給例子：「我認識的單字大概是這樣的程度：（貼一段課本句子），請照這個程度改寫。」重點是說出具體哪裡不滿意、要改成怎樣。

</details>

6. 開放挑戰：找一個家人（或同學），請他想一件想請 AI 幫忙的事，用一句話說出來。你負責把這句話改寫成四要素齊全的提示詞，拿去問 AI，再把結果給他看。記錄：你問了他哪些「人會反問的問題」，才把提示詞補完整？

<details><summary>參考答案</summary>

開放題。你很可能會發現自己問了：「這是要給誰看的？」「要多長？」「你已經有什麼了？」「你不要什麼？」——這些就是背景與格式。這個活動的意義是：寫提示詞的能力，其實就是「把事情交代清楚」的能力，而這個能力對人、對 AI 都一樣有用。

</details>

## 本章小結

- AI 是接龍機器，你的提示詞是龍頭；龍頭說清楚，接出來的才是你要的。
- 四要素：**角色、任務、背景、格式**。最常被忘記的是背景——它不知道你是誰、幾年級、懂什麼。
- **給例子**比用文字形容「我要的感覺」更有效。
- **一步一步來**：大任務拆成小步驟、每一步看過再往下；推理與計算請它把過程寫出來。
- 不用一次問到完美，**追問與修改**是正常流程；對話太長變亂就開新的。
- 「不要什麼」（不要公式、不要直接給答案）跟「要什麼」一樣重要。
- 提示詞不是咒語，是「把事情交代清楚」；寫一份自己的範本，常用的事直接填空。
- 好的問法解決「答非所問」，但解決不了「答錯」；那是第 3 章的事。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 提示詞 | Prompt | 你輸入給 AI 的那段文字，決定它接出什麼 |
| 角色 | Role | 提示詞裡指定 AI 用什麼身分、口吻回答 |
| 任務 | Task | 提示詞裡要 AI 做的事，用動詞開頭 |
| 背景 | Context | 提示詞裡告訴 AI 的情況：你是誰、要用在哪、已經做了什麼 |
| 格式 | Format | 提示詞裡指定回答的長度、結構、語言 |
| 少量示範 | Few-shot | 在提示詞裡先給一兩個例子，讓 AI 照著做 |
| 逐步思考 | Step-by-step / Chain of Thought | 請 AI 把推理過程一步步寫出來再給答案 |
| 追問 | Follow-up | 在同一個對話裡接著要求它修改或補充 |
| 提示詞範本 | Prompt Template | 把常用的提示詞寫成有空格的固定格式，用時填空 |
| 對話長度限制 | Context Window | AI 一次能「顧到」的文字量，對話太長會忘記前面的內容 |
