# 前言　開始之前

## 這本書是給誰的

這本書是寫給**想把 AI 接進自己工具與專案的人**。

你可能已經會跟 ChatGPT 或 Claude 聊天、會請它幫忙寫程式；讀過《AI 怎麼運作》的話，你也知道語言模型其實是在「預測下一個字」。但是聊天視窗有個天花板：它只能一次回你一段話。你想要的可能是「每天早上自動把新聞變成三句摘要」、「用自然語言開關家裡的燈」、「問一個只懂我自己筆記的機器人」。這些事都要把 AI **當成零件**裝進程式裡，而不是當成一個聊天對象。這本書就是教你怎麼裝。

主要讀者是會一點 Python 的國中生到大人。你不需要是工程師，但需要能看懂 `for` 迴圈、函式、`dict` 和 `list`，而且願意打開終端機打指令。如果你完全沒碰過 Python，建議先讀《AI 怎麼運作》的附錄或任何一本 Python 入門，寫過幾個小程式再回來。

## 兩部的關係

全書分成兩部。**第一部（第 1–6 章）是初階**：用現成的雲端模型（Claude），學會呼叫 API、讓它回 JSON、讓它用工具、寫 Skill、接 MCP、組成代理，最後學會怎麼評估它做得好不好。這一部每一章的程式都在幾十行內，重點是把「跟 AI 講話」變成「寫程式控制 AI」。

**第二部（第 7–15 章）是進階**：自己做 RAG（讓 AI 查你的資料再回答）、在自己電腦上跑開源模型、用 LoRA 微調、從零訓練一個迷你模型、自己架 MCP 伺服器，最後把這些組成可以用瀏覽器打開的小應用。第二部會用到第一部的所有東西，所以請照順序讀；但第二部內部的第 10–12 章（微調與訓練）和第 13 章（自架 MCP）可以對調。

## 環境安裝

下面是全書會用到的工具。第一部只需要前四項加 API 金鑰；Ollama 到第 8、9 章才需要。附錄 A 有 Windows 與 macOS 的逐步截圖說明，這裡只講重點。

**1. Python 3.10 以上。** 到 https://www.python.org 下載安裝；Windows 安裝時記得勾「Add Python to PATH」。打開終端機（macOS 用「終端機」，Windows 用「PowerShell」）輸入 `python --version`（有些電腦要打 `python3`），看到 3.10 以上就可以。

**2. 虛擬環境 venv。** 每個專案用自己的套件櫃子，不要全裝在系統裡。在專案資料夾執行：

```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
.venv\Scripts\activate           # Windows PowerShell
pip install anthropic
```

啟用成功後，命令列最前面會出現 `(.venv)`。之後每次開新終端機都要先 `activate` 一次。

**3. 編輯器 VS Code。** 到 https://code.visualstudio.com 下載，裝 Python 擴充套件。用「檔案 → 開啟資料夾」打開專案，`Ctrl + ~` 可以在裡面開終端機。

**4. Claude Code 與 Claude Desktop。** Claude Code 是在終端機裡跑的 AI 助理，第 3、4、5 章會用到；安裝方式請看官方說明（https://code.claude.com/docs ），常見的做法是 `npm install -g @anthropic-ai/claude-code`，裝好後在專案資料夾輸入 `claude` 就會啟動。Claude Desktop 是桌面版聊天程式（https://claude.ai/download ），第 4 章接 MCP 時會用。兩者都需要 Claude 帳號登入；本書的 Skill 與 MCP 範例用 Claude Code 為主。

**5. Ollama（第 8 章起）。** 到 https://ollama.com 下載安裝，然後 `ollama pull` 一個小模型（例如 Qwen、Llama、Gemma 系列的小參數版本），詳細在第 9 章。

**6. API 金鑰怎麼拿與保管。** 到 Anthropic 的開發者主控台（https://console.anthropic.com ）註冊、設定付款，在「API Keys」建立一把金鑰，長得像 `sk-ant-api03-...`。**金鑰只會顯示一次**，先複製下來。然後把它放進環境變數，不要寫在程式裡：

```bash
# macOS / Linux：加在 ~/.zshrc 或 ~/.bashrc 最後一行，重開終端機生效
export ANTHROPIC_API_KEY="sk-ant-你的金鑰"

# Windows PowerShell：只對目前視窗有效；要永久請用「系統 → 環境變數」設定
$env:ANTHROPIC_API_KEY = "sk-ant-你的金鑰"
```

檢查有沒有設好：`python -c "import os; print(os.environ.get('ANTHROPIC_API_KEY', '沒設定')[:12])"`，印出 `sk-ant-api03` 開頭就對了。

保管三件事：（1）金鑰不進程式碼、不進 git（把 `.env` 加進 `.gitignore`）；（2）不要貼在聊天視窗、截圖或作業裡；（3）在主控台設**每月花費上限**，就算外洩也不會損失太多。金鑰如果不小心外流，立刻到主控台刪掉重發。

API 是**按用量付費**的，計價單位是 token（大約是 0.7 個中文字或 0.75 個英文單字）。寫書時本書用的模型每 100 萬個輸入 token 約 4 美元、輸出約 20 美元；本書所有活動全做完，花費通常在 1 到 3 美元之間。第 1 章會教你算費用。

## 安全三原則

這本書會讓 AI 碰你的檔案、資料庫、甚至家裡的電燈。請從第一章就養成三個習慣：

1. **金鑰與密碼只放環境變數。** 程式碼、git、截圖、聊天視窗裡都不該出現金鑰。這是最常見、也最花錢的錯誤。
2. **給 AI 的權限越小越好。** 讓它整理資料夾就只開那個資料夾；讓它讀資料庫就只給唯讀；工具收到的輸入一律檢查後才執行。AI 會出錯、也可能被人用文字「騙」去做事（第 2 章與第 14 章會講 prompt injection）。
3. **自己架的服務不要直接開到網路上。** 本書所有伺服器預設只在你自己的電腦（`127.0.0.1`）上跑。要給別人用，必須先加驗證，第 14 章會講怎麼做。
