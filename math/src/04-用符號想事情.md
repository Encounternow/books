# 第 4 章　用符號想事情

## 本章目標
- 學完你會知道「未知數」只是一個暫時不知道的數，用 x、n 這種字母代替它，不是什麼神祕的符號。
- 學完你會正確讀出 3x、x/2、x²、2(x + 1) 這些式子的意思，並且把數字代進去算出結果。
- 學完你會用分配律把括號拆開，也會把「同類項」合併，讓一個長長的式子變短。
- 學完你會用式子描述一個規律（例如火柴棒圖形的第 n 個要幾根），而且能解釋式子裡每個部分代表什麼。
- 學完你會拆穿「數字魔術」，知道為什麼不管想什麼數，答案都一樣。

## 開場：猜不到的數，猜得到的答案

表妹拿著一張紙走過來：「小宇，你心裡想一個數，不要告訴我。把它乘以 2，再加 10，再除以 2，最後減掉你一開始想的那個數。」

小宇想的是 7。7 × 2 = 14，14 + 10 = 24，24 ÷ 2 = 12，12 − 7 = 5。

「答案是 5 對不對？」表妹得意地說。小宇不信邪，換了 100 再試一次：200、210、105、105 − 100 = 5。又是 5！換成 0 試、換成 ½ 試，答案全部都是 5。

表妹當然不是讀心術。她的祕密是：她根本不需要知道小宇想的是什麼數。她只要把那個數叫做「某個數」，然後跟著步驟走一遍，就會發現最後那個「某個數」自己消掉了。

這就是這一章要教的事：**給不知道的數取一個名字，然後照著規則算它。** 數學家把這個名字寫成 x、n、a 這種字母，這門學問叫做代數（Algebra）。學會之後，你會發現很多問題不用一個一個試，而是可以「一次算完所有情況」。

## 核心概念

### 未知數：給「那個數」一個名字

想像一個不透明的信封，裡面裝了幾枚 1 元硬幣，你不知道幾枚。你可以叫它「信封裡的硬幣數」，但這樣每次都要寫一長串，很麻煩。數學家的習慣是用一個字母代替它，例如 x。於是「信封裡的硬幣加上桌上的 3 枚」就寫成 x + 3。

這個 x 叫做未知數（Unknown），有時也叫變數（Variable），因為它可以「變」：如果信封裡有 5 枚，x 就是 5；有 12 枚，x 就是 12。字母本身沒有魔法，它只是一個**代號**。你用 x、用 n、用 ☆ 都可以，只要前後一致。

小學時你看過這種題目：「□ + 3 = 8，□ 是多少？」那個 □ 就是未知數。國中只是把 □ 換成字母，因為字母可以有很多個（x、y、z），而且寫起來比畫方格快。

### 式子怎麼讀

把數字、字母、加減乘除組合在一起，就叫做代數式（Algebraic Expression），簡稱式子。讀式子有幾個約定，第一次看會覺得奇怪，但習慣了會覺得很省事：

| 寫法 | 意思 | 為什麼這樣寫 |
|---|---|---|
| 3x | 3 × x | 乘號 × 和字母 x 長得太像，所以省掉乘號 |
| xy | x × y | 同上 |
| x/2 或 ½x | x ÷ 2 | 除法寫成分數，之後約分比較方便 |
| x² | x × x | 「x 的平方」，右上角的小 2 表示乘自己 2 次 |
| 2(x + 1) | 2 × (x + 1) | 括號裡的先算；2 乘的是整個括號 |
| −x | (−1) × x | x 的相反數，x 是 5 時 −x 就是 −5 |
| 1x | 就寫成 x | 1 乘任何數都不變，所以 1 省略 |

幾個常見的誤讀要特別小心：

- 3x 是「3 個 x 加起來」，不是「3 旁邊放一個 x」。如果 x = 4，3x = 12，不是 34。
- x² 是 x × x，不是 x × 2。x = 5 時 x² = 25，2x = 10，兩個完全不一樣。
- 2(x + 1) 的 2 要乘括號裡的每一樣東西（下面會講分配律），不是只乘 x。

### 代入：把數字放回去

式子本身只是一個「算法說明」。要得到數字，就要把 x 換成一個實際的數，這叫做代入（Substitution）。代入的時候，建議先在心裡把省略的乘號補回來，再把 x 換成數字，最後照四則運算的順序算。

例：x = 4 時，3x + 5 是多少？

- 補回乘號：3 × x + 5
- 換成數字：3 × 4 + 5
- 先乘後加：12 + 5 = 17

例：x = −2 時，x² − 3x 是多少？負數代入最容易錯，建議**先加括號再代**：

- (−2)² − 3 × (−2)
- = 4 − (−6)
- = 4 + 6 = 10

如果忘了加括號，寫成 −2² − 3 × −2，很容易算成 −4 − 6 = −10，正負號就全錯了。

### 同類項：蘋果只能跟蘋果加

3 顆蘋果加 2 顆蘋果是 5 顆蘋果。3 顆蘋果加 2 顆橘子呢？只能說「3 顆蘋果和 2 顆橘子」，沒辦法變成「5 顆什麼」。

式子也一樣。3x + 2x = 5x，因為 3 個 x 加 2 個 x 當然是 5 個 x。但 3x + 2 就是 3x + 2，不能寫成 5x，因為那個 2 不是「2 個 x」，它只是 2。

字母部分完全一樣的項，叫做同類項（Like Terms）。3x 和 2x 是同類項；5 和 7 是同類項（都沒有字母）；3x 和 3x² **不是**同類項，因為一個是 x、一個是 x²，就像「3 張 100 元」和「3 張 1000 元」不能直接說是 6 張一樣的鈔票。

合併同類項的方法：**同類項的係數相加，字母部分不變**。係數（Coefficient）就是字母前面的數字。

例：化簡 4x + 7 − x + 2

- 先找同類項：4x 和 −x 是一類，7 和 2 是一類
- x 的部分：4x − x = 3x（記得 −x 的係數是 −1）
- 數字部分：7 + 2 = 9
- 結果：3x + 9

**一個小技巧：** 每一項都帶著它前面的正負號走。4x + 7 − x + 2 可以看成 (+4x)、(+7)、(−x)、(+2) 四個東西，重新排列成 (+4x)、(−x)、(+7)、(+2) 再合併，就不會把負號弄丟。

### 分配律：為什麼 2(x + 3) = 2x + 6

分配律（Distributive Law）說的是：a × (b + c) = a × b + a × c。你其實早就會了，只是沒有用字母寫過。

想一想這個情境：一份套餐是一個漢堡（x 元）加一杯飲料（3 元）。買 2 份套餐要多少錢？你可以先算一份 x + 3，再乘 2，寫成 2(x + 3)；也可以想成 2 個漢堡加 2 杯飲料，寫成 2x + 6。兩種算法買的是一模一樣的東西，所以 2(x + 3) = 2x + 6。

用面積想會更清楚。畫一個長方形，高是 2，寬是 x + 3：

```
       <----- x -----><- 3 ->
      +---------------+------+
   2  |     2x        |  6   |
      +---------------+------+
```

整個長方形的面積是 2 × (x + 3)。把它沿著虛線切成兩塊，左邊面積 2x，右邊面積 6，合起來就是 2x + 6。括號前的數字要**分配**給括號裡的每一項，這就是「分配」律的意思。

負數在括號前面時要特別小心：−2(x − 4) 是把 −2 分給 x 和 −4，得到 −2x + 8。很多人會忘記第二項，寫成 −2x − 4 或 −2x − 8。一個檢查的辦法：代一個數試試看。x = 5 時，−2(5 − 4) = −2 × 1 = −2；而 −2 × 5 + 8 = −10 + 8 = −2。一樣，表示拆對了。

### 用式子描述規律

代數最有用的地方，是把「很多情況」壓縮成一條規則。看下面用火柴棒排的正方形：

```
 1 個正方形      2 個正方形           3 個正方形
  +--+           +--+--+              +--+--+--+
  |  |           |  |  |              |  |  |  |
  +--+           +--+--+              +--+--+--+
 4 根            7 根                 10 根
```

數一數：1 個正方形要 4 根，2 個要 7 根，3 個要 10 根。每多一個正方形就多 3 根（新正方形和前面共用一邊，所以只要再加右邊、上邊、下邊三根）。那第 100 個圖形要幾根？你當然可以從 4 開始一直加 3 加 99 次，但更聰明的做法是找出式子。

**想法一：從「每次加 3」出發。** 第 1 個是 4 根，之後每多一個加 3，所以第 n 個是 4 + 3 × (n − 1) = 4 + 3n − 3 = 3n + 1。

**想法二：從圖形的結構出發。** 每個正方形有自己的「上、下、右」三根，n 個正方形就是 3n 根，再加最左邊那一根，一共 3n + 1 根。

兩種想法得到同一個式子 3n + 1，這很好，表示式子大概是對的。驗算：n = 1 時 3 + 1 = 4 ✓；n = 3 時 9 + 1 = 10 ✓。所以第 100 個圖形要 3 × 100 + 1 = 301 根。

式子裡的每個部分都有意義：3 是「每多一個正方形多幾根」，1 是「一開始多出來的那一根」。能說出式子每個部分代表什麼，才是真的懂了。

### 拆穿數字魔術

回到開場的魔術。把「你想的數」叫做 x，跟著步驟走：

| 步驟 | 式子 | 化簡後 |
|---|---|---|
| 想一個數 | x | x |
| 乘以 2 | 2x | 2x |
| 加 10 | 2x + 10 | 2x + 10 |
| 除以 2 | (2x + 10) ÷ 2 | x + 5 |
| 減掉原來的數 | x + 5 − x | 5 |

最後一步 x 和 −x 互相抵消，剩下 5。不管 x 是 7、100、0 還是 ½，結果一定是 5。這就是為什麼表妹不用讀心術也能猜中：她設計的步驟，讓 x 自己消失了。

注意第四步「除以 2」用到了分配律：(2x + 10) ÷ 2 = 2x ÷ 2 + 10 ÷ 2 = x + 5。如果你只把 2x 除以 2、忘了 10 也要除，就會算錯。

## 動手做

### 活動 4-1：信封天平

**材料／工具**
- 衣架 1 個、棉線或橡皮筋 2 條、紙杯 2 個（當秤盤）
- 1 元硬幣 20 枚以上
- 小信封或對摺的紙 2 個（用來藏硬幣）
- 紙筆

**步驟**
1. 把兩個紙杯用棉線綁在衣架兩端，衣架掛在門把或椅背上，做成一個簡單的天平。先空著看看是否大致平衡；不平衡的話把線往中間或外側移一點調整。（如果衣架怎麼調都歪，也可以在紙上畫一個天平，用「畫」的方式玩，推理過程完全一樣。）
2. 一個人當「出題者」，背著另一個人把若干枚硬幣（例如 5 枚）裝進信封封好。這個信封裡的硬幣數就是未知數 x。
3. 出題者在左邊紙杯放「1 個信封 + 3 枚硬幣」，右邊紙杯放 8 枚硬幣，讓天平平衡。
4. 「解題者」看著天平，用式子寫下看到的東西：x + 3 = 8。然後推理：左邊的信封加 3 枚和右邊 8 枚一樣重，所以信封裡應該是 8 − 3 = 5 枚。拆開信封驗證。
5. 換人出題。試試這些擺法：左邊「2 個信封」、右邊 10 枚（2x = 10）；左邊「2 個信封 + 1 枚」、右邊「1 個信封 + 6 枚」（2x + 1 = x + 6）。每次先寫式子，再推理，再拆信封。

**你應該看到／得到**
- 每一種擺法都可以翻譯成一條含 x 的式子，而且從天平「兩邊一樣重」可以推理出 x 是多少。
- 第 5 步的最後一題你可能會發現：兩邊都有信封時，先把兩邊各拿走一個信封，天平仍然平衡，問題就變簡單了。這個想法下一章會正式登場。

**觀察與記錄**

| 左盤 | 右盤 | 寫成式子 | 推理出的 x | 拆信封驗證 |
|---|---|---|---|---|
| 1 信封 + 3 枚 | 8 枚 | x + 3 = 8 | | |
| 2 信封 | 10 枚 | | | |
| 2 信封 + 1 枚 | 1 信封 + 6 枚 | | | |
| （自己設計） | | | | |

### 活動 4-2：設計你自己的數字魔術

**材料／工具**
- 紙筆
- 一位願意被「讀心」的家人或同學

**步驟**
1. 先用開場的魔術（×2、+10、÷2、−原數）對家人表演一次，確認每次答案都是 5。
2. 在紙上用 x 代表對方想的數，把每一步的式子寫下來，親自看到 x 消失、剩下 5。
3. 現在改一改：把「+10」換成「+20」，其他不變。先用 x 推算答案會變成多少，再找人試驗。
4. 再設計一個「答案是對方原本想的數」的魔術，例如：想一個數、加 3、乘以 2、減 6、除以 2。用 x 推算結果，確認最後剩下 x。
5. 挑戰：設計一個至少 5 個步驟、最後答案永遠是 10 的魔術。寫下每一步的式子作為「說明書」，表演給家人看。

**你應該看到／得到**
- 第 3 步答案會變成 10，因為 (2x + 20) ÷ 2 − x = x + 10 − x = 10。
- 第 4 步：(2(x + 3) − 6) ÷ 2 = (2x + 6 − 6) ÷ 2 = 2x ÷ 2 = x。所以你可以「猜」出對方想的數，只要請他說出最後的結果。
- 魔術的關鍵永遠是：乘了多少、後面就除回多少；加上去的常數才是最後留下來的東西。

**觀察與記錄**

| 魔術步驟（口訣） | 每一步的式子 | 最後結果 | 實際試驗 3 次的結果 |
|---|---|---|---|
| ×2、+10、÷2、−原數 | 2x → 2x + 10 → x + 5 → 5 | 5 | |
| ×2、+20、÷2、−原數 | | | |
| +3、×2、−6、÷2 | | | |
| （自己設計） | | | |

### 活動 4-3：火柴棒的第 n 個圖形

**材料／工具**
- 火柴棒、牙籤或吸管剪成的小段，至少 40 根
- 方格紙或白紙、筆

**步驟**
1. 用火柴棒排出「一排正方形」：先排 1 個（4 根），再接著排成 2 個（7 根）、3 個（10 根）、4 個。每排好一個就數一次總根數，記在表裡。
2. 觀察「每多一個正方形多幾根」。找出第 n 個圖形的式子，用 n = 1、2、3、4 驗算。
3. 換一種圖形：一排三角形（每個三角形和前一個共用一邊）。排出 1 到 4 個，數根數，找式子。
4. 再換一種：一排「小房子」（正方形上面加一個三角形屋頂，房子和房子共用一面牆）。排出 1 到 3 間，數根數，找式子。
5. 對每一個式子，指著圖形說明：式子裡的每個數字對應圖形的哪個部分？

**你應該看到／得到**
- 正方形：4、7、10、13，式子 3n + 1。
- 三角形：3、5、7、9，式子 2n + 1（三角形一上一下排成一條帶子，每個三角形有自己的一根橫邊和一根斜邊，再加最左邊那根斜邊）。
- 小房子：6、11、16，式子 5n + 1（每間房子有自己的「地板、右牆、兩片屋頂、屋頂底邊」5 根，再加最左邊那面牆）。
- 「每次多幾根」會變成 n 前面的係數，「一開始多出來的」會變成後面加的常數。

**觀察與記錄**

|---|---|---|---|---|---|---|
| 一排正方形 | 4 | 7 | 10 | | | |
| 一排三角形 | | | | | | |
| 一排小房子 | | | | | | |

## 用工具看看

這一次用 Google 試算表（Google Sheets）來當「代入機器」，一次把很多個 x 代進式子，順便檢查「兩個式子是不是真的相等」。

**操作步驟**

1. 打開 Google 試算表，新增一個空白檔案。
2. 在 A1 打「x」，A2 打 −3，A3 打 −2，一路打到 A9 打 4。（也可以在 A2 打 −3、A3 打 −2，選取兩格後往下拖曳，試算表會自動接著填。）
3. 在 B1 打「2(x+3)」，B2 打公式 `=2*(A2+3)`，按 Enter。把 B2 往下拖到 B9，每一列都會自動代入該列的 x。
4. 在 C1 打「2x+6」，C2 打公式 `=2*A2+6`，往下拖到 C9。
5. 在 D1 打「2x+3」，D2 打公式 `=2*A2+3`，往下拖到 D9。
6. 在 E1 打「魔術結果」，E2 打公式 `=(2*A2+10)/2-A2`，往下拖。

**你會看到**

| x | 2(x+3) | 2x+6 | 2x+3 | 魔術結果 |
|---|---|---|---|---|
| −3 | 0 | 0 | −3 | 5 |
| −2 | 2 | 2 | −1 | 5 |
| −1 | 4 | 4 | 1 | 5 |
| 0 | 6 | 6 | 3 | 5 |
| 1 | 8 | 8 | 5 | 5 |
| 2 | 10 | 10 | 7 | 5 |
| 3 | 12 | 12 | 9 | 5 |
| 4 | 14 | 14 | 11 | 5 |

B 欄和 C 欄每一列都一樣，證明 2(x + 3) 和 2x + 6 不管 x 是多少都相等，這就是分配律。D 欄每一列都和 B 欄差 3，所以 2(x + 3) 絕對不等於 2x + 3。E 欄不管 x 是什麼都是 5，就是開場魔術的祕密。

**試試看：** 在 F 欄輸入 `=A2^2`（x²），G 欄輸入 `=2*A2`（2x）。比較兩欄，你會發現只有 x = 0 和 x = 2 的時候兩者相等，其他時候都不一樣。試算表裡 `^` 代表「次方」。

## 常見錯誤與迷思

- **錯誤想法：3x 就是把 3 和 x 排在一起，x = 4 時 3x = 34。** → 為什麼錯：3x 省略了乘號，意思是 3 × x。 → 正確理解：x = 4 時 3x = 12。看到字母前面的數字，先在心裡補上「×」。
- **錯誤想法：x² 和 2x 是一樣的。** → 為什麼錯：x² 是 x × x，2x 是 x + x。只有 x = 0 或 x = 2 時碰巧相等。 → 正確理解：x = 3 時，x² = 9，2x = 6。
- **錯誤想法：3x + 2 可以合併成 5x。** → 為什麼錯：3x 是 3 個 x，2 只是 2，不是「2 個 x」，它們不是同類項，就像 3 顆蘋果和 2 顆橘子不能變成 5 顆蘋果。 → 正確理解：3x + 2 已經是最簡了，不能再合併。
- **錯誤想法：2(x + 3) = 2x + 3，括號前的數只乘第一項。** → 為什麼錯：2 份「漢堡加飲料」是 2 個漢堡加 2 杯飲料，飲料也要乘 2。 → 正確理解：2(x + 3) = 2x + 6。不確定時代一個數試試：x = 1 時左邊 8、右邊 2x + 3 = 5，不相等就表示拆錯了。
- **錯誤想法：−2(x − 4) = −2x − 8。** → 為什麼錯：−2 乘 −4 是 +8，負負得正。 → 正確理解：−2(x − 4) = −2x + 8。括號前有負號時，括號裡每一項的正負號都要翻。
- **錯誤想法：x = −2 代入 x² 得到 −4。** → 為什麼錯：(−2)² = (−2) × (−2) = 4。寫成 −2² 會被看成 −(2²) = −4，所以負數代入一定要加括號。 → 正確理解：先寫 (−2)²，再算出 4。
- **錯誤想法：式子的字母一定要用 x，用別的字母就錯了。** → 為什麼錯：字母只是代號，用 n、a、t 都可以，數學家常依情境選字母（n 常代表個數，t 常代表時間）。 → 正確理解：一題裡面同一個未知數前後要用同一個字母，不同未知數用不同字母，就可以了。

## 想一想

1. 設 a = 6，分別算出 3a、a/4、a²、2(a + 1) 的值。

<details><summary>參考答案</summary>

3a = 3 × 6 = 18；a/4 = 6 ÷ 4 = 1.5；a² = 6 × 6 = 36；2(a + 1) = 2 × 7 = 14。

</details>

2. 把 x = 3、x = −2、x = ½ 分別代入 5x − 2，算出三個結果。

<details><summary>參考答案</summary>

x = 3：5 × 3 − 2 = 15 − 2 = 13。

x = −2：5 × (−2) − 2 = −10 − 2 = −12。（記得負數要加括號。）

x = ½：5 × ½ − 2 = 2.5 − 2 = 0.5。

</details>

3. 化簡下面兩個式子：(1) 4x + 7 − x + 2；(2) 2a + 3b − a + b。

<details><summary>參考答案</summary>

(1) 同類項分組：(4x − x) + (7 + 2) = 3x + 9。

(2) a 的一類：2a − a = a；b 的一類：3b + b = 4b。結果 a + 4b。a 和 b 不是同類項，不能再合併。

</details>

4. 用分配律拆開並化簡：(1) 3(2x + 5)；(2) −2(x − 4)；(3) 5(x + 2) − 3x。拆完後各代 x = 1 檢查。

<details><summary>參考答案</summary>

(1) 3 × 2x + 3 × 5 = 6x + 15。檢查 x = 1：原式 3 × 7 = 21，拆後 6 + 15 = 21 ✓。

(2) (−2) × x + (−2) × (−4) = −2x + 8。檢查 x = 1：原式 −2 × (−3) = 6，拆後 −2 + 8 = 6 ✓。

(3) 先拆括號：5x + 10 − 3x，再合併同類項：2x + 10。檢查 x = 1：原式 5 × 3 − 3 = 12，拆後 2 + 10 = 12 ✓。

</details>

5. 用火柴棒排「一排小房子」（正方形加三角形屋頂，相鄰房子共用一面牆）：1 間要 6 根，2 間要 11 根，3 間要 16 根。(1) 寫出 n 間房子要幾根的式子；(2) 20 間房子要幾根？(3) 如果有 101 根火柴棒，最多能排幾間房子？

<details><summary>參考答案</summary>

(1) 每多一間多 5 根，第 1 間是 6 根，所以第 n 間是 6 + 5(n − 1) = 5n + 1。意思是：每間房子有自己的 5 根（地板、右牆、兩片屋頂、屋頂底邊），加上最左邊那面牆 1 根。驗算 n = 3：15 + 1 = 16 ✓。

(2) 5 × 20 + 1 = 101 根。

(3) 5n + 1 = 101 時 n = 20，所以剛好能排 20 間。

</details>

6. 一家餐廳每人餐費 x 元，結帳時要再加 10% 服務費。(1) 4 個人去吃，總共要付多少？用 x 寫出式子並化簡。(2) 如果 x = 250，要付多少？(3) 如果是 n 個人去吃呢？

<details><summary>參考答案</summary>

(1) 4 個人餐費 4x，加 10% 服務費就是 4x × 1.1 = 4.4x 元。也可以寫成 4x + 0.4x = 4.4x。

(2) 4.4 × 250 = 1100 元。

(3) n 個人：nx × 1.1 = 1.1nx 元。

</details>

7. 設計一個數字魔術：不管對方想什麼數，最後答案都是 10，而且至少包含一次「乘」和一次「除」。用 x 寫出每一步，證明答案一定是 10。

<details><summary>參考答案</summary>

這題答案不只一種。一個例子：「想一個數、乘以 3、加 30、除以 3、減掉原來的數。」

用 x 檢查：3x → 3x + 30 → (3x + 30) ÷ 3 = x + 10 → x + 10 − x = 10。

設計的原則：乘幾就要除回幾，這樣 x 的係數才會回到 1，最後減掉原數才能把 x 消掉；中間加的數除以同樣的倍數之後，就是最後留下的答案（這裡 30 ÷ 3 = 10）。

</details>

8. （挑戰）很多人以為 (a + b)² = a² + b²。(1) 用 a = 3、b = 4 算一算兩邊，看看是否相等。(2) 畫一個邊長 a + b 的正方形，把它切成四塊，用面積說明 (a + b)² 到底等於什麼。

<details><summary>參考答案</summary>

(1) 左邊 (3 + 4)² = 7² = 49；右邊 3² + 4² = 9 + 16 = 25。不相等，所以 (a + b)² = a² + b² 是錯的。

(2) 邊長 a + b 的正方形，橫的切一刀、直的切一刀（都在 a 和 b 的交界處），得到四塊：

```
      <-- a --><- b ->
     +--------+------+
  a  |  a²    |  ab  |
     +--------+------+
  b  |  ab    |  b²  |
     +--------+------+
```

四塊面積加起來：a² + ab + ab + b² = a² + 2ab + b²。所以 (a + b)² = a² + 2ab + b²，多出來的 2ab 就是那兩塊長方形。用 a = 3、b = 4 驗算：9 + 24 + 16 = 49 ✓。這其實也是分配律：(a + b)(a + b) 的每一項都要乘到另一個括號的每一項。

</details>

## 本章小結

- 未知數只是一個「暫時不知道的數」的代號，用 x、n 或任何字母都可以，前後一致就好。
- 讀式子時把省略的乘號補回來：3x 是 3 × x，x² 是 x × x，2(x + 1) 是 2 × (x + 1)。
- 代入就是把字母換成數字再算；負數代入要先加括號，例如 (−2)² = 4。
- 同類項才能合併：3x + 2x = 5x，但 3x + 2 不能再簡化。合併時係數相加，字母不變。
- 分配律 a(b + c) = ab + ac：括號前的數要乘括號裡的每一項，可以用長方形面積來理解。括號前是負數時，裡面每一項的正負號都要翻。
- 用式子描述規律時，「每次增加的量」變成係數，「一開始多出來的量」變成常數；式子的每個部分都應該對得上圖形。
- 數字魔術的祕密是：設計步驟讓 x 自己消掉，所以答案和你想的數無關。
- 不確定兩個式子是否相等，代幾個數試試（或用試算表一次代很多個）是最實在的檢查方法。

|---|---|---|
| 代數 | Algebra | 用字母代替數，再照規則運算的數學 |
| 未知數 | Unknown | 暫時不知道、用字母代替的那個數 |
