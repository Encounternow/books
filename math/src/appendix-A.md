# 附錄 A　公式與定義速查

這一頁是做題、做專題時翻的。每一條都有三欄：**公式或定義**、**算例**（數字都算過）、**為什麼**（一句話說出它從哪裡來，忘記公式時可以自己推回去）。依章節排列，最後有常用數值與單位換算表。

使用約定：
- π 取 3.14（精確計算時用計算機的 π 鍵）。
- √2 ≈ 1.414、√3 ≈ 1.732、√5 ≈ 2.236。
- 1 坪 ≈ 3.3058 m²；1 吋 = 2.54 cm。

## A.1　數與數線（第 1 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 絕對值 \|a\| = a 到 0 的距離 | \|−7\| = 7，\|7\| = 7 | 距離只問多遠，不問哪個方向。 |
| 數線上 a 與 b 的距離 = \|a − b\| | \|3 − (−4)\| = \|7\| = 7 | 從 −4 走到 3 要走 7 步。 |
| 負數加負數：同向累加，結果為負 | (−3) + (−5) = −8 | 欠 3 元再欠 5 元，總共欠 8 元。 |
| 正負相加：大的減小的，取大的符號 | 7 + (−10) = −3 | 往右 7 步再往左 10 步，停在左邊 3。 |
| 減一個負數 = 加一個正數 | 5 − (−3) = 5 + 3 = 8 | 拿走一筆欠款，等於多了一筆錢。 |
| 正 × 負 = 負 | 4 × (−3) = −12 | 往左走 3 步，走 4 次，在左邊 12。 |
| 負 × 負 = 正 | (−2) × (−3) = 6 | 方向反轉兩次，回到原來的方向。 |
| 除法符號規則同乘法 | (−12) ÷ 3 = −4；(−12) ÷ (−3) = 4 | 除法是乘法的反運算，符號規則一樣。 |
| 數線上左邊的數比較小 | −3 < −2 < 0 < 1 | 越往左越冷、越往左欠越多。 |

## A.2　分數與小數（第 2 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 分數 a/b：分 b 份取 a 份 | 3/4：切 4 份拿 3 份 | 分母說怎麼切，分子說拿幾塊。 |
| 等值分數：分子分母同乘（除）一個數 | 2/3 = 4/6 = 6/9 | 切更細但拿的總量一樣。 |
| 加減先通分（分母變一樣） | 1/2 + 1/3 = 3/6 + 2/6 = 5/6 | 大小不同的塊不能直接數，要先切成一樣大。 |
| 分數乘法：分子乘分子、分母乘分母 | 2/3 × 3/4 = 6/12 = 1/2 | 「3/4 的 2/3」就是把 3/4 再切 3 份取 2 份。 |
| 分數除法：乘以倒數 | 3/4 ÷ 1/2 = 3/4 × 2/1 = 3/2 | 問「3/4 裡有幾個 1/2」，答案 1 個半。 |
| 帶分數 ↔ 假分數 | 2 ¼ = 9/4 | 2 個整的是 8/4，再加 1/4。 |
| 分數 → 小數：分子 ÷ 分母 | 3/8 = 3 ÷ 8 = 0.375 | 分數本來就是一個除法。 |
| 小數 → 分數：寫成十分之、百分之，再約分 | 0.75 = 75/100 = 3/4 | 小數點後兩位就是「百分之」。 |
| 循環小數：某一段數字無限重複 | 1/3 = 0.333…；3/11 = 0.2727… | 除不盡時餘數會重複出現。 |
| 純循環小數 → 分數：循環節 ÷ 同位數的 9 | 0.2727… = 27/99 = 3/11 | 設 x = 0.2727…，100x − x = 27，x = 27/99。 |
| 小數相乘：先當整數乘，再點回小數位數 | 0.3 × 0.3 = 0.09 | 3 × 3 = 9，兩個一位小數共兩位，所以是 0.09。 |

## A.3　百分比與比例（第 3 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 百分比 = 部分 ÷ 全體 × 100% | 40 題答對 12 題：12 ÷ 40 = 0.3 = 30% | 百分比就是「每 100 個有幾個」。 |
| 折扣：售價 = 原價 × (1 − 折扣率)；八折 = × 0.8 | 800 × 0.8 = 640 元 | 打八折是「付 80%」，不是減 8 元。 |
| 加成：新價 = 原價 × (1 + 加成率) | 含 5% 稅：500 × 1.05 = 525 元 | 原本的 100% 再加 5%。 |
| 變化率 = (新 − 舊) ÷ 舊 × 100% | 50 → 60：(60 − 50) ÷ 50 = 20% | 基準永遠是「舊的」那個。 |
| 連續折扣相乘不相加 | 八折再九折：0.8 × 0.9 = 0.72（七二折） | 第二次折扣是對已經打過折的價錢。 |
| 比 a:b 的比值 = a ÷ b | 3:4 的比值 = 0.75 | 比值是「a 是 b 的幾倍」。 |
| 比例式 a:b = c:d ⇔ a × d = b × c | 3:4 = x:20 → 4x = 60 → x = 15 | 兩個比的比值相等，交叉相乘自然相等。 |
| 速率 = 距離 ÷ 時間 | 150 km ÷ 2.5 h = 60 km/h | 速率就是「每小時走幾公里」。 |
| 時間 = 距離 ÷ 速率；距離 = 速率 × 時間 | 170 km ÷ 80 km/h ≈ 2.1 h | 同一個關係換個位置。 |
| km/h → m/s：÷ 3.6 | 72 km/h = 72 ÷ 3.6 = 20 m/s | 1 km = 1000 m，1 h = 3600 s，1000 ÷ 3600 = 1/3.6。 |
| 平均速率 = 總距離 ÷ 總時間（不是速率平均） | 去 120 km 時速 60、回程時速 40：240 ÷ (2 + 3) = 48 km/h | 慢的那段花的時間比較多，拉低平均。 |
| 比例尺 1:n：圖上 1 單位 = 實際 n 單位 | 1:25,000 圖上 4 cm = 100,000 cm = 1 km | 比例尺就是圖上長度比實際長度。 |
| 相似形：邊長比 k，面積比 k²，體積比 k³ | 邊長放大 2 倍，面積 4 倍，體積 8 倍 | 面積是兩個長度相乘，所以倍數也乘兩次。 |
| 單位換算：乘以「1 的分數」 | 2.5 m = 2.5 × (100 cm / 1 m) = 250 cm | 100 cm / 1 m 等於 1，乘 1 不改變大小。 |

## A.4　用符號想事情（第 4 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 2x 表示 x 的 2 倍；x² 表示 x × x | x = 3：2x = 6，x² = 9 | 省略乘號只是寫法，意思沒變。 |
| 代入：把數字放進字母的位置 | x = 3，2x + 5 = 2 × 3 + 5 = 11 | 字母是數的代號，給它值就能算。 |
| 分配律 a(b + c) = ab + ac | 3(x + 4) = 3x + 12 | 3 袋，每袋 x 個蘋果和 4 個橘子，共 3x 個蘋果、12 個橘子。 |
| 負號分配：−(a − b) = −a + b | −(x − 2) = −x + 2 | 負號是乘 −1，括號裡每一項都要乘。 |
| 合併同類項：字母部分相同才能加減 | 2x + 3x = 5x；4a + 2 − a = 3a + 2 | 2 個 x 加 3 個 x 是 5 個 x；x 和常數不是同類。 |
| 2x + 3 不能再化簡 | 2x + 3 ≠ 5x | 2 個蘋果加 3 個橘子不是 5 個蘋果。 |
| 用式子描述規律 | 火柴棒：第 n 個圖形 3n + 1 根 | 每多一格多 3 根，第 1 格 4 根。 |

## A.5　一元一次方程式（第 5 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 等量公理：等號兩邊同加、同減、同乘、同除（除數不為 0），仍相等 | x + 5 = 12，兩邊減 5：x = 7 | 天平兩邊拿掉一樣重的東西，還是平的。 |
| 移項變號：一項移到等號另一邊，加變減、減變加 | 3x − 4 = 11 → 3x = 11 + 4 = 15 | 其實是兩邊同加 4，左邊的 −4 消掉了。 |
| 係數移到另一邊變除 | 3x = 15 → x = 15 ÷ 3 = 5 | 兩邊同除 3。 |
| 分母先乘掉 | x/4 = 3 → x = 3 × 4 = 12 | 兩邊同乘 4。 |
| 兩邊同除時每一項都要除 | 2x + 4 = 10 → x + 2 = 5 → x = 3 | 不是只除有 x 的那一項。 |
| 解完代回驗算 | x = 5 代回 3x − 4：15 − 4 = 11 ✓ | 驗算是唯一能自己發現錯誤的方法。 |
| 應用題：設未知數 → 列式 → 解 → 驗算 → 答（含單位） | 爸爸年齡是小明 3 倍、相差 28 歲：3x − x = 28，x = 14，爸爸 42 歲 | 把「文字」翻譯成「式子」，解完再翻回「文字」。 |

## A.6　坐標與直線（第 6 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 點 (x, y)：先橫後直 | (3, 2)：往右 3、往上 2 | 約定先寫 x 再寫 y，不能對調。 |
| 四個象限：第一象限 (+,+)、第二 (−,+)、第三 (−,−)、第四 (+,−) | (−2, 5) 在第二象限 | 從右上逆時針數。 |
| 一次函數 y = ax + b | y = 2x + 1，x = 3 → y = 7 | x 每加 1，y 加 a；x = 0 時 y = b。 |
| 斜率 a = (y₂ − y₁) ÷ (x₂ − x₁) | (1, 3)、(4, 9)：(9 − 3) ÷ (4 − 1) = 2 | 斜率是「往右走 1 格，往上走幾格」。 |
| 斜率正：往右上；負：往右下；0：水平 | y = −x + 7 往右下 | 正斜率 y 跟著 x 變大。 |
| y 截距 = b（x = 0 時的 y） | y = 2x + 1 的 y 截距 1 | 直線和 y 軸的交點。 |
| x 截距：令 y = 0 解 x | 2x + 1 = 0 → x = −½ | 直線和 x 軸的交點。 |
| 兩直線交點 = 聯立方程式的解 | y = 2x + 1 與 y = −x + 7：2x + 1 = −x + 7 → x = 2，y = 5，交點 (2, 5) | 交點同時在兩條線上，所以同時滿足兩個式子。 |
| 費用直線：總費用 = 固定費 + 單價 × 數量 | 月租 299 + 每 GB 5 元：y = 5x + 299 | 固定費是截距，單價是斜率。 |

## A.7　角與三角形（第 7 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 銳角 < 90°，直角 = 90°，鈍角介於 90° 與 180°，平角 = 180°，周角 = 360° | 120° 是鈍角 | 轉一整圈是 360°，半圈 180°。 |
| 互餘：兩角和 90°；互補：兩角和 180° | 35° 的餘角 55°，補角 145° | 餘 = 補到直角，補 = 補到平角。 |
| 對頂角相等 | 兩直線相交，一角 40°，對面也是 40° | 它們都和同一個鄰角互補。 |
| 平行線：同位角相等、內錯角相等、同側內角互補 | 截線與平行線成 70°，另一條也是 70° | 平行線「方向一樣」，被同一條線切出的角一樣。 |
| 三角形內角和 = 180° | 兩角 50°、60°，第三角 70° | 把三個角撕下來拼在一起剛好一條直線。 |
| 外角 = 不相鄰兩內角和 | 內角 50°、60°，對應外角 110° | 外角 + 相鄰內角 = 180° = 三內角和。 |
| 等腰三角形兩底角相等 | 頂角 40°，底角各 (180 − 40) ÷ 2 = 70° | 對摺後兩邊重合。 |
| 三角形任兩邊和 > 第三邊 | 3、4、6 可以；3、4、8 不行（3 + 4 < 8） | 兩邊太短就碰不到一起。 |
| 全等條件：SSS、SAS、ASA、AAS、RHS | 三邊都對應相等 → 全等 | 這些條件決定了形狀和大小只有一種可能。 |
| n 邊形內角和 = (n − 2) × 180° | 五邊形 3 × 180° = 540° | 從一個頂點切成 n − 2 個三角形。 |

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 長方形面積 = 長 × 寬 | 5 × 3 = 15 cm² | 每排 5 個單位方格，排 3 排。 |
| 正方形面積 = 邊² | 4² = 16 cm² | 長方形的特例。 |
| 平行四邊形面積 = 底 × 高 | 6 × 4 = 24 cm² | 切下一角移到另一邊變成長方形。 |
| 三角形面積 = 底 × 高 ÷ 2 | 6 × 4 ÷ 2 = 12 cm² | 兩個一樣的三角形拼成平行四邊形。 |
| 梯形面積 = (上底 + 下底) × 高 ÷ 2 | (3 + 7) × 4 ÷ 2 = 20 cm² | 兩個梯形倒著拼成底為「上底 + 下底」的平行四邊形。 |
| 圓周長 = 2πr = πd | r = 5：2 × 3.14 × 5 = 31.4 cm | π 的定義就是周長 ÷ 直徑。 |
| 圓面積 = πr² | r = 5：3.14 × 25 = 78.5 cm² | 切成很多扇形拼成近似長方形，長 πr、寬 r。 |
| 長方體體積 = 長 × 寬 × 高 | 4 × 3 × 2 = 24 cm³ | 一層 4 × 3 個方塊，疊 2 層。 |
| 長方體表面積 = 2(ab + bc + ca) | 4、3、2：2 × (12 + 6 + 8) = 52 cm² | 六個面，兩兩相同。 |
| 圓柱體積 = πr²h | r = 3、h = 10：3.14 × 9 × 10 = 282.6 cm³ | 底面積 × 高，和長方體同理。 |
| 圓柱表面積 = 2πr² + 2πrh | r = 3、h = 10：2 × 3.14 × 9 + 2 × 3.14 × 30 = 56.52 + 188.4 = 244.92 cm² | 兩個圓 + 一張攤開的長方形（長 2πr、寬 h）。 |
| 1 m² = 10,000 cm²；1 m³ = 1,000,000 cm³ | 2.5 m² = 25,000 cm² | 100 × 100；100 × 100 × 100。 |
| 1 L = 1,000 mL = 1,000 cm³；1 m³ = 1,000 L | 一瓶 600 mL = 600 cm³ | 1 cm³ 就是 1 mL。 |
| 1 坪 ≈ 3.3058 m² | 10.8 m² ≈ 3.27 坪 | 坪是日式榻榻米兩張的面積。 |

## A.9　平方根與畢氏定理（第 9 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 平方 a² = a × a；平方根 √a 是「平方後等於 a 的正數」 | 7² = 49，√49 = 7 | 平方根是平方的反運算。 |
| √a 只取正數；x² = a 的解才有 ±√a | √16 = 4；x² = 16 → x = ±4 | 符號 √ 約定代表非負的那一個。 |
| 估算平方根：夾在兩個完全平方數之間 | 49 < 50 < 64 → 7 < √50 < 8，√50 ≈ 7.07 | 越接近 49，答案越接近 7。 |
| √(a × b) = √a × √b | √12 = √4 × √3 = 2√3 ≈ 3.464 | (√a × √b)² = a × b。 |
| 畢氏定理：直角三角形 a² + b² = c²（c 是斜邊） | 3² + 4² = 9 + 16 = 25 = 5² | 兩個小正方形的面積拼成大正方形（拼圖證明）。 |
| 求斜邊 c = √(a² + b²) | a = 5、b = 12：√(25 + 144) = √169 = 13 | 同上。 |
| 求股 b = √(c² − a²) | c = 10、a = 6：√(100 − 36) = √64 = 8 | 移項後開根號。 |
| 兩點距離 = √((x₂ − x₁)² + (y₂ − y₁)²) | (1, 2)、(4, 6)：√(9 + 16) = 5 | 水平差與垂直差是兩股，距離是斜邊。 |
| 正方形對角線 = 邊 × √2 | 邊 10：10 × 1.414 ≈ 14.1 | √(a² + a²) = a√2。 |
| 螢幕尺寸是對角線的吋數 | 55 吋 16:9 螢幕：寬 ≈ 121.8 cm、高 ≈ 68.5 cm | 16² + 9² = 337，√337 ≈ 18.36；寬 = 55 × 16 ÷ 18.36 ≈ 47.9 吋 × 2.54。 |

## A.10　統計與機率簡介（第 10 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 平均數 = 總和 ÷ 個數 | 70、80、90、100：340 ÷ 4 = 85 | 把總量平分給每個人。 |
| 中位數：排序後最中間的數（偶數個取中間兩個的平均） | 3、7、8、12、20 → 8；3、7、8、12 → 7.5 | 一半的人比它高、一半比它低，不受極端值影響。 |
| 眾數：出現最多次的值 | 72、85、91、68、85 → 85 | 看哪個最常見。 |
| 全距 = 最大值 − 最小值 | 91 − 68 = 23 | 數據散布多寬的最簡單量法。 |
| 機率 = 有利結果數 ÷ 所有等可能結果數 | 骰子出現偶數：3 ÷ 6 = ½ | 每個結果一樣可能，數就好。 |
| 互斥事件「或」：機率相加 | 擲出 1 或 2：1/6 + 1/6 = 1/3 | 不會同時發生，可以直接加。 |
| 獨立事件「且」：機率相乘 | 兩次都是 6：1/6 × 1/6 = 1/36 | 36 種組合裡只有 (6, 6)。 |
| 餘事件：P(至少一次) = 1 − P(一次都沒有) | 兩次至少一個 6：1 − 25/36 = 11/36 | 「至少一次」的反面是「全部沒有」。 |
| 兩顆骰子點數和的結果數：2→1、3→2、…、7→6、…、12→1，共 36 | 和為 7 的機率 6/36 = 1/6 | 畫 6 × 6 表數。 |
| 期望值 = Σ(數值 × 機率) | 一顆骰子的期望點數 (1 + 2 + … + 6) ÷ 6 = 3.5 | 長期平均一次得到多少。 |
| 相對次數 = 出現次數 ÷ 總次數，次數多時接近機率 | 擲 600 次出現 6 共 98 次：98 ÷ 600 ≈ 0.163 ≈ 1/6 | 大數法則。 |

## A.11　數學推理與證明（第 11 章）

| 公式／定義 | 算例 | 為什麼 |
|---|---|---|
| 反例：一個例子就能推翻「所有」 | 「所有質數都是奇數」→ 反例 2 | 「所有」只要有一個不符合就是假的。 |
| 要證明「存在」，舉一個例子就夠 | 「存在偶數的質數」→ 2 | 找到一個就證明了。 |
| 偶數寫成 2k，奇數寫成 2k + 1 | 14 = 2 × 7；15 = 2 × 7 + 1 | 偶數是 2 的倍數。 |
| 偶 + 偶 = 偶 | 2k + 2m = 2(k + m) | 提出公因數 2，結果仍是 2 的倍數。 |
| 奇 + 奇 = 偶 | (2k + 1) + (2m + 1) = 2(k + m + 1) | 兩個多出來的 1 湊成一個 2。 |
| 逆命題不一定成立 | 「若下雨則地濕」對，「若地濕則下雨」不一定 | 灑水也會讓地濕。 |
| 歸納發現 → 還要證明 | n² − n + 41 在 n = 1 到 40 都是質數，n = 41 不是 | 前幾項成立不代表永遠成立。 |
| 1 + 2 + … + n = n(n + 1) ÷ 2 | n = 100：100 × 101 ÷ 2 = 5050 | 頭尾配對每對 n + 1，共 n/2 對。 |
| 漢諾塔 n 層最少 2ⁿ − 1 步 | 3 層 7 步、5 層 31 步、10 層 1023 步 | 搬 n 層 = 搬 n − 1 層兩次再加 1 步。 |
| 握手問題 n(n − 1) ÷ 2 | 20 人 190 次 | 每人握 n − 1 次，每次被算兩遍。 |

## A.12　解題策略（第 12 章）
