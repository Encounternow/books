# 第 7 章　角與三角形

## 本章目標
- 學完你會用量角器量角、依大小把角分成銳角、直角、鈍角、平角，並說出餘角、補角、對頂角的關係。
- 學完你會在「兩條平行線被第三條線切過」的圖裡，找出同位角、內錯角、同側內角，並說出它們相等或互補的理由。
- 學完你會用撕角和平行線兩種方法，解釋三角形內角和為什麼是 180°，而不是只會背。
- 學完你會判斷三根棒子能不能圍成三角形（三角不等式），也會說出三角形為什麼「穩」。
- 學完你會用 SSS、SAS、ASA 判斷兩個三角形是否全等，並找出對應的邊和角。

## 開場：為什麼腳踏車的車架是三角形？

小宇洗腳踏車的時候，第一次認真看車架：前叉、座管、上管、下管，拼起來居然是兩個三角形接在一起。他又看了一眼家裡的鐵門，斜對角也焊了一根鐵條，把長方形切成兩個三角形。

表妹說：「因為三角形很穩啊。」小宇追問：「為什麼三角形就穩？四邊形為什麼不穩？」表妹答不出來。

這個問題的答案藏在一件很簡單的事實裡：**三根長度固定的棒子，只能圍出一種三角形。** 你沒辦法把它壓扁或拉歪。但四根棒子圍出的四邊形可以隨便歪，因為它的角沒有被邊「鎖住」。

這一章我們就從「角」開始，一路講到三角形。你會親手撕下一個三角形的三個角，把它們拼成一條直線，發現內角和永遠是 180°；也會用吸管試試看哪三根能圍成三角形、哪三根不行。學完之後，你再看腳踏車、鐵門、橋梁、鐵塔，會看到滿滿的三角形，而且知道它們為什麼在那裡。

## 核心概念

### 角：從一點張開的兩條線

從一個點（頂點，Vertex）畫出兩條射線（邊），它們之間張開的程度叫做角（Angle）。角的單位是度（Degree，°），把一整圈平分成 360 份，每一份是 1°。（為什麼是 360？一般認為是古代巴比倫人的習慣，而且 360 能被 2、3、4、5、6、8、9、10、12 整除，分起來方便。）

角的大小只跟「張開多少」有關，跟邊畫得多長無關。畫一個 30° 的角，把兩邊各延長一倍，它還是 30°。這一點很多人會搞錯。

依大小分類：

| 名稱 | 英文 | 大小 | 生活例子 |
|---|---|---|---|
| 銳角 | Acute Angle | 0° 到 90° 之間 | 剪刀稍微張開、時鐘 1 點整時針分針的夾角（30°） |
| 直角 | Right Angle | 剛好 90° | 書的角、牆角 |
| 鈍角 | Obtuse Angle | 90° 到 180° 之間 | 躺椅靠背和座面的角、時鐘 5 點整（150°） |
| 平角 | Straight Angle | 剛好 180° | 一條直線 |
| 周角 | Full Angle | 剛好 360° | 轉一整圈 |

兩個特別的關係：兩個角加起來是 90° 叫互為餘角（Complementary），加起來是 180° 叫互為補角（Supplementary）。35° 的餘角是 55°，補角是 145°。記法：「餘」是補到直角、「補」是補到平角，補角比餘角「補」得多。

### 對頂角：兩條直線交叉

兩條直線交叉，會出現四個角：

```
          A               D
           \     1       /
            \           /
         4   \         /   2
              \       /
               \     /
                \   /
                 \ /
                  O
                 / \
                /   \
               /     \
          3   /       \
             /         \
            /           \
           C             B
```

∠1 和 ∠3 隔著頂點 O 相對，叫對頂角（Vertical Angles）；∠2 和 ∠4 也是一對。**對頂角一定相等。** 為什麼？∠1 和 ∠2 合起來是直線 AB 上的平角，所以 ∠1 + ∠2 = 180°；∠3 和 ∠2 合起來是直線 CD 上的平角，∠3 + ∠2 = 180°。兩個式子都是「某個角加 ∠2 等於 180°」，那個角當然一樣，所以 ∠1 = ∠3。

這是本章第一個「不用量就知道」的結論。數學喜歡這種東西：量角器會有誤差，推理不會。

### 平行線與截線：三組角

兩條永遠不相交的直線叫平行線（Parallel Lines），記作 L₁ ∥ L₂。鐵軌、筆記本的橫線、斑馬線都是。再畫一條線把它們切過去，叫做截線（Transversal），就出現八個角：

```
                    /
             1     /    2
   L1 ------------+------------
             4   /    3
                /
               /
         5    /    6
   L2 -------+-----------------
         8  /    7
           /
```

這八個角依位置分成三組，名字聽起來很多，但其實就是「在哪個位置」的描述：

| 名稱 | 英文 | 意思 | 例子 | 關係（當 L₁ ∥ L₂ 時） |
|---|---|---|---|---|
| 同位角 | Corresponding Angles | 在截線同一側、兩條平行線「同樣位置」的角 | ∠1 與 ∠5，∠2 與 ∠6，∠4 與 ∠8，∠3 與 ∠7 | 相等 |
| 內錯角 | Alternate Interior Angles | 在兩平行線之間、截線兩側交錯的角 | ∠4 與 ∠6，∠3 與 ∠5 | 相等 |
| 同側內角 | Co-interior Angles | 在兩平行線之間、截線同一側的角 | ∠4 與 ∠5，∠3 與 ∠6 | 互補（和 180°） |

為什麼同位角相等？因為兩條線平行，它們「歪的方向」一模一樣，截線切過去的角度當然也一樣。你可以把 L₁ 連同它的四個角沿著截線往下滑，滑到 L₂ 的位置會完全重合，∠1 就疊在 ∠5 上。這是平行線的基本性質，其他兩組都可以從它推出來：

- 內錯角：∠4 和 ∠2 是對頂角所以相等，∠2 和 ∠6 是同位角所以相等，於是 ∠4 = ∠6。
- 同側內角：∠4 + ∠1 = 180°（平角），而 ∠1 = ∠5（同位角），所以 ∠4 + ∠5 = 180°。

反過來也成立：量到一組同位角相等，就能斷定兩條線平行。

### 三角形的內角和為什麼是 180°

三角形（Triangle）有三個頂點、三條邊、三個內角（Interior Angles）。你一定聽過「三角形內角和是 180°」，但為什麼？

**第一個理由：撕下來拼。** 隨便剪一個三角形，把三個角撕下來，頂點對頂點拼在一起，你會發現它們剛好拼成一條直線，也就是一個平角 180°。這個活動在「動手做」裡會做，很有說服力，但它有個問題：你只試了幾個三角形，怎麼知道「每一個」三角形都是這樣？

**第二個理由：用平行線推理。** 這才是數學上真正的「為什麼」。

```
                      A
   -------------------+-------------------  直線 L，過 A 且平行於 BC
                   2 / \ 3
                    /   \
                   /  1  \
                  /       \
                 /         \
                / 2       3 \
               +-------------+
               B             C
```

過頂點 A 畫一條直線 L 平行於底邊 BC。在 A 的上方，L 被 AB 和 AC 切成三個角，從左到右是 ∠2、∠1、∠3，三個角合起來是直線 L 上的平角：

> ∠2 + ∠1 + ∠3 = 180°

現在看這三個角是誰：

- 中間的 ∠1 就是三角形的 ∠A。
- 左邊的 ∠2 和三角形的 ∠B 是內錯角（AB 是截線，切過平行的 L 和 BC），所以 ∠2 = ∠B。
- 右邊的 ∠3 和 ∠C 是內錯角（AC 是截線），所以 ∠3 = ∠C。

把它們換掉：∠B + ∠A + ∠C = 180°。

這個推理對**任何**三角形都成立，因為我們沒有用到任何特定的長度或角度，只用了「平行線的內錯角相等」和「平角是 180°」。撕角拼直線其實就是在「用手」做這件事：你把 ∠B 和 ∠C 搬到 A 旁邊，正好是內錯角的位置。

知道內角和 180° 之後，很多事可以算：

- 兩個角是 40° 和 65°，第三個角是 180° − 40° − 65° = 75°。
- 直角三角形（有一個 90° 的角）的另外兩個角加起來一定是 90°，互為餘角。
- 等腰三角形（兩邊等長）的兩個底角相等，頂角 40° 時每個底角是 (180° − 40°) ÷ 2 = 70°。
- 正三角形（三邊等長）每個角都是 180° ÷ 3 = 60°。

### 外角：等於不相鄰的兩個內角之和

把三角形的一邊延長，延長線和另一邊夾出來的角叫外角（Exterior Angle）：

```
                 A
                / \
               /   \
              /     \
             /       \
            /         \
           +-----------+-------------
           B           C    外角 ∠ACD    D
```

∠ACD 和內角 ∠ACB 拼成平角，所以 ∠ACD = 180° − ∠C。又因為 ∠A + ∠B + ∠C = 180°，所以 180° − ∠C = ∠A + ∠B。合起來得到：

> 外角 = 不相鄰的兩個內角之和

例：∠A = 50°、∠B = 60°，則 ∠ACD = 110°。檢查：∠C = 70°，180° − 70° = 110° ✓。這個性質很好用，因為少算一步。

### 三角形的邊：三角不等式

三根棒子隨便拿，一定能圍成三角形嗎？試試看 2 公分、3 公分、6 公分：把 2 和 3 接起來才 5 公分，還不到 6 公分，根本碰不到另一端。

```
       2      3
    +-----+--------+          6 公分的棒子
    +-----------------+       ← 短的兩根加起來還是太短，合不攏
```

所以三角形的三邊必須滿足三角不等式（Triangle Inequality）：**任兩邊的和要大於第三邊。** 其實只要檢查「最短的兩邊加起來有沒有大於最長邊」就夠了，因為其他兩個條件一定自動成立。

- 3、4、5：3 + 4 = 7 > 5 ✓，可以。
- 2、3、6：2 + 3 = 5 < 6 ✗，不行。
- 5、5、10：5 + 5 = 10，剛好等於，兩根短的會「躺平」在長的上面，壓成一條線，也不行。

反過來問：兩邊是 4 和 9，第三邊 x 可以是多少？要 4 + 9 > x，所以 x < 13；也要 4 + x > 9，所以 x > 5。答案是 5 < x < 13。

另一個關於邊的事實：**大邊對大角**。三角形裡最長的邊對面的角最大，最短的邊對面的角最小。想像把一個角張得越開，對面的邊就被撐得越長。

### 為什麼三角形很穩

回到開場。三根長度固定的棒子圍成三角形，**三個角就被完全決定了**：你沒辦法在不改變邊長的情況下改變任何一個角。這就是三角形的穩定性（Rigidity）。

四邊形不一樣。四根棒子圍成的正方形可以壓成菱形，邊長都沒變但角全變了。要讓它穩，就得加一根對角線，把它變成兩個三角形。這就是鐵門、鷹架、橋梁、鐵塔到處都是三角形的原因。

「三邊決定三角形」這件事還有一個數學上的名字，叫做 SSS 全等，下一節講。

### 全等：一模一樣的三角形

兩個三角形如果能完全疊在一起（可以移動、旋轉、翻面），叫做全等（Congruent），記作 △ABC ≅ △DEF。全等的三角形，對應的邊相等、對應的角相等。「對應」的意思是「疊在一起時碰在一起的那一對」，寫 △ABC ≅ △DEF 時，字母順序就告訴你 A 對 D、B 對 E、C 對 F。

要判斷兩個三角形全等，不需要六樣東西（三邊三角）都量，只要三樣就夠，但要對的三樣：

| 判斷法 | 英文 | 要知道什麼 | 為什麼夠 |
|---|---|---|---|
| SSS | Side-Side-Side | 三邊對應相等 | 三根棒子只能圍出一種三角形（穩定性） |
| SAS | Side-Angle-Side | 兩邊和它們**夾的角**對應相等 | 兩根棒子用固定的角度接起來，第三邊的位置就定了 |
| ASA | Angle-Side-Angle | 兩角和它們**夾的邊**對應相等 | 一根棒子兩端各以固定角度射出一條線，交點只有一個 |

要特別注意的是 AAA（三個角都相等）**不能**判斷全等：一個小三角形和一個放大兩倍的三角形，三個角完全一樣，但大小不同。這種叫相似（Similar），第 3 章的縮放就是在講它。另外 SSA（兩邊和一個不是夾角的角）也不行，同樣的條件可能畫出兩個不同的三角形。

## 動手做

### 活動 7-1：撕角拼直線

**材料／工具**
- 色紙或影印紙 3 張、剪刀、尺、三種顏色的筆
- 量角器（文具店有，或用手機的量角器 App）

**步驟**
1. 在紙上隨便畫一個三角形，三個角盡量長得不一樣（一個很尖、一個很鈍）。用尺把三邊畫直，剪下來。
2. 先用量角器量三個角，記在表裡，加總看看。
3. 用三種顏色把三個角塗上記號（只塗角的附近就好）。
4. 把三個角撕下來（撕得不整齊沒關係，重點是頂點要留著）。
5. 在另一張紙上畫一條直線，在線上點一個點。把三個撕下來的角的**頂點對準這個點**，彼此緊貼不重疊，擺在直線的同一側。
6. 觀察三個角是不是剛好填滿直線的一側（半圈）。
7. 再剪一個完全不同形狀的三角形（例如一個很扁、很長的），重做一次。
8. 挑戰：剪一個四邊形，撕下四個角，頂點對準一點拼拼看，會拼成什麼？

**你應該看到／得到**
- 三個角不管怎麼撕，拼起來剛好是一條直線（180°），不多不少。量角器量的三個角加起來會接近 180°，差個一兩度是量角器的誤差。
- 四邊形的四個角拼起來會繞成一整圈（360°）。
- 想一想：撕下來的 ∠B 和 ∠C 放到 ∠A 旁邊，正好就是核心概念裡「過 A 畫平行線」的那張圖。你的手做的事和推理做的事是同一件。

**觀察與記錄**

| 三角形 | ∠A（量） | ∠B（量） | ∠C（量） | 三角和 | 拼起來是直線嗎 |
|---|---|---|---|---|---|
| 第 1 個 | | | | | |
| 第 2 個 | | | | | |
| 四邊形（四個角） | | | | | 拼成一整圈嗎： |

### 活動 7-2：吸管三角形

**材料／工具**
- 吸管 10 根以上、剪刀、尺
- 毛根（扭扭棒）或細鐵絲剪成 2 公分小段，用來接吸管（也可以用細線穿過去綁）
- 紙筆

**步驟**
1. 把吸管剪成下面這些長度（公分）：3、4、5、2、6、5、5、10、7、8、9。每根寫上長度。
2. 用毛根把三根吸管接成三角形，依序試這幾組：(3, 4, 5)、(2, 3, 6)、(5, 5, 10)、(7, 8, 9)、(4, 5, 9)。每一組先**預測**能不能圍成，再動手。
3. 對能圍成的組合，試著用手把三角形壓扁或拉歪（不要把接頭弄壞）。能變形嗎？
4. 再用四根吸管（例如 5、5、5、5）接成正方形，用手壓壓看。
5. 在正方形裡加一根對角線吸管（量一下需要多長，約 7 公分），再壓壓看。
6. 對 (7, 8, 9) 這組，用量角器量三個角，看最大的角對著哪一邊。

**你應該看到／得到**
- (3, 4, 5)、(7, 8, 9) 可以圍成；(2, 3, 6)、(4, 5, 9) 兩根短的合起來碰不到；(5, 5, 10) 剛好躺平成一條線，立不起來。規律：最短兩邊相加要**大於**最長邊。
- 三角形怎麼壓都不會變形（除非接頭壞掉），正方形一壓就歪成菱形，加了對角線之後就不會歪了。
- (7, 8, 9) 最大的角對著 9 公分那根，最小的角對著 7 公分那根。

**觀察與記錄**

| 三邊長 | 最短兩邊相加 | 最長邊 | 預測能圍成嗎 | 實際結果 |
|---|---|---|---|---|
| 3, 4, 5 | 7 | 5 | | |
| 2, 3, 6 | | | | |
| 5, 5, 10 | | | | |
| 7, 8, 9 | | | | |
| 4, 5, 9 | | | | |

| 形狀 | 用手壓會變形嗎 | 為什麼 |

### 活動 7-3：照條件畫三角形，看看會不會一樣

**材料／工具**
- 圓規、尺、量角器、白紙
- 一位家人或同學（兩人各畫一份）

**步驟**
1. 兩人分開、不互看，各自照這個條件畫一個三角形：三邊 6 公分、8 公分、10 公分。畫法：先畫 10 公分的底邊 BC；圓規張開 6 公分，以 B 為中心畫一段弧；圓規張開 8 公分，以 C 為中心畫一段弧；兩段弧的交點就是 A。連起來。
2. 畫完後把兩張紙疊在一起對著光看，三角形重合嗎？（可以翻面比。）
3. 再各自畫：兩邊 5 公分、7 公分，夾角 50°。畫法：畫 7 公分的底邊，在一端用量角器畫 50° 的射線，在射線上量 5 公分做記號，連起來。疊起來比。
4. 再各自畫：三個角 40°、60°、80°，邊長隨意。疊起來比。
5. 最後各自畫：兩邊 5 公分、7 公分，和一個 40° 的角，但這個角**不是夾角**（是 7 公分那邊對面的角）。疊起來比，再看看是否有人畫出不一樣的形狀。

**你應該看到／得到**
- 第 1 步（SSS）和第 3 步（SAS）兩人畫的完全重合，全等。
- 第 4 步（AAA）兩人畫的形狀一樣但大小不一定相同，是相似不是全等。
- 第 5 步（SSA）可能出現兩種不同的三角形，所以 SSA 不能當全等的判斷條件。

**觀察與記錄**

## 用工具看看

用 GeoGebra 畫一個三角形，量三個角，然後**拖動頂點**，看內角和會不會變。

**GeoGebra 幾何操作**

1. 打開 geogebra.org/geometry（幾何）。
2. 在工具列找「多邊形」工具（圖示是一個三角形），點一下。在畫布上點三個地方，再點回第一個點，就畫出三角形 ABC。
3. 找「角度」工具（圖示是一個小扇形）。用這個工具**在三角形內部點一下**，GeoGebra 會一次標出三個內角 α、β、γ 的度數。（如果只標出一個，就依序逆時針點三個頂點，例如點 B、A、C 得 ∠A。）
4. 在左邊代數區的輸入列打 `α + β + γ` 按 Enter，會出現一個數字 180°。
5. 切回「移動」工具（箭頭），用滑鼠拖動頂點 A、B 或 C。三個角的數字一直在變，但 α + β + γ 永遠是 180°。
6. 把 A 拖到很靠近 BC，讓三角形變得很扁：∠A 會接近 180°，另外兩個接近 0°，和還是 180°。

**GeoGebra 看平行線的角**

1. 用「直線」工具畫一條直線 BC。
2. 用「平行線」工具（圖示是兩條平行線）：先點直線 BC，再點畫布上方一個點 A，會畫出過 A 且平行於 BC 的直線。
3. 用「線段」工具連 AB、AC。
4. 用「角度」工具量 A 上方的三個角和三角形的 ∠B、∠C。你會看到左邊那個角等於 ∠B、右邊那個角等於 ∠C（內錯角相等），而上方三個角相加是 180°。
5. 拖動 A、B、C，這些相等關係一直保持。這就是核心概念那個證明的動態版本。

## 常見錯誤與迷思

- **錯誤想法：角的兩邊畫得越長，角就越大。** → 為什麼錯：角是「張開的程度」，和邊的長度無關。 → 正確理解：用量角器量的是張開的角度，邊延長再多也不變。
- **錯誤想法：餘角和補角記反。** → 為什麼錯：兩個都是「補到某個角」，容易混。 → 正確理解：餘角補到 90°（直角），補角補到 180°（平角）；「補」比「餘」補得多。35° 的餘角 55°、補角 145°。
- **錯誤想法：只要有截線，同位角就相等。** → 為什麼錯：同位角相等的前提是兩條線**平行**。不平行的兩條線被切過，同位角不相等。 → 正確理解：先確認（或題目給了）平行，才能用同位角、內錯角相等、同側內角互補。
- **錯誤想法：內角和 180° 只對「普通」三角形成立，很扁或很尖的不一定。** → 為什麼錯：證明只用了平行線性質和平角，對任何三角形都成立。 → 正確理解：三角形不管什麼形狀，內角和都是 180°；用 GeoGebra 拖動頂點可以親眼看到。
- **錯誤想法：三根棒子一定能圍成三角形。** → 為什麼錯：2、3、6 公分的棒子，兩根短的加起來碰不到長的那根。 → 正確理解：最短兩邊相加必須大於最長邊；剛好等於也不行，會躺平成一條線。
- **錯誤想法：三個角都相等的兩個三角形一定全等。** → 為什麼錯：角相等只能保證形狀一樣，不能保證大小一樣，例如一個邊長 3 的正三角形和一個邊長 6 的正三角形。 → 正確理解：那是相似。全等要用 SSS、SAS 或 ASA，條件裡至少要有一條邊。
- **錯誤想法：SAS 的角可以是任何一個角。** → 為什麼錯：SAS 的角必須是兩邊「夾」的那個角；如果是其他角（SSA），可能畫出兩個不同的三角形。 → 正確理解：看到兩邊一角，先確認角在不在兩邊中間。

## 想一想

1. 把 35°、90°、120°、180° 分類（銳角、直角、鈍角、平角），並寫出 35° 的餘角與補角。

<details><summary>參考答案</summary>

35° 銳角、90° 直角、120° 鈍角、180° 平角。35° 的餘角是 90° − 35° = 55°，補角是 180° − 35° = 145°。

</details>

2. 兩條直線交叉，其中一個角是 50°。另外三個角各是多少？說明理由。

<details><summary>參考答案</summary>

對頂角 50°（對頂角相等）；另外兩個角和 50° 各拼成平角，所以都是 180° − 50° = 130°，而且它們互為對頂角。檢查：50 + 130 + 50 + 130 = 360° ✓（繞一圈）。

</details>

3. L₁ ∥ L₂，截線切過去，核心概念圖裡的 ∠1 = 70°。求 ∠5、∠3、∠4、∠6，並說出每一個用的是哪種角的關係。

<details><summary>參考答案</summary>

∠5 = 70°：∠1 與 ∠5 是同位角，平行時相等。

∠3 = 70°：∠1 與 ∠3 是對頂角，一定相等。

∠4 = 110°：∠1 與 ∠4 在直線 L₁ 上拼成平角，180° − 70° = 110°。

∠6 = 110°：∠4 與 ∠6 是內錯角，平行時相等。

檢查：∠4 + ∠5 = 110° + 70° = 180°，同側內角互補 ✓；∠2 = 180° − 70° = 110°，∠2 與 ∠6 是同位角，也是 110° ✓。三組關係互相對得上，答案才可靠。

</details>

4. (1) 三角形兩個角是 40° 和 65°，第三個角多少？(2) 等腰三角形頂角 40°，底角各多少？(3) 直角三角形的一個銳角是 28°，另一個銳角多少？

<details><summary>參考答案</summary>

(1) 180° − 40° − 65° = 75°。

(2) (180° − 40°) ÷ 2 = 70°，兩個底角都是 70°。

(3) 90° − 28° = 62°（直角三角形兩個銳角互為餘角）。

</details>

5. 三角形 ABC 中 ∠A = 50°、∠B = 60°，把 BC 延長到 D。(1) 求外角 ∠ACD；(2) 用兩種方法算，看答案是否一致。

<details><summary>參考答案</summary>

方法一：∠C = 180° − 50° − 60° = 70°，外角 ∠ACD = 180° − 70° = 110°。

方法二：外角等於不相鄰的兩內角之和，∠ACD = 50° + 60° = 110°。兩種方法一致。

</details>

6. (1) 下面哪幾組可以圍成三角形：3、4、5；2、3、6；5、5、10；7、8、9？(2) 兩邊是 4 和 9，第三邊的長度 x 要在什麼範圍？(3) 如果 x 必須是整數，有幾種可能？

<details><summary>參考答案</summary>

(1) 3、4、5 可以（3 + 4 = 7 > 5）；2、3、6 不行（2 + 3 = 5 < 6）；5、5、10 不行（5 + 5 = 10，剛好等於會躺平）；7、8、9 可以（7 + 8 = 15 > 9）。

(2) 4 + 9 > x 得 x < 13；4 + x > 9 得 x > 5。所以 5 < x < 13。

(3) x 可以是 6、7、8、9、10、11、12，共 7 種。

</details>

7. 兩個三角形 △ABC 和 △DEF，已知 AB = DE、∠B = ∠E、BC = EF。(1) 它們全等嗎？用的是哪個判斷法？(2) 哪一組邊和角是「對應」的？(3) 如果條件改成 AB = DE、BC = EF、∠A = ∠D，還能判斷全等嗎？

<details><summary>參考答案</summary>

(1) 全等，SAS：兩邊 AB、BC 和它們夾的角 ∠B，對應 DE、EF 和 ∠E。寫作 △ABC ≅ △DEF。

(2) A 對 D、B 對 E、C 對 F；所以 AC = DF、∠A = ∠D、∠C = ∠F。

(3) 不能。∠A 不是 AB 和 BC 夾的角（夾角是 ∠B），這是 SSA，可能畫出兩個不同的三角形。活動 7-3 的第 5 步就是這種情況。

</details>

8. （挑戰）(1) 任意四邊形的內角和是多少？提示：畫一條對角線。(2) 五邊形呢？六邊形呢？(3) 寫出 n 邊形內角和的式子。(4) 正六邊形（六邊等長、六角相等）每個角幾度？用這個解釋為什麼蜂巢的六邊形可以拼滿平面不留縫。

<details><summary>參考答案</summary>

(1) 畫一條對角線，四邊形變成兩個三角形，內角和 = 2 × 180° = 360°。活動 7-1 第 8 步撕四個角拼成一整圈，就是 360°。

(2) 從一個頂點畫對角線，五邊形切成 3 個三角形，內角和 3 × 180° = 540°；六邊形切成 4 個，4 × 180° = 720°。

(3) n 邊形從一個頂點可以切成 (n − 2) 個三角形，內角和 = (n − 2) × 180°。檢查 n = 3：1 × 180° = 180° ✓；n = 4：2 × 180° = 360° ✓。

(4) 720° ÷ 6 = 120°。在一個點周圍擺三個正六邊形，3 × 120° = 360°，剛好繞一整圈，所以不留縫也不重疊。正五邊形每角 108°，三個只有 324°、四個就 432°，怎麼擺都不合，所以沒有正五邊形的蜂巢。

</details>

## 本章小結

- 角是張開的程度，單位是度，和邊長無關。銳角小於 90°，直角 90°，鈍角介於 90° 和 180°，平角 180°。餘角合 90°，補角合 180°。
- 對頂角相等，理由是它們和同一個角各拼成平角。
- 兩平行線被截線切過：同位角相等、內錯角相等、同側內角互補。前提是「平行」。
- 三角形內角和 180°：撕角拼直線是親眼看，過頂點畫平行線、用內錯角把三個角搬到一條直線上是真正的證明。
- 外角等於不相鄰的兩個內角之和。
- 三角不等式：最短兩邊相加要大於最長邊，剛好等於也不行。大邊對大角。
- 三邊固定就只能圍出一種三角形，所以三角形不會變形，這就是車架、鐵門、橋梁用三角形的原因。
- 全等判斷用 SSS、SAS（角要是夾角）、ASA；AAA 只能說相似，SSA 不能判斷。
- n 邊形內角和是 (n − 2) × 180°，因為可以切成 n − 2 個三角形。
