# 第 5 章　一元一次方程式

## 本章目標
- 學完你會說出「方程式」和「式子」的差別，知道「解方程式」是在找讓等號成立的那個數。
- 學完你會用天平解釋「等式兩邊同時做一樣的事，等號還是成立」，並用這個道理解方程式。
- 學完你會解釋「移項為什麼要變號」，而且知道它不是一條要背的規則，而是「兩邊同時減掉同一個數」的縮寫。
- 學完你會照固定步驟解含括號、含分數、兩邊都有 x 的一元一次方程式，並且會驗算。
- 學完你會把年齡、購物、速度這類文字題翻譯成方程式，再解出答案。

## 開場：媽媽幾歲的時候是你的三倍？

小宇今年 8 歲，媽媽 36 歲。晚餐時媽媽隨口說：「等我剛好是你三倍年紀的時候，我們去環島。」小宇很興奮，但那是幾年後？

他開始試：明年小宇 9、媽媽 37，不是三倍。再明年 10 和 38，不是。11 和 39，不是⋯⋯試到第 6 年：小宇 14，媽媽 42，42 = 3 × 14，就是這一年！

試了六次才找到，還好不是六十年後。有沒有辦法不用一個一個試？

有。把「幾年後」叫做 n，那時候小宇 8 + n 歲，媽媽 36 + n 歲，「媽媽是小宇的三倍」就寫成 36 + n = 3(8 + n)。這一條式子叫做方程式，它把題目的條件全部裝進去了。接下來只要學會「解」它，答案 n = 6 就會自己跑出來，不管題目的數字多大都一樣。

上一章我們學會用字母寫式子，這一章要學的是：**當式子裡有等號，怎麼把那個未知數找出來。** 工具只有一個，就是天平。

## 核心概念

### 式子、等式、方程式

上一章的 3x + 1 是一個式子，它沒有等號，不能問「對不對」，只能問「x 是多少時它的值是多少」。

把兩個式子用等號接起來，例如 3x + 1 = 16，就成了等式（Equation）。這個等式有一個未知數 x，而且 x 只是一次方（沒有 x²），所以叫做一元一次方程式（Linear Equation in One Variable）：「一元」是一個未知數，「一次」是最高次方為 1。

方程式和一般的等式不同的地方在於：它**不一定成立**。3x + 1 = 16 在 x = 5 的時候成立（15 + 1 = 16 ✓），在 x = 2 的時候不成立（6 + 1 = 7 ≠ 16）。讓等號成立的那個 x 值，叫做方程式的解（Solution）。「解方程式」就是把這個值找出來。

所以解完方程式之後，永遠要做一件事：**把解代回去，看等號是不是真的成立。** 這叫驗算，是你自己當自己老師的方法。

### 等式就是一座天平

想像一座平衡的天平，左盤放 3 個裝了 x 枚硬幣的信封加 1 枚硬幣，右盤放 16 枚硬幣。天平平衡，就是 3x + 1 = 16。

```
         3x + 1                 16
    [x][x][x] (1)        (16 枚硬幣)
   ________|________    ________|________
           \                    /
            \__________________/
                     ^
                  平衡
```

平衡的天平有一個很簡單的性質：**兩邊同時拿走一樣的東西，或同時放上一樣的東西，天平還是平衡。** 兩邊同時加倍、同時減半，也還是平衡。寫成規則就是等量公理（Properties of Equality）：

| 天平動作 | 等式規則 | 例子（從 3x + 1 = 16 開始） |
|---|---|---|
| 兩邊同時拿走一樣的東西 | 兩邊同減一數 | 3x + 1 − 1 = 16 − 1，得 3x = 15 |
| 兩邊同時放上一樣的東西 | 兩邊同加一數 | 3x + 5 = 20（和原式有同樣的解） |
| 兩邊同時變成幾倍 | 兩邊同乘一數（不是 0） | 6x + 2 = 32 |
| 兩邊同時平分成幾份 | 兩邊同除一數（不是 0） | 從 3x = 15 兩邊除以 3，得 x = 5 |

解方程式就是**一直對天平兩邊做一樣的事，直到左盤只剩一個信封**。這時右盤的硬幣數就是 x。

### 移項為什麼要變號

學校常教一句口訣：「移項變號」。把 3x + 1 = 16 的 +1 移到右邊變成 −1，得到 3x = 16 − 1。這句口訣沒有錯，但很多人背了口訣卻不知道為什麼，一碰到乘除或負號就亂掉。

真正發生的事情是這樣的：

```
  3x + 1 = 16
  3x + 1 − 1 = 16 − 1      ← 兩邊同時減 1（天平兩邊各拿走 1 枚）
  3x = 16 − 1              ← 左邊的 +1 和 −1 抵消了
  3x = 15
```

看第三行：左邊的 +1 消失了，右邊出現了 −1。看起來像是「+1 搬到右邊變成 −1」，其實是**兩邊同時減 1，左邊的 1 剛好被消掉，右邊的 −1 留下來了**。所謂「移項變號」，只是把這兩步縮寫成一步而已。

同樣的道理：

- x − 4 = 9：兩邊同加 4，左邊 −4 消掉，右邊變 9 + 4。看起來像「−4 移過去變 +4」。
- 3x = 15：兩邊同除以 3，左邊 3 消掉，右邊變 15 ÷ 3。看起來像「乘 3 移過去變除以 3」。
- x/5 = 4：兩邊同乘 5，左邊除以 5 消掉，右邊變 4 × 5。

所以更準確的說法是：**加的移過去變減、減的變加、乘的變除、除的變乘**，原因都是「兩邊同時做相反的運算，把它消掉」。只要記得天平，口訣忘了也推得出來。

### 解方程式的固定步驟

遇到比較長的方程式，建議照下面的順序，每一步只做一件事，不要在腦中跳步：

1. **去括號**：用分配律把括號拆開。
2. **去分母**：如果有分數，兩邊同乘分母的最小公倍數。
3. **移項**：把含 x 的項全部移到一邊（通常是左邊），常數全部移到另一邊。移過等號要變號。
4. **合併同類項**：左邊合併成「幾 x」，右邊合併成一個數。
5. **係數化為 1**：兩邊同除以 x 的係數。
6. **驗算**：把解代回原式，兩邊算出來要一樣。

來做一題完整的：解 3(x − 2) = 2x + 1。

```
  3(x − 2) = 2x + 1
  3x − 6 = 2x + 1          ← 去括號：3 分給 x 和 −2
  3x − 2x = 1 + 6          ← 移項：2x 移到左邊變 −2x，−6 移到右邊變 +6
  x = 7                    ← 合併同類項
```

驗算：左邊 3(7 − 2) = 3 × 5 = 15；右邊 2 × 7 + 1 = 15。相等 ✓。

再做一題有分數的：解 x/2 + x/3 = 10。

```
  x/2 + x/3 = 10
  6 × (x/2 + x/3) = 6 × 10     ← 去分母：2 和 3 的最小公倍數是 6，兩邊同乘 6
  3x + 2x = 60                 ← 6 × x/2 = 3x，6 × x/3 = 2x，右邊也要乘！
  5x = 60
  x = 12                       ← 兩邊同除以 5
```

驗算：12/2 + 12/3 = 6 + 4 = 10 ✓。

注意去分母時，**右邊的 10 也要乘 6**。天平兩邊要一起變 6 倍，不能只變一邊。這是最常漏掉的地方。

### 兩邊都有 x 怎麼辦

5x − 3 = 2x + 9，兩邊都有 x。用天平想：左盤 5 個信封少 3 枚，右盤 2 個信封加 9 枚。兩邊同時拿走 2 個信封，天平還是平衡：

```
  5x − 3 = 2x + 9
  5x − 2x − 3 = 9           ← 兩邊同減 2x（把 2x 移到左邊變 −2x）
  3x − 3 = 9
  3x = 9 + 3                ← 兩邊同加 3
  3x = 12
  x = 4
```

驗算：5 × 4 − 3 = 17；2 × 4 + 9 = 17 ✓。

把 x 都集中到一邊，建議移到**係數比較大的那一邊**，這樣 x 的係數會是正的，比較不容易出錯。例如 7 − 2x = 3x − 8，把 −2x 移到右邊變成 +2x：7 + 8 = 3x + 2x，15 = 5x，x = 3。驗算：7 − 6 = 1，9 − 8 = 1 ✓。

### 把文字題翻譯成方程式

文字題的難處通常不在「解」，而在「列式」。翻譯有四個步驟：

1. **設未知數**：題目問什麼，就把什麼設成 x（有時設別的東西會更好算，之後再轉換）。
2. **用 x 表示其他的量**：題目裡每一個會跟著 x 變的數，都寫成含 x 的式子。
3. **找出「相等」的那句話**：題目裡一定有一句「⋯⋯等於⋯⋯」、「⋯⋯一共⋯⋯」、「⋯⋯和⋯⋯一樣」，那就是等號在的地方。
4. **列式、解、驗算、回答**：解出來的 x 要帶單位，而且要看看合不合理（人數不能是 3.5，年齡不能是負的）。

**年齡問題**（開場那題）：設 n 年後。那時小宇 8 + n 歲，媽媽 36 + n 歲。「媽媽是小宇的三倍」：36 + n = 3(8 + n)。解：36 + n = 24 + 3n，36 − 24 = 3n − n，12 = 2n，n = 6。驗算：6 年後小宇 14、媽媽 42，42 = 3 × 14 ✓。答：6 年後。

**購物問題**：3 枝筆和 1 本筆記本共 95 元，筆記本比筆貴 15 元，筆一枝多少？設筆 x 元，則筆記本 x + 15 元。「一共 95」：3x + (x + 15) = 95。解：4x + 15 = 95，4x = 80，x = 20。驗算：3 × 20 + 35 = 95 ✓。答：筆 20 元，筆記本 35 元。

**速度問題**：哥哥走路 4 公里／小時，先出門 30 分鐘後，弟弟騎腳踏車 12 公里／小時去追。弟弟要騎多久才追上？設弟弟騎了 t 小時。追上時兩人走的距離一樣：弟弟走 12t 公里，哥哥走了 t + 0.5 小時，共 4(t + 0.5) 公里。「距離一樣」：12t = 4(t + 0.5)。解：12t = 4t + 2，8t = 2，t = 0.25 小時 = 15 分鐘。驗算：弟弟 12 × 0.25 = 3 公里，哥哥 4 × 0.75 = 3 公里 ✓。答：15 分鐘。

速度問題的關鍵是**距離 = 速率 × 時間**，而「追上」、「相遇」這些字眼告訴你哪兩個距離相等（或加起來等於全程）。畫一條線段圖會很有幫助：

```
  出發點 ─────────────────────── 追上的地方
          哥哥：4 × (t + 0.5)
          弟弟：12 × t
          （兩段一樣長）
```

### 沒有解和無限多解

有些方程式很奇怪。解 2x + 3 = 2x + 5：兩邊同減 2x，得到 3 = 5。這是不可能的事，表示**沒有任何 x 能讓等號成立**，這個方程式無解。用天平想：左盤 2 個信封加 3 枚，右盤 2 個信封加 5 枚，不管信封裡幾枚，右邊永遠多 2 枚，天平永遠不會平衡。

再解 x + x = 2x：兩邊同減 2x，得到 0 = 0。這永遠是對的，表示**任何 x 都是解**，稱為恆等式（Identity）。它其實不是在問問題，只是把同一件事寫了兩種寫法。

這兩種情況不常考，但碰到的時候不要慌：x 消失了，看剩下的數字對不對，就知道是無解還是無限多解。

## 動手做

### 活動 5-1：天平解方程

**材料／工具**
- 第 4 章做的衣架天平（衣架、棉線、2 個紙杯），或在紙上畫一個天平
- 1 元硬幣 30 枚以上
- 小信封 4 個、紙筆

**步驟**
1. 出題者在每個信封裡裝**同樣數量**的硬幣（例如每個 4 枚），封好。這個數就是 x，解題者不知道。
2. 出題者擺出 2x + 3 = 11：左盤放 2 個信封和 3 枚硬幣，右盤放 11 枚硬幣。確認平衡。
3. 解題者在紙上寫下 2x + 3 = 11，然後**只能做「兩邊一樣」的動作**：先從兩盤各拿走 3 枚硬幣，寫下 2x = 8；再把兩盤各「平分成兩份」（左邊 2 個信封各一份，右邊 8 枚分成 4、4），寫下 x = 4。
4. 拆信封確認。然後換下面這些題目，每一題都先擺天平、再一步一步寫式子：
   - 3x + 1 = 13
   - 2x + 5 = x + 9（兩邊都有信封，先從兩邊各拿走 1 個信封）
   - 4x = 2x + 6
5. 進階：出題者故意擺一個「x − 2 = 5」。信封裡怎麼可能「少 2 枚」？討論一下：可以把它想成「信封裡本來有 x 枚，但拿掉 2 枚後剩 5 枚」，所以要「兩邊各放回 2 枚」。這就是「−2 移到右邊變 +2」的天平版本。

**你應該看到／得到**
- 每一次拿走硬幣、拿走信封、平分，天平都保持平衡（在紙上畫的時候，你會覺得「兩邊一樣所以一定還是一樣」）。
- 「移項變號」不需要背：拿走左邊的 3 枚，右邊自然也少 3 枚。
- 2x + 5 = x + 9 這題，兩邊各拿走一個信封後變成 x + 5 = 9，再拿走 5 枚，x = 4。

**觀察與記錄**

| 方程式 | 第 1 步（兩邊同時⋯⋯） | 第 2 步 | 解出的 x | 拆信封驗證 |
|---|---|---|---|---|
| 2x + 3 = 11 | 各拿走 3 枚 → 2x = 8 | 各平分成 2 份 → x = 4 | 4 | |
| 3x + 1 = 13 | | | | |
| 2x + 5 = x + 9 | | | | |
| 4x = 2x + 6 | | | | |

### 活動 5-2：紙杯硬幣演方程式

這個活動不用天平，用「倒扣的紙杯」當 x，更快、更適合一個人練習。

**材料／工具**
- 紙杯 5 個（倒扣，每個代表一個 x）
- 1 元硬幣 30 枚（每枚代表 +1）
- 紅色小紙片 10 張（代表 −1，和 +1 一枚碰在一起會「抵消」，一起拿掉）
- 一張 A4 紙，中間畫一條直線當等號

**步驟**
1. 擺出 3x − 2 = 2x + 4：左邊放 3 個倒扣紙杯和 2 張「−1」紙片，右邊放 2 個紙杯和 4 枚硬幣。
2. 兩邊各拿走 2 個紙杯（兩邊同減 2x）。左邊剩 1 個紙杯和 2 張「−1」，右邊剩 4 枚硬幣。
3. 想要消掉左邊的「−1」，就要在**兩邊各加 2 枚硬幣**。左邊的 2 枚硬幣和 2 張「−1」互相抵消拿掉，剩 1 個紙杯；右邊變成 6 枚。所以 x = 6。
4. 驗算：把每個紙杯都「打開」放 6 枚硬幣。原來的左邊 3 × 6 − 2 = 16，右邊 2 × 6 + 4 = 16 ✓。
5. 用同樣方法演這些題目，每一步都在旁邊寫式子：
   - 2x + 1 = 7
   - 5x − 3 = 2x + 9
   - 4 − x = 1（左邊是 4 枚硬幣和 1 個「負的紙杯」，可以用一個貼了紅紙片的紙杯代表 −x。想想看：要怎麼讓它變回正的？提示：兩邊各加一個正紙杯，正負紙杯抵消。）
6. 自己設計一題「兩邊都有紙杯、也都有負號」的方程式，先用紙杯演一遍，再只用式子解一遍，比較兩種方法。

**你應該看到／得到**
- 「+1 和 −1 碰在一起消失」就是加法的抵消；「兩邊各加 2 枚」就是「−2 移到右邊變 +2」。
- 4 − x = 1：兩邊各加一個 x，變成 4 = 1 + x，再兩邊各拿走 1 枚，得 3 = x。這題很多人會算錯成 x = −3，用紙杯演一遍就不會錯了。
- 演過三、四題之後，你會發現不用紙杯、只用式子也可以，因為每一步你都知道「天平那邊發生了什麼」。

**觀察與記錄**

| 方程式 | 擺法（左｜右） | 做了哪些「兩邊一樣」的動作 | x = | 驗算 |
|---|---|---|---|---|
| 3x − 2 = 2x + 4 | 3 杯 2 負｜2 杯 4 正 | 各拿 2 杯；各加 2 正 | 6 | 16 = 16 ✓ |
| 2x + 1 = 7 | | | | |
| 5x − 3 = 2x + 9 | | | | |
| 4 − x = 1 | | | | |

### 活動 5-3：文字題翻譯機

**材料／工具**
- 紙筆
- 一位家人（當出題者或解題者）

**步驟**
1. 從下面三個情境各挑一些數字編成題目，寫在紙上：
   - 年齡：「爸爸 __ 歲，我 __ 歲，幾年後爸爸是我的 __ 倍？」
   - 購物：「買 __ 個 A 和 1 個 B 共 __ 元，B 比 A 貴 __ 元，A 多少錢？」
   - 速度：「兩人相距 __ 公里，一人每小時 __ 公里、另一人每小時 __ 公里，相向而行幾小時後相遇？」
2. 兩人交換題目。拿到題目後，**先不要算**，只做翻譯：寫下「設 x = ⋯⋯」、用 x 表示題目裡其他的量、圈出題目裡表示「相等」的那句話、列出方程式。
3. 把方程式交回給出題者檢查：出題者看式子就要能說出「這個式子的每一項對應題目的哪一句話」。
4. 檢查通過後再解方程式、驗算、回答（記得帶單位，並確認答案合理）。
5. 試著出一題「答案不合理」的題目（例如解出來人數是 2.5 人），討論是題目有問題還是列式有問題。

**你應該看到／得到**
- 列式比解題難。很多時候卡住是因為「相等的那句話」沒找到，不是因為不會移項。
- 同一題可能有不同的設法（例如設筆記本的價錢為 x），列出的方程式不同，但答案相同。

**觀察與記錄**

| 題目（簡述） | 設 x 是什麼 | 其他量用 x 表示 | 「相等」那句話 | 方程式 | 解與驗算 |
|---|---|---|---|---|---|

| | | | | | |

## 用工具看看

這次用 Google 試算表做「猜測與檢驗」的自動版，體會一下「方程式的解，就是讓左右兩邊剛好一樣的那個 x」。最後再用 GeoGebra 直接解一次。

**Google 試算表操作**

1. 打開新的試算表。A1 打「x」，A2 到 A12 填 0、1、2、⋯⋯、10。
2. B1 打「左邊 5x−3」，B2 打 `=5*A2-3`，往下拖到 B12。
3. C1 打「右邊 2x+9」，C2 打 `=2*A2+9`，往下拖到 C12。
4. D1 打「左減右」，D2 打 `=B2-C2`，往下拖。
5. 往下看 D 欄，找到 0 的那一列。

**你會看到**

| x | 左邊 5x−3 | 右邊 2x+9 | 左減右 |
|---|---|---|---|
| 0 | −3 | 9 | −12 |
| 1 | 2 | 11 | −9 |
| 2 | 7 | 13 | −6 |
| 3 | 12 | 15 | −3 |
| 4 | 17 | 17 | 0 |
| 5 | 22 | 19 | 3 |
| 6 | 27 | 21 | 6 |

x = 4 那一列左右相等、差是 0，和我們前面解出來的一樣。你也會注意到「左減右」每一列剛好多 3：因為 x 每多 1，左邊多 5、右邊多 2，差就多 3。左邊從落後一路追到 x = 4 時剛好追平，之後反超。這種「每次變一樣多」的現象，下一章畫成圖會看得更清楚。

**試試看：** 把方程式改成 2x + 3 = 2x + 5（B 欄 `=2*A2+3`，C 欄 `=2*A2+5`），你會發現 D 欄永遠是 −2，永遠找不到 0，這就是「無解」。再把 A 欄改成 0、0.5、1、1.5⋯⋯，試試看解不是整數的方程式，例如 4x + 1 = 7。

**GeoGebra 操作**

1. 打開 GeoGebra（網頁版 geogebra.org/calculator 或手機 App），切換到「CAS」（代數運算）視窗；如果找不到 CAS，用一般的「代數區」輸入列也可以。
2. 在輸入列打 `Solve(3(x-2)=2x+1)` 按 Enter，會顯示 {x = 7}。
3. 再試 `Solve(x/2+x/3=10)`，顯示 {x = 12}。
4. 試 `Solve(2x+3=2x+5)`，會顯示 {} 空集合，表示無解。

GeoGebra 一秒就解完，但它不會告訴你「為什麼」。它適合用來**驗算**你手算的結果，不適合用來代替思考。

## 常見錯誤與迷思

- **錯誤想法：移項變號是一條魔法規則，所以 3x = 7 的 3 移過去就變成 x = 7 − 3。** → 為什麼錯：移項不是魔法，是「兩邊同時做相反運算」的縮寫。3x 的 3 是「乘」，相反運算是「除」。 → 正確理解：加減的項移過去變減加（兩邊同減或同加），乘除的係數移過去變除乘（兩邊同除或同乘）。3x = 7 的解是 x = 7/3。
- **錯誤想法：去分母時只乘有分數的那一邊。** → 為什麼錯：x/2 + x/3 = 10 兩邊同乘 6 變成 3x + 2x = 60，右邊的 10 也要乘 6。只乘一邊等於天平只有一邊加倍，會不平衡。 → 正確理解：兩邊每一項都要乘。
- **錯誤想法：4 − x = 1 的解是 x = −3。** → 為什麼錯：把 4 移到右邊得到 −x = 1 − 4 = −3，這時左邊是 −x 不是 x，還要兩邊同乘 −1 才得到 x = 3。 → 正確理解：解出 −x = −3 之後，再變號得 x = 3。驗算：4 − 3 = 1 ✓。
- **錯誤想法：解出 x 就結束了，不用驗算。** → 為什麼錯：移項錯一個正負號很常見，不驗算就不會發現。 → 正確理解：把 x 代回**原來的**方程式（不是中間某一步），兩邊算出來一樣才算完成。
- **錯誤想法：去括號時，括號前的數只乘第一項，例如 3(x − 2) = 3x − 2。** → 為什麼錯：分配律要求乘括號裡的每一項。 → 正確理解：3(x − 2) = 3x − 6。
- **錯誤想法：文字題一定要設「題目問的那個量」為 x。** → 為什麼錯：設別的量有時更好列式，例如「筆記本比筆貴 15 元」時設筆為 x，筆記本就是 x + 15，比較簡單。 → 正確理解：設哪個量為 x 是自由的，但最後要記得回答題目問的東西。
- **錯誤想法：方程式一定有一個解。** → 為什麼錯：2x + 3 = 2x + 5 化簡後得 3 = 5，沒有任何 x 能讓它成立。 → 正確理解：x 消失時，看剩下的數字等式對不對：不對就無解，對就是任何 x 都可以。

## 想一想

1. 解下面四個方程式，每一題說出你對「天平兩邊」做了什麼：(1) x + 7 = 15；(2) x − 4 = 9；(3) 3x = 21；(4) x/5 = 4。

<details><summary>參考答案</summary>

(1) 兩邊同減 7，x = 8。

(2) 兩邊同加 4，x = 13。

(3) 兩邊同除以 3，x = 7。

(4) 兩邊同乘 5，x = 20。

</details>

2. 解：(1) 2x + 5 = 17；(2) 3x − 8 = 10；(3) 4 − x = 1。每一題都要驗算。

<details><summary>參考答案</summary>

(1) 2x = 17 − 5 = 12，x = 6。驗算：2 × 6 + 5 = 17 ✓。

(2) 3x = 10 + 8 = 18，x = 6。驗算：3 × 6 − 8 = 10 ✓。

(3) 把 x 移到右邊：4 − 1 = x，x = 3。（或者 −x = 1 − 4 = −3，再兩邊乘 −1 得 x = 3。）驗算：4 − 3 = 1 ✓。

</details>

3. 兩邊都有 x：(1) 5x − 3 = 2x + 9；(2) 7 − 2x = 3x − 8。

<details><summary>參考答案</summary>

(1) 5x − 2x = 9 + 3，3x = 12，x = 4。驗算：20 − 3 = 17，8 + 9 = 17 ✓。

(2) 把 −2x 移到右邊、−8 移到左邊：7 + 8 = 3x + 2x，15 = 5x，x = 3。驗算：7 − 6 = 1，9 − 8 = 1 ✓。

</details>

4. 有括號和分數：(1) 3(x − 2) = 2x + 1；(2) x/2 + x/3 = 10；(3) (x + 4)/3 = 5。

<details><summary>參考答案</summary>

(1) 3x − 6 = 2x + 1，3x − 2x = 1 + 6，x = 7。驗算：3 × 5 = 15，14 + 1 = 15 ✓。

(2) 兩邊同乘 6：3x + 2x = 60，5x = 60，x = 12。驗算：6 + 4 = 10 ✓。

(3) 兩邊同乘 3：x + 4 = 15，x = 11。驗算：15 ÷ 3 = 5 ✓。

</details>

5. 小宇今年 8 歲，媽媽 36 歲。(1) 幾年後媽媽的年齡是小宇的 3 倍？(2) 幾年**前**媽媽的年齡是小宇的 5 倍？

<details><summary>參考答案</summary>

(1) 設 n 年後：36 + n = 3(8 + n)，36 + n = 24 + 3n，12 = 2n，n = 6。驗算：42 = 3 × 14 ✓。答：6 年後。

(2) 設 m 年前：36 − m = 5(8 − m)，36 − m = 40 − 5m，5m − m = 40 − 36，4m = 4，m = 1。驗算：1 年前媽媽 35、小宇 7，35 = 5 × 7 ✓。答：1 年前。

</details>

6. 文具店裡 3 枝筆和 1 本筆記本共 95 元，筆記本比筆貴 15 元。(1) 設筆 x 元，列方程式並解出筆和筆記本的價錢。(2) 改設筆記本 y 元重做一次，看看答案是否相同。

<details><summary>參考答案</summary>

(1) 筆記本 x + 15 元。3x + (x + 15) = 95，4x = 80，x = 20。筆 20 元，筆記本 35 元。驗算：60 + 35 = 95 ✓。

(2) 筆就是 y − 15 元。3(y − 15) + y = 95，3y − 45 + y = 95，4y = 140，y = 35。筆記本 35 元，筆 20 元，答案相同。

</details>

7. 哥哥走路每小時 4 公里，出門 30 分鐘後，弟弟騎腳踏車每小時 12 公里去追。(1) 弟弟騎幾分鐘追上哥哥？(2) 追上的地方離家幾公里？(3) 如果弟弟改騎每小時 8 公里，要幾分鐘追上？

<details><summary>參考答案</summary>

(1) 設弟弟騎 t 小時。12t = 4(t + 0.5)，12t = 4t + 2，8t = 2，t = 0.25 小時 = 15 分鐘。

(2) 12 × 0.25 = 3 公里（用哥哥算也一樣：4 × 0.75 = 3 公里 ✓）。

(3) 8t = 4(t + 0.5)，8t = 4t + 2，4t = 2，t = 0.5 小時 = 30 分鐘。速度差變小，追的時間就變長。

</details>

8. （挑戰）(1) 解 2x + 3 = 2x + 5 和 3(x + 1) = 3x + 3，說明各發生了什麼事。(2) 設計一個「看起來很複雜、其實無解」的方程式，再設計一個「任何 x 都是解」的方程式，用天平或紙杯解釋為什麼。

<details><summary>參考答案</summary>

(1) 2x + 3 = 2x + 5：兩邊同減 2x 得 3 = 5，不可能，所以無解。天平上兩邊信封數一樣，但右邊永遠多 2 枚，永遠不會平衡。

3(x + 1) = 3x + 3：去括號得 3x + 3 = 3x + 3，兩邊同減 3x 得 3 = 3，永遠成立，所以任何 x 都是解。兩邊根本是同一堆東西的兩種寫法。

(2) 例子：無解可以用 4(x − 1) + 2 = 2(2x + 3)，拆開是 4x − 2 = 4x + 6，得 −2 = 6，無解。任何 x 都是解可以用 5x − (2x − 4) = 3x + 4，拆開是 3x + 4 = 3x + 4。設計的訣竅：讓兩邊的 x 係數一樣，常數相同就是恆等式，常數不同就是無解。

</details>

## 本章小結

- 方程式是「含未知數的等式」，解方程式就是找出讓等號成立的那個數，找到之後一定要代回去驗算。
- 等式像天平：兩邊同時加、減、乘、除同一個數（乘除不能是 0），等號依然成立。
- 「移項變號」不是魔法，是「兩邊同時做相反運算」的縮寫：加變減、減變加、乘變除、除變乘。
- 解方程式的步驟：去括號 → 去分母 → 移項 → 合併同類項 → 係數化為 1 → 驗算。去分母時兩邊每一項都要乘。
- 兩邊都有 x 時，把 x 移到係數大的那邊，常數移到另一邊，就不容易出錯。
- 文字題先設未知數，用 x 寫出其他的量，找出題目裡「相等」的那句話列出等號，解完要回答題目問的東西並檢查合不合理。
- 速度問題記住「距離 = 速率 × 時間」，追上或相遇就是距離相等（或相加等於全程）。
- x 全部消失時：剩下的等式不對就無解，對就是任何 x 都可以。
