# 附錄 B　GeoGebra 與試算表操作速查

全書「用工具看看」只用三樣免費工具：**GeoGebra**（幾何、函數、3D）、**Google 試算表**（列表、統計、畫圖；Excel 幾乎一樣）、**手機計算機**。這一頁把每個操作拆成可以照著按的步驟，依「第一次打開」→「本書各章會用到的指令」→「出問題怎麼辦」排列。

## B.1　GeoGebra：第一次打開

GeoGebra 有網頁版和手機 App，都免費、不用註冊。

| 想做什麼 | 打開哪一個 |
|---|---|
| 畫點、直線、函數、量角度、畫圓 | geogebra.org/calculator（「繪圖計算機」）或 geogebra.org/geometry |
| 立體：長方體、圓柱、體積 | geogebra.org/3d（「3D 計算機」） |
| 全功能（包含試算表視窗） | geogebra.org/classic |

畫面分三區：
- **代數區**（左邊）：你打的每一個指令和它的結果都列在這裡。
- **繪圖區**（右邊）：圖畫在這裡。滑鼠滾輪縮放、按住拖曳平移、3D 時拖曳旋轉。
- **輸入列**（代數區最上面或最下面那一格）：打指令按 Enter。

幾個習慣：
- 指令英文大小寫不分，但括號和逗號要半形：`Polygon(A,B,C)`。
- 小數點用 `.`，不要用全形。
- 乘號可以省略：`2x` 和 `2*x` 一樣；次方用 `^`：`x^2`。
- 每個物件都有名字（A、B、f、eq1……），後面的指令可以用名字叫它。
- 打錯了：按 Ctrl+Z（Mac 是 ⌘+Z）復原，或在代數區點物件旁的三點刪除。

## B.2　GeoGebra：點、線、函數（第 6、12 章）

| 想做什麼 | 在輸入列打 | 你會看到 |
|---|---|---|
| 畫一個點 | `A=(2,3)` | 繪圖區出現點 A，代數區顯示 A = (2, 3) |
| 畫直線（函數） | `y=2x+1` | 一條往右上的直線，代數區命名 f 或 eq1 |
| 用 f(x) 寫法 | `f(x)=2x+1` | 同上，之後可以打 `f(3)` 得 7 |
| 兩點畫線 | `Line(A,B)` | 通過 A、B 的直線 |
| 兩點線段 | `Segment(A,B)` | A 到 B 的線段 |
| 看斜率 | `Slope(f)` | 畫面上出現一個小三角形，標示斜率 2 |
| 兩條線的交點 | `Intersect(f,g)` | 交點 C；例如 y = 2x + 1 與 y = −x + 7 交於 (2, 5) |
| 用方程式畫線 | `x+y=15` 與 `4x+2y=44` | 兩條線，`Intersect(eq1,eq2)` 得 (7, 8)（第 12 章停車場題） |
| 做一個滑桿 | `a=1`，然後點代數區 a 旁邊的小圓點 | 出現滑桿；再打 `y=a x+1`，拉滑桿看直線跟著轉 |
| 函數值表 | 打 `f(x)=2x+1` 後，代數區點 f 的三點 → 「數值表」 | 一張 x 與 f(x) 的表；x 從 −3 到 3 會看到 −5、−3、−1、1、3、5、7 |
| 畫拋物線（參考） | `y=x^2` | 一條 U 形曲線 |

**步驟範例：看斜率是什麼意思**
1. 打 `a=1`，點代數區 a 左邊的圓圈，出現滑桿。
2. 打 `b=0`，同樣做出滑桿。
3. 打 `y=a*x+b`。
4. 拉 a 的滑桿從 −3 到 3：直線從右下變成右上，a = 0 時水平。
5. 拉 b 的滑桿：直線上下平移，和 y 軸的交點就是 b。

## B.3　GeoGebra：幾何、角度、面積（第 7、8、9 章）

| 想做什麼 | 在輸入列打或用哪個工具 | 你會看到 |
|---|---|---|
| 畫多邊形 | `Polygon((0,0),(6,0),(2,4))` | 一個三角形，代數區顯示面積 12 |
| 量角度 | `Angle(A,B,C)`（B 是頂點） | 角的弧線與度數 |
| 三角形三個內角 | `Angle(poly1)` | 三個角一起出現，加起來 180° |
| 量長度 | `Distance(A,B)` 或 `Segment(A,B)` | 數值 |
| 畫圓 | `Circle(A,3)`（圓心 A、半徑 3） | 圓；`Circumference(c)` 得周長 18.85，`Area(c)` 得 28.27 |
| 畫平行線 | `Line(C,f)`（通過 C、平行 f） | 和 f 平行的線 |
| 畫垂線 | `PerpendicularLine(C,f)` | 和 f 垂直的線 |
| 中點 | `Midpoint(A,B)` | 一個點 |
| 驗證畢氏定理 | `A=(0,0)`、`B=(3,0)`、`C=(0,4)`，`Polygon(A,B,C)`，`Distance(B,C)` | 斜邊 5 |
| 用工具列點選 | 工具列「點」「線段」「多邊形」「角度」圖示 | 用滑鼠點而不用打字 |

**步驟範例：撕角拼直線的數位版**
1. 打 `Polygon((0,0),(6,0),(2,4))`，出現三角形 t1。
2. 打 `Angle(t1)`，三個角 α、β、γ 出現，代數區顯示各是多少度。
3. 打 `α+β+γ`（從代數區複製希臘字母，或直接點它們），結果 180°。
4. 用滑鼠拖動任何一個頂點，三個角會變，但總和一直是 180°。

## B.5　Google 試算表：第一次打開

1. 到 sheets.google.com（需要 Google 帳號；沒有的話 Excel 或 LibreOffice Calc 也行，公式幾乎一樣）。
2. 點「空白」新增一張表。
3. 每一格叫**儲存格**，用「欄字母 + 列數字」命名：A1 是左上角，B3 是第 B 欄第 3 列。
4. 公式一定以 `=` 開頭，打完按 Enter。沒有 `=` 的話它只是文字。
5. **往下拉**：點一格，把右下角的小方塊往下拖，公式會自動複製，而且列號會跟著變（A2 → A3 → A4）。
6. **絕對參照**：寫成 `$B$7` 的格子，往下拉時不會變。算「占比」時分母要用它。
7. 範圍寫成 `A2:A11`，意思是 A2 到 A11 這一整段。
8. 文字條件要加引號：`"有"`、`">=10"`。
9. 顯示百分比：選取儲存格 → 工具列的「%」按鈕；顯示小數位數：工具列的「.00」「.0」按鈕。

## B.6　試算表：本書會用到的函式

下面用這組數字示範（打在 A2 到 A6）：72、85、91、68、85。

| 函式 | 意思 | 範例 | 結果 | 章 |
|---|---|---|---|---|
| `SUM` | 加總 | `=SUM(A2:A6)` | 401 | 3、13 |
| `AVERAGE` | 平均數 | `=AVERAGE(A2:A6)` | 80.2 | 10 |
| `MEDIAN` | 中位數 | `=MEDIAN(A2:A6)` | 85 | 10 |
| `MODE` | 眾數 | `=MODE(A2:A6)` | 85 | 10 |
| `MAX`、`MIN` | 最大、最小 | `=MAX(A2:A6)-MIN(A2:A6)` | 91 − 68 = 23（全距） | 10 |
| `COUNT` | 數有幾個數字 | `=COUNT(A2:A6)` | 5 | 10 |
| `COUNTIF` | 符合條件的有幾個 | `=COUNTIF(A2:A6,">=80")` | 3 | 10、13 |
| `ROUND` | 四捨五入到幾位 | `=ROUND(80.2,0)`；`=ROUND(3.14159,2)` | 80；3.14 | 全書 |
| `ABS` | 絕對值 | `=ABS(-7)` | 7 | 1 |
| `SQRT` | 平方根 | `=SQRT(2)` | 1.4142… | 9 |
| `POWER` 或 `^` | 次方 | `=POWER(2,10)` 或 `=2^10` | 1024 | 9、11 |
| `PI()` | 圓周率 | `=PI()*5^2` | 78.54（半徑 5 的圓面積） | 8 |
| `MOD` | 餘數 | `=MOD(17,5)` | 2 | 11 |
| `GCD`、`LCM` | 最大公因數、最小公倍數 | `=GCD(12,18)`；`=LCM(4,6)` | 6；12 | 2 |
| `RANDBETWEEN` | 隨機整數 | `=RANDBETWEEN(1,6)` | 1 到 6 隨機一個（模擬骰子） | 10、13 |
| `IF` | 條件 | `=IF(C2=44,"就是這列","")` | C2 是 44 才顯示文字 | 12 |
| `AND` | 多個條件都成立 | `=IF(AND(C2>=5,C2<=7),1,0)` | 和在 5–7 之間給 1 | 13 |
| `SEQUENCE` | 一次產生一串數 | `=SEQUENCE(16,1,0,1)` | 0、1、2、…、15 直排 | 12 |

**分數**：試算表會把 `1/2` 算成 0.5。要顯示分數：格式 → 數值 → 自訂，或先算小數再對照附錄 A.13。

## B.7　試算表：列表法解題（第 12 章）

1. A1「汽車數」、B1「機車數」、C1「輪子數」。
2. A2 打 `0`，A3 打 `=A2+1`，往下拉到 A17。
3. B2 打 `=15-A2`，往下拉。
4. C2 打 `=4*A2+2*B2`，往下拉。
5. D2 打 `=IF(C2=44,"✓","")`，往下拉；✓ 出現在汽車 7、機車 8 那一列。
6. 要換題目：改 B2 的 15 和 D2 的 44，重新拉一次。

## B.8　試算表：函數表與畫直線（第 6 章）

1. A1「x」、B1「y」。
2. A2 打 `-3`，A3 打 `=A2+1`，往下拉到 A8（−3 到 3）。
3. B2 打 `=2*A2+1`，往下拉；會看到 −5、−3、−1、1、3、5、7。
4. 選取 A1:B8 → 插入 → 圖表 → 圖表類型選「散佈圖」→ 自訂 → 數列 → 勾「趨勢線」，就是直線 y = 2x + 1。
5. 比較兩個手機方案：C1「方案 B」，C2 打 `=3*A2+15`，往下拉，再把 A1:C8 畫在同一張散佈圖，兩條線交叉的地方就是「哪個方案開始比較划算」的分界點。

## B.9　試算表：預算表與占比（第 3、13 章）

1. A1「項目」、B1「金額」、C1「占比」。
2. A2 到 A6 打項目名稱，B2 到 B6 打金額（範例：4200、4500、3600、1800、900）。
3. B7 打 `=SUM(B2:B6)`，得 15000。
4. C2 打 `=B2/$B$7`，往下拉到 C6；選取 C2:C6 按「%」，看到 28%、30%、24%、12%、6%。
5. C7 打 `=SUM(C2:C6)`，應該是 100%；不是的話有地方漏了。
6. 選取 A1:B6 → 插入 → 圖表 → 圓餅圖或長條圖。

## B.10　試算表：擲骰子模擬與相對次數（第 10、13 章）

1. A1「紅」、B1「藍」、C1「和」。
2. A2、B2 都打 `=RANDBETWEEN(1,6)`；C2 打 `=A2+B2`。
3. 選取 A2:C2，往下拉到第 601 列（600 回合）。
4. E1 打「和」、E2 到 E12 打 2 到 12；F1 打「次數」，F2 打 `=COUNTIF($C$2:$C$601,E2)`，往下拉到 F12。
5. G1 打「相對次數」，G2 打 `=F2/600`，往下拉；H2 打理論值 `=1/36`、H3 `=2/36`……H7 `=6/36`……H12 `=1/36`。
6. 比 G 欄和 H 欄：和為 7 的相對次數應該在 0.15 到 0.19 之間（理論 0.167）。
7. 隨便在空白格打一個字再刪掉，整張表會重擲一次，看 G 欄怎麼跳。
8. **累計相對次數**（看它越來越接近理論值）：D2 打 `=IF(C2=7,1,0)`，往下拉；I2 打 `=SUM($D$2:D2)/ROW(A1)`，往下拉（注意 `$D$2:D2` 只有前面加 $，往下拉會變成 `$D$2:D3`、`$D$2:D4`……）；選取 I2:I601 插入折線圖，線會從亂跳慢慢穩定在 0.167 附近。

## B.11　試算表：畫圖的通用步驟

1. 選取要畫的資料（包含第一列的標題）。
2. 插入 → 圖表。
3. 右邊「圖表編輯器」→「設定」→ 圖表類型：
   - 比較幾類的大小 → **長條圖**（直條圖）。
   - 看趨勢、看累計 → **折線圖**。
   - 看兩個量的關係、畫函數 → **散佈圖**。
   - 看占比 → **圓餅圖**。
4. 「自訂」→「圖表和軸標題」打標題與軸名稱（含單位）。
5. 點圖表右上角三點 → 下載 → PNG，可以放進報告。

## B.12　手機計算機

- iPhone：打開「計算機」，把手機**橫放**會出現科學計算機（√、x²、括號、π）。
- Android：打開「計算機」，向左滑或點「進階」展開科學功能。
- 括號很重要：算 (3 + 7) × 4 ÷ 2 要打 `( 3 + 7 ) × 4 ÷ 2`，不打括號會變成 3 + 28 ÷ 2 = 17。
- 負數：先打數字再按 `+/−`，或打 `( − 5 )`。
- 開根號：先打數字再按 √（有的計算機要先按 √ 再打數字，試一下 √16 看會不會得 4）。
- 分數：打 `3 ÷ 4` 得 0.75；要回到分數看附錄 A.13 的對照。
- 百分比鍵 `%` 各家行為不同，建議不要用，直接乘 0.8 或除以 100。

## B.13　出問題怎麼辦

| 狀況 | 原因與解法 |
|---|---|
| GeoGebra 打指令沒反應或出現紅字 | 括號、逗號用了全形；或指令拼錯。改成半形，檢查大小寫無所謂但字母要對。 |
| GeoGebra 的點看不到 | 跑到畫面外了。按右鍵 → 「顯示所有物件」或滾輪縮小。 |
| 3D 裡看不出立體 | 按住繪圖區拖曳旋轉；或右鍵選「標準視圖」。 |
| 試算表顯示 `#DIV/0!` | 除以 0 或除以空白格。檢查分母那一格。 |
| 試算表顯示 `#NAME?` | 函式名稱拼錯，或文字條件忘了加引號。 |
| 試算表顯示 `#REF!` | 公式參照的格子被刪了。復原（Ctrl+Z）再看。 |
| 往下拉後數字都一樣 | 本來就是一樣（例如常數），或參照寫了 `$`。看公式裡要不要 `$`。 |
| 百分比顯示 0% 或 2800% | 格式錯：原本是小數 0.28 卻又乘了 100，或反過來。只做一件事：要嘛乘 100、要嘛按「%」按鈕。 |
| RANDBETWEEN 一直變 | 這是正常的，每次表有變動就重擲。要固定結果：複製 → 選擇性貼上 → 僅貼上值。 |
| 計算機算出奇怪的數 | 通常是括號或運算順序。把式子一段一段分開算，每段寫下來。 |
