# 第 6 章　坐標與直線

## 本章目標
- 學完你會在坐標平面上用一對數字 (x, y) 標出一個點，也會看圖讀出一個點的坐標，知道正負號代表哪個方向。
- 學完你會把 y = ax + b 這種式子列成表、畫成點、連成一條直線，並解釋為什麼它一定是直線。
- 學完你會說出斜率是什麼（每往右走 1 格，往上走幾格），會從兩個點算出斜率，也會從圖上看出斜率是正、負還是 0。
- 學完你會解釋截距在圖上和在生活裡各代表什麼（例如月租費、起跳價）。
- 學完你會用兩條直線的交點來解方程式，並且用圖比較兩個方案哪個划算。

## 開場：哪個手機方案比較划算？

小宇要辦第一個手機門號，門市有兩個方案：

- 方案甲：月租 200 元，通話每分鐘 3 元。
- 方案乙：月租 500 元，通話每分鐘 1 元。

店員說：「講得少選甲，講得多選乙。」小宇問：「多少算多？」店員想了一下，說不出來。

其實這個問題可以算。方案甲一個月講 x 分鐘要付 3x + 200 元，方案乙要付 x + 500 元。你可以列一張表，x 從 0 分鐘、50 分鐘、100 分鐘一路算下去，看哪一欄比較小。但更快的方法是**把兩個方案畫成兩條線**，一眼就看出哪一條在下面（比較便宜），以及兩條線在哪裡交叉（從這裡開始換另一個方案划算）。

要把「式子」變成「線」，需要一張特別的紙：坐標平面。這一章我們先學會在這張紙上標點、畫線，再回來解決小宇的手機方案。

## 核心概念

### 坐標平面：用兩個數字說位置

要告訴朋友教室裡某個座位在哪裡，你會說「第 3 排第 2 個」，兩個數字就夠了。坐標平面（Coordinate Plane）就是把這個想法用到整張紙上：畫一條橫的數線叫 x 軸（x-axis），一條直的數線叫 y 軸（y-axis），兩條線交叉的地方叫原點（Origin），記作 O，坐標是 (0, 0)。

平面上任何一個點，都可以用「往右幾格、往上幾格」兩個數字來說，寫成 (x, y)，叫做這個點的坐標（Coordinates）。**x 寫在前面，y 寫在後面，順序不能換。** 往左、往下就用負數。

```
                    y
                    ^
                 4  |
                 3  |       * A(2, 3)
     B(-3, 1)    2  |
        *        1  |
     ---+---+---+---+---+---+---+--> x
       -3  -2  -1   O   1   2   3
                -1  |
                -2  * C(0, -2) 在 y 軸上
                -3  |
```

- A(2, 3)：從原點往右 2 格、往上 3 格。
- B(−3, 1)：往左 3 格、往上 1 格。
- C(0, −2)：往右 0 格（不動）、往下 2 格，所以它剛好在 y 軸上。

兩條軸把平面切成四塊，叫做象限（Quadrant），從右上角逆時針數第一、第二、第三、第四象限。右上角的第一象限 x、y 都是正的，生活中的問題（分鐘數、錢）大多落在這裡。

(2, 3) 和 (3, 2) 是不同的兩個點，一個往右 2 往上 3，一個往右 3 往上 2。寫錯順序就會標錯位置，所以永遠記得：**先橫再直，先 x 再 y**。

### 從式子到表、從表到點、從點到線

拿一個簡單的式子 y = 2x + 1。它的意思是：給我一個 x，我就算一個 y 給你。我們把幾個 x 代進去，列成表：

| x | 2x + 1 | y | 點 |
|---|---|---|---|
| −2 | 2 × (−2) + 1 | −3 | (−2, −3) |
| −1 | 2 × (−1) + 1 | −1 | (−1, −1) |
| 0 | 2 × 0 + 1 | 1 | (0, 1) |
| 1 | 2 × 1 + 1 | 3 | (1, 3) |
| 2 | 2 × 2 + 1 | 5 | (2, 5) |

把這五個點標到坐標平面上：

```
                    y
                    ^
                 5  |       * (2, 5)
                 4  |     /
                 3  |   * (1, 3)
                 2  | /
                 1  * (0, 1)
     ---+---+---+-/-+---+---+---+--> x
       -3  -2  -1   O   1   2   3
      (-1, -1)  *   |
              / -2  |
  (-2, -3)  *   -3  |
```

你會發現這五個點**排成一直線**。這不是巧合：x 每多 1，y 就多 2，每一步「往右 1、往上 2」都一樣，所以點永遠沿著同一個方向走，連起來當然是直線。這種 y = ax + b 的關係叫做一次函數（Linear Function），「一次」是因為 x 只有一次方，「函數」（Function）是「給一個 x 就得到一個 y」的機器。

而且，如果你把 x = 0.5 代進去得到 y = 2，點 (0.5, 2) 也會剛好落在這條線上。所以這條線其實是由**無限多個點**組成的，我們畫的五個點只是用來定位。實際畫圖時，兩個點就能決定一條直線，但建議算三個點，第三個點用來檢查前兩個有沒有算錯。

### 斜率：每往右走 1 格，往上走幾格

兩條直線最明顯的差別是「陡不陡」。數學用斜率（Slope）來量它：

> 斜率 = 縱的變化 ÷ 橫的變化 = 往上走了幾格 ÷ 往右走了幾格

對 y = 2x + 1 來說，從 (0, 1) 到 (1, 3)，往右 1、往上 2，斜率 = 2 ÷ 1 = 2。從 (−2, −3) 到 (2, 5)，往右 4、往上 8，斜率 = 8 ÷ 4 = 2。不管你選哪兩個點，算出來都是 2，**因為直線上每一段的陡度都一樣**。這就是為什麼斜率是「一條線」的性質，而不是「某一段」的性質。

畫成樓梯會很清楚：

```
                  .
                 /|
                / | 上 2
               /  |
              .---+
             /|  右 1
            / | 上 2
           /  |
          .---+
           右 1
```

y = ax + b 裡的 a 就是斜率。它藏在式子裡的理由是：x 每多 1，ax 就多 a，所以 y 就多 a。每往右一步就往上 a 格，陡度就是 a。

斜率可以是各種數：

| 斜率 | 圖的樣子 | 例子 |
|---|---|---|
| 正數（例如 2） | 往右上爬，數字越大越陡 | y = 2x + 1：講越多分鐘，錢越多 |
| 0 | 水平線，往右走不上不下 | y = 500：不管講幾分鐘都付 500 |
| 負數（例如 −3） | 往右下降 | y = 1000 − 3x：零用錢每天花 3 元，越來越少 |
| 分數（例如 ½） | 很緩的坡，往右 2 格才上 1 格 | y = ½x |

從兩個點算斜率，用公式：

> 斜率 = (y₂ − y₁) ÷ (x₂ − x₁)

例：通過 (1, 2) 和 (4, 8) 的直線，斜率 = (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2。通過 (0, 5) 和 (2, 1) 的直線，斜率 = (1 − 5) ÷ (2 − 0) = −4 ÷ 2 = −2，是往右下走的線。

注意兩個點的順序要一致：分子用「第二點減第一點」，分母也要「第二點減第一點」。倒過來也可以（兩個都倒），但不能一個倒一個不倒。

### 截距：x = 0 的時候 y 是多少

y = ax + b 裡的 b 叫做 y 截距（y-intercept），它是直線和 y 軸交叉的地方。為什麼？因為 y 軸上的點 x 都是 0，代入 x = 0 得 y = b，所以直線在 (0, b) 穿過 y 軸。

截距在生活裡通常是「還沒開始就要付的錢」或「一開始的狀態」：

- 手機方案 y = 3x + 200：截距 200 是月租，一分鐘都不講也要付。
- 計程車 y = 20x + 70：截距 70 是起跳價。
- 水池放水 y = 2000 − 50x：截距 2000 是一開始的水量。

所以看到一條直線的式子，你可以立刻說出兩件事：**b 告訴你從哪裡開始，a 告訴你每一步變多少。** 畫圖時先在 y 軸上點出 (0, b)，再用斜率「往右 1、往上 a」走幾步，連起來就是了。

### 從圖找式子

反過來，如果有人給你一條線，你怎麼寫出它的式子？

1. 看它穿過 y 軸的地方，那是 b。
2. 在線上找兩個格點（坐標是整數的點），算斜率 a。
3. 寫成 y = ax + b。

例：一條直線通過 (0, 4) 和 (2, 10)。它穿過 y 軸的點是 (0, 4)，所以 b = 4。斜率 = (10 − 4) ÷ (2 − 0) = 3。式子是 y = 3x + 4。檢查：x = 2 時 y = 6 + 4 = 10 ✓。

如果給的兩個點都不在 y 軸上，先算斜率，再把其中一個點代進 y = ax + b 求 b。例：通過 (1, 5) 和 (3, 11)，斜率 = 6 ÷ 2 = 3，把 (1, 5) 代入 y = 3x + b 得 5 = 3 + b，b = 2，所以 y = 3x + 2。檢查 (3, 11)：9 + 2 = 11 ✓。

### 用圖解方程式：兩條線交叉的地方

上一章我們用天平解 2x + 1 = −x + 7，得到 x = 2。現在換一個角度：把等號左邊看成一條線 y = 2x + 1，右邊看成另一條線 y = −x + 7。兩邊相等的意思是「同一個 x 給出同一個 y」，也就是兩條線**交叉的那一點**。

```
                y
                ^
  (0, 7)     7  *           * y = 2x + 1
             6  |   \     /
             5  |       X ← 交點 (2, 5)
             4  |     /     \
             3  |   *           * y = -x + 7
             2  | /
  (0, 1)     1  *
     ---+---+---+---+---+---+---+--> x
       -2  -1   O   1   2   3   4
```

交點是 (2, 5)：x = 2 就是方程式的解，y = 5 是這時候兩邊的值（2 × 2 + 1 = 5，−2 + 7 = 5 ✓）。

這個想法對開場的手機方案特別有用。方案甲 y = 3x + 200，方案乙 y = x + 500。交點就是「兩個方案一樣貴」的分鐘數：3x + 200 = x + 500，2x = 300，x = 150。這時兩邊都是 650 元。圖上交點左邊（講不到 150 分鐘）甲那條線在下面，比較便宜；交點右邊乙在下面。店員說不出來的「多少算多」，答案是 150 分鐘。

## 動手做

### 活動 6-1：方格紙寶藏地圖

**材料／工具**
- 方格紙 2 張（文具店買得到，或用 Google 試算表把欄寬調成正方形後列印）
- 鉛筆、尺、兩種顏色的筆
- 一位家人或同學

**步驟**
1. 每人拿一張方格紙，在中間畫一個十字當 x 軸和 y 軸，交點標 O，往右、往上標 1 到 8，往左、往下標 −1 到 −8。
2. 每人在自己的紙上偷偷畫 3 個「寶藏」，每個寶藏是**相鄰的 3 個格點連成的直線**（橫的、直的或斜的都可以）。例如 (2, 3)、(3, 3)、(4, 3)，或 (−1, −1)、(0, 0)、(1, 1)。
3. 輪流「挖」：說一個坐標，例如「(3, 3)」。對方要誠實回答「挖到了」或「沒東西」。挖到的用一種顏色標在自己的紀錄紙上，沒挖到的用另一種顏色。
4. 先挖出對方全部 3 個寶藏的人獲勝。
5. 遊戲結束後，把對方的 3 個寶藏坐標抄下來，看看每個寶藏的三個點：x 每多 1，y 多多少？這條寶藏線的斜率是多少？

**你應該看到／得到**
- 剛開始一定有人會把 (3, 1) 挖到 (1, 3) 去。玩幾輪之後，「先橫再直」就會變成反射動作。
- 橫的寶藏（例如 (2, 3)、(3, 3)、(4, 3)）斜率是 0；斜的寶藏（例如 (0, 0)、(1, 1)、(2, 2)）斜率是 1；直的寶藏（例如 (5, 1)、(5, 2)、(5, 3)）x 沒有變，斜率算不出來（分母是 0），這種線不是「函數」，因為同一個 x 對應好幾個 y。

**觀察與記錄**

| 寶藏 | 三個點的坐標 | 方向（橫／直／斜） | x 每多 1，y 多多少 | 斜率 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

### 活動 6-2：在方格紙上畫直線、蓋樓梯

**材料／工具**
- 方格紙、尺、鉛筆、三種顏色的筆

**步驟**
1. 畫好坐標軸，x 從 −4 到 4，y 從 −6 到 10。
2. 對 y = 2x + 1，先列表：x = −2、−1、0、1、2，算出對應的 y，把五個點標上去。用尺把它們連成一條線（會發現真的在同一條直線上）。
3. 在這條線上任選兩個格點，用另一種顏色畫「樓梯」：從左邊的點先往右走到正下方，再往上走到右邊的點。數一數往右幾格、往上幾格，相除就是斜率。再換兩個離更遠的點畫一次，確認斜率一樣。
4. 用第三種顏色，在同一張圖上畫 y = 2x + 4 和 y = 2x − 2。比較三條線：一樣陡嗎？差在哪裡？
5. 再畫 y = −x + 3 和 y = ½x + 1。觀察斜率是負數、是分數的線長什麼樣子。
6. 最後畫 y = 3（水平線）。想一想：它的斜率是多少？為什麼？

**你應該看到／得到**
- 三條斜率都是 2 的線互相平行，只是穿過 y 軸的高度不同（1、4、−2），這就是截距的作用。
- y = −x + 3 往右下走；y = ½x + 1 很緩，往右 2 格才上 1 格。
- 水平線 y = 3 斜率是 0，因為往右走再多格 y 都不變，「上升 0 格」。
- 不管在哪一段蓋樓梯，同一條線的「上升 ÷ 前進」永遠一樣。

**觀察與記錄**

| 直線 | 用了哪兩個點蓋樓梯 | 往右幾格 | 往上幾格（負數表示往下） | 斜率 | 穿過 y 軸的點 |
|---|---|---|---|---|---|
| y = 2x + 1 | | | | | |
| y = 2x + 4 | | | | | |
| y = 2x − 2 | | | | | |
| y = −x + 3 | | | | | |
| y = ½x + 1 | | | | | |
| y = 3 | | | | | |

### 活動 6-3：量一量真實的斜坡

**材料／工具**
- 一塊硬的板子（切菜板、大本的硬皮書）
- 幾本書疊成「墊高用」
- 尺或捲尺、紙筆

**步驟**
1. 把板子一端放在桌上，另一端架在一本書上，做成一個斜坡。
2. 量兩個數：斜坡高的那一端離桌面多高（上升），以及板子在桌面上投影的水平長度（前進）。前進可以這樣量：從板子高端往下對準桌面的點，到板子低端的距離。
3. 算斜率 = 上升 ÷ 前進。
4. 加一本書墊高再量一次，加兩本書再量一次。把三次結果記下來。
5. 試著找家裡或學校附近的斜坡（無障礙坡道、樓梯），用同樣方法估計斜率。無障礙坡道的法規建議斜率不超過 1/12，也就是前進 12 公分才上升 1 公分。看看你找到的坡道合不合格。

**你應該看到／得到**
- 墊得越高，斜率越大，板子越陡。
- 斜率是一個「比值」，沒有單位：用公分量和用公釐量，算出來的斜率一樣。
- 樓梯的斜率通常在 0.6 到 0.8 之間（例如踏階高 17 公分、深 26 公分，斜率約 0.65）；無障礙坡道的斜率很小，大約 0.08。

**觀察與記錄**

| 斜坡 | 上升（公分） | 前進（公分） | 斜率 = 上升 ÷ 前進 |
|---|---|---|---|
| 墊 1 本書 | | | |
| 墊 2 本書 | | | |
| 墊 3 本書 | | | |
| 家裡或學校的坡道 | | | |

## 用工具看看

用 Google 試算表把開場的手機方案畫出來，再用 GeoGebra 直接畫直線、找交點。

**Google 試算表：畫兩條費用直線**

1. 打開新試算表。A1 打「分鐘」，A2 打 0，A3 打 25，選取 A2 和 A3 後往下拖到 A14（會自動填 0、25、50、⋯⋯、300）。
2. B1 打「方案甲 3x+200」，B2 打 `=3*A2+200`，往下拖到 B14。
3. C1 打「方案乙 x+500」，C2 打 `=A2+500`，往下拖到 C14。
4. 選取 A1 到 C14，點選單「插入」→「圖表」。在右側圖表編輯器的「圖表類型」選「折線圖」。如果 x 軸沒有顯示分鐘數，在「設定」裡確認「X 軸」是「分鐘」欄。
5. 看圖：兩條線在哪裡交叉？交叉前哪一條在下面？

**你會看到**

| 分鐘 | 方案甲 3x+200 | 方案乙 x+500 |
|---|---|---|
| 0 | 200 | 500 |
| 50 | 350 | 550 |
| 100 | 500 | 600 |
| 150 | 650 | 650 |
| 200 | 800 | 700 |
| 250 | 950 | 750 |
| 300 | 1100 | 800 |

圖上方案甲從 200 出發（截距），每 25 分鐘漲 75 元，很陡；方案乙從 500 出發，每 25 分鐘漲 25 元，比較平緩。兩條線在 150 分鐘、650 元交叉。150 分鐘前甲在下面（便宜），之後乙在下面。

**試試看：** 把方案乙的月租改成 400（C2 改成 `=A2+400`），交點會往左移到 100 分鐘。把方案甲每分鐘改成 2 元，交點會變成哪裡？先用方程式算（2x + 200 = x + 500，x = 300），再看圖驗證。

**GeoGebra：畫線、找交點**

1. 打開 geogebra.org/calculator（繪圖計算機）。
2. 在左邊輸入列打 `y = 3x + 200` 按 Enter，再打 `y = x + 500` 按 Enter。畫面上會出現兩條直線，但可能看不到交點，因為範圍太小。
3. 用滑鼠滾輪或兩指縮放，把畫面縮小到 x 看得到 0 到 300、y 看得到 0 到 1200。也可以按右下角的設定（齒輪）調整 x 軸、y 軸範圍。
4. 在輸入列打 `Intersect(f, g)`（f、g 是 GeoGebra 自動給兩條線取的名字，看左邊代數區確認），會出現交點 A = (150, 650)。
5. 再試 `y = 2x + 1` 和 `y = -x + 7`，交點應該是 (2, 5)。
6. 玩一玩：輸入 `y = a x + b`，GeoGebra 會問你要不要建立滑桿（slider）。按「建立滑桿」後拖動 a 和 b，親眼看斜率和截距怎麼改變直線。

## 常見錯誤與迷思

- **錯誤想法：(3, 1) 和 (1, 3) 是同一個點。** → 為什麼錯：坐標有順序，第一個數是往右（x），第二個是往上（y）。 → 正確理解：(3, 1) 是往右 3 往上 1，(1, 3) 是往右 1 往上 3，是兩個不同的點。
- **錯誤想法：斜率就是「線有多長」或「線到多高」。** → 為什麼錯：斜率是陡度，是「上升」和「前進」的比值，和線的長短、位置無關。y = 2x + 1 和 y = 2x + 100 斜率一樣，只是高度不同。 → 正確理解：斜率 = 往上走幾格 ÷ 往右走幾格。
- **錯誤想法：斜率從不同兩點算會不一樣。** → 為什麼錯：直線上每一段的陡度都相同，所以任選兩點算出來都一樣；若算出不一樣，是其中一個點算錯了或不在線上。 → 正確理解：這正是「直線」的意思，也是可以用兩點決定一條直線的原因。
- **錯誤想法：算斜率時分子用 y₂ − y₁，分母用 x₁ − x₂。** → 為什麼錯：一個順著減、一個倒著減，正負號會反掉，正斜率會變負斜率。 → 正確理解：分子分母都用「第二點減第一點」（或都用第一點減第二點）。
- **錯誤想法：y = ax + b 的 b 是線和 x 軸交叉的地方。** → 為什麼錯：b 是 x = 0 時的 y 值，x = 0 的點都在 y 軸上。 → 正確理解：b 是 y 截距，直線在 (0, b) 穿過 y 軸。和 x 軸交叉的點要解 ax + b = 0。
- **錯誤想法：水平線 y = 3 沒有斜率。** → 為什麼錯：水平線往右走 y 不變，上升是 0，斜率 = 0 ÷ 前進 = 0，是有斜率的，只是等於 0。 → 正確理解：斜率 0 是水平線；真正「沒有斜率」的是鉛直線（例如 x = 2），因為前進是 0，不能當分母。
- **錯誤想法：畫直線只要標兩個點就夠了，不用檢查。** → 為什麼錯：兩點確實決定一條直線，但其中一點算錯你不會發現。 → 正確理解：算三個點，第三個點落在前兩點的連線上才放心。

## 想一想

1. 看下圖，寫出 A、B、C、D 四個點的坐標，並說出各在第幾象限（或在哪條軸上）。

```
                    y
                    ^
                 3  |       * A
                 2  |
      B *        1  |
     ---+---+---+---+---+---+---+---+--> x
       -3  -2  -1   O   1   2   3   4
                -1  |               * D
                -2  * C
```

<details><summary>參考答案</summary>

A(2, 3)，第一象限；B(−3, 1)，第二象限；C(0, −2)，在 y 軸上（不屬於任何象限）；D(4, −1)，第四象限。

</details>

2. 對 y = 2x − 1：(1) 列出 x = −1、0、1、2、3 的 y 值；(2) 點 (10, 19) 在這條線上嗎？(3) 點 (5, 10) 呢？

<details><summary>參考答案</summary>

(1) y 依序是 −3、−1、1、3、5（例如 x = 3 時 2 × 3 − 1 = 5）。

(2) 代 x = 10：2 × 10 − 1 = 19，和 y = 19 相同，所以 (10, 19) 在線上。

(3) 代 x = 5：2 × 5 − 1 = 9，但給的 y 是 10，不相等，所以 (5, 10) 不在線上。

</details>

3. 算斜率：(1) 通過 (1, 2) 和 (4, 8) 的直線；(2) 通過 (0, 5) 和 (2, 1) 的直線；(3) 通過 (−2, 4) 和 (3, 4) 的直線。

<details><summary>參考答案</summary>

(1) (8 − 2) ÷ (4 − 1) = 6 ÷ 3 = 2。

(2) (1 − 5) ÷ (2 − 0) = −4 ÷ 2 = −2，往右下走。

(3) (4 − 4) ÷ (3 − (−2)) = 0 ÷ 5 = 0，是水平線 y = 4。

</details>

4. 寫出直線的式子：(1) 斜率 3、y 截距 −2；(2) 通過 (0, 4) 和 (2, 10)；(3) 通過 (1, 5) 和 (3, 11)。

<details><summary>參考答案</summary>

(1) y = 3x − 2。

(2) 穿過 y 軸的點是 (0, 4)，b = 4；斜率 (10 − 4) ÷ 2 = 3。y = 3x + 4。檢查 x = 2：6 + 4 = 10 ✓。

(3) 斜率 (11 − 5) ÷ (3 − 1) = 3。把 (1, 5) 代入 y = 3x + b：5 = 3 + b，b = 2。y = 3x + 2。檢查 (3, 11)：9 + 2 = 11 ✓。

</details>

5. 某城市的計程車起跳 70 元，之後每公里加 20 元。(1) 寫出車資 y 和里程 x 的式子；(2) 坐 10 公里要多少錢？(3) 付了 220 元，大約坐了幾公里？(4) 式子裡的 70 和 20 在圖上各代表什麼？

<details><summary>參考答案</summary>

(1) y = 20x + 70。

(2) 20 × 10 + 70 = 270 元。

(3) 20x + 70 = 220，20x = 150，x = 7.5 公里。

(4) 70 是 y 截距，直線從 (0, 70) 出發，意思是還沒開始跑就要付 70 元；20 是斜率，每往右 1 公里，車資往上 20 元。

</details>

6. 回到開場的手機方案：甲 y = 3x + 200，乙 y = x + 500。(1) 一個月講 100 分鐘，哪個便宜？便宜多少？(2) 講 200 分鐘呢？(3) 講幾分鐘兩個方案一樣貴？(4) 如果有第三個方案丙：月租 800 元、通話免費，講超過幾分鐘選丙最划算？

<details><summary>參考答案</summary>

(1) 甲 300 + 200 = 500 元，乙 100 + 500 = 600 元。甲便宜 100 元。

(2) 甲 600 + 200 = 800 元，乙 200 + 500 = 700 元。乙便宜 100 元。

(3) 3x + 200 = x + 500，2x = 300，x = 150 分鐘，兩者都是 650 元。

(4) 丙是水平線 y = 800。和乙比：x + 500 = 800 時 x = 300，超過 300 分鐘後乙會比 800 貴，丙最划算。（甲在 150 分鐘後已經輸給乙，所以只要和乙比就好。）

</details>

7. 用畫圖的方法解 2x + 1 = −x + 7：在方格紙上畫出 y = 2x + 1 和 y = −x + 7，讀出交點，再用上一章的方法解一次確認。

<details><summary>參考答案</summary>

y = 2x + 1 過 (0, 1)、(1, 3)、(2, 5)；y = −x + 7 過 (0, 7)、(1, 6)、(2, 5)。兩條線在 (2, 5) 交叉，所以 x = 2。

代數解：2x + x = 7 − 1，3x = 6，x = 2。兩種方法一致。y = 5 是 x = 2 時兩邊共同的值。

</details>

8. （挑戰）游泳池原本有 2000 公升的水，打開排水孔後每分鐘流出 50 公升。(1) 寫出剩餘水量 y 和時間 x（分鐘）的式子；(2) 斜率是多少？負的斜率在這裡是什麼意思？(3) 幾分鐘後水放完？這個答案在圖上是哪個點？(4) 如果同時有人用每分鐘 20 公升的速度注水，式子和放完的時間會怎麼變？

<details><summary>參考答案</summary>

(1) y = 2000 − 50x，也可以寫成 y = −50x + 2000。

(2) 斜率 −50，意思是每過 1 分鐘，水量往下掉 50 公升，直線往右下走。

(3) 2000 − 50x = 0，x = 40 分鐘。在圖上是直線和 x 軸交叉的點 (40, 0)，叫做 x 截距。

(4) 每分鐘淨流出 50 − 20 = 30 公升，式子變成 y = 2000 − 30x，斜率變緩成 −30。放完要 2000 ÷ 30 ≈ 66.7 分鐘，大約 1 小時 7 分。

</details>

## 本章小結

- 坐標平面用一對數字 (x, y) 說位置：先橫再直，往左、往下用負數，原點是 (0, 0)。
- y = ax + b 是一次函數，列表、標點、連線，點一定排成直線，因為 x 每多 1，y 就固定多 a。
- 斜率 a = 上升 ÷ 前進 = (y₂ − y₁) ÷ (x₂ − x₁)，是整條線的陡度，任選兩點算都一樣。正斜率往右上，負斜率往右下，0 是水平線。
- y 截距 b 是 x = 0 時的 y，也就是直線穿過 y 軸的高度，生活中常是月租、起跳價、初始量。
- 從圖找式子：先讀截距 b，再找兩個格點算斜率 a；兩點都不在 y 軸上就先算 a，再代一個點求 b。
- 兩條線的交點就是方程式「左邊 = 右邊」的解，也是兩個方案「一樣貴」的地方；交點兩側誰的線在下面，誰就比較便宜。
- 畫直線算三個點，用第三個點檢查前兩個。
- 試算表能一次算很多點並畫折線圖，GeoGebra 可以直接畫直線、求交點、用滑桿看 a 和 b 的影響。
