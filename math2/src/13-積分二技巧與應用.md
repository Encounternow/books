# 第 13 章　積分二技巧與應用

## 本章目標
- 學完你會背出並使用基本積分表：xⁿ、1/x、eˣ、sin、cos，每一條都能微分回去驗證。
- 學完你會用「換單位」的直覺做代換法，處理 ∫ 2x cos(x²) dx 這類題目。
- 學完你會算兩條曲線之間的面積，知道要先找交點、再用「上減下」。
- 學完你會把旋轉體切成一疊圓盤，用 V = ∫ π r² dx 算體積，並實際量一個花瓶驗證。
- 學完你會用積分算平均值、功與距離，並用 Python 做數值積分。

## 開場：花瓶裝得下多少水？

家裡有一個曲線形的花瓶，肚子圓、脖子細、口又微微張開。媽媽問：「這瓶子裝得下 500 mL 嗎？」最直接的方法是倒水進去量。但如果這是一個設計圖上的花瓶，還沒做出來呢？或者是博物館裡不能碰的古董？

阿哲想到第 8 章學過的圓柱體積 πr²h。可是花瓶不是圓柱，每一個高度的半徑都不一樣。他接著想到上一章的黎曼和：**把花瓶橫著切成很多薄片，每一片差不多是一個很扁的圓柱，算出每片體積再加起來。** 切得越薄，越準。

他拿尺量了花瓶每 1 公分高度的直徑，算出半徑，用 π r² × 1 算每一片，加起來得到 369 mL。再用量杯倒水進去，倒到 370 mL 剛好滿。數學算的和實際量的差不到 1%。

這一章我們把積分從「面積」推廣到「體積」、「平均」、「功」，而且學兩個讓反導數變好找的技巧：代換法和分部積分。所有的應用都用同一個想法：**切薄片、每片算一下、全部加起來。**

## 核心概念

### 基本積分表

上一章的基本定理說：要算定積分，先找反導數。所以我們需要一張「反導數表」。它其實就是第 9、10 章的導數表倒過來讀，每一條都可以微分回去驗證：

| 積分公式 | 算例 | 為什麼（微分回去） |
|---|---|---|
| ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C（n ≠ −1） | ∫ x⁴ dx = x⁵/5 + C | (x⁵/5)′ = 5x⁴/5 = x⁴ |
| ∫ 1/x dx = ln\|x\| + C | ∫₁² 1/x dx = ln 2 ≈ 0.693 | (ln x)′ = 1/x |
| ∫ eˣ dx = eˣ + C | ∫₀¹ eˣ dx = e − 1 ≈ 1.718 | (eˣ)′ = eˣ |
| ∫ cos x dx = sin x + C | ∫₀^(π/2) cos x dx = 1 | (sin x)′ = cos x |
| ∫ sin x dx = −cos x + C | ∫₀^π sin x dx = −cos π + cos 0 = 2 | (−cos x)′ = sin x |
| ∫ k dx = kx + C | ∫ 7 dx = 7x + C | (7x)′ = 7 |
| ∫ (f ± g) dx = ∫ f dx ± ∫ g dx | ∫ (x² + eˣ) dx = x³/3 + eˣ + C | 和的導數是導數的和 |
| ∫ k·f dx = k·∫ f dx | ∫ 3 cos x dx = 3 sin x + C | 常數可以提出來 |

兩個要特別注意的地方：

- **n = −1 不能用次方加一**，因為 x⁰/0 沒有意義。1/x 的反導數是 ln|x|，這是第 10 章 (ln x)′ = 1/x 的反面。絕對值是因為 x 是負數時 ln x 沒定義，但 ln(−x) 的導數也是 1/x。
- **sin 積分出來有負號**，cos 沒有。記法：微分 sin → cos → −sin → −cos → sin 是一個循環，積分就反著走。

算例：∫₀² (x³ − 2x + 1) dx = [x⁴/4 − x² + x]₀² = (4 − 4 + 2) − 0 = 2。

### 代換法：換單位的直覺

遇到 ∫ 2x cos(x²) dx，表上沒有。被積函數是「cos 的裡面塞了 x²，外面又多了一個 2x」。注意 2x 剛好是 x² 的導數，這不是巧合，是第 10 章鏈鎖法則留下的痕跡：

> (sin(x²))′ = cos(x²) · 2x

所以 ∫ 2x cos(x²) dx = sin(x²) + C。鏈鎖法則倒過來讀，就是**代換法（Substitution）**。

它的直覺是「換單位」。想像你在算一段路的長度，路上的標記是用「公尺」寫的，但你的尺是「公分」。你要把每個公尺數乘以 100 才能用公分來讀。代換法就是：把式子裡「太複雜的那一塊」當成新的變數 u，然後把 dx 換成 du，換算的比率就是 du/dx。

步驟：

1. 挑出裡面那一塊，令 u = x²。
2. 算 du/dx = 2x，所以 du = 2x dx。這是「公尺換公分」的換算率。
3. 把原式用 u 寫：∫ cos(x²) · 2x dx = ∫ cos u du。
4. 查表：∫ cos u du = sin u + C。
5. 把 u 換回來：sin(x²) + C。

再做一個：∫ (3x + 1)⁴ dx。令 u = 3x + 1，du = 3 dx，所以 dx = du/3。原式 = ∫ u⁴ · (du/3) = (1/3)(u⁵/5) + C = (3x + 1)⁵/15 + C。微分回去檢查：(1/15) · 5(3x + 1)⁴ · 3 = (3x + 1)⁴，對了。

**定積分做代換時，上下限也要換單位。** 例如 ∫₀¹ 2x e^(x²) dx。令 u = x²，du = 2x dx。x 從 0 到 1 時，u 從 0 到 1（這題剛好一樣，但不一定）。所以 = ∫₀¹ eᵘ du = e − 1 ≈ 1.718。

再一個上下限會變的：∫₀² 2x cos(x²) dx，u = x²，x 從 0 到 2 時 u 從 0 到 4，所以 = ∫₀⁴ cos u du = sin 4 − sin 0 ≈ −0.757。（4 是弧度，sin 4 是負的，因為 4 弧度 ≈ 229°，在第三象限。）

什麼時候用代換法？**看到「某一塊的導數」也出現在式子裡的時候。** 像 x · √(x² + 1)（x 是 x² + 1 的導數的一半）、x/(x² + 1)、sin x cos x（cos x 是 sin x 的導數）、(ln x)/x（1/x 是 ln x 的導數）。差一個常數倍沒關係，可以把常數提出來調整。

### 分部積分簡介（選配）

代換法處理的是「合成」，那「乘積」呢？例如 ∫ x eˣ dx，x 和 eˣ 相乘，誰也不是誰的導數。

第 10 章的乘積法則說 (f·g)′ = f′g + fg′。移項得 fg′ = (fg)′ − f′g，兩邊積分：

> ∫ f g′ dx = f g − ∫ f′ g dx

這叫**分部積分（Integration by Parts）**。意思是：把乘積中的一個當 f（準備微分它）、另一個當 g′（準備積分它），交換角色後，新的積分可能比原來簡單。

∫ x eˣ dx：取 f = x（微分後變 1，變簡單）、g′ = eˣ（積分後還是 eˣ，不會變難）。f′ = 1，g = eˣ。

> ∫ x eˣ dx = x eˣ − ∫ 1 · eˣ dx = x eˣ − eˣ + C = (x − 1)eˣ + C

檢查：((x − 1)eˣ)′ = eˣ + (x − 1)eˣ = x eˣ。對了。定積分：∫₀¹ x eˣ dx = [(x − 1)eˣ]₀¹ = 0 − (−1) = 1。

另一個經典是 ∫ ln x dx，看起來不是乘積，但可以寫成 ln x · 1。取 f = ln x、g′ = 1，f′ = 1/x、g = x：∫ ln x dx = x ln x − ∫ x · (1/x) dx = x ln x − x + C。

挑 f 的原則：**微分之後會變簡單的當 f**（多項式、ln x），**積分之後不會變複雜的當 g′**（eˣ、sin、cos）。這一節是選配，之後的應用不會用到它。

### 面積與兩曲線之間的面積

上一章算的是「曲線和 x 軸之間」。如果是兩條曲線之間呢？例如 y = x 和 y = x² 在 0 到 1 之間圍出的小葉子形狀。

```
  1 ┼          ╱•
    │       ╱▒╱
    │     ╱▒╱     上面是 y = x，下面是 y = x²
    │   ╱▒╱
    │ ╱•╱
  0 •───────────► x
    0          1
```

切成細長條：每一條的高是「上面的函數減下面的函數」，寬是 dx。所以：

> 兩曲線間面積 = ∫ₐᵇ (上 − 下) dx

這裡上是 x、下是 x²（在 0 到 1 之間 x 比 x² 大）：∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6。

三個步驟：**先找交點**（解 上 = 下，得到積分範圍）、**判斷誰在上面**（代一個中間的 x 試試）、**積分上減下**。

再一題：y = 4 − x² 和 y = x + 2。交點：4 − x² = x + 2 → x² + x − 2 = 0 → (x + 2)(x − 1) = 0 → x = −2 或 1。代 x = 0：4 − 0 = 4 比 0 + 2 = 2 大，所以拋物線在上。

> 面積 = ∫₋₂¹ [(4 − x²) − (x + 2)] dx = ∫₋₂¹ (2 − x − x²) dx = [2x − x²/2 − x³/3]₋₂¹ = (2 − 1/2 − 1/3) − (−4 − 2 + 8/3) = 7/6 − (−10/3) = 9/2 = 4.5

如果兩條曲線在中途交叉（誰在上面換了），要在交點切開分段算。

### 旋轉體體積：把圓盤疊起來

回到開場的花瓶。把一條曲線 y = f(x) 繞著 x 軸轉一圈，掃出來的立體叫**旋轉體（Solid of Revolution）**。花瓶、酒杯、陶壺、燈泡都是旋轉體。

怎麼算體積？**切成一疊圓盤。** 在位置 x 切一片，厚度 dx，這一片是個很扁的圓柱，半徑就是曲線的高度 f(x)，所以體積是 π [f(x)]² dx。把所有圓盤從 a 到 b 加起來：

> V = ∫ₐᵇ π [f(x)]² dx

這叫**圓盤法（Disk Method）**。和算面積的差別只有一個：長方形面積「高 × 寬」換成了圓盤體積「π 半徑² × 厚」。

```
        y = f(x)
   ╭────╮
  ╱ ┃┃┃┃ ╲        每一片：半徑 f(x)、厚 dx
 │  ┃┃┃┃  │       體積 π f(x)² dx
  ╲ ┃┃┃┃ ╱
   ╰────╯
 ─────────────► x
   a      b
```

用它驗證幾個你已經知道的公式：

- **圓柱**：y = 2（固定），0 到 5。V = ∫₀⁵ π · 4 dx = 20π ≈ 62.8。和 πr²h = π · 4 · 5 一樣。
- **圓錐**：y = x/2（直線），0 到 6，底半徑 3、高 6。V = ∫₀⁶ π (x/2)² dx = π ∫₀⁶ x²/4 dx = π [x³/12]₀⁶ = 18π ≈ 56.5。公式 πr²h/3 = π · 9 · 6/3 = 18π。對了！國小背的 1/3 原來是從 x² 積分出來的 1/3。
- **彎的**：y = √x，0 到 4，像一個喇叭。V = ∫₀⁴ π x dx = π [x²/2]₀⁴ = 8π ≈ 25.1。
- **球**：y = √(r² − x²) 從 −r 到 r。V = π ∫₋ᵣʳ (r² − x²) dx = π [r²x − x³/3]₋ᵣʳ = π (2r³ − 2r³/3) = 4πr³/3。球體積公式就是這樣來的。

真實的花瓶沒有公式，但有測量值。把花瓶直立，高度 h 從 0 到 10 公分，每 1 公分量一次直徑，取一半得半徑：

| 高度 h（cm） | 直徑（cm） | 半徑 r（cm） | 這一層用的半徑（兩端平均） | π r² × 1（mL） | 累積（mL） |
|---|---|---|---|---|---|
| 0 | 6.0 | 3.0 | | | 0 |
| 1 | 6.8 | 3.4 | 3.20 | 32.2 | 32.2 |
| 2 | 7.6 | 3.8 | 3.60 | 40.7 | 72.9 |
| 3 | 8.0 | 4.0 | 3.90 | 47.8 | 120.7 |
| 4 | 8.0 | 4.0 | 4.00 | 50.3 | 170.9 |
| 5 | 7.4 | 3.7 | 3.85 | 46.6 | 217.5 |
| 6 | 6.4 | 3.2 | 3.45 | 37.4 | 254.9 |
| 7 | 5.6 | 2.8 | 3.00 | 28.3 | 283.2 |
| 8 | 5.6 | 2.8 | 2.80 | 24.6 | 307.8 |
| 9 | 6.2 | 3.1 | 2.95 | 27.3 | 335.1 |
| 10 | 7.0 | 3.5 | 3.30 | 34.2 | 369.3 |

這就是一個「圓盤法的黎曼和」，10 片圓盤疊起來 369 mL（1 cm³ = 1 mL）。

### 平均值

一天 24 小時的氣溫一直在變，「今天的平均氣溫」是什麼意思？如果只有 24 個整點的數據，就 24 個加起來除以 24。如果氣溫是連續的函數 T(t)，「無限多個數加起來除以無限多」要怎麼算？

答案是用積分：把「加起來」換成積分，「除以個數」換成「除以區間長度」：

> f 在 [a, b] 的平均值 = (1/(b − a)) ∫ₐᵇ f(x) dx

直覺：曲線下的面積，如果攤平成一個等寬的長方形，長方形的高就是平均值。

算例：f(x) = x² 在 [0, 3] 的平均值 = (1/3) · 9 = 3。注意不是 (0 + 9)/2 = 4.5，因為 x² 大部分時間都比較小，小的值比較多，拉低了平均。

又如速度 v(t) = 3t² 從 0 到 2 秒，距離 ∫₀² 3t² dt = 8 公尺，平均速度 8/2 = 4 公尺／秒。這正是「總距離除以總時間」，和國小的定義一致。

### 功與距離

物理裡「功 = 力 × 距離」，但只對固定的力成立。彈簧的力會隨拉長的距離變大：F = kx（虎克定律）。把彈簧從 0 拉到 d，每拉一小段 dx 做功 F dx，全部加起來：

> W = ∫₀ᵈ kx dx = [kx²/2]₀ᵈ = kd²/2

例：k = 50 牛頓／公尺，拉 0.2 公尺，W = 50 × 0.04 / 2 = 1 焦耳。這個式子和三角形面積 ½ × 底 d × 高 kd 一樣，因為 F = kx 的圖是一條斜線。

距離也是同樣的事：距離 = ∫ 速度 dt，上一章已經做過。模式永遠一樣：**只要一個量是「另一個量 × 小段」累積出來的，就是積分。**

## 動手做

### 活動 13-1：量花瓶體積，再用量杯驗證

**材料／工具**：一個上下粗細不同的花瓶或玻璃杯（最好是透明、圓形截面的）、尺或捲尺、一張紙和筆、500 mL 量杯、計算機（或試算表）。

**步驟**：
1. 把花瓶立在桌上。用尺在瓶身外側每 1 公分做一個記號（或貼一條紙膠帶，在紙膠帶上畫刻度），從底部 0 到瓶口。
2. 在每個刻度量「外直徑」：用尺橫跨瓶子最寬處，量兩側外緣的距離。如果玻璃厚度約 0.3 公分，直徑要減掉 0.6 再除以 2 得內半徑。瓶底如果很厚，第一個刻度從瓶內底部開始。
3. 把每層「上下兩端半徑的平均」算出來，再算 π × 半徑² × 1 公分，填進表格。
4. 全部加起來，就是你算的體積（cm³ = mL）。
5. 用量杯慢慢把水倒進花瓶，倒滿為止，記下總共倒了多少 mL。
6. 算誤差百分比 = |算的 − 量的| ÷ 量的 × 100%。

**你應該看到／得到**：如果直徑量得仔細、玻璃厚度有扣掉，誤差通常在 5% 以內。開場的例子是 369 mL 對 370 mL。如果誤差超過 10%，最常見的原因是：忘了扣玻璃厚度（算出來會偏大）、瓶底很厚沒扣（偏大）、或者某一層剛好在最寬或最窄的地方變化很快，1 公分太粗（可以在那一段改成每 0.5 公分量一次）。

**觀察與記錄**：

| 高度（cm） | 外直徑（cm） | 內半徑（cm） | 這層半徑（平均） | π r² × 厚（mL） | 累積（mL） |
|---|---|---|---|---|---|
| 0 | | | | | 0 |
| 1 | | | | | |
| 2 | | | | | |
| … | | | | | |
| 算出的總體積 | | | | | |
| 量杯實際倒入 | | | | | |
| 誤差 % | | | | | |

### 活動 13-2：用紙圓盤疊出圓錐

**材料／工具**：厚紙或硬卡紙、圓規、剪刀、尺、米或綠豆、兩個一樣的紙杯。

**步驟**：
1. 在卡紙上畫並剪出 6 個圓，半徑分別是 0.5、1.0、1.5、2.0、2.5、3.0 公分。（如果卡紙厚度是 0.1 公分，疊起來是一個 6 層的「階梯圓錐」。）
2. 把 6 片圓從大到小疊起來，看它像不像一個圓錐。這就是「圓盤法」的實體版：每片是一個圓柱 π r² × 厚。
3. 算 6 片的體積和：π (0.5² + 1² + 1.5² + 2² + 2.5² + 3²) × 0.1 = π × 22.75 × 0.1 ≈ 7.15 cm³。
4. 一個底半徑 3、高 0.6 的真正圓錐體積是 π × 9 × 0.6 / 3 ≈ 5.65 cm³。你的階梯圓錐比較大，因為每片都用了那一層「最大」的半徑（像右和）。
5. 想一想：如果切成 60 片、每片 0.01 公分，階梯圓錐會更接近真正的圓錐嗎？（會。這就是黎曼和收斂。）
6. 延伸：用紙杯裝米，一杯當圓錐（把紙杯內部想像成倒過來的圓錐台），每 1 公分量一次內直徑，用圓盤法算容量，再把米倒進量杯比對。

**你應該看到／得到**：階梯圓錐的體積和真圓錐差約 26%，看起來很多，但那是因為只有 6 片。每片半徑用「這一層的中間高度」的半徑（0.25、0.75、…）算的話，會更接近。

**觀察與記錄**：

| 片數 | 每片厚 | 半徑用法 | 算出體積 | 真圓錐體積 | 誤差 % |
|---|---|---|---|---|---|
| 6 | 0.1 | 每層最大 | | 5.65 | |
| 6 | 0.1 | 每層中間 | | 5.65 | |

## 用工具看看

### 用 Desmos 看兩曲線之間的面積

1. 打開 desmos.com/calculator。
2. 第一行輸入 `y = 4 - x^2`，第二行輸入 `y = x + 2`。看到拋物線和直線在 x = −2 和 x = 1 交叉。
3. 第三行輸入 `(4 - x^2) - (x + 2) \{-2 \le x \le 1\}`，Desmos 會畫出「上減下」這個差函數，只畫在交點之間。
4. 第四行輸入 `\int_{-2}^{1} ((4 - x^2) - (x + 2)) dx`，Desmos 會直接顯示 4.5。
5. 把第二行改成 `y = x + 3`，交點變了，面積也變了，Desmos 第四行會算錯（因為上下限還是舊的）。這提醒你：**上下限要跟著交點改**。

### 用 Python 做數值積分：梯形法與辛普森法

很多函數沒有公式解的反導數，例如 e^(−x²)（統計常態分布的核心）。這時候就靠電腦切片。比長方形更聰明的是**梯形法**（每片用梯形，上邊是斜的）和**辛普森法**（每兩片用一小段拋物線）。在 Colab 貼上：

```python
import math

def trapezoid(f, a, b, n):
    # 梯形法：把曲線下方切成 n 個梯形，每個梯形面積 = (左高 + 右高) / 2 × 寬
    h = (b - a) / n
    total = (f(a) + f(b)) / 2            # 頭尾兩個高各算一半
    for i in range(1, n):
        total += f(a + i * h)            # 中間的高各算一次
    return total * h

def simpson(f, a, b, n):
    # 辛普森法：每兩段用一條拋物線代替曲線，n 必須是偶數
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        weight = 4 if i % 2 == 1 else 2  # 奇數點權重 4，偶數點權重 2
        total += weight * f(a + i * h)
    return total * h / 3

# 三個測試：x² 在 [0,1]（答案 1/3）、sin x 在 [0,π]（答案 2）、e^(−x²) 在 [0,1]（沒有公式解）
tests = [
    ("x²  [0,1]", lambda x: x ** 2, 0, 1, 1 / 3),
    ("sin x [0,π]", math.sin, 0, math.pi, 2),
    ("e^(−x²) [0,1]", lambda x: math.exp(-x * x), 0, 1, 0.7468241328),
]
for name, f, a, b, exact in tests:
    print(name, "  正確答案 ≈", round(exact, 6))
    for n in [4, 10, 100]:
        print(f"   n={n:3d}  梯形 {trapezoid(f, a, b, n):.6f}  辛普森 {simpson(f, a, b, n):.6f}")
```

兩件值得注意的事：辛普森法對 x² 這種二次函數「一次就全對」（因為它本來就用拋物線），對其他函數也只要 n = 10 就準到小數第四位。梯形法 n = 100 才到小數第三位。所以工程上大家用辛普森法。

## 常見錯誤與迷思

- **「∫ 1/x dx = x⁰/0」** → n = −1 時公式不適用。正確是 ln|x| + C，因為 (ln x)′ = 1/x。
- **「∫ sin x dx = cos x」** → 少了負號。(cos x)′ = −sin x，所以要 −cos x 才對。永遠微分回去檢查。
- **「代換後忘了換 dx」** → ∫ cos(x²) dx 不能直接寫成 ∫ cos u du，因為 dx ≠ du。du = 2x dx，如果式子裡沒有 2x，代換法做不了（這題事實上沒有初等反導數）。
- **「定積分代換後用舊的上下限」** → u 的範圍和 x 的範圍不同。∫₀² 2x cos(x²) dx 換成 u 後上限是 4，不是 2。或者先用 u 算出不定積分、換回 x、再代原來的上下限，兩種方法選一種，不要混用。
- **「兩曲線面積 = ∫ f − ∫ g，不管誰在上」** → 如果下減上，答案會變負的。而且如果中途交叉，必須分段。先畫圖。
- **「旋轉體體積是 ∫ π f(x) dx」** → 半徑要平方。圓盤面積是 π r²，不是 π r。
- **「平均值是 (f(a) + f(b)) / 2」** → 那只是頭尾兩點的平均。x² 在 [0, 3] 的平均是 3，不是 4.5。要用面積除以區間長度。
- **「花瓶量到的誤差很大是數學錯了」** → 更可能是玻璃厚度沒扣、刻度太粗、或瓶子不是正圓。先檢查測量。

1. 算下列不定積分，並微分回去檢查：(a) ∫ (x³ − 2x + 1) dx　(b) ∫ 3 cos x dx　(c) ∫ (eˣ + 1/x) dx

(a) x⁴/4 − x² + x + C。檢查：x³ − 2x + 1。

(b) 3 sin x + C。檢查：3 cos x。

(c) eˣ + ln|x| + C。檢查：eˣ + 1/x。

2. 用代換法算 ∫ x √(x² + 1) dx，並算 ∫₀² x √(x² + 1) dx。

<details><summary>參考答案</summary>

令 u = x² + 1，du = 2x dx，x dx = du/2。原式 = ∫ √u · du/2 = (1/2) · u^(3/2)/(3/2) + C = (1/3)(x² + 1)^(3/2) + C。

定積分：x 從 0 到 2，u 從 1 到 5。= (1/3)(5^(3/2) − 1) = (1/3)(11.180 − 1) ≈ 3.393。

</details>

3. 算 ∫₀¹ x/(x² + 1) dx。

<details><summary>參考答案</summary>

令 u = x² + 1，du = 2x dx，x dx = du/2。x 從 0 到 1 時 u 從 1 到 2。= ∫₁² (1/u)(du/2) = (1/2)[ln u]₁² = (ln 2)/2 ≈ 0.347。

</details>

4. 求 y = x² 和 y = 2x 圍出的面積。

<details><summary>參考答案</summary>

交點：x² = 2x → x = 0 或 2。代 x = 1：2x = 2 比 x² = 1 大，所以 2x 在上。面積 = ∫₀² (2x − x²) dx = [x² − x³/3]₀² = 4 − 8/3 = 4/3。

</details>

5. 把 y = x 從 0 到 3 繞 x 軸旋轉，得到一個圓錐。(a) 用圓盤法算體積。(b) 用國小公式驗算。(c) 把 y = x² 從 0 到 1 繞 x 軸旋轉的體積是多少？

<details><summary>參考答案</summary>

(a) V = ∫₀³ π x² dx = π [x³/3]₀³ = 9π ≈ 28.3。

(b) 底半徑 3、高 3，πr²h/3 = π · 9 · 3/3 = 9π。一致。

(c) V = ∫₀¹ π (x²)² dx = π ∫₀¹ x⁴ dx = π/5 ≈ 0.628。

6. 一天的氣溫是 T(t) = 20 + 10 sin(πt/12)，t 是從早上 6 點起算的小時數，0 ≤ t ≤ 24。(a) 一天的平均氣溫是多少？(b) 中午 12 點（t = 6）到晚上 6 點（t = 12）之間的平均氣溫呢？

<details><summary>參考答案</summary>

(a) (1/24) ∫₀²⁴ [20 + 10 sin(πt/12)] dt。sin 在完整的一個週期（24 小時）積分是 0，所以平均 = 20°C。

(b) (1/6) ∫₆¹² 10 sin(πt/12) dt + 20。令 u = πt/12，du = (π/12) dt，dt = (12/π) du；t 從 6 到 12 時 u 從 π/2 到 π。∫ = 10 · (12/π) [−cos u]_(π/2)^π = (120/π)(−cos π + cos(π/2)) = (120/π)(1 + 0) = 120/π ≈ 38.2。除以 6 得 6.37。平均 ≈ 26.4°C。

</details>

7. （選配）用分部積分算 ∫₀¹ x e^(−x) dx。

<details><summary>參考答案</summary>

取 f = x、g′ = e^(−x)，f′ = 1、g = −e^(−x)。∫ x e^(−x) dx = −x e^(−x) − ∫ (−e^(−x)) dx = −x e^(−x) − e^(−x) + C = −(x + 1)e^(−x) + C。定積分：[−(x + 1)e^(−x)]₀¹ = −2/e − (−1) = 1 − 2/e ≈ 0.264。

</details>

8. （挑戰）一個碗的內壁形狀是 y = x²/4（y 是高度、x 是半徑，單位公分）繞 y 軸旋轉，碗深 4 公分。(a) 碗裝滿水是幾 mL？提示：這次是對 y 積分，圓盤半徑是 x，x² = 4y。(b) 裝到一半深度（2 公分）時裝了幾 mL？是總量的一半嗎？為什麼？

<details><summary>參考答案</summary>

(a) 水平切片在高度 y 的半徑是 x = √(4y)，圓盤面積 π x² = 4πy。V = ∫₀⁴ 4πy dy = 4π [y²/2]₀⁴ = 32π ≈ 100.5 mL。

(b) ∫₀² 4πy dy = 4π · 2 = 8π ≈ 25.1 mL，只有總量的四分之一。因為碗越上面越寬，上半段的水比下半段多很多。體積和高度的關係是 V = 2πy²，是二次的，不是一次的。

</details>

## 本章小結

- 基本積分表是導數表倒過來讀；每一條都能微分回去檢查，養成這個習慣。
- 1/x 的反導數是 ln|x|；sin 積分出來是 −cos。
- 代換法是鏈鎖法則倒過來，直覺是「換單位」：令 u = 裡面那一塊，du = u′ dx，上下限也要換。
- 分部積分是乘積法則倒過來：∫ f g′ = f g − ∫ f′ g，微分會變簡單的當 f。
- 兩曲線間面積：找交點、判斷上下、積分「上減下」，中途交叉要分段。
- 旋轉體體積：切成圓盤，V = ∫ π [f(x)]² dx。圓錐的 1/3、球的 4/3 都是這樣積出來的。
- 平均值 = 面積 ÷ 區間長度；功 = ∫ 力 dx；距離 = ∫ 速度 dt。所有「某量 × 小段」累積出來的東西都是積分。
- 沒有公式解就用數值積分：辛普森法 n = 10 通常就很準。
