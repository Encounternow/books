# 第 10 章　微分二：規則與函數

## 本章目標
- 學完你會用「兩邊都在長的長方形」解釋乘積法則，並用它微分兩個函數的乘積與商。
- 學完你會用「齒輪比」解釋鏈鎖法則，微分像 (3x + 1)²、sin 2x、√(x² + 1) 這樣一層套一層的函數。
- 學完你會用數值表與圖形說明為什麼 sin 的導數是 cos、cos 的導數是 −sin。
- 學完你會說明 eˣ 的導數為什麼是它自己、ln x 的導數為什麼是 1/x，並會微分 2ˣ 這類一般指數函數。
- 學完你會算二階導數，知道加速度是位置的二階導數，並對隱函數微分有初步印象。

## 開場：網拍的營收變多快？

阿姨在網路上賣手工餅乾。她發現兩件事同時在變：單價因為原料漲價，每個月漲 2 元；銷量因為口碑，每個月多賣 30 盒。這個月單價 100 元、賣 400 盒，營收 40,000 元。她問：「下個月營收大約會多多少？」

表弟說：「單價多 2 元，400 盒就多 800 元；銷量多 30 盒，每盒 100 元就多 3,000 元。加起來大概多 3,800 元。」阿姨又問：「那漲價的 2 元乘上多賣的 30 盒呢？」表弟說：「那只有 60 元，比起 3,800 小太多，先不管。」

表弟其實已經發現了乘積法則：**兩個都在變的量相乘，變化率 = 一個不動乘另一個的變化 + 另一個不動乘這一個的變化。** 上一章的四條公式只能處理「加減」和「乘常數」，這一章要補上「乘」、「除」和「套在一起」三種情況，然後把 sin、cos、eˣ、ln x 這些非多項式的函數也納進來。學完之後，你幾乎什麼函數都能微分了。

## 核心概念

### 乘積法則：兩邊都在長的長方形

把兩個函數 f 和 g 想成一個長方形的長和寬，面積就是 f × g。現在 x 稍微增加一點（增加 h），長變成 f + Δf，寬變成 g + Δg：

```
          ←──── f ────→←Δf→
       ┌──────────────┬────┐
    ↑  │              │    │
    │  │   原本的面積   │ g  │  ← 新增：g × Δf
    g  │    f × g      │×Δf │
    │  │              │    │
    ↓  ├──────────────┼────┤
   Δg  │   f × Δg     │小角 │  ← 新增：f × Δg；小角是 Δf × Δg
       └──────────────┴────┘
```

面積的增加量是三塊：右邊的長條 g·Δf，下面的長條 f·Δg，和右下角的小角 Δf·Δg。除以 h，再讓 h → 0：Δf/h → f′、Δg/h → g′，而小角 Δf·Δg/h = Δf × (Δg/h) → 0 × g′ = 0（Δf 本身也趨近 0）。所以：

```
(f × g)′ = f′ × g + f × g′
```

這就是乘積法則（Product Rule）。口訣：「前微後不微，加上前不微後微」。回到網拍：營收 R = p × q，R′ = p′q + pq′ = 2 × 400 + 100 × 30 = 800 + 3,000 = 3,800（元/月），表弟算對了，而他丟掉的 60 元正是會消失的小角。

**例子 1**：檢查 x² × x³。用乘積法則：(x²)′·x³ + x²·(x³)′ = 2x·x³ + x²·3x² = 2x⁴ + 3x⁴ = 5x⁴。直接算：x² × x³ = x⁵，導數 5x⁴。一致。

**例子 2**：(x · sin x)′ = 1 · sin x + x · cos x（sin 的導數等一下會講）。

注意：**乘積的導數不是導數的乘積。** (x² × x³)′ ≠ 2x × 3x² = 6x³，這是最常見的錯誤。

### 商法則

除法可以從乘積法則推出來。設 Q = f/g，則 f = Q × g。兩邊微分：f′ = Q′g + Qg′，解出 Q′ = (f′ − Qg′)/g = (f′ − (f/g)g′)/g，通分得：

```
(f / g)′ = (f′ × g − f × g′) / g²
```

這是商法則（Quotient Rule）。口訣：「上微下不微，減去上不微下微，除以下面的平方」。減號的順序不能顛倒。

**例子**：f(x) = x/(x + 1)。f′ = (1·(x + 1) − x·1)/(x + 1)² = 1/(x + 1)²。在 x = 2：1/9 ≈ 0.111。數值檢查：(2.001/3.001 − 1.999/2.999)/0.002 ≈ 0.1111。

**例子**：用商法則算 (1/x)′ = (0·x − 1·1)/x² = −1/x²，和上一章用冪次公式得到的一樣。

什麼時候用商法則、什麼時候不用？如果分母只是常數，例如 (x² + 1)/3，直接當成 (1/3)(x² + 1) 用常數倍就好；如果分母是單一個冪次，例如 (x³ + 2)/x²，拆成 x + 2x⁻² 逐項微分更快。真正需要商法則的，是分母本身是一個「拆不開」的函數的情況，像 x/(x + 1)、sin x / cos x。

### 鏈鎖法則：齒輪比

腳踏車踏板齒輪有 48 齒，後輪齒輪有 16 齒。踏板轉 1 圈，後輪轉 3 圈；後輪轉 1 圈，車子前進 2 公尺。那踏板轉 1 圈，車子前進幾公尺？當然是 3 × 2 = 6 公尺。**變化率一層一層相乘**，這就是鏈鎖法則（Chain Rule）。

用符號寫：設 y 是 u 的函數、u 又是 x 的函數（y = f(u)，u = g(x)），則：

```
dy/dx = dy/du × du/dx          或寫成    (f(g(x)))′ = f′(g(x)) × g′(x)
```

萊布尼茲記號在這裡特別漂亮：du 看起來像被「約掉」了。意思是：**x 動一點 → u 跟著動 g′ 倍 → y 再跟著動 f′ 倍，總共 f′ × g′ 倍。**

**例子 1**：y = (3x + 1)²。外層是「平方」（u²，導數 2u），內層是 u = 3x + 1（導數 3）。
```
dy/dx = 2u × 3 = 2(3x + 1) × 3 = 6(3x + 1) = 18x + 6
```
驗證：展開 (3x + 1)² = 9x² + 6x + 1，直接微分得 18x + 6。一致。在 x = 1 的值是 24。

**例子 2**：y = √(x² + 1)。外層是 √u = u^(1/2)（導數 1/(2√u)），內層 u = x² + 1（導數 2x）。
```
dy/dx = 1/(2√(x² + 1)) × 2x = x / √(x² + 1)
```
在 x = 2：2/√5 ≈ 0.8944。數值檢查（中央差分）：0.8944。

**例子 3**：y = sin(2x)。外層 sin u（導數 cos u），內層 u = 2x（導數 2）。dy/dx = 2 cos(2x)。齒輪的說法：2x 讓波變密兩倍，所以每一點的斜率也變陡兩倍。

鏈鎖法則的步驟口訣：**先認出「外層」和「內層」，外層照微但裡面原樣保留，再乘上內層的導數。** 遇到三層就乘三次，例如 e^(sin(x²))：eᵘ × cos(x²) × 2x，把 u = sin(x²) 放回去，就是 e^(sin(x²)) × cos(x²) × 2x。

怎麼知道一個函數需不需要鏈鎖法則？問自己：「如果我要用計算機算它的值，要按幾次鍵？」算 sin(2x) 時你得先把 x 乘 2，再按 sin，兩個動作，就是兩層；算 (3x + 1)² 時先算 3x + 1 再平方，也是兩層。只要「裡面不是單純的 x」，就有內層，就要乘它的導數。反過來說，sin x、x²、eˣ 裡面都只是 x，內層導數是 1，乘了等於沒乘，所以上一章不需要這條法則。

它叫「鏈鎖」是因為變化像鏈子一樣一環扣一環傳下去：x 推動 u，u 推動 y。腳踏車的例子只有兩環，但汽車的變速箱、鐘錶裡的齒輪組可以有五六環，總傳動比永遠是每一環的比相乘，這也是為什麼鏈鎖法則可以無限制地疊下去。

### sin 的導數是 cos：用數值表看

先看數值。用上一章的中央差分，h = 0.001，弧度制：

| x | 0 | 0.5 | 1 | 1.5 | π/2 ≈ 1.571 | 2 | 2.5 | 3 | π ≈ 3.142 |
|---|---|---|---|---|---|---|---|---|---|
| sin x | 0 | 0.479 | 0.841 | 0.997 | 1 | 0.909 | 0.598 | 0.141 | 0 |
| 數值導數 | 1.000 | 0.878 | 0.540 | 0.071 | 0.000 | −0.416 | −0.801 | −0.990 | −1.000 |
| cos x | 1.000 | 0.878 | 0.540 | 0.071 | 0.000 | −0.416 | −0.801 | −0.990 | −1.000 |

每一欄都對上。再看圖的對應關係：

```
 sin x        1 |   .-'''-.                  斜率：
              0 +--'-------'--------.-----   x=0 最陡（往上）→ 1
             -1 |            '-...-'         x=π/2 山頂、水平 → 0
                0    π/2     π    3π/2  2π   x=π 最陡（往下）→ -1
                                             x=3π/2 谷底 → 0
 cos x        1 |'-.               .-'
              0 +---'-----.-------'------
             -1 |          '-...-'
                0    π/2     π    3π/2  2π
```

sin 在 0 爬得最快，cos 在 0 是 1；sin 在 π/2 到頂，cos 在 π/2 是 0；sin 在 π 掉得最快，cos 在 π 是 −1。**cos 的圖形就是 sin 的「斜率圖」。**

為什麼？用第 6 章的和角公式 sin(x + h) = sin x cos h + cos x sin h，差商變成：

```
(sin(x + h) − sin x)/h = sin x × (cos h − 1)/h + cos x × (sin h)/h
```

第 8 章算過 (sin h)/h → 1；而 (cos h − 1)/h → 0（用計算機試 h = 0.01 得 −0.005）。所以 h → 0 時，差商 → sin x × 0 + cos x × 1 = cos x。同樣的方法可得 **(cos x)′ = −sin x**（cos 在 0 是山頂、斜率 0；在 π/2 往下掉、斜率 −1，正好是 −sin）。

兩個提醒：第一，**一定要用弧度**。如果用角度，sin x / x → π/180 ≈ 0.01745，導數會多一個 0.01745 的因子，公式就不漂亮了，這是弧度存在的最大理由。第二，tan x = sin x / cos x，用商法則可以得到 (tan x)′ = 1/cos²x（想一想第 4 題）。

### eˣ 的導數是它自己

對指數函數 f(x) = aˣ 用定義：
```
(a^(x+h) − aˣ)/h = aˣ × (aʰ − 1)/h
```
aˣ 可以提出來，剩下的 (aʰ − 1)/h 只和 a 有關、和 x 無關。所以 **(aˣ)′ = aˣ × 某個常數**，這個常數就是 aˣ 在 x = 0 的斜率。用計算機算一算：

| h | 1 | 0.1 | 0.01 | 0.001 | 0.0001 | 極限 |
|---|---|---|---|---|---|---|
| (2ʰ − 1)/h | 1 | 0.7177 | 0.6956 | 0.6934 | 0.6932 | 0.6931 = ln 2 |
| (eʰ − 1)/h | 1.7183 | 1.0517 | 1.0050 | 1.0005 | 1.00005 | 1 |
| (3ʰ − 1)/h | 2 | 1.1612 | 1.1047 | 1.0992 | 1.0987 | 1.0986 = ln 3 |

2ˣ 的常數約 0.693，3ˣ 的約 1.099，而 e ≈ 2.718 夾在中間，常數剛好是 1。這就是 e 為什麼特別：**eˣ 是唯一「斜率等於自己高度」的指數函數**：

```
(eˣ)′ = eˣ            一般地：(aˣ)′ = aˣ × ln a
```

數值檢查：x = 1 時 eˣ = 2.7183，中央差分也是 2.7183；x = 2 時都是 7.3891。而 0.693 = ln 2、1.099 = ln 3 不是巧合，這是第 4 章自然對數的真正身分：ln a 就是「aˣ 在 0 的斜率」。

直覺上這代表：細菌數量 N = eᵗ，每一刻的成長速率 N′ 就等於當時的數量 N，數量越多長越快。第 3 章說過複利、人口、病毒傳播都是指數成長，它們的共同特徵就是「增加的速度和現在的量成正比」，而 e 是把這個特徵寫得最乾淨的底數：比例常數剛好是 1。這是第 14 章 dy/dt = ky 的起點。配上鏈鎖法則，(e^(kx))′ = k·e^(kx)；例如 (e^(−x²))′ = −2x·e^(−x²)。

### ln x 的導數是 1/x

數值表先看：

| x | 0.5 | 1 | 2 | 4 | 10 |
|---|---|---|---|---|---|
| ln x 的數值導數 | 2.000 | 1.000 | 0.500 | 0.250 | 0.100 |
| 1/x | 2 | 1 | 0.5 | 0.25 | 0.1 |

為什麼？ln 是 eˣ 的反函數（第 4 章）。設 y = ln x，則 x = eʸ。把 x 看成 y 的函數微分：dx/dy = eʸ = x。鏈鎖法則的齒輪倒過來轉：dy/dx = 1/(dx/dy) = 1/x。

```
(ln x)′ = 1/x            配鏈鎖法則：(ln(x² + 1))′ = 2x/(x² + 1)
```

圖的意思：ln x 一直在爬，但越爬越平；x = 1 時斜率 1，x = 10 時只剩 0.1。對數「把大數字壓扁」的能力，就寫在它的導數裡。

### 高階導數與加速度

導數 f′ 自己也是函數，可以再微分一次，得到二階導數（Second Derivative），記作 f″(x) 或 d²y/dx²。對運動來說：位置 s(t) 微分是速度 v = s′，速度再微分是加速度 a = v′ = s″。

**例子**：s(t) = t³ − 6t² + 9t（公尺，t 秒）。
- v(t) = 3t² − 12t + 9
- a(t) = 6t − 12

| t | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 位置 s | 0 | 4 | 2 | 0 | 4 |
| 速度 v | 9 | 0 | −3 | 0 | 9 |
| 加速度 a | −12 | −6 | 0 | 6 | 12 |

t = 1 時速度 0（停下來準備倒退），加速度 −6（正被往回推）；t = 3 時再度停下，加速度 +6（正被往前推）。丟球的 s = 4.9t² 則是 v = 9.8t、a = 9.8，加速度固定，這就是重力加速度。

坐車的時候你感覺不到速度，只感覺得到加速度：車子起步你被壓進椅背、煞車你往前傾、等速行駛時就算時速 100 也像沒在動。所以「身體的感覺」讀的是二階導數，「窗外景物後退的快慢」讀的才是一階導數。雲霄飛車設計師真正在意的是 s″，而不是 s′，第 15 章的專題會回到這件事。

二階導數也描述圖形的「彎法」：f″ > 0 時 f′ 遞增，曲線像碗口朝上（凹向上）；f″ < 0 時像倒扣的碗。第 11 章判斷極值會用到。

### 隱函數微分簡介（選配）

圓 x² + y² = 25 不是「y = …」的形式，但仍然可以問斜率。把 y 看成 x 的函數，兩邊對 x 微分，y² 要用鏈鎖法則（外層平方、內層 y）：

```
2x + 2y × dy/dx = 0    →    dy/dx = −x/y
```

在點 (3, 4)：斜率 −3/4 = −0.75。檢查：圓心到 (3, 4) 的半徑斜率是 4/3，切線應該和它垂直，斜率是 −3/4。對了。這招叫隱函數微分（Implicit Differentiation），第 11 章的梯子問題會再用。

### 活動 10-2：方格紙上長大的長方形

**材料／工具**
- 方格紙、兩色的筆

**步驟**
1. 畫一個長 5 格、寬 3 格的長方形，面積 15 格。想像長每秒長 2 格、寬每秒長 1 格。
2. 畫出 1 秒後的長方形：長 7、寬 4，面積 28。用第一種顏色塗「右邊新增的長條」（3 × 2 = 6 格），第二種顏色塗「下面新增的長條」（5 × 1 = 5 格），右下角留白（2 × 1 = 2 格）。
3. 算一算：6 + 5 + 2 = 13 = 28 − 15。對了。
4. 現在把時間縮短成 0.1 秒：長變 5.2、寬變 3.1。右邊長條 3 × 0.2 = 0.6，下面長條 5 × 0.1 = 0.5，小角 0.2 × 0.1 = 0.02。面積每秒變化率 = (0.6 + 0.5 + 0.02)/0.1 = 11.2。
5. 再縮到 0.01 秒，算出變化率；比較它和乘積法則給的 f′g + fg′ = 2 × 3 + 5 × 1 = 11。

**你應該看到／得到**

| 時間間隔 | 右長條 | 下長條 | 小角 | 面積變化率 |
|---|---|---|---|---|
| 1 秒 | 6 | 5 | 2 | 13 |
| 0.1 秒 | 0.6 | 0.5 | 0.02 | 11.2 |
| 0.01 秒 | 0.06 | 0.05 | 0.0002 | 11.02 |
| → 0 | | | 消失 | 11 |

小角是兩個小量相乘，縮得比別人快，最後只剩兩條長條，這就是乘積法則只有兩項的原因。

**Python（Google Colab）：一次檢查四條公式**

```python
# 用數值微分檢查 sin、eˣ、ln x 的導數公式
# 在 Google Colab 貼上整段執行
import math

def central_diff(f, x, h=0.0001):
    # 中央差分：(f(x+h) − f(x−h)) / (2h)，h 取 0.0001 已經夠準
    return (f(x + h) - f(x - h)) / (2 * h)

print("檢查 d/dx sin x = cos x")
for x in [0, 0.5, 1, 1.5, 2, 2.5, 3]:
    # 左邊是數值算出的斜率，右邊是 cos x，看兩者是否一致
    print(f"x = {x:<4} 數值導數 = {central_diff(math.sin, x):8.4f}   cos x = {math.cos(x):8.4f}")

print()
print("檢查 d/dx eˣ = eˣ")
for x in [0, 1, 2]:
    # eˣ 的斜率應該等於它自己的高度
    print(f"x = {x}  數值導數 = {central_diff(math.exp, x):8.4f}   eˣ = {math.exp(x):8.4f}")

print()
print("檢查 d/dx ln x = 1/x")
for x in [0.5, 1, 2, 4, 10]:
    # ln x 的斜率應該是 1/x，x 越大越平
    print(f"x = {x:<4} 數值導數 = {central_diff(math.log, x):8.4f}   1/x = {1 / x:8.4f}")

print()
print("檢查鏈鎖法則：d/dx sin(2x) = 2 cos(2x)")
g = lambda x: math.sin(2 * x)
for x in [0, 0.5, 1]:
    # 外層 sin 的導數 cos，乘上內層 2x 的導數 2
    print(f"x = {x}  數值導數 = {central_diff(g, x):8.4f}   2cos(2x) = {2 * math.cos(2 * x):8.4f}")
```

## 常見錯誤與迷思

- **「(f × g)′ = f′ × g′。」** → (x² × x³)′ 會算成 6x³，但正確是 5x⁴ → 長方形長大時兩條長條都要算：f′g + fg′。
- **「(f/g)′ 的分子順序隨便。」** → 寫成 fg′ − f′g 會差一個負號 → 「上微下不微」在前面；或改用 f × g⁻¹ 配乘積與鏈鎖法則。
- **「(sin 2x)′ = cos 2x。」** → 忘了內層的齒輪 → 要乘內層導數 2，得 2 cos 2x；用 Desmos 畫 f′ 可以一眼抓到這種錯。
- **「(x²)′ = 2x，所以 (2ˣ)′ = x·2ˣ⁻¹。」** → 冪次公式只適用於「底數是變數、指數是常數」 → 指數函數要用 (aˣ)′ = aˣ ln a，(2ˣ)′ = 2ˣ × 0.693。
- **「(ln 2x)′ = 1/(2x)。」** → 鏈鎖法則給 (1/(2x)) × 2 = 1/x → 其實 ln 2x = ln 2 + ln x，常數 ln 2 微分是 0，所以答案和 ln x 一樣是 1/x。
- **「用角度算 sin 的導數也會是 cos。」** → 數值表會多出 0.01745 的因子 → 微積分裡的三角函數一律用弧度。
- **「速度是 0，加速度就是 0。」** → s = t³ − 6t² + 9t 在 t = 1 速度 0 但加速度 −6 → 速度和加速度是不同階的導數，球到最高點時速度 0、加速度仍是 −9.8。

1. 求導數：(1) x² sin x；(2) x eˣ；(3) (x² + 1)³；(4) cos(3x)。

<details><summary>參考答案</summary>

(1) 2x sin x + x² cos x（乘積法則）。

(2) 1·eˣ + x·eˣ = (x + 1)eˣ。

(3) 3(x² + 1)² × 2x = 6x(x² + 1)²（鏈鎖法則）。在 x = 1：6 × 4 = 24。

(4) −3 sin(3x)。

</details>

2. 求導數：(1) e^(−x²)；(2) ln(x² + 1)；(3) 2ˣ；(4) (2x + 3)/(x − 1)。

<details><summary>參考答案</summary>

(1) e^(−x²) × (−2x) = −2x e^(−x²)。在 x = 1：−2/e ≈ −0.7358。

(2) 2x/(x² + 1)。在 x = 2：4/5 = 0.8。

(3) 2ˣ ln 2 ≈ 0.693 × 2ˣ。在 x = 3：8 × 0.693 ≈ 5.545。

(4) 商法則：(2(x − 1) − (2x + 3)·1)/(x − 1)² = −5/(x − 1)²。

</details>

3. 阿姨的餅乾：單價 p(t) = 100 + 2t（元），銷量 q(t) = 400 + 30t（盒），t 是月數。(1) 寫出營收 R(t) = p(t)q(t) 並展開；(2) 直接微分展開式求 R′(t)；(3) 用乘積法則求 R′(t)，確認兩者一樣；(4) R′(0) 是多少？和開場表弟的估計比較。

<details><summary>參考答案</summary>

(1) R = (100 + 2t)(400 + 30t) = 40,000 + 3,000t + 800t + 60t² = 40,000 + 3,800t + 60t²。

(2) R′ = 3,800 + 120t。

(3) p′q + pq′ = 2(400 + 30t) + (100 + 2t)(30) = 800 + 60t + 3,000 + 60t = 3,800 + 120t。一樣。

(4) R′(0) = 3,800 元/月，正是表弟的估計。被他丟掉的 60 元藏在 60t² 裡，一個月後才貢獻 120t 中的一部分。

</details>

4. 用商法則證明 (tan x)′ = 1/cos²x。再用計算機（弧度）算 (tan 1.001 − tan 0.999)/0.002，和 1/cos²(1) 比較。

<details><summary>參考答案</summary>

tan x = sin x / cos x。商法則：(cos x · cos x − sin x · (−sin x))/cos²x = (cos²x + sin²x)/cos²x = 1/cos²x（用了 sin² + cos² = 1）。

數值：(tan 1.001 − tan 0.999)/0.002 ≈ 3.4255；1/cos²(1) = 1/0.2919 ≈ 3.4255。一致。

</details>

5. 一輛車的位置是 s(t) = 5t²（公尺）。(1) 求 v(t) 和 a(t)；(2) t = 2 時的速度與加速度；(3) 換成 s(t) = 2t³，加速度還是常數嗎？

<details><summary>參考答案</summary>

(1) v = 10t，a = 10。

(2) v(2) = 20 公尺/秒，a = 10 公尺/秒²。

(3) v = 6t²，a = 12t，不是常數，加速度本身還在增加（油門越踩越深）。

</details>

6. 水的溫度 T(t) = 20 + 60e^(−0.1t)（°C，t 分鐘）。(1) 求 T′(t)；(2) t = 0 和 t = 10 時的降溫速率各是多少？(3) 為什麼 T′ 永遠是負的，而且越來越接近 0？

<details><summary>參考答案</summary>

(1) T′ = 60 × (−0.1)e^(−0.1t) = −6e^(−0.1t)。

(2) T′(0) = −6 °C/分；T′(10) = −6e⁻¹ ≈ −2.21 °C/分。

(3) e^(−0.1t) 永遠是正的，前面乘 −6 所以永遠負（一直在降溫）；而 e^(−0.1t) → 0，所以降溫越來越慢，水溫往 20 °C（室溫）靠近但不會低於它。這是第 14 章牛頓冷卻定律。

</details>

7. （挑戰）用隱函數微分求橢圓 x²/16 + y²/9 = 1 在點 (2, 3√3/2 ≈ 2.598) 的切線斜率。

<details><summary>參考答案</summary>

兩邊對 x 微分：2x/16 + (2y/9) × dy/dx = 0，得 dy/dx = −(x/8) × (9/(2y)) = −9x/(16y)。

代入 (2, 2.598)：−18/(16 × 2.598) ≈ −0.433（精確值是 −√3/4）。

</details>

8. （開放挑戰）設 f(x) = sin x。算 f′、f″、f‴、f⁗（四階導數），你會發現什麼規律？第 100 階導數是什麼？再對 eˣ 和 e^(2x) 做同樣的事，說說它們有什麼不同。

<details><summary>參考答案</summary>

f′ = cos x、f″ = −sin x、f‴ = −cos x、f⁗ = sin x，每 4 次回到原點。100 是 4 的倍數，所以第 100 階導數就是 sin x 本身。

eˣ 微幾次都是 eˣ，每一階都不變。e^(2x) 每微一次多乘一個 2：第 n 階是 2ⁿe^(2x)，第 100 階是 2¹⁰⁰e^(2x)。sin 是「轉圈」型（四步一輪迴），eˣ 是「不動」型，e^(2x) 是「每步放大」型；這三種行為在第 14 章的微分方程裡分別對應振動、單純成長與加速成長。

</details>

## 本章小結
- 乘積法則 (fg)′ = f′g + fg′：長方形兩邊都在長，面積增加兩條長條，小角會消失。
- 商法則 (f/g)′ = (f′g − fg′)/g²，可由乘積法則推出，分子順序不能錯。
- 鏈鎖法則 dy/dx = dy/du × du/dx：變化率像齒輪比一層一層相乘；外層照微、內層保留、再乘內層導數。
- (sin x)′ = cos x、(cos x)′ = −sin x，用數值表、圖形與和角公式三種方式都能確認；一定用弧度。
- (eˣ)′ = eˣ，因為 e 是唯一讓 (aʰ − 1)/h → 1 的底數；一般的 (aˣ)′ = aˣ ln a。
- (ln x)′ = 1/x，因為 ln 是 eˣ 的反函數，齒輪倒過來轉。
- 二階導數 f″ 是導數的導數；位置 → 速度 → 加速度；f″ 的正負描述曲線向上凹或向下凹。
- 隱函數微分把 y 當成 x 的函數，對 y 的項用鏈鎖法則補上 dy/dx。
