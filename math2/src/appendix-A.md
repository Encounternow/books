# 附錄 A　公式速查

每一條公式附一個算例和一句「為什麼」。「為什麼」不是證明，是一句讓你記得住、能自己重建的直覺。忘了公式時，先想「為什麼」，通常就推得回來。

## A.1 函數（第 1、2 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| 一次函數 y = mx + b，斜率 m = Δy/Δx | 過 (1, 3) 和 (3, 7)：m = 4/2 = 2，y = 2x + 1 | 斜率是「x 每多 1，y 多多少」，b 是 x = 0 時的 y。 |
| 二次函數 y = ax² + bx + c，頂點 x = −b/(2a) | y = x² − 4x + 1：頂點 x = 2，y = −3 | 拋物線左右對稱，對稱軸在兩個根的正中間 −b/(2a)。 |
| 配方法 ax² + bx + c = a(x + b/(2a))² + (c − b²/(4a)) | x² − 4x + 1 = (x − 2)² − 3 | 把 x² + bx 補成完全平方，多補的減回來。 |
| 二次公式 x = (−b ± √(b² − 4ac)) / (2a) | x² − 5x + 6 = 0：x = (5 ± 1)/2 = 3 或 2 | 就是配方法解到底的結果。 |
| 判別式 b² − 4ac：> 0 兩根、= 0 一根、< 0 無實根 | x² + 1 = 0：0 − 4 < 0，無實根 | 根號裡面是負的就開不了根。 |
| 平移：y = f(x − h) + k 把圖往右 h、往上 k | y = (x − 2)² + 3 是 y = x² 右移 2、上移 3 | x 要先減 2 才等於原來的 x，所以整張圖晚了 2 才出現。 |
| 伸縮：y = a·f(x) 縱向拉 a 倍；y = f(bx) 橫向壓 b 倍 | y = 2 sin x 高度兩倍；y = sin 2x 週期一半 | 乘在外面改輸出，乘在裡面改輸入。 |
| 合成 (f∘g)(x) = f(g(x)) | f(x) = x², g(x) = x + 1：f(g(2)) = 9，g(f(2)) = 5 | 先做裡面的 g，再把結果餵給 f，順序不能換。 |
| 反函數：f(f⁻¹(x)) = x，圖形沿 y = x 對稱 | f(x) = 2x + 1，f⁻¹(x) = (x − 1)/2 | 反函數是「倒著做」：把 x 和 y 交換再解出 y。 |
| 絕對值 \|x\| = x（x ≥ 0）或 −x（x < 0） | \|−3\| = 3，y = \|x\| 是 V 形 | 距離不會是負的。 |

## A.2 指數與對數（第 3、4 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| aᵐ · aⁿ = aᵐ⁺ⁿ | 2³ · 2⁴ = 2⁷ = 128 | 3 個 2 相乘再乘 4 個 2，共 7 個。 |
| aᵐ / aⁿ = aᵐ⁻ⁿ | 2⁵ / 2² = 2³ = 8 | 5 個 2 消掉 2 個。 |
| (aᵐ)ⁿ = aᵐⁿ | (2³)² = 2⁶ = 64 | 「3 個 2」這包東西拿 2 包。 |
| a⁰ = 1，a⁻ⁿ = 1/aⁿ | 2⁻³ = 1/8 | 從 2³、2²、2¹ 每降一次除以 2，繼續降下去自然得到 1、1/2、1/4。 |
| a^(1/n) = ⁿ√a，a^(m/n) = ⁿ√(aᵐ) | 8^(2/3) = (³√8)² = 4 | 自己乘 n 次要變 a，就是 n 次方根。 |
| 指數成長／衰減 y = y₀ · rᵗ | 1000 元年利 5%，10 年：1000 × 1.05¹⁰ ≈ 1629 | 每段時間乘同一個倍數。 |
| 半衰期：y = y₀ · (1/2)^(t/T) | T = 5730 年，t = 11460：剩 1/4 | 每過一個 T 就減半。 |
| e ≈ 2.71828 = lim (1 + 1/n)ⁿ | n = 1000 時 ≈ 2.7169 | 利息切得無限細、連續複利的極限。 |
| 連續成長 y = y₀ eᵏᵗ | k = 0.05，t = 10：e^0.5 ≈ 1.649 | 瞬間成長率固定是 k 的結果。 |
| log_a x = y ⟺ aʸ = x | log₂ 8 = 3，因為 2³ = 8 | 對數就是問「要乘幾次」。 |
| log(xy) = log x + log y | log₁₀ 1000 = log 10 + log 100 = 1 + 2 | 乘法變加法，因為指數相乘時次方相加。 |
| log(x/y) = log x − log y | log₂(32/4) = 5 − 2 = 3 | 同上，除法變減法。 |
| log(xⁿ) = n log x | log₁₀ 10⁶ = 6 | n 個 x 相乘，次方加了 n 次。 |
| 換底 log_a x = ln x / ln a | log₂ 10 = 2.3026/0.6931 ≈ 3.32 | 兩邊都用 e 當尺來量，比例不變。 |
| ln eˣ = x，e^(ln x) = x | ln e³ = 3 | ln 和 eˣ 互為反函數。 |
| 解 aᵗ = b：t = ln b / ln a | 1.05ᵗ = 2：t = 0.6931/0.0488 ≈ 14.2 年 | 兩邊取 ln，次方掉下來。 |
| 對數刻度：每格乘 10 | 分貝、pH、芮氏規模 | 大範圍的數用「乘幾次 10」來畫才看得清。 |

## A.3 三角（第 5、6 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| sin θ = 對邊/斜邊，cos θ = 鄰邊/斜邊，tan θ = 對邊/鄰邊 | 3-4-5 三角形：sin = 3/5、cos = 4/5、tan = 3/4 | 相似三角形的比值固定，所以比值只跟角度有關。 |
| tan θ = sin θ / cos θ | tan 45° = (√2/2)/(√2/2) = 1 | 對/斜 ÷ 鄰/斜 = 對/鄰。 |
| sin² θ + cos² θ = 1 | sin 30° = 1/2，cos 30° = √3/2：1/4 + 3/4 = 1 | 畢氏定理，斜邊是 1。 |
| 特殊角：30°：(1/2, √3/2)；45°：(√2/2, √2/2)；60°：(√3/2, 1/2)（sin, cos） | sin 60° ≈ 0.866 | 正三角形對半切、正方形對角切。 |
| 弧度：π 弧度 = 180°，1 弧度 ≈ 57.3° | 90° = π/2，60° = π/3 | 弧度是「弧長 ÷ 半徑」，繞一圈是 2π。 |
| 弧長 s = rθ（θ 用弧度） | r = 5，θ = 2：s = 10 | 弧度的定義直接給出。 |
| 單位圓：(cos θ, sin θ) 是角 θ 對應的點 | θ = π：(−1, 0) | 把三角比從直角三角形推廣到任何角度。 |
| sin(−θ) = −sin θ，cos(−θ) = cos θ | sin(−30°) = −1/2 | 單位圓上下翻，y 變號 x 不變。 |
| sin(θ + 2π) = sin θ（週期 2π） | sin(13π/6) = sin(π/6) = 1/2 | 繞一圈回原點。 |
| 波 y = A sin(ωt + φ)：振幅 A、週期 2π/ω、頻率 ω/2π | y = 3 sin(4πt)：A = 3，週期 0.5，頻率 2 Hz | ω 越大，sin 跑完一圈需要的 t 越短。 |
| 反三角 arcsin(1/2) = 30°，arctan 1 = 45° | 樓高 10、距離 10：仰角 arctan 1 = 45° | 反過來問「哪個角的 sin 是 1/2」。 |
| 和角 sin(a + b) = sin a cos b + cos a sin b | sin 75° = sin 45° cos 30° + cos 45° sin 30° ≈ 0.966 | 兩個旋轉接起來（用單位圓可畫出）。 |
| 正弦定理 a/sin A = b/sin B = c/sin C | A = 30°，a = 5，B = 90°：b = 10 | 每邊都等於「它對角的 sin × 外接圓直徑」。 |
| 餘弦定理 c² = a² + b² − 2ab cos C | a = b = 1，C = 60°：c² = 1 | 畢氏定理的推廣，C = 90° 時最後一項是 0。 |

## A.4 數列與級數（第 7 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| 等差數列 aₙ = a₁ + (n − 1)d | 3, 7, 11, …：a₁₀ = 3 + 9 × 4 = 39 | 從第一項出發，走 n − 1 步，每步 d。 |
| 等差級數 Sₙ = n(a₁ + aₙ)/2 | 1 + 2 + … + 100 = 100 × 101/2 = 5050 | 頭尾配對，每對和一樣，共 n/2 對。 |
| 等比數列 aₙ = a₁ · rⁿ⁻¹ | 2, 6, 18, …：a₅ = 2 × 3⁴ = 162 | 從第一項出發乘 n − 1 次 r。 |
| 等比級數 Sₙ = a₁(1 − rⁿ)/(1 − r)（r ≠ 1） | 1 + 2 + 4 + … + 2⁹ = (1 − 2¹⁰)/(1 − 2) = 1023 | Sₙ − r·Sₙ 大部分項互相消掉，只剩頭尾。 |
| 無窮等比級數 S = a₁/(1 − r)（\|r\| < 1） | 1 + 1/2 + 1/4 + … = 1/(1 − 1/2) = 2 | rⁿ → 0，Sₙ 的公式少掉 rⁿ。 |
| 0.999… = 1 | 0.9 + 0.09 + … = 0.9/(1 − 0.1) = 1 | 無窮等比級數的和。 |
| Σ 記號 Σᵢ₌₁ⁿ aᵢ = a₁ + a₂ + … + aₙ | Σᵢ₌₁⁴ i² = 1 + 4 + 9 + 16 = 30 | 「把 i 從 1 跑到 n，每個 aᵢ 加起來」。 |
| Σ i = n(n+1)/2，Σ i² = n(n+1)(2n+1)/6 | n = 4：10，30 | 第一條是等差級數；第二條可以用堆積木或歸納法看出。 |
| 費波那契 Fₙ = Fₙ₋₁ + Fₙ₋₂，Fₙ₊₁/Fₙ → φ ≈ 1.618 | 1, 1, 2, 3, 5, 8, 13：13/8 = 1.625 | 遞迴定義；比值收斂到黃金比例，因為 φ 滿足 φ² = φ + 1。 |

## A.5 極限（第 8 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| lim (x→a) f(x) = L：x 越靠近 a，f(x) 越靠近 L | lim (x→2) (x² − 4)/(x − 2) = lim (x + 2) = 4 | 約分後靠近 2 的值趨近 4，雖然 x = 2 本身沒定義。 |
| 連續：lim (x→a) f(x) = f(a) | x² 處處連續；1/x 在 0 不連續 | 圖形畫得過去，不用抬筆。 |
| lim (x→∞) 1/x = 0 | x = 1000 時 0.001 | 分母越大，值越小。 |
| lim (x→0⁺) 1/x = +∞，lim (x→0⁻) 1/x = −∞ | x = 0.001 時 1000；x = −0.001 時 −1000 | 左右極限不同，所以在 0 沒有極限。 |
| lim (n→∞) (1 + 1/n)ⁿ = e | n = 1000000 時 ≈ 2.71828 | 連續複利的定義。 |
| lim (x→0) sin x / x = 1（x 用弧度） | x = 0.01 時 0.99998 | 小角度時 sin x ≈ x（弧長 ≈ 弦長）。 |
| lim (x→0) (1 − cos x)/x = 0 | x = 0.01 時 0.005 | 1 − cos x ≈ x²/2，比 x 小得多。 |
| 多項式比的極限（x→∞）看最高次 | lim (3x² + 1)/(x² + 5) = 3 | x 很大時低次項不重要。 |
| 夾擠：g ≤ f ≤ h 且 g、h 極限相同，則 f 也是 | −1/x ≤ sin x / x ≤ 1/x（x→∞）→ 0 | 被夾在中間沒地方去。 |

## A.6 導數表（第 9、10、11 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| 定義 f′(x) = lim (h→0) [f(x + h) − f(x)]/h | f = x²：[(x+h)² − x²]/h = 2x + h → 2x | 割線斜率在 h → 0 時變成切線斜率。 |
| (c)′ = 0 | (5)′ = 0 | 常數不變，變化率是 0。 |
| (xⁿ)′ = n xⁿ⁻¹ | (x³)′ = 3x²；(√x)′ = (1/2)x^(−1/2)；(1/x)′ = −1/x² | 展開 (x+h)ⁿ，h 的一次項係數是 n xⁿ⁻¹。 |
| (c·f)′ = c·f′，(f ± g)′ = f′ ± g′ | (3x² + 2x)′ = 6x + 2 | 變化率可以分開算、常數倍跟著放大。 |
| 乘積 (fg)′ = f′g + fg′ | (x² sin x)′ = 2x sin x + x² cos x | 長方形面積變化 = 長的變化×寬 + 長×寬的變化。 |
| 商 (f/g)′ = (f′g − fg′)/g² | (x/(x+1))′ = 1/(x+1)² | 乘積法則用在 f · g⁻¹。 |
| 鏈鎖 (f(g(x)))′ = f′(g(x)) · g′(x) | (sin(x²))′ = cos(x²) · 2x | 外面變化率乘裡面變化率，像齒輪比。 |
| (sin x)′ = cos x，(cos x)′ = −sin x | 在 x = 0：sin 的斜率是 1 | 單位圓上點的速度方向垂直於半徑。 |
| (tan x)′ = 1/cos² x = sec² x | 在 x = 0：1 | 用商法則對 sin/cos。 |
| (eˣ)′ = eˣ | 在 x = 1：e ≈ 2.718 | e 的定義就是「斜率等於自己高度」的底數。 |
| (aˣ)′ = aˣ ln a | (2ˣ)′ = 2ˣ × 0.693 | aˣ = e^(x ln a)，用鏈鎖法則。 |
| (ln x)′ = 1/x | 在 x = 2：0.5 | ln 是 eˣ 的反函數，斜率互為倒數。 |
| (log_a x)′ = 1/(x ln a) | (log₁₀ x)′ 在 x = 1：0.434 | 換底之後是 ln x / ln a。 |
| 二階導數 f″ = (f′)′；位置→速度→加速度 | s = t³：v = 3t²，a = 6t | 變化率的變化率。 |
| 遞增 f′ > 0，遞減 f′ < 0；極值在 f′ = 0 | x² − 4x：f′ = 2x − 4 = 0 → x = 2 最小 | 斜率正就往上走，斜率零是山頂或谷底。 |
| 凹向上 f″ > 0，凹向下 f″ < 0 | x³：f″ = 6x，x > 0 凹向上 | f″ 說斜率是在變大還是變小。 |
| 線性近似 f(x + h) ≈ f(x) + f′(x) h | √26 ≈ √25 + (1/10)(1) = 5.1（實際 5.099） | 在附近用切線代替曲線。 |
| 牛頓法 xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) | 解 x² = 2 從 1.5：1.5 − 0.25/3 = 1.4167 | 沿切線走到 x 軸，再從那裡重來。 |
| 相關變化率：對 t 微分，用鏈鎖 | V = (4/3)πr³，dV/dt = 4πr² · dr/dt | 每個隨時間變的量都帶一個 d/dt。 |

## A.7 積分表（第 12、13、14 章）

| 公式 | 算例 | 為什麼 |
|---|---|---|
| 定積分 ∫ₐᵇ f(x) dx = lim Σ f(xᵢ) Δx | ∫₀³ t² dt = 9（黎曼和收斂到 9） | 無限多個細長方形的面積和。 |
| 基本定理 ∫ₐᵇ f(x) dx = F(b) − F(a)，F′ = f | ∫₀³ t² dt = [t³/3]₀³ = 9 | 累積函數的變化率就是 f，所以累積量 = 反導數頭尾差。 |
| d/dx ∫ₐˣ f(t) dt = f(x) | d/dx ∫₀ˣ t² dt = x² | 面積增加的快慢等於曲線此刻的高度。 |
| ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C（n ≠ −1） | ∫ x² dx = x³/3 + C | 微分回去：(n+1)xⁿ/(n+1) = xⁿ。 |
| ∫ 1/x dx = ln\|x\| + C | ∫₁ᵉ 1/x dx = 1 | (ln x)′ = 1/x。 |
| ∫ eˣ dx = eˣ + C，∫ eᵏˣ dx = eᵏˣ/k + C | ∫₀¹ e^(2x) dx = (e² − 1)/2 ≈ 3.19 | 微分 eᵏˣ 會多乘 k，所以除回去。 |
| ∫ cos x dx = sin x + C，∫ sin x dx = −cos x + C | ∫₀^π sin x dx = 2 | sin 的導數是 cos；cos 的導數是 −sin，所以要補負號。 |
| ∫ k dx = kx + C；∫ (f ± g) = ∫ f ± ∫ g；∫ k·f = k ∫ f | ∫₀² (3x² + 1) dx = 8 + 2 = 10 | 和的反導數是反導數的和。 |
| ∫ₐᵇ f = −∫ᵦₐ f；∫ₐᵃ f = 0；∫ₐᵇ + ∫ᵦᶜ = ∫ₐᶜ | ∫₀³ x² = ∫₀¹ + ∫₁³ = 1/3 + 26/3 = 9 | 面積可以拆開加、反向走變號。 |
| 代換 ∫ f(g(x)) g′(x) dx = ∫ f(u) du，u = g(x) | ∫₀¹ 2x e^(x²) dx = ∫₀¹ eᵘ du = e − 1 | 鏈鎖法則倒過來；上下限也要換成 u 的。 |
| 分部 ∫ f g′ dx = f g − ∫ f′ g dx | ∫ x eˣ dx = (x − 1)eˣ + C | 乘積法則倒過來。 |
| 兩曲線間面積 ∫ₐᵇ (上 − 下) dx | y = x 與 y = x²，[0, 1]：1/2 − 1/3 = 1/6 | 每條細長條的高是上減下。 |
| 旋轉體 V = ∫ₐᵇ π [f(x)]² dx | y = √x，[0, 4]：π ∫ x dx = 8π | 圓盤疊起來，每片 π r² × 厚。 |
| 平均值 (1/(b − a)) ∫ₐᵇ f dx | x² 在 [0, 3]：9/3 = 3 | 面積攤平成等寬長方形的高。 |
| 距離 = ∫ v dt；功 = ∫ F dx | ∫₀² 3t² dt = 8；∫₀^0.2 50x dx = 1 J | 變化率 × 小段累積。 |
| dy/dt = ky → y = y₀ eᵏᵗ | k = 0.0347，t = 60，y₀ = 100：800 | 導數是自己常數倍的函數只有指數。 |
| 牛頓冷卻 T = T環 + (T₀ − T環)e^(−kt) | 90°C → 25°C 室溫，k = 0.0368，t = 30：46.6 | 溫差滿足 dD/dt = −kD。 |
| 邏輯斯 dP/dt = rP(1 − P/K)，解是 S 形，上限 K | r = 0.5，K = 1000：第 10 天約 410 | 指數成長加「剎車」(1 − P/K)。 |
| 尤拉法 yₙ₊₁ = yₙ + h · f(tₙ, yₙ) | dy/dt = y，h = 0.1：十步得 2.594（e ≈ 2.718） | 每一小步把曲線當直線走。 |
| 梯形法 ≈ h[(f₀ + fₙ)/2 + f₁ + … + fₙ₋₁] | ∫₀¹ x² dx，n = 10：0.3350 | 每片用梯形代替長方形。 |
| 辛普森法 ≈ (h/3)[f₀ + 4f₁ + 2f₂ + 4f₃ + … + fₙ]，n 偶數 | ∫₀^π sin x dx，n = 10：2.00011 | 每兩片用拋物線代替曲線。 |
