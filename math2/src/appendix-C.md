# 附錄 C　常見錯誤總表

每一條都是「錯誤 → 正確 → 為什麼」。做題卡住、或答案和別人不一樣時，先來這裡對一下。括號裡是相關的章。

## 函數與代數（第 1、2 章）

1. **(x + y)² = x² + y²** → (x + y)² = x² + 2xy + y² → 把長 x + y 的正方形切開，中間有兩塊 xy 的長方形。代 x = y = 1 檢查：4 ≠ 2。
2. **√(a² + b²) = a + b** → 不能拆 → 3-4-5 三角形：√(9 + 16) = 5，不是 7。根號不能分配到加法。
3. **f(x + h) = f(x) + f(h)** → 一般不成立 → f(x) = x²：f(1 + 1) = 4，f(1) + f(1) = 2。只有一次函數過原點時才成立。
4. **f(2x) 是把圖「橫向拉長兩倍」** → 是橫向「壓縮」成一半 → 要讓 2x = 1，x 只要 0.5，原本在 1 發生的事提早在 0.5 發生，圖變窄。
5. **y = f(x − 3) 是向左移 3** → 向右移 3 → x 要先減 3 才和原來一樣，所以整張圖「晚」3 才出現，往右移。
6. **二次函數頂點在 x = −b/a** → x = −b/(2a) → 對稱軸在兩根中間，兩根的和是 −b/a，一半是 −b/(2a)。
7. **ax² + bx + c = 0 沒有實根就是「無解」** → 是沒有實數解，有兩個複數解 → 本書只談實數，但要知道「圖不碰 x 軸」才是意思。
8. **反函數就是 1/f(x)** → f⁻¹ 是「倒著做」的函數，不是倒數 → f(x) = 2x 的反函數是 x/2，不是 1/(2x)。
9. **定義域只要看式子有沒有錯** → 還要看實際情境 → 面積函數 A(x) = x(10 − x) 數學上 x 可以是任何數，但邊長要 0 < x < 10。

## 指數與對數（第 3、4 章）

10. **2³ × 2⁴ = 2¹²** → 2⁷ → 指數相乘時「次方相加」，3 個 2 再乘 4 個 2 是 7 個 2。(2³)⁴ 才是 2¹²。
11. **2⁻¹ 是負數** → 2⁻¹ = 1/2，正數 → 負指數是倒數，不是負號。
12. **x⁰ = 0** → x⁰ = 1（x ≠ 0） → x³/x³ = x⁰，而任何數除以自己是 1。
13. **指數成長「每年加固定的量」** → 每年「乘」固定的倍數 → 5% 複利是每年乘 1.05，不是加 5。十年是 1.05¹⁰ ≈ 1.63，不是 1.5。
14. **log(a + b) = log a + log b** → log(ab) = log a + log b → 對數把「乘」變「加」，不是把「加」變「加」。log(1 + 1) = 0.301 ≠ 0 + 0。
15. **log(x²) = (log x)²** → log(xⁿ) = n log x → log(100²) = 4，(log 100)² = 4 剛好一樣是巧合；log(10²) = 2，(log 10)² = 1 就不一樣了。
16. **log 0 = 0** → log 0 沒有定義 → 10 的幾次方會是 0？沒有。x → 0⁺ 時 log x → −∞。
17. **ln 和 log 一樣** → ln 是以 e 為底，log 通常以 10 為底（計算機上），數學書的 log 有時指 ln → 看清楚底數。ln 10 ≈ 2.30，log₁₀ 10 = 1。
18. **分貝加倍就是聲音能量加倍** → 分貝是對數刻度，+10 dB 是能量 10 倍，+3 dB 才是 2 倍 → 對數刻度每「加一格」是「乘一個倍數」。

## 三角（第 5、6 章）

19. **sin(2θ) = 2 sin θ** → sin(2θ) = 2 sin θ cos θ → sin 不是線性函數。sin 60° ≈ 0.866，2 sin 30° = 1。
20. **sin⁻¹ x = 1/sin x** → sin⁻¹ 是反正弦（arcsin），1/sin 寫成 csc → 符號很糟但已經約定俗成。arcsin(1/2) = 30°，1/sin 30° = 2。
21. **計算機模式搞混（DEG／RAD）** → 用角度就切到 DEG，用弧度（微積分一律用弧度）就切到 RAD → sin 30 在 DEG 是 0.5，在 RAD 是 −0.988。
22. **(sin x)′ = cos x 在「角度」制也對** → 只在弧度制成立 → 角度制下 (sin x°)′ = (π/180) cos x°。這是微積分用弧度的理由。
23. **tan 90° = 無限大** → tan 90° 沒有定義 → cos 90° = 0，不能除以 0。接近 90° 時 tan 趨近 +∞（從左邊）或 −∞（從右邊）。
24. **sin θ 最大是 1，所以 3 sin θ 最大也是 1** → 最大是 3 → 振幅 A 把整個波縱向拉 A 倍。
25. **y = sin(2t) 週期是 4π** → 週期是 π → 週期 = 2π/ω，ω 越大週期越短。

## 數列與極限（第 7、8 章）

26. **無窮多個正數加起來一定是無限大** → 可能收斂 → 1 + 1/2 + 1/4 + … = 2。但 1 + 1/2 + 1/3 + … 真的發散。要看項縮小得夠不夠快。
27. **0.999… 比 1 小一點點** → 0.999… = 1 → 無窮等比級數 0.9/(1 − 0.1) = 1；或者 x = 0.999…，10x − x = 9，x = 1。
28. **lim (x→a) f(x) 就是 f(a)** → 只有 f 在 a 連續時才相等 → (x² − 4)/(x − 2) 在 x = 2 沒定義，但極限是 4。
29. **極限「永遠到不了」所以不算真的等於** → 極限是一個確定的數 → 「越來越接近 L，想多近就多近」就定義為等於 L，這不是近似。
30. **1/x 在 x = 0 的極限是無限大** → 左右極限不同（−∞ 和 +∞），所以極限不存在 → 要分左右。1/x² 的話兩邊都是 +∞。
31. **(1 + 1/n)ⁿ 當 n → ∞ 時，1/n → 0，所以答案是 1ⁿ = 1** → 答案是 e ≈ 2.718 → 底數趨近 1 和次方趨近 ∞ 在「拔河」，不能分開取極限。

## 微分（第 9、10、11 章）

32. **導數是「f(x + h) − f(x)」** → 要除以 h 再取極限 → 導數是斜率，是「變化量 ÷ 間隔」，不是變化量本身。
33. **(x²)′ = x** → 2x → 次方拿下來當係數，次方減一。用定義算：[(x+h)² − x²]/h = 2x + h → 2x。
34. **(2ˣ)′ = x · 2ˣ⁻¹** → 2ˣ ln 2 → xⁿ 的規則是「變數在底」，aˣ 是「變數在次方」，完全不同的函數。
35. **(f·g)′ = f′·g′** → f′g + fg′ → (x · x)′ = (x²)′ = 2x，但 1 × 1 = 1。
36. **(sin(x²))′ = cos(x²)** → cos(x²) · 2x → 裡面是 x² 不是 x，鏈鎖法則要乘裡面的導數。
37. **(eˣ)′ = x eˣ⁻¹** → eˣ → e 是常數底，不是變數底。eˣ 的導數是自己。
38. **(ln x)′ = ln x / x 或 1/ln x** → 1/x → ln 是 eˣ 的反函數，斜率互為倒數：在 (a, ln a) 的斜率是 1/a。
39. **f′(a) = 0 就一定是極值** → 可能是「平台」 → x³ 在 0 的導數是 0，但不是極值。要看 f′ 左右有沒有變號。
40. **二階導數是導數的平方** → f″ = (f′)′，是導數再微分一次 → 位置 → 速度 → 加速度。
41. **切線只碰曲線一點** → 切線可能在別處再碰曲線 → 切線的定義是「在那一點斜率等於 f′」，不是「只碰一次」。
42. **dy/dx 是一個分數，可以隨便約分** → 它是一個符號，代表極限 → 鏈鎖法則 dy/dx = (dy/du)(du/dx) 看起來像約分是因為極限的性質，不是真的分數。
43. **最大最小問題只要令導數為 0** → 還要檢查端點與定義域 → 圍籬問題若限制 x ≤ 3，最大值可能在 x = 3 的端點，而不是導數為 0 的地方。
44. **數值微分的 h 越小越準** → 太小（< 1e-8）電腦捨入誤差會爆掉 → h = 1e-5 左右最好，用中央差分。

## 積分（第 12、13 章）

45. **∫ x² dx = x³** → x³/3 + C → 微分回去：(x³)′ = 3x²。次方加一後要除以新的次方。
46. **不定積分不用寫 + C** → 一定要 → x² 和 x² + 7 的導數都是 2x，反導數有無限多個。
47. **∫ 1/x dx = x⁰/0** → ln\|x\| + C → n = −1 時次方公式失效，這一條要另外記。
48. **∫ sin x dx = cos x** → −cos x + C → (cos x)′ = −sin x，要補負號才對。
49. **x 軸下方的面積也是正的** → 定積分裡是負的 → ∫₀³ (x² − 4) dx = −3。要「總面積」就分段取絕對值。
50. **黎曼和切 4 段算出的數就是定積分** → 那是近似，定積分是 n → ∞ 的極限 → 切 3 段右和是 14，真正是 9。
51. **dx 只是裝飾** → dx 是長方形的寬，也指明對哪個變數積分 → ∫ t² dt 和 ∫ t² dx 不一樣。
52. **代換後 dx 可以直接換成 du** → du = u′ dx，要有換算率 → u = x²，du = 2x dx；式子裡沒有 2x 就不能直接換。
53. **定積分代換後用原來的上下限** → 上下限要換成 u 的值 → ∫₀² 2x cos(x²) dx，u 從 0 到 4，不是 0 到 2。
54. **兩曲線間面積 = ∫ f − ∫ g，不管誰在上** → 要「上減下」，中途交叉要分段 → 下減上會得到負數。
55. **旋轉體體積 = ∫ π f(x) dx** → ∫ π [f(x)]² dx → 圓盤面積是 π r²，半徑要平方。
56. **函數的平均值 = (f(a) + f(b))/2** → (1/(b − a)) ∫ₐᵇ f dx → 頭尾平均只用了兩個點。x² 在 [0, 3] 平均是 3，不是 4.5。
57. **微積分基本定理只是「積分和微分互逆」的口訣** → 它的內容是「累積函數的變化率等於被累積的函數」 → 面積增加的速度等於曲線此刻的高度，這才是為什麼。
58. **辛普森法 n 可以是奇數** → n 必須是偶數 → 每兩段配一條拋物線。n 奇數時程式會算錯而不報錯。

## 微分方程（第 14 章）

59. **dy/dt = ky 的解是 y = kt + C** → y = y₀ eᵏᵗ → 變化率「正比於 y 自己」才長出指數；dy/dt = k（常數）的解才是直線。
60. **冷卻是「每分鐘降固定度數」** → 溫差以固定比例遞減 → 直線模型會降到零下；牛頓冷卻永遠不低於室溫。
61. **擬合 ln(T − T環) 的斜率就是 k** → 斜率是 −k → ln D = ln D₀ − kt。
62. **尤拉法算出來就是正確答案** → 是近似，步長越小越準 → dy/dt = y 用 h = 0.1 得 2.594，真正是 2.718。步長減半檢查答案有沒有變。
63. **邏輯斯成長就是指數成長** → 有上限 K，成長率被 (1 − P/K) 剎住 → 開頭像指數，長期是平的 S 形。

## 工具與測量（各章）

64. **試算表公式往下拉時，常數格也跟著跑了** → 常數格要加 $（如 `$E$2`） → 不加的話 E2 會變 E3、E4。
65. **Python 用 `^` 當次方** → 要用 `**` → `2^3` 在 Python 是位元運算，等於 1。
66. **Python 的 `math.log(100)` 是 2** → 是 ln 100 ≈ 4.605 → 10 為底要用 `math.log10`。
67. **Desmos 的 sin 用角度** → 預設是弧度 → 右上角設定可以切換，畫 sin(x) 時一定要確認。
68. **量花瓶時用外直徑** → 要扣掉玻璃厚度用內半徑 → 外徑算出來的體積會偏大 10% 以上。
69. **實驗數據和模型不合就刪掉那幾點** → 保留並討論 → 不合的點往往是最有價值的（模型失效的地方）。
70. **報告裡只放算出來的數字，不放單位** → 每個數字都要有單位 → 「k = 0.0368」沒有意義，「k = 0.0368 每分鐘」才有。
