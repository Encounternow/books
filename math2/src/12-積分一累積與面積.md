# 第 12 章　積分一累積與面積

## 本章目標
- 學完你會說出「速度曲線下面的面積就是走過的距離」，並解釋為什麼。
- 學完你會用長方形（黎曼和）逼近曲線下的面積，而且知道把長方形切細，答案會越來越準。
- 學完你會看懂並寫出定積分記號 ∫ₐᵇ f(x) dx，說出每一個符號的意思。
- 學完你會找簡單函數的反導數（xⁿ、常數、和差），並用它算定積分。
- 學完你會用「累積函數的變化率就是原函數」這句話，解釋微積分基本定理為什麼成立。

## 開場：碼表壞了，但速度表還在

小芸騎腳踏車去圖書館，碼表的「里程」顯示壞掉了，但「速度」還能看。她每隔一分鐘瞄一眼速度表，記下來：第 1 分鐘大約 12 公里／小時，第 2 分鐘 15，第 3 分鐘 18，後來遇到上坡掉到 9……這樣一路記了 20 分鐘。

回家後她想：「我到底騎了幾公里？」里程表壞了，但她有每一分鐘的速度。她先想到國小的公式：距離 = 速度 × 時間。可是速度一直在變，哪一個速度才對？

她試著這樣算：第 1 分鐘速度 12 公里／小時，一分鐘是 1/60 小時，所以第 1 分鐘大約走了 12 × 1/60 = 0.2 公里。第 2 分鐘 15 × 1/60 = 0.25 公里。每一分鐘各算一塊，20 塊加起來，就是總距離。

她又想：「如果我每 10 秒看一次速度，算出來會不會更準？」會。每 1 秒看一次呢？更準。看得越密，答案越接近真正的里程。

這個「切成很多小段、每段用當時的速度乘時間、全部加起來」的想法，就是這一章的主角：**積分**。它和第 9 章的微分剛好是相反的方向：微分是「從距離看速度」，積分是「從速度拼回距離」。

## 核心概念

### 速度曲線下的面積就是距離

先從最簡單的情形開始。一輛車以固定速度 10 公尺／秒跑 4 秒，距離是 10 × 4 = 40 公尺。把速度畫成圖，橫軸是時間 t（秒），縱軸是速度 v（公尺／秒），圖形是一條水平線。

```
 v (m/s)
 10 ┼──────────────────┐
    │▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│   長方形：寬 4、高 10
    │▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│   面積 = 40 = 距離
  0 ┼──────────────────┼──► t (s)
    0                  4
```

距離 40 正好是水平線下方那個長方形的面積：寬是時間 4，高是速度 10。**「速度 × 時間」在圖上就是「寬 × 高」。**

再來一個速度會變的例子。一台玩具車從靜止開始，速度 v(t) = 2t（公尺／秒），也就是每秒增加 2 公尺／秒。4 秒後走了多遠？

圖形是一條從原點出發的斜線，4 秒時高度是 8。斜線下方是一個三角形，底 4、高 8，面積 = ½ × 4 × 8 = 16。所以 4 秒走了 16 公尺。你可以用「平均速度」驗算：速度從 0 均勻增加到 8，平均是 4，4 × 4 = 16，一樣。

```
 v
  8 ┼              ╱│
    │           ╱▒▒│
  4 ┼        ╱▒▒▒▒▒│   三角形面積 = ½ × 4 × 8 = 16
    │     ╱▒▒▒▒▒▒▒▒│
  0 ┼──╱───────────┼──► t
    0      2       4
```

這是整章最重要的一句話：**速度曲線下面的面積，就是走過的距離。** 為什麼？因為把時間切成很多小段，每一小段「速度 × 小段時間」是一個細長方形的面積，全部加起來既是總距離，也是曲線下方的總面積。

這個想法不只用在速度和距離：

| 縱軸是什麼 | 橫軸是什麼 | 曲線下面積是什麼 |
|---|---|---|
| 速度（公尺／秒） | 時間（秒） | 距離（公尺） |
| 水龍頭流量（公升／分） | 時間（分） | 流進桶子的水量（公升） |
| 用電功率（瓦） | 時間（小時） | 用電量（瓦小時） |
| 每天賣出的杯數（杯／天） | 天 | 總共賣出的杯數 |

共同的模式是：**縱軸是「每單位橫軸的變化率」，面積就是「累積的總量」。**

### 曲線彎了怎麼辦：黎曼和

長方形和三角形的面積我們會算，但如果速度曲線是彎的呢？例如 v(t) = t²，從 t = 0 到 t = 3。曲線下方是一個一邊彎彎的區域，沒有現成公式。

辦法就是小芸的辦法：**切成很多直條，每一條用長方形代替，全部加起來。** 這種和叫**黎曼和（Riemann Sum）**，Riemann 是提出這個想法的德國數學家。

先切 3 段，每段寬 1。每一條長方形要多高？有幾種取法：

- **左和**：用每段左端點的高度。三段的左端點是 t = 0、1、2，高度是 0、1、4。面積 = (0 + 1 + 4) × 1 = 5。
- **右和**：用右端點 t = 1、2、3，高度 1、4、9。面積 = (1 + 4 + 9) × 1 = 14。
- **中點和**：用中點 t = 0.5、1.5、2.5，高度 0.25、2.25、6.25。面積 = (0.25 + 2.25 + 6.25) × 1 = 8.75。

```
 v = t²                    右和（3 段）
  9 ┼                      ┌───┐
    │                      │▒▒▒│
    │                      │▒▒▒│
  4 ┼              ┌───┐   │▒▒▒│
    │              │▒▒▒│   │▒▒▒│   每條長方形的高
  1 ┼      ┌───┐   │▒▒▒│   │▒▒▒│   = 該段右端點的 t²
  0 ┼──────┴───┴───┴───┴───┴───┴──► t
    0      1       2       3
```

左和 5 太小（長方形都在曲線下面，少算了），右和 14 太大（長方形凸出曲線，多算了）。真正的面積一定夾在 5 和 14 中間。中點和 8.75 比較接近，但也不一定剛好。

### 加密：用表格看收斂

切 3 段太粗了。把每段再對半切，變成 6 段，每段寬 0.5。左和的六個高度是 0、0.25、1、2.25、4、6.25，加起來 13.75，乘以寬 0.5 得 6.875。右和是 11.375。繼續對半切下去，下面這張表是用 Python 算的（程式在「用工具看看」）：

| 段數 n | 每段寬 | 左和 | 右和 | 中點和 |
|---|---|---|---|---|
| 3 | 1 | 5.0000 | 14.0000 | 8.7500 |
| 6 | 0.5 | 6.8750 | 11.3750 | 8.9375 |
| 12 | 0.25 | 7.9062 | 10.1562 | 8.9844 |
| 24 | 0.125 | 8.4453 | 9.5703 | 8.9961 |
| 48 | 0.0625 | 8.7207 | 9.2832 | 8.9990 |
| 96 | 0.03125 | 8.8599 | 9.1411 | 8.9998 |
| 192 | 0.015625 | 8.9298 | 9.0704 | 8.9999 |

看出來了嗎？左和從下面往上爬，右和從上面往下降，兩邊越夾越緊，中點和早就停在 9 附近不動了。段數每加倍，左和右和的差距就減半（14 − 5 = 9，11.375 − 6.875 = 4.5，2.25，1.125……）。當 n 趨近無限大，三個和都趨近同一個數：**9**。

這就是第 8 章學的極限。曲線 v = t² 從 0 到 3 下方的面積是 9，也就是說，速度是 t² 的東西，3 秒走了 9 公尺。

### 定積分的定義與記號 ∫

數學家把「黎曼和在段數趨近無限大時的極限」取了名字，叫**定積分（Definite Integral）**，記號是：

> ∫₀³ t² dt = 9

每個符號都有意思：

- **∫** 是一個拉長的 S，代表 Sum（和）。它在提醒你：這是「很多小東西加起來」。
- **0 和 3** 寫在 ∫ 的下面和上面，是**積分下限**與**積分上限**，說明從哪裡加到哪裡。
- **t²** 是被加的東西的「高」，叫**被積函數（Integrand）**。
- **dt** 是每一小條的「寬」，是 Δt 在無限細的時候的寫法。它也告訴你哪個字母是變數。

所以 ∫₀³ t² dt 讀作「t² 從 0 到 3 的積分」，意思是「把 t² × dt 這些細長方形，從 t = 0 加到 t = 3」。用 Σ 記號寫出來就是：

> ∫ₐᵇ f(x) dx = lim (n→∞) Σ f(xᵢ) Δx，其中 Δx = (b − a)/n

第 7 章的 Σ 是「有限個加起來」，∫ 是「無限多個無限小的加起來」。兩個記號長得像，是故意的。

### 面積可以是負的

如果函數在某段是負的呢？例如 f(x) = x² − 4，在 0 ≤ x < 2 時 x² − 4 小於 0，圖形在 x 軸下方。黎曼和的「高」f(xᵢ) 是負數，乘上正的寬，每條長方形貢獻負值。所以 **x 軸下方的面積，在定積分裡算成負的**。

```
      y = x² − 4
  5 ┼                    ╱
    │                  ╱ ▒ ← 2 到 3 之間：正，面積 7/3
  0 ┼────────────────╱────► x
    │╲    ▒▒▒▒     ╱  2   3
 −4 ┼  ╲▒▒▒▒▒▒▒╱      ← 0 到 2 之間：負，面積 −16/3
    0      1    2
```

∫₀³ (x² − 4) dx = (−16/3) + (7/3) = −3。負號的意思是「下方的部分比上方多」。如果問的是「圖形和 x 軸之間總共圍了多大的面積」，就要分段算，再把絕對值加起來：16/3 + 7/3 = 23/3。

用速度來想很自然：速度是負的代表往回走，距離的「淨變化」當然要扣掉。「淨距離」用定積分，「總路程」要把負的翻正。

### 反導數與不定積分

每次都切無限多個長方形再取極限，太累了。我們需要捷徑，捷徑的關鍵是第 9 章的導數。

想一個問題：哪個函數的導數是 2x？你會說 x²，因為 (x²)′ = 2x。x² + 1 也行，x² − 100 也行，因為常數的導數是 0。這種「微分之後變成 f 的函數」叫 f 的**反導數（Antiderivative）**，也叫**原函數**。

反導數記作 ∫ f(x) dx，沒有上下限，叫**不定積分（Indefinite Integral）**。因為差一個常數都算，答案要加 **+ C**：

> ∫ 2x dx = x² + C

從第 9 章的導數公式反過來讀，就得到基本的積分公式：

| 導數公式（第 9 章） | 反過來讀 | 算例 |
|---|---|---|
| (xⁿ⁺¹)′ = (n+1)xⁿ | ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C（n ≠ −1） | ∫ x² dx = x³/3 + C |
| (kx)′ = k | ∫ k dx = kx + C | ∫ 5 dx = 5x + C |
| (f + g)′ = f′ + g′ | ∫ (f + g) dx = ∫ f dx + ∫ g dx | ∫ (x + 1) dx = x²/2 + x + C |
| (k·f)′ = k·f′ | ∫ k·f dx = k ∫ f dx | ∫ 6x² dx = 6 · x³/3 = 2x³ + C |

xⁿ 的規則記成口訣：「**次方加一，再除以新的次方**」。檢查方法永遠是微分回去：(x³/3)′ = 3x²/3 = x²，對了。

### 微積分基本定理：累積函數的變化率就是原函數

現在把兩件事接起來。定積分是「曲線下的面積」，反導數是「微分之後變回原來的函數」，它們看起來八竿子打不著，但其實是同一件事。這就是**微積分基本定理（Fundamental Theorem of Calculus）**。

先做一個具體的例子。定義一個「累積函數」：

> A(x) = ∫₀ˣ t² dt = 「v = t² 這條曲線，從 0 到 x 下方的面積」

A(x) 隨 x 變大而變大，因為面積越累積越多。我們剛才算過 A(3) = 9。用同樣的方法（或者先相信後面的公式）可以算出 A(1) = 1/3、A(2) = 8/3。看起來 A(x) = x³/3。

重點問題來了：**A(x) 的變化率是多少？** 也就是 A′(x) 是什麼？

想像 x 從 2 走到 2.01。面積多了一條很窄的長方形：寬是 0.01，高大約是曲線在 x = 2 的高度，也就是 2² = 4。所以面積大約增加 4 × 0.01 = 0.04。變化率 ≈ 0.04 / 0.01 = 4。用 A(x) = x³/3 實際算：A(2.01) − A(2) = 2.70687 − 2.66667 = 0.04020，除以 0.01 得 4.02，很接近 4。步長越小，越接近 4，而 4 正是 x = 2 時曲線的高度 x²。

```
            y = t²
            ╱
          ╱ ┃   ← 新增的細長條：高 ≈ f(2) = 4，寬 = Δx
        ╱▒▒▒┃
      ╱▒▒▒▒▒┃      A(x + Δx) − A(x) ≈ f(x) · Δx
    ╱▒▒▒▒▒▒▒┃      所以  A′(x) = f(x)
 ───┴───────┴┴──► t
    0        2 2.01
```

這就是基本定理的直覺：**累積函數的變化率，就是正在被累積的那個函數本身。** 面積增加得快慢，取決於曲線此刻有多高。寫成式子：

> 若 A(x) = ∫ₐˣ f(t) dt，則 A′(x) = f(x)

換句話說，**面積函數 A 是 f 的反導數**。這一步把「面積」和「反導數」綁在一起了。

### 用基本定理算定積分

既然 A 是 f 的一個反導數，而任何反導數 F 都和 A 只差一個常數，F(x) = A(x) + C。那麼：

> F(b) − F(a) = (A(b) + C) − (A(a) + C) = A(b) − A(a) = A(b) − 0 = ∫ₐᵇ f(x) dx

常數 C 自己消掉了。這就是計算定積分的捷徑：

> **∫ₐᵇ f(x) dx = F(b) − F(a)，其中 F 是 f 的任何一個反導數。**

常常寫成 [F(x)]ₐᵇ，意思是「把 b 代進去，減掉把 a 代進去」。

回到開頭的 ∫₀³ t² dt。反導數 F(t) = t³/3，所以答案是 F(3) − F(0) = 27/3 − 0 = 9。和切 192 段的黎曼和一致，但只花了一行。

再算幾個：

- ∫₁³ (2x + 1) dx = [x² + x]₁³ = (9 + 3) − (1 + 1) = 10。
- ∫₀⁴ (8 − 2t) dt = [8t − t²]₀⁴ = (32 − 16) − 0 = 16。一台車速度從 8 開始每秒減 2，4 秒剛好停下，走了 16 公尺。
- ∫₁⁴ √x dx = ∫₁⁴ x^(1/2) dx = [x^(3/2) / (3/2)]₁⁴ = (2/3)(8 − 1) = 14/3。

基本定理的意義是：**要算累積的總量，不必真的一小塊一小塊加，只要找到「變化率是它」的那個函數，看頭尾差多少。** 從速度拼回距離，只需要找到「導數是速度」的那個位置函數。

## 動手做

### 活動 12-1：方格紙數格子算面積

**材料／工具**：一張方格紙（文具店的 0.5 公分方格就好）、鉛筆、尺、計算機。

**步驟**：
1. 在方格紙上畫座標軸。讓 1 單位 = 2 公分 = 4 格，也就是 1 平方單位 = 4 × 4 = 16 格。
2. 畫 y = x² 從 x = 0 到 x = 2 的曲線。先列點：x = 0、0.5、1、1.5、2 時 y = 0、0.25、1、2.25、4，再多補幾個點（x = 0.25 時 y = 0.0625，x = 1.25 時 y ≈ 1.56，x = 1.75 時 y ≈ 3.06），用平滑的線連起來。
3. 數曲線下方、x = 0 到 2 之間的格子。完整在裡面的格子算 1 格；被曲線切過的格子，看起來超過一半算 1 格，不到一半算 0 格（或者認真一點估 0.5）。
4. 把格數除以 16，就是面積（平方單位）。
5. 用基本定理算正確答案：∫₀² x² dx = [x³/3]₀² = 8/3 ≈ 2.667 平方單位 ≈ 42.7 格。

**你應該看到／得到**：數出來大約 40 到 45 格，除以 16 大約 2.5 到 2.8，和 2.667 相差不到 10%。切過的格子估得越仔細，越接近。

**觀察與記錄**：

| 項目 | 數值 |
|---|---|
| 完整格子數 | |
| 切過的格子數（算一半） | |
| 總格數（完整 + 切過 ÷ 2） | |
| 面積 = 總格數 ÷ 16 | |
| 正確答案 8/3 ≈ 2.667 | |
| 誤差百分比 | |

如果你想再做一次，換 y = 4 − x² 從 0 到 2（答案 16/3 ≈ 5.33，約 85 格），看誤差是不是也在 10% 內。

### 活動 12-2：用水桶流量算累積水量

**材料／工具**：一個有刻度的大水桶或大量杯（至少 2 公升）、一個 500 mL 的量杯、手機碼表、水龍頭、紙筆。

**步驟**：
1. 把水龍頭開到一個固定位置，用 500 mL 量杯接水，用碼表量裝滿要幾秒。例如 10 秒裝滿，流量就是 500 ÷ 10 = 50 mL／秒 = 3 公升／分。
2. 現在開始「變化的流量」實驗。請一個人負責轉水龍頭、一個人負責計時和記錄。把水龍頭對準大水桶，每隔 30 秒換一次水量：第 1 個 30 秒開小、第 2 個 30 秒開中、第 3、4 個開大、第 5 個開中、第 6 個開小。每一段都要在開始時先用量杯量一下這個開度的流量（量 5 秒就好，再換算）。
3. 把每段的「流量（mL／秒）× 30 秒」算出來，就是這一段流進去的水量。
4. 六段加起來，是你「用積分」算出的總水量。
5. 看大水桶的刻度，讀出實際的總水量。

**你應該看到／得到**：計算的總水量和桶子刻度相差通常在 10% 到 15% 內。差距主要來自換開度的那幾秒流量不穩，以及量 5 秒的誤差。把「流量 × 時間」畫成長條圖，六根長條的總面積就是水量，這正是一個六段的黎曼和。

**觀察與記錄**：

| 時段 | 開度 | 量杯 5 秒接到（mL） | 流量（mL／秒） | 這段水量 = 流量 × 30（mL） | 累積水量（mL） |
|---|---|---|---|---|---|
| 0–30 秒 | 小 | | | | |
| 30–60 秒 | 中 | | | | |
| 60–90 秒 | 大 | | | | |
| 90–120 秒 | 大 | | | | |
| 120–150 秒 | 中 | | | | |

### 用 Python 算黎曼和看收斂

打開 Google Colab（colab.research.google.com），新增筆記本，貼上這段程式，按執行。它會算出本章那張收斂表。

```python
# 黎曼和：用長方形逼近 v(t) = t² 在 0 到 3 之間的面積
def v(t):
    return t ** 2          # 速度函數，可以換成任何你想算的函數

def riemann(f, a, b, n, kind):
    # f 是函數，[a, b] 是區間，n 是切成幾段，kind 是取左、右或中點
    dt = (b - a) / n       # 每一段的寬度
    total = 0
    for i in range(n):
        if kind == "左":
            t = a + i * dt           # 左端點
        elif kind == "右":
            t = a + (i + 1) * dt     # 右端點
        else:
            t = a + (i + 0.5) * dt   # 中點
        total += f(t) * dt           # 長方形面積 = 高 × 寬，累加
    return total

# 段數每次加倍，看三種黎曼和往哪裡靠近
print("  n     左和      右和      中點和")
for n in [3, 6, 12, 24, 48, 96, 192]:
    L = riemann(v, 0, 3, n, "左")
    R = riemann(v, 0, 3, n, "右")
    M = riemann(v, 0, 3, n, "中")
    print(f"{n:4d}  {L:8.4f}  {R:8.4f}  {M:8.4f}")
print("真正的面積 = 3³/3 =", 3 ** 3 / 3)
```

## 常見錯誤與迷思

- **「積分就是算面積」** → 面積只是積分的一種圖像。積分真正的意思是「把變化率累積成總量」：速度累積成距離、流量累積成水量、功率累積成用電量。面積是因為「高 × 寬」剛好對應「變化率 × 時間」。
- **「黎曼和就是答案」** → 黎曼和只是近似。切 3 段的右和 14 和真正的 9 差很遠。定積分是黎曼和在 n → ∞ 的極限。寫作業時切 4 段算出的數字，要說「大約」。
- **「圖形在 x 軸下方的部分不算」或「下方的面積也是正的」** → 定積分裡 x 軸下方的部分算負值。∫₀³ (x² − 4) dx = −3。要「總面積」就得分段取絕對值。
- **「∫ x² dx = x³」** → 忘了除以新的次方。微分回去檢查：(x³)′ = 3x²，不是 x²。正確是 x³/3 + C。
- **「不定積分不用寫 + C」** → 反導數有無限多個，彼此差一個常數。x² 和 x² + 7 的導數都是 2x。定積分時 C 會消掉所以不用寫，不定積分一定要。
- **「dx 只是裝飾」** → dx 是長方形的「寬」，沒有它，∫ f(x) 只有高沒有寬，面積算不出來。它也告訴你對哪個變數積分：∫ t² dt 和 ∫ t² dx 是不同的東西（後者把 t² 當常數）。
- **「微積分基本定理只是一個公式」** → 它是一個「為什麼」：面積函數的變化率等於曲線的高度，所以面積函數是反導數，所以面積可以用反導數的頭尾差算出來。記得那條細長條的圖，就記得為什麼。

2. 玩具車速度 v(t) = 3t（公尺／秒），從 t = 0 到 t = 4，用三角形面積算距離，再用基本定理驗算。

<details><summary>參考答案</summary>

4 秒時速度是 12，三角形底 4 高 12，面積 ½ × 4 × 12 = 24 公尺。基本定理：∫₀⁴ 3t dt = [3t²/2]₀⁴ = 3 × 16/2 − 0 = 24。一致。

3. 用 n = 4 的左和與右和估 ∫₀² x² dx，說出真正答案被夾在哪兩個數之間，再用基本定理算出正確值。

<details><summary>參考答案</summary>

每段寬 0.5。左端點 0、0.5、1、1.5，高度 0、0.25、1、2.25，左和 = 3.5 × 0.5 = 1.75。右端點 0.5、1、1.5、2，高度 0.25、1、2.25、4，右和 = 7.5 × 0.5 = 3.75。真正答案在 1.75 和 3.75 之間。基本定理：[x³/3]₀² = 8/3 ≈ 2.667，確實在中間。

4. 算下列定積分：(a) ∫₀² (x² + 1) dx　(b) ∫₁² (1/x²) dx　(c) ∫₀¹ (4x³ − 2x) dx

<details><summary>參考答案</summary>

(a) [x³/3 + x]₀² = 8/3 + 2 = 14/3 ≈ 4.667。

(b) 1/x² = x⁻²，反導數是 x⁻¹/(−1) = −1/x。[−1/x]₁² = (−1/2) − (−1) = 1/2。

(c) [x⁴ − x²]₀¹ = (1 − 1) − 0 = 0。圖形在 0 到 1 之間有一段在 x 軸下、一段在上，剛好抵消。

5. 一輛車的速度是 v(t) = 20 − 2t（公尺／秒），t 從 0 到 10 秒。(a) 它什麼時候停下來？(b) 停下來之前走了多遠？(c) 如果繼續算到 t = 15，∫₀¹⁵ v dt 是多少？這個數字代表什麼？

<details><summary>參考答案</summary>

(a) 20 − 2t = 0，t = 10 秒。

(b) ∫₀¹⁰ (20 − 2t) dt = [20t − t²]₀¹⁰ = 200 − 100 = 100 公尺。

(c) [20t − t²]₀¹⁵ = 300 − 225 = 75。10 秒之後速度是負的（往回走），10 到 15 秒倒退了 25 公尺，所以 15 秒時離起點只有 75 公尺。總路程是 100 + 25 = 125 公尺，但淨位移是 75 公尺。

</details>

6. 設 A(x) = ∫₀ˣ (2t + 1) dt。(a) 直接算出 A(x) 的式子。(b) 求 A′(x)。(c) 用「細長條」的圖解釋為什麼 A′(x) 就是 2x + 1。

<details><summary>參考答案</summary>

(a) A(x) = [t² + t]₀ˣ = x² + x。

(b) A′(x) = 2x + 1。

(c) x 往右移一小步 Δx，面積多了一條寬 Δx、高約 2x + 1 的細長條，面積增加約 (2x + 1)Δx，所以變化率 A′(x) = 2x + 1，正好是曲線在 x 的高度。這就是微積分基本定理。

</details>

7. （挑戰）一條河的流量 Q(t)（立方公尺／秒）在一天中的變化可以近似成 Q(t) = 30 + 10 sin(πt/12)，t 是小時，0 ≤ t ≤ 24。(a) 不用積分，猜一天流過的總水量大約是多少（提示：sin 在一整個週期的平均是多少？）。(b) 用試算表或 Python 切 24 段的中點和驗證你的猜測。(c) 如果有人說「流量最大時是 40，所以一天最多流 40 × 86400 立方公尺」，這句話哪裡有問題？

<details><summary>參考答案</summary>

(a) sin(πt/12) 的週期是 24 小時，正負剛好抵消，平均 0，所以平均流量是 30 立方公尺／秒。一天 86400 秒，總水量 ≈ 30 × 86400 = 2,592,000 立方公尺。

(b) 中點和會得到非常接近 2,592,000 的值（中點和對正弦這種對稱曲線特別準）。

(c) 那是「上限」，不是實際值。流量不是一直都是 40，只有一瞬間是 40。實際總量是曲線下的面積，等於平均流量乘時間，不是最大流量乘時間。

</details>

## 本章小結

- 速度曲線下方的面積就是距離。更一般地說，**變化率曲線下的面積 = 累積的總量**。
- 曲線彎了就切成長方形來加，這叫黎曼和。左和偏小、右和偏大（遞增時），中點和通常最準。
- 把段數加倍再加倍，黎曼和會收斂到一個固定值，這個極限就是定積分 ∫ₐᵇ f(x) dx。
- ∫ 是拉長的 S（和），a、b 是從哪加到哪，f(x) 是高，dx 是寬。
- x 軸下方的部分在定積分裡是負的；要總面積就分段取絕對值。
- 反導數 F 是「微分之後變成 f」的函數，要加 + C。xⁿ 的反導數是 xⁿ⁺¹/(n+1)。
- 微積分基本定理：累積函數 A(x) = ∫ₐˣ f(t) dt 的變化率就是 f(x)，所以 ∫ₐᵇ f(x) dx = F(b) − F(a)。
- 面積函數的變化率就是曲線的高度，這句話是整個定理的核心，記住那條細長條。
