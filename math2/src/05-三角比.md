# 第 5 章　三角比

## 本章目標

- 學完你會說出 sin、cos、tan 是直角三角形裡「兩邊的比值」，並解釋為什麼同一個角度的比值永遠一樣（相似三角形）。
- 學完你會不查表就寫出 30°、45°、60° 的三角比，並知道它們是從正方形和正三角形切出來的。
- 學完你會只用一支量角器（或手機）和一把捲尺，量出樹、大樓、旗竿的高度與河的寬度。
- 學完你會用反三角比（sin⁻¹、cos⁻¹、tan⁻¹）從「已知兩邊」反推出角度，例如算出樓梯或斜坡的傾斜角。
- 學完你會在角度與弧度之間換算，知道 π/6 就是 30°，以及為什麼數學家偏愛弧度。

## 開場：不爬上去，怎麼知道大樓有多高？

小宇家對面有一棟新大樓，他和表妹打賭它有幾層樓高。表妹說用數窗戶的，小宇說那不準，每層樓高度又不一樣。兩個人站在馬路對面想辦法，身上只有一支手機和一條 5 公尺的捲尺，大樓當然不可能讓他們拿捲尺去爬。

表妹忽然想到以前學過的影子法：「量影子長度，再量我的影子，用比例算。」好主意——但那天陰天，沒有影子。

小宇想到另一件事：手機裡有一個「水平儀」App，可以顯示手機傾斜的角度。他把手機舉到眼前，對準大樓的頂端，螢幕上顯示 35°。然後他用捲尺一段一段量出自己距離大樓底部是 20 公尺。

「現在怎麼辦？我有一個角度、一段距離，要算高度。」

這就是這一章的問題。古埃及人用它算金字塔、航海家用它算離岸多遠、測量員用它畫地圖、天文學家用它算月亮有多遠。工具只有一個：直角三角形裡，**角度決定了邊長的比例**。這個比例有名字，叫做**三角比（Trigonometric Ratio）**。學完這章，你會算出那棟大樓大約 15.5 公尺高，而且不需要任何人讓你上去量。

## 核心概念

### 相似三角形：角度一樣，比例就一樣

先回到第一冊學過的一件事。兩個三角形如果三個角都相同，它們就是**相似三角形（Similar Triangles）**，形狀一樣、只是大小不同。而相似三角形的對應邊**成比例**。

現在只看直角三角形。直角三角形有一個 90°，三個角加起來 180°，所以你只要再決定一個角（例如 35°），第三個角就固定了（55°）。也就是說：**所有「有一個 35° 角」的直角三角形，全部彼此相似。**

```
           C                                          C'
           /|                                        /|
          / |                                       / |
         /  |                                      /  |
        /   | 對邊                                /   |
       /    | (opposite)                         /    |
      /     |                                   /     |
     /      |                                  /      |
    /       |                                 /       |
   / 35°    |                                / 35°    |
  A─────────B                               A'────────B'
      鄰邊 (adjacent)
  小三角形：AB = 10，BC = 7.0              大三角形：A'B' = 20，B'C' = 14.0
  BC ÷ AB = 0.700                          B'C' ÷ A'B' = 0.700  ← 一樣！
```

無論三角形畫多大，只要那個角是 35°，「對邊 ÷ 鄰邊」永遠是 0.700。這個數不屬於某個三角形，它屬於「35° 這個角」。這就是三角比的核心想法：**角度本身就帶著一組固定的比值。** 查出這組比值，你就能從一個角和一條邊，算出其他的邊。

### 三個比值：sin、cos、tan

在直角三角形裡，先選一個銳角 θ（唸「theta」，數學上常用來代表角度）。三條邊相對於 θ 各有名字：

- **斜邊（Hypotenuse）**：直角對面那條最長的邊。
- **對邊（Opposite）**：θ 對面的那條邊。
- **鄰邊（Adjacent）**：θ 旁邊、不是斜邊的那條邊。

三個三角比的定義：

> **sin θ** = 對邊 ÷ 斜邊　　（正弦，Sine）
> **cos θ** = 鄰邊 ÷ 斜邊　　（餘弦，Cosine）
> **tan θ** = 對邊 ÷ 鄰邊　　（正切，Tangent）

```
                    .
                   /|
                  / |
        斜邊     /  |
      (hyp)    /    |  對邊 (opp)
              /     |
             /      |
            / θ     |
           ─────────┘
            鄰邊 (adj)

   sin θ = opp / hyp     cos θ = adj / hyp     tan θ = opp / adj
```

背法：用英文字首「**SOH-CAH-TOA**」——Sin = Opposite/Hypotenuse、Cos = Adjacent/Hypotenuse、Tan = Opposite/Adjacent。唸起來像「搜卡托阿」，唸三遍就記住了。

用最有名的 3-4-5 直角三角形算一次。設 θ 是「對邊 3、鄰邊 4」的那個角，斜邊 5：

- sin θ = 3/5 = 0.6
- cos θ = 4/5 = 0.8
- tan θ = 3/4 = 0.75

這個角是多少度？按計算機（後面會教），約 36.87°。所以「sin 36.87° = 0.6」是一個永遠成立的事實，不管你畫的三角形是 3-4-5、6-8-10 還是 30-40-50。

三個比值不是獨立的。因為 tan = 對/鄰 = (對/斜) ÷ (鄰/斜)，所以 **tan θ = sin θ ÷ cos θ**（0.6 ÷ 0.8 = 0.75，對）。還有，畢氏定理說 對² + 鄰² = 斜²，兩邊都除以斜²，得到 **sin²θ + cos²θ = 1**（0.36 + 0.64 = 1，對）。這兩條關係以後常用。

### 三角比的表：從 0° 到 90°

下面是每 10° 的三角比（計算機算出，取 4 位小數）。先別背，先看趨勢。

| θ | sin θ | cos θ | tan θ |
|---|---|---|---|
| 0° | 0 | 1 | 0 |
| 10° | 0.1736 | 0.9848 | 0.1763 |
| 20° | 0.3420 | 0.9397 | 0.3640 |
| 30° | 0.5000 | 0.8660 | 0.5774 |
| 40° | 0.6428 | 0.7660 | 0.8391 |
| 45° | 0.7071 | 0.7071 | 1.0000 |
| 50° | 0.7660 | 0.6428 | 1.1918 |
| 60° | 0.8660 | 0.5000 | 1.7321 |
| 70° | 0.9397 | 0.3420 | 2.7475 |
| 80° | 0.9848 | 0.1736 | 5.6713 |
| 90° | 1 | 0 | （無定義） |

看出什麼？

1. **sin 從 0 爬到 1，cos 從 1 掉到 0**。角度越大，對邊越長、鄰邊越短。θ 接近 0° 時三角形扁到幾乎沒有對邊，θ 接近 90° 時幾乎沒有鄰邊。
2. **sin 和 cos 永遠不會超過 1**，因為斜邊是最長的邊，分子不可能比分母大。
3. **sin 20° = cos 70°，sin 40° = cos 50°**。因為直角三角形的兩個銳角互為餘角（加起來 90°），這個角的對邊就是那個角的鄰邊。「餘弦」的「餘」就是餘角的意思：cos θ = sin (90° − θ)。
4. **tan 可以多大就多大**。45° 時對邊等於鄰邊所以 tan = 1；80° 時 tan 已經 5.67；89° 時 57.3；90° 時鄰邊變 0，除以 0 沒有意義，所以 tan 90° 無定義。

### 30°、45°、60°：三個不用查表的角

這三個角的三角比可以直接從兩個基本圖形切出來，考試、工程、物理都常用。

**45° 來自正方形。** 邊長 1 的正方形沿對角線切開，得到兩個等腰直角三角形，兩股都是 1，斜邊由畢氏定理 √(1² + 1²) = √2。

```
        ┌───────┐
        │     ／│
        │   ／  │ 1          sin 45° = 1/√2 = √2/2 ≈ 0.7071
        │ ／45° │            cos 45° = 1/√2 = √2/2 ≈ 0.7071
        └───────┘            tan 45° = 1/1 = 1
            1
```

**30° 和 60° 來自正三角形。** 邊長 2 的正三角形從頂點往下切一刀到底邊中點，切出一個直角三角形：斜邊 2、底 1、高 √(2² − 1²) = √3。頂端的角是 30°、底角是 60°。

```
            /\
           /  \
        2 /    \ 2            從 30° 看：對邊 1、鄰邊 √3、斜邊 2
         /  30° \               sin 30° = 1/2         cos 30° = √3/2 ≈ 0.866    tan 30° = 1/√3 ≈ 0.577
        /   |    \            從 60° 看：對邊 √3、鄰邊 1、斜邊 2
       /    |√3   \             sin 60° = √3/2 ≈ 0.866  cos 60° = 1/2         tan 60° = √3 ≈ 1.732
      / 60° |      \
     ───────┴───────
         1     1
```

整理成一張表：

| θ | sin θ | cos θ | tan θ |
|---|---|---|---|
| 30° | 1/2 | √3/2 | 1/√3 = √3/3 |
| 45° | √2/2 | √2/2 | 1 |
| 60° | √3/2 | 1/2 | √3 |

小技巧：sin 的分子是 √1、√2、√3，分母都是 2；cos 倒過來。

### 用三角比量東西：知道角和一邊，算另一邊

回到開場。小宇站在離大樓 20 公尺處，手機對準樓頂量到 35°，眼睛離地 1.5 公尺。

```
                                    ▲ 樓頂
                                   /│
                                  / │
                                 /  │ h（眼睛以上的高度）
                                /   │
                               /    │
                              / 35° │
      眼睛 ●─────────────────────────┤ ← 和眼睛同高的水平線
            │        20 m           │
        1.5 │                       │
            │                       │
      ──────┴───────────────────────┴────── 地面
```

我們知道鄰邊（20 公尺）和角（35°），要求對邊 h。用 tan：

tan 35° = h ÷ 20 → h = 20 × tan 35° = 20 × 0.7002 ≈ 14.0 公尺

加上眼睛高度 1.5 公尺，大樓約 **15.5 公尺**。大約五層樓。

通用步驟：

1. 畫出直角三角形，標上已知的角、已知的邊、要求的邊。
2. 看已知邊和要求邊相對於那個角是「對、鄰、斜」的哪兩個，選對應的比值（對÷斜用 sin、鄰÷斜用 cos、對÷鄰用 tan）。
3. 寫出等式，移項，按計算機。

再一個：一座 4 公尺長的梯子靠在牆上，和地面夾 75°，梯子頂端離地幾公尺？已知斜邊 4、角 75°，求對邊 → sin 75° = h ÷ 4 → h = 4 × 0.9659 ≈ 3.86 公尺。梯腳離牆 = 4 × cos 75° = 4 × 0.2588 ≈ 1.04 公尺。

### 反三角比：知道兩邊，反推角度

反過來的問題：樓梯每階高 18 公分、深 28 公分，樓梯有多斜？

tan θ = 18 ÷ 28 = 0.643。現在要問「哪個角的 tan 是 0.643？」這和上一章對數的想法完全一樣：**從結果反推輸入**。這個反運算叫做**反正切（Arctangent）**，寫成 tan⁻¹ 或 arctan：

θ = tan⁻¹ (0.643) ≈ 32.7°

計算機上按 `SHIFT` + `tan`（或 `2nd` + `tan`），輸入 0.643，得到 32.7。同理有 sin⁻¹ 和 cos⁻¹。幾個例子：sin⁻¹ (0.5) = 30°、cos⁻¹ (0.5) = 60°、tan⁻¹ (1) = 45°、tan⁻¹ (2) ≈ 63.4°。

注意：tan⁻¹ 的「−1」**不是** 1/tan（倒數），它是「反函數」的記號，和上一章對數是指數的反函數一樣。這是最容易搞錯的地方。

道路標示的「坡度 10%」意思是每走 100 公尺水平距離上升 10 公尺，也就是 tan θ = 0.1，θ = tan⁻¹ (0.1) ≈ 5.7°。看起來很小，但騎腳踏車上去就知道了。無障礙坡道的規定是 1:12，θ = tan⁻¹ (1/12) ≈ 4.8°。

### 角度與弧度：另一種量角的方式

目前我們用「度」量角：一圈 360°。這是古巴比倫人的習慣，和數學本身沒有關係。數學家更喜歡另一種單位：**弧度（Radian）**。

定義：以角的頂點為圓心畫一個半徑 r 的圓，這個角「切出來」的弧長如果剛好等於 r，這個角就是 1 弧度。

```
                 ....
             .          .
           .     弧長 = r  .
          .   ╱╲           .
          .  ╱  ╲ 1 rad     .   ← 弧長剛好等於半徑時，圓心角 = 1 弧度 ≈ 57.3°
          . ╱    ╲          .
          .●──────●         .
          .   r             .
           .              .
             .          .
                 ....
```

一整圈的弧長是圓周 2πr，等於 2π 個半徑，所以 **360° = 2π 弧度**，180° = π 弧度。換算：

> 弧度 = 角度 × π ÷ 180　　角度 = 弧度 × 180 ÷ π

| 角度 | 弧度 | 小數 |
|---|---|---|
| 30° | π/6 | 0.5236 |
| 45° | π/4 | 0.7854 |
| 60° | π/3 | 1.0472 |
| 90° | π/2 | 1.5708 |
| 180° | π | 3.1416 |
| 360° | 2π | 6.2832 |
| 1 弧度 | 1 | 57.30° |

為什麼要多學一套單位？因為弧度讓很多公式變乾淨。例如半徑 r 的圓，θ 弧度的扇形弧長就是 **r × θ**（半徑 5 公分、60° = π/3 弧度，弧長 = 5 × π/3 ≈ 5.24 公分），用度數就得多乘一個 π/180。到第 10 章你會看到更重要的理由：只有用弧度，sin 的導數才會剛好是 cos。從下一章起本書會越來越常用弧度，所以現在先把 π/6、π/4、π/3、π/2 和 30°、45°、60°、90° 對起來。

**計算機的坑**：計算機有 DEG（度）和 RAD（弧度）模式。輸入 sin 30 在 DEG 模式得到 0.5，在 RAD 模式會得到 −0.988（因為它把 30 當成 30 弧度）。按出奇怪答案時，第一件事是看模式。

## 動手做

### 活動 5-1：自製量角器測高儀，量出大樓或大樹的高度

**材料／工具**：一支量角器（文具店的塑膠半圓量角器）、一根吸管、一段 30 公分的棉線、一個小重物（螺帽或迴紋針串）、膠帶、捲尺或步測、計算機、記錄用紙筆。要到戶外，請找大人一起。

**步驟**

1. 把吸管用膠帶貼在量角器的直邊上，當作瞄準器。在量角器直邊中點（0° 和 180° 中間、也就是圓心的位置）綁上棉線，另一端綁重物，讓線能自由垂下。
2. 拿著量角器，直邊朝上，透過吸管瞄準目標的頂端（樹梢或樓頂）。棉線會因為重力垂直向下，這時讀棉線壓在量角器上的刻度。
3. 棉線讀到的刻度減 90° 就是仰角 θ（吸管水平時線在 90°；往上抬 35°，線會指在 125° 或 55°，取和 90° 的差）。
4. 用捲尺量你站的位置到目標底部的水平距離 d。如果太長，先量你一步多長，再數步數。
5. 量你的眼睛離地高度 e（約身高減 10 公分）。
6. 高度 H = d × tan θ + e。
7. 換一個距離（例如遠一倍）再量一次，兩次算出的高度應該差不多。

**你應該看到／得到**：同一棵樹從 10 公尺和 20 公尺處量，角度會從大約 50° 降到大約 30°，但 d × tan θ 算出來的高度接近（差 1 公尺以內算成功）。如果差很多，通常是讀角度時手晃，或距離量錯。

**觀察與記錄**

| 目標 | 距離 d（m） | 仰角 θ | tan θ | d × tan θ | 眼高 e | 高度 H |
|---|---|---|---|---|---|---|
| | | | | | | |
| 同目標，距離加倍 | | | | | | |
| | | | | | | |

### 活動 5-2：用手機傾斜儀量斜坡、樓梯與屋頂的角度

**材料／工具**：手機（iPhone 內建「測距儀」App 裡的「水平儀」；Android 可搜尋免費的「水平儀」或「Clinometer」App）、捲尺、一塊平板或硬書當墊板。

**步驟**

1. 打開水平儀 App，把手機平放在桌上，確認讀數是 0°（有的 App 需要先校正）。
2. 找家裡的樓梯：把墊板斜放，同時碰到兩階的邊緣，再把手機放在墊板上，讀出角度 θ₁。
3. 用捲尺量一階的高（垂直）h 和深（水平）w，算 tan⁻¹ (h ÷ w)，記為 θ₂。比較 θ₁ 和 θ₂。
4. 再找三個斜的東西量：書架斜撐、腳踏車坡道、公園溜滑梯、屋頂斜面。每一個都「量角度」加「量兩邊算角度」各做一次。
5. 進階：量溜滑梯的滑面長度 L（斜邊）和角度 θ，算出它的垂直高度 L × sin θ，再實際用捲尺量高度驗證。

**你應該看到／得到**：樓梯大約 30°–35°（18 公分高、28 公分深的樓梯是 32.7°），兩種方法差在 2° 以內。溜滑梯的 L × sin θ 和實際量的高度相差應在 10 公分內。你會發現：三角比是「可以用尺驗證」的真實東西。

### 活動 5-3：用兩個角度量一條過不去的河（或馬路）的寬度

**材料／工具**：活動 5-1 的測高儀改成橫著用（或手機指南針 App 讀方位角）、捲尺、兩個標記物（石頭或背包）。

**步驟**

1. 站在河的這一岸（A 點），對岸選一個明顯目標 T（一棵樹）。讓 AT 垂直河岸——方法：面向 T 站好，左右各轉 90° 看，確認河岸在你正左右方。
2. 沿河岸走一段距離（例如 30 公尺）到 B 點，用捲尺量出 AB = d。
3. 在 B 點量「B 看 T」和「B 看 A」的夾角 θ（用手機指南針讀兩個方位角相減，或用量角器平放瞄準）。
4. 河寬 = AT = d × tan θ。

**你應該看到／得到**：如果 d = 30 公尺、θ = 50°，河寬 = 30 × 1.192 ≈ 35.8 公尺。拿到學校操場試：對面目標距離已知，看你量出來差幾公尺。

## 用工具看看

**GeoGebra（https://www.geogebra.org/geometry ）：親眼看到「同一角度，比值不變」**

1. 開啟「幾何」頁面。用「點」工具點出 A、B 兩點，用「線段」畫 AB。
2. 用「垂線」工具：點 B 再點線段 AB，畫出過 B 的垂線。在垂線上點一個 C，連 AC、BC。
3. 用「角度」工具點 B、A、C（順序：先點 B 再 A 再 C），顯示 ∠BAC。
4. 用「距離或長度」工具量 AB、BC、AC。
5. 在左邊的代數區輸入 `BC/AB`，它會顯示一個數字。

7. 在代數區輸入 `tan(角度名稱)`（例如 `tan(α)`），它和 BC/AB 永遠相同。

**Google 試算表：自己做一張三角比表**

## 常見錯誤與迷思

- **錯誤：sin 30 的「30」是長度** → sin 吃的是角度，輸出的是比值。sin 30° = 0.5 的意思是「30° 的直角三角形，對邊是斜邊的一半」。→ 三角比的輸入永遠是角，輸出永遠是一個沒有單位的比值。
- **錯誤：三角形變大，sin 也變大** → 相似三角形各邊同時放大，比值不變。→ sin、cos、tan 只跟角度有關，跟三角形大小無關。
- **錯誤：sin (A + B) = sin A + sin B** → sin 30° + sin 60° = 0.5 + 0.866 = 1.366，但 sin 90° = 1。→ 三角比不是乘法，不能把括號拆開（它有自己的和角公式，本書不需要）。
- **錯誤：tan⁻¹ x 就是 1/tan x** → tan⁻¹ 是「反正切」，從比值反推角度；1/tan 是倒數。tan⁻¹ (1) = 45°，1/tan (1°) = 57.3。→ 看到 sin⁻¹、cos⁻¹、tan⁻¹，一律讀成「哪個角的 sin（cos、tan）是這個數」。
- **錯誤：計算機算 sin 30 得到 −0.988，所以課本錯了** → 計算機在 RAD 模式，把 30 當成 30 弧度。→ 用度數時確認是 DEG 模式；試算表要先用 RADIANS() 換算。
- **錯誤：量樓高只要 d × tan θ 就好** → 你量的角是從眼睛出發，所以算出來的是「眼睛以上」的高度。→ 要加上眼睛離地的高度。
- **錯誤：cos 是「比較小的那個」** → 哪個大要看角度：θ < 45° 時 cos 比 sin 大，θ > 45° 時反過來。→ 不要用大小判斷，用「對邊還是鄰邊」判斷。

## 想一想

**1.** 一個直角三角形的兩股分別是 5 和 12。算出斜邊，再寫出「對邊是 5」那個角的 sin、cos、tan，並用計算機求這個角是幾度。

<details><summary>參考答案</summary>

斜邊 = √(5² + 12²) = √169 = 13。sin θ = 5/13 ≈ 0.385、cos θ = 12/13 ≈ 0.923、tan θ = 5/12 ≈ 0.417。θ = tan⁻¹ (5/12) ≈ 22.6°。驗算：sin²θ + cos²θ = 25/169 + 144/169 = 1。

</details>

**2.** 不查表、不用計算機，寫出 sin 60°、cos 45°、tan 30° 的精確值（含根號），並說明它們分別從哪個圖形切出來。

<details><summary>參考答案</summary>

sin 60° = √3/2（邊長 2 的正三角形切半：對邊 √3、斜邊 2）；cos 45° = √2/2（邊長 1 的正方形切半：鄰邊 1、斜邊 √2）；tan 30° = 1/√3 = √3/3（同正三角形，從 30° 看：對邊 1、鄰邊 √3）。

</details>

**3.** 小宇放風箏，線長 50 公尺，線和地面的夾角 60°（假設線是直的）。風箏離地多高？小宇手離地 1 公尺。

<details><summary>參考答案</summary>

已知斜邊 50 和角 60°，求對邊：h = 50 × sin 60° = 50 × 0.866 = 43.3 公尺，加上手的高度 1 公尺，風箏約 44.3 公尺高。

</details>

**4.** 一條直線上坡路，路牌寫「坡度 8%」。(a) 這條路和水平面的夾角是幾度？(b) 沿著這條路走 200 公尺（斜著走的距離），你會上升幾公尺？

<details><summary>參考答案</summary>

(a) tan θ = 0.08 → θ = tan⁻¹ (0.08) ≈ 4.57°。(b) 上升 = 200 × sin 4.57° ≈ 200 × 0.0797 ≈ 15.9 公尺。（用 tan 估：水平 200 × 0.08 = 16 公尺，因為角很小所以幾乎一樣。）

</details>

**5.** 一架飛機在 3000 公尺高度飛行。地面上的你仰頭看它的仰角是 25°。(a) 飛機在地面上的投影點離你多遠？(b) 飛機離你（直線距離）多遠？

<details><summary>參考答案</summary>

(a) 已知對邊 3000、角 25°，求鄰邊：d = 3000 ÷ tan 25° = 3000 ÷ 0.4663 ≈ 6434 公尺。(b) 求斜邊：L = 3000 ÷ sin 25° = 3000 ÷ 0.4226 ≈ 7099 公尺。驗算：6434² + 3000² ≈ 7099²（41.40 百萬 + 9 百萬 = 50.40 百萬，7099² ≈ 50.40 百萬），對。

</details>

**6.** 把下列角度換成弧度（用 π 表示），弧度換成角度：150°、240°、2 弧度、5π/6。另外：半徑 10 公分的圓，圓心角 2 弧度的弧長是多少？

<details><summary>參考答案</summary>

150° = 150π/180 = 5π/6 ≈ 2.618；240° = 4π/3 ≈ 4.189；2 弧度 = 2 × 180/π ≈ 114.6°；5π/6 = 150°（和第一個互相印證）。弧長 = r × θ = 10 × 2 = 20 公分（這就是弧度的好處：直接乘）。

</details>

**7.** 你想量一棟大樓的高度，但走不到它的正下方（中間隔著圍牆）。你站在 A 點量到樓頂仰角 20°，往大樓方向直走 40 公尺到 B 點，再量得仰角 35°。眼高 1.5 公尺。大樓多高？（提示：設 B 到大樓底的距離為 x，寫兩個 tan 等式。）

<details><summary>參考答案</summary>

設樓頂高於眼睛 h，B 到樓底 x。從 B：h = x × tan 35° = 0.7002x。從 A：h = (x + 40) × tan 20° = 0.3640(x + 40)。兩式相等：0.7002x = 0.3640x + 14.56 → 0.3362x = 14.56 → x ≈ 43.3 公尺。h = 0.7002 × 43.3 ≈ 30.3 公尺。加眼高：大樓約 31.8 公尺。這就是測量員「不用走到底下」的標準方法。

</details>

**8.（挑戰）** 西元前 240 年，埃拉托斯特尼（Eratosthenes）在埃及的賽伊尼（今亞斯文）發現夏至正午太陽直射井底，同一時刻在正北方約 800 公里的亞歷山卓，太陽光和垂直的柱子夾 7.2°。假設地球是圓的、太陽光是平行的，他怎麼算出地球的周長？算出來是多少？和今天知道的 40,000 公里比呢？

<details><summary>參考答案</summary>

太陽光平行，所以柱子和陽光的夾角 7.2° 就等於兩地相對地心的圓心角（內錯角相等）。7.2° 是一整圈 360° 的 1/50（360 ÷ 7.2 = 50），所以兩地的弧長 800 公里是周長的 1/50，周長 ≈ 800 × 50 = 40,000 公里。和現代的 40,075 公里幾乎一樣——用一根柱子和一口井，2200 年前就量出了地球。這題用的是弧度的想法：弧長 ÷ 周長 = 角 ÷ 360°。

</details>

## 本章小結

- 直角三角形裡，有一個銳角固定，所有這樣的三角形都相似，所以邊長的比值只跟角度有關。這個比值就是三角比。
- sin θ = 對/斜、cos θ = 鄰/斜、tan θ = 對/鄰（SOH-CAH-TOA）。tan = sin ÷ cos，sin² + cos² = 1。
- 30°、45°、60° 的值從正三角形和正方形切出來：sin 分別是 1/2、√2/2、√3/2，cos 倒過來，tan 是 1/√3、1、√3。
- 量高度：H = 距離 × tan（仰角）+ 眼高。知道角和一邊，就能算另一邊。
- 反三角比 sin⁻¹、cos⁻¹、tan⁻¹ 從比值反推角度；「−1」是反函數不是倒數。
- 弧度：弧長等於半徑時的角是 1 弧度 ≈ 57.3°；180° = π，30° = π/6，45° = π/4，60° = π/3，90° = π/2。弧長 = r × θ（θ 用弧度）。
- 計算機與試算表都要注意 DEG／RAD 模式；試算表要用 RADIANS() 和 DEGREES() 換算。
