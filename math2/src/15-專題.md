## 專題一：雲霄飛車設計

### 目標

- 用好幾段函數「拼」出一條雲霄飛車的軌道，讓接點處平滑（沒有折角）。
- 用導數判斷每一段的坡度和轉彎的急緩，用能量守恆估計每一點的速度。
- 算出乘客在最低點會感受到幾個「G」，判斷設計安不安全。
- 用紙板和彈珠做一條迷你軌道，看看彈珠會不會飛出去。

### 材料

- Desmos（desmos.com/calculator）。
- 瓦楞紙板或厚卡紙（至少 60 公分長）、美工刀、膠帶、幾顆彈珠、一條軟管或切半的水管（當軌道用，也可以用對摺的厚紙做 V 形槽）。
- 尺、量角器、手機（錄影用）。

### 步驟

**第一步：決定軌道的「骨架」。** 一座簡單的雲霄飛車至少有四段：上坡、翻過山頂、下坡、谷底再上去。我們先設計一條「教科書版」，然後你再改成自己的。

先定座標：橫軸 x 是水平距離，縱軸 y 是高度，**1 單位 = 5 公尺**。

- 第 1 段（上坡直線，0 ≤ x ≤ 4）：y₁ = 0.5x。斜率 0.5，爬到 x = 4 時高 2。
- 第 2 段（山頂，4 ≤ x ≤ 8）：y₂ = 2 + 0.5(x − 4) − 0.125(x − 4)²。這是一條開口向下的拋物線。
- 第 3 段（下坡直線，8 ≤ x ≤ 12）：y₃ = 2 − 0.5(x − 8)。
- 第 4 段（谷底，12 ≤ x ≤ 16）：y₄ = 0.125(x − 12)² − 0.5(x − 12)。開口向上的拋物線。

```
 y（1 單位 = 5 m）
 2.5┼           ╭─•─╮          ← 山頂 (6, 2.5)
 2  ┼         ╱       ╲
    │       ╱           ╲
 1  ┼     ╱               ╲
    │   ╱                   ╲
 0  •─╱───────────────────────╲─────────────•──► x
    0     4     6     8    12   ╲    14    ╱16
−0.5┼                             ╰───•───╯    ← 谷底 (14, −0.5)
```

**第二步：檢查接點平滑。** 兩段在接點要滿足兩件事：高度一樣（接得起來）、斜率一樣（沒有折角）。這是第 9 章導數的用處。

| 接點 | 左邊那段的 y 和 y′ | 右邊那段的 y 和 y′ | 平滑嗎 |
|---|---|---|---|
| x = 4 | y₁ = 2，y₁′ = 0.5 | y₂ = 2，y₂′ = 0.5 − 0.25(4 − 4) = 0.5 | 是 |
| x = 8 | y₂ = 2，y₂′ = 0.5 − 0.25 × 4 = −0.5 | y₃ = 2，y₃′ = −0.5 | 是 |
| x = 12 | y₃ = 0，y₃′ = −0.5 | y₄ = 0，y₄′ = 0.25 × 0 − 0.5 = −0.5 | 是 |

第 2 段的導數是 y₂′ = 0.5 − 0.25(x − 4)，在 x = 6 等於 0，那是山頂，高 2.5。第 4 段的導數是 y₄′ = 0.25(x − 12) − 0.5，在 x = 14 等於 0，那是谷底，高 −0.5。

**第三步：在 Desmos 畫出來。** 一行一個，用大括號限制範圍：

```
y = 0.5x {0 <= x <= 4}
y = 2 + 0.5(x-4) - 0.125(x-4)^2 {4 <= x <= 8}
y = 2 - 0.5(x-8) {8 <= x <= 12}
y = 0.125(x-12)^2 - 0.5(x-12) {12 <= x <= 16}
```

你應該看到一條連續、沒有尖角的軌道。試著把第 2 段的 −0.125 改成 −0.25，接點 x = 8 就會出現折角，因為斜率變成 −1.5 和 −0.5 對不上。

**第四步：算速度。** 假設車子在山頂 (6, 2.5) 幾乎靜止（速度 0），往下滑的過程不計摩擦，能量守恆給出：

> v = √(2 g h落差)，g = 9.8 公尺／秒²，h落差 = (2.5 − y) × 5 公尺

| 位置 | y（單位） | 落差（公尺） | v = √(2 × 9.8 × 落差) |
|---|---|---|---|
| 山頂 x = 6 | 2.5 | 0 | 0 |
| 接點 x = 8 | 2 | 2.5 | 7.0 m/s |
| 接點 x = 12 | 0 | 12.5 | 15.7 m/s |
| 谷底 x = 14 | −0.5 | 15 | 17.1 m/s（約 62 km/h） |

**第五步：算 G 力。** 在谷底，軌道是向上彎的，車子要被「推」著轉彎，乘客會覺得變重。感受到的重力倍數是：

> G = 1 + v² / (g R)，R 是那一點的「轉彎半徑」

拋物線 y = a x² 在頂點的轉彎半徑是 R = 1/(2a)。第 4 段在真實尺度下是 y = (0.125/5) X² = 0.025 X²（X 是公尺），所以 R = 1/(2 × 0.025) = 20 公尺。谷底 v = 17.1，G = 1 + 17.1² / (9.8 × 20) = 1 + 292/196 ≈ 2.5。乘客會覺得自己變成 2.5 倍重，這在真實的雲霄飛車是常見的範圍（通常 3 到 4 G 以內）。

山頂那一段是向下彎的，G = 1 − v²/(gR)。如果山頂速度是 0，G = 1；如果車子衝過山頂的速度夠快，G 會變負，乘客會被拋起來（這就是「失重」感）。

**第六步：做實體。** 用紙板做一個等比例縮小的軌道（例如 1 單位 = 5 公分），用軟管或 V 形紙槽當軌道，從山頂放彈珠。觀察彈珠在谷底有沒有飛出軌道，在接點有沒有跳動。用手機慢動作錄影，數彈珠通過 10 公分需要幾格影格，估算速度。

**你應該看到**：接點平滑的軌道上，彈珠會順順地滾過每個接點；如果你故意把第 2 段的係數改成 −0.25 做一條「有折角」的版本，彈珠經過 x = 8 時會明顯跳一下，甚至脫軌。谷底的實測速度大約是理論值 √(2gh) 的 80% 到 85%。

**第七步：設計自己的軌道。** 教科書版只是示範。你的軌道可以有兩個山峰、一個更深的谷、或一段長平路。規則只有三條：每個接點高度和斜率都要對上；每個谷底算 G 力，不要超過 4；每個山頂的 G 不要低於 0（否則乘客會飛出去，除非有安全壓桿）。先在紙上畫、再到 Desmos 調、最後用紙板做。

### 分析方法

- **平滑**：每個接點列出左右兩段的 y 和 y′，兩個都相等才平滑。有折角就要調整拋物線的係數。設計你自己的軌道時，一個簡單的方法是：直線段先定好，拋物線段寫成 y = y₀ + m(x − x₀) + a(x − x₀)²，其中 y₀ 和 m 是接點的高度和斜率（自動滿足左邊的條件），然後調 a 讓右邊的接點也對上。
- **速度**：v = √(2 g h落差)。Desmos 裡可以在軌道旁邊再畫一條 v(x) 的曲線：`sqrt(2*9.8*(2.5 - f(x))*5)`，把 f(x) 換成各段的式子。
- **轉彎急緩**：第 10 章的二階導數 y″ 代表「彎的程度」。拋物線 a x² 的 y″ = 2a 是常數，所以整段彎得一樣急。y″ 越大，R 越小，G 越大。直線的 y″ = 0，不轉彎，G = 1。
- **實測速度與理論的差**：彈珠會滾，一部分能量變成轉動，實際速度大約是理論的 85%（√(5/7) ≈ 0.845）。如果你量到的接近 85%，說明能量守恆加滾動修正是對的。

### 延伸

- 加一段「迴圈」：用半徑 R 的圓，進入迴圈的速度至少要 √(5gR) 才不會掉下來（頂點 G = 0 的條件）。算算看要從多高放才夠。
- 加摩擦：假設每公尺軌道損失 2% 的動能，用試算表一段一段扣，看谷底速度變成多少。
- 把第 2 段換成餘弦曲線 y = 2.25 + 0.25 cos(π(x − 6)/2)，檢查接點是否仍然平滑（提示：要算 cos 的導數。你會發現 x = 4 的高度接得上、斜率卻是 0 而不是 0.5，有折角。能不能把第 1 段也改成曲線，讓它平滑？）。
- 查一查真實雲霄飛車「迴旋飛車」的最高點與最低點高度差，估計最高速度，和官方數據比。

## 專題二：漏水的水桶

### 目標

- 量出一個底部打洞的寶特瓶，水位隨時間下降的曲線。
- 發現「水位高時漏得快、水位低時漏得慢」，寫出對應的微分方程 dh/dt = −k√h。
- 解出 h(t)，用實測數據擬合 k，並預測「漏完要多久」。
- 用積分從流量算回總水量，和瓶子的容量對照。

### 材料

- 一個 1.5 或 2 公升的圓形寶特瓶（截面是圓的那種，不要方的），把上面三分之一剪掉變成一個桶。
- 圖釘或小鑽子、尺、油性筆、手機碼表、量杯、水盆（接水用）、紙筆。
- 試算表或 Python（擬合用）。

### 步驟

1. 在瓶身距底部約 1 公分的側面用圖釘戳一個小洞（直徑約 2 到 3 毫米）。先用手指按住。
2. 用尺和油性筆在瓶身從洞的高度起每 1 公分畫一條刻度線，記為 h = 0、1、2、……直到 20 公分。
3. 量瓶子的內直徑 D（例如 8 公分），算截面積 A = π(D/2)²（例如 50.3 平方公分）。
4. 按住洞，裝水到 h = 20。
5. 放開手同時按碼表。每當水位經過一條刻度線（20、19、18、……），記下時間。一個人讀水位、一個人記時間。
6. 記到 h = 0（流不出來為止）。總時間記為 T。
7. 重複做一次，看兩次是否一致。

### 記錄表

| 水位 h（cm） | 第一次 t（秒） | 第二次 t（秒） | 平均 t | √h | 這 1 公分花的時間 Δt | 下降速率 −Δh/Δt（cm/s） |
|---|---|---|---|---|---|---|
| 20 | 0 | 0 | 0 | 4.47 | | |
| 19 | | | | 4.36 | | |
| 18 | | | | 4.24 | | |
| … | | | | | | |
| 1 | | | | 1.00 | | |
| 0 | | | | 0 | | |

瓶子資料：內直徑 D = ____ cm，截面積 A = ____ cm²，洞直徑 d ≈ ____ mm，總時間 T = ____ 秒。

### 分析方法

**第一步：看出規律。** 最後一欄「下降速率」在 h = 20 附近很大，在 h = 2 附近很小。把速率對 h 畫圖，不是直線，是彎的。把速率對 √h 畫圖，大約是直線。這就是**托里切利定律（Torricelli's Law）**：水從洞流出的速度是 √(2gh)，和「從 h 高處掉下來的速度」一樣。所以：

> dh/dt = −k √h

k 是個常數，和洞的大小、瓶子的粗細有關（理論上 k = (a/A)√(2g)，a 是洞的面積）。

**第二步：解這條微分方程。** 猜解的形式：如果 h = (c − bt)²，那 dh/dt = −2b(c − bt) = −2b√h。對照 dh/dt = −k√h，得 2b = k。而 t = 0 時 h = c² = h₀，所以 c = √h₀。解是：

> **h(t) = (√h₀ − kt/2)²**

這個解有一個漂亮的性質：**√h 隨時間直線下降**。所以用實測數據，把 √h 對 t 畫圖，應該是一條直線，斜率是 −k/2。

**第三步：擬合 k。** 最簡單：漏完時 h = 0，所以 √h₀ − kT/2 = 0，k = 2√h₀/T。例如 h₀ = 20、T = 120 秒，k = 2 × 4.472/120 = 0.0745。用這個 k 預測中間的水位：

| t（秒） | 預測 h = (4.472 − 0.0373 t)²（cm） |
|---|---|
| 0 | 20.0 |
| 30 | 11.25 |
| 60 | 5.0 |
| 90 | 1.25 |
| 120 | 0 |

注意：**時間過了一半，水只剩四分之一**（不是一半）。這是和直線模型最大的差別，也是你最容易驗證的預測。在試算表裡用 `=SLOPE(√h 那欄, t 那欄)` 可以得到更準的斜率，k = −2 × 斜率。

**第四步：用積分算總水量。** 流出的流量是 Q(t) = A × |dh/dt| = A k √h(t)（立方公分／秒）。總流出的水量 = ∫₀ᵀ Q dt。你可以用梯形法在試算表算，也可以直接想：總水量當然等於 A × h₀。例如 A = 50.3、h₀ = 20，是 1006 cm³ ≈ 1 公升。算出來如果一致，表示「流量積分 = 水量」這件事在真實世界成立。

**第五步（選配）：用 Python 尤拉法驗證解。** 把第 14 章的尤拉程式裡的變化率改成 `lambda t, h: -0.0745 * math.sqrt(max(h, 0))`，h₀ = 20，h（步長）= 1 秒，走 120 步。你會得到 t = 30 時 11.22、t = 60 時 4.95、t = 90 時 1.20，和公式解 11.25、5.0、1.25 幾乎一樣。

**你應該看到**：√h 對 t 的散佈圖幾乎是一條直線，但最後幾公分（h < 2）常常比直線預測的慢，因為水位很低時表面張力和洞口形狀的影響變大；這是討論誤差時最好的材料。半程時間的水位接近 h₀/4（例如 20 公分的四分之一是 5 公分），你可以當場用這個預測嚇一嚇旁邊的人。

**第六步：比較理論的 k。** 洞直徑 3 毫米，a = π × 0.15² = 0.0707 cm²；A = 50.3；k理論 = (0.0707/50.3) × √(2 × 980) = 0.0622。實際的 k 通常會比理論小一點（洞口的水流會收縮，叫收縮係數，約 0.6 到 0.8），所以實際漏完的時間比理論長。如果你量到的 k 是理論值的 60% 到 90%，是正常的。

### 延伸

- 換一個更大的洞（5 毫米），k 應該變成約 (5/3)² ≈ 2.8 倍，漏完的時間變成 1/2.8。驗證看看。
- 用方形瓶子重做，A 不同，k 會怎麼變？
- 如果同時用水龍頭以固定流量 Q進 補水，方程變成 dh/dt = Q進/A − k√h。水位會停在哪裡？（提示：dh/dt = 0。）用尤拉法模擬，再真的試試看。
- 古代的「水鐘」就是靠這個原理。想一想：為什麼水鐘的容器要做成特殊的曲線形狀，而不是直筒？（提示：要讓水位等速下降，容器的截面積要隨高度怎麼變？答案是 A ∝ √h。）

## 專題三：最省材料的包裝盒

### 目標

- 給定一張固定大小的厚紙，設計能裝最多東西的無蓋盒子。
- 給定要裝的體積，設計用最少材料的有蓋盒子與圓柱罐。
- 用導數找最佳尺寸，用試算表驗證，並實際做出來量材料。
- 比較真實商品（鋁罐、紙盒）和理論最佳值，討論為什麼廠商沒有照數學做。

### 材料

- 幾張 30 × 30 公分的厚紙或卡紙（或把更大的紙裁成這個尺寸）。
- 尺、鉛筆、美工刀或剪刀、膠帶。
- 米或綠豆（量容量用）、量杯、廚房秤。
- 一個 355 mL 的鋁罐飲料、一盒牛奶或果汁（紙盒）。
- 試算表、Desmos。

### 步驟

**問題 A：一張紙做最大的無蓋盒子。** 30 × 30 的紙，四個角各剪掉一個 x × x 的正方形，摺起來就是一個無蓋盒子，底是 (30 − 2x) × (30 − 2x)，高是 x。

```
  ┌──┬────────────┬──┐
  │剪│            │剪│   x
  ├──┼────────────┼──┤
  │  │            │  │
  │  │   底 面    │  │   30 − 2x
  │  │            │  │
  ├──┼────────────┼──┤
  │剪│            │剪│   x
  └──┴────────────┴──┘
   x     30 − 2x    x
```

1. 體積 V(x) = x(30 − 2x)²。先在試算表列 x = 1 到 14 的 V，看哪個最大。
2. 用導數算：V = x(30 − 2x)²，用乘積法則 V′ = (30 − 2x)² + x · 2(30 − 2x)(−2) = (30 − 2x)[(30 − 2x) − 4x] = (30 − 2x)(30 − 6x)。V′ = 0 → x = 15（體積 0，不要）或 **x = 5**。V(5) = 5 × 20² = 2000 cm³。
3. 做三個盒子：x = 3、x = 5、x = 7，分別裝滿米，倒進量杯量容量。

| x（cm） | 底邊 30 − 2x | V = x(30 − 2x)²（cm³） |
|---|---|---|
| 3 | 24 | 1728 |

## 專題四：用 Python 模擬投籃軌跡與最佳角度

### 目標

- 寫出投籃的運動方程（水平等速、垂直等加速度），用 Python 模擬球的軌跡。
- 對每個出手角度，找出「剛好進籃」需要的最小出手速度，找出最省力的角度。
- 加入空氣阻力（選配），看最佳角度和速度怎麼變。
- （選配）用手機錄影量自己投籃的出手速度與角度，和模擬比較。

### 材料

- Google Colab。
- 籃球、籃框（學校或公園）、手機（慢動作錄影）、捲尺。
- 罰球線到籃框中心的水平距離是 4.19 公尺（標準場），籃框高 3.05 公尺。你的出手高度自己量（本專題假設 2.0 公尺）。

### 步驟

**第一步：寫出沒有空氣阻力的公式。** 出手速度 v₀、角度 θ，水平速度 vₓ = v₀ cos θ 不變，垂直速度 v_y = v₀ sin θ − 9.8t。位置：

> x(t) = v₀ cos θ · t，　y(t) = 2.0 + v₀ sin θ · t − 4.9 t²

把 t = x/(v₀ cos θ) 代進 y，得到軌跡（一條拋物線，第 2 章）：

> y = 2.0 + x tan θ − 4.9 x² / (v₀² cos² θ)

要球到 x = 4.19 時 y = 3.05，解出 v₀：

> v₀² = 4.9 × 4.19² / (cos² θ × (4.19 tan θ − 1.05))

**第二步：列表看角度和速度的關係。** 用試算表或計算機（記得把角度換成弧度，第 5 章）：

| 角度 θ | 需要的 v₀（m/s，無阻力） |
|---|---|
| 35° | 8.24 |
| 40° | 7.71 |
| 45° | 7.40 |
| 50° | 7.26 |
| 52° | **7.25**（最小） |
| 55° | 7.28 |
| 60° | 7.44 |
| 65° | 7.79 |
| 70° | 8.38 |

最省力的角度大約是 52°，不是 45°。因為籃框比出手點高 1.05 公尺，最佳角度是 45° + ½ × arctan(1.05/4.19) ≈ 52°（這個公式用第 11 章的方法可以推出來）。也注意到 45° 到 60° 之間速度都差不到 3%，所以實際投籃選一個比較「穩」的角度比追求最省力重要。

**第三步：用 Python 模擬，加上空氣阻力。** 有阻力時沒有公式解，要用第 14 章的尤拉法一步一步走。球的加速度 = 重力 + 阻力，阻力和速度平方成正比、方向相反。籃球的阻力係數大約 0.012（每公尺）。在 Colab 貼上：

```python
import math

def shoot(v0, angle_deg, drag=0.0, dt=0.001):
    # 從 (0, 2.0) 出發（出手高度 2 公尺），回傳球飛到 x = 4.19 公尺時的高度
    th = math.radians(angle_deg)
    x, y = 0.0, 2.0
    vx, vy = v0 * math.cos(th), v0 * math.sin(th)
    while y >= 0:
        speed = math.hypot(vx, vy)
        ax = -drag * speed * vx            # 空氣阻力：與速度平方成正比、方向相反
        ay = -9.8 - drag * speed * vy      # 重力永遠往下 9.8
        x += vx * dt                       # 尤拉法：位置用速度更新
        y += vy * dt
        vx += ax * dt                      # 速度用加速度更新
        vy += ay * dt
        if x >= 4.19:                      # 到達籃框的水平距離就停
            return y
    return 0.0                             # 掉到地上都還沒到籃框

def needed_speed(angle_deg, drag=0.0):
    # 二分法：找出讓球剛好到達籃框高度 3.05 公尺的最小出手速度
    lo, hi = 5.0, 12.0
    for _ in range(40):
        mid = (lo + hi) / 2
        if shoot(mid, angle_deg, drag) < 3.05:
            lo = mid
        else:
            hi = mid
    return hi

print("角度   無阻力速度   有阻力速度 (m/s)")
best = None
for deg in range(35, 71, 5):
    v_free = needed_speed(deg)
    v_drag = needed_speed(deg, drag=0.012)
    print(f"{deg:3d}°   {v_free:7.3f}      {v_drag:7.3f}")
    if best is None or v_free < best[1]:
        best = (deg, v_free)
print("無阻力時最省力的角度大約是", best[0], "度")
```

無阻力的數值和公式算的一致（驗證了尤拉法）。有阻力時每個角度都要多 2% 左右的速度，最佳角度幾乎沒變。因為這段距離短、速度慢，空氣阻力影響不大；換成三分球（6.75 公尺）阻力就明顯了。

**你應該看到**：模擬出的最佳角度在 50° 到 52° 之間；把出手高度改成 2.3 公尺（高個子），最佳角度會降到 50° 左右；改成 1.7 公尺（小朋友），會升到 53° 以上。這說明每個人的「最佳角度」不同，取決於出手點和籃框的高度差。影片量出的出手速度通常在 7 到 8 公尺／秒之間，和模擬需要的 7.3 很接近。

### 分析方法

- **軌跡是拋物線**：把 t 消掉之後 y 是 x 的二次函數，第 2 章的頂點公式可以算出最高點。
- **最佳角度是最佳化問題**：v₀²(θ) 是 θ 的函數，求最小值就是第 11 章。你可以用 Desmos 畫 `f(t) = 4.9*4.19^2/(cos(t)^2*(4.19*tan(t)-1.05))`（t 用弧度，範圍 0.5 到 1.3），直接點最低點。
- **尤拉法的驗證**：把 drag 設成 0 跑出來的結果和公式解比，差不到 0.5% 才算程式寫對。這是寫模擬程式的基本習慣：**先用有公式解的情況驗證，再加上沒有公式解的效果。**
- **進籃的容許範圍**：籃框直徑 45 公分、球直徑 24 公分，所以球心到框中心的水平誤差在 ±10 公分左右都能進。把程式裡的 4.19 改成 4.09 和 4.29，看需要的速度範圍是多少，這就是你「出手速度的容許誤差」。角度越高，球從上方落下，容許範圍越大，這是教練說「拋高一點」的數學理由。
