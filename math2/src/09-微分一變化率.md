## 開場：測速照相怎麼知道你「這一瞬間」多快？

爸爸開車經過一台測速照相機，閃了一下。回家後罰單寫著「時速 68 公里，超速 8 公里」。爸爸不服氣：「我從家裡到那裡 10 公里開了 15 分鐘，平均時速才 40，哪來的 68？」

媽媽說：「平均 40 是整段路的事。照相機拍的是你經過它『那一瞬間』的速度。」

爸爸想了想又問：「可是一瞬間時間是 0，距離也是 0，0 除以 0 要怎麼算出 68？」

這個問題困擾了人類很久，一直到牛頓與萊布尼茲在 17 世紀才真正解決。答案就是上一章的極限：不要真的用 0 去除，而是用「越來越短的時間」去算平均速度，看它靠近哪個數。測速照相機實際上就是這麼做的：它量你在兩條感應線之間（相距可能只有 1 公尺）花了多少時間，算出一個「很短的平均速度」，當作瞬時速度。

這一章我們要把「瞬時速度」這個想法整理成一個工具，叫做導數。學會它之後，不只是速度，任何「某個量變得多快」的問題：水位上升多快、人口成長多快、成本增加多快，都用同一招解決。

## 核心概念

### 平均速度：兩個時刻之間

平均速度（Average Velocity）你早就會算：

```
平均速度 = 位置的改變 ÷ 時間的改變 = Δs / Δt
```

Δ 讀作「delta」，意思是「改變量」。從 10 樓丟下一顆球（忽略空氣阻力），t 秒後掉落的距離是 s(t) = 4.9t²（公尺）。第 1 秒到第 2 秒之間的平均速度是：

```
Δs / Δt = (s(2) − s(1)) / (2 − 1) = (19.6 − 4.9) / 1 = 14.7 公尺/秒
```

這個數代表的是「這一整秒的平均表現」，但球一直在加速，第 1 秒剛開始時比較慢，接近第 2 秒時比較快。14.7 兩邊都不是。

### 瞬時速度：把時間間隔縮到 0

我們想知道「t = 1 這一瞬間」的速度。辦法是：把第二個時刻一步一步往 1 靠近，看平均速度往哪裡去。

| 時間區間 | Δt | s(終點) − s(1) | 平均速度 (m/s) |
|---|---|---|---|
| 1 到 2 | 1 | 19.6 − 4.9 = 14.7 | 14.7 |
| 1 到 1.5 | 0.5 | 11.025 − 4.9 = 6.125 | 12.25 |
| 1 到 1.1 | 0.1 | 5.929 − 4.9 = 1.029 | 10.29 |
| 1 到 1.01 | 0.01 | 4.99849 − 4.9 = 0.09849 | 9.849 |
| 1 到 1.001 | 0.001 | 4.9098049 − 4.9 = 0.0098049 | 9.8049 |

Δt 越小，平均速度越靠近 9.8。所以 t = 1 時的瞬時速度（Instantaneous Velocity）是 9.8 公尺/秒。我們沒有真的拿 0 去除，而是用上一章的語言說：

```
瞬時速度 = lim Δs/Δt
          Δt→0
```

這正是「用越來越接近的數，取代沒辦法直接算的 0/0」。

### 從割線到切線

把 s(t) = 4.9t² 畫成圖，平均速度就有了幾何意義。連接圖上兩點 (1, 4.9) 和 (2, 19.6) 的直線叫割線（Secant Line），它的斜率是「上升 ÷ 前進」= 14.7 ÷ 1 = 14.7，正好就是平均速度。

```
  s
 20 |                       ● (2, 19.6)
    |                    /  |
 15 |                 /     |   割線斜率 = 14.7
    |              /        |
 10 |           /  .        |
    |        /  .           |
  5 |     ●.                |   ← (1, 4.9)
    |  . /                  |
  0 +---+-------------------+---- t
    0   1                   2
       （曲線以 . 表示，割線以 / 表示）
```

現在把第二個點沿著曲線往第一個點滑：(1.5, 11.025)、(1.1, 5.929)、(1.01, 4.998)……割線會轉動，斜率 12.25、10.29、9.849……最後割線「停」在一個位置，只碰曲線一下，這條線叫切線（Tangent Line），斜率就是 9.8。

**切線斜率 = 瞬時變化率。** 這句話把「速度」（物理）和「斜率」（幾何）綁在一起，是整個微分的核心畫面。從此以後，只要你看到一條曲線，就可以問「這一點的斜率是多少」，而答案的意義就是「這一點變得多快」。

### 導數的定義

把上面的做法寫成通用的式子。設函數 f，固定一點 x，另一點是 x + h（h 就是剛才的 Δt）。兩點之間的平均變化率是：

```
(f(x + h) − f(x)) / h          ← 這個分數叫差商（Difference Quotient）
```

讓 h → 0，極限就是 f 在 x 的導數（Derivative），記作 f′(x)（讀作「f prime x」）：

```
              f(x + h) − f(x)
f′(x) = lim  ─────────────────
        h→0         h
```

f′(x) 同時是三件事：**x 點的切線斜率、x 點的瞬時變化率、「f 在 x 附近每多 1 單位輸入，輸出大約增加多少」。** 求導數這個動作叫微分（Differentiation）。

### 用定義算 x² 的導數

設 f(x) = x²。我們把定義裡的每一步寫出來，不跳步：

**第 1 步**：算 f(x + h)。
```
f(x + h) = (x + h)² = x² + 2xh + h²
```

**第 2 步**：算 f(x + h) − f(x)。
```
(x² + 2xh + h²) − x² = 2xh + h²
```

**第 3 步**：除以 h。h ≠ 0 時可以約分：
```
(2xh + h²) / h = h(2x + h) / h = 2x + h
```

**第 4 步**：讓 h → 0。
```
lim (2x + h) = 2x
h→0
```

所以 **f′(x) = 2x**。驗證一下：x = 3 時 f′(3) = 6。回頭用數值表看：

| h | 1 | 0.1 | 0.01 | 0.001 |
|---|---|---|---|---|
| (f(3 + h) − f(3)) / h | 7 | 6.1 | 6.01 | 6.001 |

每個值都是「6 + h」，h 越小越靠近 6，和公式一致。注意第 3 步：我們能約掉 h，是因為 h 只是「靠近 0」、不是「等於 0」，這就是上一章說的「極限不踩在那一點上」。

再對照一下丟球：s(t) = 4.9t² 是 t² 的 4.9 倍，所以 s′(t) = 4.9 × 2t = 9.8t。t = 1 時 9.8，和數值表完全吻合；t = 3 時 29.4 公尺/秒。

### 用定義算 x³ 的導數

設 f(x) = x³。(x + h)³ 要展開：(x + h)³ = x³ + 3x²h + 3xh² + h³（可以用 (x + h)(x + h)² 乘出來驗證）。

**第 1 步**：f(x + h) = x³ + 3x²h + 3xh² + h³

**第 2 步**：f(x + h) − f(x) = 3x²h + 3xh² + h³

**第 3 步**：除以 h：3x² + 3xh + h²

**第 4 步**：h → 0，含 h 的項都消失：**f′(x) = 3x²**

驗證：x = 2 時 f′(2) = 12。數值表：

| h | 1 | 0.1 | 0.01 | 0.001 |
|---|---|---|---|---|
| ((2 + h)³ − 8) / h | 19 | 12.61 | 12.0601 | 12.006 |

你會發現一個模式：x² 的導數是 2x，x³ 的導數是 3x²。「次方數跑到前面當係數，次方數減 1。」這就是等一下的冪次公式。

### 導數是「斜率函數」

f′(x) = 2x 不是一個數，而是一個**新的函數**：你給它任何 x，它回答「f 在那一點的斜率」。

| x | −3 | −2 | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| f(x) = x² | 9 | 4 | 1 | 0 | 1 | 4 | 9 |
| f′(x) = 2x | −6 | −4 | −2 | 0 | 2 | 4 | 6 |

對照圖形：x 是負的時候，拋物線往下走，斜率是負的；x = 0 是谷底，切線水平，斜率 0；x 是正的時候，往上走，斜率是正的，而且越往右越陡。

```
   f(x) = x²                     f′(x) = 2x
  9 |\         /                   6 |        /
    | \       /                      |      /
  4 |  \     /                     2 |    /
    |   \   /                        |  /
  1 |    \_/                   -----+/--------- x
    +---+-+-+---- x               -2 |/   
   -3  -1 0 1   3              -6  /|
                              -3 -1 0 1  3
   左邊下坡、右邊上坡            左邊是負、右邊是正、中間剛好 0
```

讀 f′ 的圖有一個口訣：**f′ > 0 的地方 f 在爬坡，f′ < 0 的地方 f 在下坡，f′ = 0 的地方 f 是平的（山頂、谷底或平台）。** 第 11 章找最大最小值全靠這一句。

### 基本公式

每次都用定義很累。好消息是，有四條公式可以處理所有多項式：

| 公式 | 內容 | 例子 |
|---|---|---|
| 冪次 | (xⁿ)′ = n·xⁿ⁻¹ | (x⁵)′ = 5x⁴；(x)′ = 1 |
| 常數 | (c)′ = 0 | (7)′ = 0 |
| 常數倍 | (c·f)′ = c·f′ | (4x³)′ = 4 × 3x² = 12x² |
| 和差 | (f ± g)′ = f′ ± g′ | (x² + x³)′ = 2x + 3x² |

為什麼？常數函數的圖是水平線，斜率當然是 0。常數倍是把圖形上下拉伸 c 倍，每一段的「上升」都變 c 倍，斜率也變 c 倍。和差是因為兩個函數的改變量可以分開加：(f + g) 的改變 = f 的改變 + g 的改變。冪次公式我們驗證了 n = 2 和 n = 3，其他 n 的證明方法一樣（展開 (x + h)ⁿ，只有 n·xⁿ⁻¹·h 那一項會在約分後留下來）。

**例子 1**：f(x) = 3x² − 5x + 7。逐項處理：
```
f′(x) = 3 × 2x − 5 × 1 + 0 = 6x − 5
```
f′(2) = 12 − 5 = 7：在 x = 2 這點，x 每多 1，f 大約多 7。

**例子 2**：冪次公式對任何實數 n 都成立，包括負數和分數：
- 1/x = x⁻¹，所以 (1/x)′ = −1·x⁻² = −1/x²。在 x = 2：−1/4 = −0.25。數值檢查：(1/2.001 − 1/2) / 0.001 ≈ −0.2499。
- √x = x^(1/2)，所以 (√x)′ = (1/2)x^(−1/2) = 1/(2√x)。在 x = 4：1/4 = 0.25。數值檢查：(√4.001 − 2) / 0.001 ≈ 0.24998。

**例子 3（經濟）**：工廠生產 q 個杯子的總成本是 C(q) = 0.1q² + 20q + 500（元）。C′(q) = 0.2q + 20，叫邊際成本（Marginal Cost）：「再多做一個要多花多少」。C′(100) = 40 元，C′(500) = 120 元：做得越多，再多做一個越貴（例如要加班）。

### 記號：f′(x) 和 dy/dx

導數有兩套記號，你都會遇到：

- 牛頓／拉格朗日式：f′(x)，或 y′。簡潔，適合代入數字，例如 f′(3)。
- 萊布尼茲式：dy/dx，讀作「d y d x」，或寫成 d/dx (x²) = 2x。它提醒你導數是 Δy/Δx 在 Δx → 0 時的極限：「d」就是「小到極限的 Δ」。這套記號在第 10 章的鏈鎖法則和第 11 章的相關變化率特別好用。

兩者完全相同：如果 y = x³，則 y′ = dy/dx = 3x²。

### 切線方程式

知道斜率，就能寫出切線。y = x² 在 x = 3 這一點：

- 切點：(3, 9)。
- 斜率：f′(3) = 6。
- 切線（第一冊的點斜式）：y − 9 = 6(x − 3)，整理得 y = 6x − 9。

切線的用處是「用直線代替曲線」：在 x = 3.1，切線給 6 × 3.1 − 9 = 9.6，真正的 3.1² = 9.61，差 0.01。離切點越近越準。第 11 章的「線性近似」就是這件事。

### 活動 9-1：錄影玩具車，算瞬時速度

**材料／工具**
- 一台會自己跑的玩具車（發條車、電動車、或從斜坡滑下的小車）
- 手機（有錄影功能，最好能調成慢動作或 60 fps）
- 捲尺或長尺、紙膠帶
- 試算表或紙筆

**步驟**
1. 在地板或桌上用紙膠帶貼一條直線跑道，從起點開始每 5 公分貼一小段膠帶做刻度，貼到 60 公分。
2. 把手機架在跑道正上方或正側面（固定不動，可以靠在書上），開始錄影。

5. 把「時間、位置」填入表格，算出每一段 0.1 秒的平均速度 = (後一位置 − 前一位置) ÷ 0.1。
6. 要估 t = 0.3 秒「這一瞬間」的速度，用它前後兩格：(s(0.4) − s(0.2)) ÷ 0.2。這叫中央差分，比只用一邊準。

## 用工具看看

**試算表：差商逼近表**

1. A1 打「h」，A2 打 1，A3 打 `=A2/10`，往下拉到 A6。
2. B1 打「差商」，B2 打 `=((3+A2)^2-3^2)/A2`，往下拉。這就是 f(x) = x² 在 x = 3 的差商。
3. 你會看到 7、6.1、6.01、6.001、6.0001。想換函數就改 B 欄的式子，例如 x³ 在 x = 2：`=((2+A2)^3-2^3)/A2`。
4. 進階：C2 打 `=((3+A2)^2-(3-A2)^2)/(2*A2)`（中央差分），你會發現它每一列都剛好是 6。對 x² 來說中央差分沒有誤差，對其他函數則是「比單邊準很多」。

**Python（Google Colab）：數值微分**

打開 colab.research.google.com，按「新增筆記本」，把下面的程式貼進儲存格，按 Shift + Enter。

```python
# 數值微分：用「很小的 h」逼近導數
# 在 Google Colab 新增一個儲存格，貼上整段後按 Shift+Enter 執行

def f(x):
    # 想微分的函數，先用 x 的平方試試
    return x ** 2

def forward_diff(f, x, h):
    # 前向差分：(f(x+h) − f(x)) / h，就是導數定義裡的那個分數
    return (f(x + h) - f(x)) / h

def central_diff(f, x, h):
    # 中央差分：左右各取一點，(f(x+h) − f(x−h)) / (2h)，通常更準
    return (f(x + h) - f(x - h)) / (2 * h)

x = 3
print("在 x = 3 處逼近 f'(3)，正確答案是 2 × 3 = 6")
print("h\t\t前向差分\t中央差分")
for h in [1, 0.1, 0.01, 0.001, 0.0001]:
    # h 一步一步變小，看兩種估計值往哪裡靠近
    print(f"{h}\t\t{forward_diff(f, x, h):.6f}\t{central_diff(f, x, h):.6f}")

print()
print("把整條斜率函數畫成表：x 從 -3 到 3")
for x in range(-3, 4):
    # 每個 x 都算一次中央差分，再和公式 2x 比較
    print(f"x = {x:2d}  數值導數 = {central_diff(f, x, 0.001):8.4f}  公式 2x = {2 * x}")
```

    v = (s[i + 1] - s[i]) / (t[i + 1] - t[i])

## 常見錯誤與迷思

- **「瞬時速度就是距離 0 除以時間 0。」** → 0/0 沒有意義 → 瞬時速度是「時間間隔 → 0 時平均速度的極限」，永遠用很短但不是 0 的間隔去逼近。
- **「導數是一個數。」** → f′(3) = 6 是數，但 f′(x) = 2x 是函數 → 導數是「斜率函數」，每一點都有自己的斜率；先求出函數，再代入點。
- **「算差商時直接讓 h = 0。」** → 會得到 0/0 → 先用代數約掉 h（像 x² 那樣得到 2x + h），再讓 h → 0。
- **「(x²)′ = 2x，所以 (3x²)′ 也是 2x。」** → 忘了常數倍 → (3x²)′ = 3 × 2x = 6x；圖形拉高 3 倍，斜率也變 3 倍。
- **「常數的導數是 1。」** → 混淆了 (x)′ = 1 和 (c)′ = 0 → 常數是水平線，斜率 0；x 是 45° 的直線，斜率 1。
- **「切線一定只碰曲線一次。」** → 對拋物線成立，但 y = x³ 在 x = 0 的切線 y = 0 會穿過曲線 → 切線的定義是「割線的極限位置」，不是「碰一次」。
- **「f′(x) = 0 的地方 f 一定是最大或最小。」** → y = x³ 在 x = 0 斜率 0，但那裡既不是最高也不是最低 → f′ = 0 只是「平」，第 11 章會教怎麼分辨。

## 想一想

1. 求下列函數的導數：(1) f(x) = x⁵；(2) f(x) = 4x³ − 2x² + x − 9；(3) f(x) = 10；(4) f(x) = 2/x。

<details><summary>參考答案</summary>

(1) 5x⁴。

(2) 12x² − 4x + 1。

(3) 0。

(4) 2/x = 2x⁻¹，導數是 2 × (−1)x⁻² = −2/x²。

</details>

2. 一顆球往上丟，t 秒後的高度是 h(t) = 20t − 4.9t²（公尺）。(1) 求速度函數 h′(t)；(2) t = 1 秒時速度多少？(3) 什麼時候速度是 0？那時球在做什麼？

<details><summary>參考答案</summary>

(1) h′(t) = 20 − 9.8t。

(2) h′(1) = 10.2 公尺/秒，還在往上。

(3) 20 − 9.8t = 0 得 t ≈ 2.04 秒。速度 0 代表球到達最高點，正要掉下來。高度 h(2.04) ≈ 20.4 公尺。

</details>

3. 用導數的定義（四個步驟）算 f(x) = x² − 4x + 1 的導數，再算 f′(2)。f′(2) 的值告訴你圖形在 x = 2 長什麼樣？

<details><summary>參考答案</summary>

f(x + h) = (x + h)² − 4(x + h) + 1 = x² + 2xh + h² − 4x − 4h + 1。

f(x + h) − f(x) = 2xh + h² − 4h。

除以 h：2x + h − 4。

h → 0：f′(x) = 2x − 4。（用公式驗證：2x − 4 + 0，一致。）

f′(2) = 0，x = 2 是這條拋物線的谷底（頂點），切線水平。配方法也可確認：x² − 4x + 1 = (x − 2)² − 3，頂點 (2, −3)。

</details>

4. 求 y = x³ 在 x = 2 的切線方程式，並用它估計 2.05³。真正的值是 8.615125，你的估計差多少？

<details><summary>參考答案</summary>

切點 (2, 8)，斜率 3 × 2² = 12，切線 y − 8 = 12(x − 2)，即 y = 12x − 16。

估計 2.05³ ≈ 12 × 2.05 − 16 = 8.6，真值 8.615125，差約 0.015。

</details>

5. 下表是某水庫在一天中不同時刻的水位。估計上午 8 點和中午 12 點的「瞬時」水位變化率（公分/小時），並說明你為什麼選那樣算。

| 時刻 | 6:00 | 8:00 | 10:00 | 12:00 | 14:00 |
|---|---|---|---|---|---|
| 水位 (公分) | 320 | 326 | 338 | 356 | 380 |

<details><summary>參考答案</summary>

8 點：用前後兩點做中央差分，(338 − 320) ÷ 4 = 4.5 公分/小時。

12 點：(380 − 338) ÷ 4 = 10.5 公分/小時。

選中央差分是因為它把「上升中」的前後兩段平均掉，比只看一邊更接近那一瞬間；如果只有單邊資料（例如 6 點），就只能用前向差分 (326 − 320) ÷ 2 = 3。

</details>

6. 第一冊學過直線 y = mx + b。用導數的定義證明它的導數是 m（每一點斜率都一樣），並說明這和「直線斜率固定」的意思為何一致。

<details><summary>參考答案</summary>

f(x + h) − f(x) = (m(x + h) + b) − (mx + b) = mh，除以 h 得 m，和 h 無關，所以 h → 0 時仍是 m。

意義：直線不管你在哪裡、取多長的區間，割線都和它自己重合，斜率永遠是 m，所以「平均變化率」和「瞬時變化率」相同。曲線則不然，這正是為什麼曲線需要導數。

</details>

7. （挑戰）用定義算 f(x) = 1/x 的導數。提示：先把 1/(x + h) − 1/x 通分。

<details><summary>參考答案</summary>

1/(x + h) − 1/x = (x − (x + h)) / (x(x + h)) = −h / (x(x + h))。

除以 h：−1 / (x(x + h))。

h → 0：−1/x²。和冪次公式 (x⁻¹)′ = −x⁻² 一致。

</details>

8. （開放挑戰）測速照相機有兩條感應線相距 1 公尺，一輛車通過兩線花了 0.05 秒。(1) 它算出的速度是多少（換算成公里/小時）？(2) 這算「瞬時速度」嗎？為什麼工程師覺得夠用？(3) 如果車子正在猛踩煞車，這個數和真正的瞬時速度會差多少方向？

<details><summary>參考答案</summary>

(1) 1 ÷ 0.05 = 20 公尺/秒 = 72 公里/小時。

(2) 嚴格說是「0.05 秒的平均速度」。但汽車在 0.05 秒內速度幾乎不變（就算用力煞車，減速度約 8 m/s²，0.05 秒也只差 0.4 m/s），所以和瞬時速度的差距遠小於儀器本身的誤差，實務上等同瞬時速度。這就是「h 夠小就夠用」的工程版本。

(3) 煞車中速度越來越慢，平均速度會比「通過第二條線那一瞬間」的速度略高、比「通過第一條線那一瞬間」略低，大約等於中間那一刻的瞬時速度，誤差約 0.2 m/s。

</details>

## 本章小結
- 平均速度 = Δs/Δt，是一段時間的整體表現；瞬時速度是 Δt → 0 時平均速度的極限。
- 在圖上，平均變化率是割線斜率，瞬時變化率是切線斜率；切線是割線的極限位置。
- 導數定義：f′(x) = lim (f(x + h) − f(x))/h（h → 0）。算法：展開、相減、約掉 h、讓 h → 0。
- (x²)′ = 2x、(x³)′ = 3x²，一般地 (xⁿ)′ = n·xⁿ⁻¹，n 可以是負數或分數。
- 常數的導數是 0，常數倍和和差可以分開處理，所以任何多項式都能逐項微分。
- 導數是斜率函數：f′ > 0 爬坡、f′ < 0 下坡、f′ = 0 水平。
- 記號 f′(x) 與 dy/dx 意思相同；切線方程式是 y − f(a) = f′(a)(x − a)。
- 數值微分用差商逼近，中央差分 (f(x + h) − f(x − h))/(2h) 通常比前向差分準。
