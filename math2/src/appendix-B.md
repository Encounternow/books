# 附錄 B　工具操作速查

這本書用四個免費工具：Desmos（畫函數最快）、GeoGebra（幾何與動態圖）、Google 試算表（算數值表）、Python 在 Google Colab 上（數值微分、積分、模擬）。這一篇是「打開哪裡、打什麼、看到什麼」的速查，每個工具先列基本操作，再列本書各章會用到的招式。

## B.1 Desmos（desmos.com/calculator）

**打開**：瀏覽器進 desmos.com/calculator，不用登入就能用。手機也有 App（Desmos Graphing Calculator）。左邊是輸入欄，右邊是圖。

**基本輸入**：

| 想做什麼 | 打什麼 | 備註 |
|---|---|---|
| 畫 y = x² | `y = x^2` | 打 `^` 會自動變上標 |
| 畫 √x | `y = sqrt(x)` | 或打 `\sqrt` |
| 畫 sin | `y = sin(x)` | 預設是弧度；右上角扳手可改成角度 |
| 畫 eˣ、ln x | `y = e^x`、`y = ln(x)` | `log(x)` 是以 10 為底 |
| 絕對值 | `y = abs(x)` 或 `y = |x|` | |
| 只畫一段 | `y = x^2 {0 <= x <= 2}` | 大括號內是範圍 |
| 分段函數 | `y = {x < 0: -x, x^2}` | 冒號前是條件，最後一個是「其他情況」 |
| 定義函數 | `f(x) = x^2 - 4x + 1` | 之後可以打 `f(2)`、`y = f(x - 3)` |
| 參數滑桿 | `y = a x^2`，按出現的「加入滑桿 a」 | 拖滑桿看圖怎麼變 |
| 列點 | `(1, 2), (2, 5), (3, 10)` | 或用「+」→ 表格 |
| 畫一個點 | `(3, f(3))` | |

**本書會用到的招式**：

| 章 | 做什麼 | 打什麼 | 看到什麼 |
|---|---|---|---|
| 1 | 平移與伸縮 | `f(x) = x^2`、`y = f(x - h) + k`，加滑桿 h、k | 拖滑桿，拋物線跟著移 |
| 2 | 找頂點 | 畫 `y = x^2 - 4x + 1`，點圖上的灰點 | 顯示 (2, −3) |
| 6 | 疊加兩個波 | `y = sin(x)`、`y = sin(1.1x)`、`y = sin(x) + sin(1.1x)` | 第三條有拍頻（忽大忽小） |
| 8 | 看極限 | `y = sin(x)/x`，放大到 x = 0 附近 | 接近 1，但 x = 0 有一個洞 |
| 9 | 畫切線 | `f(x) = x^2`、`a = 1`（滑桿）、`y = f(a) + 2a(x - a)` | 拖 a，切線跟著曲線跑 |
| 10 | f 與 f′ 對照 | `f(x) = sin(x)`、`y = f'(x)` | Desmos 直接畫導數（打一撇） |
| 11 | 找極值 | 畫函數後點圖上的灰點 | 顯示最高／最低點座標 |
| 12 | 畫定積分 | `\int_0^3 x^2 dx` | 直接顯示 9 |
| 12 | 黎曼和圖 | `f(x) = x^2`、`n = 6`、`\sum_{i=0}^{n-1} f(3i/n) * 3/n` | 顯示左和，改 n 看收斂 |
| 13 | 兩曲線間面積 | `\int_{-2}^{1} ((4 - x^2) - (x + 2)) dx` | 顯示 4.5 |
| 13 | 旋轉體體積 | `\int_0^4 pi * (sqrt(x))^2 dx` | 顯示 25.13（= 8π） |
| 15 | 分段軌道 | 四行各加 `{a <= x <= b}` | 連續的雲霄飛車軌道 |

**小技巧**：按住圖拖曳可以移動，滾輪縮放。右上角「分享」可以複製連結貼在報告裡。打 `d/dx` 或 `f'(x)` 會自動算導數，打 `\int` 會出現積分符號。

## B.2 GeoGebra（geogebra.org/calculator）

Desmos 擅長函數，GeoGebra 擅長幾何、滑桿、動畫，以及「圖形＋代數同時看」。

**打開**：geogebra.org/calculator，選「繪圖」（Graphing）或「幾何」（Geometry）。

**基本輸入**（在左邊的「代數區」打）：

| 想做什麼 | 打什麼 | 備註 |
|---|---|---|
| 畫函數 | `f(x) = x^2` | 名字可以自己取 |
| 導數 | `Derivative(f)` 或 `f'(x)` | 會畫出 f′ 並給出式子 |
| 切線 | `Tangent(2, f)` | 在 x = 2 畫切線並顯示方程 |
| 定積分與陰影 | `Integral(f, 0, 3)` | 畫出陰影並顯示 9 |
| 黎曼和圖 | `LowerSum(f, 0, 3, 6)`、`UpperSum(f, 0, 3, 6)` | 畫出長方形並顯示和 |
| 兩曲線間 | `IntegralBetween(f, g, a, b)` | 畫陰影並顯示面積 |
| 滑桿 | `n = Slider(1, 100, 1)` | 1 到 100，每步 1 |
| 點 | `A = (1, 2)` | 可以拖 |
| 極值 | `Extremum(f, 0, 5)` | 標出區間內的極值點 |
| 兩圖交點 | `Intersect(f, g)` | |
| 旋轉體（3D） | 切到「3D 繪圖」，`Surface(x, f(x) cos(t), f(x) sin(t), x, 0, 4, t, 0, 2π)` | 看到花瓶形狀 |

| 章 | 做什麼 | 怎麼做 |

## B.3 Google 試算表

**打開**：sheets.google.com，新增空白試算表。Excel 的公式幾乎一樣。

**基本公式**（都以 `=` 開頭）：

| 功能 | 公式 | 例 |
|---|---|---|
| 次方 | `^` | `=A2^2` |
| 根號 | `SQRT` | `=SQRT(A2)` |
| e 的次方、自然對數 | `EXP`、`LN` | `=EXP(0.05*A2)`、`=LN(B2-24)` |
| 10 為底對數 | `LOG10` | `=LOG10(A2)` |
| 三角（弧度） | `SIN`、`COS`、`TAN` | `=SIN(A2)` |
| 角度轉弧度 | `RADIANS` | `=SIN(RADIANS(30))` |
| 圓周率 | `PI()` | `=PI()*B2^2` |
| 加總、平均 | `SUM`、`AVERAGE` | `=SUM(D2:D11)` |
| 直線擬合斜率、截距 | `SLOPE(y範圍, x範圍)`、`INTERCEPT` | `=SLOPE(D2:D8, A2:A8)` |
| 固定某格（拉公式時不動） | `$` | `=B2+$E$2*C2` |

**往下拉**：選取有公式的格子，拖右下角的小方塊往下，公式會自動把列號加 1。這是做數值表最重要的動作。

**畫圖**：選取兩欄 → 插入 → 圖表 → 圖表類型選「散佈圖」（看點）或「折線圖」（看趨勢）。

**本書會用到的招式**：

| 章 | 表格怎麼排 | 關鍵公式 |
|---|---|---|
| 3 | A 欄年數 0–30，B 欄金額 | B3 = `=B2*1.05` |
| 7 | A 欄 n，B 欄項，C 欄部分和 | C3 = `=C2+B3` |
| 8 | A 欄 n（10、100、…），B 欄 (1+1/n)ⁿ | B2 = `=(1+1/A2)^A2` |
| 9 | A 欄 x，B 欄 f(x)，C 欄數值導數 | C2 = `=(B3-B2)/(A3-A2)` |
| 10 | A 欄 x，B 欄 sin，C 欄數值導數，D 欄 cos | 看 C 和 D 幾乎一樣 |
| 12 | A 欄 i，B 欄 xᵢ，C 欄 f(xᵢ)，D 欄 f(xᵢ)·Δx | 最下面 `=SUM(D:D)` |
| 14 | A 欄 t，B 欄 y，C 欄變化率 | B3 = `=B2+$E$2*C2`（尤拉法） |
| 14 | 冷卻數據：A 欄 t，B 欄 T，C 欄 LN(T − 室溫) | k = `=-SLOPE(C2:C8, A2:A8)` |

**黎曼和完整範例**（∫₀¹ x² dx，10 段）：

```
    A      B            C          D
1   i      x_i          f(x_i)     f(x_i)*dx
2   0      =A2*0.1      =B2^2      =C2*0.1
3   1      =A3*0.1      =B3^2      =C3*0.1
…   …（往下拉到 i = 9）
12  合計                            =SUM(D2:D11)   → 0.285（左和）
```

把 B2 改成 `=(A2+0.5)*0.1` 往下拉，得到中點和 0.3325。

## B.4 Python（Google Colab）

**打開**：colab.research.google.com，登入 Google 帳號，「新增筆記本」。看到一個格子（cell），把程式貼進去，按左邊的播放鍵或 Shift + Enter 執行。結果出現在格子下方。不用安裝任何東西。

**最基本的語法**（這本書只用到這些）：

| 想做什麼 | 寫法 | 說明 |
|---|---|---|
| 印出來 | `print(x)` | 多個用逗號隔開 |
| 變數 | `x = 3` | 不用宣告型別 |
| 次方 | `x ** 2` | 不是 `^` |
| 數學函數 | `import math` 之後 `math.sqrt(2)`、`math.sin(1)`、`math.exp(1)`、`math.log(2)`、`math.pi` | `math.log` 是自然對數 |
| 定義函數 | `def f(x):` 下一行縮排 `return x ** 2` | 縮排是四個空格 |
| 匿名函數 | `lambda x: x ** 2` | 用在當參數傳 |
| 迴圈 | `for i in range(10):` | i 從 0 跑到 9 |
| 條件 | `if x > 0:` ... `else:` | |

**常見錯誤**：縮排不對（IndentationError）、忘了冒號、用 `^` 當次方、忘了 `import math`、整數除法用 `//` 而不是 `/`。

### 範例一：數值微分

```python
import math

def derivative(f, x, h=1e-5):
    # 中央差分：用 x 左右各一小步的斜率來估 f′(x)，比單邊差分準很多
    return (f(x + h) - f(x - h)) / (2 * h)

# 測試三個函數，和公式解對照
print("f(x)=x³ 在 x=2：數值", round(derivative(lambda x: x**3, 2), 6), "公式 3x² =", 12)
print("f(x)=sin x 在 x=0：數值", round(derivative(math.sin, 0), 6), "公式 cos 0 =", 1)
print("f(x)=eˣ 在 x=1：數值", round(derivative(math.exp, 1), 6), "公式 e =", round(math.e, 6))

# 畫一張導數表：f(x) = x² 從 0 到 2，每 0.5 算一次
print("x    f(x)=x²   f′(x) 數值   2x")
for i in range(5):
    x = i * 0.5
    print(f"{x:.1f}  {x**2:7.2f}   {derivative(lambda t: t**2, x):8.4f}   {2*x:.1f}")
```

執行結果：

```
f(x)=x³ 在 x=2：數值 12.0 公式 3x² = 12
f(x)=sin x 在 x=0：數值 1.0 公式 cos 0 = 1
f(x)=eˣ 在 x=1：數值 2.718282 公式 e = 2.718282
x    f(x)=x²   f′(x) 數值   2x
0.0     0.00     0.0000   0.0
0.5     0.25     1.0000   1.0
1.0     1.00     2.0000   2.0
1.5     2.25     3.0000   3.0
2.0     4.00     4.0000   4.0
```

`h` 不要設太小（小於 1e-8），電腦的小數會不準；也不要太大（大於 0.1），割線和切線差太多。1e-5 是好用的中間值。

### 範例二：黎曼和

```python
def riemann_mid(f, a, b, n):
    # 中點黎曼和：把 [a, b] 切成 n 段，每段用中點的高度畫長方形
    dx = (b - a) / n
    total = 0
    for i in range(n):
        x_mid = a + (i + 0.5) * dx   # 第 i 段的中點
        total += f(x_mid) * dx       # 長方形面積累加
    return total

# ∫₀¹ x² dx = 1/3，看 n 加大時怎麼收斂
for n in [1, 2, 4, 8, 16, 32, 64]:
    print(f"n={n:3d}  中點和 = {riemann_mid(lambda x: x**2, 0, 1, n):.6f}")
print("正確答案 1/3 =", round(1/3, 6))
```

執行結果：

```
n=  1  中點和 = 0.250000
n=  2  中點和 = 0.312500
n=  4  中點和 = 0.328125
n=  8  中點和 = 0.332031
n= 16  中點和 = 0.333008
n= 32  中點和 = 0.333252
n= 64  中點和 = 0.333313
正確答案 1/3 = 0.333333
```

n 每加倍，誤差大約變成四分之一（中點和的誤差和 1/n² 成正比）。要算別的積分，把 `lambda x: x**2` 和 `0, 1` 換掉就好。第 13 章有更準的梯形法與辛普森法。

### 範例三：尤拉法解微分方程

```python
def euler(rate, y0, t0, t_end, h):
    # 尤拉法：已知變化率 rate(t, y)，從 (t0, y0) 一步一步往前推
    t, y = t0, y0
    rows = [(t, y)]
    steps = round((t_end - t0) / h)
    for _ in range(steps):
        y = y + h * rate(t, y)   # 新值 = 舊值 + 變化率 × 步長
        t = t + h
        rows.append((t, y))
    return rows

# 牛頓冷卻：dT/dt = −0.05 (T − 20)，T(0) = 80，每步 1 分鐘，算 30 分鐘
rows = euler(lambda t, T: -0.05 * (T - 20), 80, 0, 30, 1)
for t, T in rows:
    if t % 5 == 0:
        print(f"t = {t:2d} 分   T ≈ {T:.2f} °C")
```

執行結果：

```
t =  0 分   T ≈ 80.00 °C
t =  5 分   T ≈ 66.43 °C
t = 10 分   T ≈ 55.92 °C
t = 15 分   T ≈ 47.80 °C
t = 20 分   T ≈ 41.51 °C
t = 25 分   T ≈ 36.64 °C
t = 30 分   T ≈ 32.88 °C
```

公式解 T = 20 + 60 e^(−0.05t) 在 t = 30 是 33.39，尤拉法 32.88，差 0.5 度；把 h 改成 0.1 會縮到 0.05 度。要換成別的微分方程，只改 `lambda t, T: ...` 那一行：指數成長是 `lambda t, y: 0.3 * y`，邏輯斯是 `lambda t, P: 0.5 * P * (1 - P / 1000)`。

### 畫圖（選配）

Colab 內建 matplotlib，在程式最後加：

```python
import matplotlib.pyplot as plt

ts = [r[0] for r in rows]          # 把時間抓出來
Ts = [r[1] for r in rows]          # 把溫度抓出來
plt.plot(ts, Ts, marker="o")       # 畫折線加點
plt.xlabel("t (min)")              # 橫軸名稱
plt.ylabel("T (°C)")               # 縱軸名稱
plt.grid(True)                     # 加格線
plt.show()
```

會在格子下方出現冷卻曲線的圖，可以右鍵另存，貼進專題報告。
