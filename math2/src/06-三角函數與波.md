# 第 6 章　三角函數與波

## 本章目標

- 學完你會用單位圓定義任何角度（包括大於 90°、負的、超過 360°）的 sin 和 cos，並說出為什麼這樣定義和直角三角形的定義一致。
- 學完你會畫出 y = sin x 和 y = cos x 的圖形，指出週期、振幅、零點、最高最低點。
- 學完你會看懂 y = A sin(ωt + φ) 裡 A、ω、φ 各自控制什麼，並從一段聲音、交流電或潮汐的描述寫出它的公式。
- 學完你會用「兩個波相加」解釋拍頻，知道為什麼兩支音叉頻率差 2 Hz 時會聽到每秒兩次的「嗡—嗡—」。
- 學完你會把示波器上的波形和 A sin(ωt + φ) 對應起來：格子讀出振幅與週期，換算成頻率。

## 開場：摩天輪的高度，為什麼是一條波？

小宇坐摩天輪，手上的手機開著高度計 App，每 30 秒記一次高度。摩天輪半徑 20 公尺、中心離地 22 公尺、轉一圈 8 分鐘。他從最低點（離地 2 公尺）開始記：2、7.9、22、36.1、42、36.1、22、7.9、2……然後又從頭來一次。

回家後他把數字畫成圖，橫軸是時間，縱軸是高度。畫出來的不是直線、不是拋物線，是一條上上下下、永遠重複的曲線——像海浪，像心電圖，像《動手玩電》示波器螢幕上的那條線。

他想：摩天輪是在「轉圈」，可是畫出來是「波」。轉圈和波有什麼關係？

關係就是上一章的 sin。上一章 sin 只能處理 0° 到 90° 的直角三角形；這一章我們讓角度繞著圓一直轉下去，sin 就從「一個比值」變成「一條會重複的曲線」——這就是**三角函數（Trigonometric Function）**。從那一刻起，它不再只是量樓高的工具，而是描述所有「繞圈」和「來回」現象的語言：聲音、交流電、潮汐、四季、鞦韆、心跳。學完這一章，你看示波器上的任何一條正弦波，都能直接寫出它的公式。

## 核心概念

### 單位圓：讓角度可以轉下去

上一章的三角比只能到 90°，因為直角三角形裡不可能有第二個 90° 以上的角。要處理摩天輪轉 180°、270°、720°，需要一個新的舞台：**單位圓（Unit Circle）**——圓心在原點、半徑 1 的圓。

規則很簡單：

1. 從 x 軸正方向（3 點鐘方向）出發，**逆時針**轉 θ 角，停在圓上一點 P。
2. **P 的 x 座標就定義為 cos θ，y 座標就定義為 sin θ。**

```
                        y
                        │
                   ●────┼────●  P = (cos θ, sin θ)
                 ／     │      ╲
               ／       │       ╲
              │         │  r=1   /│
              │         │      /  │ sin θ
              │         │    /    │
    ──────────┼─────────┼──/──θ───┼───────── x
              │         │ O       │
              │         │  cos θ  │
               ╲        │        ／
                 ╲      │      ／
                   ●────┼────●
                        │
```

為什麼這樣定義和上一章一致？當 θ 在 0° 到 90° 之間時，從 P 往下畫垂線到 x 軸，就得到一個直角三角形：斜邊是半徑 1，對邊是 P 的 y 座標，鄰邊是 P 的 x 座標。sin θ = 對/斜 = y/1 = y，cos θ = x/1 = x。完全一樣。

但新定義的好處是：**θ 超過 90° 以後，P 還是在圓上，還是有 x、y 座標，所以 sin 和 cos 還是有值**——只是可能變負。

| θ | P 在哪一區 | cos θ（x） | sin θ（y） |
|---|---|---|---|
| 0° | 右 | 1 | 0 |
| 30° | 右上 | 0.866 | 0.5 |
| 90° | 正上方 | 0 | 1 |
| 120° | 左上 | −0.5 | 0.866 |
| 150° | 左上 | −0.866 | 0.5 |
| 180° | 左 | −1 | 0 |
| 210° | 左下 | −0.866 | −0.5 |
| 270° | 正下方 | 0 | −1 |
| 330° | 右下 | 0.866 | −0.5 |
| 360° | 回到右 | 1 | 0 |

看 150°：P 在左上方，x 是負的、y 是正的，所以 cos 150° = −0.866、sin 150° = 0.5。而 sin 150° 和 sin 30° 一樣是 0.5，因為 150° 和 30° 的點關於 y 軸對稱，高度相同。這種「對稱」讓你只要記住第一象限（0°–90°）的值，其他象限都能推出來：**先看落在哪一區決定正負，再找它和 x 軸的夾角查值。**

還有兩件事變得自然：

- **超過 360°**：轉 390° 就是轉一圈再轉 30°，停在同一點，所以 sin 390° = sin 30°。每轉一圈值就重複，這叫**週期性（Periodicity）**。
- **負角度**：順時針轉。sin (−30°) = −0.5（點在右下方），cos (−60°) = 0.5。

tan θ 仍然定義為 sin θ ÷ cos θ。cos 為 0 的地方（90°、270°）tan 無定義。

從現在起角度常用弧度：一圈 2π，半圈 π，90° 是 π/2。單位圓用弧度特別自然，因為**半徑 1 的圓上，弧長就等於弧度**——轉 θ 弧度，走過的弧長就是 θ。

### 把 sin 攤開：正弦波

現在做一件事：讓 θ 從 0 開始一直增加，每個 θ 都記下 sin θ（P 的高度），然後以 θ 為橫軸、sin θ 為縱軸畫圖。這就是摩天輪的高度圖：

```
 sin x
  1 │          ●●●●●●●●
    │       ●●●        ●●●●
    │    ●●●               ●●
    │  ●●                    ●●
    │●●                        ●●
  0 ●────────────────────────────●●────────────────────────────●──→ x
    │0        π/2       π          ●●       3π/2             2π ●●
    │                                ●●                    ●●
    │                                  ●●               ●●●
    │                                    ●●●●        ●●●
 −1 │                                        ●●●●●●●●
```

這條曲線叫**正弦波（Sine Wave）**。讀它：

- 從 0 出發往上爬，在 π/2（90°）到最高點 1——P 在圓的正上方。
- 在 π（180°）回到 0——P 在最左邊，高度 0。
- 在 3π/2（270°）到最低點 −1——P 在正下方。
- 在 2π（360°）回到 0，然後整個圖形**一模一樣地重複**。

cos 的圖形長得一樣，只是提前了 π/2：cos 在 0 就已經是最高點 1。

```
 cos x
  1 ●●●●●                                                  ●●●●●
    │    ●●●                                            ●●●
    │       ●●                                        ●●
    │         ●●                                    ●●
    │           ●●                                ●●
  0 ├─────────────●●────────────────────────────●●──────────────→ x
    │0        π/2   ●●       π               ●●  3π/2        2π
    │                 ●●                   ●●
    │                   ●●●             ●●●
    │                      ●●●       ●●●
 −1 │                         ●●●●●●●
```

事實上 cos x = sin (x + π/2)：cos 就是「提早 1/4 圈出發的 sin」。摩天輪從最低點出發是 −cos，從側邊出發是 sin，從最高點出發是 cos，三個都是同一條波，只是起點不同。

兩個形容波的詞：

- **週期（Period）**：圖形重複一次要走多遠。sin x 的週期是 2π（一整圈）。
- **振幅（Amplitude）**：離中線的最大距離。sin x 的振幅是 1（最高 1、最低 −1）。

### 調整波：y = A sin(ωt + φ)

真實世界的波不會剛好振幅 1、週期 2π。我們需要三個旋鈕。

**旋鈕 A：振幅。** y = A sin x 把整條波在垂直方向拉長 A 倍。y = 3 sin x 最高 3、最低 −3。摩天輪半徑 20 公尺，振幅就是 20。聲音越大、振幅越大；交流電電壓越高、振幅越高。

**旋鈕 ω：角速度（轉多快）。** y = sin(ωt)。這裡把橫軸改成時間 t，ω（唸 omega）是每秒轉幾弧度。轉得越快，波越密。一圈 2π 弧度需要的時間（週期 T）滿足 ω T = 2π，所以：

> T = 2π / ω　　　頻率 f = 1 / T = ω / 2π　　　ω = 2πf

**頻率（Frequency）** f 是每秒重複幾次，單位赫茲（Hz）。台灣的家用電 60 Hz：ω = 2π × 60 ≈ 377 弧度/秒，週期 T = 1/60 ≈ 16.7 毫秒。標準音 A 是 440 Hz：T ≈ 2.27 毫秒，ω ≈ 2765。摩天輪 8 分鐘一圈：T = 480 秒，ω = 2π/480 ≈ 0.0131 弧度/秒。

**旋鈕 φ：相位（從哪裡出發）。** y = sin(ωt + φ)。φ（唸 phi）把整條波往左移 φ/ω 的時間。φ = π/2 就變成 cos。兩個頻率相同的波如果 φ 不同，就是「一個比另一個早一點出發」；《動手玩電》第 10 章交流訊號裡，電容讓電流比電壓「超前 90°」，講的就是相位。

再加一個**中線 C**（波不一定繞著 0 上下）：

> **y = C + A sin(ωt + φ)**

現在把摩天輪寫出來：中心高 22、半徑 20、週期 480 秒、從最低點出發（最低點是 −cos 的起點）：

> h(t) = 22 − 20 cos(2πt / 480)

驗算：t = 0 → 22 − 20 = 2 公尺（最低）；t = 120 秒（1/4 圈）→ cos(π/2) = 0 → 22 公尺；t = 240 秒 → 22 + 20 = 42 公尺（最高）。和開場的紀錄一樣。

幾個真實的波：

| 現象 | 公式 | 說明 |
|---|---|---|
| 台灣家用交流電 | v(t) = 155.6 sin(377t) | 110 V 是「有效值」，峰值是 110 × √2 ≈ 155.6 V；60 Hz |
| 標準音 A4 | p(t) = A sin(2765t) | 440 Hz；A 取決於音量 |
| 潮汐（簡化） | h(t) = 中線 + A sin(2πt / 12.42) | 半日潮週期約 12.42 小時（t 用小時） |
| 台北月均溫（簡化） | T(m) = 23 − 7 cos(2π(m − 1) / 12) | m = 月份；1 月最冷 16°C，7 月最熱 30°C |
| 台北白天長度 | D(d) = 12 + 1.7 sin(2π(d − 80) / 365) | d = 一年的第幾天；6 月 21 日約 13.7 小時、12 月 21 日約 10.3 小時 |

月均溫那條驗算一下：m = 1 → 23 − 7 = 16；m = 4 → cos(π/2) = 0 → 23；m = 7 → 23 + 7 = 30；m = 10 → 23。四季就是一條振幅 7、週期 12 個月的餘弦波。

### 兩個波相加：疊加與拍頻

這是本章最漂亮的部分。兩個波同時存在時，每一瞬間的總高度就是兩個高度**相加**，這叫**疊加（Superposition）**。水波如此、聲波如此、電訊號也如此。

**情況一：頻率相同、相位相同。** sin x + sin x = 2 sin x。振幅加倍，波形不變。兩台喇叭同步放一樣的音，更大聲。

**情況二：頻率相同、相位差 π（半圈）。** sin x + sin(x + π) = 0。一個往上時另一個剛好往下，永遠互相抵消。降噪耳機就是這樣：聽到外面的聲音，立刻製造一個「相位反過來」的聲音疊上去。

**情況三：頻率只差一點點。** 這是最有趣的。兩支音叉，一支 440 Hz、一支 442 Hz，一起響。剛開始兩個波同步，相加變大聲；但 442 Hz 的那個每秒多走 2 圈，慢慢跑到「反相」，兩個抵消，變小聲；再繼續跑，又回到同相，變大聲。結果你聽到的是一個 441 Hz 的聲音，音量**每秒大小變化 2 次**。這種「嗡—嗡—嗡—」叫做**拍頻（Beat）**，拍頻的頻率 = 兩個頻率的差。

```
 兩個頻率接近的波相加後的樣子（示意）：

   ╭──╮                 ╭──╮                 ╭──╮
  ╱|||||╲             ╱|||||╲             ╱|||||╲          ← 外面的「包絡線」慢慢起伏
 ╱|||||||╲           ╱|||||||╲           ╱|||||||╲            起伏的頻率 = f₁ − f₂（拍頻）
───────────╲───────╱───────────╲───────╱───────────╲────── t
            ╲|||||╱             ╲|||||╱             ╲
             ╰──╯                 ╰──╯                 ← 裡面密密的小波 = 平均頻率 (f₁ + f₂)/2

 大聲 ──→ 小聲 ──→ 大聲 ──→ 小聲：每秒 |f₁ − f₂| 次
```

鋼琴調音師靠這個調音：敲標準音叉和琴弦，聽拍頻，轉弦軸直到「嗡嗡」消失，兩個頻率就一樣了。吉他調弦也可以這樣做。

### 示波器上的波

《動手玩電》第 6 章「示波器入門」（https://book.vichuang.tw/electric/06-示波器入門.html ）教你用示波器看電壓對時間的圖。現在你有了語言可以描述它看到的東西。示波器螢幕橫向 10 格、縱向 8 格，每格的時間（s/div）和電壓（V/div）會顯示在畫面上。假設畫面上是：

```

 └────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘
```

讀法：

1. **振幅 A**：最高點在中線上 2 格，1.00 V/div，所以 A = 2 V。（示波器的 Vpp「峰對峰」是 4 V，A 是 Vpp 的一半。）
2. **週期 T**：從一個最高點到下一個最高點橫跨 5 格，500 µs/div，所以 T = 2.5 ms。
3. **頻率 f** = 1/T = 1/0.0025 = 400 Hz。ω = 2π × 400 ≈ 2513。
4. 寫出公式：v(t) = 2 sin(2513t + φ)。φ 看波形在 t = 0（畫面最左邊或觸發點）的位置決定；這裡 t = 0 時在中線往上穿過，φ = 0。

反過來也行：示波器的訊號產生器設定「正弦波、2 Vpp、1 kHz」，你應該預期：振幅 1 V、週期 1 ms。如果 s/div 設 200 µs，一個週期佔 5 格，畫面上會看到兩個完整的波。

拍頻在示波器上也看得到：用兩個訊號產生器分別輸出 1000 Hz 和 1010 Hz，接到同一個通道（或用示波器的 Math 功能做 CH1 + CH2），畫面會出現上面那種「包絡線」，包絡線每秒起伏 10 次。

## 動手做

### 活動 6-1：轉動物體的投影，親手畫出正弦波

**材料／工具**：一個大圓盤（披薩紙盤、鍋蓋或用圓規畫一個半徑 10 公分的圓剪下來）、一支圖釘或大頭針、一張 A4 方格紙（或自己畫格子）、尺、量角器、鉛筆。

**步驟**

1. 在圓盤邊緣用筆做一個記號點 P。用量角器在圓盤上每 30° 畫一條從圓心出發的線，標上 0°、30°、60°、……、330°。
2. 方格紙橫放。左邊畫一個和圓盤一樣大的圓（半徑 10 公分），圓心標 O，畫出水平線（x 軸）通過圓心並向右延伸到紙的右邊。
3. 在 x 軸上從圓的右側邊緣開始，每 1 公分標一個刻度，寫上 0°、30°、60°……到 360°（共 12 格、12 公分）。
4. 把圓盤用圖釘固定在紙上畫好的圓上，圓心對準。把 P 轉到 0°（3 點鐘方向），用尺量 P 離 x 軸的高度（此時是 0），在右邊 0° 刻度上方 0 公分處畫一點。
5. 轉 30°：量 P 離 x 軸的垂直高度（應該約 5 公分，因為 10 × sin 30° = 5），在 30° 刻度上方 5 公分畫一點。
6. 繼續每 30° 做一次：60°（8.7 公分）、90°（10 公分）、120°（8.7）、150°（5）、180°（0）、210°（−5，畫在 x 軸下方）、240°（−8.7）、270°（−10）、300°（−8.7）、330°（−5）、360°（0）。
7. 把 13 個點用平滑曲線連起來。
8. 進階：把每個點的「水平座標」（P 離 y 軸的左右距離）也量出來，在另一張紙畫出來，那是 cos 波。

**你應該看到／得到**：一條從 0 上升到 10、再降到 −10、再回到 0 的平滑波。它的振幅就是圓的半徑，週期就是轉一圈。你會親手證明：**正弦波就是轉圈的影子**。

### 活動 6-2：用手機頻譜看音叉與拍頻

**材料／工具**：手機裝免費頻譜 App（搜尋「Spectroid」（Android）或「頻譜分析」「Spectrum Analyzer」（iPhone））、能發出固定音的東西（音叉最好；沒有的話用另一支手機搜尋「440 Hz tone」和「442 Hz tone」線上播放、或用吉他的 A 弦）、安靜的房間。

**步驟**

1. 打開頻譜 App，螢幕橫軸是頻率（Hz）、縱軸是強度。先安靜一下，看背景雜訊長什麼樣。
2. 播放 440 Hz。你會看到在 440 的位置冒出一根尖峰。記下 App 顯示的峰值頻率。
3. 換播 880 Hz（高八度）。尖峰移到右邊兩倍遠。
4. 如果用吉他或音叉：撥 A 弦，看尖峰。你會看到不只一根——440 旁邊還有 880、1320……這些是「泛音」，是弦同時以好幾種方式振動的結果，也是每種樂器音色不同的原因。
5. 拍頻：同時播放 440 Hz 和 442 Hz（兩支手機或兩個分頁）。用耳朵聽：音量每秒「嗡—嗡—」兩次。
6. 再試 440 和 445：每秒 5 次，快到快聽不清。再試 440 和 460：變成一種粗糙的聲音，拍頻太快，耳朵已經分不出一次次的起伏。
7. 如果 App 有「波形」模式（顯示聲音對時間的圖，就像示波器），切過去看拍頻的包絡線。

**你應該看到／得到**：純音在頻譜上是一根細尖峰，位置就是頻率。兩個頻率差 Δf 的音一起響，每秒聽到 Δf 次強弱變化。你的耳朵就是一台拍頻偵測器。

### 活動 6-3：記錄一天的氣溫，擬合一條波

**材料／工具**：手機天氣 App（有逐小時預報或過去 24 小時紀錄）、方格紙或試算表。

**步驟**

1. 從天氣 App 抄下今天 24 小時每小時的氣溫（0 時到 23 時）。
2. 畫成圖：橫軸小時、縱軸溫度。
3. 找最高溫 Tmax（通常下午 2 點左右）和最低溫 Tmin（清晨 5 點左右）。中線 C = (Tmax + Tmin) / 2，振幅 A = (Tmax − Tmin) / 2。
4. 週期是 24 小時，所以 ω = 2π/24。最高點在 14 時，sin 的最高點在 ωt + φ = π/2 處，所以 φ = π/2 − 2π × 14/24 = π/2 − 7π/6 = −2π/3。
5. 寫出公式 T(t) = C + A sin(2πt/24 − 2π/3)，算幾個小時的值，畫在同一張圖上和實際資料比。

**你應該看到／得到**：早晚的部分大致吻合，但真實氣溫不是完美的正弦（白天升溫快、晚上降溫慢），所以會有偏差。這正是重點：正弦波是「最簡單的來回」，真實世界是很多正弦波疊起來的——這個想法以後叫傅立葉分析，本書不講，但你已經摸到門口了。

## 用工具看看

**Desmos（https://www.desmos.com/calculator ）：疊加兩個正弦波**

1. 第一列輸入 `y = sin(x)`。先確認右上角設定是「弧度」。
2. 第二列輸入 `y = sin(1.1x)`。兩條波一開始重疊，越往右越錯開。
3. 第三列輸入 `y = sin(x) + sin(1.1x)`。把 x 軸範圍拉到 −10 到 130（點左右兩邊的圖表設定，或用滑鼠縮放）。你會看到拍頻：振幅從 2 縮到 0 再回到 2，一個「包」的長度是 2π/0.1 ≈ 62.8。
4. 改第二列為 `y = sin(x + π)`（打 `pi` 會變成 π），第三列變成一條完全平的線 y = 0：反相抵消。
5. 旋鈕練習：輸入 `y = A sin(w x + p)`，Desmos 會問你要不要為 A、w、p 加滑桿，按「全部」。拖動 A 看振幅、拖 w 看疏密、拖 p 看左右移。把 A 設 155.6、w 設 377，x 軸範圍 0 到 0.05：這就是插座裡的電壓對時間圖，三個週期。
6. 進階：輸入 `y = sin(x) + sin(3x)/3 + sin(5x)/5 + sin(7x)/7`。正弦波疊出一個越來越像方波的東西——示波器上的方波其實是無限多個正弦波的總和。

## 常見錯誤與迷思

- **錯誤：sin 150° 應該比 sin 90° 大，因為角度比較大** → 單位圓上 150° 的點已經開始往下走了。sin 在 90° 最大，之後下降。→ sin 不是「角越大越大」，它在 0 到 1 之間上上下下。
- **錯誤：sin 不能是負的** → 直角三角形的 sin 不會是負的，但單位圓定義下，P 跑到 x 軸下方時 y 座標為負。→ 180° 到 360° 之間 sin 為負；90° 到 270° 之間 cos 為負。
- **錯誤：y = sin(2x) 的週期是 4π** → 2x 跑完 2π 時 x 只跑了 π，所以波被壓密，週期變 π。→ 週期 = 2π ÷ ω，ω 越大週期越短。
- **錯誤：振幅就是最高點的值** → y = 22 − 20 cos t 的最高點 42，振幅是 20。→ 振幅是「離中線」的最大距離，等於（最高 − 最低）÷ 2。
- **錯誤：示波器上 Vpp = 4 V 代表振幅 4 V** → Vpp 是峰到峰，從最低到最高。→ 振幅 A = Vpp ÷ 2 = 2 V。
- **錯誤：兩個聲音一起響一定更大聲** → 相位相反時會抵消；頻率接近時會忽大忽小。→ 疊加是「每一瞬間相加」，結果可能更大、更小或起伏。
- **錯誤：拍頻是「兩個聲音混出來的第三個音」** → 拍頻不是一個新頻率的音，是音量的起伏。你聽到的音高是兩者的平均，起伏的快慢是兩者的差。→ 拍頻 = |f₁ − f₂|，是「每秒幾次忽大忽小」。
- **錯誤：Desmos 畫 sin(x) 看起來不對** → 可能設定成「度」，sin(x) 在 x = 1 到 10 之間幾乎是平的。→ 畫函數圖形時用弧度。

## 想一想

**1.** 不用計算機，用單位圓寫出 sin 210°、cos 300°、sin 180°、cos 90°、sin (−90°)。

<details><summary>參考答案</summary>

210° 在左下方，和 x 軸夾 30°，sin 為負：sin 210° = −1/2。300° 在右下方，和 x 軸夾 60°，cos 為正：cos 300° = 1/2。180° 在最左邊 (−1, 0)：sin 180° = 0。90° 在正上方 (0, 1)：cos 90° = 0。−90° 順時針到正下方 (0, −1)：sin (−90°) = −1。

</details>

**2.** 寫出下列函數的振幅、週期與最高最低值：(a) y = 3 sin(2x)；(b) y = 5 + 2 cos(x/2)；(c) y = −4 sin(πx)。

<details><summary>參考答案</summary>

(a) 振幅 3，週期 2π/2 = π，最高 3、最低 −3。(b) 振幅 2，週期 2π ÷ (1/2) = 4π，最高 7、最低 3。(c) 振幅 4（負號只是上下翻轉），週期 2π/π = 2，最高 4、最低 −4。

</details>

**3.** 台灣插座電壓是 v(t) = 155.6 sin(377t)（t 單位秒）。(a) 頻率是多少？(b) t = 1 毫秒時電壓是多少？(c) 第一次達到最高 155.6 V 是在什麼時候？

<details><summary>參考答案</summary>

(a) f = ω/2π = 377/6.283 ≈ 60 Hz。(b) v = 155.6 × sin(0.377) ≈ 155.6 × 0.368 ≈ 57.3 V（計算機用弧度）。(c) sin 最高在 377t = π/2 → t = 1.5708/377 ≈ 0.00417 秒 = 4.17 毫秒，正好是週期 16.7 毫秒的四分之一。

</details>

**4.** 示波器設定 2 V/div、200 µs/div。畫面上正弦波最高點在中線上方 1.5 格、最低點在下方 1.5 格，相鄰兩個最高點相隔 4 格。寫出這個訊號的 A、T、f、ω 和公式。

<details><summary>參考答案</summary>

A = 1.5 × 2 = 3 V（Vpp = 6 V）。T = 4 × 200 µs = 800 µs = 0.0008 秒。f = 1/0.0008 = 1250 Hz。ω = 2π × 1250 ≈ 7854。公式：v(t) = 3 sin(7854t + φ)，φ 要看 t = 0 時波在哪裡。

</details>

**5.** 某港口的潮位 h(t) = 2.0 + 1.2 sin(2πt / 12.4)，h 單位公尺，t 從今天 0 時起算的小時數。(a) 第一次漲到最高是幾點？最高幾公尺？(b) 一艘船需要水深至少 2.6 公尺才能進港，上午哪個時段可以進？（提示：解 sin(…) ≥ 0.5。）

<details><summary>參考答案</summary>

(a) sin 最高在 2πt/12.4 = π/2 → t = 12.4/4 = 3.1 小時，約凌晨 3 點 06 分，潮位 2.0 + 1.2 = 3.2 公尺。(b) 需要 1.2 sin(…) ≥ 0.6，即 sin(…) ≥ 0.5。sin 在 π/6 到 5π/6 之間 ≥ 0.5，所以 2πt/12.4 在 π/6 到 5π/6 → t 在 12.4/12 ≈ 1.03 到 12.4 × 5/12 ≈ 5.17 小時之間，大約凌晨 1 點 02 分到 5 點 10 分可以進港。下一次要等半個週期以後（約 13.4 到 17.6 時）。

</details>

**6.** 鋼琴調音師敲 440 Hz 音叉和一根琴弦，每秒聽到 3 次拍頻。他把弦稍微拉緊（頻率升高），拍頻變成每秒 5 次。這根弦原本的頻率是多少？他應該拉緊還是放鬆？

<details><summary>參考答案</summary>

原本 |f − 440| = 3，所以 f 是 437 或 443。拉緊後頻率升高、拍頻變大（5），表示離 440 更遠了，所以原本是 443 Hz（443 → 445，差 5）。如果原本是 437，拉緊會變 439，拍頻變 1 才對。所以他應該放鬆弦，讓 443 降到 440。

</details>

**7.** 摩天輪半徑 20 公尺、中心離地 22 公尺、8 分鐘一圈，從最低點出發：h(t) = 22 − 20 cos(2πt/480)，t 單位秒。(a) 第 100 秒時離地幾公尺？(b) 哪些時刻離地剛好 32 公尺？（一圈內找出兩個。）

<details><summary>參考答案</summary>

(a) 2π × 100/480 = 1.309 弧度，cos(1.309) = 0.259，h = 22 − 5.18 ≈ 16.8 公尺。(b) 22 − 20 cos θ = 32 → cos θ = −0.5 → θ = 2π/3 或 4π/3（120° 或 240°）。t = 480 × (2π/3) / 2π = 160 秒，以及 t = 320 秒。驗算：t = 160 秒是 1/3 圈，點在左上方，高度 22 + 20 × 0.5 = 32，對。

</details>

**8.（挑戰）** 為什麼 sin(x) + sin(1.1x) 會出現拍頻？用「兩個轉速不同的摩天輪」解釋：兩個摩天輪一個 8 分鐘一圈、一個 8.8 分鐘一圈，兩個人同時從最低點出發。多久以後兩個人會「一個在最高、一個在最低」？多久以後又回到「同時在最低」？這個時間和拍頻有什麼關係？

<details><summary>參考答案</summary>

快的摩天輪每分鐘轉 1/8 圈，慢的每分鐘轉 1/8.8 圈，每分鐘快的多轉 1/8 − 1/8.8 = 0.0114 圈。領先半圈（一個最高、一個最低，高度相加最接近中線，相當於抵消）需要 0.5 ÷ 0.0114 ≈ 44 分鐘；領先一整圈（又同時在最低，相當於同相、相加最大）需要 1 ÷ 0.0114 = 88 分鐘。所以兩人的高度和每 88 分鐘「強—弱—強」一次。拍頻 = 1/88 每分鐘 = 1/8 − 1/8.8 = f₁ − f₂。這就是拍頻公式的來源：兩個波的相位差以 (f₁ − f₂) 的速率累積，每累積一整圈就完成一次強弱循環。

</details>

## 本章小結

- 單位圓：從 x 軸逆時針轉 θ，停下的點的 x 座標是 cos θ、y 座標是 sin θ。這和直角三角形的定義在 0°–90° 完全一致，但可以推廣到任何角度。
- sin 和 cos 在各象限的正負由點的位置決定；每轉一圈（2π）值就重複，這是週期性。
- 把 sin θ 對 θ 畫出來就是正弦波：振幅 1、週期 2π；cos 是提前 π/2 的 sin。
- y = C + A sin(ωt + φ)：C 是中線、A 是振幅、ω 是角速度（週期 T = 2π/ω、頻率 f = ω/2π）、φ 是相位（起點）。
- 交流電、聲音、潮汐、季節、摩天輪都是這條公式。台灣家用電 v = 155.6 sin(377t)。
- 兩個波疊加就是每一瞬間相加：同相加倍、反相抵消、頻率接近出現拍頻，拍頻 = |f₁ − f₂|。
- 示波器上讀振幅（格數 × V/div，= Vpp/2）和週期（格數 × s/div），就能寫出波的公式。

## 名詞表

| 中文 | 英文 | 一句話解釋 |
|---|---|---|
| 單位圓 | Unit Circle | 圓心在原點、半徑 1 的圓，用來定義任意角的三角函數 |
| 三角函數 | Trigonometric Function | 把角度（或時間）對應到 sin、cos 值的函數，圖形是波 |
| 正弦波 | Sine Wave | y = sin x 的圖形，最簡單的週期波 |
| 週期 | Period (T) | 波重複一次所需的時間或長度 |
| 振幅 | Amplitude (A) | 波離中線的最大距離 |
| 頻率 | Frequency (f) | 每秒重複的次數，單位赫茲（Hz），f = 1/T |
| 角速度 | Angular Frequency (ω) | 每秒轉過的弧度，ω = 2πf |
| 相位 | Phase (φ) | 波的起點位置，決定波左右移動多少 |
| 週期性 | Periodicity | 函數每隔固定間隔就重複的性質 |
| 疊加 | Superposition | 兩個波同時存在時，每一瞬間的值相加 |
| 拍頻 | Beat | 兩個頻率接近的波疊加後音量的週期性起伏，頻率為兩者之差 |
| 峰對峰值 | Peak-to-Peak (Vpp) | 示波器上最高點到最低點的差，等於振幅的 2 倍 |
| 有效值 | RMS Value | 交流電「相當於多少直流」的值，正弦波的峰值是有效值的 √2 倍 |
