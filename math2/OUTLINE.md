# 《數學這樣想（進階）：從函數、三角到微積分》全書大綱

共用規範：/Users/vichuang/Codes/electric-course/STYLE_GUIDE.md。檔名 `src/NN-章名.md`。
本書是《數學這樣想》（https://book.vichuang.tw/math/ ）的第二冊，讀者是讀完第一冊、對數學有興趣的國小高年級資優生到國中生，以及想重新把高中數學與微積分學懂的大人。**本書可以使用超過共用規範的數學程度**（根號、指數、對數、三角、極限、導數、積分），但每個新工具都要從直覺與具體例子建起來，不假設讀者先會。數學式用純文字與 Unicode（x²、√x、sin θ、π、Σ、∫、dy/dx、≈、→），不用 LaTeX；函數圖形用 ASCII 或用表格列點。每章「動手做」是量東西、畫圖、數值實驗、用零用錢與生活情境；「用工具看看」用免費的 Desmos 或 GeoGebra 畫圖、Google 試算表算數值，第 9 章起加 Python（Google Colab）做數值微分積分，程式要完整可執行。每章「想一想」6–8 題真正的練習題附詳解。

- 00-前言.md：給誰的、這本書和第一冊的關係、為什麼微積分國中生也能懂（它只是「變化」與「累積」）、怎麼讀、給陪讀家長、工具（Desmos、GeoGebra、試算表、Colab）、全書地圖。
- 01-函數.md：函數是「輸入 → 規則 → 輸出」的機器；定義域與值域；函數圖形怎麼讀；一次、二次、反比、絕對值的形狀；平移與伸縮；合成函數與反函數的直覺。活動：自製函數機（投幣販賣機）；量自己家水龍頭流量畫圖。
- 02-二次函數與多項式.md：y = ax² + bx + c 的拋物線；配方法找頂點；最大最小問題（圍籬最大面積）；因式分解與解方程；多項式的次數與形狀。活動：丟球錄影找拋物線；用繩子圍最大面積。
- 03-指數.md：指數律從「重複乘」推出；負指數與分數指數的意義；指數成長與衰減（細菌、複利、半衰期、摩爾定律）；e 的直覺（連續複利）。活動：摺紙對摺 42 次到月球；用試算表模擬複利與病毒傳播。
- 04-對數.md：對數是「指數的反問題：要乘幾次」；log 法則與為什麼；常用對數與自然對數；對數刻度（分貝、pH、地震規模、對數圖）；對數幫你看懂大數字。活動：用對數刻度畫出從病毒到宇宙的尺寸；量聲音分貝。
- 05-三角比.md：直角三角形的 sin、cos、tan 是「比值」；為什麼同一角度比值固定（相似）；用三角比量樹高、樓高、距離；30°、45°、60° 的值；反三角比的意思；角度與弧度。活動：自製量角器測樓高；用手機傾斜儀。
- 06-三角函數與波.md：單位圓定義把角度推廣到任意角；sin、cos 圖形與週期、振幅、相位；y = A sin(ωt + φ) 描述聲音、交流電、潮汐、季節溫度；疊加與拍頻直覺（連結《動手玩電》示波器）。活動：轉動物體投影畫正弦波；用手機頻譜看音叉；用 Desmos 疊加兩個正弦波。
- 07-數列與級數.md：等差與等比數列、遞迴（費波那契）、Σ 記號、等差與等比級數和的推導、無窮等比級數收斂（0.999… = 1、芝諾悖論）。活動：摺紙與米粒棋盤；用試算表算級數部分和看收斂。
- 08-極限.md：數列的極限（越來越接近）；函數在一點的極限；左極限右極限；連續；無窮大與 1/x；極限是微積分的語言，但只用直覺與數值表，不用 ε-δ。活動：用試算表算 (1 + 1/n)ⁿ 看 e；用計算機逼近 sin x / x。
- 09-微分一變化率.md：平均速度 → 瞬時速度；割線 → 切線；導數的定義 f'(x) = lim (f(x+h) − f(x)) / h；用定義算 x²、x³；導數是「斜率函數」；基本公式（xⁿ、常數、和差、常數倍）；用 Python 做數值微分。活動：錄影玩具車算瞬時速度；畫切線量斜率。
- 10-微分二規則與函數.md：乘積、商、鏈鎖法則的直覺與例子；sin、cos、eˣ、ln x 的導數（用圖與數值說明為什麼）；高階導數與加速度；隱函數簡介（選配）。活動：用 Desmos 畫 f 與 f' 對照；用試算表驗證 d/dx sin = cos。
- 11-微分的應用.md：遞增遞減與極值；最大最小問題（最省材料的罐頭、最大面積、最快路徑）；相關變化率（氣球膨脹、梯子滑落）；牛頓法求根（選配）；線性近似。活動：做出最省紙的罐頭並驗證；量氣球充氣速度。
- 12-積分一累積與面積.md：從「速度曲線下面積 = 距離」出發；黎曼和（長方形逼近）；定積分的定義與記號 ∫；用試算表算黎曼和看收斂；反導數與不定積分；微積分基本定理為什麼成立（累積函數的變化率就是原函數）。活動：用方格紙數格子算曲線下面積；用水桶流量算累積水量。
- 13-積分二技巧與應用.md：基本積分公式；代換法的直覺；分部積分簡介（選配）；面積、兩曲線間面積、旋轉體體積（圓盤法）、平均值、功與距離。活動：算一個花瓶的體積並用量杯驗證；Python 數值積分。
- 14-微分方程與模型.md（選配）：dy/dt = ky 的意義（成長衰減）；牛頓冷卻；邏輯斯成長；用試算表或 Python 做尤拉法數值模擬。活動：量一杯熱水冷卻曲線並用模型擬合。
- 15-專題.md：四個專題：(1) 雲霄飛車設計（函數拼接、斜率、曲率直覺、Desmos）；(2) 漏水的水桶（流量、積分、微分方程、實測）；(3) 最佳化：設計最省材料的包裝盒；(4) 用 Python 模擬投籃軌跡與最佳角度（含空氣阻力選配）。附專題報告格式。
- appendix-A.md：公式速查（函數、指數對數、三角、數列、極限、導數、積分表），每條附算例與一句「為什麼」。
- appendix-B.md：Desmos、GeoGebra、試算表、Python（Colab）操作速查，含數值微分積分範例程式。
- appendix-C.md：常見錯誤總表（至少 40 條）。
- appendix-D.md：名詞對照表（中英）。
- 16-傅立葉與拉普拉斯.md（延伸章，放在專題之後）：**只講原理與用途，不推導、不嚇人。** 傅立葉級數：任何週期訊號都可以拆成一堆正弦波相加（用方波 = sin x + sin 3x/3 + sin 5x/5 … 的逐項疊加表格與 ASCII 圖讓讀者「看到」）；頻譜的概念（時間域 vs 頻率域，像把一杯果汁拆回水果）；用在哪裡：音樂與 MP3、手機頻譜 App、示波器的 FFT 功能（連結《動手玩電》）、JPEG 圖片壓縮、降噪耳機、心電圖。拉普拉斯轉換：把「隨時間變化的問題（微分方程）」變成「代數問題」再變回來的翻譯機，像把乘除換成加減的對數；s 是什麼的直覺（衰減與振盪的組合）；用在哪裡：電路（RC 濾波為什麼是 1/(1+sRC)）、控制（恆溫器、無人機平衡、自駕車）、機械震動、訊號處理；工程師怎麼用查表而不是手算。動手做：用試算表或 Python 逐項疊加正弦波做出方波與三角波；用手機頻譜 App 看自己的聲音有哪些頻率；用 RC 電路或試算表模擬看低頻通過高頻被擋。用工具看看：Python 用 numpy 做 FFT 把一段合成訊號拆回頻率；Desmos 滑桿疊加正弦波。想一想：以概念題為主。
